### derivative (0.0s)

## 导数

**定义。** 设函数 $f$ 在点 $x_0$ 的某邻域内有定义。若极限

$$f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h}$$

存在且有限，则称 $f$ 在点 $x_0$ **可微**，并将该极限值称为 $f$ 在 $x_0$ 处的**导数**（derivative）。几何上，$f'(x_0)$ 即曲线 $y = f(x)$ 在点 $(x_0,\, f(x_0))$ 处切线的斜率；物理上，若 $f(t)$ 表示位移，则 $f'(t)$ 表示瞬时速度。

---

**例题。** 求 $f(x) = x^2$ 在 $x_0 = 3$ 处的导数。

按定义展开差商：

$$\frac{f(3+h) - f(3)}{h} = \frac{(3+h)^2 - 9}{h} = \frac{9 + 6h + h^2 - 9}{h} = 6 + h.$$

令 $h \to 0$，得

$$f'(3) = \lim_{h \to 0}(6 + h) = 6.$$

几何验证：曲线 $y = x^2$ 在点 $(3, 9)$ 处的切线方程为 $y - 9 = 6(x - 3)$，即 $y = 6x - 9$。

---

**定理（可微必连续）。** 若 $f$ 在 $x_0$ 处可微，则 $f$ 在 $x_0$ 处连续。

**证明思路。** 将函数增量写成

$$f(x_0 + h) - f(x_0) = \frac{f(x_0+h)-f(x_0)}{h} \cdot h.$$

当 $h \to 0$ 时，右端第一个因子趋向 $f'(x_0)$（有限值），第二个因子 $h \to 0$，故乘积趋向 $0$，即 $\lim_{h\to 0} f(x_0+h) = f(x_0)$，连续性得证。$\blacksquare$

注意逆命题不成立：$f(x) = |x|$ 在 $x = 0$ 处连续但不可微，因为左右极限 $\lim_{h\to 0^-} h/|h| = -1 \neq 1 = \lim_{h\to 0^+} h/|h|$ 不相等。

---

**实验单元（SymPy）。**

```python
import sympy as sp

x, h = sp.symbols('x h')
f = x**2

# 用极限定义计算导数
diff_quot = (f.subs(x, x + h) - f) / h
derivative = sp.limit(diff_quot, h, 0)
print(derivative)          # 输出：2*x

# 符号求导验证
print(sp.diff(f, x))       # 输出：2*x
```

运行上述代码，两种方式均输出 $2x$，与幂函数求导公式 $(x^n)' = nx^{n-1}$（取 $n=2$）完全一致。

### absolute_extrema (0.0s)

## Absolute Extrema

**定义。** 设函数 $f$ 定义在区间 $I$ 上。若存在点 $c \in I$，使得对所有 $x \in I$ 均有 $f(c) \geq f(x)$，则称 $f(c)$ 为 $f$ 在 $I$ 上的**绝对最大值**（全局最大值）；若对所有 $x \in I$ 均有 $f(c) \leq f(x)$，则称 $f(c)$ 为 $f$ 在 $I$ 上的**绝对最小值**（全局最小值）。绝对最大值与绝对最小值统称为**绝对极值**（绝对极端值）。

**极值存在定理（闭区间定理）。** 若函数 $f$ 在闭区间 $[a, b]$ 上连续，则 $f$ 在 $[a, b]$ 上必同时取得绝对最大值与绝对最小值。该定理的两个条件——连续性与闭区间——缺一不可：开区间 $(0,1)$ 上的函数 $f(x)=x$ 连续却无绝对最大值；闭区间 $[0,1]$ 上的分段函数若含跳跃间断点，同样可能失去极值。

**求法（候选点法）。** 绝对极值只能在以下三类点上取得：（1）区间端点 $a$、$b$；（2）区间内部满足 $f'(c)=0$ 的**驻点**；（3）区间内部 $f'$ 不存在的**奇异点**。依次计算这些候选点处的函数值，最大者为绝对最大值，最小者为绝对最小值。

**例题。** 求 $f(x) = x^3 - 3x^2 + 1$ 在 $[-\tfrac{1}{2},\, 3]$ 上的绝对极值。

*解：* 首先求导：$f'(x) = 3x^2 - 6x = 3x(x-2)$。令 $f'(x)=0$，得驻点 $x=0$ 与 $x=2$，均在区间内。列表计算各候选点处的函数值：

| 候选点 | $f$ 值 |
|--------|--------|
| $x = -\tfrac{1}{2}$ | $(-\tfrac{1}{2})^3 - 3(\tfrac{1}{4}) + 1 = \tfrac{1}{8}$ |
| $x = 0$ | $1$ |
| $x = 2$ | $8 - 12 + 1 = -3$ |
| $x = 3$ | $27 - 27 + 1 = 1$ |

比较可知，绝对最大值为 $\boxed{1}$（在 $x=0$ 与 $x=3$ 处同时取得），绝对最小值为 $\boxed{-3}$（在 $x=2$ 处取得）。

**实验单元（SymPy）。**

```python
from sympy import *
x = symbols('x')
f = x**3 - 3*x**2 + 1
interval = Rational(-1,2), 3

crit = solve(diff(f, x), x)
candidates = list(interval) + [c for c in crit if interval[0] < c < interval[1]]
vals = {c: f.subs(x, c) for c in candidates}
print("绝对最大值:", max(vals, key=vals.get), "→", max(vals.values()))
print("绝对最小值:", min(vals, key=vals.get), "→", min(vals.values()))
```

### critical_point (0.0s)

## 极值点

**定义。** 设函数 $f$ 在开区间 $I$ 上可微。若某点 $c \in I$ 满足

$$f'(c) = 0$$

或 $f'(c)$ 不存在，则称 $c$ 为 $f$ 的**极值点**（临界点）。极值点是函数局部极大值或局部极小值的*必要候选*，但并非所有极值点都对应极值。

几何上，$f'(c)=0$ 意味着曲线 $y=f(x)$ 在 $x=c$ 处的切线为水平线；导数不存在的点（如尖角或竖直切线处）同样需要检验。

---

**例题。** 设 $f(x) = x^3 - 3x + 2$，求其所有极值点并判断类型。

**第一步：求导并令导数为零。**

$$f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$$

令 $f'(x)=0$，解得 $x=1$ 与 $x=-1$，均为极值点候选。

**第二步：用第二导数检验。**

$$f''(x) = 6x$$

- $x=-1$：$f''(-1)=-6<0$，故 $f$ 在 $x=-1$ 处取得**局部极大值** $f(-1)=4$。  
- $x=1$：$f''(1)=6>0$，故 $f$ 在 $x=1$ 处取得**局部极小值** $f(1)=0$。

---

**关键定理（费马定理）。** 若 $f$ 在点 $c$ 处可微，且 $c$ 为局部极值点，则

$$f'(c) = 0.$$

**证明思路：** 不妨设 $c$ 为局部极大值点，则存在 $\delta>0$，对一切 $|h|<\delta$ 有 $f(c+h)\le f(c)$。

$$\lim_{h\to 0^+}\frac{f(c+h)-f(c)}{h}\le 0, \qquad \lim_{h\to 0^-}\frac{f(c+h)-f(c)}{h}\ge 0.$$

由于导数存在，两个单侧极限相等，故必有 $f'(c)=0$。$\blacksquare$

注意：定理的逆命题不成立。$g(x)=x^3$ 在 $x=0$ 处有 $g'(0)=0$，但该点为**鞍点**（拐点），并非极值。

---

**实验单元（SymPy）**

```python
from sympy import symbols, diff, solve, latex

x = symbols('x')
f = x**3 - 3*x + 2
fp  = diff(f, x)
fpp = diff(fp, x)

critical_pts = solve(fp, x)
for c in critical_pts:
    val   = f.subs(x, c)
    test  = fpp.subs(x, c)
    kind  = "局部极小" if test > 0 else "局部极大" if test < 0 else "需进一步检验"
    print(f"x = {c}: f(x) = {val}, f''(x) = {test} → {kind}")
```

运行后将输出 $x=-1$（局部极大，$f=4$）与 $x=1$（局部极小，$f=0$），与手算结果完全一致。

### local_extrema (0.0s)

## Local Extrema

**定义。** 设函数 $f$ 在点 $c$ 的某邻域内有定义。若存在 $\delta > 0$，使得对所有满足 $|x - c| < \delta$ 的 $x$，均有 $f(x) \leq f(c)$，则称 $c$ 为 $f$ 的**局部极大值点**，$f(c)$ 为对应的**局部极大值**。类似地，若 $f(x) \geq f(c)$ 对上述邻域内所有 $x$ 成立，则 $c$ 为**局部极小值点**。局部极大值点与局部极小值点统称为**局部极值点**（local extrema）。

**费马定理（必要条件）。** 若 $f$ 在 $c$ 处可微且 $c$ 为局部极值点，则 $f'(c) = 0$。

> *证明思路：* 不妨设 $c$ 为局部极大值点。对 $h > 0$ 充分小，有
> $$\frac{f(c+h)-f(c)}{h} \leq 0, \quad \frac{f(c-h)-f(c)}{-h} \geq 0.$$
> 令 $h \to 0^+$，两侧均趋向 $f'(c)$，故 $f'(c) \leq 0$ 且 $f'(c) \geq 0$，即 $f'(c) = 0$。

注意费马定理仅给出必要条件：$f'(c) = 0$ 的点称为**驻点**，驻点未必是极值点（如 $f(x) = x^3$ 在 $x = 0$ 处）。

**二阶导数判别法（充分条件）。** 设 $f'(c) = 0$ 且 $f''(c)$ 存在。若 $f''(c) < 0$，则 $c$ 为局部极大值点；若 $f''(c) > 0$，则 $c$ 为局部极小值点；若 $f''(c) = 0$，则此判别法失效，需进一步分析。

**例题。** 求 $f(x) = x^3 - 3x$ 的局部极值。

令 $f'(x) = 3x^2 - 3 = 0$，解得 $x = \pm 1$。计算二阶导数：$f''(x) = 6x$。

- 在 $x = -1$：$f''(-1) = -6 < 0$，故 $x = -1$ 为局部极大值点，$f(-1) = 2$。
- 在 $x = 1$：$f''(1) = 6 > 0$，故 $x = 1$ 为局部极小值点，$f(1) = -2$。

**实验单元（SymPy）。**

```python
from sympy import symbols, diff, solve, latex

x = symbols('x')
f = x**3 - 3*x
fp = diff(f, x)
critical = solve(fp, x)
fpp = diff(fp, x)
for c in critical:
    print(f"x={c}: f''={fpp.subs(x,c)}, f(c)={f.subs(x,c)}")
```

### extreme_value_theorem (0.0s)

## Extreme Value Theorem

**定义.** 设 $f$ 为定义在闭区间 $[a, b]$ 上的连续函数。**极值定理**（Extreme Value Theorem，EVT）断言：$f$ 在 $[a, b]$ 上必然取得其最大值与最小值，即存在点 $c, d \in [a, b]$，使得对所有 $x \in [a, b]$，均有

$$
f(d) \leq f(x) \leq f(c).
$$

此处，$f(c)$ 称为 $f$ 在 $[a, b]$ 上的**全局最大值**，$f(d)$ 称为**全局最小值**。定理成立的两个关键条件缺一不可：区间必须**有界且闭合**，函数必须**连续**。若去掉任一条件，结论可能失效——例如 $f(x) = x$ 在开区间 $(0, 1)$ 上连续，却无最大值。

---

**例题.** 求 $f(x) = x^3 - 3x$ 在 $[-2, 2]$ 上的全局极值。

**解：** 首先求驻点。令

$$
f'(x) = 3x^2 - 3 = 0 \implies x = \pm 1.
$$

两个驻点均属于 $(-2, 2)$，因此候选点为端点与驻点共四处：

| $x$ | $f(x)$ |
|-----|--------|
| $-2$ | $(-8)+6 = -2$ |
| $-1$ | $-1+3 = 2$ |
| $1$ | $1-3 = -2$ |
| $2$ | $8-6 = 2$ |

比较可得：**全局最大值**为 $f(-1) = f(2) = 2$，**全局最小值**为 $f(-2) = f(1) = -2$。

---

**关键定理（证明思路）.** 极值定理的严格证明依赖实数完备性。其核心步骤如下：

1. 因 $[a,b]$ 为紧集，$f$ 连续，故 $f([a,b])$ 亦为紧集（连续映射保紧性）。
2. $\mathbb{R}$ 中的紧子集有界且闭合，因而其上确界 $M = \sup_{x\in[a,b]} f(x)$ 属于该集合。
3. 故存在 $c \in [a,b]$ 使 $f(c) = M$；最小值同理可证。$\blacksquare$

---

**实验单元（SymPy）.**

```python
from sympy import *
x = symbols('x')
f = x**3 - 3*x
interval = (-2, 2)

candidates = [interval[0], interval[1]] + solve(diff(f, x), x)
values = {c: f.subs(x, c) for c in candidates if interval[0] <= c <= interval[1]}

print("全局最大值:", max(values, key=values.get), "→", max(values.values()))
print("全局最小值:", min(values, key=values.get), "→", min(values.values()))
```

运行结果将验证上述手算结论，并展示如何利用符号计算系统性地搜索极值候选点。

### fermats_theorem (0.0s)

## 费马定理

### 定义

设 $p$ 为素数，$a$ 为整数且 $\gcd(a, p) = 1$（即 $p \nmid a$），则

$$a^{p-1} \equiv 1 \pmod{p}.$$

这一结论称为**费马小定理**（Fermat's Little Theorem），是初等数论中最基本的同余结果之一。其等价形式为：对任意整数 $a$ 及素数 $p$，均有

$$a^p \equiv a \pmod{p},$$

此形式无需对 $p \nmid a$ 加以额外假设。

### 证明思路

考虑集合 $S = \{1, 2, \ldots, p-1\}$，共 $p-1$ 个元素。将 $S$ 中每个元素乘以 $a$ 后对 $p$ 取余，得到集合 $\{a \cdot 1,\, a \cdot 2,\, \ldots,\, a \cdot (p-1)\} \pmod{p}$。由于 $\gcd(a,p)=1$，乘法映射在 $\mathbb{Z}/p\mathbb{Z}^*$ 上是双射，故该集合仍为 $S$ 的一个排列。于是

$$\prod_{k=1}^{p-1}(ak) \equiv \prod_{k=1}^{p-1} k \pmod{p},$$

即 $a^{p-1}(p-1)! \equiv (p-1)! \pmod{p}$。因 $\gcd((p-1)!, p) = 1$，两边约去 $(p-1)!$ 得 $a^{p-1} \equiv 1 \pmod{p}$。$\blacksquare$

### 具体例子

取素数 $p = 7$，$a = 3$。费马小定理预言 $3^6 \equiv 1 \pmod{7}$。

逐步验证：

$$3^1 = 3,\quad 3^2 = 9 \equiv 2,\quad 3^3 \equiv 6,\quad 3^4 \equiv 18 \equiv 4,\quad 3^5 \equiv 12 \equiv 5,\quad 3^6 \equiv 15 \equiv 1 \pmod{7}.$$

结果与定理完全吻合。

### 关键定理（推论：模逆元）

若 $p$ 为素数且 $p \nmid a$，则 $a$ 在模 $p$ 意义下的乘法逆元为

$$a^{-1} \equiv a^{p-2} \pmod{p}.$$

这是费马小定理在密码学（如 RSA 算法）和组合数学中计算模逆元的核心应用。

### 实验单元（SymPy）

```python
from sympy import isprime, mod_inverse

p, a = 7, 3
assert isprime(p)

# 验证费马小定理
print(pow(a, p - 1, p))          # 输出 1

# 利用费马定理计算逆元
inv_fermat = pow(a, p - 2, p)
inv_sympy  = mod_inverse(a, p)
print(inv_fermat, inv_sympy)      # 均输出 5，因为 3×5=15≡1 (mod 7)
```

### limits_at_infinity (0.0s)

## Limits At Infinity

### 定义

设函数 $f(x)$ 在区间 $(a, +\infty)$ 上有定义。若对任意 $\varepsilon > 0$，存在 $M > 0$，使得当 $x > M$ 时，恒有

$$|f(x) - L| < \varepsilon,$$

则称当 $x \to +\infty$ 时，$f(x)$ 的**极限为** $L$，记作

$$\lim_{x \to +\infty} f(x) = L.$$

类似地，可定义 $\lim_{x \to -\infty} f(x) = L$。若上述两个单侧极限均等于 $L$，则称 $\lim_{x \to \infty} f(x) = L$，此时直线 $y = L$ 称为函数图像的**水平渐近线**。

---

### 例题

求极限 $\displaystyle\lim_{x \to +\infty} \frac{3x^2 - 2x + 1}{5x^2 + 4}$。

**解：** 分子、分母同除以 $x^2$（$x \to +\infty$ 时 $x^2 > 0$）：

$$\lim_{x \to +\infty} \frac{3 - \dfrac{2}{x} + \dfrac{1}{x^2}}{5 + \dfrac{4}{x^2}}.$$

由于 $\dfrac{1}{x} \to 0$ 且 $\dfrac{1}{x^2} \to 0$（当 $x \to +\infty$），代入得

$$\frac{3 - 0 + 0}{5 + 0} = \frac{3}{5}.$$

故 $y = \dfrac{3}{5}$ 为该函数的水平渐近线。

---

### 关键定理

**有理函数无穷极限定理：** 设 $f(x) = \dfrac{a_n x^n + \cdots + a_0}{b_m x^m + \cdots + b_0}$，$a_n \neq 0$，$b_m \neq 0$，则

$$\lim_{x \to \infty} f(x) = \begin{cases} \dfrac{a_n}{b_m}, & n = m, \\[6pt] 0, & n < m, \\[4pt] \text{不存在（趋于} \pm\infty\text{）}, & n > m. \end{cases}$$

**证明思路：** 将分子分母同除以 $x^{\max(n,m)}$，利用 $\lim_{x\to\infty} x^{-k} = 0$（$k > 0$）逐项化简，再由极限的四则运算法则得到结论。

---

### 实验单元（SymPy）

```python
from sympy import symbols, limit, oo, Rational

x = symbols('x')
f = (3*x**2 - 2*x + 1) / (5*x**2 + 4)

print(limit(f, x, oo))   # 输出：3/5
print(limit(f, x, -oo))  # 输出：3/5
```

运行上述代码，验证两个单侧极限均为 $\dfrac{3}{5}$，与手算结果一致。读者可尝试修改分子或分母的次数，观察极限如何随阶数关系的变化而改变。

### rolles_theorem (20.1s)

## Rolles Theorem

### 定义

设函数 $f$ 满足以下三个条件：

1. $f$ 在闭区间 $[a, b]$ 上连续；
2. $f$ 在开区间 $(a, b)$ 上可微；
3. $f(a) = f(b)$。

则存在至少一点 $c \in (a, b)$，使得

$$f'(c) = 0.$$

这一结论称为**罗尔定理**（Rolle's Theorem）。直观上，若一条光滑曲线在两端点处取相同的函数值，则曲线上必存在某处"水平切线"，即导数为零的点。

### 证明思路

由于 $f$ 在 $[a, b]$ 上连续，根据极值定理，$f$ 必在该区间上取到最大值 $M$ 与最小值 $m$。

- 若 $M = m$，则 $f$ 为常函数，从而 $(a,b)$ 内任意点均满足 $f'(c) = 0$。
- 若 $M > m$，则最大值或最小值中至少有一个在开区间 $(a,b)$ 内某点 $c$ 处取到。由费马定理，可微函数在内部极值点处导数为零，故 $f'(c) = 0$。$\blacksquare$

### 具体例题

**题目：** 设 $f(x) = x^2 - 4x + 3$，验证罗尔定理在区间 $[1, 3]$ 上成立，并求满足条件的点 $c$。

**解：**

首先检验三个条件：
- $f$ 为多项式，在 $[1,3]$ 上连续且在 $(1,3)$ 上可微；
- $f(1) = 1 - 4 + 3 = 0$，$f(3) = 9 - 12 + 3 = 0$，故 $f(1) = f(3)$。

三个条件均满足。对 $f$ 求导：

$$f'(x) = 2x - 4.$$

令 $f'(c) = 0$，得

$$2c - 4 = 0 \implies c = 2.$$

因 $2 \in (1, 3)$，故 $c = 2$ 即为所求点。

### 关键定理

罗尔定理是**拉格朗日中值定理**（Lagrange's Mean Value Theorem）的特殊情形，后者将端点等值的限制推广为一般斜率，断言存在 $c \in (a,b)$ 使得

$$f'(c) = \frac{f(b) - f(a)}{b - a}.$$

罗尔定理亦是证明该定理的核心工具。

### 实验单元（SymPy）


### mean_value_theorem (18.2s)

## Mean Value Theorem

**定义。** 设函数 $f$ 在闭区间 $[a, b]$ 上连续，在开区间 $(a, b)$ 上可微。则存在至少一点 $c \in (a, b)$，使得

$$f'(c) = \frac{f(b) - f(a)}{b - a}.$$

这一结论称为**微分中值定理**（Mean Value Theorem，简称 MVT）。其几何含义是：在满足上述条件的曲线上，至少存在一点处的切线与连接端点 $(a, f(a))$ 和 $(b, f(b))$ 的割线平行。

---

**证明思路。** 构造辅助函数

$$g(x) = f(x) - f(a) - \frac{f(b)-f(a)}{b-a}(x - a).$$

可以验证 $g(a) = g(b) = 0$。由于 $f$ 在 $[a,b]$ 上连续、在 $(a,b)$ 上可微，$g$ 亦满足相同条件，故由**罗尔定理**（Rolle's Theorem）知，存在 $c \in (a,b)$ 使得 $g'(c) = 0$，即

$$f'(c) - \frac{f(b)-f(a)}{b-a} = 0,$$

由此得出定理结论。$\blacksquare$

---

**工作例题。** 设 $f(x) = x^3 - 3x$，区间为 $[0, 2]$。

首先计算割线斜率：

$$\frac{f(2) - f(0)}{2 - 0} = \frac{(8 - 6) - 0}{2} = \frac{2}{2} = 1.$$

令 $f'(x) = 3x^2 - 3 = 1$，解得 $3x^2 = 4$，即

$$x = \frac{2}{\sqrt{3}} = \frac{2\sqrt{3}}{3} \approx 1.155.$$

由于 $\frac{2\sqrt{3}}{3} \in (0,2)$，中值定理得以验证，此点处切线斜率恰好等于 $1$。

---

**关键推论。** 若 $f'(x) = 0$ 在区间 $(a,b)$ 上处处成立，则 $f$ 在该区间上为常数函数。这一推论是不定积分唯一性（相差常数）的理论基础。

---

**实验单元（SymPy）。**

```python
from sympy import *
x, c = symbols('x c', real=True)
f = x**3 - 3*x
a_val, b_val = 0, 2
slope = (f.subs(x, b_val) - f.subs(x, a_val)) / (b_val - a_val)
c_vals = solve(diff(f, x) - slope, x)
print("割线斜率:", slope)          # 输出: 1
print("中值点 c:", c_vals)         # 输出: [-2√3/3, 2√3/3]
```

运行上述代码，取满足 $c \in (0,2)$ 的正根，即可在数值上确认定理结论。

### concavity (18.9s)

## 凹凸性

**定义**

设函数 $f$ 在区间 $I$ 上二阶可导。若对 $I$ 上所有 $x$ 均有 $f''(x) > 0$，则称 $f$ 在 $I$ 上是**凹函数**（向上弯曲）；若 $f''(x) < 0$，则称 $f$ 在 $I$ 上是**凸函数**（向下弯曲）。几何直观上，凹函数的切线斜率单调递增，其图像始终位于任意切线的**上方**；凸函数则相反，图像位于切线的**下方**。若存在点 $c$ 使得 $f''$ 在 $c$ 两侧变号，则称 $c$ 为**拐点**（inflection point）。

**例题**

考察函数 $f(x) = x^3 - 3x^2 + 2$。

逐步求导：

$$f'(x) = 3x^2 - 6x, \qquad f''(x) = 6x - 6 = 6(x-1).$$

令 $f''(x) = 0$，得 $x = 1$。

- 当 $x < 1$ 时，$f''(x) < 0$，故 $f$ 在 $(-\infty,\, 1)$ 上为**凸函数**；
- 当 $x > 1$ 时，$f''(x) > 0$，故 $f$ 在 $(1,\, +\infty)$ 上为**凹函数**；
- 在 $x = 1$ 处，$f''$ 变号，故 $\bigl(1,\, f(1)\bigr) = (1,\, 0)$ 为拐点。

**关键定理**

> **二阶导数判定定理**：设 $f$ 在开区间 $I$ 上二阶可导。
> 1. 若 $f''(x) > 0$ 对所有 $x \in I$ 成立，则 $f$ 在 $I$ 上为凹函数。
> 2. 若 $f''(x) < 0$ 对所有 $x \in I$ 成立，则 $f$ 在 $I$ 上为凸函数。
> 3. 若 $f''(c) = 0$ 且 $f''$ 在 $c$ 处变号，则 $c$ 为拐点。

该定理是极值第二判别法的基础：若 $f'(c) = 0$ 且 $f''(c) > 0$，则 $c$ 为极小值点；若 $f''(c) < 0$，则 $c$ 为极大值点。

**实验单元（SymPy）**

```python
from sympy import symbols, diff, solve, simplify

x = symbols('x')
f = x**3 - 3*x**2 + 2

f2 = diff(f, x, 2)              # 计算二阶导数
inflection_pts = solve(f2, x)   # 求拐点候选

print("f''(x) =", f2)
print("拐点候选 x =", inflection_pts)

# 验证变号
for pt in inflection_pts:
    left  = f2.subs(x, pt - 1)
    right = f2.subs(x, pt + 1)
    print(f"x={pt} 左侧 f''={left}, 右侧 f''={right}")
```

运行后应输出 $f''(x) = 6x - 6$，拐点 $x = 1$，且左侧为负、右侧为正，与手算结果完全吻合。

### end_behavior (18.3s)

## 端行为

**定义。** 设函数 $f(x)$ 在 $(-\infty, +\infty)$ 上有定义（或在某无界区间上有定义）。若当 $x \to +\infty$ 时 $f(x)$ 趋近于某个有限值 $L$，则称 $L$ 为 $f$ 在正无穷处的**水平渐近线**，记作

$$\lim_{x \to +\infty} f(x) = L.$$

类似地，若 $\lim_{x \to -\infty} f(x) = M$，则 $y = M$ 为负无穷处的水平渐近线。若上述极限为 $\pm\infty$，则函数无界增长或无界递减，此时称函数在该方向**无水平渐近线**。函数在 $x \to \pm\infty$ 时的整体表现，统称为函数的**端行为**（end behavior）。

---

**例题。** 分析有理函数

$$f(x) = \frac{3x^2 - 5}{2x^2 + x + 1}$$

的端行为。

将分子分母同除以最高次项 $x^2$：

$$f(x) = \frac{3 - \dfrac{5}{x^2}}{2 + \dfrac{1}{x} + \dfrac{1}{x^2}}.$$

当 $x \to \pm\infty$ 时，所有含 $x$ 的分母项趋于零，故

$$\lim_{x \to \pm\infty} f(x) = \frac{3 - 0}{2 + 0 + 0} = \frac{3}{2}.$$

因此 $y = \dfrac{3}{2}$ 是 $f$ 唯一的水平渐近线，函数从两侧均趋近于该值。

---

**关键定理（有理函数端行为）。** 设 $f(x) = \dfrac{a_n x^n + \cdots}{b_m x^m + \cdots}$，$a_n, b_m \neq 0$。则：

1. 若 $n < m$，则 $\displaystyle\lim_{x \to \pm\infty} f(x) = 0$，水平渐近线为 $y = 0$；
2. 若 $n = m$，则 $\displaystyle\lim_{x \to \pm\infty} f(x) = \dfrac{a_n}{b_m}$；
3. 若 $n > m$，则极限为 $\pm\infty$，无水平渐近线（此时可能存在斜渐近线）。

**证明思路：** 对 $\dfrac{a_n x^n}{b_m x^m} = \dfrac{a_n}{b_m} x^{n-m}$ 取极限，其余低次项在无穷远处可忽略不计。

---

**SymPy 实验单元。**

```python
from sympy import *
x = symbols('x')

f = (3*x**2 - 5) / (2*x**2 + x + 1)

lim_pos = limit(f, x, oo)
lim_neg = limit(f, x, -oo)

print("x → +∞ 时的极限：", lim_pos)   # 3/2
print("x → -∞ 时的极限：", lim_neg)   # 3/2

# 绘制函数图像以直观验证端行为
plot(f, (x, -50, 50), ylabel='f(x)', title='端行为示例')
```

运行后可观察到：图像在两端均趋近于水平线 $y = \dfrac{3}{2}$，与理论结论吻合。

### mvt_corollaries (19.3s)

## Mvt Corollaries

### 定义

均值定理（Mean Value Theorem，简称 MVT）的推论是一组由 MVT 直接衍生的重要结论，它们将函数的导数行为与函数整体性质紧密相连。设 $f$ 在闭区间 $[a, b]$ 上连续，在开区间 $(a, b)$ 上可微，则 MVT 保证存在 $c \in (a, b)$ 使得

$$f'(c) = \frac{f(b) - f(a)}{b - a}.$$

由此出发，可得三条核心推论：

**推论一（零导数定理）**：若对所有 $x \in (a, b)$ 均有 $f'(x) = 0$，则 $f$ 在 $[a, b]$ 上为常数函数。

**推论二（单调性判别）**：若 $f'(x) > 0$（或 $< 0$）对所有 $x \in (a, b)$ 成立，则 $f$ 在该区间上严格递增（或严格递减）。

**推论三（Lipschitz 估计）**：若 $|f'(x)| \leq M$ 对所有 $x \in (a, b)$ 成立，则对任意 $x_1, x_2 \in [a, b]$，有

$$|f(x_1) - f(x_2)| \leq M|x_1 - x_2|.$$

---

### 典型例题

设 $f(x) = x^3 - 3x$，在区间 $[0, 2]$ 上验证推论二。

计算导数：$f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$。

在 $(1, 2)$ 上，$x > 1$ 且 $x > -1$，故 $f'(x) > 0$，由推论二知 $f$ 在 $[1, 2]$ 上严格递增。验证：$f(1) = -2$，$f(2) = 2$，确实 $f(2) > f(1)$，结论吻合。

---

### 关键定理

**定理（函数相差常数）**：设 $f, g$ 在 $(a, b)$ 上可微，且对所有 $x \in (a, b)$ 均有 $f'(x) = g'(x)$，则存在常数 $C$ 使得

$$f(x) = g(x) + C, \quad \forall x \in [a, b].$$

**证明思路**：令 $h = f - g$，则 $h'(x) = 0$，由推论一知 $h$ 为常数，从而结论成立。$\blacksquare$

此定理是不定积分唯一性（相差任意常数）的理论基础。

---

### 实验单元（SymPy）

```python
from sympy import symbols, diff, solve, Rational

x = symbols('x')
f = x**3 - 3*x
a, b = 0, 2

# 求满足 MVT 的点 c
slope = (f.subs(x, b) - f.subs(x, a)) / (b - a)
c_vals = solve(diff(f, x) - slope, x)
print("MVT 点 c =", [v for v in c_vals if 0 < v < 2])

# 验证推论三的 Lipschitz 常数
M = max(abs(diff(f, x).subs(x, v)) for v in [0, 1, 2])
print("Lipschitz 常数上界 M =", M)
```

### first_derivative_test (34.8s)

## First Derivative Test

**定义。** 设函数 $f$ 在点 $c$ 的某个开区间上可微，且 $f'(c) = 0$（或 $f'(c)$ 不存在但 $f$ 连续）。**一阶导数判别法**通过考察 $f'$ 在 $c$ 两侧的符号来判断 $f(c)$ 的极值类型：

- 若 $f'$ 在 $c$ 左侧为正、右侧为负，则 $f(c)$ 是**极大值**；
- 若 $f'$ 在 $c$ 左侧为负、右侧为正，则 $f(c)$ 是**极小值**；
- 若 $f'$ 在 $c$ 两侧同号，则 $f(c)$ **不是极值**（称为驻点但无极值）。

直观上，导数的符号描述函数的单调方向：正值对应递增，负值对应递减。极大值恰好出现在函数从递增转为递减的时刻，极小值则相反。

---

**例题。** 设 $f(x) = x^3 - 3x + 2$，求其极值点。

**解：** 先求导并令其为零：
$$f'(x) = 3x^2 - 3 = 3(x-1)(x+1) = 0 \implies x = \pm 1.$$

对 $x = -1$：取 $x = -2$ 时 $f'(-2) = 9 > 0$，取 $x = 0$ 时 $f'(0) = -3 < 0$。符号由正变负，故 $f(-1) = 4$ 为**极大值**。

对 $x = 1$：取 $x = 0$ 时 $f'(0) = -3 < 0$，取 $x = 2$ 时 $f'(2) = 9 > 0$。符号由负变正，故 $f(1) = 0$ 为**极小值**。

---

**关键定理。** 设 $f$ 在包含 $c$ 的开区间 $I$ 上连续，$c$ 为 $f$ 的临界点。若存在 $\delta > 0$ 使得：
$$\text{对所有 } x \in (c-\delta,\, c),\quad f'(x) > 0;\quad \text{对所有 } x \in (c,\, c+\delta),\quad f'(x) < 0,$$
则 $f(c)$ 为严格极大值。极小值情形类似，方向互换。**证明思路：** 利用均值定理——对任意 $x \in (c-\delta, c)$，存在 $\xi \in (x, c)$ 使 $f(c) - f(x) = f'(\xi)(c - x) > 0$，故 $f(c) > f(x)$；右侧同理。

---

**实验单元（SymPy）。**

```python
from sympy import symbols, diff, solve, simplify

x = symbols('x')
f = x**3 - 3*x + 2
fp = diff(f, x)

critical = solve(fp, x)
for c in critical:
    left  = fp.subs(x, c - 0.01)
    right = fp.subs(x, c + 0.01)
    kind  = "极大值" if left > 0 and right < 0 else "极小值" if left < 0 and right > 0 else "非极值"
    print(f"x = {c}: f(c) = {f.subs(x, c)},  类型 = {kind}")
```

运行上述代码，学生可验证 $x = -1$ 给出极大值 $4$，$x = 1$ 给出极小值 $0$，与手算结果完全一致。

### horizontal_asymptote (19.2s)

## Horizontal Asymptote

**定义。** 设函数 $f(x)$ 在区间 $(-\infty, +\infty)$ 上（或其某一无界子集上）有定义。若存在常数 $L \in \mathbb{R}$，使得

$$\lim_{x \to +\infty} f(x) = L \quad \text{或} \quad \lim_{x \to -\infty} f(x) = L,$$

则称直线 $y = L$ 为函数 $f(x)$ 的一条**水平渐近线**（horizontal asymptote）。水平渐近线描述的是：当自变量趋向正无穷或负无穷时，函数值无限接近某一固定水平直线，但未必与之相交。一个函数最多有两条水平渐近线（$x \to +\infty$ 与 $x \to -\infty$ 各一条）。

---

**例题。** 求函数

$$f(x) = \frac{3x^2 - 5}{2x^2 + x + 1}$$

的水平渐近线。

**解：** 分子与分母均为 $x$ 的二次多项式，次数相同。将分子分母同除以 $x^2$：

$$\lim_{x \to \pm\infty} \frac{3x^2 - 5}{2x^2 + x + 1} = \lim_{x \to \pm\infty} \frac{3 - \dfrac{5}{x^2}}{2 + \dfrac{1}{x} + \dfrac{1}{x^2}} = \frac{3 - 0}{2 + 0 + 0} = \frac{3}{2}.$$

因此，$y = \dfrac{3}{2}$ 是 $f(x)$ 在 $x \to +\infty$ 与 $x \to -\infty$ 两个方向上唯一的水平渐近线。

---

**关键定理（有理函数的水平渐近线判别法）。** 设 $f(x) = \dfrac{p(x)}{q(x)}$，其中 $p(x)$ 与 $q(x)$ 为多项式，$\deg p = m$，$\deg q = n$。

- 若 $m < n$，则 $y = 0$ 为水平渐近线；
- 若 $m = n$，则 $y = \dfrac{a_m}{b_n}$（首项系数之比）为水平渐近线；
- 若 $m > n$，则不存在水平渐近线（函数趋向无穷）。

**证明要点：** 将分子分母同除以 $x^{\max(m,n)}$，利用 $\lim_{x\to\infty} x^{-k} = 0$（$k > 0$）即得。

---

**实验单元（SymPy）**

```python
from sympy import *
x = symbols('x')
f = (3*x**2 - 5) / (2*x**2 + x + 1)

lim_pos = limit(f, x,  oo)   # x → +∞
lim_neg = limit(f, x, -oo)   # x → -∞
print(lim_pos, lim_neg)       # 输出：3/2  3/2

plot(f, (x, -50, 50), title='f(x) 及其水平渐近线 y = 3/2')
```

运行上述代码，可在图像中观察到曲线在两端均趋近水平线 $y = \dfrac{3}{2}$，直观验证解析结论。

### oblique_asymptote (16.9s)

## Oblique Asymptote

**定义。** 设函数 $f(x)$ 在 $(-\infty, +\infty)$ 上（或某无穷区间上）有定义。若存在实数 $k \neq 0$ 与 $b$，使得

$$\lim_{x \to +\infty} \left[ f(x) - (kx + b) \right] = 0 \quad \text{或} \quad \lim_{x \to -\infty} \left[ f(x) - (kx + b) \right] = 0,$$

则称直线 $y = kx + b$ 为 $f(x)$ 的一条**斜渐近线**（oblique asymptote）。当 $k = 0$ 时退化为水平渐近线，故斜渐近线要求 $k \neq 0$。

确定斜渐近线的标准方法分两步：

$$k = \lim_{x \to \infty} \frac{f(x)}{x}, \qquad b = \lim_{x \to \infty} \left[ f(x) - kx \right].$$

若上述两极限均存在且有限，则 $y = kx + b$ 即为所求斜渐近线。

---

**例题。** 求函数 $f(x) = \dfrac{x^2 + 2x - 1}{x - 1}$ 当 $x \to +\infty$ 时的斜渐近线。

**解：** 首先计算斜率：

$$k = \lim_{x \to +\infty} \frac{f(x)}{x} = \lim_{x \to +\infty} \frac{x^2 + 2x - 1}{x(x-1)} = \lim_{x \to +\infty} \frac{x^2 + 2x - 1}{x^2 - x} = 1.$$

再做多项式除法：$x^2 + 2x - 1 = (x-1)(x+3) + 2$，故

$$f(x) = x + 3 + \frac{2}{x-1}.$$

因此

$$b = \lim_{x \to +\infty} \left[ f(x) - x \right] = \lim_{x \to +\infty} \left( 3 + \frac{2}{x-1} \right) = 3.$$

斜渐近线为 $y = x + 3$。$\blacksquare$

---

**关键定理。** 设 $f(x) = \dfrac{P(x)}{Q(x)}$ 为有理函数，其中 $\deg P = \deg Q + 1$。则 $f(x)$ 恰好存在一条斜渐近线，其方程由 $P(x) \div Q(x)$ 的商的线性部分给出；余式对应的分式项趋于零。

---

**实验单元（SymPy）。**

```python
from sympy import *
x = symbols('x')
f = (x**2 + 2*x - 1) / (x - 1)

k = limit(f / x, x, oo)
b = limit(f - k*x, x, oo)
print(f"斜渐近线：y = {k}x + {b}")   # 输出：y = 1x + 3

# 验证：多项式除法
q, r = div(x**2 + 2*x - 1, x - 1, x)
print(f"商：{q}，余式：{r}")           # 商：x+3，余式：2
```

### second_derivative_test (20.0s)

## Second Derivative Test

**定义。** 设函数 $f$ 在点 $c$ 处二阶可微，且 $f'(c) = 0$（即 $c$ 为驻点）。**二阶导数判别法**利用 $f''(c)$ 的符号来判定 $c$ 是极小值点、极大值点还是鞍点：

$$
\begin{cases}
f''(c) > 0 & \Rightarrow c \text{ 为严格极小值点，} f(c) \text{ 为局部极小值；} \\
f''(c) < 0 & \Rightarrow c \text{ 为严格极大值点，} f(c) \text{ 为局部极大值；} \\
f''(c) = 0 & \Rightarrow \text{判别法失效，需进一步分析。}
\end{cases}
$$

几何直觉：$f''(c) > 0$ 表明函数在 $c$ 附近向上弯曲（凹形），如同碗底；$f''(c) < 0$ 表明函数向下弯曲（凸形），如同山顶。

---

**例题。** 求函数 $f(x) = x^3 - 3x$ 的所有极值。

**解：** 首先求驻点：
$$f'(x) = 3x^2 - 3 = 3(x-1)(x+1) = 0 \implies x = 1 \text{ 或 } x = -1.$$

再计算二阶导数：
$$f''(x) = 6x.$$

在 $x = 1$ 处：$f''(1) = 6 > 0$，故 $x=1$ 为极小值点，极小值为 $f(1) = 1 - 3 = -2$。

在 $x = -1$ 处：$f''(-1) = -6 < 0$，故 $x=-1$ 为极大值点，极大值为 $f(-1) = -1 + 3 = 2$。

---

**关键定理（二阶导数判别法）。** 设 $f$ 在开区间 $I$ 上二阶连续可微，$c \in I$ 满足 $f'(c)=0$。若 $f''(c) \neq 0$，则

$$f(c) \text{ 为极值} \iff f''(c) \neq 0,$$

且极值类型由 $f''(c)$ 的符号唯一确定。

**证明思路：** 由泰勒展开，在 $c$ 附近有
$$f(c+h) = f(c) + \underbrace{f'(c)}_{=0}h + \tfrac{1}{2}f''(c)h^2 + O(h^3).$$
当 $|h|$ 足够小时，$O(h^3)$ 项可忽略，故 $f(c+h) - f(c) \approx \tfrac{1}{2}f''(c)h^2$。由于 $h^2 > 0$，差值的符号完全由 $f''(c)$ 决定，从而结论成立。$\blacksquare$

---

**实验单元（SymPy）。**

```python
from sympy import symbols, diff, solve, latex

x = symbols('x')
f = x**3 - 3*x
fp  = diff(f, x)
fpp = diff(fp, x)

critical = solve(fp, x)
for c in critical:
    val = fpp.subs(x, c)
    kind = "极小值" if val > 0 else ("极大值" if val < 0 else "失效")
    print(f"x = {c}: f''(x) = {val} → {kind}，f({c}) = {f.subs(x, c)}")
```

运行后输出 `x = -1: 极大值，f(-1) = 2` 与 `x = 1: 极小值，f(1) = -2`，与手算结果完全一致。修改 $f$ 的表达式，可对任意多项式函数进行系统性极值分析。

## Curve Sketching

**定义。** 曲线描绘（curve sketching）是指综合运用函数的定义域、极限、导数与二阶导数等信息，系统地刻画函数图像整体行为的分析方法。设 $f: D \to \mathbb{R}$ 为可微函数，曲线描绘通常按以下步骤进行：确定定义域与对称性；求渐近线（水平、竖直与斜渐近线）；利用 $f'(x)$ 判断单调区间与极值；利用 $f''(x)$ 判断凹凸性与拐点；最后综合以上信息绘制图像。

---

**例题。** 描绘函数 $f(x) = \dfrac{x^2 - 1}{x^2 + 1}$ 的图像。

**第一步：定义域与对称性。** 定义域为 $\mathbb{R}$；因 $f(-x) = f(x)$，$f$ 为偶函数，图像关于 $y$ 轴对称。

**第二步：渐近线。** $\lim_{x \to \pm\infty} f(x) = 1$，故 $y = 1$ 为水平渐近线；分母 $x^2 + 1 \neq 0$，无竖直渐近线。

**第三步：单调性与极值。** 计算导数：
$$f'(x) = \frac{2x(x^2+1) - (x^2-1)\cdot 2x}{(x^2+1)^2} = \frac{4x}{(x^2+1)^2}.$$
令 $f'(x) = 0$ 得 $x = 0$。当 $x < 0$ 时 $f' < 0$（递减），当 $x > 0$ 时 $f' > 0$（递增），故 $x=0$ 处取极小值 $f(0) = -1$。

**第四步：凹凸性与拐点。** 计算二阶导数：
$$f''(x) = \frac{4(1-3x^2)}{(x^2+1)^3}.$$
令 $f''(x)=0$ 得 $x = \pm \tfrac{1}{\sqrt{3}}$，两点均为拐点；$|x| < \tfrac{1}{\sqrt{3}}$ 时图像上凸（$f''<0$），$|x| > \tfrac{1}{\sqrt{3}}$ 时下凸（$f''>0$）。

---

**关键定理（一阶导数判别法）。** 设 $f$ 在 $x_0$ 处连续，在 $x_0$ 的去心邻域内可微。若 $f'$ 在 $x_0$ 左侧异号于右侧，则 $x_0$ 为极值点；若同号，则非极值点。

---

**实验单元（SymPy）。**

```python
from sympy import *
x = symbols('x')
f = (x**2 - 1) / (x**2 + 1)
print("f'  =", simplify(diff(f, x)))
print("f'' =", simplify(diff(f, x, 2)))
print("极值点:", solve(diff(f, x), x))
print("拐点:  ", solve(diff(f, x, 2), x))
```

运行上述代码，可验证 $f'(0)=0$、$f''\!\left(\pm\tfrac{1}{\sqrt{3}}\right)=0$，与手算结果一致。通过此例可见，曲线描绘将局部微分信息整合为全局图像，是微积分分析工具的集中体现。

### continuous_probability_distribution (0.0s)

## Continuous Probability Distribution

**Definition.** A random variable $X$ is *continuous* if there exists a non-negative function $f : \mathbb{R} \to [0, \infty)$, called the **probability density function (PDF)**, such that for every interval $[a, b] \subseteq \mathbb{R}$,

$$P(a \le X \le b) = \int_a^b f(x)\, dx.$$

Two conditions must hold: $f(x) \ge 0$ for all $x$, and $\int_{-\infty}^{\infty} f(x)\, dx = 1$. Unlike the discrete case, $P(X = x) = 0$ for any single point; probability is carried by intervals, not atoms. The **cumulative distribution function (CDF)** is defined as

$$F(x) = P(X \le x) = \int_{-\infty}^{x} f(t)\, dt,$$

so $F$ is non-decreasing, right-continuous, $\lim_{x \to -\infty} F(x) = 0$, and $\lim_{x \to \infty} F(x) = 1$. Where $F$ is differentiable, $f(x) = F'(x)$.

**Worked Example.** Let $X \sim \text{Uniform}(0, 2)$, so $f(x) = \tfrac{1}{2}$ on $[0,2]$ and $0$ elsewhere. To find $P(0.5 \le X \le 1.5)$:

$$P(0.5 \le X \le 1.5) = \int_{0.5}^{1.5} \frac{1}{2}\, dx = \frac{1}{2}(1.5 - 0.5) = \frac{1}{2}.$$

The corresponding CDF is $F(x) = x/2$ for $x \in [0,2]$, confirming $F'(x) = 1/2 = f(x)$.

**Key Theorem (Expectation and Variance).** For a continuous random variable $X$ with PDF $f$, provided the integrals converge absolutely,

$$\mu = E[X] = \int_{-\infty}^{\infty} x\, f(x)\, dx, \qquad \sigma^2 = \text{Var}(X) = \int_{-\infty}^{\infty} (x - \mu)^2 f(x)\, dx.$$

Equivalently, $\sigma^2 = E[X^2] - \mu^2$. These are the continuous analogues of the weighted sums used in the discrete case, with integration replacing summation.

**Lab Cell.**

```python
from sympy import symbols, integrate, oo, Rational, simplify

x = symbols('x')
f = Rational(1, 2)                          # Uniform(0,2) PDF

prob = integrate(f, (x, Rational(1,2), Rational(3,2)))
mu   = integrate(x * f, (x, 0, 2))
var  = integrate((x - mu)**2 * f, (x, 0, 2))

print("P(0.5 ≤ X ≤ 1.5) =", prob)          # 1/2
print("E[X] =", mu)                          # 1
print("Var(X) =", simplify(var))             # 1/3
```

### mean (0.0s)

## Mean

**Definition.** Let $x_1, x_2, \ldots, x_n$ be a finite sequence of real numbers. The *arithmetic mean* (or *sample mean*) of this sequence is the value

$$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i.$$

The mean is the unique real number that minimises the sum of squared deviations: $\bar{x} = \arg\min_{c \in \mathbb{R}} \sum_{i=1}^n (x_i - c)^2$. Geometrically, it is the balance point of the data — the centre of mass if each observation is assigned equal weight.

**Worked example.** A student records the following five quiz scores: $72, 85, 90, 68, 95$. The arithmetic mean is

$$\bar{x} = \frac{72 + 85 + 90 + 68 + 95}{5} = \frac{410}{5} = 82.$$

Now suppose one score is changed from $68$ to $168$ (a data-entry error). The new mean becomes $\frac{510}{5} = 102$, which exceeds all legitimate scores. This illustrates that the arithmetic mean is sensitive to outliers — a single extreme value can shift it substantially, motivating robust alternatives such as the median.

**Key theorem (Linearity of the sample mean).** For two sequences $x_1, \ldots, x_n$ and $y_1, \ldots, y_n$ and constants $a, b \in \mathbb{R}$, let $z_i = a x_i + b y_i$. Then

$$\bar{z} = a\,\bar{x} + b\,\bar{y}.$$

*Proof sketch.* Apply the definition directly: $\bar{z} = \frac{1}{n}\sum_i (ax_i + by_i) = a \cdot \frac{1}{n}\sum_i x_i + b \cdot \frac{1}{n}\sum_i y_i$. $\square$

This linearity makes the mean uniquely tractable for combining scaled or shifted datasets without recomputing from raw observations.

**Lab cell.**

```python
from sympy import Rational

scores = [72, 85, 90, 68, 95]
sample_mean = Rational(sum(scores), len(scores))
print("Sample mean:", sample_mean)          # 82

# Linearity check: scale each score by 1.1 and add a 5-point bonus
adjusted = [Rational(11, 10) * s + 5 for s in scores]
mean_adjusted = Rational(sum(adjusted), len(adjusted))
expected = Rational(11, 10) * sample_mean + 5
print("Mean of adjusted scores:", mean_adjusted)   # 95.2
print("Computed via linearity:  ", expected)        # 95.2
```

Running this cell confirms that scaling each score by $1.1$ and adding $5$ points raises the mean from $82$ to $\frac{476}{5} = 95.2$, in exact agreement with the linearity theorem applied to $\bar{x}$.

### random_variable (0.0s)

## Random Variable

**Definition.** A *random variable* is a measurable function $X : \Omega \to \mathbb{R}$ defined on a probability space $(\Omega, \mathcal{F}, P)$, where $\Omega$ is the sample space, $\mathcal{F}$ is a $\sigma$-algebra of events, and $P$ is a probability measure. For every Borel set $B \subseteq \mathbb{R}$, we require $X^{-1}(B) = \{\omega \in \Omega : X(\omega) \in B\} \in \mathcal{F}$, ensuring that the probability $P(X \in B)$ is well-defined. Informally, a random variable assigns a real number to each outcome of an experiment, translating abstract events into numerical quantities amenable to analysis.

Random variables are classified by their range. A *discrete* random variable takes values in a countable set $\{x_1, x_2, \ldots\}$ and is characterized by its *probability mass function* (PMF) $p(x_k) = P(X = x_k)$, satisfying $\sum_k p(x_k) = 1$. A *continuous* random variable takes values in an interval and is described by a *probability density function* (PDF) $f$, where $P(a \le X \le b) = \int_a^b f(x)\,dx$ and $\int_{-\infty}^{\infty} f(x)\,dx = 1$.

**Worked Example.** Roll a fair six-sided die. Set $\Omega = \{1,2,3,4,5,6\}$ with $P(\{\omega\}) = 1/6$ for each outcome. Define $X(\omega) = \omega$. Then $X$ is a discrete random variable with PMF $p(k) = 1/6$ for $k \in \{1,\ldots,6\}$. Its *expected value* is
$$\mathbb{E}[X] = \sum_{k=1}^{6} k \cdot \frac{1}{6} = \frac{21}{6} = 3.5,$$
and its *variance* is $\operatorname{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2 = \frac{91}{6} - \frac{441}{36} = \frac{35}{12} \approx 2.92$.

**Key Theorem (Law of the Unconscious Statistician).** If $g : \mathbb{R} \to \mathbb{R}$ is measurable and $X$ is a discrete random variable, then
$$\mathbb{E}[g(X)] = \sum_k g(x_k)\, p(x_k),$$
without needing to derive the distribution of $g(X)$ explicitly. The analogous statement for continuous $X$ replaces the sum with $\int_{-\infty}^{\infty} g(x) f(x)\,dx$.

**Lab Cell.**
```python
from sympy import symbols, Rational, summation, simplify

k = symbols('k', integer=True)
pmf = Rational(1, 6)

E_X  = summation(k * pmf, (k, 1, 6))
E_X2 = summation(k**2 * pmf, (k, 1, 6))
Var_X = simplify(E_X2 - E_X**2)

print(f"E[X]   = {E_X}")      # 7/2
print(f"Var(X) = {Var_X}")    # 35/12
```

### standard_deviation (0.0s)

## Standard Deviation

**Definition.** Let $X$ be a random variable with expected value $\mu = E[X]$. The *standard deviation* of $X$, denoted $\sigma$ (or $\sigma_X$), is defined as

$$\sigma = \sqrt{E\!\left[(X - \mu)^2\right]}.$$

The quantity inside the square root, $\sigma^2 = E[(X-\mu)^2]$, is called the *variance*. For a finite dataset $\{x_1, x_2, \ldots, x_n\}$, the population standard deviation is

$$\sigma = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_i - \mu)^2}, \qquad \mu = \frac{1}{n}\sum_{i=1}^{n} x_i.$$

When the dataset is treated as a *sample* drawn from a larger population, the denominator is replaced by $n-1$ (Bessel's correction), yielding the sample standard deviation $s$.

**Worked Example.** Consider the dataset $\{2, 4, 4, 4, 5, 5, 7, 9\}$, which has $n = 8$ values.

1. Compute the mean: $\mu = \dfrac{2+4+4+4+5+5+7+9}{8} = \dfrac{40}{8} = 5$.

2. Compute squared deviations:
$$\sum_{i=1}^{8}(x_i - 5)^2 = 9 + 1 + 1 + 1 + 0 + 0 + 4 + 16 = 32.$$

3. Population standard deviation: $\sigma = \sqrt{32/8} = \sqrt{4} = 2$.

Intuitively, the data points lie, on average, two units away from the mean of 5.

**Key Theorem (Chebyshev's Inequality).** For *any* distribution with finite mean $\mu$ and standard deviation $\sigma$, and for every $k > 1$,

$$P(|X - \mu| \geq k\sigma) \leq \frac{1}{k^2}.$$

This guarantees, for example, that at least $1 - 1/4 = 75\%$ of any distribution's probability mass lies within two standard deviations of the mean — no assumptions on the shape of the distribution are required. For the normal distribution the corresponding figure is approximately 95.4%, a much tighter bound arising from its specific analytic form.

**Lab Cell.**

```python
import sympy as sp

data = [2, 4, 4, 4, 5, 5, 7, 9]
n = len(data)
mu = sp.Rational(sum(data), n)
variance = sum((sp.Rational(x) - mu)**2 for x in data) / n
sigma = sp.sqrt(variance)
print(f"mean={mu}, variance={variance}, sigma={sigma}")
# mean=5, variance=4, sigma=2
```

### normal_distribution (0.0s)

## Normal Distribution

**Definition.** A continuous random variable $X$ is said to follow a *normal distribution* with mean $\mu \in \mathbb{R}$ and variance $\sigma^2 > 0$, written $X \sim \mathcal{N}(\mu, \sigma^2)$, if its probability density function (PDF) is

$$f(x;\mu,\sigma^2) = \frac{1}{\sigma\sqrt{2\pi}}\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right), \quad x \in \mathbb{R}.$$

The parameter $\mu$ controls the center of the symmetric bell-shaped curve, while $\sigma$ (the standard deviation) controls its spread. The cumulative distribution function (CDF) is $F(x) = \int_{-\infty}^{x} f(t;\mu,\sigma^2)\,dt$; because the integral has no closed form in elementary functions, probabilities are read from precomputed tables or computed numerically.

**Worked Example.** Suppose the heights of adult males in a population are modeled as $X \sim \mathcal{N}(175, 49)$ (centimeters), so $\mu = 175$ and $\sigma = 7$. Find the probability that a randomly selected male is taller than $182\,\text{cm}$.

Because every normal CDF can be expressed in terms of the $\mathcal{N}(0,1)$ table, set $z = (182 - 175)/7 = 1$ and look up $F(182) = F_{\mathcal{N}(0,1)}(1) \approx 0.8413$. Therefore

$$P(X > 182) = 1 - F(182) \approx 1 - 0.8413 = 0.1587.$$

Approximately $15.9\%$ of males exceed $182\,\text{cm}$.

**Key Theorem (68–95–99.7 Rule).** If $X \sim \mathcal{N}(\mu,\sigma^2)$, then

$$P(\mu - k\sigma \le X \le \mu + k\sigma) \approx \begin{cases} 0.6827 & k=1,\\ 0.9545 & k=2,\\ 0.9973 & k=3. \end{cases}$$

This follows from evaluating $2F(\mu+k\sigma)-1$ at $k=1,2,3$, and it provides a rapid sanity-check for whether observed data are plausibly normal.

**Lab Cell.**

```python
from sympy import symbols, exp, pi, sqrt, integrate, oo, simplify

x = symbols('x', real=True)
sigma_val = 7
mu_val = 175

f = (1 / (sigma_val * sqrt(2 * pi))) * exp(-(x - mu_val)**2 / (2 * sigma_val**2))

# P(X > 182)
prob = integrate(f, (x, 182, oo))
print("P(X > 182) =", simplify(prob))  # expects (1 - erf(1/sqrt(2))) / 2
```

### cumulative_distribution_function (0.0s)

## Cumulative Distribution Function

**Definition.** Let $X$ be a real-valued random variable defined on a probability space $(\Omega, \mathcal{F}, P)$. The *cumulative distribution function* (CDF) of $X$ is the function $F_X : \mathbb{R} \to [0,1]$ defined by

$$F_X(x) = P(X \leq x), \quad x \in \mathbb{R}.$$

Every CDF satisfies three fundamental properties: (i) *monotonicity* — $F_X$ is non-decreasing; (ii) *right-continuity* — $F_X(x) = \lim_{t \to x^+} F_X(t)$ for all $x$; and (iii) *boundary conditions* — $\lim_{x \to -\infty} F_X(x) = 0$ and $\lim_{x \to +\infty} F_X(x) = 1$. Conversely, any function satisfying these three properties is the CDF of some random variable.

**Worked Example.** Let $X \sim \mathrm{Uniform}(0,1)$, so its probability density function is $f_X(x) = 1$ for $x \in [0,1]$ and zero otherwise. The CDF is obtained by integration:

$$F_X(x) = \int_{-\infty}^{x} f_X(t)\, dt = \begin{cases} 0, & x < 0, \\ x, & 0 \leq x \leq 1, \\ 1, & x > 1. \end{cases}$$

One may verify directly that $P(0.25 \leq X \leq 0.75) = F_X(0.75) - F_X(0.25) = 0.75 - 0.25 = 0.50$, confirming that exactly half the probability mass lies in the central interval.

**Key Theorem (Probability via CDF).** For any random variable $X$ with CDF $F_X$,

$$P(a < X \leq b) = F_X(b) - F_X(a), \quad a < b.$$

*Proof sketch.* The events $\{X \leq a\}$ and $\{a < X \leq b\}$ are disjoint with union $\{X \leq b\}$. Additivity of $P$ then gives $P(X \leq b) = P(X \leq a) + P(a < X \leq b)$, and rearranging yields the result. $\square$

This theorem is the workhorse of probability calculations: any interval probability reduces to two CDF evaluations, regardless of whether $X$ is discrete, continuous, or mixed.

**Lab Cell.**
```python
from sympy import symbols, Piecewise, integrate, Rational, plot

x = symbols('x', real=True)
f = Piecewise((1, (x >= 0) & (x <= 1)), (0, True))
F = integrate(f, (x, -float('inf'), x))

# Verify P(0.25 <= X <= 0.75)
prob = F.subs(x, Rational(3,4)) - F.subs(x, Rational(1,4))
print(prob)   # Expected: 1/2
plot(F, (x, -0.5, 1.5), title='CDF of Uniform(0,1)')
```

### percentile_and_invnorm (0.0s)

## Percentile And Invnorm

**Definition.** Let $X$ be a continuous random variable with cumulative distribution function $F(x) = P(X \leq x)$. The **$p$-th percentile** of $X$, denoted $x_p$, is the value satisfying

$$F(x_p) = p, \qquad 0 < p < 1.$$

Equivalently, $x_p = F^{-1}(p)$, the *quantile function* (or inverse CDF). For the standard normal distribution $Z \sim \mathcal{N}(0,1)$, this inverse is written $z_p = \Phi^{-1}(p)$ and is called the **inverse normal** or **invnorm**. For a general normal $X \sim \mathcal{N}(\mu, \sigma^2)$, the percentile converts via the standardisation identity:

$$x_p = \mu + \sigma\,\Phi^{-1}(p).$$

**Worked Example.** Adult resting heart rates are approximately normally distributed with mean $\mu = 70$ bpm and standard deviation $\sigma = 10$ bpm. Find the 90th percentile.

We need $x_{0.90} = 70 + 10\,\Phi^{-1}(0.90)$. From standard tables (or a CAS), $\Phi^{-1}(0.90) \approx 1.2816$. Therefore

$$x_{0.90} = 70 + 10(1.2816) = 70 + 12.816 \approx 82.8 \text{ bpm}.$$

Interpretation: 90% of adults have a resting heart rate at or below approximately 83 bpm.

**Key Theorem (Symmetry of the Standard Normal Percentile).** Because $\Phi$ is symmetric about zero, its inverse satisfies

$$\Phi^{-1}(1 - p) = -\Phi^{-1}(p), \qquad 0 < p < 1.$$

*Proof sketch.* By the reflection symmetry $\Phi(-z) = 1 - \Phi(z)$, setting $z = \Phi^{-1}(p)$ gives $\Phi(-\Phi^{-1}(p)) = 1 - p$, so $-\Phi^{-1}(p)$ is the value whose CDF equals $1-p$, which is exactly $\Phi^{-1}(1-p)$. $\square$

A direct consequence is that upper and lower percentiles are paired: for example, $\Phi^{-1}(0.90) = -\Phi^{-1}(0.10) \approx 1.2816$, halving the table lookups needed in practice.

**Lab Cell.**

```python
from scipy.stats import norm
import sympy as sp

mu, sigma = 70, 10

# 90th percentile numerically
p90 = norm.ppf(0.90, loc=mu, scale=sigma)
print(f"90th percentile: {p90:.2f} bpm")

# Verify: P(X <= p90) should equal 0.90
print(f"CDF check: {norm.cdf(p90, loc=mu, scale=sigma):.4f}")

# Symbolic inverse CDF via SymPy (standard normal)
p = sp.Symbol('p', positive=True)
# Phi^{-1}(p) = sqrt(2)*erfinv(2p - 1)
invnorm_expr = sp.sqrt(2) * sp.erfinv(2*p - 1)
print(sp.simplify(invnorm_expr.subs(p, sp.Rational(1,2))))  # => 0

# Confirm symmetry: Phi^{-1}(0.90) == -Phi^{-1}(0.10)
print(f"Phi^{{-1}}(0.90) = {norm.ppf(0.90):.4f}")
print(f"-Phi^{{-1}}(0.10) = {-norm.ppf(0.10):.4f}")
```

Running this cell confirms $x_{0.90} \approx 82.82$ bpm, that $\Phi^{-1}(0.5) = 0$ by symmetry, and that $\Phi^{-1}(0.90) = -\Phi^{-1}(0.10)$ to four decimal places.

### interquartile_range_normal (0.0s)

## Interquartile Range Normal

**Definition.** The *interquartile range* (IQR) of a random variable $X$ is the difference between its 75th and 25th percentiles:
$$\mathrm{IQR}(X) = Q_3 - Q_1 = F^{-1}(0.75) - F^{-1}(0.25),$$
where $F^{-1}$ denotes the quantile function (inverse CDF). For the standard normal distribution $X \sim \mathcal{N}(0,1)$, both quartiles are symmetric about zero, so
$$Q_1 = -z_{0.75}, \quad Q_3 = z_{0.75}, \quad \mathrm{IQR}_{\mathcal{N}(0,1)} = 2\,z_{0.75},$$
where $z_{0.75} = \Phi^{-1}(0.75) \approx 0.6745$. Hence $\mathrm{IQR}_{\mathcal{N}(0,1)} \approx 1.3490$.

For the general normal $X \sim \mathcal{N}(\mu, \sigma^2)$, the linear scaling $X = \mu + \sigma Z$ gives
$$\mathrm{IQR}(X) = \sigma \cdot \mathrm{IQR}_{\mathcal{N}(0,1)} \approx 1.3490\,\sigma.$$

**Worked Example.** IQ scores are modelled as $\mathcal{N}(100, 15^2)$. Find the IQR.

Step 1: Identify $\mu = 100$, $\sigma = 15$.

Step 2: Apply the formula:
$$Q_1 = 100 + 15 \times (-0.6745) \approx 89.88, \quad Q_3 = 100 + 15 \times 0.6745 \approx 110.12.$$

Step 3:
$$\mathrm{IQR} = Q_3 - Q_1 \approx 110.12 - 89.88 = 20.23.$$

Approximately half of all IQ scores fall within a 20-point window centred on the mean.

**Key Theorem.** For $X \sim \mathcal{N}(\mu, \sigma^2)$, the IQR satisfies
$$\mathrm{IQR}(X) = 2\,\Phi^{-1}(0.75)\,\sigma \approx 1.3490\,\sigma,$$
and accordingly the *normalized IQR estimator* $\hat{\sigma} = \mathrm{IQR}/1.3490$ is an unbiased, robust estimator of $\sigma$ under the normal model. Unlike the sample standard deviation, $\hat{\sigma}$ is resistant to outliers because it discards the extreme 25% of observations on each tail.

**Lab Cell (SymPy).**

```python
from sympy import Rational, N
from sympy.stats import Normal, quantile

X = Normal('X', 0, 1)
Q1 = quantile(X)(Rational(1, 4))
Q3 = quantile(X)(Rational(3, 4))
iqr = Q3 - Q1
print("Symbolic IQR:", iqr)
print("Numeric IQR :", N(iqr, 6))   # expects ≈ 1.34898
```

The one new primitive here is `quantile`, which inverts the normal CDF symbolically. Running this cell confirms $\mathrm{IQR}_{\mathcal{N}(0,1)} \approx 1.34898$, matching the closed-form value $2\,\Phi^{-1}(0.75)$ derived above.

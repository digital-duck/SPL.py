### relation (0.0s)

## 关系

**定义．** 设 $A$ 与 $B$ 为两个集合。从 $A$ 到 $B$ 的一个**二元关系**（binary relation）是笛卡尔积 $A \times B$ 的任意子集 $R \subseteq A \times B$。若 $(a, b) \in R$，则记作 $a \mathrel{R} b$，读作"$a$ 与 $b$ 有关系 $R$"。当 $A = B$ 时，称 $R$ 为集合 $A$ 上的关系。

关系是函数概念的推广：函数要求每个输入恰好对应唯一输出，而关系对此不作限制——一个元素可以与多个元素相关，也可以不与任何元素相关。

---

**例题．** 设 $A = \{1, 2, 3\}$，定义 $A$ 上的整除关系

$$R = \{(a, b) \in A \times A \mid a \text{ 整除 } b\}.$$

列举所有有序对：$1$ 整除 $1, 2, 3$；$2$ 整除 $2$；$3$ 整除 $3$。故

$$R = \{(1,1),\,(1,2),\,(1,3),\,(2,2),\,(3,3)\}.$$

可验证：$(2, 3) \notin R$，因为 $2 \nmid 3$。

---

**关系的性质．** 设 $R$ 为集合 $A$ 上的关系，常见性质定义如下：

| 性质 | 定义 |
|------|------|
| 自反性 | $\forall a \in A,\ a \mathrel{R} a$ |
| 对称性 | $a \mathrel{R} b \Rightarrow b \mathrel{R} a$ |
| 传递性 | $a \mathrel{R} b \land b \mathrel{R} c \Rightarrow a \mathrel{R} c$ |
| 反对称性 | $a \mathrel{R} b \land b \mathrel{R} a \Rightarrow a = b$ |

同时满足自反性、对称性与传递性的关系称为**等价关系**；同时满足自反性、反对称性与传递性的关系称为**偏序关系**。

**定理（等价类划分）．** 设 $\sim$ 为集合 $A$ 上的等价关系。对每个 $a \in A$，定义等价类 $[a] = \{x \in A \mid x \sim a\}$。则全体等价类构成 $A$ 的一个划分，即：$\bigcup_{a \in A} [a] = A$，且任意两个不同等价类互不相交。

---

**实验单元（SymPy）．**

```python
from sympy import FiniteSet
A = FiniteSet(1, 2, 3)
R = [(a, b) for a in A for b in A if b % a == 0]
print("整除关系 R =", R)

# 验证传递性
transitive = all(
    (a, c) in R
    for (a, b) in R for (b2, c) in R if b == b2
)
print("传递性成立:", transitive)
```

运行上述代码，可观察到 $R$ 满足自反性与传递性，但不满足对称性（因 $(1,2) \in R$ 而 $(2,1) \notin R$），从而确认整除关系是 $A$ 上的偏序关系。

### function (0.0s)

## 函数

**定义。** 设 $A$ 与 $B$ 为两个非空集合。若存在一个规则 $f$，使得对 $A$ 中的**每一个**元素 $x$，都有 $B$ 中**唯一确定**的元素 $y$ 与之对应，则称 $f$ 为从 $A$ 到 $B$ 的一个**函数**（function），记作

$$f: A \to B, \quad x \mapsto f(x).$$

集合 $A$ 称为 $f$ 的**定义域**（domain），记作 $\operatorname{dom}(f)$；集合 $\{f(x) \mid x \in A\}$ 称为 $f$ 的**值域**（range），记作 $\operatorname{ran}(f) \subseteq B$。需特别强调"唯一性"：同一个 $x$ 不可对应两个不同的 $y$；否则该规则不构成函数。

---

**例题。** 考察规则 $f(x) = x^2 - 2x + 3$，定义域取 $A = \mathbb{R}$。

1. **验证为函数：** 对任意实数 $x$，表达式 $x^2 - 2x + 3$ 给出唯一实数值，故 $f$ 是函数。
2. **求函数值：** $f(0) = 0 - 0 + 3 = 3$；$f(2) = 4 - 4 + 3 = 3$；$f(-1) = 1 + 2 + 3 = 6$。
3. **确定值域：** 配方得 $f(x) = (x-1)^2 + 2 \geq 2$，且等号在 $x=1$ 时成立，故 $\operatorname{ran}(f) = [2, +\infty)$。

---

**基本定理（函数相等）。** 设 $f: A \to B$ 与 $g: C \to B$ 为两个函数。$f = g$ 当且仅当：

$$\operatorname{dom}(f) = \operatorname{dom}(g) \quad \text{且} \quad \forall\, x \in A,\ f(x) = g(x).$$

**证明思路：** 若 $\operatorname{dom}(f) \neq \operatorname{dom}(g)$，则存在某 $x_0$ 仅属于其中一个定义域，对应值无从比较，故两函数必然不同。当定义域相等时，逐点比较函数值即可完成判定。$\square$

---

**实验单元（SymPy）。**

```python
from sympy import symbols, factor, solve, oo, S

x = symbols('x')
f = x**2 - 2*x + 3

# 配方与最小值
completed = factor(f - 2) + 2          # (x-1)^2 + 2
minimum   = solve(f.diff(x), x)        # [1]

# 值域下界验证
print("最小值点:", minimum)            # [1]
print("最小值:  ", f.subs(x, 1))      # 2
```

运行上述代码，SymPy 将返回最小值点 $x=1$ 及最小值 $2$，与手工计算完全吻合，从而验证值域为 $[2,+\infty)$。

### one_to_one_function (18.7s)

## One To One Function

**定义。** 设 $f: A \to B$ 为一函数。若对任意 $x_1, x_2 \in A$，

$$x_1 \neq x_2 \implies f(x_1) \neq f(x_2),$$

则称 $f$ 为**单射函数**（一一函数）。等价地，其逆否命题为：

$$f(x_1) = f(x_2) \implies x_1 = x_2.$$

直观上，单射函数对定义域中每一个不同的输入，均给出不同的输出，即不存在两个不同的自变量映射到同一因变量值。在图形上，这等价于**水平线检验**：任意水平线 $y = c$ 与函数图像至多有一个交点。

---

**例题。** 判断 $f(x) = 2x + 3$（$f: \mathbb{R} \to \mathbb{R}$）是否为单射。

**解。** 设 $f(x_1) = f(x_2)$，即

$$2x_1 + 3 = 2x_2 + 3.$$

两边同减 $3$，再除以 $2$，得

$$x_1 = x_2.$$

因此，由定义可知 $f$ 为单射函数。$\blacksquare$

再考察 $g(x) = x^2$（$g: \mathbb{R} \to \mathbb{R}$）。取 $x_1 = 2,\ x_2 = -2$，则 $x_1 \neq x_2$，但

$$g(2) = 4 = g(-2),$$

故 $g$ **不是**单射函数。若将定义域限制为 $[0, +\infty)$，则 $g$ 成为单射。

---

**关键定理（单射与可逆性）。** 设 $f: A \to B$。$f$ 存在左逆（即存在函数 $h: B \to A$ 使得 $h \circ f = \mathrm{id}_A$）当且仅当 $f$ 为单射。

**证明思路。** 若 $f$ 为单射，对每个 $b \in f(A)$ 恰有唯一 $a \in A$ 满足 $f(a) = b$，故可良定义 $h(b) = a$；对 $b \notin f(A)$ 任意指定值。验证知 $h(f(a)) = a$，即 $h \circ f = \mathrm{id}_A$。反之，若左逆存在，则 $f(x_1)=f(x_2)$ 蕴含 $x_1 = h(f(x_1)) = h(f(x_2)) = x_2$，故 $f$ 为单射。$\square$

---

**实验单元（SymPy）。**

```python
from sympy import symbols, solve, Function

x1, x2 = symbols('x1 x2')
f = lambda x: 2*x + 3

# 验证单射：解 f(x1) = f(x2) 是否仅有 x1 = x2
sol = solve(f(x1) - f(x2), x1)
print(sol)  # 期望输出: [x2]
```

### exponential_function (0.0s)

## Exponential Function

### 定义

**指数函数**是形如

$$f(x) = a^x, \quad a > 0,\; a \neq 1$$

的函数，其中 $a$ 称为**底数**，$x$ 为实数指数。当底数取自然常数 $e \approx 2.71828$ 时，得到**自然指数函数** $f(x) = e^x$，它在分析学中占据核心地位。指数函数的定义域为 $\mathbb{R}$，值域为 $(0, +\infty)$；函数图像过点 $(0, 1)$，当 $a > 1$ 时单调递增，当 $0 < a < 1$ 时单调递减。

### 基本性质

指数函数满足以下运算律：

$$a^{x+y} = a^x \cdot a^y, \qquad a^{xy} = (a^x)^y, \qquad a^0 = 1.$$

这些性质将乘法运算转化为加法运算，是对数函数存在的根本原因。

### 例题

**问题：** 求解方程 $2^{2x-1} = 32$。

**解：** 将右侧改写为 $2$ 的幂次：

$$32 = 2^5.$$

因此原方程化为

$$2x - 1 = 5 \implies x = 3.$$

验证：$2^{2(3)-1} = 2^5 = 32$，成立。$\blacksquare$

### 核心定理

**定理（自然指数函数的导数）。** 设 $f(x) = e^x$，则对一切 $x \in \mathbb{R}$，有

$$f'(x) = e^x.$$

**证明要点：** 由导数定义，

$$f'(x) = \lim_{h \to 0} \frac{e^{x+h} - e^x}{h} = e^x \lim_{h \to 0} \frac{e^h - 1}{h}.$$

利用极限 $\displaystyle\lim_{h \to 0} \frac{e^h - 1}{h} = 1$（可由 $e$ 的级数定义严格证明），立得 $f'(x) = e^x$。这一性质说明自然指数函数是以自身为导数的唯一（在差一个常数倍意义下）函数，使其成为微分方程的天然解。$\square$

### 实验单元（SymPy）

```python
from sympy import *
x = symbols('x')

# 定义自然指数函数并求导
f = exp(x)
print("f(x)  =", f)
print("f'(x) =", diff(f, x))          # 应输出 exp(x)

# 求解指数方程 2^(2x-1) = 32
eq = Eq(2**(2*x - 1), 32)
print("解：x =", solve(eq, x))        # 应输出 [3]

# 绘制 e^x 在 [-2, 2] 上的图像
plot(exp(x), (x, -2, 2), title='f(x) = e^x', ylabel='f(x)')
```

运行上述代码，可验证导数公式与方程求解结果，并直观观察指数增长的急剧态势。

### inverse_function (17.2s)

## 反函数

**定义。** 设 $f: A \to B$ 为一个函数。若存在函数 $g: B \to A$，使得对所有 $x \in A$ 有 $g(f(x)) = x$，且对所有 $y \in B$ 有 $f(g(y)) = y$，则称 $g$ 为 $f$ 的**反函数**，记作 $f^{-1}$。反函数存在的充要条件是 $f$ 为**双射**（即既是单射又是满射）。直观地说，$f^{-1}$ 将 $f$ 的输出"还原"为原来的输入，满足

$$f^{-1}(f(x)) = x \quad \text{且} \quad f(f^{-1}(y)) = y.$$

在几何上，$y = f^{-1}(x)$ 的图像是 $y = f(x)$ 的图像关于直线 $y = x$ 的对称像。

---

**例题。** 求函数 $f(x) = 2x + 3$（定义域 $\mathbb{R}$）的反函数。

**解：** 令 $y = 2x + 3$，解出 $x$：

$$y - 3 = 2x \implies x = \frac{y - 3}{2}.$$

将 $x$ 与 $y$ 互换，得

$$f^{-1}(x) = \frac{x - 3}{2}.$$

验证：$f^{-1}(f(x)) = \dfrac{(2x+3)-3}{2} = x$ ✓，$f(f^{-1}(x)) = 2\cdot\dfrac{x-3}{2}+3 = x$ ✓。

---

**关键定理（反函数微分法则）。** 设 $f$ 在开区间 $I$ 上可微且严格单调，$f^{-1}$ 在对应区间上存在。若 $f'(x) \neq 0$，则 $f^{-1}$ 在 $y = f(x)$ 处可微，且

$$\left(f^{-1}\right)'(y) = \frac{1}{f'(x)}.$$

**证明思路：** 对恒等式 $f(f^{-1}(y)) = y$ 两边关于 $y$ 求导，由链式法则得 $f'(f^{-1}(y)) \cdot (f^{-1})'(y) = 1$，整理即得结论。$\square$

---

**实验单元（SymPy）。**

```python
from sympy import symbols, solve, Function, diff

x, y = symbols('x y')
f_expr = 2*x + 3

# 求反函数
inv_expr = solve(f_expr - y, x)[0]
print("f⁻¹(y) =", inv_expr)          # (y - 3)/2

# 验证微分法则
f_prime = diff(f_expr, x)
inv_prime = diff(inv_expr, y)
print("1/f'(x) =", 1/f_prime)        # 1/2
print("(f⁻¹)'(y) =", inv_prime)      # 1/2
```

运行结果确认 $(f^{-1})'(y) = 1/f'(x) = 1/2$，与定理完全吻合。

### logarithmic_function (17.3s)

## 对数函数

**定义。** 设 $a > 0$ 且 $a \neq 1$，$x > 0$。若 $a^y = x$，则称 $y$ 为以 $a$ 为底 $x$ 的**对数**，记作

$$y = \log_a x.$$

对数函数 $f(x) = \log_a x$ 是指数函数 $g(x) = a^x$ 的反函数，两者关于直线 $y = x$ 对称。其定义域为 $(0, +\infty)$，值域为 $(-\infty, +\infty)$，在 $x=1$ 处恒有 $\log_a 1 = 0$。当 $a > 1$ 时函数单调递增；当 $0 < a < 1$ 时单调递减。

特别地，以 $10$ 为底的对数称为**常用对数**，记作 $\lg x$；以自然常数 $e \approx 2.71828$ 为底的对数称为**自然对数**，记作 $\ln x$。

---

**典型例题。** 求满足 $\log_2(3x - 1) = 4$ 的实数 $x$。

由对数的定义，将方程转化为指数形式：

$$3x - 1 = 2^4 = 16.$$

解得

$$x = \frac{17}{3}.$$

验证：$3 \times \dfrac{17}{3} - 1 = 16 > 0$，满足真数为正的要求。$\blacksquare$

---

**关键定理（对数运算法则）。** 设 $a > 0$，$a \neq 1$，$M, N > 0$，则：

$$\log_a(MN) = \log_a M + \log_a N,$$
$$\log_a\!\left(\frac{M}{N}\right) = \log_a M - \log_a N,$$
$$\log_a M^n = n\log_a M \quad (n \in \mathbb{R}).$$

**换底公式**尤为重要：

$$\log_a M = \frac{\ln M}{\ln a}.$$

**证明思路（乘法法则）：** 令 $p = \log_a M$，$q = \log_a N$，则 $M = a^p$，$N = a^q$，故 $MN = a^{p+q}$，由定义即得 $\log_a(MN) = p + q$。其余法则类似推导。

---

**实验单元（SymPy）。**

```python
from sympy import *
x = symbols('x', positive=True)
a = symbols('a', positive=True)

f = log(x, a)                          # log_a(x)
print(expand_log(log(3*x**2, a), force=True))   # 展开对数
print(simplify(log(8, 2)))             # 计算 log_2(8)
print(diff(log(x), x))                # 求导 d/dx ln(x)
```

运行后应分别输出 $\log_a 3 + 2\log_a x$、$3$ 与 $\dfrac{1}{x}$，直观验证上述运算法则及导数公式 $(\ln x)' = \dfrac{1}{x}$。

### richter_scale_application (20.6s)

## Richter Scale Application

**定义。** 里氏震级（Richter magnitude scale）是一种对地震能量的对数度量。设地震释放的能量为 $E$（单位：焦耳），则震级 $M$ 定义为

$$M = \frac{2}{3} \log_{10}\!\left(\frac{E}{E_0}\right),$$

其中 $E_0 = 10^{4.4}\ \text{J}$ 为参考能量（对应震级零点的标准值）。等价地，若以地震仪记录的地面位移振幅 $A$（微米）与参考振幅 $A_0$ 之比来表达，则

$$M = \log_{10}\!\left(\frac{A}{A_0}\right).$$

对数的使用意味着震级每增加 $1$，振幅增大 $10$ 倍，能量增大约 $31.6$ 倍（即 $10^{3/2}$）。

---

**例题。** 2011 年日本东北地震的震级为 $M = 9.0$，而 1994 年洛杉矶北岭地震的震级为 $M = 6.7$。试求两者能量之比。

**解：** 由定义，

$$\frac{E_1}{E_2} = 10^{\frac{3}{2}(M_1 - M_2)} = 10^{\frac{3}{2}(9.0 - 6.7)} = 10^{\frac{3}{2} \times 2.3} = 10^{3.45} \approx 2818.$$

即东北地震释放的能量约为北岭地震的 $2818$ 倍。尽管震级仅相差 $2.3$，能量差异却超过三个数量级，清晰展示了对数尺度的"压缩"效应。

---

**关键定理（震级–能量单调性）。** 设 $M_1 > M_2$，则对应能量满足 $E_1 > E_2$，且

$$\ln\!\left(\frac{E_1}{E_2}\right) = \frac{3\ln 10}{2}(M_1 - M_2).$$

**证明思路：** 由定义 $M = \frac{2}{3}\log_{10}(E/E_0)$ 可解出 $E = E_0 \cdot 10^{3M/2}$，因此 $E_1/E_2 = 10^{3(M_1-M_2)/2}$，两边取自然对数即得结论。单调性由指数函数的严格递增性保证。$\blacksquare$

---

**实验单元（SymPy）**

```python
from sympy import symbols, log, Rational, simplify, N

M1, M2 = 9.0, 6.7
ratio = 10 ** (Rational(3, 2) * (M1 - M2))
print(f"能量之比: {N(ratio, 6)}")  # 输出约 2818.38

M = symbols('M')
E0 = 10 ** Rational(22, 5)          # 10^4.4
E_expr = E0 * 10 ** (Rational(3, 2) * M)
print(simplify(log(E_expr, 10)))    # 验证定义的可逆性
```

运行上述代码，可验证能量比的数值结果，并通过符号化推导确认对数定义的自洽性。

### limits_at_infinity (16.6s)

## Limits At Infinity

### 定义

设函数 $f(x)$ 在区间 $(a, +\infty)$ 上有定义。若对任意 $\varepsilon > 0$，存在 $M > 0$，使得当 $x > M$ 时，恒有

$$|f(x) - L| < \varepsilon,$$

则称当 $x \to +\infty$ 时，$f(x)$ 的**极限为** $L$，记作

$$\lim_{x \to +\infty} f(x) = L.$$

类似地，可定义 $\lim_{x \to -\infty} f(x) = L$。若上述两个单侧极限均等于 $L$，则称 $\lim_{x \to \infty} f(x) = L$，此时直线 $y = L$ 称为函数图像的**水平渐近线**。

---

### 例题

求极限 $\displaystyle\lim_{x \to +\infty} \frac{3x^2 - 2x + 1}{5x^2 + 4}$。

**解：** 分子、分母同除以 $x^2$（$x \to +\infty$ 时 $x^2 > 0$）：

$$\lim_{x \to +\infty} \frac{3 - \dfrac{2}{x} + \dfrac{1}{x^2}}{5 + \dfrac{4}{x^2}}.$$

由于 $\dfrac{1}{x} \to 0$ 且 $\dfrac{1}{x^2} \to 0$（当 $x \to +\infty$），代入得

$$\frac{3 - 0 + 0}{5 + 0} = \frac{3}{5}.$$

故 $y = \dfrac{3}{5}$ 为该函数的水平渐近线。

---

### 关键定理

**有理函数无穷极限定理：** 设 $f(x) = \dfrac{a_n x^n + \cdots + a_0}{b_m x^m + \cdots + b_0}$，$a_n \neq 0$，$b_m \neq 0$，则

$$\lim_{x \to \infty} f(x) = \begin{cases} \dfrac{a_n}{b_m}, & n = m, \\[6pt] 0, & n < m, \\[4pt] \text{不存在（趋于} \pm\infty\text{）}, & n > m. \end{cases}$$

**证明思路：** 将分子分母同除以 $x^{\max(n,m)}$，利用 $\lim_{x\to\infty} x^{-k} = 0$（$k > 0$）逐项化简，再由极限的四则运算法则得到结论。

---

### 实验单元（SymPy）

```python
from sympy import symbols, limit, oo, Rational

x = symbols('x')
f = (3*x**2 - 2*x + 1) / (5*x**2 + 4)

print(limit(f, x, oo))   # 输出：3/5
print(limit(f, x, -oo))  # 输出：3/5
```

运行上述代码，验证两个单侧极限均为 $\dfrac{3}{5}$，与手算结果一致。读者可尝试修改分子或分母的次数，观察极限如何随阶数关系的变化而改变。

### derivative (0.0s)

## 导数

**定义。** 设函数 $f$ 在点 $x_0$ 的某邻域内有定义。若极限

$$f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h}$$

存在且有限，则称 $f$ 在点 $x_0$ **可微**，并将该极限值称为 $f$ 在 $x_0$ 处的**导数**（derivative）。几何上，$f'(x_0)$ 即曲线 $y = f(x)$ 在点 $(x_0,\, f(x_0))$ 处切线的斜率；物理上，若 $f(t)$ 表示位移，则 $f'(t)$ 表示瞬时速度。

---

**例题。** 求 $f(x) = x^2$ 在 $x_0 = 3$ 处的导数。

按定义展开差商：

$$\frac{f(3+h) - f(3)}{h} = \frac{(3+h)^2 - 9}{h} = \frac{9 + 6h + h^2 - 9}{h} = 6 + h.$$

令 $h \to 0$，得

$$f'(3) = \lim_{h \to 0}(6 + h) = 6.$$

几何验证：曲线 $y = x^2$ 在点 $(3, 9)$ 处的切线方程为 $y - 9 = 6(x - 3)$，即 $y = 6x - 9$。

---

**定理（可微必连续）。** 若 $f$ 在 $x_0$ 处可微，则 $f$ 在 $x_0$ 处连续。

**证明思路。** 将函数增量写成

$$f(x_0 + h) - f(x_0) = \frac{f(x_0+h)-f(x_0)}{h} \cdot h.$$

当 $h \to 0$ 时，右端第一个因子趋向 $f'(x_0)$（有限值），第二个因子 $h \to 0$，故乘积趋向 $0$，即 $\lim_{h\to 0} f(x_0+h) = f(x_0)$，连续性得证。$\blacksquare$

注意逆命题不成立：$f(x) = |x|$ 在 $x = 0$ 处连续但不可微，因为左右极限 $\lim_{h\to 0^-} h/|h| = -1 \neq 1 = \lim_{h\to 0^+} h/|h|$ 不相等。

---

**实验单元（SymPy）。**

```python
import sympy as sp

x, h = sp.symbols('x h')
f = x**2

# 用极限定义计算导数
diff_quot = (f.subs(x, x + h) - f) / h
derivative = sp.limit(diff_quot, h, 0)
print(derivative)          # 输出：2*x

# 符号求导验证
print(sp.diff(f, x))       # 输出：2*x
```

运行上述代码，两种方式均输出 $2x$，与幂函数求导公式 $(x^n)' = nx^{n-1}$（取 $n=2$）完全一致。

### indeterminate_forms (18.8s)

## 不定式

**定义.** 设函数 $f(x)$ 与 $g(x)$ 在点 $a$ 的某去心邻域内有定义，若当 $x \to a$ 时，$f(x) \to 0$ 且 $g(x) \to 0$，则极限

$$\lim_{x \to a} \frac{f(x)}{g(x)}$$

称为 $\dfrac{0}{0}$ 型**不定式**（indeterminate form）。类似地，若 $f(x) \to \infty$ 且 $g(x) \to \infty$，则称为 $\dfrac{\infty}{\infty}$ 型不定式。此外，常见的不定式还包括 $0 \cdot \infty$、$\infty - \infty$、$0^{0}$、$1^{\infty}$ 与 $\infty^{0}$ 共七种形式。所谓"不定"，是指极限值不能由各因子的极限直接确定，需借助专门方法加以分析。

---

**典型例子.** 考察极限

$$\lim_{x \to 0} \frac{\sin x}{x}.$$

当 $x \to 0$ 时，分子 $\sin x \to 0$，分母 $x \to 0$，构成 $\dfrac{0}{0}$ 型不定式。直接代入给出 $\dfrac{0}{0}$，无意义。利用单位圆几何不等式可以证明

$$\cos x \leq \frac{\sin x}{x} \leq 1 \quad (0 < |x| < \tfrac{\pi}{2}),$$

再由夹逼定理得 $\displaystyle\lim_{x \to 0} \frac{\sin x}{x} = 1$，极限存在且唯一确定。

---

**关键定理（洛必达法则）.** 设 $f, g$ 在点 $a$ 的去心邻域内可微，$g'(x) \neq 0$，且极限 $\dfrac{f(x)}{g(x)}$ 为 $\dfrac{0}{0}$ 型或 $\dfrac{\infty}{\infty}$ 型不定式。若极限

$$\lim_{x \to a} \frac{f'(x)}{g'(x)} = L \quad (L \in \mathbb{R} \cup \{\pm\infty\}),$$

则 $\displaystyle\lim_{x \to a} \frac{f(x)}{g(x)} = L$。

*证明思路：* $\dfrac{0}{0}$ 型情形可由柯西中值定理直接导出；其余类型可通过代数变换化归为上述两种基本型后再施用该定理。

---

**实验单元（SymPy）.**

```python
from sympy import *
x = symbols('x')

# 验证 sin(x)/x 在 x→0 处的极限
expr = sin(x) / x
print(limit(expr, x, 0))          # 输出: 1

# 洛必达法则应用示例
f = exp(x) - 1
g = x
print(limit(f/g, x, 0))           # 输出: 1
print(limit(diff(f,x)/diff(g,x), x, 0))  # 输出: 1，与直接极限一致
```

通过符号计算的验证可以看到，洛必达法则将不定式的求解转化为对导函数比值极限的计算，是分析不定式的最系统工具。

### lhopitals_rule (20.3s)

## Lhopitals Rule

**定义**

设函数 $f$ 与 $g$ 在点 $a$ 的某去心邻域内可微，且 $g'(x)\neq 0$。若极限 $\lim_{x\to a}f(x)=0,\;\lim_{x\to a}g(x)=0$（或两者均趋于 $\pm\infty$），则

$$
\lim_{x\to a}\frac{f(x)}{g(x)}=\lim_{x\to a}\frac{f'(x)}{g'(x)},
$$

前提是右侧极限存在（有限或为无穷大）。此规则由法国数学家洛必达（Guillaume de l'Hôpital）于 1696 年在其著作中正式发表，实际证明归功于约翰·伯努利（Johann Bernoulli）。

---

**证明思路**

以 $\tfrac{0}{0}$ 型为例。由柯西中值定理，存在 $c$ 介于 $x$ 与 $a$ 之间，使得

$$
\frac{f(x)-f(a)}{g(x)-g(a)}=\frac{f'(c)}{g'(c)}.
$$

因 $f(a)=g(a)=0$，上式化为 $\dfrac{f(x)}{g(x)}=\dfrac{f'(c)}{g'(c)}$。当 $x\to a$ 时，夹逼关系迫使 $c\to a$，故极限成立。

---

**典型例题**

计算 $\displaystyle\lim_{x\to 0}\frac{\sin x - x}{x^3}$。

直接代入得 $\tfrac{0}{0}$ 型，连续施用洛必达法则：

$$
\lim_{x\to 0}\frac{\sin x - x}{x^3}
\xrightarrow{L}
\lim_{x\to 0}\frac{\cos x - 1}{3x^2}
\xrightarrow{L}
\lim_{x\to 0}\frac{-\sin x}{6x}
\xrightarrow{L}
\lim_{x\to 0}\frac{-\cos x}{6}
=-\frac{1}{6}.
$$

每次施用前均需验证仍为 $\tfrac{0}{0}$ 或 $\tfrac{\infty}{\infty}$ 型，否则结果无效。

---

**关键定理**

洛必达法则对以下六种不定式均适用（经适当代数变形后化归为 $\tfrac{0}{0}$ 或 $\tfrac{\infty}{\infty}$）：

$$
\frac{0}{0},\quad \frac{\infty}{\infty},\quad 0\cdot\infty,\quad \infty-\infty,\quad 0^{0},\quad \infty^{0},\quad 1^{\infty}.
$$

---

**实验单元（SymPy）**

```python
from sympy import *
x = symbols('x')
f = sin(x) - x
g = x**3
# 直接求极限
print(limit(f/g, x, 0))          # 输出 -1/6

# 手动验证各步导数
for _ in range(3):
    f, g = diff(f, x), diff(g, x)
    print(simplify(f), "/", simplify(g), "→", limit(f/g, x, 0))
```

运行上述代码，可逐步观察分子分母在三次求导后的化简过程，加深对法则逐步施用机制的直观理解。

### growth_rates (20.0s)

## Growth Rates

**定义。** 设 $f, g : \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ 为两个正值函数。若极限

$$L = \lim_{x \to \infty} \frac{f(x)}{g(x)}$$

存在且有限，则称 $f$ 与 $g$ 具有**相同的增长阶**，记作 $f \sim g$（当 $L=1$ 时）或 $f = \Theta(g)$（当 $0 < L < \infty$ 时）。若 $L = 0$，则 $f$ 的增长**慢于** $g$，记作 $f = o(g)$；若 $L = \infty$，则 $f$ 的增长**快于** $g$，记作 $g = o(f)$。这一比较框架构成了算法分析与渐近分析的基础。

常见函数的增长阶从慢到快排列如下：

$$1 \;\prec\; \ln x \;\prec\; x^\alpha \;\prec\; x^\beta \;\prec\; a^x \;\prec\; x! \;\prec\; x^x \qquad (0 < \alpha < \beta,\; a > 1)$$

**例题。** 比较 $f(x) = 3x^2 + 5x$ 与 $g(x) = x^2 \ln x$ 的增长阶。

计算极限：

$$\lim_{x \to \infty} \frac{3x^2 + 5x}{x^2 \ln x} = \lim_{x \to \infty} \frac{3 + 5/x}{\ln x} = \frac{3}{\infty} = 0$$

因此 $f = o(g)$，即 $x^2 \ln x$ 的增长严格快于 $3x^2 + 5x$。直觉上，多项式的主项系数在对数因子面前最终失去主导地位。

**关键定理（L'Hôpital 准则的推论）。** 设 $f, g$ 均为最终正值、可微的函数，且 $\lim_{x\to\infty} g(x) = \infty$。若

$$\lim_{x \to \infty} \frac{f'(x)}{g'(x)} = L \in [0, +\infty]$$

则 $\displaystyle\lim_{x \to \infty} \frac{f(x)}{g(x)} = L$。

**证明梗概：** 对 $f/g$ 在区间 $[a, x]$ 上应用 Cauchy 中值定理，令 $a \to \infty$ 即得结论。$\blacksquare$

**实验室单元。**

```python
from sympy import *
x = symbols('x', positive=True)

f = 3*x**2 + 5*x
g = x**2 * ln(x)

# 计算增长阶比值
ratio = limit(f / g, x, oo)
print("lim f/g =", ratio)  # 输出 0，确认 f = o(g)

# 绘制对数坐标下的增长曲线
import matplotlib.pyplot as plt
import numpy as np
xs = np.logspace(1, 4, 300)
plt.loglog(xs, 3*xs**2 + 5*xs, label=r'$3x^2+5x$')
plt.loglog(xs, xs**2 * np.log(xs), label=r'$x^2\ln x$')
plt.legend(); plt.xlabel('x'); plt.title('增长阶比较'); plt.show()
```

运行上述代码可直观验证：在对数坐标下，$x^2 \ln x$ 的斜率最终超越 $3x^2 + 5x$，与理论分析完全吻合。

## 图(Graph)

**定义。** 图是描述"对象及其相互关系"的数学结构。一个图 $G=(V,E)$ 由顶点集 $V$(对象)和边集 $E$(关系)组成。若边没有方向(如"互为好友"),称为无向图;若边有方向(如"课程A是课程B的先修课"),称为有向图。顶点 $v$ 的**度**是与它相连的边数,记作 $\deg(v)$。在无向图中,所有顶点度数之和等于边数的两倍:

$$\sum_{v\in V}\deg(v)=2|E|.$$

图的常见存储方式有两种:**邻接表**(每个顶点存一份邻居列表,适合稀疏图)和**邻接矩阵**($A_{ij}=1$ 表示 $i$ 到 $j$ 有边,适合稠密图)。

**例题。** 某校有四门课:微积分(C)、线性代数(L)、概率论(P)、机器学习(M)。先修关系为:C→L,C→P,L→M,P→M。

邻接表为:

- C: [L, P]
- L: [M]
- P: [M]
- M: []

问:要修机器学习,最少需要先修哪些课?它们的合法修读顺序是什么?

解:从 M 沿边反向追溯,得到 L 和 P;再追溯得到 C。因此必须先修 C、L、P 三门课。合法顺序需满足每条边的起点先于终点,例如 C, L, P, M 或 C, P, L, M。这种满足所有边方向的排列称为**拓扑排序**,它只在**无环**的有向图(DAG)中存在。

**问题求解应用。** 许多实际问题都可以先"建图",再用成熟算法求解:

1. **最短路径**:地图导航中,路口是顶点,道路是边,边权为距离或时间。无权图用广度优先搜索(BFS)即可求出最少边数的路径。
2. **连通性**:判断社交网络中两人是否能通过朋友链相识,即判断两顶点是否在同一连通分量中。可用深度优先搜索(DFS)实现:

```python
def reachable(graph, start, goal):
    seen, stack = set(), [start]
    while stack:
        v = stack.pop()
        if v == goal:
            return True
        if v not in seen:
            seen.add(v)
            stack.extend(graph[v])
    return False
```

3. **依赖检测**:若先修关系中出现环(如 A→B→C→A),则任何人都无法修完这些课。用 DFS 检测环,是软件构建系统、任务调度器的基本功能。

**小结。** 解图问题的关键在于三步:确定什么是顶点、什么是边;选择合适的存储方式;再套用 BFS、DFS 或拓扑排序等算法。把陌生问题转化为图,往往就解决了一大半。

## 图嵌入(Graph Embedding)

**定义。** 图嵌入是把图 $G=(V,E)$ 中的每个节点映射为低维向量 $\mathbf{z}_v\in\mathbb{R}^d$($d\ll |V|$)的方法,目标是让图中"关系近"的节点在向量空间中也"距离近"。这样,原本只能用邻接表或邻接矩阵表示的结构信息,就可以直接交给聚类、分类、最近邻检索等标准机器学习工具处理。

最简单的训练目标是:对相连的节点,让内积 $\mathbf{z}_u^\top\mathbf{z}_v$ 较大;对随机选取的不相连节点,让内积较小。DeepWalk、node2vec 等方法则先在图上做随机游走,把节点序列当作"句子",再用词向量(skip-gram)方法训练。

**例题。** 考虑 4 个节点的小图:边为 $A\!-\!B,\ B\!-\!C,\ C\!-\!A,\ C\!-\!D$。取 $d=2$,假设训练得到

$$\mathbf{z}_A=(1,0.9),\ \mathbf{z}_B=(0.9,1),\ \mathbf{z}_C=(0.8,0.7),\ \mathbf{z}_D=(-0.5,0.2).$$

比较欧氏距离:

$$\|\mathbf{z}_A-\mathbf{z}_B\|=\sqrt{0.1^2+0.1^2}\approx 0.14,\qquad \|\mathbf{z}_A-\mathbf{z}_D\|=\sqrt{1.5^2+0.7^2}\approx 1.66.$$

$A,B,C$ 构成三角形,彼此紧密相连,所以向量聚在一起;$D$ 只通过 $C$ 与它们相连,因此被"推"到远处。向量几何忠实地反映了图的社区结构。

**问题求解应用:链接预测。** 假设要判断 $B$ 与 $D$ 之间是否可能"缺失"一条边。步骤如下:

1. 计算相似度,例如余弦相似度:
$$\cos(\mathbf{z}_B,\mathbf{z}_D)=\frac{\mathbf{z}_B\cdot\mathbf{z}_D}{\|\mathbf{z}_B\|\|\mathbf{z}_D\|}=\frac{-0.45+0.2}{1.345\times 0.539}\approx -0.34.$$
2. 与已有边比较:$\cos(\mathbf{z}_A,\mathbf{z}_B)\approx 1.0$。
3. 设定阈值(如 0.5),$B$–$D$ 的得分远低于阈值,因此不预测这条边。

同样的流程可用于其他任务:对 $\mathbf{z}_v$ 做 $k$-means 可发现社区;把 $\mathbf{z}_v$ 输入分类器可预测用户类别;对查询节点做最近邻检索可实现推荐。

**实践要点。** 嵌入维度 $d$ 过小会丢失结构信息,过大则容易过拟合且计算成本高,通常用验证集上的下游任务表现来选择。另外要注意,不同次训练得到的向量坐标可能整体旋转或平移,所以只有同一次训练内的距离和相似度才有意义,不能直接比较不同模型的坐标。

**小结。** 图嵌入把"结构关系"转化为"几何距离",使图数据能够使用成熟的向量化工具,是链接预测、社区发现与推荐系统的共同基础。

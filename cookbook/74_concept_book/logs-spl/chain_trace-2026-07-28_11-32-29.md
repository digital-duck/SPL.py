### continuous_random_variable (18.0s)

## Continuous Random Variable

**定义。** 设 $(\Omega, \mathcal{F}, P)$ 为概率空间。若随机变量 $X: \Omega \to \mathbb{R}$ 存在非负可积函数 $f_X: \mathbb{R} \to [0, +\infty)$，使得对任意 Borel 集 $B \subseteq \mathbb{R}$ 均有

$$P(X \in B) = \int_B f_X(x)\, dx,$$

则称 $X$ 为**连续型随机变量**，$f_X$ 称为其**概率密度函数**（probability density function，PDF）。$f_X$ 须满足归一化条件：

$$\int_{-\infty}^{+\infty} f_X(x)\, dx = 1.$$

值得注意的是，对任意单点 $c \in \mathbb{R}$，有 $P(X = c) = 0$，这与离散型随机变量有本质区别。

---

**例题。** 设 $X$ 服从区间 $[0, 3]$ 上的均匀分布，即

$$f_X(x) = \begin{cases} \dfrac{1}{3}, & 0 \le x \le 3, \\ 0, & \text{其他.} \end{cases}$$

求 $P(1 \le X \le 2)$。

**解。**

$$P(1 \le X \le 2) = \int_1^2 \frac{1}{3}\, dx = \frac{1}{3} \cdot (2 - 1) = \frac{1}{3}.$$

---

**核心定理（累积分布函数的可微性）。** 设 $X$ 为连续型随机变量，其累积分布函数（CDF）定义为

$$F_X(x) = P(X \le x) = \int_{-\infty}^{x} f_X(t)\, dt.$$

则 $F_X$ 在 $f_X$ 的连续点处可微，且

$$F_X'(x) = f_X(x).$$

**证明要点。** 由微积分基本定理，当 $f_X$ 在 $x$ 处连续时，

$$\frac{d}{dx} \int_{-\infty}^{x} f_X(t)\, dt = f_X(x). \qquad \square$$

该定理表明，PDF 与 CDF 互为微分–积分对，从而将概率计算转化为标准的定积分运算。

---

**实验单元（SymPy）。**

```python
from sympy import symbols, integrate, Rational, Piecewise, oo

x = symbols('x')
f = Rational(1, 3)                         # 均匀分布密度

# 验证归一化
print(integrate(f, (x, 0, 3)))             # 输出 1

# 计算 P(1 ≤ X ≤ 2)
prob = integrate(f, (x, 1, 2))
print(prob)                                # 输出 1/3

# 构造 CDF
F = integrate(f, (x, 0, x))
print(F)                                   # 输出 x/3
```

运行上述代码，学生可直观验证归一化条件成立，并观察 CDF 在 $[0,3]$ 上以斜率 $\tfrac{1}{3}$ 线性递增至 $1$，加深对密度函数与分布函数关系的理解。

### probability_density_function (15.2s)

## Probability Density Function

**定义。** 设 $X$ 为连续型随机变量。若存在非负可积函数 $f: \mathbb{R} \to [0, +\infty)$，使得对任意实数 $a \leq b$，均有

$$P(a \leq X \leq b) = \int_a^b f(x)\, dx,$$

则称 $f(x)$ 为 $X$ 的**概率密度函数**（Probability Density Function，简称 PDF）。概率密度函数须满足归一化条件：

$$\int_{-\infty}^{+\infty} f(x)\, dx = 1.$$

需要特别注意的是，$f(x)$ 本身并非概率，而是概率关于区间长度的密度；单点处的概率 $P(X = x_0) = 0$ 恒成立。

---

**例题。** 设随机变量 $X$ 的概率密度函数为

$$f(x) = \begin{cases} c\,x^2, & 0 \leq x \leq 3, \\ 0, & \text{其他.} \end{cases}$$

**第一步：确定常数 $c$。** 由归一化条件，

$$\int_0^3 c\,x^2\, dx = c \cdot \frac{x^3}{3}\Big|_0^3 = c \cdot 9 = 1 \implies c = \frac{1}{9}.$$

**第二步：计算概率。** 求 $P(1 \leq X \leq 2)$：

$$P(1 \leq X \leq 2) = \int_1^2 \frac{x^2}{9}\, dx = \frac{1}{9} \cdot \frac{x^3}{3}\Big|_1^2 = \frac{1}{27}(8 - 1) = \frac{7}{27} \approx 0.259.$$

---

**关键定理（累积分布函数与 PDF 的关系）。** 若 $X$ 的概率密度函数为 $f(x)$，则其累积分布函数（CDF）定义为

$$F(x) = P(X \leq x) = \int_{-\infty}^{x} f(t)\, dt.$$

由微积分基本定理，在 $f$ 连续处有 $F'(x) = f(x)$。这一关系揭示了 PDF 与 CDF 之间的微分—积分对偶性，是连续概率论的核心结构。

---

**实验单元（SymPy）。**

```python
from sympy import *
x = symbols('x')
f = x**2 / 9
# 验证归一化
print(integrate(f, (x, 0, 3)))          # 输出：1
# 计算区间概率
print(integrate(f, (x, 1, 2)))          # 输出：7/27
# 求累积分布函数
F = integrate(f, (x, 0, x))
print(F)                                 # 输出：x**3/27
```

### exponential_distribution (20.1s)

## 指数分布

**定义**

设随机变量 $X$ 表示某随机事件两次相继发生之间的等待时间，若 $X$ 的概率密度函数为

$$f(x;\lambda) = \begin{cases} \lambda e^{-\lambda x}, & x \geq 0 \\ 0, & x < 0 \end{cases}$$

其中参数 $\lambda > 0$ 称为**速率参数**（rate parameter），则称 $X$ 服从参数为 $\lambda$ 的**指数分布**，记作 $X \sim \mathrm{Exp}(\lambda)$。其累积分布函数为

$$F(x;\lambda) = 1 - e^{-\lambda x}, \quad x \geq 0.$$

期望与方差分别为 $\mathbb{E}[X] = \dfrac{1}{\lambda}$，$\mathrm{Var}(X) = \dfrac{1}{\lambda^2}$。

---

**例题**

某网络服务器平均每分钟接收 3 个请求，即 $\lambda = 3$（次/分钟）。设相邻两次请求的间隔时间 $X \sim \mathrm{Exp}(3)$，求间隔时间超过 $0.5$ 分钟的概率。

**解：**

$$P(X > 0.5) = 1 - F(0.5) = e^{-3 \times 0.5} = e^{-1.5} \approx 0.2231.$$

因此，约有 $22.3\%$ 的概率等待时间超过半分钟。

---

**核心定理：无记忆性**

指数分布是连续分布中**唯一**具有无记忆性（memoryless property）的分布。具体地，对任意 $s, t > 0$，有

$$P(X > s + t \mid X > s) = P(X > t).$$

**证明要点：** 利用条件概率定义与指数函数性质，

$$P(X > s + t \mid X > s) = \frac{P(X > s+t)}{P(X > s)} = \frac{e^{-\lambda(s+t)}}{e^{-\lambda s}} = e^{-\lambda t} = P(X > t). \qed$$

此性质表明：已知系统已正常运行 $s$ 分钟，其在此后继续运行至少 $t$ 分钟的概率，与从零时刻起运行至少 $t$ 分钟的概率完全相同——系统对过去毫无"记忆"。

---

**实验室：SymPy 验证**

```python
from sympy import symbols, exp, integrate, oo, simplify

x, lam = symbols('x lambda', positive=True)

# 概率密度函数
f = lam * exp(-lam * x)

# 验证归一化
total = integrate(f, (x, 0, oo))
print("积分 =", total)  # 输出: 1

# 计算期望
mean = integrate(x * f, (x, 0, oo))
print("期望 =", mean)   # 输出: 1/lambda

# 验证无记忆性：P(X > s+t) / P(X > s) == P(X > t)
s, t = symbols('s t', positive=True)
ratio = simplify(exp(-lam*(s+t)) / exp(-lam*s))
print("条件概率 =", ratio)  # 输出: exp(-lambda*t)
```

### uniform_distribution (16.6s)

## 均匀分布

**定义。** 设随机变量 $X$ 在区间 $[a, b]$（$a < b$）上取值，若其概率密度函数为

$$
f(x) = \begin{cases} \dfrac{1}{b - a}, & a \leq x \leq b, \\ 0, & \text{其他}, \end{cases}
$$

则称 $X$ 服从区间 $[a, b]$ 上的**均匀分布**，记作 $X \sim U(a, b)$。直觉上，均匀分布意味着 $X$ 落在 $[a, b]$ 内任意等长子区间的概率完全相同——没有任何位置被"偏爱"。其累积分布函数为

$$
F(x) = \begin{cases} 0, & x < a, \\ \dfrac{x - a}{b - a}, & a \leq x \leq b, \\ 1, & x > b. \end{cases}
$$

**例题。** 公交车每隔 $10$ 分钟一班，乘客到站时刻与下一班车发车时刻之间的等待时间 $X \sim U(0, 10)$（单位：分钟）。求乘客等待超过 $6$ 分钟的概率。

$$
P(X > 6) = \int_{6}^{10} \frac{1}{10}\,dx = \frac{10 - 6}{10} = 0.4.
$$

因此，有 $40\%$ 的概率需要等待超过 $6$ 分钟。

**关键定理。** 若 $X \sim U(a, b)$，则其期望与方差分别为

$$
E[X] = \frac{a + b}{2}, \qquad \operatorname{Var}(X) = \frac{(b - a)^2}{12}.
$$

**证明要点。** 直接计算：

$$
E[X] = \int_{a}^{b} \frac{x}{b-a}\,dx = \frac{1}{b-a} \cdot \frac{b^2 - a^2}{2} = \frac{a+b}{2}.
$$

类似地，$E[X^2] = \dfrac{a^2 + ab + b^2}{3}$，由此得 $\operatorname{Var}(X) = E[X^2] - (E[X])^2 = \dfrac{(b-a)^2}{12}$。均匀分布还具有重要的变换性质：若 $U \sim U(0,1)$，则 $X = a + (b-a)U \sim U(a,b)$，这是蒙特卡洛模拟中生成任意均匀样本的理论基础。

**实验单元（SymPy）。**

```python
from sympy import *
a, b, x = symbols('a b x', real=True)
f = Rational(1, 1) / (b - a)
mean = integrate(x * f, (x, a, b))
var  = integrate(x**2 * f, (x, a, b)) - mean**2
print("期望 =", simplify(mean))   # (a + b)/2
print("方差 =", simplify(var))    # (b - a)**2/12
```

运行上述代码，可验证理论公式并直观感受符号积分与均匀分布参数之间的关系。

### mean_and_standard_deviation_of_continuous_distributions (16.6s)

## Mean And Standard Deviation Of Continuous Distributions

### 定义

设 $X$ 为连续型随机变量，其概率密度函数为 $f(x)$，满足 $f(x) \geq 0$ 且 $\int_{-\infty}^{+\infty} f(x)\,dx = 1$。

**期望（均值）** 定义为：
$$\mu = E[X] = \int_{-\infty}^{+\infty} x\,f(x)\,dx$$

**方差** 定义为偏差平方的期望：
$$\sigma^2 = \operatorname{Var}(X) = E\bigl[(X - \mu)^2\bigr] = \int_{-\infty}^{+\infty}(x - \mu)^2 f(x)\,dx$$

**标准差** 为方差的正平方根：$\sigma = \sqrt{\sigma^2}$。

期望 $\mu$ 描述分布的"重心"位置，标准差 $\sigma$ 量化数据围绕该中心的离散程度。

---

### 例题

设 $X$ 服从区间 $[0,\,2]$ 上的均匀分布，即

$$f(x) = \begin{cases} \dfrac{1}{2}, & 0 \le x \le 2 \\ 0, & \text{其余} \end{cases}$$

**计算均值：**

$$\mu = \int_0^2 x \cdot \frac{1}{2}\,dx = \frac{1}{2}\cdot\frac{x^2}{2}\Big|_0^2 = \frac{1}{2}\cdot 2 = 1$$

**计算方差：**

$$\sigma^2 = \int_0^2 (x-1)^2 \cdot \frac{1}{2}\,dx = \frac{1}{2}\cdot\frac{(x-1)^3}{3}\Big|_0^2 = \frac{1}{2}\cdot\left(\frac{1}{3}+\frac{1}{3}\right) = \frac{1}{3}$$

故 $\sigma = \dfrac{1}{\sqrt{3}} \approx 0.577$。

---

### 核心定理

**方差的计算公式：**

$$\operatorname{Var}(X) = E[X^2] - \mu^2$$

**证明思路：** 展开 $(X-\mu)^2 = X^2 - 2\mu X + \mu^2$，对积分取期望，利用 $E[\mu X] = \mu E[X] = \mu^2$ 及 $E[\mu^2] = \mu^2$，化简即得。此公式在实际计算中往往比直接积分 $(x-\mu)^2$ 更为简便。

---

### 实验单元（SymPy）

```python
from sympy import *
x = symbols('x')
f = Rational(1, 2)                        # 均匀分布密度
mu    = integrate(x * f, (x, 0, 2))
E_x2  = integrate(x**2 * f, (x, 0, 2))
var   = E_x2 - mu**2
sigma = sqrt(var)
print(f"均值 μ = {mu},  方差 σ² = {var},  标准差 σ = {sigma}")
```

运行结果：`均值 μ = 1, 方差 σ² = 1/3, 标准差 σ = sqrt(3)/3`，与手算完全吻合。

### empirical_vs_theoretical_distribution_comparison (20.0s)

## Empirical Vs Theoretical Distribution Comparison

**定义**

设 $X_1, X_2, \ldots, X_n$ 为来自某未知总体的独立同分布随机样本。**经验分布函数**（empirical distribution function，EDF）定义为

$$F_n(x) = \frac{1}{n} \sum_{i=1}^{n} \mathbf{1}[X_i \leq x],$$

其中 $\mathbf{1}[\cdot]$ 为示性函数。$F_n(x)$ 是一个阶梯函数，在每个观测值处跳跃 $1/n$。**理论分布函数**（theoretical CDF）$F(x)$ 则由参数模型（如正态分布、泊松分布）完全确定。比较 $F_n$ 与 $F$ 是统计推断的核心任务之一。

---

**例题**

设观测样本为 $\{1.2,\ 2.4,\ 2.4,\ 3.1,\ 4.0\}$，假设理论模型为 $X \sim \mathcal{N}(\mu, \sigma^2)$，用矩估计得 $\hat{\mu} = 2.62$，$\hat{\sigma} = 1.01$。计算 $x = 2.4$ 处的比较：

$$F_5(2.4) = \frac{3}{5} = 0.60, \qquad F(2.4) = \Phi\!\left(\frac{2.4 - 2.62}{1.01}\right) \approx \Phi(-0.218) \approx 0.414.$$

两者偏差为 $|F_5(2.4) - F(2.4)| \approx 0.186$，提示在该点处经验分布与正态模型存在可观差距。

---

**关键定理：Kolmogorov–Smirnov 统计量**

定义 KS 统计量

$$D_n = \sup_{x \in \mathbb{R}} |F_n(x) - F(x)|.$$

**Glivenko–Cantelli 定理**保证，当 $n \to \infty$ 时，$D_n \xrightarrow{a.s.} 0$，即经验分布函数几乎必然一致收敛于真实 CDF。进一步，Kolmogorov 证明

$$\sqrt{n}\, D_n \xrightarrow{d} K,$$

其中 $K$ 为 Kolmogorov 分布。给定显著性水平 $\alpha$，若 $D_n > c_\alpha / \sqrt{n}$，则拒绝 $H_0: F = F_0$。

---

**实验单元（SymPy / SciPy）**

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(42)
sample = rng.normal(loc=0, scale=1, size=50)

# KS 检验：与标准正态比较
stat, p_value = stats.kstest(sample, 'norm', args=(0, 1))
print(f"D_n = {stat:.4f},  p 值 = {p_value:.4f}")

# 绘制 EDF 与理论 CDF
import matplotlib.pyplot as plt
x = np.linspace(-4, 4, 200)
plt.step(np.sort(sample), np.arange(1, 51)/50, label='$F_n(x)$')
plt.plot(x, stats.norm.cdf(x), label='$F(x)$')
plt.legend(); plt.title('经验分布与理论分布对比'); plt.show()
```

通过可视化与 KS 检验，学生可直观理解 $F_n$ 随样本量增大逐渐逼近 $F$ 的过程，并掌握假设检验的量化依据。

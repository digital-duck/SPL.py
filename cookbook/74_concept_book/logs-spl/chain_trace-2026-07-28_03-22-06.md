### partition (0.0s)

## Partition

**Definition.** Let $S$ be a non-empty set. A *partition* of $S$ is a collection of subsets $\{A_1, A_2, \ldots, A_k\}$ (finite case) or $\{A_i\}_{i \in I}$ (general case) satisfying three conditions:

1. **Non-emptiness:** $A_i \neq \emptyset$ for all $i$.
2. **Mutual disjointness:** $A_i \cap A_j = \emptyset$ whenever $i \neq j$.
3. **Exhaustiveness:** $\displaystyle\bigcup_{i \in I} A_i = S$.

Each $A_i$ is called a *block* (or *cell*) of the partition. Partitions arise whenever a set is classified by some equivalence relation: the blocks are precisely the equivalence classes.

**Worked Example.** Consider $S = \{1, 2, 3, 4, 5, 6\}$ and the relation "same remainder modulo 3." The remainder classes are:

$$A_0 = \{3, 6\}, \quad A_1 = \{1, 4\}, \quad A_2 = \{2, 5\}.$$

We verify: (1) each block is non-empty; (2) $A_0 \cap A_1 = A_0 \cap A_2 = A_1 \cap A_2 = \emptyset$; (3) $A_0 \cup A_1 \cup A_2 = S$. Hence $\{A_0, A_1, A_2\}$ is a partition of $S$ into three blocks of equal size 2.

**Counting partitions — Bell numbers.** The number of distinct partitions of an $n$-element set is the $n$-th *Bell number* $B_n$. These satisfy the recurrence

$$B_{n+1} = \sum_{k=0}^{n} \binom{n}{k} B_k, \qquad B_0 = 1.$$

The first few values are $B_0=1,\; B_1=1,\; B_2=2,\; B_3=5,\; B_4=15$. The growth is super-exponential; a closed-form expression uses the *Bell triangle* or Dobinski's formula $B_n = e^{-1}\sum_{k=0}^{\infty} k^n / k!$.

**Theorem (Partition–Equivalence Correspondence).** There is a bijection between partitions of $S$ and equivalence relations on $S$: given a partition, define $a \sim b$ iff $a$ and $b$ belong to the same block; conversely, given an equivalence relation, its equivalence classes form a partition.

```python
           for i in range(3) for j in range(3) if i != j)
print("Partition verified:", blocks)
```

### sigma_notation (0.0s)

## Sigma Notation

**Definition.** Let $a_m, a_{m+1}, \ldots, a_n$ be a finite sequence of real numbers indexed by integers $m \leq n$. The *sigma notation* (or *summation notation*) for their sum is

$$\sum_{k=m}^{n} a_k = a_m + a_{m+1} + \cdots + a_n,$$

where $k$ is called the *index of summation*, $m$ is the *lower limit*, and $n$ is the *upper limit*. The symbol $\Sigma$ (capital Greek sigma) stands for "sum." The expression $a_k$ is the *summand*, a formula in $k$ that specifies the $k$-th term. When the lower limit equals $1$, the notation collapses to the familiar $\sum_{k=1}^{n} a_k$.

**Worked Example.** Evaluate $\displaystyle S = \sum_{k=1}^{5} (2k - 1)$.

Expanding term by term with $k = 1, 2, 3, 4, 5$:

$$S = 1 + 3 + 5 + 7 + 9 = 25.$$

Observe that these are the first five odd integers. Alternatively, apply the closed-form identity for arithmetic sums: the $k$-th term is $a_k = 2k - 1$, so

$$S = 2\sum_{k=1}^{5} k \;-\; \sum_{k=1}^{5} 1 = 2 \cdot \frac{5 \cdot 6}{2} - 5 = 30 - 5 = 25.$$

Both routes confirm $S = 25$.

**Key Theorem (Linearity of Summation).** For constants $c, d \in \mathbb{R}$ and sequences $\{a_k\}$, $\{b_k\}$,

$$\sum_{k=m}^{n} (c\,a_k + d\,b_k) = c\sum_{k=m}^{n} a_k + d\sum_{k=m}^{n} b_k.$$

*Proof sketch.* Addition of real numbers is commutative and associative; regrouping the finite sum term by term yields the result immediately. $\square$

Two further identities follow directly: $\sum_{k=1}^{n} k = \dfrac{n(n+1)}{2}$ and $\sum_{k=1}^{n} k^2 = \dfrac{n(n+1)(2n+1)}{6}$, both provable by induction.

**Lab Cell.**

```python
from sympy import symbols, summation, factor

k, n = symbols('k n', positive=True, integer=True)

# Reproduce the worked example
print(summation(2*k - 1, (k, 1, 5)))          # 25

# Closed form for the first n odd integers
result = summation(2*k - 1, (k, 1, n))
print(factor(result))                           # n**2
```

Running this cell confirms $\sum_{k=1}^{n}(2k-1) = n^2$, a classical result that sigma notation makes both compact and mechanically verifiable.

### riemann_sum (0.0s)

## Riemann Sum

**Definition.** Let $f$ be a bounded function defined on a closed interval $[a, b]$. Partition $[a, b]$ into $n$ subintervals by choosing points $a = x_0 < x_1 < x_2 < \cdots < x_n = b$. The $k$-th subinterval is $[x_{k-1}, x_k]$ with width $\Delta x_k = x_k - x_{k-1}$. Choose a *sample point* $x_k^* \in [x_{k-1}, x_k]$ arbitrarily. The **Riemann sum** of $f$ over this partition is

$$S_n = \sum_{k=1}^{n} f(x_k^*)\, \Delta x_k.$$

Geometrically, each term $f(x_k^*)\,\Delta x_k$ is the signed area of a rectangle whose base spans $[x_{k-1}, x_k]$ and whose height is $f$ evaluated at the sample point. The sum approximates the net signed area between the curve and the $x$-axis.

**Worked Example.** Approximate $\int_0^2 x^2\,dx$ using a right-endpoint Riemann sum with $n = 4$ equal subintervals.

The common width is $\Delta x = \frac{2-0}{4} = 0.5$. The right endpoints are $x_k^* = 0.5k$ for $k = 1, 2, 3, 4$.

$$S_4 = \sum_{k=1}^{4} (0.5k)^2 \cdot 0.5 = 0.5\bigl(0.25 + 1.00 + 2.25 + 4.00\bigr) = 0.5 \times 7.5 = 3.75.$$

The exact value $\int_0^2 x^2\,dx = \tfrac{8}{3} \approx 2.667$, so the right-endpoint sum overshoots because $x^2$ is increasing on $[0,2]$.

**Key Theorem (Riemann Integrability).** If $f$ is continuous on $[a, b]$, then for any sequence of partitions whose mesh $\|\mathcal{P}_n\| = \max_k \Delta x_k \to 0$, and for any choice of sample points, the Riemann sums converge to a unique limit:

$$\lim_{\|\mathcal{P}_n\| \to 0} S_n = \int_a^b f(x)\,dx.$$

This limit is independent of how sample points are chosen, which justifies the definition of the definite integral itself.

**Lab Cell.**

```python
from sympy import symbols, summation, limit, oo, simplify

k, n = symbols('k n', positive=True, integer=True)
a, b = 0, 2

delta_x = (b - a) / n
x_k = a + k * delta_x          # right endpoint
f_k  = x_k**2

riemann = summation(f_k * delta_x, (k, 1, n))
integral_value = limit(riemann, n, oo)
print(simplify(integral_value))  # expects 8/3
```

### area_under_curve_limit (0.0s)

## Area Under Curve Limit

**Definition.** Let $f : [a, b] \to \mathbb{R}$ be a bounded function. Partition $[a, b]$ into $n$ subintervals of equal width $\Delta x = \frac{b - a}{n}$, and choose a sample point $x_i^*$ in the $i$-th subinterval $[x_{i-1}, x_i]$. The *Riemann sum* is

$$S_n = \sum_{i=1}^{n} f(x_i^*)\,\Delta x.$$

The **definite integral** of $f$ over $[a, b]$ is the limit of this sum as the partition is refined indefinitely:

$$\int_a^b f(x)\,dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i^*)\,\Delta x,$$

provided this limit exists and is independent of the choice of sample points. Geometrically, $\int_a^b f(x)\,dx$ equals the net signed area between the graph of $f$ and the $x$-axis on $[a, b]$.

**Worked Example.** Compute $\int_0^1 x^2\,dx$ from the limit definition using right endpoints, so $x_i^* = \frac{i}{n}$.

$$S_n = \sum_{i=1}^{n} \left(\frac{i}{n}\right)^2 \cdot \frac{1}{n} = \frac{1}{n^3} \sum_{i=1}^{n} i^2 = \frac{1}{n^3} \cdot \frac{n(n+1)(2n+1)}{6}.$$

Simplifying:

$$S_n = \frac{(n+1)(2n+1)}{6n^2} = \frac{2n^2 + 3n + 1}{6n^2}.$$

Taking the limit:

$$\int_0^1 x^2\,dx = \lim_{n \to \infty} \frac{2n^2 + 3n + 1}{6n^2} = \frac{2}{6} = \frac{1}{3}.$$

**Theorem (Integrability of Continuous Functions).** If $f$ is continuous on $[a, b]$, then $f$ is Riemann integrable on $[a, b]$; that is, the limit $\lim_{n \to \infty} S_n$ exists and is finite. Continuity guarantees that oscillations in $f$ over each subinterval become arbitrarily small as $n \to \infty$, so upper and lower Riemann sums converge to the same value.


### antiderivative (0.0s)

## Antiderivative

**Definition.** Let $f$ be a function defined on an interval $I \subseteq \mathbb{R}$. A function $F : I \to \mathbb{R}$ is called an *antiderivative* of $f$ on $I$ if $F$ is differentiable on $I$ and

$$F'(x) = f(x) \quad \text{for all } x \in I.$$

Because the derivative of any constant is zero, antiderivatives are never unique: if $F$ is one antiderivative of $f$, then $F(x) + C$ for any constant $C \in \mathbb{R}$ is also an antiderivative. The family $\{F(x) + C \mid C \in \mathbb{R}\}$ is called the *general antiderivative* (or *indefinite integral*) of $f$, written

$$\int f(x)\, dx = F(x) + C.$$

**Worked Example.** Find all antiderivatives of $f(x) = 3x^2$.

We seek $F$ such that $F'(x) = 3x^2$. Applying the reverse power rule — increasing the exponent by one and dividing by the new exponent — gives $F(x) = x^3$. Verification: $(x^3)' = 3x^2$. The general antiderivative is therefore

$$\int 3x^2\, dx = x^3 + C.$$

To fix $C$, an initial condition is required. If, for instance, $F(1) = 5$, then $1 + C = 5$, so $C = 4$ and the unique solution is $F(x) = x^3 + 4$.

**Theorem (Uniqueness up to a constant).** *If $F$ and $G$ are both antiderivatives of $f$ on an interval $I$, then $F(x) - G(x) = C$ for some constant $C$.*

*Proof sketch.* Let $H = F - G$. Then $H'(x) = F'(x) - G'(x) = f(x) - f(x) = 0$ for all $x \in I$. By the Mean Value Theorem, a function with zero derivative on an interval must be constant. Hence $H(x) = C$. $\square$

This theorem is fundamental: it guarantees that once one antiderivative is found, the complete solution set is fully characterised.

**Lab Cell (SymPy).**

```python
from sympy import symbols, integrate, diff, simplify

x = symbols('x')
f = 3*x**2
F = integrate(f, x)          # indefinite integral
print("Antiderivative:", F)  # x**3
print("Verify:", simplify(diff(F, x) - f))  # 0
```

Running this cell prints `x**3` and `0`, confirming that differentiation recovers the original function.

### definite_integral (0.0s)

## Definite Integral

**Definition.** Let $f$ be a function defined on a closed interval $[a, b]$. Partition $[a, b]$ into $n$ subintervals of equal width $\Delta x = \frac{b - a}{n}$, and choose a sample point $x_i^*$ in the $i$-th subinterval $[x_{i-1}, x_i]$. The *definite integral* of $f$ from $a$ to $b$ is

$$\int_a^b f(x)\, dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i^*)\, \Delta x,$$

provided this limit exists and is the same for every choice of sample points. When the limit exists, $f$ is said to be *Riemann integrable* on $[a, b]$. Geometrically, $\int_a^b f(x)\, dx$ measures the *signed area* between the graph of $f$ and the $x$-axis: area above the axis contributes positively, area below negatively.

**Worked Example.** Compute $\int_0^3 x^2\, dx$ using the right-endpoint Riemann sum. With $\Delta x = \frac{3}{n}$ and $x_i = \frac{3i}{n}$,

$$\sum_{i=1}^{n} \left(\frac{3i}{n}\right)^2 \cdot \frac{3}{n} = \frac{27}{n^3} \sum_{i=1}^{n} i^2 = \frac{27}{n^3} \cdot \frac{n(n+1)(2n+1)}{6}.$$

Taking $n \to \infty$, the leading term gives $\frac{27}{6} \cdot 2 = 9$, so $\int_0^3 x^2\, dx = 9$.

**Fundamental Theorem of Calculus (Part 2).** If $f$ is continuous on $[a, b]$ and $F$ is any antiderivative of $f$ (i.e., $F' = f$), then

$$\int_a^b f(x)\, dx = F(b) - F(a).$$

This theorem is the central result of single-variable calculus: it transforms the limiting process of Riemann summation into a finite algebraic evaluation. A proof sketch follows from the Mean Value Theorem applied to $F$ on each subinterval of a partition, showing that the Riemann sum telescopes exactly to $F(b) - F(a)$ in the limit.

### fundamental_theorem_calculus_part1 (0.0s)

## Fundamental Theorem of Calculus, Part 1

**Definition.** Let $f$ be a continuous function on a closed interval $[a, b]$. Define the *accumulation function* $F : [a, b] \to \mathbb{R}$ by

$$F(x) = \int_a^x f(t)\, dt.$$

The **Fundamental Theorem of Calculus, Part 1** states that $F$ is differentiable on $(a, b)$ and

$$F'(x) = f(x)$$

for every $x \in (a, b)$. In words: differentiation undoes definite integration — the rate of change of an accumulated quantity equals the current value of the integrand.

---

**Worked Example.** Let $f(t) = 3t^2$ and $a = 0$. Compute $F(x) = \int_0^x 3t^2\, dt$ directly, then verify Part 1.

*Direct evaluation:*

$$F(x) = \int_0^x 3t^2\, dt = \left[ t^3 \right]_0^x = x^3.$$

*Verification:* $F'(x) = \dfrac{d}{dx}\, x^3 = 3x^2 = f(x)$. The theorem is confirmed.

This example illustrates the geometric intuition: $F(x)$ measures the area swept under the parabola $y = 3t^2$ from $0$ to $x$, and the instantaneous rate at which that area grows as $x$ increases is precisely the height $3x^2$ of the parabola at $x$.

---

**Key Theorem (Proof Sketch).** For small $h > 0$,

$$F(x+h) - F(x) = \int_x^{x+h} f(t)\, dt.$$

By continuity of $f$, the Mean Value Theorem for integrals guarantees a point $c \in [x, x+h]$ with

$$\int_x^{x+h} f(t)\, dt = f(c)\cdot h.$$

Dividing by $h$ and taking $h \to 0$ forces $c \to x$, so

$$F'(x) = \lim_{h \to 0} \frac{F(x+h)-F(x)}{h} = \lim_{h \to 0} f(c) = f(x). \qquad \square$$

The continuity hypothesis is essential: without it, $f(c)$ need not converge to $f(x)$.

---

**Lab Cell.**

```python
from sympy import symbols, integrate, diff, cos

t, x = symbols('t x')
f   = cos(t)
F   = integrate(f, (t, 0, x))   # accumulation function
dF  = diff(F, x)                 # should equal cos(x)

print("F(x) =", F)
print("F'(x) =", dF)
print("Equals f(x)?", dF == f.subs(t, x))
```

Running this cell returns `F'(x) = cos(x)` and confirms the symbolic equality, reinforcing that the theorem holds for transcendental integrands as well as polynomials.

### fundamental_theorem_calculus_part2 (0.0s)

## Fundamental Theorem of Calculus Part 2

**Definition.** Let $f$ be a continuous function on a closed interval $[a, b]$, and let $F$ be *any* antiderivative of $f$, meaning $F'(x) = f(x)$ for all $x \in [a, b]$. The **Fundamental Theorem of Calculus, Part 2** states:

$$\int_a^b f(x)\, dx = F(b) - F(a).$$

This deceptively simple formula unifies two previously separate operations — differentiation and integration — into a single computational procedure. Rather than computing a definite integral as a limit of Riemann sums, we need only find one antiderivative and evaluate it at the endpoints. We write $F(b) - F(a)$ compactly as $\bigl[F(x)\bigr]_a^b$.

**Proof sketch.** Define the accumulation function $G(x) = \int_a^x f(t)\, dt$. By Part 1 of the Fundamental Theorem, $G'(x) = f(x)$, so $G$ is also an antiderivative of $f$. Any two antiderivatives of the same continuous function differ by a constant, so $F(x) = G(x) + C$ for some $C \in \mathbb{R}$. Evaluating at the endpoints:

$$F(b) - F(a) = \bigl[G(b) + C\bigr] - \bigl[G(a) + C\bigr] = G(b) - G(a) = \int_a^b f(t)\, dt. \qquad \square$$

**Worked example.** Compute $\displaystyle\int_1^3 (2x + x^2)\, dx$.

An antiderivative is $F(x) = x^2 + \dfrac{x^3}{3}$. Applying the theorem:

$$\int_1^3 (2x + x^2)\, dx = \left[x^2 + \frac{x^3}{3}\right]_1^3 = \left(9 + 9\right) - \left(1 + \frac{1}{3}\right) = 18 - \frac{4}{3} = \frac{50}{3}.$$

**Key theorem.** The result holds under the sole hypothesis that $f$ is continuous on $[a, b]$; no additional smoothness is required. Moreover, the choice of antiderivative is immaterial: any valid $F$ yields the same numerical answer, because the arbitrary constant cancels at subtraction.

**Lab cell.**

```python

f = 2*x + x**2
result = integrate(f, (x, 1, 3))
print(result)          # Expected: 50/3
```

Running this cell confirms the analytic computation and illustrates how symbolic integration automates antiderivative lookup and endpoint evaluation in a single call.

### net_change_theorem (0.0s)

## Net Change Theorem

**Definition.** Let $f$ be a continuous function on the closed interval $[a, b]$, and let $F$ be any antiderivative of $f$, so that $F'(x) = f(x)$ for all $x \in [a, b]$. The *Net Change Theorem* states that the definite integral of a rate of change equals the net change in the quantity:

$$\int_a^b F'(x)\, dx = F(b) - F(a).$$

This is precisely the conclusion of the Fundamental Theorem of Calculus, Part 2, recast in terms of physical meaning. The integrand $f(x) = F'(x)$ represents the instantaneous rate at which $F$ changes; integrating it over $[a, b]$ accumulates all infinitesimal increments, yielding the total displacement—not the total distance—of $F$ from $a$ to $b$. Positive and negative contributions cancel, which is why the result is called *net* change.

**Worked Example.** A particle moves along a straight line with velocity $v(t) = t^2 - 4t + 3$ metres per second for $t \in [0, 4]$. Find the net displacement over this interval.

The position function satisfies $s'(t) = v(t)$, so by the Net Change Theorem:

$$\Delta s = \int_0^4 (t^2 - 4t + 3)\, dt = \left[\frac{t^3}{3} - 2t^2 + 3t\right]_0^4.$$

Evaluating: $\frac{64}{3} - 32 + 12 - 0 = \frac{64}{3} - 20 = \frac{4}{3}$ metres. The particle's net displacement is $\tfrac{4}{3}$ m, even though it reverses direction within $[0,4]$ (since $v(t) = 0$ at $t = 1$ and $t = 3$).

**Key Theorem.** If $f$ is continuous on $[a, b]$, then

$$\int_a^b f(x)\, dx = F(b) - F(a)$$

for any antiderivative $F$ of $f$. Moreover, the *total distance* travelled (as opposed to net displacement) is $\displaystyle\int_a^b |f(x)|\, dx$, which requires splitting the integral at each zero of $f$.

**Lab Cell (SymPy).**
```python
from sympy import *
t = symbols('t')
v = t**2 - 4*t + 3
net_displacement = integrate(v, (t, 0, 4))
total_distance    = integrate(Abs(v), (t, 0, 4))
print("Net displacement:", net_displacement)   # 4/3
print("Total distance:  ", total_distance)     # 10/3
```

### displacement_from_velocity (0.0s)

## Displacement From Velocity

**Definition.** Let a particle move along a straight line, and let $v(t)$ denote its velocity at time $t$, measured in metres per second. The *displacement* of the particle over the time interval $[a, b]$ is the net signed change in position:

$$\Delta x = \int_a^b v(t)\, dt.$$

Displacement differs fundamentally from *total distance travelled*. Displacement is a signed quantity — intervals where $v(t) < 0$ represent motion in the negative direction and subtract from the integral. Total distance, by contrast, is $\int_a^b |v(t)|\, dt$, which is always non-negative.

**Worked Example.** A particle's velocity is given by $v(t) = 3t^2 - 6t$ metres per second for $t \in [0, 3]$. Find (i) the displacement and (ii) the total distance travelled.

*Displacement:*
$$\Delta x = \int_0^3 (3t^2 - 6t)\, dt = \left[t^3 - 3t^2\right]_0^3 = (27 - 27) - 0 = 0 \text{ m}.$$

*Total distance:* First locate sign changes. Setting $v(t) = 3t(t-2) = 0$ gives $t = 0$ and $t = 2$. On $(0,2)$, $v < 0$; on $(2,3)$, $v > 0$. Therefore:
$$d = \int_0^2 |v(t)|\, dt + \int_2^3 v(t)\, dt = \left[-t^3 + 3t^2\right]_0^2 + \left[t^3 - 3t^2\right]_2^3 = 4 + 4 = 8 \text{ m}.$$

The particle returns exactly to its starting point (zero displacement) but has physically moved 8 m.

**Key Theorem (Fundamental Theorem of Calculus, Part 1).** If $v = x'(t)$ is continuous on $[a,b]$, then

$$\int_a^b v(t)\, dt = x(b) - x(a).$$

This theorem is the formal bridge between the antiderivative and definite integration: computing $\Delta x$ requires only evaluating an antiderivative of $v$ at the endpoints, not summing infinitely many infinitesimal steps explicitly.

**Lab Cell.**
```python

print("Total distance :", total_distance) # 8
```

Running this cell confirms both results symbolically, illustrating how SymPy's `Abs` integrand correctly accounts for directional sign changes without manual interval splitting.

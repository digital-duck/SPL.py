## Parent Structure

**Definition.** In Sage, every mathematical object $x$ carries a distinguished attribute $x.parent()$, an object $P$ called its *parent*, which is itself an instance of a subclass of the `Parent` class in the category-theoretic hierarchy `sage.structure.parent`. The parent encodes the algebraic structure — the set together with its operations — to which $x$ is asserted to belong: $\mathbb{Z}$ (`ZZ`), $\mathbb{Q}$ (`QQ`), the finite field $\mathbb{F}_7$ (`GF(7)`), the symbolic ring `SR`, a polynomial ring $R[x]$, a matrix space $\mathrm{Mat}_{m\times n}(R)$, and so on. Formally, Sage's coercion model realizes a fragment of category theory: each parent $P$ is associated to a category $\mathcal{C}$ (rings, fields, groups, modules, …), and arithmetic between elements of parents $P$ and $Q$ is only well-defined once a *coercion morphism* $P \to R$ or $Q \to R$ into some common parent $R$ has been established, via `sage.structure.coerce`.

**Theorem (uniqueness and canonicity of parents).** Sage's parent structure satisfies a *unique parent axiom*: for any given mathematical structure with fixed defining data, the parent object is a singleton up to `==` and often `is` (via a global cache, `UniqueRepresentation`). That is, `GF(7) is GF(7)` returns `True`, and two elements $a, b$ with $a.parent() \equiv b.parent()$ (structurally identical constructor arguments) are guaranteed interoperable without ambiguity. *Proof sketch:* `UniqueRepresentation` overrides `__classcall__` to hash the constructor arguments and consult a weak-value cache; if a parent with identical arguments already exists, the cached instance is returned instead of instantiating anew. This guarantees that parent identity (`is`), and not merely equality (`==`), can be used as a fast structural test — an essential invariant for the coercion model's performance, since exact structural comparison would otherwise require re-deriving canonical forms at each operation. $\blacksquare$

**Literature context.** The design descends from Magma's type/parent system and from Axiom/Aldor's categorical hierarchy, and is documented formally in the Sage coercion model reference and in Bosma–Cannon's original design papers for computer algebra category hierarches. What remains open, and is an active area of Sage development, is the completeness and soundness of the coercion *graph*: with an increasing number of parents (p-adics, number fields, quotient rings, tensor products), the discovery of coercion paths becomes a nontrivial search problem, and cases of ambiguous or missing coercions (e.g., between two number fields with no canonical embedding) surface regularly as reported issues.

**Suggested investigation.** Construct three parents — $\mathbb{Z}[x]$, $\mathbb{Q}[x]$, and $\mathbb{F}_5[x]$ — and systematically test which pairs support automatic coercion of a nonzero-degree element via `x.parent().has_coerce_map_from(y.parent())`. Extend to $\mathbb{Q}(\sqrt{2})$ and $\mathbb{Q}(\sqrt{3})$ and observe the failure mode when no canonical map exists. Trace the actual coercion path found (if any) using `sage.structure.coerce.py`'s `_richcmp_` and `get_action` internals with verbose coercion tracing enabled (`Parent._coerce_map_from_` debugging hooks).

**Report-writing note.** A write-up should state precisely which coercion tests succeeded and failed, give the categorical justification (ring homomorphism existence) for each success, and for each failure explain why no canonical morphism exists (as opposed to one merely not being implemented) — distinguishing mathematical obstruction from implementation gap.

## Symbolic Variable

**Definition.** A symbolic variable is an element $x$ of a free commutative algebra (typically $\mathbb{Q}[x]$, $\mathbb{R}[x]$, or a polynomial ring in several indeterminates over a base ring $R$) that is *uninterpreted*: no evaluation map $\phi: R[x] \to R$ is fixed a priori. Formally, `var('x')` in a computer algebra system (CAS) such as SageMath or a symbolic-manipulation library instantiates a generator of a free $R$-algebra, distinguished from a *numeric* variable — a name bound to a single element of $R$ — precisely by the absence of this binding. The symbol $x$ is not "a number we don't know yet" in the probabilistic sense; it is a formal placeholder satisfying only the axioms of the ring it generates (commutativity, distributivity, etc.), nothing more.

**Theorem (Universal property of the polynomial ring).** Let $R$ be a commutative ring. The polynomial ring $R[x]$, together with the inclusion $\iota: R \hookrightarrow R[x]$ and the distinguished element $x \in R[x]$, satisfies: for every commutative $R$-algebra $A$ and every element $a \in A$, there exists a unique $R$-algebra homomorphism $\varepsilon_a: R[x] \to A$ with $\varepsilon_a(x) = a$.

*Proof.* Existence: define $\varepsilon_a\left(\sum_{i=0}^n c_i x^i\right) = \sum_{i=0}^n c_i a^i$; this is well-defined since every element of $R[x]$ has a unique representation as a finite sum of monomials with coefficients in $R$, and one checks directly that $\varepsilon_a$ respects addition and multiplication because $A$ is commutative. Uniqueness: any $R$-algebra homomorphism $\psi$ with $\psi(x) = a$ must satisfy $\psi(c_i x^i) = c_i \psi(x)^i = c_i a^i$ by $R$-linearity and multiplicativity, forcing $\psi = \varepsilon_a$ on every monomial, hence on all of $R[x]$ by additivity. $\blacksquare$

This is precisely why `var('x')` grants access to "every number at once": $x$ is the *generic point* of $\mathbb{A}^1_R$, and any specific number $a$ is recovered by the evaluation homomorphism $\varepsilon_a$ — substitution. Algebra with $x$ (simplification, factoring, differentiation as a formal $R$-derivation) is computation performed once, in $R[x]$, that commutes with every subsequent specialization $\varepsilon_a$; this is the sense in which "algebra precedes arithmetic."

**Literature context.** The universal property above is standard commutative algebra (Atiyah–Macdonald, Lang); its computational incarnation is the subject of computer algebra (von zur Gathen & Gerhard). What remains genuinely active research is efficient *representation* of symbolic expressions (DAG sharing, canonical forms modulo associativity/commutativity — the word problem for expression equivalence is undecidable in general once transcendental functions are admitted, per Richardson's theorem) and the interplay between symbolic and numeric computation (interval arithmetic, hybrid symbolic-numeric algorithms).

**Suggested investigation.** Implement $\varepsilon_a$ explicitly in a CAS (Sage or SymPy) for a nontrivial $A$ (e.g. $A = M_n(R)$, matrices) and verify the homomorphism property computationally on random polynomials and matrices; then explore where naive symbolic simplification fails to detect $A$-specific identities (e.g. Cayley–Hamilton) that a numeric substitution would trivially satisfy for tested values but that require the ring structure of $A$ to prove in general.

**Report-writing note.** A write-up should state the universal property precisely, give the proof, then present the computational experiment with explicit code and output, and discuss at least one case where symbolic and numeric approaches to the same identity diverge in what they can certify (numeric: verified at sampled points; symbolic: proved for all $a \in A$).

### symbolic_expression (0.0s)

## Symbolic Expression

**Definition.** In Sage, the Symbolic Ring $SR$ is a commutative ring whose elements are formal expression trees built from symbolic variables (see [[symbolic_variable]]), numeric literals, and function/operator nodes (arithmetic operators, elementary and special functions), closed under composition. Formally, $SR$ is the free structure generated by an alphabet of symbols $x_1, x_2, \ldots$ under the signature $\Sigma = \{+, \cdot, -, /, {}^{\wedge}, \sin, \exp, \log, \Gamma, \ldots\}$, modulo no relations beyond the syntactic ones imposed by the parser — i.e., $SR$ is (up to normalization by Maxima/Pynac's simplification routines) the term algebra $T_\Sigma(X)$ over variable set $X$. An element $e \in SR$ carries its construction history exactly: $e = f(g(x), h(y))$ is stored as a directed acyclic graph (a *parent structure*, see [[parent_structure]]) with $f, g, h \in \Sigma$ and leaves $x, y \in X$, not as a floating-point approximation of its value.

**Theorem (structural uniqueness up to evaluation order).** Two symbolic expressions $e_1, e_2 \in SR$ are syntactically distinct in general even when they are semantically equal as functions of their free variables (e.g., $\sin^2(x) + \cos^2(x)$ and $1$), because $SR$ performs no automatic theorem-proving simplification — only canonicalization at the level of associativity/commutativity normal forms maintained by the underlying CAS kernel (Pynac, itself a C++ reimplementation of GiNaC's expression-tree engine). Consequently equality testing in $SR$ splits into two distinct operations: `bool(e1 == e2)`, which invokes symbolic simplification and possibly numerical sampling as a heuristic, and `(e1 - e2).is_zero()` or `.simplify_full()`, which attempts exact reduction. Neither is a decision procedure in general, since the equivalence problem for expressions involving $\exp$, $\log$, and algebraic operations is undecidable (Richardson's theorem, 1968) even for finite closed forms.

**Literature context.** Richardson's undecidability result is the standard reference bounding what any symbolic engine — Sage, Mathematica, Maple — can guarantee about expression equivalence; it explains why $SR$ deliberately exposes the raw expression tree rather than pretending to a canonical form. The design of Pynac/GiNaC follows the term-rewriting and computer-algebra tradition surveyed in von zur Gathen–Gerhard's *Modern Computer Algebra*; open questions remain in simplification heuristics (which rewrite rules to apply, in what order, to approach — never guarantee — a "simplest" form) and in efficient common-subexpression sharing across large expression DAGs, an active concern in symbolic differentiation and automatic differentiation research.

**Suggested investigation.** Construct a family of expressions known to be equal (e.g., trigonometric identities, telescoping sums, or instances of Ramanujan-type series) and empirically test: (1) does `bool(e1==e2)` succeed, (2) does `.simplify_full()` succeed, (3) how does runtime scale with expression-tree depth? Compare Sage's success rate against a direct call to Maxima and to a CAS using a different simplification strategy (e.g., Mathematica's `FullSimplify`).

**Report-writing note.** The write-up should report the DAG size (node count) of each test expression, distinguish failures due to timeout from failures due to genuine simplification incompleteness, and state explicitly which equivalences were verified exactly versus only numerically (interval sampling), since this distinction is the crux of what "symbolic" guarantees mean in practice.

### exact_integer (0.0s)

## Exact Integer

**Definition.** Let $\mathbb{Z}$ denote the ring of rational integers. A computational representation of $\mathbb{Z}$ is *exact* if it realizes every element of $\mathbb{Z}$ as a finite bit-string $b(n)$ such that the map $n \mapsto b(n)$ is injective and the ring operations $+, -, \times$ are computed via algorithms that return $b(n_1 \circ n_2)$ exactly, with no truncation, rounding, or modular wraparound, for any $n_1, n_2 \in \mathbb{Z}$ and any bit-length. Sage's `Integer` type (built on GMP/MPIR's `mpz_t`) is such a representation: an integer is stored as a sign bit plus a variable-length array of machine words (limbs) in base $2^{64}$ (or $2^{32}$), so $2^{100}$ is stored as roughly two limbs encoding one exact value, not as a floating-point approximation with a 53-bit mantissa. This stands in contrast to IEEE 754 doubles, or to fixed-width machine integers (`int32`, `int64`), whose representations are quotients of $\mathbb{Z}$ by $2^k\mathbb{Z}$ or by the floating-point rounding relation, and are therefore *not* injective on all of $\mathbb{Z}$.

**Theorem (correctness of arbitrary-precision arithmetic).** Let $a, b$ be integers represented in base-$B$ positional form with $\ell(a), \ell(b)$ limbs respectively. Schoolbook addition/subtraction runs in $O(\max(\ell(a),\ell(b)))$ word operations and produces the exact sum with no information loss, by the standard carry-propagation argument (each digit sum is bounded by $2B-1 < B^2$, representable in one extra limb of carry). Schoolbook multiplication runs in $O(\ell(a)\ell(b))$; GMP additionally implements Karatsuba ($O(n^{\log_2 3})$) and, for very large operands, Schönhage–Strassen/FFT-based multiplication ($O(n \log n \log\log n)$), each provably exact because they operate entirely over $\mathbb{Z}$ (or $\mathbb{Z}/(2^n+1)\mathbb{Z}$ with exact reconstruction) rather than over a rounded field.

*Proof sketch.* Addition/subtraction correctness follows by induction on limb position using the invariant that the running carry is bounded by the base. Karatsuba correctness follows from the algebraic identity $(a_1 B + a_0)(b_1 B + b_0) = a_1 b_1 B^2 + \big((a_1+a_0)(b_1+b_0) - a_1b_1 - a_0b_0\big)B + a_0 b_0$, which requires only three sub-multiplications instead of four, verified by direct expansion. FFT-based multiplication correctness rests on choosing a modulus large enough (via the Crandall–Fagin / Schönhage–Strassen construction) that no wraparound occurs before the final exact reconstruction, i.e. all convolution coefficients stay below the chosen modulus. $\blacksquare$

**Literature context.** The complexity landscape for exact integer multiplication has an active frontier: Schönhage–Strassen ($O(n\log n\log\log n)$, 1971) stood as the best known bound for decades until Harvey and van der Hoeven (2019, 2021) proved an $O(n\log n)$ algorithm, matching the conjectured lower bound from Fürer's work — but this algorithm is currently impractical for GMP's operand ranges (it wins only for astronomically large $n$), so GMP still switches among schoolbook, Karatsuba, Toom–Cook, and FFT methods by threshold. Open questions remain about practical crossover points, memory-bandwidth-optimal implementations, and whether Harvey–van der Hoeven-style methods can be made competitive at cryptographic or scientific-computing scales.

**Suggested investigation.** Using Sage, empirically measure the crossover points between GMP's multiplication algorithms: time `a*b` for random integers of increasing bit-length (e.g. $2^{10}$ to $2^{22}$ bits, log-spaced), and fit the timing curve to identify where the exponent of growth shifts from $\approx 2$ (schoolbook) to $\approx 1.585$ (Karatsuba) to $\approx 1$ (FFT regime). Compare against `int` overflow behavior in a fixed-width language to make the "floor of exactness" concrete.

**Report-writing note.** The write-up should state the measured crossover bit-lengths, the fitted growth exponents with error bars, and an explicit demonstration (via hash or digit-by-digit check) that Sage's product matches a symbolic/exact reference computation at every tested size — establishing exactness is preserved, not merely that timing scales as expected.

### simplification (0.0s)

## Simplification

**Definition.** Let $E$ be the set of symbolic expression trees over a field $\mathbb{K}$ (typically $\mathbb{Q}$ or $\mathbb{Q}(x_1,\dots,x_n)$) built from constants, symbols, and operators $\{+,-,\times,\div,{}^{\wedge}, \sin,\cos,\exp,\log,\dots\}$. A *simplification strategy* is a rewriting relation $\to_S \subseteq E \times E$ generated by a finite (or schema-indexed) set of identities $S$, each of the form $L(\vec x) \equiv R(\vec x)$ valid on a specified domain. `simplify_full(e)` computes a representative of the equivalence class $[e]_{\to_S^*}$ under the reflexive-transitive closure of $\to_S$, subject to a termination order (e.g., a reduction ordering on tree size or a Knuth–Bendix weight) that guarantees $\to_S$ terminates and, ideally, confluence, so the result is canonical. Separately, `is_zero(e)` decides membership of $e$ in the ideal-theoretic or transcendental sense: whether $e \equiv 0$ as a *function* (not merely as a syntax tree) on its domain — the semantic question underlying the *equation object* built by `expr == 0`, which is a **proposition**, not yet a **truth value**.

**Theorem (undecidability of the zero-equivalence problem).** For the class of elementary expressions built from $+,\times,\exp,\sin$ over $\mathbb{Q}$, the predicate "$e \equiv 0$" is undecidable in general (Richardson's theorem, 1968), even though it is decidable for purely algebraic (polynomial/rational) subexpressions via Gröbner basis membership testing, and for expressions involving only $\exp$ and polynomials via Ritt–Risch-style differential algebra when no integer-relation ambiguity (e.g. $e^{i\pi}+1$) is present.

*Proof sketch.* Richardson embeds an instance of the halting problem (or, more directly, undecidability of integer-linear-combination vanishing, $\sum n_i \log p_i = 0$) into deciding whether a specific closed-form expression involving $\sin$, $\exp$, absolute value, and integers is identically zero on $\mathbb{R}$. Reduction preserves computability class, so no algorithm can decide zero-equivalence for the full elementary class. $\blacksquare$

**Literature context.** `simplify_full()` is therefore necessarily a *heuristic normalizer*, not a decision procedure — it applies confluent, terminating rewrite systems where available (polynomial normal form via distributive/collect laws, trigonometric reduction via Chebyshev/product-to-sum identities, log/exp collapsing under branch-cut side conditions) and falls back to syntactic canonicalization elsewhere. `is_zero()` typically layers several decidable subroutines — CAS Gröbner-basis ideal membership (Buchberger 1965), Risch-style differential-field zero tests (Risch 1969), and numerical/interval sampling as a fast heuristic pre-filter (never a proof) — before returning "unknown." Open problems include: tight decidable fragments beyond purely algebraic/exp-log towers (e.g. mixed trigonometric-exponential with algebraic relations), and confluence certificates for domain-restricted trig rewriting under branch assumptions.

**Suggested investigation.** Implement a minimal rewrite system for trigonometric identities (double-angle, product-to-sum) as a term-rewriting system; prove termination via a weight function and test confluence on critical pairs (Knuth–Bendix completion). Separately, construct expressions where `is_zero()` returns `unknown` (e.g. $e^{i\pi} + \cos(0)$-style constructions with hidden algebraic relations among logarithms of primes) and characterize which decidable subroutine, if any, resolves them.

**Report-writing note.** The write-up should state precisely which subclass of expressions the implemented rewrite system decides confluently, give the termination order and a confluence proof (or counterexample), and report empirically how often `is_zero()` returns `unknown` versus a definite answer on a benchmark corpus, distinguishing numerical near-zero false positives from true undecidable instances.

**References**
- [D. Richardson, "Some Undecidable Problems Involving Elementary Functions of a Real Variable" (1968)](https://www.jstor.org/stable/2271358)
- [B. Buchberger, "Bruno Buchberger's PhD thesis 1965: An Algorithm for Finding the Basis Elements of the Residue Class Ring of a Zero Dimensional Polynomial Ideal" (English translation, 2006)](https://doi.org/10.1016/j.jsc.2005.09.007)

### polynomial_rings (0.0s)

## Polynomial Rings

**Definition.** Let $R$ be a commutative ring with identity. The polynomial ring $R[x]$ is the set of formal sums $f(x) = \sum_{i=0}^n a_i x^i$, $a_i \in R$, under coefficientwise addition and Cauchy-product multiplication:
$$
\left(\sum_i a_i x^i\right)\left(\sum_j b_j x^j\right) = \sum_k \left(\sum_{i+j=k} a_i b_j\right) x^k.
$$
When $R = F$ is a field, $F[x]$ is a Euclidean domain under the degree function $\deg$, hence a PID and a UFD. A computer algebra system's `PolynomialRing(QQ, 'x')` is not merely notation: it is the declaration of this algebraic structure, and every downstream operation (`factor`, `gcd`, `roots`) is a theorem-backed procedure valid *because* the ambient ring and its arithmetic properties are fixed in advance.

**Theorem (Division Algorithm in $F[x]$).** For $f, g \in F[x]$ with $g \neq 0$, there exist unique $q, r \in F[x]$ with $f = qg + r$ and $r = 0$ or $\deg r < \deg g$.

*Proof.* Existence: induct on $\deg f$. If $\deg f < \deg g$, take $q=0$, $r=f$. Otherwise let $a, b$ be leading coefficients of $f, g$ and $m = \deg f - \deg g \geq 0$; set $f_1 = f - (a/b)x^m g$, which has strictly smaller degree than $f$, and apply the inductive hypothesis to $f_1$. Uniqueness: if $qg+r = q'g+r'$ then $(q-q')g = r'-r$; if $q \neq q'$ the left side has degree $\geq \deg g$ while the right side has degree $< \deg g$, a contradiction. $\blacksquare$

This division algorithm is the engine behind the Euclidean algorithm for $\gcd(f,g)$ in $F[x]$, and Gauss's lemma extends factorization control to $\mathbb{Z}[x]$ by relating irreducibility over $\mathbb{Z}$ to irreducibility over $\mathbb{Q}$.

**Literature context.** Factorization algorithms for $\mathbb{Q}[x]$ trace to Kronecker's method (exponential, of historical interest only) through Zassenhaus's $p$-adic lifting and the LLL-based Lenstra–Lenstra–Lovász algorithm (1982), which gave the first polynomial-time factorization of $\mathbb{Z}[x]$ polynomials via lattice reduction on Berlekamp's mod-$p$ factorization lifted through Hensel's lemma. Open directions include: sharper bit-complexity bounds for multivariate factorization, factorization over function fields and finite fields of small characteristic where Berlekamp's original algorithm still dominates practice, and the interplay between symbolic factorization and numerical polynomial root-finding (the "hybrid symbolic-numeric" literature, e.g. Kaltofen's work on approximate GCDs).

**Suggested investigation.** Implement (by hand or in Sage) Berlekamp's algorithm for factoring a polynomial over $\mathbb{F}_p$, then Hensel-lift a factorization from $\mathbb{F}_p[x]$ to $\mathbb{Z}/p^k\mathbb{Z}[x]$, and finally recombine factors to recover a factorization over $\mathbb{Z}[x]$. Compare running time and correctness against `factor()` for polynomials of degree 10–50 with controlled coefficient size.

**Report-writing note.** A write-up should state the ring precisely at each stage ($\mathbb{F}_p[x]$, $\mathbb{Z}/p^k[x]$, $\mathbb{Z}[x]$), prove why lifting preserves the factorization up to units, and report empirically observed versus theoretical complexity as degree and coefficient bit-length grow.

**References**
- [Lenstra, Lenstra, Lovász, "Factoring Polynomials with Rational Coefficients" (1982)](https://link.springer.com/article/10.1007/BF01457454)

### substitution_evaluation (19.3s)

## Substitution Evaluation

**Definition.** Let $E$ be a symbolic expression over a set of free variables $X = \{x_1, \dots, x_n\}$, formally an element of a term algebra $T(\Sigma, X)$ built from an operator signature $\Sigma$. *Substitution* is a map $\sigma: X \to T(\Sigma, X)$, extended homomorphically to $E\sigma$ by structural recursion on $E$'s syntax tree. *Numerical evaluation* $n(E)$ is the further map $T(\Sigma, \emptyset) \to \mathbb{R}$ (or $\mathbb{C}$, or a floating-point/interval type) obtained once every leaf of the tree is a numeral, defined by interpreting each operator symbol in $\Sigma$ as a concrete function on that codomain. The composition $\text{eval}_\sigma(E) = n(E\sigma)$ is what a user usually wants, but the API design in `subs()`/`n()` deliberately factors it into two independent stages.

**Theorem (well-definedness and commutativity of substitution).** If $\sigma_1, \sigma_2$ have disjoint domains, then $(E\sigma_1)\sigma_2 = (E\sigma_2)\sigma_1 = E(\sigma_1 \cup \sigma_2)$, and for any $E$ with $\text{FV}(E) \subseteq \text{dom}(\sigma)$, $E\sigma$ contains no free occurrence of any $x \in \text{dom}(\sigma)$.

*Proof.* By structural induction on $E$. Base case: $E = x_i$, a leaf; $E\sigma_1\sigma_2 = \sigma_1(x_i)\sigma_2$, which equals $\sigma_2(\sigma_1(x_i))$ trivially if $x_i \notin \text{dom}(\sigma_2)$; if instead $E = x_i \notin \text{dom}(\sigma_1)$, symmetric argument applies. Inductive step: for $E = f(E_1,\dots,E_k)$, substitution distributes over the operator, $E\sigma = f(E_1\sigma,\dots,E_k\sigma)$, so the claim reduces to the induction hypothesis on each $E_i$. The second claim follows since substitution replaces every occurrence of $x_i \in \text{dom}(\sigma)$ syntactically, leaving none behind (no variable capture occurs in a first-order term algebra without binders). $\blacksquare$

This is essentially the confluence property underlying $\beta$-reduction in the $\lambda$-calculus restricted to a binder-free term algebra, and it is what guarantees that the order of independent substitutions in a computer algebra system (Sage, SymPy, Mathematica) never affects the result.

**Literature context.** The separation of symbolic substitution from numeric evaluation mirrors the classical distinction in term rewriting systems (Baader & Nipkow) between *rewriting* (syntactic, confluent up to the rules) and *interpretation* (semantic, in a fixed algebra). What remains genuinely open is efficiency: naive substitution on a DAG-shared expression can cause exponential blow-up if sharing is not preserved (the "expression swell" problem well known in Gröbner basis and CAS implementations), and current systems differ substantially in how they cache or memoize $E\sigma$ for repeated $\sigma$.

**Suggested investigation.** Implement `subs()` on a DAG (not a tree) representation with hash-consing, and measure expression size growth versus a naive tree-copy implementation across a family of expressions with deep sharing (e.g., iterated squaring $E_{k+1} = E_k^2 + E_k$). Then benchmark $n(\cdot)$ under exact rational arithmetic versus floating point, tracking catastrophic cancellation.

**Report-writing note.** The write-up should state the sharing representation precisely, give asymptotic bounds (naive vs. hash-consed) with a proof sketch, and report empirical blow-up factors with the specific expression family and node counts used.

- [Baader, F. & Nipkow, T., *Term Rewriting and All That* (1998)](https://www.cambridge.org/core/books/term-rewriting-and-all-that/71768055278D0DEF4FFC58A2E4256088)

## Exact Rational

**Definition.** The type $\mathbb{Q}_{\text{exact}}$ represents a rational number as a pair $(n, d) \in \mathbb{Z} \times \mathbb{Z}_{>0}$ with $\gcd(n,d) = 1$, interpreted as the value $n/d \in \mathbb{Q}$. Arithmetic operations are defined by the field structure of $\mathbb{Q}$ and a normalization map $\rho: \mathbb{Z} \times (\mathbb{Z}\setminus\{0\}) \to \mathbb{Q}_{\text{exact}}$,
$$
\rho(a,b) = \left(\frac{a/g}{\,\text{sgn}(b)\,},\ \frac{|b|/g}{1}\right), \qquad g = \gcd(a,b).
$$
Decimal or floating-point representations are not part of the type; they arise only under an explicit coercion $\delta_k: \mathbb{Q}_{\text{exact}} \to \mathbb{R}$ truncated to $k$ digits, applied on output, never internally.

**Theorem (closure under the four operations).** Let $x = n_1/d_1$, $y = n_2/d_2$ be in lowest terms. Then
$$
x+y = \rho(n_1 d_2 + n_2 d_1,\ d_1 d_2), \quad x \cdot y = \rho(n_1 n_2,\ d_1 d_2), \quad x/y = \rho(n_1 d_2,\ n_2 d_1)\ (y\neq 0),
$$
and each result, after normalization by $\rho$, is again an element of $\mathbb{Q}_{\text{exact}}$ with a *unique* representative pair. Uniqueness follows immediately from $\gcd(n,d)=1$ combined with a fixed sign convention on $d>0$: any two coprime pairs representing the same rational differ by a unit $(-1,-1)$, which the sign convention eliminates.

*Proof sketch.* Closure is the standard verification that $\mathbb{Q}$ is a field under the usual fraction arithmetic; the substance here is that $\rho$ is total and computable via Euclid's algorithm, so no operation can silently leave lowest-terms form or introduce rounding. Uniqueness of the coprime representative is the fundamental theorem of arithmetic applied to $n/g, d/g$. $\blacksquare$

**Literature context.** This construction is the algebraic-datatype analogue of the classical field of fractions of $\mathbb{Z}$ (Hungerford, *Algebra*, Ch. III); its computational realization is the subject of exact/symbolic arithmetic systems (GMP's `mpq`, Python's `fractions.Fraction`, Lisp's rational tower). The open engineering question is not existence but *complexity*: repeated addition without intermediate GCD reduction causes numerator/denominator bit-length to grow, in the worst case, linearly per operation, giving quadratic-or-worse blowup over $k$ operations — a phenomenon studied under "coefficient growth" in computer algebra (von zur Gathen & Gerhard, *Modern Computer Algebra*). Whether a given implementation reduces eagerly (every operation) or lazily (only before comparison/output) is a genuine design tradeoff, not a settled matter.

**Suggested investigation.** Implement $\mathbb{Q}_{\text{exact}}$ two ways — eager reduction vs. lazy reduction — and empirically measure numerator bit-length growth over a random walk of $10^4$ additions/multiplications on rationals with small initial denominators (e.g. summing $1/1, 1/2, \dots$ as in the harmonic series). Compare wall-clock time against `Fraction` in an existing library.

**Report-writing note.** A write-up should state the normalization invariant precisely, prove it is preserved by each operation, and present the growth-rate measurement with a fitted asymptotic (linear vs. superlinear) alongside the theoretical worst-case bound, explicitly flagging any gap between the two.

### number_theory_sage (0.0s)

## Number Theory Sage

**Definition.** Let $n \in \mathbb{Z}_{>0}$. The core operations of computational number theory addressed here are: integer factorization $n = \prod_i p_i^{e_i}$, primality testing, Euler's totient $\varphi(n) = \#\{k \in [1,n] : \gcd(k,n)=1\}$, and the Chinese Remainder Theorem (CRT), which asserts that for pairwise coprime moduli $m_1,\dots,m_r$,
$$\mathbb{Z}/M\mathbb{Z} \;\cong\; \prod_{i=1}^r \mathbb{Z}/m_i\mathbb{Z}, \qquad M = \prod_i m_i,$$
via the map $x \mapsto (x \bmod m_1, \dots, x \bmod m_r)$. Sage's `factor()`, `is_prime()`, `euler_phi()`, and `CRT()` expose PARI/GP's compiled number-theoretic library (with fallbacks to GMP and FLINT) at the interactive prompt, so operations that are asymptotically hard remain tractable up to cryptographically relevant sizes.

**Theorem (CRT, constructive form).** Given the system $x \equiv a_i \pmod{m_i}$, $i=1,\dots,r$, with $m_i$ pairwise coprime, a solution is
$$x \equiv \sum_{i=1}^r a_i \, M_i \, y_i \pmod{M}, \qquad M_i = M/m_i, \quad y_i \equiv M_i^{-1} \pmod{m_i},$$
and this $x$ is unique mod $M$.
*Proof.* Existence: each term $a_i M_i y_i \equiv a_i \pmod{m_i}$ since $M_i y_i \equiv 1$, while $a_j M_j y_j \equiv 0 \pmod{m_i}$ for $j \neq i$ because $m_i \mid M_j$. Summing recovers $x \equiv a_i \pmod{m_i}$ for every $i$. Uniqueness follows since if $x, x'$ both satisfy the system, $m_i \mid (x-x')$ for all $i$, and pairwise coprimality gives $M \mid (x - x')$ by induction on the lcm of coprime integers. $\blacksquare$

The totient satisfies $\varphi(n) = n \prod_{p \mid n} (1 - 1/p)$, multiplicativity following directly from the CRT isomorphism above: $\varphi(m_1 m_2) = \varphi(m_1)\varphi(m_2)$ for coprime $m_1, m_2$, since $(\mathbb{Z}/m_1m_2\mathbb{Z})^\times \cong (\mathbb{Z}/m_1\mathbb{Z})^\times \times (\mathbb{Z}/m_2\mathbb{Z})^\times$.

**Literature context.** Primality testing is polynomial-time unconditionally since AKS (Agrawal–Kayal–Saxena, 2004), but practical systems including PARI use probabilistic Miller–Rabin plus BPSW, believed but not proven to have no counterexamples. Integer factorization has no known polynomial-time classical algorithm; the best general-purpose method, the number field sieve, runs in sub-exponential time $L_n[1/3, (64/9)^{1/3}]$, and this asymmetry between factoring's hardness and primality testing's tractability is the basis of RSA. Shor's algorithm factors in polynomial time on a quantum computer, motivating post-quantum cryptography — an active research frontier. PARI/GP's internal algorithms (elliptic curve method, quadratic sieve, MPQS) are documented in the PARI user manual.

**Suggested investigation.** Benchmark `factor(n)` in Sage against a naive trial-division implementation for $n$ with 20, 40, 60, 80 decimal digits, plotting wall-clock time on a log scale to observe the sub-exponential regime empirically. Separately, verify the CRT construction by hand for a small coprime modulus system, then confirm against `CRT_list()`, and extend the investigation to ask what fails when moduli are *not* pairwise coprime (existence condition via $\gcd$ compatibility).

**Report-writing note.** The write-up should state the factorization timing data with fitted asymptotic model, explicitly derive the CRT solution for the chosen numerical example before comparing to Sage's output, and discuss one concrete case (RSA modulus generation, or a non-coprime CRT failure) illustrating why the algorithmic distinction between "easy" (primality, modular arithmetic) and "hard" (factoring) problems matters.

## Calculus Sage

**Definition.** Let $\mathcal{E}$ denote the ring of symbolic expressions generated from indeterminates $x_1,\dots,x_n$, the field of constants (rational, algebraic, or transcendental symbols), and a signature of elementary and special functions closed under composition. A *symbolic differentiation* operator $D_{x_i}: \mathcal{E} \to \mathcal{E}$ is a homomorphism satisfying the Leibniz rule $D_{x_i}(fg) = fD_{x_i}(g) + gD_{x_i}(f)$, linearity, and the chain rule $D_{x_i}(f\circ g) = (D f)\circ g \cdot D_{x_i} g$, computed structurally on the expression tree of $f$ rather than numerically. *Symbolic integration* seeks $F\in\mathcal{E}$ (or a proof that none exists in $\mathcal{E}$) with $D_x F = f$; *symbolic limits* and *series* compute $\lim_{x\to a} f(x)$ and the Taylor/Laurent expansion $f(x)=\sum_k c_k(x-a)^k$ as closed-form or truncated symbolic objects, not floating-point approximations.

**Theorem (Risch, 1969).** For $f$ an elementary function built from field operations, exponentials, and logarithms over a differential field $(K,D)$ with constant field $C$ algebraically closed of characteristic $0$, there is an algorithm — the Risch algorithm — that decides whether an elementary antiderivative $F$ exists and, if so, constructs it. *Proof sketch:* the problem reduces recursively by the tower structure of $K$ (successive extensions by $\log$ or $\exp$ of previously constructed elements) to a linear differential equation over each extension; Liouville's theorem constrains the form of $F$ to $F = v_0 + \sum_i c_i \log v_i$ with $v_i \in K$, $c_i \in C$, reducing existence to solving a linear system for undetermined coefficients. Full details: Risch, *The problem of integration in finite terms* (Trans. AMS, 1969); Bronstein, *Symbolic Integration I* (2005) gives a complete, implementable treatment.

**Fundamental theorem, checked computationally.** Given a returned antiderivative $F$, every serious CAS re-differentiates: $D_x F \stackrel{?}{=} f$ up to simplification in $\mathcal{E}$, exploiting $\int_a^b f\,dx = F(b)-F(a)$ as *both* the mathematical content and the correctness certificate — differentiation is decidable and structural, so it is cheap to verify what integration, limits, and series (whose correctness proofs are deep) claim to compute. This asymmetry — easy verification, hard construction — is the same pattern underlying $\mathsf{P}$ vs $\mathsf{NP}$-flavored heuristics in computer algebra.

**Literature context.** The Risch algorithm is complete for the purely transcendental (exp-log) case but only semi-decidable once algebraic functions, special functions (error function, elliptic integrals), or mixed exponential-algebraic towers enter; no complete algorithm is known for general special-function integration, and Risch's original procedure has never been fully implemented as stated due to its reliance on the constant-field decision problem. Series and limit computation for functions with essential singularities or oscillatory behavior (e.g. $\lim_{x\to 0} x^x$, asymptotic series that are divergent but Borel-summable) remain active areas — see Bronstein's book and the *Symbolic-Numeric* literature (Corless, Watt) for open cases.

**Suggested investigation.** Implement a restricted Risch algorithm for the purely exponential tower $\mathbb{Q}(x, e^x)$; test it against a CAS (Sage's `integrate`, or Maxima's `risch`) on 20 curated integrands, classifying successes, failures, and cases where the CAS silently returns a special-function (non-elementary) result. Separately, investigate a family of functions with removable/essential singularities and compare symbolic limit results to numerically extrapolated ones (Richardson extrapolation), quantifying where symbolic methods diverge from numerical heuristics.

**Report-writing note.** The write-up should state precisely which differential field the test integrands live in, report the Risch-decidability class of each (elementary vs. non-elementary), and include the re-differentiation check as an explicit verification step for every claimed antiderivative — not merely CAS output trusted at face value.

## Exact Linear Algebra

**Definition.** Let $\mathbb{F}$ be an exact field of characteristic $0$ implemented with unbounded-precision rational or algebraic arithmetic (as with `QQ` or `QQbar` in Sage). Exact linear algebra is the study of matrix computations — row reduction, kernel and image computation, characteristic and minimal polynomials, eigenvalues, canonical forms — performed entirely within $\mathbb{F}$, so that every intermediate and final quantity is a provably correct element of $\mathbb{F}$, not a floating-point approximation subject to rounding error or ill-conditioning.

**Theorem (Correctness and complexity of exact Gaussian elimination).** Let $A \in \mathbb{Q}^{n\times n}$ with entries of bit-length at most $h$. There is an algorithm computing the reduced row-echelon form (RREF) of $A$ using exact rational arithmetic in time polynomial in $n$ and $h$, and the RREF is unique and exact.

*Proof sketch.* Fraction-free Gaussian elimination (the Bareiss algorithm) performs elimination by tracking determinants of leading principal minors, replacing each pivot division by an exact division guaranteed to have zero remainder — a consequence of the Sylvester identity relating successive minors. This controls *intermediate expression swell*: naive fraction arithmetic on rationals can cause numerator/denominator bit-length to grow exponentially in $n$ without such control, since each elimination step multiplies denominators. Bareiss's method keeps the bit-length of intermediate entries polynomially bounded (specifically $O(n h)$ under mild assumptions), giving an overall complexity polynomial in $n$ and $h$, in contrast to naive fraction-arithmetic elimination which is correct but not polynomially bounded without such control. Uniqueness of RREF is a standard linear-algebra fact independent of the field's representation. $\blacksquare$

**Literature context.** The complexity landscape for exact linear algebra is still evolving. Bareiss's 1968 algorithm remains foundational, but faster asymptotic methods exist: Storjohann's work reduces exact linear system solving and rank/kernel computation to essentially the same complexity as matrix multiplication ($O(n^\omega)$ arithmetic operations with bit-complexity overhead), and p-adic/Chinese Remainder lifting techniques (Dixon's algorithm, 1982) solve $Ax=b$ over $\mathbb{Q}$ by lifting a solution modulo a prime and reconstructing rationals via continued fractions, avoiding intermediate swell entirely. Exact eigenvalue computation is fundamentally different from the numerical case: eigenvalues of a rational matrix are algebraic numbers, roots of the characteristic polynomial, and are generally *not* expressible by radicals for $n \geq 5$ (Abel–Ruffini), so "exact" eigenvalues require symbolic representation via algebraic number fields (e.g. `QQbar`) or isolating intervals with certified refinement (as in `AlgebraicRealField`). An open and actively researched question is finding the practical complexity crossover: for which matrix sizes and sparsity patterns do certified numerical methods (interval arithmetic, iterative refinement) outperform genuinely symbolic ones, and how do modular/CRT techniques scale for very large sparse systems relevant to lattice cryptography and integer programming.

**Suggested investigation.** Implement (in Sage or another CAS) naive fraction-arithmetic Gaussian elimination and Bareiss's fraction-free variant on a family of $n\times n$ rational matrices with controlled entry size; empirically measure the growth in numerator/denominator bit-length as a function of $n$ for each method, and compare wall-clock time against Sage's built-in RREF (which uses more sophisticated modular methods).

**Report-writing note.** The write-up should state the theoretical bit-length bound for Bareiss's method, present measured bit-length and timing data confirming or contradicting it, and discuss at what matrix size (if any) naive elimination becomes practically infeasible due to swell.

## Plotting Visualization

**Definition.** Let $f : D \subseteq \mathbb{R} \to \mathbb{R}$ be a computable expression in a computer algebra system (CAS), and let $S = \{(x, y) \in D \times \mathbb{R} : y = f(x)\}$ be its graph. The operation `plot(f, x, a, b)` computes a finite sample $P = \{(x_i, f(x_i))\}_{i=0}^n$, $x_i \in [a,b]$, and renders a piecewise-linear (or spline) interpolant $\hat{S}$ approximating $S$. The generalizations `plot3d` (surfaces $z = f(x,y)$, or parametric $\mathbf{r}(u,v)$) and `implicit_plot` (level sets $\{(x,y) : F(x,y) = 0\}$, computed via contouring algorithms such as marching squares/cubes) extend this to $\mathbb{R}^3$ and to relations not solvable in closed form for $y$. Crucially, these routines act directly on the symbolic object — not on a separately transcribed formula — so a plotting call is a structural query on the same expression tree used in `substitution_evaluation`.

**Theorem (plotting as a decision procedure, informally).** If $f$ and $g$ are symbolically distinct expressions with $f - g \not\equiv 0$ on $D$, then generically $\hat{S}_f \neq \hat{S}_g$ as rendered curves on any sufficiently fine sample grid with $n \geq N(\varepsilon)$ points, where $N(\varepsilon)$ depends on the modulus of continuity of $f-g$ and a visual tolerance $\varepsilon$. This is *not* a proof of $f \equiv g$ or $f \not\equiv g$ — visual coincidence at finite resolution is necessary but not sufficient evidence — but it is a fast, high-recall filter: a visible discrepancy refutes an algebraic claim ($f = g$) with near-certainty, since sampling error alone rarely conspires to hide a genuine functional difference over an interval. This asymmetry (plots reject, not confirm) is the logical content of "visualization as a check."

**Literature context.** The theoretical question of *how many samples suffice to guarantee no branch or singularity is missed* is genuinely open in general: adaptive plotting algorithms (as in Mathematica's `PlotPoints`/`MaxRecursionDepth`, or Sage's `plot` adaptive refinement, following Wolfram's and earlier Lane's heuristics) refine near high curvature or discontinuities, but no algorithm can certify completeness for arbitrary $f$ without additional structure (e.g. Lipschitz bounds, or symbolic detection of poles via `singularities`). Implicit plotting is harder still: marching-squares contouring (Lorensen & Cline 1987, originally for 3D marching cubes) can miss thin filaments or isolated points of a variety when the grid is coarser than the feature scale — a concrete instance of the aliasing problem in numerical algebraic geometry, connected to certified/interval-arithmetic plotting (e.g. Tupper's reliable implicit plotting algorithm, 2001).

**Suggested investigation.** Construct a family $f_\epsilon(x) = \sin(x) + \epsilon \sin(N x)$ for large $N$ and small $\epsilon$, and determine experimentally the sampling density $n(\epsilon, N)$ at which uniform-grid `plot` first visually distinguishes $f_\epsilon$ from $\sin(x)$; compare against adaptive plotting. Separately, implement (or study) Tupper's algorithm and construct an implicit curve with a component of measure zero (an isolated point or degenerate branch of $F(x,y)=0$) that a naive marching-squares implementation misses at a given resolution but interval-arithmetic contouring recovers.

**Report-writing note.** The write-up should state the exact sampling scheme used (grid vs. adaptive), quantify the resolution threshold at which the discrepancy or missed feature becomes visible/invisible, and explicitly distinguish "plot confirms an identity" (unjustified) from "plot refutes an identity" (the sound use), citing the specific $\varepsilon$–$n$ tradeoff observed.

## Solving Equations

**Definition.** Let $R$ be a symbolic ring — typically $\mathbb{Q}[x_1,\dots,x_n]$ or an extension thereof carrying algebraic and transcendental generators — and let $f_1,\dots,f_m \in R$. The equation-solving problem asks for the *exact* solution set

$$V(f_1,\dots,f_m) = \{\, \mathbf{x} \in \overline{K}^n : f_i(\mathbf{x}) = 0 \text{ for all } i \,\}$$

together with, for each isolated point, its multiplicity as a zero of the ideal $I = \langle f_1,\dots,f_m\rangle$. This is categorically distinct from numeric root-finding: a symbolic `solve()` returns elements of $\overline{K}$ (algebraic closure of the coefficient field) — radicals, algebraic numbers presented as roots of minimal polynomials, or parametrized families — rather than floating-point approximants. The auxiliary operation `assume()` restricts the ambient domain (e.g., $x \in \mathbb{R}_{>0}$, or a branch cut for $\arg$), which prunes $V$ to $V \cap D$ before or during simplification.

**Theorem (multiplicity via the Jacobian criterion).** For a single polynomial $f \in K[x]$ and $\alpha \in \overline{K}$ with $f(\alpha)=0$, the multiplicity of $\alpha$ is
$$\mu(\alpha) = \min\{\, k : f^{(k)}(\alpha) \neq 0 \,\}.$$
*Proof.* Write $f(x) = (x-\alpha)^{\mu} g(x)$ with $g(\alpha)\neq 0$, by unique factorization in $K[x]$ (or $\overline{K}[x]$). Differentiating $\mu$ times via the Leibniz rule kills every term with a surviving factor $(x-\alpha)$ except $\mu! \, g(\alpha) \neq 0$; fewer than $\mu$ derivatives leave a factor $(x-\alpha)^{>0}$, hence vanish at $\alpha$. $\blacksquare$

For systems ($n>1$), multiplicity is instead the dimension of the local ring $\dim_K \mathcal{O}_{V,\mathbf{p}}$ as a $K$-vector space; this is what a CAS actually computes via Gröbner bases and primary decomposition of $I$, not naive differentiation.

**Literature context.** The reduction of "solve" to elimination is classical (resultants, Gröbner bases — Buchberger's algorithm), with complexity doubly exponential in $n$ in the worst case for general systems, though singly exponential bounds hold for zero-dimensional generic systems (Lazard, Faugère's F4/F5). Radical solvability of univariate $f$ is governed by Galois theory: $f$ is solvable by radicals iff $\mathrm{Gal}(f/K)$ is a solvable group — the reason symbolic solvers fall back to `RootOf`/algebraic representations for quintics and beyond (Abel–Ruffini). Open and active: certified real-root isolation with optimal bit complexity, and efficient multiplicity-aware primary decomposition for large sparse systems.

**Suggested investigation.** Implement multiplicity detection two ways — (1) successive symbolic differentiation per the theorem, (2) `dim_K` of the local quotient ring via a Gröbner basis of $I + \mathfrak{m}_p^N$ — on a battery of test polynomials/systems (including near-degenerate cases like $(x-1)^3(x+2)$ and a bivariate tangency), and benchmark agreement and runtime scaling in $n$.

**Report-writing note.** State precisely the domain $D$ each `assume()` imposed, list $V$ with multiplicities and Galois-theoretic solvability status per irreducible factor, and report where the two multiplicity methods diverge (numerically unstable near-multiple roots) with the ideal-theoretic explanation.

### conjecture_loop (20.3s)

## Conjecture Loop

**Definition.** A *conjecture loop* is an iterated experimental procedure over a computable domain $D$ (typically $\mathbb{Z}$, $\mathbb{Q}$, or a finitely presented algebraic structure) consisting of four stages:

$$
\text{Generate} \to \text{Compute} \to \text{Pattern-match} \to \text{Falsify},
$$

repeated until either (a) a counterexample terminates the cycle, or (b) the proposer commits to a formal proof attempt. Formally, let $P: D \to \{\text{true}, \text{false}\}$ be a computable predicate. The loop maintains a finite sample $S_n \subset D$, $|S_n| = n$, and a candidate conjecture $C$ inferred from $\{(x, P(x)) : x \in S_n\}$ by inductive generalization (pattern-matching on residues, growth rates, factorizations, or symbolic closed forms). At each step the loop either draws $x_{n+1} \notin S_n$ adversarially — biased toward regimes where $C$ is *least* tested (large magnitude, edge-case parity, boundary of a stated range) — and checks $P(x_{n+1})$ against $C$'s prediction.

**Theorem (loop soundness, informal).** If $C$ survives $n$ adversarially chosen trials without amendment and $D$ is searched without density bias, the *posterior* confidence in $C$ increases monotonically but never reaches certainty for any finite $n$; only a proof (or an exhaustive check over a decidable finite subdomain) closes the gap. This is not a probabilistic guarantee in a rigorous Bayesian sense unless a prior over conjecture space is specified — the loop is a heuristic search procedure, not an inference engine with calibrated error bounds. Its value is falsificationist (Popperian): the loop is efficient at *rejecting* false conjectures cheaply, and its failure to reject is evidence, not proof.

**Literature context.** The canonical cautionary tale is the Pólya conjecture (that $\pi(x)$-related summatory Liouville function $L(n) = \sum_{k \le n}\lambda(k) \le 0$ for $n \ge 2$), verified computationally for $n$ up to $8\times10^8$ before Haselgrove (1958) exhibited a counterexample near $n \approx 1.845 \times 10^{361}$, later sharpened by Tanaka (1980) to $n = 906{,}150{,}257$. Similarly, Mertens' conjecture ($|M(n)| < \sqrt n$) held for enormous ranges before Odlyzko–te Riele (1985) disproved it via lattice-basis reduction on zeros of $\zeta(s)$ — no explicit counterexample is even known to this day. These cases anchor the methodological lesson: *the conjecture loop's sample density is not uniform in the arithmetic quantities that matter* (e.g., first sign change of an oscillating summatory function is governed by low-lying zeta zeros, not by naive magnitude). Sage and PARI/GP's fast integer/polynomial arithmetic make the "generate–compute" stages of the loop essentially free for $n$ in the millions, shifting the bottleneck entirely to the "pattern-match/falsify" stages — this is precisely where symbolic regression, OEIS lookups, and visualization (residue plots, log-log growth plots) earn their keep.

**Suggested investigation.** Pick an unresolved or moderately deep conjecture with elementary statement (e.g., a variant of the Collatz function restricted to a residue class, or a divisor-sum inequality). Implement the loop in Sage: (1) generate $S_n$ via structured sampling (not just $1,\dots,n$ — include primes, near-powers, adversarial residues mod small primes); (2) plot the relevant statistic against $n$ on log and log-log axes to expose growth-rate mismatches; (3) query OEIS programmatically on the generated sequence; (4) attempt a targeted search in regimes analogous to Haselgrove's — large $n$, rare residue classes — before accepting the conjecture as "well-tested."

**Report-writing note.** The write-up must state the exact sampling strategy (uniform vs. adversarial), the range searched, and explicitly address *why* the untested regime, if any, is unlikely to hide a counterexample — citing analogous historical near-misses where relevant.

## Group Theory Sage

**Definition.** A permutation group $G \le S_n$ is a subgroup of the symmetric group on $n$ letters, presented computationally by a generating set $\{g_1,\dots,g_k\} \subset S_n$. A matrix group $G \le \mathrm{GL}_n(F)$ over a field or ring $F$ is likewise given by generators, with $|G|$ possibly infinite. SageMath's `PermutationGroup`, `MatrixGroup`, and `libgap` interface expose these as computable objects: order, center $Z(G)$, conjugacy classes, and the subgroup lattice become queries rather than derivations left to hand computation.

**Theorem (Schreier–Sims correctness and complexity).** Given generators $\{g_1,\dots,g_k\}$ of $G \le S_n$, the Schreier–Sims algorithm computes a base $B=(\beta_1,\dots,\beta_r)$ and strong generating set (SGS) in time polynomial in $n$ and $k$ (with high-probability or deterministic variants), from which $|G| = \prod_i |G^{(i-1)}:G^{(i)}|$ is read off exactly as a product of orbit sizes, where $G^{(i)}$ is the pointwise stabilizer of $\beta_1,\dots,\beta_i$.

*Proof sketch.* The stabilizer chain $G = G^{(0)} \ge G^{(1)} \ge \cdots \ge G^{(r)} = 1$ satisfies $|G^{(i-1)}:G^{(i)}| = |\beta_i^{G^{(i-1)}}|$, the orbit of $\beta_i$ under $G^{(i-1)}$, by the orbit–stabilizer theorem:
$$
|G^{(i-1)}| = |\beta_i^{G^{(i-1)}}| \cdot |G^{(i)}|.
$$
Schreier's lemma produces generators for each $G^{(i)}$ from a Schreier tree on the orbit of $\beta_i$ together with the generators of $G^{(i-1)}$, giving at most $|\beta_i^{G^{(i-1)}}| \cdot |\{\text{gens}\}|$ new generators — a bound sifted down via the Schreier–Sims sifting procedure to keep the SGS size $O(n^2)$. Iterating over $i=1,\dots,r$ terminates when $G^{(r)}$ is trivial, and telescoping the orbit–stabilizer identities gives $|G|$. $\blacksquare$

**Literature context.** This is the algorithmic backbone of computational group theory, underlying GAP, Magma, and Sage's `libgap`-backed permutation and matrix group routines (Seress, *Permutation Group Algorithms*, 2003, is the standard reference; Holt–Eick–O'Brien, *Handbook of Computational Group Theory*, 2005, covers matrix groups, polycyclic presentations, and the constructive recognition problem). For matrix groups the situation is genuinely open in places: deciding whether a given finite subgroup of $\mathrm{GL}_n(\mathbb{F}_q)$ is the full group, or identifying its composition factors, relies on the *matrix group recognition project* (Aschbacher's classification of maximal subgroups of classical groups, and the algorithmic realization by Leedham-Green, O'Brien, et al.), which remains an active research area — not every case is polynomial-time in practice, and black-box recognition of simple group types is still being refined.

**Suggested investigation.** Take $G = \mathrm{PGL}_2(\mathbb{F}_p)$ for a prime $p$ and, in Sage, construct it both as a permutation group (acting on $\mathbb{P}^1(\mathbb{F}_p)$) and as a matrix group over $\mathbb{F}_p$. Verify $|G| = p(p-1)(p+1)$, compute the subgroup lattice for small $p$ (say $p=7,11$), and identify the conjugacy classes with their cycle types under the permutation representation. ## Manifolds Geometry

**Definition.** A smooth manifold $M$ of dimension $n$ is a second-countable Hausdorff topological space equipped with an atlas $\{(U_\alpha, \varphi_\alpha)\}$ of charts $\varphi_\alpha : U_\alpha \to \mathbb{R}^n$ whose transition maps $\varphi_\beta \circ \varphi_\alpha^{-1}$ are $C^\infty$. A Riemannian (or pseudo-Riemannian) structure adds a metric tensor $g \in \Gamma(T^*M \otimes T^*M)$, symmetric and nondegenerate, and an affine connection $\nabla$ specifies parallel transport via Christoffel symbols $\Gamma^k_{ij}$ satisfying, for the Levi-Civita connection, $\nabla g = 0$ and torsion-freeness $\Gamma^k_{ij} = \Gamma^k_{ji}$. Curvature is encoded by the Riemann tensor
$$
R^l{}_{ijk} = \partial_j \Gamma^l_{ik} - \partial_k \Gamma^l_{ij} + \Gamma^l_{jm}\Gamma^m_{ik} - \Gamma^l_{km}\Gamma^m_{ij},
$$
with contractions Ricci $R_{ik} = R^j{}_{ijk}$ and scalar curvature $R = g^{ik}R_{ik}$.

**Theorem (Levi-Civita, existence and uniqueness).** For any pseudo-Riemannian $(M,g)$ there exists a unique torsion-free connection $\nabla$ with $\nabla g = 0$, given in local coordinates by
$$
\Gamma^k_{ij} = \tfrac{1}{2} g^{kl}\left(\partial_i g_{jl} + \partial_j g_{il} - \partial_l g_{ij}\right).
$$
*Proof sketch.* Existence and uniqueness follow from the Koszul formula, obtained by cyclically permuting metric-compatibility and torsion-free conditions applied to $g(\nabla_X Y, Z)$; nondegeneracy of $g$ inverts the resulting linear system for $g(\nabla_X Y, Z)$ uniquely. $\blacksquare$

SageManifolds (Gourgoulhon, Bejger, Mancini, 2015 onward) implements this entirely symbolically: charts as `Chart`, tensor fields as `TensorField` with components tracked per chart, and `metric.christoffel_symbols_display()` and `metric.riemann()` compute the above via symbolic differentiation and simplification (Maxima/Sage's simplification chains), not numerical approximation — this is genuinely executable differential geometry, closing the gap between the pen-and-paper index gymnastics of, e.g., Wald (1984) or do Carmo (1992) and machine-checked symbolic computation.

**Literature context.** SageManifolds' architecture — atlases of overlapping charts with symbolic transition maps, tensor components stored relative to a chosen frame/coframe and converted on demand — is described in Gourgoulhon–Bejger–Mancini (2015) and used productively in numerical relativity and Kerr–de Sitter spacetime computations. Open directions include: symbolic computation on manifolds without global coordinates (relying purely on frame-based tensor calculus), automated Petrov/Segre classification of curvature tensors, and integration with exterior calculus (differential forms, de Rham cohomology) at scale for higher-dimensional supergravity backgrounds — an active area given software like `xAct` (Mathematica) and `Cadabra` provide overlapping but not identical capability.

**Suggested investigation.** Compute the Schwarzschild metric's Riemann tensor, Kretschmann scalar $R_{ijkl}R^{ijkl}$, and geodesic equations symbolically in SageManifolds; verify the vacuum Einstein equations $R_{ik} = 0$ hold identically, then perturb the metric with a parametrized deviation and study which curvature invariants remain finite as $r \to 2M$.

## Experimental Mathematics

**Definition.** Experimental mathematics is the methodology by which numerical, symbolic, and graphical computation is used to discover mathematical facts, formulate conjectures, and guide (but not replace) formal proof. Formally, given a mathematical statement $\varphi$ depending on parameters $\theta$, an experimental-mathematics workflow constructs an oracle $\mathcal{O}: \Theta \to \{\text{true}, \text{false}, \text{undecided}\}$ implemented by computation — high-precision arithmetic (PSLQ, LLL-based integer relation detection), symbolic algebra (Gröbner bases, Sage's group-theory routines), or numerical simulation over manifolds — and uses $\mathcal{O}(\theta)$ for many $\theta$ to estimate $\Pr[\varphi \text{ holds}]$ before investing in a proof. This is the *conjecture loop*: generate instances, compute invariants, pattern-match, falsify or gain confidence, then escalate to a proof assistant.

**Theorem/Proof pattern — integer relation detection.** A canonical experimental tool: given real numbers $x_1,\dots,x_n$, the PSLQ algorithm (Ferguson–Bailey–Arno, 1999) finds, in polynomial time in the bit-precision $d$, an integer vector $(a_1,\dots,a_n)\in\mathbb{Z}^n\setminus\{0\}$ such that
$$
\left|\sum_{i=1}^n a_i x_i\right| < \varepsilon
$$
for $\varepsilon$ near machine precision, *or* certifies no relation of bounded norm exists. The algorithm terminates because it maintains a decreasing sequence of positive integers bounding the relation norm via a reduced lattice basis; termination and the polynomial complexity bound follow from the analysis in Ferguson, Bailey & Arno (*Math. Comp.* 68 (1999)). This is not a proof that $\sum a_i x_i = 0$ exactly — it is evidence strong enough (at 50+ digit precision) to motivate a search for an exact identity, which the 1996 discovery of the BBP formula for $\pi$ exemplifies: PSLQ found the relation numerically, and a subsequent hand/symbolic proof verified it exactly.

**Literature context.** The field was named and systematized by Borwein, Bailey & Girgensohn (*Experimentation in Mathematics: Computational Paths to Discovery*, 2004) and Bailey & Borwein's subsequent work on "experimental mathematics as methodology." Open problems abound: no general complexity-theoretic characterization exists for *which* conjectures are amenable to integer-relation or lattice-reduction discovery versus requiring genuinely new invariants (e.g., from `manifolds_geometry` — curvature, characteristic classes — or `group_theory_sage` — character tables, cohomology of finite groups). The hand-off step itself — from numerically-suggested identity to Lean/Coq-checked proof — remains largely manual; formalizing *when* a numerical pattern is proof-ready is an active research question in the interaction between computer algebra and proof assistants (cf. the `sagemath`–Lean bridge literature).

**Suggested investigation.** Pick a family of definite integrals or lattice sums parametrized by a group-theoretic or geometric invariant (e.g., volumes of hyperbolic manifolds from `manifolds_geometry`, or class-sum identities from `group_theory_sage`). Compute each to 100+ digits, run PSLQ against a basis of candidate constants ($\pi$, $\zeta(3)$, logs of small integers), and tabulate the hit rate as the parameter varies. Escalate any discovered relation to a formal proof attempt in Lean.

**Report-writing note.** The write-up must state precision used, the candidate constant basis, PSLQ's returned relation norm and residual, and explicitly separate "numerically verified" from "formally proved," with the Lean artifact (if any) referenced by commit hash.

## Math Research

**Definition.** *Experimental mathematics* is the systematic use of large-scale symbolic and numeric computation to discover, test, and refine mathematical conjectures before — or in place of — proof. Formally, given a parametrized family of mathematical objects $\{X_n\}_{n\in\mathbb{N}}$ and a candidate invariant or relation $R(X_n)$, the experimental method constructs a computational oracle $\mathcal{O}: n \mapsto R(X_n)$, evaluates $\mathcal{O}$ over a large sample $S \subset \mathbb{N}$ (often $|S| > 10^6$), and searches for a closed-form pattern $f$ such that $\mathcal{O}(n) = f(n)$ for all $n \in S$, typically via integer-relation detection (e.g., the PSLQ algorithm) or symbolic regression over a basis of candidate constants and functions.

**Theorem/Proof sketch.** The paradigmatic tool is the PSLQ algorithm (Ferguson–Bailey–Arno, 1999): given real numbers $x_1,\dots,x_n$ suspected to satisfy an integer relation $\sum_{i=1}^n a_i x_i = 0$ with $a_i \in \mathbb{Z}$, PSLQ finds such a relation (if one exists with bounded coefficients) in polynomial time in the precision required, using an LLL-type lattice reduction on a matrix built from the partial sums of the $x_i$. The key correctness argument is that if a relation exists, the lattice of relation-vectors has a short vector detectable once numerical precision exceeds a bound governed by the relation's coefficient size — this is why experimental discoveries (e.g., BBP-type formulas for $\pi$) require hundreds or thousands of digits of precision, not mere floating point. Crucially, PSLQ *finds* candidate identities; it does not *prove* them. The discovery of the BBP formula
$$
\pi = \sum_{k=0}^\infty \frac{1}{16^k}\left(\frac{4}{8k+1} - \frac{2}{8k+4} - \frac{1}{8k+5} - \frac{1}{8k+6}\right)
$$
via PSLQ, later proved rigorously by symbolic telescoping, is the canonical example of the experiment-then-prove loop.

**Literature context.** This methodology, championed by Bailey, Borwein, and Wilf–Zeilberger's "A=B" holonomic framework, has produced conjectures in number theory (e.g., Zagier's dilogarithm identities), knot theory (volume conjectures via SnapPy computation), and combinatorics (OEIS-driven conjecture generation, now the largest crowdsourced experimental-math database, with over 370,000 sequences). What remains open is largely methodological: no general decision procedure exists for *when* a numerically matched identity is provable by a known automated method (holonomic closure, WZ-pairs, cylindric/Macdonald identities) versus requiring genuinely new mathematics — DeepMind's 2021 work coupling supervised learning with attribution techniques to conjecture new theorems in knot theory and representation theory (Davies et al., *Nature*) suggests machine-learning-guided search is now a live extension of this loop, with formal guarantees largely absent.

**Suggested investigation.** Pick a family with a computable invariant (e.g., the number of domino tilings of an $n\times n$ Aztec diamond, or coefficients of a $q$-series arising from a partition statistic). Compute the sequence for $n$ up to computational feasibility, submit it to the OEIS, and if unmatched, apply PSLQ or Zeilberger's algorithm (implemented in Maple's `gfun` or Sage) to search for a linear recurrence with polynomial coefficients (a P-recursive / holonomic certificate). Attempt a WZ-style proof of any recurrence found.

**Report-writing note.** The write-up must state precisely: the computational precision/sample size used, the search algorithm and its parameters (lattice dimension, coefficient bound), the conjectured closed form or recurrence, and — critically — whether it was subsequently proved, disproved by a larger counterexample, or remains open, since the value of experimental output is measured by its falsifiability, not its numerical fit.

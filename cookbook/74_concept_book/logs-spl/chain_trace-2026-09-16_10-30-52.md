### function (10.9s)

## Function

A function is a rule that assigns to each input exactly one output. If $f$ is a function from a set $X$ (the domain) to a set $Y$ (the codomain), we write $f: X \to Y$, and for each $x \in X$ there is a unique element $f(x) \in Y$. This uniqueness condition — one output per input — is the entire content of the definition. It is what separates a function from a general relation, and it is why the vertical line test works: a curve represents a function precisely when no vertical line crosses it more than once, since two intersection points would mean one input producing two outputs.

The crucial shift for calculus is to stop thinking of a function as "a formula" and start thinking of it as a mapping — an assignment of outputs to inputs that may or may not have a closed-form expression. Consider $f(x) = x^2$, $g(x) = \sin(x)$, and the piecewise function
$$
h(x) = \begin{cases} x & x < 0 \\ x^2 & x \geq 0 \end{cases}.
$$
Despite looking structurally different, all three are functions in exactly the same sense: each obeys the one-output rule on its domain. A table of values, a graph, or even an algorithm that computes an output from an input all qualify as functions, provided the assignment is well-defined.

This mapping-first view matters for problem-solving because it tells you what to check before applying any calculus tool. Suppose you're asked whether $y^2 = x$ defines $y$ as a function of $x$. Solve for $y$: $y = \pm\sqrt{x}$. For $x = 4$, this gives $y = 2$ and $y = -2$ — two outputs for one input — so $y^2 = x$ does *not* define a function of $x$. But if you restrict to $y = \sqrt{x}$ alone (discarding the negative branch), the rule now assigns exactly one output to each $x \geq 0$, and it is a function with domain $[0, \infty)$.

This habit — asking "does exactly one output correspond to each input, and over what domain?" — is the first check you'll run before differentiating, composing, or inverting any expression, since operations like finding $f^{-1}$ or evaluating $\lim_{x \to a} f(x)$ presuppose that $f$ is a genuine function to begin with.

### limit (9.2s)

## Limit

The limit of a function $f(x)$ as $x$ approaches a value $a$ describes the value that $f(x)$ gets arbitrarily close to as $x$ gets arbitrarily close to $a$ — without ever requiring $x = a$. This distinction matters: $f$ may not even be defined at $a$, yet the limit can still exist. We write

$$\lim_{x \to a} f(x) = L$$

to mean that $L$ is that approached value. The idea is made rigorous by the $\varepsilon$-$\delta$ definition: for every tolerance $\varepsilon > 0$ on the output, there exists a tolerance $\delta > 0$ on the input such that whenever $0 < |x - a| < \delta$, it follows that $|f(x) - L| < \delta$... more precisely, $|f(x) - L| < \varepsilon$. In words: no matter how tightly you demand $f(x)$ stay near $L$, you can always find an interval around $a$ (excluding $a$ itself) that guarantees it.

**Worked example.** Consider $f(x) = \dfrac{x^2 - 4}{x - 2}$ at $a = 2$. Direct substitution gives $\frac{0}{0}$, an undefined expression — $f$ is not even defined at $x=2$. But for $x \neq 2$, we can factor:

$$f(x) = \frac{(x-2)(x+2)}{x-2} = x + 2$$

As $x$ approaches 2 from either side, $f(x)$ approaches $4$, so $\lim_{x \to 2} f(x) = 4$, even though $f(2)$ itself doesn't exist. This is the essential payoff of the limit concept: it lets us reason about behavior *near* a point independently of what happens *at* that point.

**Problem-solving application.** Limits are the operation underlying the rest of calculus. The derivative is defined as the limit of a difference quotient, $f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$, capturing instantaneous rate of change. The definite integral is a limit of Riemann sums as rectangle widths shrink to zero. An infinite series is defined as the limit of its sequence of partial sums. In each case, an intuitive but imprecise idea — instantaneous speed, exact area, infinite sum — is rescued from paradox by phrasing it as a limit and proving that limit exists. When solving problems, first check whether direct substitution works; if it produces an indeterminate form like $\frac{0}{0}$, try algebraic simplification (factoring, rationalizing) or, later, L'Hôpital's rule, to reveal the limit that direct evaluation obscures.

### infinity (24.3s)

## Infinity

Infinity is not a number you can compute with — it is a description of behavior that never terminates. The one idea to fix firmly is arbitrarily small scale, written $\varepsilon \to 0$: a positive quantity you can force below any threshold, no matter how tiny you name. Unbounded growth, $x \to \infty$, is the same idea seen from the other side — if $\varepsilon$ can be made as small as you like, then $1/\varepsilon$ is a quantity that grows past any bound you like. So we don't need a second independent notion; "arbitrarily large" is just "arbitrarily small" turned upside down.

This matters because it is exactly the machinery behind the formal definition of a limit. To say $\lim_{x \to \infty} \frac{1}{x} = 0$ means: for every $\varepsilon > 0$, no matter how small, there exists a point beyond which $\left|\frac{1}{x}\right| < \varepsilon$. Notice that infinity never appears as a value plugged into the function — it appears only as a promise: however small a tolerance you demand, I can eventually satisfy it.

The same idea governs infinite sums. Consider $\sum_{n=1}^{\infty} \frac{1}{2^n}$. This is not "adding infinitely many numbers" in a literal sense; it is the limit of partial sums $S_N = \sum_{n=1}^{N} \frac{1}{2^n}$ as $N$ grows without bound. Computing a few: $S_1 = 0.5$, $S_2 = 0.75$, $S_3 = 0.875$, $S_4 = 0.9375$ — each term closes half the remaining gap to 1. Formally,

$$S_N = 1 - \frac{1}{2^N}, \qquad \lim_{N \to \infty} S_N = 1.$$

The sum "equals" 1 not because we ever finish adding, but because the gap $1 - S_N = \frac{1}{2^N}$ can be forced below any $\varepsilon > 0$ by taking $N$ large enough — the same $\varepsilon$ challenge as above, applied to a different quantity.

Problem-solving payoff: whenever you see $\infty$ in an expression, translate it into a single question — "can the relevant gap be forced below any $\varepsilon > 0$?" — rather than treating $\infty$ as a number to substitute. This one translation is what lets you prove convergence of sequences, sums, and improper integrals rigorously instead of just trusting a pattern.

### real_number (26.2s)

## Real Number

The real numbers, denoted $\mathbb{R}$, form the set of all points on an infinite, unbroken line: every rational number $\frac{p}{q}$ (with $p,q$ integers, $q \neq 0$), and every irrational number — one that cannot be written as such a ratio, like $\sqrt{2}$, $\pi$, or $e$. Together they fill the number line completely, with no gaps. This property, called **completeness**, is what separates $\mathbb{R}$ from $\mathbb{Q}$ (the rationals alone) and is the single fact that makes calculus possible.

To see why completeness matters, consider the sequence $1, 1.4, 1.41, 1.414, 1.4142, \dots$ — successive decimal approximations to $\sqrt{2}$. Each term is rational, but the sequence "converges toward" a target value. If we restricted ourselves to $\mathbb{Q}$, that target would not exist: there is no rational number whose square is exactly $2$. The sequence would be heading toward a hole. In $\mathbb{R}$, that hole is filled — the limit $\sqrt{2}$ is itself a real number, sitting on the line waiting for the sequence to arrive.

Formally, completeness says: every nonempty set of real numbers that is bounded above has a *least* real number that sits above all of them (its smallest upper bound). This is not true of $\mathbb{Q}$: the set $\{x \in \mathbb{Q} : x^2 < 2\}$ is bounded above (e.g., by $1.5$), yet no rational number serves as its smallest upper bound — the "ceiling" you'd want to place on it is $\sqrt{2}$, which isn't rational. Only in $\mathbb{R}$ does every such set get a real number sitting exactly at its edge, with no gap.

**Problem-solving application.** Suppose you're told a sequence $a_n$ is increasing and bounded above by $10$. Does it converge? Over $\mathbb{Q}$, you couldn't say for sure — it might be sneaking up on an irrational value. Over $\mathbb{R}$, completeness guarantees convergence directly: since the sequence is increasing and bounded above, the set of its values is bounded above, so by completeness it has a smallest real upper bound — and that value is exactly the limit the sequence approaches. This reasoning — bounded and increasing therefore convergent — is the bedrock justification for every limit argument in calculus: it lets you prove a limit exists before you ever compute it, and it's also why a continuous function that goes from negative to positive on an interval is guaranteed to cross zero *somewhere real*, rather than skip over a gap.

### derivative (9.7s)

## Derivative

The derivative of a function $f$ at a point $x$ is defined as

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

This expression measures the **instantaneous rate of change** of $f$ at $x$. The fraction $\frac{f(x+h)-f(x)}{h}$ is the slope of a secant line through the points $(x, f(x))$ and $(x+h, f(x+h))$ — the *average* rate of change over that interval. As $h \to 0$, the second point slides toward the first, and the secant line rotates into the **tangent line** at $x$. The derivative is the slope of that tangent.

**Worked example.** Let $f(x) = x^2$. Then

$$f'(x) = \lim_{h \to 0} \frac{(x+h)^2 - x^2}{h} = \lim_{h \to 0} \frac{2xh + h^2}{h} = \lim_{h \to 0} (2x + h) = 2x$$

So at $x = 3$, the slope of the tangent to $y = x^2$ is $f'(3) = 6$: the curve is rising six times as fast as $x$ is changing, at that instant.

**Problem-solving application.** The derivative converts *position* into *velocity* and *total cost* into *marginal cost* because both are instances of the same underlying idea: an instantaneous rate of change. If $s(t)$ gives position at time $t$, then $v(t) = s'(t)$ gives velocity — not the average speed over an interval, but the speed *right now*. Suppose $s(t) = 4t^2$ (meters, with $t$ in seconds). Then $s'(t) = 8t$, so at $t = 5$ seconds the object's instantaneous velocity is $40\text{ m/s}$, even though its *average* velocity from $t=0$ to $t=5$ was only $20\text{ m/s}$.

The same logic applies economically: if $C(x)$ is the total cost of producing $x$ units, $C'(x)$ is the marginal cost — the approximate cost of producing one additional unit. If $C(x) = 0.01x^2 + 5x + 200$, then $C'(x) = 0.02x + 5$. At $x = 100$, marginal cost is $C'(100) = 7$: producing the 101st unit costs about \$7, distinct from the *average* cost per unit, $C(100)/100 = \$4.90$. This distinction between average and instantaneous rates is precisely what the limit in the derivative's definition is built to resolve, and it is the reason derivatives, not simple ratios, drive optimization problems in physics, economics, and engineering.

### riemann_sum (11.2s)

## Riemann Sum

**Definition.** Given a function $f$ continuous on $[a,b]$, partition the interval into $n$ subintervals of width $\Delta x = \frac{b-a}{n}$, with endpoints $a = x_0 < x_1 < \cdots < x_n = b$. On each subinterval $[x_{i-1}, x_i]$, choose a sample point $x_i^*$. The Riemann sum is

$$
S_n = \sum_{i=1}^{n} f(x_i^*)\,\Delta x.
$$

Each term $f(x_i^*)\,\Delta x$ is the area of a rectangle: height $f(x_i^*)$, width $\Delta x$. The sum approximates the area between the curve $y=f(x)$ and the $x$-axis by stacking these rectangles side by side. The choice of $x_i^*$ — left endpoint, right endpoint, or midpoint — changes the sum's value but not its limiting behavior. As $n \to \infty$ and $\Delta x \to 0$, the Riemann sum converges to the exact area, defining the definite integral:

$$
\int_a^b f(x)\,dx = \lim_{n\to\infty} \sum_{i=1}^{n} f(x_i^*)\,\Delta x.
$$

This is the constructive definition of integration: the integral is not merely "area under a curve" as a primitive notion, but the limit of a discrete, computable process.

**Worked example.** Approximate $\int_0^2 x^2\,dx$ using $n=4$ right-endpoint rectangles. Then $\Delta x = 0.5$, and the endpoints are $x_1=0.5, x_2=1, x_3=1.5, x_4=2$. Compute:

$$
S_4 = 0.5\big[(0.5)^2 + (1)^2 + (1.5)^2 + (2)^2\big] = 0.5(0.25+1+2.25+4) = 3.75.
$$

The exact value is $\int_0^2 x^2\,dx = \frac{8}{3} \approx 2.667$. The overestimate occurs because $x^2$ is increasing, so right endpoints overshoot on every subinterval.

**Problem-solving application.** Riemann sums matter beyond calculus proofs: they are the algorithmic backbone of numerical integration. When $f$ has no elementary antiderivative (e.g., $e^{-x^2}$), you cannot evaluate the integral symbolically — you approximate it. In code, this means looping over $n$ subintervals, evaluating $f$ at sample points, and summing. Doubling $n$ typically halves the error for left/right sums, which tells you how many subintervals you need for a target precision — a direct link between the abstract limit and a concrete stopping criterion in a program.

### definite_integral (8.8s)

## Definite Integral

The definite integral $\int_a^b f(x)\, dx$ is defined as the limit of Riemann sums as the partition width shrinks to zero:

$$
\int_a^b f(x)\, dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i^*)\, \Delta x, \qquad \Delta x = \frac{b-a}{n}
$$

Geometrically, this is the *signed* area between the curve $y = f(x)$ and the $x$-axis on $[a,b]$: regions where $f(x) > 0$ contribute positive area, regions where $f(x) < 0$ contribute negative area, and the integral totals the net accumulation of $f$ over the interval. This is what distinguishes it from ordinary geometric area, which is always nonnegative.

**Worked example.** Consider $f(x) = x^2 - 1$ on $[0, 2]$. The function is negative on $[0,1)$ and positive on $(1,2]$. Using the antiderivative $F(x) = \frac{x^3}{3} - x$ (justified by the Fundamental Theorem of Integral Calculus, which connects this limit definition to antidifferentiation):

$$
\int_0^2 (x^2 - 1)\, dx = F(2) - F(0) = \left(\frac{8}{3} - 2\right) - 0 = \frac{2}{3}
$$

The result $\frac{2}{3}$ is not the total geometric area enclosed by the curve and axis — it's the *net* signed area, where the region below the axis on $[0,1]$ partially cancels the region above the axis on $[1,2]$.

**Problem-solving application.** Suppose you're asked for the *total* area between $f(x) = x^2 - 1$ and the $x$-axis on $[0,2]$, not the net accumulation. You must first find where $f$ changes sign — here, $x = 1$ — split the interval there, and take the absolute value of each piece:

$$
\text{Area} = \left| \int_0^1 (x^2-1)\,dx \right| + \left| \int_1^2 (x^2-1)\,dx \right| = \left|-\frac{2}{3}\right| + \left|\frac{4}{3}\right| = 2
$$

This distinction — signed accumulation versus total geometric area — is the single most common source of error when applying definite integrals to physical problems like net displacement (signed) versus total distance traveled (unsigned), so always check the sign of $f$ before integrating over a region that crosses the axis.

### differential_equation (9.2s)

## Differential Equation

A differential equation relates a function to its own derivatives. Instead of solving for a number, you solve for the function itself — the equation constrains how a quantity changes, and the solution is the family of quantities consistent with that constraint. The simplest nontrivial example is $y' = ky$: the rate of change of $y$ is proportional to $y$ itself. This single line encodes population growth, radioactive decay, compound interest, and cooling — anything whose rate of change scales with its current amount.

To solve $y' = ky$, separate variables: $\frac{dy}{y} = k\,dt$. Integrating both sides gives $\ln|y| = kt + C_1$, and exponentiating yields

$$
y(t) = Ce^{kt}
$$

where $C = y(0)$ is fixed by an initial condition. Check it: differentiate $y = Ce^{kt}$ and you get $y' = kCe^{kt} = ky$, confirming the solution satisfies the original equation. Notice that the differential equation alone doesn't pin down one function — it defines an infinite family, indexed by $C$. The initial condition selects the specific member of that family that matches your physical situation.

This is why differential equations are the native language of physics. Newton's second law, $F = ma$, is really $F = m\frac{d^2x}{dt^2}$ — a statement about how position changes over time, not position itself. Maxwell's equations relate electric and magnetic fields through their spatial and temporal derivatives. The Schrödinger equation governs how a quantum wavefunction evolves. In each case, physical law doesn't hand you the answer directly; it hands you a local rule for change, and solving the differential equation is how you extract global behavior — a trajectory, a field, a probability distribution — from that rule.

Problem-solving practice: suppose a bacterial culture doubles every 3 hours. Model it with $y' = ky$. Since $y(3) = 2y(0)$, substitute into $y(t) = y(0)e^{kt}$ to get $2 = e^{3k}$, so $k = \frac{\ln 2}{3} \approx 0.231$. You now have a complete predictive model, $y(t) = y(0)e^{0.231t}$, built entirely from one derivative relationship and one data point — the general pattern for turning a rate-of-change statement into a usable forecast.

### physics_kinematics (11.0s)

## Physics Kinematics

Kinematics describes motion without asking what causes it, and calculus is its exact language. Position is a function of time, $x(t)$. Velocity is its instantaneous rate of change, $v(t) = x'(t) = \frac{dx}{dt}$, and acceleration is the rate of change of velocity, $a(t) = v'(t) = x''(t) = \frac{d^2x}{dt^2}$. Because differentiation and integration are inverses, motion can be reconstructed in reverse: given acceleration, integrating once recovers velocity, and integrating again recovers position.

$$v(t) = v_0 + \int_0^t a(\tau)\, d\tau, \qquad x(t) = x_0 + \int_0^t v(\tau)\, d\tau$$

**Worked example.** A drone starts at rest ($v_0 = 0$) at position $x_0 = 0$ and experiences acceleration $a(t) = 6t \text{ m/s}^2$ for the first 4 seconds of a vertical test flight. Integrating once gives velocity:

$$v(t) = \int_0^t 6\tau\, d\tau = 3t^2$$

At $t=4$s, $v(4) = 48$ m/s. Integrating again gives position:

$$x(t) = \int_0^t 3\tau^2\, d\tau = t^3$$

At $t=4$s, $x(4) = 64$ m. Notice that when acceleration is constant ($a(t) = a_0$), this same process reproduces the familiar formulas $v = v_0 + a_0 t$ and $x = x_0 + v_0 t + \frac{1}{2}a_0 t^2$ — those are not separate rules to memorize, but special cases of the general integral relationship above.

**Problem-solving application.** This calculus framing matters because real acceleration is rarely constant — engineers must integrate whatever $a(t)$ the physics actually gives them, whether it comes from a sensor reading, a control law, or a differential equation like $a(t) = -kx(t)$ (as in a spring). When you are handed a graph of $v(t)$ instead of a formula, the same idea applies geometrically: displacement is the *signed area* under the velocity curve, $\Delta x = \int_{t_1}^{t_2} v(t)\, dt$, and acceleration at any instant is the *slope* of that curve. Every kinematic "equation of motion" you encounter — including the ones in a mechanics graph relating force, mass, and acceleration — is ultimately a differential equation relating $x$, $x'$, and $x''$; solving a mechanics problem is solving that equation, subject to initial position and velocity.

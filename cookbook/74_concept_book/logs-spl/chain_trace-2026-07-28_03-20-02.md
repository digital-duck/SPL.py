## Derivative

**Definition.** Let $f : (a, b) \to \mathbb{R}$ be a real-valued function and let $x_0 \in (a, b)$. The *derivative* of $f$ at $x_0$ is defined as the limit

$$f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h},$$

provided this limit exists and is finite. When the limit exists, $f$ is said to be *differentiable* at $x_0$. The quantity $\frac{f(x_0+h)-f(x_0)}{h}$ is the *difference quotient*, representing the slope of the secant line through $(x_0, f(x_0))$ and $(x_0+h, f(x_0+h))$; the derivative is the slope of the tangent line obtained as $h \to 0$.

**Worked Example.** Compute $f'(x)$ for $f(x) = x^3$.

Applying the definition directly:

$$f'(x) = \lim_{h \to 0} \frac{(x+h)^3 - x^3}{h}.$$

Expanding $(x+h)^3 = x^3 + 3x^2 h + 3xh^2 + h^3$ gives

$$\frac{(x^3 + 3x^2 h + 3xh^2 + h^3) - x^3}{h} = 3x^2 + 3xh + h^2.$$

Taking $h \to 0$ yields $f'(x) = 3x^2$, confirming the power rule $\frac{d}{dx} x^n = nx^{n-1}$ for $n = 3$.

**Key Theorem (Differentiability Implies Continuity).** If $f$ is differentiable at $x_0$, then $f$ is continuous at $x_0$.

*Proof sketch.* Write $f(x_0 + h) - f(x_0) = \frac{f(x_0+h)-f(x_0)}{h} \cdot h$. As $h \to 0$, the first factor converges to $f'(x_0)$ and the second factor converges to $0$, so $\lim_{h \to 0}[f(x_0+h) - f(x_0)] = f'(x_0) \cdot 0 = 0$, establishing continuity. The converse fails: $f(x) = |x|$ is continuous but not differentiable at $x = 0$. $\square$

**Lab Cell.**

```python
from sympy import symbols, diff, limit, Function, simplify

x, h = symbols('x h')
f = x**3

# Derivative via limit definition
dq = (f.subs(x, x + h) - f) / h
deriv_limit = limit(dq, h, 0)
print("Limit definition:", deriv_limit)   # 3*x**2

# Derivative via diff
deriv_diff = diff(f, x)
print("diff():", deriv_diff)              # 3*x**2

assert simplify(deriv_limit - deriv_diff) == 0
```

Both methods confirm $\frac{d}{dx} x^3 = 3x^2$, and `simplify` verifies that the two expressions are identical.

### differentials (0.0s)

## Differentials

**Definition.** Let $f$ be a differentiable function of $x$. The *differential* of $x$, written $dx$, is an independent variable representing an arbitrary increment in $x$. The *differential of $f$*, written $df$ or $dy$, is defined by

$$df = f'(x)\,dx.$$

Unlike the derivative $f'(x) = dy/dx$, which is a limit of a ratio, $df$ and $dx$ are genuine quantities — infinitesimal proxies for the actual change $\Delta y = f(x + \Delta x) - f(x)$ and the step $\Delta x$. When $\Delta x$ is small, $df \approx \Delta y$, with the error being $O((\Delta x)^2)$.

**Worked Example.** Estimate $\sqrt{4.06}$ using differentials.

Set $f(x) = \sqrt{x}$, so $f'(x) = \tfrac{1}{2}x^{-1/2}$. Choose the base point $x = 4$ (where $f$ is easy to evaluate exactly) and let $dx = 0.06$. Then

$$df = f'(4)\,dx = \frac{1}{2\sqrt{4}}\cdot 0.06 = \frac{1}{4}\cdot 0.06 = 0.015.$$

Therefore $\sqrt{4.06} \approx f(4) + df = 2 + 0.015 = 2.015$. The true value is $\approx 2.01494$, so the error is less than $0.00006$ — demonstrating the quality of the linear approximation for small $dx$.

**Key Theorem (Linear Approximation via Differentials).** If $f$ is differentiable at $a$ and $\Delta x = dx$ is small, then

$$\Delta y \;=\; f'(a)\,dx \;+\; \epsilon\,dx, \qquad \text{where } \epsilon \to 0 \text{ as } dx \to 0.$$

*Proof sketch.* By the definition of the derivative, $f'(a) = \lim_{\Delta x \to 0} \Delta y/\Delta x$. Writing $\Delta y/\Delta x = f'(a) + \epsilon$ with $\epsilon \to 0$ and multiplying through by $\Delta x$ gives the result. $\square$

The differential $df = f'(a)\,dx$ is thus the *principal linear part* of $\Delta y$; it captures the dominant behavior while the $\epsilon\,dx$ remainder vanishes faster than $dx$.

**Lab Cell (SymPy).**

```python
import sympy as sp

x = sp.Symbol('x')
f = sp.sqrt(x)
dx = sp.Symbol('dx')

df = sp.diff(f, x) * dx
base = 4

approx = f.subs(x, base) + df.subs(x, base).subs(dx, sp.Rational(6, 100))
print("Differential approximation:", approx)          # 2 + 3/200
print("Exact value:", float(sp.sqrt(sp.Rational(406, 100))))
```

Running this cell confirms the approximation $2 + \tfrac{3}{200} = 2.015$ and invites experimentation with different base points and step sizes.

## Propagated Error

**Definition.** When a quantity $y$ is computed from one or more measured inputs $x_1, x_2, \ldots, x_n$, each carrying its own uncertainty $\delta x_i$, the *propagated error* $\delta y$ is the resulting uncertainty in $y$ induced by those input uncertainties. For a differentiable function $y = f(x_1, x_2, \ldots, x_n)$, the standard formula for propagated error is

$$
\delta y = \sqrt{\sum_{i=1}^{n} \left(\frac{\partial f}{\partial x_i}\right)^2 (\delta x_i)^2},
$$

assuming the input errors are independent and random. This expression follows from a first-order Taylor expansion of $f$ about the measured values, retaining only the linear terms and combining contributions in quadrature.

**Worked Example.** Suppose the period of a simple pendulum is measured as $T = 2.00 \pm 0.02\ \text{s}$, and we wish to determine the gravitational acceleration from $g = 4\pi^2 L / T^2$, where the length $L = 1.00 \pm 0.005\ \text{m}$ is also measured. The partial derivatives are

$$
\frac{\partial g}{\partial L} = \frac{4\pi^2}{T^2}, \qquad \frac{\partial g}{\partial T} = -\frac{8\pi^2 L}{T^3}.
$$

Evaluating at the measured values ($T = 2.00\ \text{s}$, $L = 1.00\ \text{m}$) gives $g \approx 9.87\ \text{m/s}^2$. The propagated error is

$$
\delta g = \sqrt{\left(\frac{4\pi^2}{T^2}\right)^2 (\delta L)^2 + \left(\frac{8\pi^2 L}{T^3}\right)^2 (\delta T)^2} \approx \sqrt{(9.87)^2(0.005)^2 + (9.87)^2(0.02)^2} \approx 0.20\ \text{m/s}^2.
$$

The fractional uncertainty $\delta g / g \approx 2\%$ is dominated by the timing error, as expected from the squared $T$ dependence.

**Key Theorem.** If $f$ is linear in each $x_i$, the propagated error formula is exact. For nonlinear $f$, the formula is a first-order approximation valid when $\delta x_i \ll \left|\partial f / \partial x_i\right|^{-1} \cdot f$; higher-order terms become significant only when input uncertainties are large relative to the scale over which $f$ curves.

**Lab Cell.**

```python
from sympy import *

L, T, dL, dT = symbols('L T dL dT', positive=True)
g = 4 * pi**2 * L / T**2

dg = sqrt((diff(g, L)**2 * dL**2 + diff(g, T)**2 * dT**2))
dg_val = dg.subs({L: 1.00, T: 2.00, dL: 0.005, dT: 0.02})
print("Propagated error in g:", float(dg_val.evalf()))
```

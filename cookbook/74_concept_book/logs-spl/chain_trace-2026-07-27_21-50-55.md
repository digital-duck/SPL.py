### flow_network (0.0s)

## Flow Network

**Definition.** A *flow network* is a directed graph $G = (V, E)$ equipped with a non-negative *capacity function* $c : E \to \mathbb{R}_{\geq 0}$, a designated *source* $s \in V$, and a designated *sink* $t \in V$. Given such a network, a *flow* is any assignment $f : E \to \mathbb{R}_{\geq 0}$ that obeys two rules at every edge and every interior vertex:

1. **Capacity constraint:** $0 \leq f(u,v) \leq c(u,v)$ for every edge $(u,v) \in E$.
2. **Flow conservation:** For every vertex $v \in V \setminus \{s, t\}$, total inflow equals total outflow:
$$\sum_{u:(u,v)\in E} f(u,v) \;=\; \sum_{w:(v,w)\in E} f(v,w).$$

The *value* of a flow is the net amount leaving the source: $|f| = \sum_{w:(s,w)\in E} f(s,w) - \sum_{u:(u,s)\in E} f(u,s)$.

**Worked Example.** Take $V = \{s, A, B, t\}$ with capacities $c(s,A)=3$, $c(s,B)=2$, $c(A,t)=2$, $c(B,t)=3$, $c(A,B)=1$. Set $f(s,A)=3$, $f(s,B)=2$, $f(A,t)=2$, $f(A,B)=1$, $f(B,t)=3$. At vertex $A$: inflow $= 3$, outflow $= 2 + 1 = 3$ ✓. At vertex $B$: inflow $= 2 + 1 = 3$, outflow $= 3$ ✓. Each edge respects its capacity, and $|f| = 3 + 2 = 5$.

**Key Theorem (Max-Flow Min-Cut).** The maximum achievable flow value from $s$ to $t$ equals the minimum total capacity of any set of edges whose removal disconnects $s$ from $t$. The proof identifies a maximum flow with a residual graph that admits no augmenting path; the vertices reachable from $s$ in that residual graph then define the separating edge set of minimum capacity.

**Lab Cell (NetworkX).**
```python
import networkx as nx

G = nx.DiGraph()
G.add_edge('s', 'A', capacity=3)
G.add_edge('s', 'B', capacity=2)
G.add_edge('A', 't', capacity=2)
G.add_edge('B', 't', capacity=3)
G.add_edge('A', 'B', capacity=1)

flow_value, flow_dict = nx.maximum_flow(G, 's', 't')
print("Max flow:", flow_value)          # Expected: 5
print("Flow on each edge:", flow_dict)
```

### capacity_function (0.0s)

## Capacity Function

**Definition.** Let $G = (V, E)$ be a directed graph. A *capacity function* is a map $c : E \to \mathbb{R}_{\geq 0}$ that assigns to each directed edge $(u, v) \in E$ a non-negative real number $c(u, v)$, called the *capacity* of that edge. For any ordered pair $(u, v)$ where no directed edge exists, we set $c(u, v) = 0$ by convention. Intuitively, $c(u, v)$ represents the maximum rate at which some commodity — data, fluid, traffic — can be transported from $u$ to $v$ per unit time.

A *flow network* is a quadruple $(G, c, s, t)$ where $s \in V$ is the designated *source* and $t \in V$ is the designated *sink*. Every quantitative question about routing — how much can be sent, where the bottleneck lies — is ultimately answered in terms of $c$. Subsequent sections introduce feasible flows and the Max-Flow Min-Cut Theorem; the present goal is to read and construct $c$ correctly.

**Worked Example.** Consider the network with vertex set $\{s, a, b, t\}$ and the following capacity assignments:

$$c(s,a) = 3,\quad c(s,b) = 2,\quad c(a,t) = 2,\quad c(b,t) = 3,\quad c(a,b) = 1.$$

All other ordered pairs, such as $(a, s)$ or $(b, a)$, receive capacity $0$ by the default convention. Observe that the total capacity leaving $s$ is $c(s,a)+c(s,b)=5$ and the total capacity entering $t$ is $c(a,t)+c(b,t)=5$ — a balance that will prove significant when maximum flows are studied. For now, verify that every listed value is non-negative and that unlisted directed pairs default to $0$.

**Theorem (Asymmetry of $c$).** In a capacity function, it is possible that $c(u,v) \neq c(v,u)$ for the same pair of vertices. Consequently, the direction of each edge is essential: reversing it may reduce the capacity to zero. This asymmetry is precisely what allows flow networks to model one-way pipes, directed highways, and asymmetric bandwidth links.

```python
# Lab: build and inspect a capacity function
capacities = {('s','a'): 3, ('s','b'): 2,
              ('a','t'): 2, ('b','t'): 3, ('a','b'): 1}

def c(u, v):
    return capacities.get((u, v), 0)

assert all(val >= 0 for val in capacities.values())

print(f"c(a,b) = {c('a','b')}, c(b,a) = {c('b','a')}")  # c(a,b) = 1, c(b,a) = 0

out_s = c('s', 'a') + c('s', 'b')
print(f"Total capacity leaving s: {out_s}")  # 5
```

### flow (0.0s)

## Flow

**Definition.** Let $f : \mathbb{R}^n \to \mathbb{R}^n$ be a smooth vector field and consider the autonomous ordinary differential equation

$$\dot{\mathbf{x}} = f(\mathbf{x}), \qquad \mathbf{x}(0) = \mathbf{x}_0.$$

Under the Picard–Lindelöf theorem, if $f$ is Lipschitz continuous on an open set $U \subseteq \mathbb{R}^n$, there exists a unique solution $\mathbf{x}(t)$ for $t$ in some interval $(-\varepsilon, \varepsilon)$. The **flow** of $f$ is the map

$$\phi : \mathbb{R} \times \mathbb{R}^n \to \mathbb{R}^n, \qquad \phi(t, \mathbf{x}_0) = \mathbf{x}(t),$$

where $\phi(t, \mathbf{x}_0)$ records the position at time $t$ of the trajectory that starts at $\mathbf{x}_0$. For each fixed $t$, the map $\phi_t(\cdot) := \phi(t, \cdot)$ is a diffeomorphism; the collection $\{\phi_t\}_{t \in \mathbb{R}}$ forms a one-parameter group satisfying $\phi_0 = \mathrm{id}$ and $\phi_{s+t} = \phi_s \circ \phi_t$.

**Worked example.** Take $n = 2$ and $f(x, y) = (-y,\; x)$. The system $\dot{x} = -y$, $\dot{y} = x$ has the explicit solution

$$\phi\!\left(t,\begin{pmatrix}x_0\\y_0\end{pmatrix}\right) = \begin{pmatrix}\cos t & -\sin t\\ \sin t & \cos t\end{pmatrix}\begin{pmatrix}x_0\\y_0\end{pmatrix}.$$

Every initial point traces a circle of radius $r = \sqrt{x_0^2 + y_0^2}$ with period $2\pi$. The group property is immediate: $\phi_{s+t} = R_{s+t} = R_s R_t = \phi_s \circ \phi_t$, where $R_\theta$ denotes rotation by $\theta$.

**Key theorem (Continuity of flow).** If $f$ is $C^k$ ($k \geq 1$), then the flow $\phi(t, \mathbf{x}_0)$ is $C^k$ jointly in $(t, \mathbf{x}_0)$. In particular, the Jacobian $\partial \phi_t / \partial \mathbf{x}_0$ satisfies the **variational equation**

$$\frac{d}{dt}\frac{\partial \phi_t}{\partial \mathbf{x}_0} = Df\!\left(\phi_t(\mathbf{x}_0)\right)\frac{\partial \phi_t}{\partial \mathbf{x}_0},$$

with initial condition $\partial \phi_0 / \partial \mathbf{x}_0 = I$. This linear ODE propagates small perturbations forward in time and is fundamental to stability analysis and Lyapunov exponents.

**Lab cell.**

```python
from sympy import symbols, cos, sin, Matrix, simplify

t, x0, y0 = symbols('t x0 y0', real=True)

# Flow of the rotation vector field f(x,y) = (-y, x)
phi = Matrix([cos(t)*x0 - sin(t)*y0,
              sin(t)*x0 + cos(t)*y0])

# Verify group property: phi(s+t) = phi_s(phi_t(x0,y0))
s = symbols('s', real=True)
phi_t = phi                                      # phi(t, (x0,y0))
phi_s_of_phi_t = phi_t.subs([(t, s), (x0, phi[0]), (y0, phi[1])])
phi_sum = phi.subs(t, s + t)

print(simplify(phi_s_of_phi_t - phi_sum))       # Expected: Matrix([0, 0])
```

### feasible_flow (0.0s)

## Feasible Flow

**Definition.** Let $G = (V, E)$ be a directed graph in which every edge $e \in E$ carries a *capacity* $c(e) \geq 0$ and a *lower bound* $\ell(e) \geq 0$. A **feasible flow** is a function $f : E \to \mathbb{R}_{\geq 0}$ satisfying two conditions:

1. **Capacity constraints:** $\ell(e) \leq f(e) \leq c(e)$ for every $e \in E$.
2. **Flow conservation:** For every internal node $v \in V \setminus \{s, t\}$,
$$\sum_{e \text{ into } v} f(e) \;=\; \sum_{e \text{ out of } v} f(e).$$

Here $s$ denotes the **source** (net producer of flow) and $t$ the **sink** (net consumer). When all lower bounds are zero, the feasibility condition reduces to the familiar capacity and conservation constraints of standard network flow.

**Worked Example.** Consider a network with nodes $\{s, a, b, t\}$ and edges:

| Edge | $\ell$ | $c$ |
|------|--------|-----|
| $s \to a$ | 1 | 4 |
| $s \to b$ | 0 | 3 |
| $a \to t$ | 2 | 5 |
| $b \to t$ | 1 | 3 |
| $a \to b$ | 0 | 2 |

Set $f(s \to a) = 3$, $f(s \to b) = 1$, $f(a \to t) = 3$, $f(b \to t) = 1$, $f(a \to b) = 0$. Verify: all values lie within $[\ell, c]$, node $a$ has inflow $3$ and outflow $3 + 0 = 3$ ✓, node $b$ has inflow $1$ and outflow $1$ ✓. This assignment is a feasible flow of value $|f| = f(s \to a) + f(s \to b) = 4$.

**Key Theorem (Feasibility Characterization).** A feasible flow exists in a network with lower bounds if and only if, in the *circulation* obtained by adding a return arc $t \to s$ with $\ell = c = \infty$, the auxiliary network constructed by replacing each bounded arc with a demand-shifted arc admits a *saturating* flow from a supersource $S$ to a supersink $T$. Equivalently, feasibility requires that for every subset $U \subseteq V$,

$$\sum_{e \text{ entering } U} c(e) \;\geq\; \sum_{e \text{ leaving } U} \ell(e).$$

This cut condition generalizes the max-flow min-cut theorem to networks with mandatory lower bounds.

**Lab Cell.**

```python
import sympy as sp

# Edge data: (tail, head, lower, capacity)
edges = [
    ('s','a', 1, 4),
    ('s','b', 0, 3),
    ('a','t', 2, 5),
    ('b','t', 1, 3),
    ('a','b', 0, 2),
]

# Proposed flow assignment
flow = {('s','a'): 3, ('s','b'): 1,
        ('a','t'): 3, ('b','t'): 1, ('a','b'): 0}

# Check capacity constraints
cap_ok = all(l <= flow[u,v] <= c for u,v,l,c in edges)

# Check conservation at internal nodes
def net_flow(node):
    inflow  = sum(flow[u,v] for u,v,_,_ in edges if v == node)
    outflow = sum(flow[u,v] for u,v,_,_ in edges if u == node)
    return sp.Rational(inflow - outflow)

conservation_ok = all(net_flow(n) == 0 for n in ['a','b'])

print("Capacity constraints satisfied:", cap_ok)
print("Flow conservation satisfied:", conservation_ok)
print("Flow value:", flow[('s','a')] + flow[('s','b')])
```

### residual_capacity (0.0s)

## Residual Capacity

**Definition.** Let $G = (V, E)$ be a directed graph representing a flow network, where each edge $(u, v) \in E$ carries a non-negative *capacity* $c(u, v) \geq 0$. A *flow* on $G$ is a function $f : V \times V \to \mathbb{R}$ satisfying capacity constraints $0 \leq f(u,v) \leq c(u,v)$ and conservation at every interior vertex. Given such a flow $f$, the **residual capacity** of an ordered pair $(u, v)$ is defined as

$$c_f(u, v) \;=\; c(u, v) - f(u, v).$$

Intuitively, $c_f(u,v)$ measures how much additional flow can still be pushed from $u$ to $v$ without violating the capacity constraint. The *residual network* $G_f = (V, E_f)$ retains every pair $(u,v)$ for which $c_f(u,v) > 0$, and crucially includes the *reverse* arc $(v, u)$ with $c_f(v, u) = f(u, v)$, representing the option to cancel previously committed flow.

**Worked example.** Consider a single edge $(s, t)$ with $c(s,t) = 10$ and current flow $f(s,t) = 7$. Then

$$c_f(s,t) = 10 - 7 = 3, \qquad c_f(t,s) = 7 - 0 = 7.$$

The forward residual arc says we may push up to $3$ additional units from $s$ to $t$; the backward arc says we may redirect up to $7$ units by canceling existing flow. Both arcs appear in $G_f$, even though $(t,s)$ was absent from the original network.

**Key theorem (Augmenting Path Theorem).** A flow $f$ in network $G$ is a *maximum flow* if and only if the residual network $G_f$ contains no directed path from the source $s$ to the sink $t$ (no *augmenting path*). Each such path can increase the total flow by $\delta = \min_{(u,v) \in P} c_f(u,v)$, the *bottleneck residual capacity* along path $P$.

*Proof sketch.* By the Max-Flow Min-Cut Theorem, any $s$-$t$ cut $\{S, T\}$ satisfies $|f| \leq c(S,T)$. If no augmenting path exists, the reachable set from $s$ in $G_f$ defines a cut whose capacity equals $|f|$, certifying optimality.

**Lab cell.**

```python
import sympy as sp

# Represent one edge: capacity and current flow
c, f_val = 10, 7

c_f_forward  = c - f_val          # residual capacity s→t
c_f_backward = f_val              # residual capacity t→s (cancellation)

bottleneck = sp.Rational(c_f_forward)  # symbolic form
print(f"c_f(s,t) = {c_f_forward}")     # 3
print(f"c_f(t,s) = {c_f_backward}")    # 7
print(f"Bottleneck along path: {bottleneck}")
```

### residual_graph (0.0s)

## Residual Graph

**Definition.** Let $G = (V, E)$ be a directed graph in which each edge $(u, v) \in E$ carries a non-negative capacity $c(u, v) \geq 0$. Given a feasible flow $f$ on $G$, the *residual graph* $G_f = (V, E_f)$ is a directed graph on the same vertex set whose edges encode the remaining freedom to route additional flow. For every edge $(u, v) \in E$, define the *residual capacity*

$$c_f(u, v) = c(u, v) - f(u, v).$$

The edge set $E_f$ contains the *forward edge* $(u, v)$ whenever $c_f(u, v) > 0$, and the *backward edge* $(v, u)$ whenever $f(u, v) > 0$. The backward edge represents the ability to cancel previously committed flow, effectively "un-routing" up to $f(u, v)$ units along the original direction.

**Worked Example.** Consider the network with vertices $\{s, a, t\}$ and edges $s \to a$ with capacity $4$, and $a \to t$ with capacity $3$. Suppose the current flow sends $f(s,a) = 3$ and $f(a,t) = 3$.

- Forward edge $s \to a$: residual capacity $4 - 3 = 1$.
- Backward edge $a \to s$: residual capacity $3$ (can cancel up to $3$ units).
- Forward edge $a \to t$: residual capacity $3 - 3 = 0$ (omitted from $G_f$).
- Backward edge $t \to a$: residual capacity $3$.

Thus $G_f$ contains $s \to a$ (capacity 1), $a \to s$ (capacity 3), and $t \to a$ (capacity 3). An *augmenting path* is any $s$-to-$t$ path in $G_f$; the Ford–Fulkerson algorithm iteratively finds such paths and pushes flow along them until none remains.

**Key Theorem (Max-Flow Min-Cut).** The value of a maximum flow from $s$ to $t$ equals the capacity of a minimum $s$-$t$ cut. The residual graph certifies optimality: a flow $f^*$ is maximum if and only if $G_{f^*}$ contains no augmenting path from $s$ to $t$.

**Lab Cell.**

```python
import sympy as sp
from sympy.combinatorics.named_groups import *

# Represent residual capacities symbolically
c, f_val = sp.symbols('c f', nonneg=True)

residual_forward  = sp.Max(c - f_val, 0)
residual_backward = sp.Max(f_val,     0)

print("Forward residual :", residual_forward)
print("Backward residual:", residual_backward)

# Concrete instance: c=4, f=3
print(residual_forward.subs([(c, 4), (f_val, 3)]))   # 1
print(residual_backward.subs([(c, 4), (f_val, 3)]))  # 3
```

### augmenting_path (0.0s)

## Augmenting Path

**Definition.** Let $G = (V, E)$ be a directed graph with a capacity function $c : E \to \mathbb{R}_{\geq 0}$ and a flow function $f : E \to \mathbb{R}_{\geq 0}$ satisfying $0 \leq f(e) \leq c(e)$ for every edge $e$. Given a source $s \in V$ and a sink $t \in V$, the *residual graph* $G_f = (V, E_f)$ is constructed by including a forward edge $u \to v$ with residual capacity $c(u,v) - f(u,v) > 0$ whenever flow can be increased, and a backward edge $v \to u$ with residual capacity $f(u,v) > 0$ whenever flow can be cancelled. An **augmenting path** is any simple path from $s$ to $t$ in $G_f$.

The *bottleneck capacity* of an augmenting path $P$ is

$$\delta(P) = \min_{e \in P} r(e),$$

where $r(e)$ denotes the residual capacity of edge $e$. Sending $\delta(P)$ additional units of flow along $P$ increases the total flow value by exactly $\delta(P)$ without violating any capacity constraint.

**Worked example.** Consider the network with edges $s \to u$, $s \to v$, $u \to t$, $v \to t$, and $u \to v$, all with capacity $10$, and suppose the current flow assigns $f(s \to u) = 10$, $f(u \to t) = 7$, $f(u \to v) = 3$, $f(v \to t) = 3$, $f(s \to v) = 0$. The total flow is $|f| = 7 + 3 = 10$. In $G_f$, the backward edge $u \to s$ has residual capacity $10$, the forward edge $s \to v$ has residual capacity $10$, and $v \to t$ has residual capacity $7$. The path $s \to v \to t$ is an augmenting path with $\delta = \min(10, 7) = 7$, raising $|f|$ to $17$.

**Theorem (Ford–Fulkerson).** A flow $f$ is a maximum flow if and only if there is no augmenting path from $s$ to $t$ in $G_f$.

*Proof sketch.* By the max-flow min-cut theorem, $|f|$ equals the capacity of every minimum $s$-$t$ cut. If an augmenting path exists, $|f|$ can be strictly increased, so $f$ is not maximum. Conversely, if no augmenting path exists, define the cut $S = \{v \in V : v \text{ is reachable from } s \text{ in } G_f\}$; every edge crossing from $S$ to $V \setminus S$ is saturated, so $|f|$ equals the cut capacity, confirming maximality. $\square$

**Lab cell.**

```python
from sympy import symbols, Rational

# Represent a tiny residual graph as a dict of dicts: r[u][v] = residual capacity
r = {'s': {'u': 0, 'v': 10},
     'u': {'s': 10, 't': 3, 'v': 7},
     'v': {'u': 0, 't': 7},
     't': {}}

def bfs_augmenting_path(r, s, t):
    from collections import deque
    parent = {s: None}
    queue = deque([s])
    while queue:
        node = queue.popleft()
        for nbr, cap in r[node].items():
            if nbr not in parent and cap > 0:
                parent[nbr] = node
                if nbr == t:
                    path = []
                    while nbr is not None:
                        path.append(nbr)
                        nbr = parent[nbr]
                    return list(reversed(path))
                queue.append(nbr)
    return None

print(bfs_augmenting_path(r, 's', 't'))  # ['s', 'v', 't']
```

### bfs_level_graph (15.3s)

## Bfs Level Graph

**Definition.** Let $G = (V, E)$ be a directed graph and $s \in V$ a designated source vertex. A *BFS level graph* (also called a *layered graph* or *level graph*) derived from $G$ with respect to $s$ is the subgraph $L_G = (V, E_L)$ where

$$E_L = \{ (u, v) \in E \mid \text{dist}(s, u) + 1 = \text{dist}(s, v) \},$$

and $\text{dist}(s, w)$ denotes the length of a shortest path from $s$ to $w$ in $G$. Equivalently, $L_G$ retains exactly those edges that strictly advance a vertex one level deeper in the BFS tree rooted at $s$. Back edges, cross edges between vertices at the same depth, and forward edges that skip levels are all discarded.

**Worked Example.** Consider the directed graph on vertices $\{s, a, b, c, t\}$ with edges $s \to a$, $s \to b$, $a \to c$, $b \to c$, $c \to t$, and $a \to t$. Running BFS from $s$ assigns levels $\ell(s)=0$, $\ell(a)=\ell(b)=1$, $\ell(c)=2$, $\ell(t)=3$. The edge $a \to t$ satisfies $\ell(a)+1 = 2 \ne 3 = \ell(t)$, so it is excluded. The retained edge set is $\{s \to a,\, s \to b,\, a \to c,\, b \to c,\, c \to t\}$, forming the level graph.

**Key Theorem (Dinic, 1970).** In the context of maximum network flow, let $G_f$ be the residual graph of a flow network at any intermediate stage, and let $L_{G_f}$ be its BFS level graph from source $s$ to sink $t$. A *blocking flow* in $L_{G_f}$—a flow that saturates at least one edge on every $s$-$t$ path in $L_{G_f}$—increases the length of the shortest augmenting path in the subsequent residual graph by at least one. Since path length is bounded by $|V|-1$, Dinic's algorithm terminates in $O(|V|)$ phases, yielding an overall complexity of $O(|V|^2 |E|)$.

**Lab Cell (SymPy / NetworkX).**

```python
import networkx as nx

G = nx.DiGraph()
G.add_edges_from([('s','a'),('s','b'),('a','c'),('b','c'),('c','t'),('a','t')])
source = 's'

dist = nx.single_source_shortest_path_length(G, source)
level_edges = [(u, v) for u, v in G.edges() if dist.get(v) == dist.get(u, -2) + 1]

L = nx.DiGraph()
L.add_edges_from(level_edges)
print("Level graph edges:", list(L.edges()))
```

### fattest_augmenting_path (18.2s)

## Fattest Augmenting Path

**Definition.** Let $G = (V, E)$ be a directed graph with a non-negative capacity function $c : E \to \mathbb{R}_{\geq 0}$, a source $s \in V$, and a sink $t \in V$. Given a feasible flow $f$, the *residual graph* $G_f$ assigns each edge a residual capacity $c_f(u,v) = c(u,v) - f(u,v)$. An *augmenting path* $P$ from $s$ to $t$ in $G_f$ carries flow limited by its *bottleneck capacity*:

$$\text{bn}(P) = \min_{(u,v) \in P} c_f(u,v).$$

The **fattest augmenting path** is the augmenting path $P^*$ that maximises this bottleneck:

$$P^* = \operatorname*{arg\,max}_{P \in \mathcal{P}} \text{bn}(P),$$

where $\mathcal{P}$ denotes all $s$-$t$ paths in $G_f$. Intuitively, the fattest path pushes the largest possible unit of flow in a single augmentation, reducing the number of iterations required to reach the maximum flow.

**Worked Example.** Consider the graph with edges and residual capacities:

$$s \xrightarrow{10} a \xrightarrow{3} t, \quad s \xrightarrow{5} b \xrightarrow{8} t, \quad s \xrightarrow{7} c \xrightarrow{7} t.$$

The three candidate paths and their bottlenecks are:

| Path | Bottleneck |
|---|---|
| $s \to a \to t$ | $\min(10,3) = 3$ |
| $s \to b \to t$ | $\min(5,8) = 5$ |
| $s \to c \to t$ | $\min(7,7) = 7$ |

The fattest path is $s \to c \to t$ with bottleneck $7$. Augmenting along it sends $7$ units, saturating both edges simultaneously.

**Key Theorem.** *(Capacity-Scaling Bound)* The fattest-path algorithm terminates in at most $O(E \log U)$ augmentation phases, where $U = \max_{e} c(e)$, and each phase requires $O(E \log V)$ time using a *maximum bottleneck spanning tree* (found via a modified Dijkstra or Prim sweep). Therefore the total runtime is $O(E^2 \log V \log U)$. In networks where $U$ is large but $E$ is small, this substantially outperforms naïve shortest-path augmentation, which may require $O(EU)$ augmentations.

**Lab Cell (SymPy / NetworkX).**

```python
import networkx as nx

G = nx.DiGraph()
G.add_weighted_edges_from([
    ('s','a',10), ('a','t',3),
    ('s','b', 5), ('b','t',8),
    ('s','c', 7), ('c','t',7),
], weight='capacity')

# NetworkX uses Edmonds-Karp internally; to demonstrate fattest-path selection:
paths = list(nx.all_simple_paths(G, 's', 't'))
fattest = max(paths,
              key=lambda p: min(G['u']['v']['capacity']
                                for u, v in zip(p, p[1:])))
bottleneck = min(G[u][v]['capacity'] for u, v in zip(fattest, fattest[1:]))
print(f"Fattest path: {fattest}, bottleneck = {bottleneck}")
# Output: Fattest path: ['s', 'c', 't'], bottleneck = 7
```

### shortest_augmenting_path (19.4s)

## Shortest Augmenting Path

**Definition.** Let $G = (V, E)$ be a directed network with source $s$, sink $t$, and non-negative integer capacities $c : E \to \mathbb{Z}_{\geq 0}$. Given a flow $f$, the *residual graph* $G_f$ contains a forward edge $(u,v)$ with residual capacity $c_f(u,v) = c(u,v) - f(u,v)$ whenever $c(u,v) - f(u,v) > 0$, and a backward edge $(v,u)$ with capacity $f(u,v)$ whenever $f(u,v) > 0$. An *augmenting path* is any simple $s$-$t$ path in $G_f$. Among all such paths, a *shortest augmenting path* is one that minimises the number of edges (hops). The **Edmonds–Karp algorithm** implements the Ford–Fulkerson method by selecting a shortest augmenting path at every iteration, discovered via breadth-first search (BFS) on $G_f$.

**Worked Example.** Consider the network below with $s = 1$, $t = 4$, and edges $(1,2,10)$, $(1,3,10)$, $(2,3,1)$, $(2,4,10)$, $(3,4,10)$ (format: $(u,v,c)$). Initially $f \equiv 0$.

- *Iteration 1.* BFS finds $s \to 2 \to 4$ (length 2). Bottleneck capacity $= \min(10,10)=10$. Push 10 units.
- *Iteration 2.* BFS finds $s \to 3 \to 4$ (length 2). Bottleneck $= 10$. Push 10 units.
- *Iteration 3.* No $s$-$t$ path remains in $G_f$. Total flow $= 20$.

**Key Theorem (Edmonds–Karp Complexity).** In any network with $|V|$ vertices and $|E|$ edges, the Edmonds–Karp algorithm terminates after at most $O(|V||E|)$ augmenting steps, giving an overall time complexity of $O(|V||E|^2)$. The proof relies on showing that the BFS distance $d_f(s,v)$ is monotonically non-decreasing across iterations for every vertex $v$. Because distances are bounded by $|V|-1$ and each edge can become *critical* (i.e., saturated) at most $O(|V|)$ times before the distance bound forces it out of the shortest-path tree, the number of augmentations is finite.

**Lab Cell.**

```python
import networkx as nx

G = nx.DiGraph()
edges = [(1,2,10),(1,3,10),(2,3,1),(2,4,10),(3,4,10)]
for u, v, cap in edges:
    G.add_edge(u, v, capacity=cap)

flow_value, flow_dict = nx.maximum_flow(G, 1, 4, flow_func=nx.algorithms.flow.edmonds_karp)
print("Max flow:", flow_value)          # Expected: 20
print("Flow on each edge:", flow_dict)
```

### edmonds_karp_polynomial_bounds (15.3s)

## Edmonds Karp Polynomial Bounds

**Definition.** The *Edmonds–Karp algorithm* is a specialization of the Ford–Fulkerson method for computing maximum flow in a network $G = (V, E)$ with capacities $c: E \to \mathbb{R}_{\geq 0}$. It selects augmenting paths by *breadth-first search* (BFS), ensuring that each chosen path is a shortest path (in terms of number of edges) from source $s$ to sink $t$. The algorithm terminates when no augmenting path exists, at which point the flow is maximum by the max-flow min-cut theorem.

The key polynomial guarantee is:

$$\text{Total augmentations} \leq O(VE),$$

yielding an overall time complexity of $O(VE^2)$, since each BFS costs $O(E)$.

---

**Worked Example.** Consider a network with $V = \{s, a, b, t\}$ and edges:

$$s \xrightarrow{10} a, \quad s \xrightarrow{10} b, \quad a \xrightarrow{1} b, \quad a \xrightarrow{10} t, \quad b \xrightarrow{10} t.$$

BFS from $s$ finds shortest paths first. The path $s \to a \to t$ (length 2) is chosen before $s \to a \to b \to t$ (length 3). After saturating two paths of capacity 10 each, the algorithm discovers the max flow is 20. Because BFS enforces shortest-path selection, it never wastes iterations cycling on long detours.

---

**Key Theorem** *(Edmonds–Karp, 1972).* *In any network with $|V|$ vertices and $|E|$ edges, the Edmonds–Karp algorithm performs at most $\frac{|V||E|}{2}$ augmentations, and thus terminates in $O(|V||E|^2)$ time.*

*Proof sketch.* Define the *distance label* $d(v)$ as the BFS shortest-path distance from $s$ to $v$ in the residual graph. One shows that $d(v)$ is monotonically non-decreasing across iterations. An edge $(u,v)$ becomes *critical* (saturated) only when $d(v) = d(u)+1$; before it can become critical again, $d(u)$ must increase by at least 2. Since $d(u) \leq |V|-1$, each edge is critical at most $O(|V|)$ times, giving at most $O(|V||E|)$ total augmentations. $\blacksquare$

---

**Lab Cell (SymPy).**

```python
import sympy as sp

V, E = sp.symbols('V E', positive=True, integer=True)
augmentations = V * E / 2
total_complexity = V * E**2
print("Max augmentations:", augmentations)
print("Time complexity:  O(", sp.simplify(total_complexity), ")")
```

This confirms that Edmonds–Karp is strongly polynomial: its running time depends only on the graph structure, not on capacity magnitudes, distinguishing it from naive Ford–Fulkerson on irrational capacities.

### advanced_maxflow_algorithms (19.8s)

## Advanced Maxflow Algorithms

**Definition.** Let $G = (V, E)$ be a directed graph with a capacity function $c : E \to \mathbb{R}_{\geq 0}$, a source $s \in V$, and a sink $t \in V$. A *flow* is a function $f : E \to \mathbb{R}_{\geq 0}$ satisfying capacity constraints $f(u,v) \leq c(u,v)$ and conservation $\sum_{u} f(u,v) = \sum_{w} f(v,w)$ for all $v \notin \{s,t\}$. The *maximum flow problem* asks for a flow that maximises $|f| = \sum_{v} f(s,v)$. Advanced algorithms improve upon the basic Ford–Fulkerson scheme—which can run in $O(|f^*| \cdot |E|)$ time—by exploiting structural properties of the residual graph $G_f$, where $c_f(u,v) = c(u,v) - f(u,v)$.

**Worked Example.** Consider the graph with $V = \{s, a, b, t\}$ and edges $s \to a$ (cap 10), $s \to b$ (cap 10), $a \to t$ (cap 10), $b \to t$ (cap 10), $a \to b$ (cap 1). The maximum flow is 20. The *Edmonds–Karp* algorithm (BFS-based augmenting paths) finds this in two saturating pushes along $s \to a \to t$ and $s \to b \to t$, each augmenting by 10. The redundant edge $a \to b$ is never used, illustrating that shortest augmenting paths avoid wasteful detours. Edmonds–Karp runs in $O(VE^2)$, independent of capacity values.

**Key Theorem (Dinic's Algorithm).** *Dinic's algorithm* constructs a *layered graph* $L_f$ via BFS on $G_f$, then finds a *blocking flow*—a flow saturating every $s$-$t$ path in $L_f$—using DFS with link-cut pruning. Each blocking-flow phase increases the shortest augmenting-path length by at least one, so there are at most $O(V)$ phases. Each phase costs $O(VE)$, giving an overall bound of $O(V^2 E)$. On unit-capacity graphs the bound improves to $O(E \sqrt{V})$, making Dinic's algorithm optimal for many practical instances including bipartite matching.

**Lab Cell.**

```python
from sympy import symbols, Rational

# Represent residual capacities as a dict and run one BFS augmentation
cap = {('s','a'): 10, ('s','b'): 10, ('a','t'): 10,
       ('b','t'): 10, ('a','b'): 1}

def bfs_path(cap, s, t):
    from collections import deque
    parent = {s: None}
    queue = deque([s])
    while queue:
        u = queue.popleft()
        for (x, y), c in cap.items():
            if x == u and y not in parent and c > 0:
                parent[y] = x
                if y == t:
                    path, node = [], t
                    while node != s:
                        path.append((parent[node], node))
                        node = parent[node]
                    return path[::-1]
                queue.append(y)
    return None

flow = 0
while (path := bfs_path(cap, 's', 't')):
    bottleneck = min(cap[e] for e in path)
    for (u, v) in path:
        cap[(u, v)] -= bottleneck
        cap.setdefault((v, u), 0)
        cap[(v, u)] += bottleneck
    flow += bottleneck

print(f"Maximum flow: {flow}")  # 20
```

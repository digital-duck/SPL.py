### difference_quotient (0.0s)

## Difference Quotient

**定义。** 设函数 $f$ 在包含点 $x$ 的某开区间上有定义，给定非零增量 $h$，称比值

$$
\frac{f(x+h)-f(x)}{h}
$$

为 $f$ 在点 $x$ 处关于增量 $h$ 的**差商**（difference quotient）。几何上，它等于曲线 $y=f(x)$ 上两点 $(x,\,f(x))$ 与 $(x+h,\,f(x+h))$ 所确定的割线（secant line）的斜率。

---

**例题。** 设 $f(x)=x^2$，计算差商并观察 $h\to 0$ 时的极限行为。

$$
\frac{f(x+h)-f(x)}{h}
=\frac{(x+h)^2-x^2}{h}
=\frac{x^2+2xh+h^2-x^2}{h}
=\frac{2xh+h^2}{h}
=2x+h.
$$

当 $h=1$ 时差商为 $2x+1$；当 $h=0.1$ 时差商为 $2x+0.1$。可以看出，随着 $h$ 趋近于零，差商趋近于 $2x$——这正是 $f(x)=x^2$ 的导数 $f'(x)=2x$。

---

**核心定理（导数的差商定义）。** 若极限

$$
\lim_{h\to 0}\frac{f(x+h)-f(x)}{h}
$$

存在且有限，则称 $f$ 在点 $x$ 处**可微**，该极限值记为 $f'(x)$，即 $f$ 在 $x$ 处的导数。差商是连接"平均变化率"与"瞬时变化率"这两个概念的桥梁：令 $h\to 0$，割线斜率趋近于切线斜率。可微性蕴含连续性，但反之不然（如 $f(x)=|x|$ 在 $x=0$ 处连续却不可微）。

---

**实验单元（SymPy）。**

```python
from sympy import symbols, limit, simplify

x, h = symbols('x h')
f = x**2

dq = (f.subs(x, x + h) - f) / h
dq_simplified = simplify(dq)
print("差商化简:", dq_simplified)          # 2*x + h

derivative = limit(dq, h, 0)
print("导数（h→0 的极限）:", derivative)   # 2*x
```

修改 `f` 为 `x**3` 或 `sin(x)`，观察差商的代数形式如何随函数变化，并验证极限结果与已知导数公式一致。

### limit (0.0s)

## 极限

**定义**

设函数 $f$ 定义在点 $a$ 的某个去心邻域内。若对任意 $\varepsilon > 0$，存在 $\delta > 0$，使得当 $0 < |x - a| < \delta$ 时，均有

$$|f(x) - L| < \varepsilon,$$

则称 $L$ 为 $f(x)$ 在 $x \to a$ 时的**极限**，记作

$$\lim_{x \to a} f(x) = L.$$

此定义（称为 $\varepsilon$-$\delta$ 定义）的核心在于：无论我们对 $f(x)$ 与 $L$ 之间的误差要求多么严苛（即 $\varepsilon$ 多么小），总能找到一个充分小的 $\delta$，使 $x$ 足够接近 $a$ 时误差得到控制。注意，$x = a$ 处 $f$ 是否有定义与极限值无关。

**例题**

证明 $\displaystyle\lim_{x \to 2}(3x - 1) = 5$。

**证明**：需要对给定的 $\varepsilon > 0$ 找到合适的 $\delta$。计算

$$|f(x) - 5| = |(3x - 1) - 5| = |3x - 6| = 3|x - 2|.$$

要使 $3|x - 2| < \varepsilon$，只需 $|x - 2| < \dfrac{\varepsilon}{3}$。故取 $\delta = \dfrac{\varepsilon}{3}$，则当 $0 < |x - 2| < \delta$ 时，

$$|f(x) - 5| = 3|x - 2| < 3\delta = \varepsilon. \qquad \square$$

**关键定理（极限的唯一性）**

若 $\displaystyle\lim_{x \to a} f(x)$ 存在，则其值唯一。

**证明思路**：设 $\lim_{x\to a}f(x)=L$ 且 $\lim_{x\to a}f(x)=M$，$L\neq M$。取 $\varepsilon=\dfrac{|L-M|}{2}>0$，则由定义可得

$$|L - M| \leq |f(x)-L| + |f(x)-M| < \varepsilon + \varepsilon = |L-M|,$$

矛盾，故 $L = M$。$\square$

**实验单元（SymPy）**

```python
from sympy import symbols, limit, oo

x = symbols('x')

# 验证上述例题
print(limit(3*x - 1, x, 2))          # 输出: 5

# 探索经典极限
print(limit((1 + 1/x)**x, x, oo))    # 输出: E（即自然常数 e）
print(limit(sin(x)/x, x, 0))         # 输出: 1
```

运行以上代码，观察 SymPy 如何通过符号运算直接给出极限值，从而验证 $\varepsilon$-$\delta$ 推导的正确性。

### derivative_at_a_point (0.0s)

## Derivative At A Point

**定义**

设函数 $f$ 在点 $x = a$ 的某个开区间内有定义。若极限

$$
f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}
$$

存在且有限，则称 $f$ 在点 $a$ 处**可微**，并将此极限值称为 $f$ 在 $a$ 处的**导数**，记作 $f'(a)$，亦可写作 $\left.\dfrac{df}{dx}\right|_{x=a}$。几何上，$f'(a)$ 等于曲线 $y = f(x)$ 在点 $(a,\, f(a))$ 处切线的斜率。

---

**例题**

设 $f(x) = x^2$，求 $f'(3)$。

$$
f'(3) = \lim_{h \to 0} \frac{(3+h)^2 - 3^2}{h} = \lim_{h \to 0} \frac{9 + 6h + h^2 - 9}{h} = \lim_{h \to 0} \frac{6h + h^2}{h} = \lim_{h \to 0}(6 + h) = 6.
$$

因此，抛物线 $y = x^2$ 在点 $(3,\, 9)$ 处的切线斜率为 $6$，切线方程为 $y - 9 = 6(x - 3)$，即 $y = 6x - 9$。

---

**关键定理**

> **定理（可微蕴含连续）**：若 $f$ 在点 $a$ 处可微，则 $f$ 在点 $a$ 处连续。

**证明思路**：利用恒等式 $f(a+h) - f(a) = \dfrac{f(a+h)-f(a)}{h} \cdot h$，对两端取 $h \to 0$ 的极限。左端极限即为 $f(a+h) - f(a)$ 趋向的值；右端由极限的乘法法则得 $f'(a) \cdot 0 = 0$，故 $\lim_{h\to 0} f(a+h) = f(a)$，连续性得证。注意逆命题不成立，$f(x) = |x|$ 在 $x=0$ 处连续但不可微即为反例。$\blacksquare$

---

**实验单元（SymPy）**

```python
from sympy import symbols, limit, sqrt

x, h = symbols('x h')

f = x**2
dfdx_at_3 = limit((f.subs(x, 3 + h) - f.subs(x, 3)) / h, h, 0)
print("f'(3) =", dfdx_at_3)          # 输出：6

# 验证 |x| 在 0 处不可微
g = sqrt(x**2)
dg_at_0 = limit((g.subs(x, h) - g.subs(x, 0)) / h, h, 0)
print("g'(0) 的极限：", dg_at_0)     # 输出：nan 或 zoo，表明极限不存在
```

运行上述代码，观察 $f'(3) = 6$ 被精确计算，而 $|x|$ 在原点的差商极限不存在，从而以符号计算直观验证定理中的反例。

### instantaneous_rate_of_change (0.0s)

## 瞬时变化率

**定义**

设函数 $f$ 在点 $x = a$ 的某邻域内有定义。若极限

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$

存在且有限，则称此极限值为 $f$ 在 $x = a$ 处的**瞬时变化率**，亦即 $f$ 在该点的导数。差商 $\dfrac{f(a+h)-f(a)}{h}$ 表示割线斜率，当 $h \to 0$ 时，割线趋近于曲线在 $x = a$ 处的切线，斜率趋近于瞬时变化率。

**例题**

设 $f(x) = x^2$，求 $f$ 在 $x = 3$ 处的瞬时变化率。

$$f'(3) = \lim_{h \to 0} \frac{(3+h)^2 - 9}{h} = \lim_{h \to 0} \frac{9 + 6h + h^2 - 9}{h} = \lim_{h \to 0} (6 + h) = 6.$$

几何意义：抛物线 $y = x^2$ 在点 $(3,\,9)$ 处切线斜率为 $6$，即函数在该点每增加一个单位 $x$，函数值瞬时增加约 $6$ 个单位。

**核心定理**

> **可微蕴含连续性**：若 $f'(a)$ 存在，则 $f$ 在 $x = a$ 处连续。

*证明概要*：由于

$$f(a+h) - f(a) = \frac{f(a+h)-f(a)}{h} \cdot h \xrightarrow{h\to 0} f'(a) \cdot 0 = 0,$$

故 $\lim_{h\to 0} f(a+h) = f(a)$，连续性成立。反之不然：$f(x) = |x|$ 在 $x=0$ 处连续但不可微。

**实验单元（SymPy）**

```python
from sympy import symbols, limit, diff, simplify

x, h = symbols('x h')
f = x**2

# 用极限定义计算瞬时变化率
difference_quotient = (f.subs(x, x + h) - f) / h
iroc_limit = limit(difference_quotient, h, 0)
print("极限定义:", iroc_limit)          # 输出：2*x

# 用 diff 直接求导验证
iroc_diff = diff(f, x)
print("diff 验证:", iroc_diff)          # 输出：2*x

# 在 x=3 处求值
print("x=3 处的值:", iroc_diff.subs(x, 3))  # 输出：6
```

运行以上代码，可验证两种方法给出相同结果，加深对瞬时变化率作为极限过程的直觉。

### population_growth_rate (17.5s)

## Population Growth Rate

### 定义

**种群增长率**（Population Growth Rate）描述种群数量随时间变化的快慢程度。设 $N(t)$ 为时刻 $t$ 时的种群数量，则**绝对增长率**定义为：

$$\frac{dN}{dt}$$

而**相对增长率**（或称比增长率）定义为单位个体的增长速率：

$$r(t) = \frac{1}{N}\frac{dN}{dt}$$

在最简单的**指数增长模型**中，$r$ 为常数，满足：

$$\frac{dN}{dt} = rN, \quad N(0) = N_0$$

其解为 $N(t) = N_0 e^{rt}$。当 $r > 0$ 时种群增长，$r < 0$ 时种群衰减，$r = 0$ 时种群稳定。

---

### 具体例子

设某细菌种群初始数量为 $N_0 = 500$，比增长率 $r = 0.3\ \text{h}^{-1}$。求 $t = 4$ 小时后的种群数量及该时刻的绝对增长率。

**解：**

$$N(4) = 500 \cdot e^{0.3 \times 4} = 500 \cdot e^{1.2} \approx 500 \times 3.320 = 1660$$

$$\left.\frac{dN}{dt}\right|_{t=4} = rN(4) = 0.3 \times 1660 \approx 498 \ \text{个/小时}$$

即在第 4 小时，种群每小时新增约 498 个个体。

---

### 关键定理：逻辑斯谛增长

纯指数模型忽略了资源限制。引入**环境容纳量** $K$，得到**逻辑斯谛方程**（Logistic Equation）：

$$\frac{dN}{dt} = rN\left(1 - \frac{N}{K}\right)$$

**定理**：上述方程的解为

$$N(t) = \frac{K}{1 + \left(\dfrac{K - N_0}{N_0}\right)e^{-rt}}$$

当 $N \ll K$ 时近似为指数增长；当 $N \to K$ 时增长率趋于零，种群趋于稳定平衡点 $N^* = K$。

---

### 实验单元（SymPy）

```python
import sympy as sp

t, r, K, N0 = sp.symbols('t r K N0', positive=True)
N = sp.Function('N')

ode = sp.Eq(N(t).diff(t), r * N(t) * (1 - N(t)/K))
sol = sp.dsolve(ode, N(t), ics={N(0): N0})
sp.pprint(sol)

# 数值示例：r=0.3, K=2000, N0=500
numerical = sol.rhs.subs({r: 0.3, K: 2000, N0: 500})
sp.pprint(sp.simplify(numerical.subs(t, 4)))
```

运行上述代码，可验证逻辑斯谛方程的解析解，并对比指数模型与逻辑斯谛模型在资源受限条件下的行为差异。

### rate_of_change (16.7s)

## Rate Of Change

**定义。** 设函数 $f$ 在包含点 $a$ 的开区间上有定义。$f$ 在 $x = a$ 处的**瞬时变化率**定义为极限

$$
f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h},
$$

若该极限存在，则称 $f$ 在 $a$ 处**可微**，并将 $f'(a)$ 称为 $f$ 在该点的导数。商式 $\dfrac{f(a+h)-f(a)}{h}$ 称为**差商**，几何上表示过点 $(a,f(a))$ 与 $(a+h,f(a+h))$ 的割线斜率；当 $h \to 0$ 时，割线趋近于曲线在 $x=a$ 处的切线，斜率即为 $f'(a)$。

**典型例题。** 设 $f(x) = x^2$，求 $f'(3)$。

由定义出发：

$$
f'(3) = \lim_{h \to 0} \frac{(3+h)^2 - 3^2}{h} = \lim_{h \to 0} \frac{9 + 6h + h^2 - 9}{h} = \lim_{h \to 0} \frac{6h + h^2}{h} = \lim_{h \to 0}(6 + h) = 6.
$$

故曲线 $y = x^2$ 在点 $(3,9)$ 处的切线斜率为 $6$，切线方程为 $y - 9 = 6(x-3)$，即 $y = 6x - 9$。

**核心定理（可微性蕴含连续性）。** 若 $f$ 在 $x=a$ 处可微，则 $f$ 在 $x=a$ 处连续。

*证明概要。* 注意到

$$
f(a+h) - f(a) = \frac{f(a+h)-f(a)}{h} \cdot h.
$$

当 $h \to 0$ 时，右侧第一个因子趋向 $f'(a)$（有限值），第二个因子趋向 $0$，故乘积趋向 $0$，即 $\lim_{h \to 0} f(a+h) = f(a)$，连续性得证。$\square$

注意逆命题不成立：$f(x)=|x|$ 在 $x=0$ 处连续但不可微。

**实验单元（SymPy）。**

```python
from sympy import symbols, diff, limit, simplify

x, h = symbols('x h')
f = x**2

# 用极限定义验证导数
difference_quotient = (f.subs(x, x + h) - f) / h
derivative_limit = limit(difference_quotient, h, 0)
print("差商极限:", derivative_limit)          # 输出: 2*x

# 用 diff 直接求导并在 x=3 处取值
print("f'(3) =", diff(f, x).subs(x, 3))     # 输出: 6
```

运行上述代码，两种方法均给出 $f'(x)=2x$，在 $x=3$ 处值为 $6$，与手算结果完全吻合。

### limit (0.0s)

## 极限

**定义**

设函数 $f$ 定义在点 $a$ 的某个去心邻域内。若对任意 $\varepsilon > 0$，存在 $\delta > 0$，使得当 $0 < |x - a| < \delta$ 时，均有

$$|f(x) - L| < \varepsilon,$$

则称 $L$ 为 $f(x)$ 在 $x \to a$ 时的**极限**，记作

$$\lim_{x \to a} f(x) = L.$$

此定义（称为 $\varepsilon$-$\delta$ 定义）的核心在于：无论我们对 $f(x)$ 与 $L$ 之间的误差要求多么严苛（即 $\varepsilon$ 多么小），总能找到一个充分小的 $\delta$，使 $x$ 足够接近 $a$ 时误差得到控制。注意，$x = a$ 处 $f$ 是否有定义与极限值无关。

**例题**

证明 $\displaystyle\lim_{x \to 2}(3x - 1) = 5$。

**证明**：需要对给定的 $\varepsilon > 0$ 找到合适的 $\delta$。计算

$$|f(x) - 5| = |(3x - 1) - 5| = |3x - 6| = 3|x - 2|.$$

要使 $3|x - 2| < \varepsilon$，只需 $|x - 2| < \dfrac{\varepsilon}{3}$。故取 $\delta = \dfrac{\varepsilon}{3}$，则当 $0 < |x - 2| < \delta$ 时，

$$|f(x) - 5| = 3|x - 2| < 3\delta = \varepsilon. \qquad \square$$

**关键定理（极限的唯一性）**

若 $\displaystyle\lim_{x \to a} f(x)$ 存在，则其值唯一。

**证明思路**：设 $\lim_{x\to a}f(x)=L$ 且 $\lim_{x\to a}f(x)=M$，$L\neq M$。取 $\varepsilon=\dfrac{|L-M|}{2}>0$，则由定义可得

$$|L - M| \leq |f(x)-L| + |f(x)-M| < \varepsilon + \varepsilon = |L-M|,$$

矛盾，故 $L = M$。$\square$

**实验单元（SymPy）**

```python
from sympy import symbols, limit, oo

x = symbols('x')

# 验证上述例题
print(limit(3*x - 1, x, 2))          # 输出: 5

# 探索经典极限
print(limit((1 + 1/x)**x, x, oo))    # 输出: E（即自然常数 e）
print(limit(sin(x)/x, x, 0))         # 输出: 1
```

运行以上代码，观察 SymPy 如何通过符号运算直接给出极限值，从而验证 $\varepsilon$-$\delta$ 推导的正确性。

### secant_line (17.8s)

## Secant Line

**定义。** 设函数 $f$ 在包含点 $a$ 与 $b$（$a \neq b$）的区间上有定义。过曲线 $y = f(x)$ 上两点 $P = (a,\, f(a))$ 与 $Q = (b,\, f(b))$ 的直线称为 $f$ 在该区间上的**割线**（secant line）。其斜率由**差商**给出：

$$m_{\sec} = \frac{f(b) - f(a)}{b - a}.$$

若令 $h = b - a$，则可将差商改写为

$$m_{\sec} = \frac{f(a + h) - f(a)}{h}, \quad h \neq 0.$$

割线的几何意义在于：它以有限步长逼近曲线的局部走势，是微分学中切线概念的基础前驱。

---

**例题。** 设 $f(x) = x^2$，取 $a = 1$，$b = 3$。

计算割线斜率：

$$m_{\sec} = \frac{f(3) - f(1)}{3 - 1} = \frac{9 - 1}{2} = 4.$$

过点 $P = (1, 1)$，割线方程为：

$$y - 1 = 4(x - 1) \implies y = 4x - 3.$$

可验证：当 $x = 3$ 时，$y = 4(3) - 3 = 9 = f(3)$，割线确实经过点 $Q = (3, 9)$。

---

**关键定理（割线极限与导数）。** 若 $f$ 在点 $a$ 处可微，则当 $b \to a$（即 $h \to 0$）时，割线斜率趋近于切线斜率：

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}.$$

**证明思路：** 差商 $\dfrac{f(a+h)-f(a)}{h}$ 对每个固定的 $h \neq 0$ 均有意义，且随 $h \to 0$ 给出一个极限（若该极限存在），此极限即为导数的定义。割线在几何上"旋转"逼近切线，斜率序列收敛正是可微性的精确表述。

---

**实验单元（SymPy）。**

```python
from sympy import symbols, simplify

x, a, h = symbols('x a h')
f = x**2

# 计算差商
secant_slope = simplify((f.subs(x, a + h) - f.subs(x, a)) / h)
print("割线斜率：", secant_slope)   # 输出：2*a + h

# 令 h → 0，得到导数
from sympy import limit
derivative = limit(secant_slope, h, 0)
print("导数 f'(a)：", derivative)   # 输出：2*a
```

运行上述代码，可直观验证：差商 $2a + h$ 在 $h \to 0$ 时确实趋近于 $f'(a) = 2a$，印证了割线向切线过渡的过程。

### tangent_line (16.1s)

## 切线

**定义**

设函数 $f$ 在点 $x = a$ 处可微，则曲线 $y = f(x)$ 在点 $P = (a, f(a))$ 处的**切线**是过 $P$ 点且斜率为 $f'(a)$ 的直线。其方程为

$$y - f(a) = f'(a)(x - a).$$

几何上，切线是割线的极限位置：当第二点 $Q = (a+h,\, f(a+h))$ 沿曲线趋向 $P$ 时，割线 $PQ$ 的斜率

$$m_{\text{割}} = \frac{f(a+h)-f(a)}{h}$$

在 $h \to 0$ 时趋向导数 $f'(a)$，故切线捕捉了曲线在该点处的瞬时变化率。

---

**例题**

求曲线 $y = x^2$ 在点 $(2, 4)$ 处的切线方程。

首先计算导数：$f'(x) = 2x$，故 $f'(2) = 4$。代入点斜式：

$$y - 4 = 4(x - 2) \implies y = 4x - 4.$$

验证：直线过 $(2,4)$ ✓，斜率为 $4$ ✓。可以注意到，在 $x = 2$ 附近，切线与抛物线几乎重合，这正是局部线性化的核心思想。

---

**关键定理**

**定理（切线存在性）**：若 $f$ 在 $x = a$ 处可微，则切线唯一存在，且切线是 $f$ 在 $a$ 点处的最佳一阶线性近似，即

$$f(x) \approx f(a) + f'(a)(x-a), \quad x \to a.$$

更精确地，误差满足 $f(x) - [f(a) + f'(a)(x-a)] = o(x-a)$（$x \to a$ 时为高阶无穷小），这也是可微性的等价刻画。

---

**实验单元（SymPy）**

```python
import sympy as sp

x = sp.Symbol('x')
f = x**2

a = 2
tangent = f.subs(x, a) + sp.diff(f, x).subs(x, a) * (x - a)
print("切线方程：y =", sp.expand(tangent))

# 绘图验证
sp.plot(f, tangent, (x, 0, 4),
        legend=True, title='y=x² 及其在 x=2 处的切线')
```

运行上述代码，可在图形中直观观察切线与曲线在 $x = 2$ 附近的贴合程度，并尝试修改 $a$ 的值，观察切线斜率随之变化的规律。

### derivative (20.6s)

## 导数

**定义。** 设函数 $f$ 在点 $x_0$ 的某邻域内有定义。若极限

$$f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h}$$

存在且有限，则称 $f$ 在点 $x_0$ **可微**，并将该极限值称为 $f$ 在 $x_0$ 处的**导数**（derivative）。几何上，$f'(x_0)$ 即曲线 $y = f(x)$ 在点 $(x_0,\, f(x_0))$ 处切线的斜率；物理上，若 $f(t)$ 表示位移，则 $f'(t)$ 表示瞬时速度。

---

**例题。** 求 $f(x) = x^2$ 在 $x_0 = 3$ 处的导数。

按定义展开差商：

$$\frac{f(3+h) - f(3)}{h} = \frac{(3+h)^2 - 9}{h} = \frac{9 + 6h + h^2 - 9}{h} = 6 + h.$$

令 $h \to 0$，得

$$f'(3) = \lim_{h \to 0}(6 + h) = 6.$$

几何验证：曲线 $y = x^2$ 在点 $(3, 9)$ 处的切线方程为 $y - 9 = 6(x - 3)$，即 $y = 6x - 9$。

---

**定理（可微必连续）。** 若 $f$ 在 $x_0$ 处可微，则 $f$ 在 $x_0$ 处连续。

**证明思路。** 将函数增量写成

$$f(x_0 + h) - f(x_0) = \frac{f(x_0+h)-f(x_0)}{h} \cdot h.$$

当 $h \to 0$ 时，右端第一个因子趋向 $f'(x_0)$（有限值），第二个因子 $h \to 0$，故乘积趋向 $0$，即 $\lim_{h\to 0} f(x_0+h) = f(x_0)$，连续性得证。$\blacksquare$

注意逆命题不成立：$f(x) = |x|$ 在 $x = 0$ 处连续但不可微，因为左右极限 $\lim_{h\to 0^-} h/|h| = -1 \neq 1 = \lim_{h\to 0^+} h/|h|$ 不相等。

---

**实验单元（SymPy）。**

```python
import sympy as sp

x, h = sp.symbols('x h')
f = x**2

# 用极限定义计算导数
diff_quot = (f.subs(x, x + h) - f) / h
derivative = sp.limit(diff_quot, h, 0)
print(derivative)          # 输出：2*x

# 符号求导验证
print(sp.diff(f, x))       # 输出：2*x
```

运行上述代码，两种方式均输出 $2x$，与幂函数求导公式 $(x^n)' = nx^{n-1}$（取 $n=2$）完全一致。

### differential_calculus (20.7s)

## 微分学

**定义**

设函数 $f$ 在点 $x_0$ 的某邻域内有定义。若极限

$$f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$$

存在且有限，则称 $f$ 在 $x_0$ 处**可微**，该极限值称为 $f$ 在 $x_0$ 处的**导数**（derivative）。几何上，$f'(x_0)$ 即曲线 $y = f(x)$ 在点 $(x_0, f(x_0))$ 处切线的斜率；物理上，若 $f(t)$ 表示位移，则 $f'(t)$ 表示瞬时速度。微分 $\mathrm{d}f = f'(x)\,\mathrm{d}x$ 给出函数在无穷小变化 $\mathrm{d}x$ 下的线性近似。

**例题**

求 $f(x) = x^3 - 2x$ 在 $x_0 = 1$ 处的导数，并写出切线方程。

由定义，

$$f'(x) = \lim_{\Delta x \to 0} \frac{(x+\Delta x)^3 - 2(x+\Delta x) - x^3 + 2x}{\Delta x}.$$

展开分子：$(x+\Delta x)^3 = x^3 + 3x^2\Delta x + 3x(\Delta x)^2 + (\Delta x)^3$，化简后分子变为 $(3x^2 - 2)\Delta x + O((\Delta x)^2)$，除以 $\Delta x$ 并令 $\Delta x \to 0$，得

$$f'(x) = 3x^2 - 2.$$

故 $f'(1) = 3(1)^2 - 2 = 1$，切点为 $(1, -1)$，切线方程为 $y = x - 2$。

**关键定理**

**链式法则**：若 $g$ 在 $x$ 处可微，$f$ 在 $g(x)$ 处可微，则复合函数 $h = f \circ g$ 在 $x$ 处可微，且

$$h'(x) = f'\!\bigl(g(x)\bigr) \cdot g'(x).$$

证明思路：令 $\Delta u = g(x+\Delta x) - g(x)$，当 $g'(x) \neq 0$ 时，

$$\frac{\Delta h}{\Delta x} = \frac{f(u+\Delta u)-f(u)}{\Delta u} \cdot \frac{\Delta u}{\Delta x} \xrightarrow{\Delta x \to 0} f'(u)\cdot g'(x).$$

$g'(x) = 0$ 的情形需单独处理，结论不变。

**实验单元（SymPy）**

```python
from sympy import symbols, diff, factor

x = symbols('x')
f = x**3 - 2*x

# 求导
df = diff(f, x)
print("f'(x) =", df)          # 3*x**2 - 2

# 链式法则示例：h(x) = sin(x^3)
from sympy import sin
h = sin(x**3)
print("h'(x) =", diff(h, x))  # 3*x**2*cos(x**3)

# 在 x=1 处求值
print("f'(1) =", df.subs(x, 1))  # 1
```

运行上述代码，可验证手算结果，并直观体验链式法则在复合函数求导中的应用。

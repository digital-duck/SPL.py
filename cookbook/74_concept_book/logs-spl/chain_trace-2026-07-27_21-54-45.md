## Matching

**Definition.** Let $G = (V, E)$ be an undirected graph. A *matching* in $G$ is a set $M \subseteq E$ of edges such that no two edges in $M$ share a common endpoint. Formally,

$$\forall\, e_1, e_2 \in M,\; e_1 \neq e_2 \implies e_1 \cap e_2 = \emptyset.$$

A vertex $v$ is *matched* if some edge in $M$ is incident to $v$; otherwise $v$ is *free* (or *exposed*). A matching is *perfect* if every vertex is matched, and *maximum* if no matching of larger cardinality exists in $G$.

---

**Worked Example.** Consider the graph $G$ with vertex set $V = \{1, 2, 3, 4, 5, 6\}$ and edge set

$$E = \{\{1,2\},\{1,3\},\{2,4\},\{3,4\},\{4,5\},\{5,6\}\}.$$

The set $M_1 = \{\{1,2\},\{3,4\},\{5,6\}\}$ is a matching of size 3: vertices 1, 2, 3, 4, 5, and 6 are all matched. Since $|M_1| = 3 = |V|/2$, this is a perfect matching (and hence also maximum). By contrast, $M_2 = \{\{1,3\},\{2,4\}\}$ is a valid matching of size 2, leaving vertices 5 and 6 free; it is neither perfect nor maximum.

---

**Key Theorem (Berge, 1957).** A matching $M$ in a graph $G$ is maximum if and only if $G$ contains no *$M$-augmenting path* — a path that begins and ends at free vertices and whose edges alternate between $E \setminus M$ and $M$.

*Proof sketch.* If an augmenting path $P$ exists, the symmetric difference $M \oplus E(P)$ is a matching of size $|M|+1$, contradicting maximality. Conversely, if no augmenting path exists, one shows by contradiction that $M$ must be maximum. $\square$

This theorem underpins the Blossom algorithm, which finds a maximum matching in $O(|V|^3)$ time.

### maximum_flow (0.0s)

## Maximum Flow

**Definition.** Let $G = (V, E)$ be a directed graph with a designated *source* $s \in V$ and *sink* $t \in V$. A *capacity function* $c : E \to \mathbb{R}_{\geq 0}$ assigns a non-negative upper bound to each edge. A *flow* is a function $f : E \to \mathbb{R}_{\geq 0}$ satisfying two conditions:

1. **Capacity constraint**: $0 \leq f(u,v) \leq c(u,v)$ for all $(u,v) \in E$.
2. **Flow conservation**: for every vertex $v \notin \{s, t\}$,
$$\sum_{u:(u,v)\in E} f(u,v) = \sum_{w:(v,w)\in E} f(v,w).$$

The *value* of the flow is $|f| = \sum_{w:(s,w)\in E} f(s,w)$, the total flow leaving the source. The **maximum flow problem** asks for a flow $f^*$ that maximises $|f|$ subject to the above constraints.

**Worked Example.** Consider the graph with vertices $\{s, a, b, t\}$ and directed edges:

$$s \xrightarrow{10} a, \quad s \xrightarrow{8} b, \quad a \xrightarrow{5} b, \quad a \xrightarrow{7} t, \quad b \xrightarrow{9} t.$$

One feasible flow assigns $f(s,a)=7$, $f(s,b)=8$, $f(a,b)=0$, $f(a,t)=7$, $f(b,t)=8$, giving $|f|=15$. No augmenting path from $s$ to $t$ remains in the residual graph, so $|f^*|=15$.

**Key Theorem (Max-Flow Min-Cut).** For any network $(G, c, s, t)$,

$$\max_{f} |f| = \min_{(S,T)} \sum_{\substack{u \in S,\, v \in T \\ (u,v)\in E}} c(u,v),$$

where the minimum is taken over all *$s$–$t$ cuts* $(S, T)$, i.e., partitions $V = S \cup T$ with $s \in S$ and $t \in T$. The theorem follows from the Ford–Fulkerson method: the algorithm terminates precisely when no augmenting path exists in the residual graph, at which point the set of vertices reachable from $s$ in that graph defines a minimum cut.

### bipartite_matching (17.8s)

## Bipartite Matching

**Definition.** A *bipartite graph* is a graph $G = (U \cup V, E)$ whose vertex set is partitioned into two disjoint sets $U$ and $V$ such that every edge $e \in E$ connects a vertex in $U$ to a vertex in $V$. A *matching* $M \subseteq E$ is a subset of edges in which no two edges share an endpoint. A *maximum matching* is a matching of largest possible cardinality $|M|$. When $|M| = |U| = |V|$, the matching is *perfect*.

Bipartite matching formalises assignment problems that arise throughout science and engineering: assigning tasks to workers, pairing students to advisors, or coupling chemical reactants to reaction sites.

**Worked Example.** Consider the assignment problem with workers $U = \{w_1, w_2, w_3\}$ and jobs $V = \{j_1, j_2, j_3\}$, where each worker is qualified for a subset of jobs:

$$E = \{(w_1,j_1),\,(w_1,j_2),\,(w_2,j_2),\,(w_3,j_2),\,(w_3,j_3)\}.$$

One valid matching is $M = \{(w_1,j_1),(w_2,j_2),(w_3,j_3)\}$, which assigns every worker to a distinct job. Since $|M| = 3 = |U|$, this matching is perfect. No larger matching is possible because $|U|$ is an upper bound on $|M|$.

**Key Theorem (König, 1931).** *In any bipartite graph, the size of a maximum matching equals the size of a minimum vertex cover.*

A *vertex cover* is a set $C \subseteq U \cup V$ such that every edge has at least one endpoint in $C$. König's theorem guarantees that the two apparently unrelated combinatorial quantities are always equal in bipartite graphs—a property that fails for general graphs. The proof proceeds via the augmenting-path characterisation of maximum matchings (Berge's theorem): $M$ is maximum if and only if $G$ contains no $M$-augmenting path, a path that alternates between unmatched and matched edges and begins and ends at unmatched vertices. The algorithm of Hopcroft and Karp finds a maximum matching in $O\!\left(|E|\sqrt{|U|+|V|}\right)$ time by searching for augmenting paths in batches.

### directed_acyclic_graph (15.3s)

## Directed Acyclic Graph

**Definition.** A *directed acyclic graph* (DAG) is an ordered pair $G = (V, E)$ where $V$ is a finite set of *vertices* and $E \subseteq V \times V$ is a set of *directed edges* (arcs), subject to the constraint that $G$ contains no directed cycle. Formally, there is no sequence of vertices $v_0, v_1, \ldots, v_k$ with $k \geq 1$ such that $(v_{i}, v_{i+1}) \in E$ for $0 \leq i < k$ and $v_k = v_0$. An edge $(u, v) \in E$ is read "$u$ points to $v$"; $u$ is a *predecessor* of $v$ and $v$ is a *successor* of $u$. A vertex with no incoming edges is called a *source*; one with no outgoing edges is called a *sink*.

**Worked Example.** Consider the DAG representing prerequisite dependencies among four university courses:

$$V = \{A, B, C, D\}, \quad E = \{(A,B),\, (A,C),\, (B,D),\, (C,D)\}.$$

Here $A$ is the sole source (no prerequisites) and $D$ is the sole sink (no dependents). The edge $(A, B)$ asserts that course $A$ must be completed before $B$. There is no directed path from any vertex back to itself, confirming the acyclic property. One valid *topological ordering* of these courses is $A, B, C, D$, meaning students may take them in that sequence without violating any prerequisite.

**Key Theorem (Topological Sort).** A directed graph $G$ is a DAG if and only if it admits a *topological ordering*: a bijection $\sigma: V \to \{1, 2, \ldots, |V|\}$ such that for every edge $(u, v) \in E$, we have $\sigma(u) < \sigma(v)$. The standard proof proceeds by showing that every DAG possesses at least one source; removing that source yields a smaller DAG, and induction completes the argument. The practical implication is Kahn's algorithm, which runs in $O(|V| + |E|)$ time by repeatedly extracting vertices of in-degree zero.

### disjoint_path_cover (15.8s)

## Disjoint Path Cover

**Definition.** Let $G = (V, E)$ be a directed acyclic graph (DAG). A *disjoint path cover* (DPC) of $G$ is a collection of directed paths $\mathcal{P} = \{P_1, P_2, \ldots, P_k\}$ such that every vertex $v \in V$ belongs to exactly one path in $\mathcal{P}$. The paths are vertex-disjoint: for $i \neq j$, $V(P_i) \cap V(P_j) = \emptyset$. A *minimum* disjoint path cover minimizes $|\mathcal{P}|$, i.e., finds the fewest paths that together visit every vertex exactly once.

**Worked Example.** Consider the DAG with vertices $V = \{1, 2, 3, 4, 5\}$ and edges $E = \{(1,3),(2,3),(3,4),(3,5)\}$. One valid DPC uses three paths: $P_1 = (1, 3, 4)$, $P_2 = (2)$, $P_3 = (5)$. Can we do better? Testing two paths: any single path through vertex 3 can incorporate at most one predecessor (1 or 2) and one successor (4 or 5), leaving the remaining predecessor and successor as isolated singleton paths. Thus the minimum number of paths is $k = 3$, achieved by $\{(1,3,4),(2),(5)\}$ or $\{(2,3,5),(1),(4)\}$.

**Key Theorem.** *(Dilworth–Reduction)* The size of a minimum disjoint path cover of a DAG $G$ with $n$ vertices equals
$$k = n - \mu(G'),$$
where $\mu(G')$ is the size of a maximum matching in the bipartite graph $G'$ constructed as follows: replace each vertex $v \in V$ with a source copy $v^+$ and a sink copy $v^-$, and add edge $(u^+, v^-)$ to $G'$ whenever $(u, v) \in E$. Each matched edge in $G'$ "chains" two vertices into a single path, reducing the path count by one. A maximum matching therefore maximally chains vertices, yielding the minimum number of paths. Computing $\mu(G')$ via the Hopcroft–Karp algorithm runs in $O(\sqrt{n}\, |E|)$ time.

**Lab Cell.**
```python
from sympy.combinatorics.named_groups import *
import networkx as nx

G = nx.DiGraph([(1,3),(2,3),(3,4),(3,5)])

# Build bipartite reduction
B = nx.DiGraph()
for u, v in G.edges():
    B.add_edge(f"{u}+", f"{v}-")

top = {n for n in B.nodes() if "+" in n}
matching = nx.bipartite.maximum_matching(B.to_undirected(), top_nodes=top)
mu = len(matching) // 2

min_paths = G.number_of_nodes() - mu
print(f"Maximum matching: {mu}")
print(f"Minimum path cover size: {min_paths}")
```

Running this cell prints `Maximum matching: 2` and `Minimum path cover size: 3`, confirming the worked example.

## Minimal Faculty Hiring

**Definition.** Let $C = \{c_1, c_2, \ldots, c_m\}$ be a finite set of required courses and $F = \{f_1, f_2, \ldots, f_n\}$ a pool of faculty candidates, where each candidate $f_i$ can teach a subset $S_i \subseteq C$. A *covering set* is any subcollection $\mathcal{H} \subseteq \{S_1, \ldots, S_n\}$ such that $\bigcup_{S \in \mathcal{H}} S = C$. The **Minimal Faculty Hiring Problem** asks for a covering set $\mathcal{H}^*$ of smallest cardinality:

$$\mathcal{H}^* = \arg\min_{\mathcal{H} \text{ covers } C} |\mathcal{H}|.$$

This is an instance of the classical **Set Cover Problem**, one of the canonical NP-hard combinatorial optimization problems.

**Worked Example.** Suppose $C = \{\text{Calculus, LinAlg, Statistics, Algorithms}\}$ and three candidates are available:

| Candidate | Courses Teachable |
|-----------|-------------------|
| $f_1$ | Calculus, LinAlg |
| $f_2$ | LinAlg, Statistics, Algorithms |
| $f_3$ | Calculus, Statistics |

The subcollection $\{f_1, f_2\}$ covers $C$ because $S_1 \cup S_2 = C$. No single candidate covers all four courses, so $|\mathcal{H}^*| = 2$ and $\mathcal{H}^* = \{f_1, f_2\}$ is optimal.

**Key Theorem (Greedy Approximation).** Because Set Cover is NP-hard (reducible from 3-SAT), no polynomial-time algorithm is known to find $\mathcal{H}^*$ in general unless $\mathrm{P} = \mathrm{NP}$. The *greedy algorithm*—repeatedly select the candidate covering the most yet-uncovered courses—achieves the approximation guarantee

$$|\mathcal{H}_{\text{greedy}}| \leq \lceil H_m \rceil \cdot |\mathcal{H}^*|,$$

where $H_m = \sum_{k=1}^{m} \frac{1}{k}$ is the $m$-th harmonic number. For $m = 4$, this ratio is at most $\lceil H_4 \rceil = 3$, bounding how far the greedy solution can deviate from optimal. Furthermore, it is known that no polynomial-time algorithm can achieve ratio better than $(1 - o(1))\ln m$ unless $\mathrm{P} = \mathrm{NP}$, so greedy is essentially tight.

**Lab Cell.**

```python
from itertools import combinations

courses = {"Calculus", "LinAlg", "Statistics", "Algorithms"}
candidates = [
    {"Calculus", "LinAlg"},
    {"LinAlg", "Statistics", "Algorithms"},
    {"Calculus", "Statistics"},
]

def min_cover(universe, sets):
    n = len(sets)
    for size in range(1, n + 1):
        for combo in combinations(range(n), size):
            if universe <= set().union(*(sets[i] for i in combo)):
                return [sets[i] for i in combo]
    return None

print(min_cover(courses, candidates))
# [{'Calculus', 'LinAlg'}, {'LinAlg', 'Statistics', 'Algorithms'}]
```

The exhaustive search confirms $|\mathcal{H}^*| = 2$; for large instances, integer linear programming replaces brute force.

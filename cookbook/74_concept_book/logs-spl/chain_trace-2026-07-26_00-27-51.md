### limit (0.0s)

## Limit

**Definition.** Let $f$ be a real-valued function defined on a punctured neighbourhood of a point $a \in \mathbb{R}$. We say that the *limit of $f$ as $x$ approaches $a$* equals $L$, written

$$\lim_{x \to a} f(x) = L,$$

if for every $\varepsilon > 0$ there exists $\delta > 0$ such that

$$0 < |x - a| < \delta \implies |f(x) - L| < \varepsilon.$$

The condition $0 < |x - a|$ is essential: the value $f(a)$ itself is irrelevant, or may not even exist. The definition formalises the intuition that $f(x)$ can be made arbitrarily close to $L$ by choosing $x$ sufficiently close (but not equal) to $a$.

---

**Worked example.** We verify $\displaystyle\lim_{x \to 2}(3x - 1) = 5$ directly from the definition.

Given $\varepsilon > 0$, we need $|3x - 1 - 5| < \varepsilon$, i.e., $3|x - 2| < \varepsilon$. Choose $\delta = \varepsilon/3$. Then

$$0 < |x - 2| < \delta \implies |f(x) - 5| = 3|x - 2| < 3\delta = \varepsilon. \quad \checkmark$$

The choice $\delta = \varepsilon/3$ was found by working backwards from the desired inequality — a standard technique in $\varepsilon$-$\delta$ proofs.

---

**Key theorem (Limit laws).** If $\lim_{x \to a} f(x) = L$ and $\lim_{x \to a} g(x) = M$, then:

$$\lim_{x \to a}[f(x) + g(x)] = L + M, \qquad \lim_{x \to a}[f(x) \cdot g(x)] = L \cdot M,$$

and, provided $M \neq 0$,

$$\lim_{x \to a}\frac{f(x)}{g(x)} = \frac{L}{M}.$$

These laws reduce the verification of composite limits to simpler ones, eliminating the need for a fresh $\varepsilon$-$\delta$ argument each time.

---

**Lab cell.**

```python
from sympy import symbols, limit, sin, oo

x = symbols('x')

# Fundamental trigonometric limit
print(limit(sin(x) / x, x, 0))          # 1

# Limit at infinity
print(limit((3*x**2 + 1) / (x**2 - 4), x, oo))  # 3

# One-sided limits
print(limit(abs(x) / x, x, 0, '+'))     # 1
print(limit(abs(x) / x, x, 0, '-'))     # -1
```

The last two calls illustrate that a two-sided limit exists only when both one-sided limits agree, connecting the symbolic machinery to the $\varepsilon$-$\delta$ definition.

### continuity_at_a_point (15.3s)

## Continuity At A Point

**Definition.** Let $f$ be a function defined on an open interval containing the point $c$. We say $f$ is *continuous at $c$* if the following three conditions all hold:

1. $f(c)$ is defined,
2. $\displaystyle\lim_{x \to c} f(x)$ exists,
3. $\displaystyle\lim_{x \to c} f(x) = f(c)$.

Equivalently, using the $\varepsilon$-$\delta$ language: for every $\varepsilon > 0$ there exists $\delta > 0$ such that $|x - c| < \delta \implies |f(x) - f(c)| < \varepsilon$. Intuitively, continuity at $c$ means that small perturbations of the input near $c$ produce arbitrarily small changes in the output — there is no jump, hole, or oscillation at that point.

**Worked Example.** Consider $f(x) = \dfrac{x^2 - 4}{x - 2}$ and the point $c = 2$.

- *Condition 1*: $f(2)$ is undefined (division by zero), so as written, $f$ is **not** continuous at $c = 2$.
- *Remedy*: Define the extension $g(x) = x + 2$ for all $x$, which equals $f(x)$ whenever $x \neq 2$. Then $g(2) = 4$, $\lim_{x\to 2} g(x) = 4$, and $g(2) = 4$. All three conditions hold, so $g$ is continuous at $2$.

This illustrates a *removable discontinuity*: the limit exists but the function value is either missing or mismatched.

**Theorem (Continuity of Algebraic Combinations).** If $f$ and $g$ are both continuous at $c$, then so are $f + g$, $f - g$, $f \cdot g$, and (provided $g(c) \neq 0$) $f/g$. Consequently, every polynomial is continuous at every real number, and every rational function is continuous wherever its denominator is nonzero.

*Proof sketch.* Each case follows directly from the corresponding limit law: e.g., $\lim_{x \to c}[f(x) + g(x)] = \lim_{x \to c} f(x) + \lim_{x \to c} g(x) = f(c) + g(c)$. $\square$

**Lab Cell.**

```python
from sympy import symbols, limit, Function, Rational

x = symbols('x')
f = (x**2 - 4) / (x - 2)

left  = limit(f, x, 2, '-')
right = limit(f, x, 2, '+')

print("Left-hand limit :", left)   # 4
print("Right-hand limit:", right)  # 4
# f(2) is undefined; defining g = x + 2 restores continuity
g = x + 2
print("g(2) =", g.subs(x, 2))     # 4
```

Running this cell confirms that both one-sided limits equal $4$, matching $g(2)$, and thereby verifying continuity of the repaired function at $x = 2$.

### continuity_over_an_interval (14.9s)

## Continuity Over An Interval

**Definition.** A function $f$ is said to be *continuous on an open interval* $(a, b)$ if it is continuous at every point $c \in (a, b)$, meaning

$$\lim_{x \to c} f(x) = f(c)$$

for all $c \in (a, b)$. For a *closed interval* $[a, b]$, we additionally require one-sided continuity at the endpoints: $f$ is continuous from the right at $a$ (i.e., $\lim_{x \to a^+} f(x) = f(a)$) and from the left at $b$ (i.e., $\lim_{x \to b^-} f(x) = f(b)$). Informally, a function is continuous on an interval if its graph can be drawn over that interval without lifting the pen.

**Worked Example.** Consider $f(x) = \sqrt{4 - x^2}$ on $[-2, 2]$. For any interior point $c \in (-2, 2)$, the function is a composition of continuous functions (square root composed with a polynomial), so continuity at $c$ follows from limit laws. At the left endpoint $x = -2$:

$$\lim_{x \to -2^+} \sqrt{4 - x^2} = \sqrt{4 - 4} = 0 = f(-2).$$

Similarly, $\lim_{x \to 2^-} \sqrt{4 - x^2} = 0 = f(2)$. Therefore $f$ is continuous on $[-2, 2]$. Geometrically, the graph is a semicircle — a single unbroken arc.

**Key Theorem (Intermediate Value Theorem).** If $f$ is continuous on $[a, b]$ and $N$ is any value strictly between $f(a)$ and $f(b)$, then there exists at least one $c \in (a, b)$ such that $f(c) = N$.

*Proof sketch.* Define $g(x) = f(x) - N$. Then $g(a)$ and $g(b)$ have opposite signs. By the completeness of $\mathbb{R}$, the set $S = \{x \in [a,b] : g(x) < 0\}$ has a supremum $c$. Continuity of $g$ forces $g(c) = 0$, so $f(c) = N$. $\square$

This theorem guarantees, for instance, that any polynomial with a sign change on $[a, b]$ must have a root there — a foundation for numerical root-finding algorithms.

**Lab Cell.**

```python
from sympy import *
x = symbols('x')
f = sqrt(4 - x**2)

# Verify one-sided limits at endpoints
print(limit(f, x, -2, '+'))   # expects 0
print(limit(f, x,  2, '-'))   # expects 0

# IVT demonstration: find c where f(c) = 1 on [-2, 2]
c = symbols('c')
print(solve(f.subs(x, c) - 1, c))  # expects [-sqrt(3), sqrt(3)]
```

### intermediate_value_theorem (13.6s)

## Intermediate Value Theorem

**Definition.** Let $f : [a, b] \to \mathbb{R}$ be a continuous function on the closed interval $[a, b]$. If $N$ is any real number strictly between $f(a)$ and $f(b)$ — that is, $\min(f(a), f(b)) < N < \max(f(a), f(b))$ — then there exists at least one point $c \in (a, b)$ such that $f(c) = N$.

Informally, a continuous function cannot jump from one value to another without passing through every intermediate value. The graph of $f$ must cross every horizontal line $y = N$ that lies between $y = f(a)$ and $y = f(b)$.

---

**Worked Example.** Show that $f(x) = x^3 - x - 1$ has a root in the interval $[1, 2]$.

Evaluate at the endpoints:
$$f(1) = 1 - 1 - 1 = -1 < 0, \qquad f(2) = 8 - 2 - 1 = 5 > 0.$$

Since $f$ is a polynomial (hence continuous everywhere), and $0$ lies strictly between $f(1) = -1$ and $f(2) = 5$, the Intermediate Value Theorem guarantees a $c \in (1, 2)$ with $f(c) = 0$. Numerical methods refine this to $c \approx 1.3247$.

---

**Key Theorem (Proof Sketch).** The result follows from the completeness of $\mathbb{R}$. Without loss of generality assume $f(a) < N < f(b)$. Define $S = \{x \in [a,b] : f(x) \leq N\}$. This set is non-empty (it contains $a$) and bounded above by $b$, so by the least-upper-bound property $c = \sup S$ exists. Continuity of $f$ at $c$ forces $f(c) = N$: if $f(c) < N$ one can find points of $S$ larger than $c$, contradicting its definition as supremum; if $f(c) > N$ then $f > N$ on a neighbourhood of $c$, again a contradiction. $\square$

A direct consequence is the **existence of $n$-th roots**: for any $y \geq 0$ and integer $n \geq 1$, the function $g(x) = x^n$ is continuous with $g(0) = 0$ and $g(y+1) > y$, so there exists $c$ with $c^n = y$.

---

```python
from sympy import symbols, solve, Rational
from sympy.plotting import plot

x = symbols('x')
f = x**3 - x - 1

# Confirm sign change
print(f.subs(x, 1), f.subs(x, 2))   # -1, 5

root = solve(f, x)
print([r.evalf() for r in root])

plot(f, (x, 1, 2), title='f(x) = x³ − x − 1', xlabel='x', ylabel='f(x)')
```

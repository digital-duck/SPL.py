### outcome (0.0s)

## 结果

**定义。** 设 $\Omega$ 为一随机试验的**样本空间**，即该试验所有可能结局的集合。其中每一个元素 $\omega \in \Omega$ 称为一个**基本结果**（outcome），它是不可再分的最小观测单元。形式上，若试验进行一次，则恰好实现 $\Omega$ 中的唯一一个元素。

更精确地，三元组 $(\Omega, \mathcal{F}, P)$ 构成一个**概率空间**，其中 $\mathcal{F} \subseteq 2^{\Omega}$ 是 $\sigma$-代数，$P: \mathcal{F} \to [0,1]$ 是满足 Kolmogorov 公理的概率测度。单个结果 $\omega$ 本身满足

$$
P(\{\omega\}) \geq 0, \qquad \sum_{\omega \in \Omega} P(\{\omega\}) = 1 \quad (\text{当 } \Omega \text{ 为可数集时}),
$$

而对于连续样本空间，则以积分代替求和。

---

**例题。** 掷一枚均匀六面骰子。样本空间为

$$
\Omega = \{1, 2, 3, 4, 5, 6\},
$$

共 6 个基本结果。由对称性，每个结果的概率相等：

$$
P(\{\omega\}) = \frac{1}{6}, \quad \forall\, \omega \in \Omega.
$$

事件"掷出偶数"可表示为集合 $A = \{2, 4, 6\} \subset \Omega$，故

$$
P(A) = P(\{2\}) + P(\{4\}) + P(\{6\}) = \frac{1}{6} + \frac{1}{6} + \frac{1}{6} = \frac{1}{2}.
$$

此处 $A$ 是三个基本结果的并，体现了事件由结果聚合而成的层次结构。

---

**关键定理（单点集的测度性）。** 设 $(\Omega, \mathcal{F}, P)$ 为概率空间且 $\Omega$ 可数。则对任意 $\omega \in \Omega$，单点集 $\{\omega\} \in \mathcal{F}$，且

$$
P(A) = \sum_{\omega \in A} P(\{\omega\}), \quad \forall\, A \in \mathcal{F}.
$$

**证明概要：** 由 $\sigma$-代数对可数并封闭，$\{\omega\} = \bigcap_{n=1}^{\infty} A_n$（适当选取 $A_n \in \mathcal{F}$）属于 $\mathcal{F}$；再由 $P$ 的可数可加性，对互不相交的单点集求和即得。$\blacksquare$

---

**实验单元（SymPy）**

```python
from sympy.stats import Die, P, Eq
from sympy import Rational

D = Die('D', 6)                        # 定义均匀六面骰子
for face in range(1, 7):
    print(f"P(D={face}) =", P(Eq(D, face)))   # 每个基本结果的概率

even_prob = P(Eq(D % 2, 0))           # 事件"偶数"的概率
print("P(偶数) =", even_prob)
```

运行上述代码，可验证每个基本结果的概率均为 $\tfrac{1}{6}$，偶数事件概率为 $\tfrac{1}{2}$，与理论完全吻合。

### sample_space (0.0s)

## 样本空间

**定义。** 设某随机试验 $\mathcal{E}$ 为一可重复的观测过程，其所有可能结果的全体构成一个集合，称为该试验的**样本空间**（sample space），记作 $\Omega$。$\Omega$ 中的每个元素 $\omega$ 称为一个**样本点**（sample point）或**基本结果**。若 $|\Omega| < \infty$，则称 $\Omega$ 为**有限样本空间**；若 $\Omega$ 可列无穷，则为**可列无穷样本空间**；若 $\Omega$ 不可列，则为**不可列样本空间**。

**具体示例。** 考虑同时掷两枚均匀硬币的试验，每枚硬币的结果为正面（H）或反面（T）。按顺序记录两枚硬币的结果，则样本空间为

$$
\Omega = \{(H,H),\,(H,T),\,(T,H),\,(T,T)\},
$$

共 $|\Omega| = 4$ 个样本点。若改为记录正面朝上的枚数，则样本空间变为 $\Omega' = \{0, 1, 2\}$，这提示我们：**样本空间的选取依赖于所关注的信息粒度**，同一物理试验可对应不同的数学样本空间。再考虑测量某零件长度（单位：mm）的连续试验，若长度理论上可取任意正值，则 $\Omega = (0, +\infty)$，为不可列样本空间。

**关键定理（样本空间的代数结构）。** 设 $\Omega$ 为样本空间，$\mathcal{F}$ 为 $\Omega$ 上满足以下条件的集族：(i) $\Omega \in \mathcal{F}$；(ii) 若 $A \in \mathcal{F}$，则 $A^c \in \mathcal{F}$；(iii) 若 $A_1, A_2, \ldots \in \mathcal{F}$，则 $\bigcup_{i=1}^{\infty} A_i \in \mathcal{F}$。则称 $(\Omega, \mathcal{F})$ 为**可测空间**，$\mathcal{F}$ 为 $\sigma$-代数。在此结构上定义概率测度 $P: \mathcal{F} \to [0,1]$，三元组 $(\Omega, \mathcal{F}, P)$ 构成概率空间，这是现代概率论的公理化基础。

**实验单元（SymPy）。**

```python
from sympy import FiniteSet, symbols

# 两枚硬币的样本空间
outcomes = [('H','H'), ('H','T'), ('T','H'), ('T','T')]
Omega = FiniteSet(*outcomes)

print("样本空间 Ω =", Omega)
print("样本点个数 |Ω| =", len(Omega))

# 事件：至少一枚正面
event_A = FiniteSet(*[o for o in outcomes if 'H' in o])
print("事件 A（至少一枚H）=", event_A)
print("P(A) =", len(event_A) / len(Omega))
```

### event (0.0s)

## 事件

**定义．** 设 $\Omega$ 为一随机试验的**样本空间**，即所有可能结果的全体。$\Omega$ 的任意子集 $A \subseteq \Omega$ 称为一个**事件**。若试验结果 $\omega \in A$，则称事件 $A$ **发生**；若 $\omega \notin A$，则称 $A$ **不发生**。特别地，$\Omega$ 本身称为**必然事件**，空集 $\emptyset$ 称为**不可能事件**。在可测空间框架下，事件须属于某一 $\sigma$-代数 $\mathcal{F}$，以保证概率的可加性得以严格定义。

**集合运算与事件的对应．** 事件之间的逻辑关系与集合运算一一对应：

$$A \cup B \quad \text{（$A$ 或 $B$ 至少之一发生）}, \qquad A \cap B \quad \text{（$A$ 与 $B$ 同时发生）}, \qquad A^c = \Omega \setminus A \quad \text{（$A$ 不发生）}.$$

若 $A \cap B = \emptyset$，则称 $A$ 与 $B$ **互斥**（互不相容）。

**具体例子．** 掷一枚公平的六面骰子，样本空间为 $\Omega = \{1,2,3,4,5,6\}$。定义事件

$$A = \{\text{出现偶数}\} = \{2,4,6\}, \qquad B = \{\text{出现大于}4的数\} = \{5,6\}.$$

则：

$$A \cup B = \{2,4,5,6\}, \quad A \cap B = \{6\}, \quad A^c = \{1,3,5\}.$$

由于 $A \cap B = \{6\} \neq \emptyset$，故 $A$ 与 $B$ 不互斥。

**关键定理（概率的有限可加性）．** 设 $A_1, A_2, \ldots, A_n$ 两两互斥，则

$$P\!\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} P(A_i).$$

**证明思路：** 由互斥条件 $A_i \cap A_j = \emptyset$（$i \neq j$），各事件对应的样本点不重叠，故其概率（频率极限意义下）可直接相加。完整证明由 Kolmogorov 公理中的 $\sigma$-可加性推出。

**实验单元（SymPy）．**

```python
from sympy import FiniteSet

omega = FiniteSet(1, 2, 3, 4, 5, 6)
A = FiniteSet(2, 4, 6)          # 偶数
B = FiniteSet(5, 6)             # 大于4

print("A ∪ B =", A.union(B))
print("A ∩ B =", A.intersect(B))
print("Aᶜ    =", omega - A)
print("互斥？ ", A.intersect(B) == FiniteSet())
```

运行此单元，可直观验证上述集合运算结果，并将 $\Omega$ 替换为任意有限样本空间以探索更复杂的事件结构。

### probability (0.0s)

## 概率

**定义。** 设 $\Omega$ 为一个非空集合，称为**样本空间**，其元素称为**基本事件**。$\mathcal{F}$ 是 $\Omega$ 的子集所构成的 $\sigma$-代数，其元素称为**事件**。**概率测度** $P: \mathcal{F} \to [0,1]$ 是满足以下柯尔莫哥洛夫公理的函数：

1. **非负性**：对任意事件 $A \in \mathcal{F}$，有 $P(A) \geq 0$；
2. **规范性**：$P(\Omega) = 1$；
3. **可数可加性**：若 $A_1, A_2, \ldots \in \mathcal{F}$ 两两不相交，则

$$P\!\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i).$$

三元组 $(\Omega, \mathcal{F}, P)$ 称为**概率空间**。

---

**例题。** 掷一枚均匀骰子，样本空间为 $\Omega = \{1, 2, 3, 4, 5, 6\}$，每个基本事件的概率均为 $\tfrac{1}{6}$。设事件 $A = \{\text{出现偶数}\} = \{2, 4, 6\}$，则由可数可加性得

$$P(A) = P(\{2\}) + P(\{4\}) + P(\{6\}) = \frac{1}{6} + \frac{1}{6} + \frac{1}{6} = \frac{1}{2}.$$

---

**关键定理（容斥原理）。** 对任意两个事件 $A, B \in \mathcal{F}$，有

$$P(A \cup B) = P(A) + P(B) - P(A \cap B).$$

**证明概要。** 将 $A \cup B$ 分拆为三个两两不相交的部分：$A \setminus B$、$B \setminus A$ 与 $A \cap B$。由可数可加性，$P(A) = P(A \setminus B) + P(A \cap B)$，$P(B) = P(B \setminus A) + P(A \cap B)$，两式相加后减去重复计入的 $P(A \cap B)$ 即得结论。$\blacksquare$

---

**实验单元（SymPy）。**

```python
from sympy import Rational, symbols
from sympy.stats import Die, P as prob, Gt

X = Die('X', 6)                          # 均匀六面骰子
p_even = prob(X % 2 | X, True)          # 偶数事件概率
A = prob(X > 2)                          # P(X > 2)
B = prob(X > 4)                          # P(X > 4)
print("P(偶数) =", prob(X % 2 == 0))    # 期望输出：1/2
print("P(X>2) =", A, "  P(X>4) =", B)
```

运行后应输出 $P(\text{偶数}) = \tfrac{1}{2}$，$P(X > 2) = \tfrac{2}{3}$，$P(X > 4) = \tfrac{1}{3}$，与手算结果一致，从而验证概率公理的数值实现。

### conditional_probability (0.0s)

## 条件概率

**定义。** 设 $(\Omega, \mathcal{F}, P)$ 为概率空间，$A, B \in \mathcal{F}$ 且 $P(B) > 0$。在事件 $B$ 已发生的条件下，事件 $A$ 发生的**条件概率**定义为

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}.$$

直觉上，条件概率将样本空间从 $\Omega$ 收缩至 $B$，并在新空间上重新归一化。可验证 $P(\cdot \mid B)$ 本身满足 Kolmogorov 公理，故构成合法的概率测度。

---

**例题。** 掷一枚均匀六面骰子一次，$\Omega = \{1,2,3,4,5,6\}$，各基本事件概率均为 $\tfrac{1}{6}$。令

$$A = \{\text{点数为偶数}\} = \{2,4,6\}, \quad B = \{\text{点数大于 3}\} = \{4,5,6\}.$$

则 $A \cap B = \{4,6\}$，故

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)} = \frac{2/6}{3/6} = \frac{2}{3}.$$

这说明：若已知点数大于 3，则为偶数的概率由原来的 $\tfrac{1}{2}$ 上升至 $\tfrac{2}{3}$——信息改变了我们对随机结果的信念。

---

**关键定理（乘法公式与全概率公式）。** 由定义直接得到**乘法公式**：

$$P(A \cap B) = P(A \mid B)\,P(B).$$

推广至有限划分 $\{B_1, B_2, \ldots, B_n\}$（两两不相交且并为 $\Omega$）时，得**全概率公式**：

$$P(A) = \sum_{i=1}^{n} P(A \mid B_i)\,P(B_i).$$

该公式将复杂事件 $A$ 的概率分解为在各"情景" $B_i$ 下的加权平均，是贝叶斯推断的基础。

---

**实验单元（SymPy）。**

```python
from sympy import Rational, symbols

# 定义概率
P_B  = Rational(3, 6)          # P(B) = 1/2
P_AB = Rational(2, 6)          # P(A∩B) = 1/3

P_A_given_B = P_AB / P_B
print("P(A|B) =", P_A_given_B)  # 输出 2/3

# 全概率公式验证
P_A_given_Bc = Rational(1, 3)   # 点数<=3时偶数概率 P(A|B^c)
P_Bc = 1 - P_B
P_A = P_A_given_B * P_B + P_A_given_Bc * P_Bc
print("P(A) =", P_A)            # 输出 1/2，与直接计算一致
```

### and_event (0.0s)

## And Event

**定义．** 设 $(\Omega, \mathcal{F}, P)$ 为一概率空间，$A, B \in \mathcal{F}$ 为两个事件。**积事件**（又称**交事件**）定义为

$$
A \cap B \;=\; \{\omega \in \Omega : \omega \in A \text{ 且 } \omega \in B\},
$$

即样本点 $\omega$ 同时属于 $A$ 与 $B$ 时所构成的事件。若 $A \cap B = \varnothing$，则称 $A$ 与 $B$ **互斥**（不相容）。积事件可推广至有限或可数无穷族：$\bigcap_{i=1}^{n} A_i$ 表示所有 $A_i$ 同时发生的事件。

---

**典型例题．** 掷一枚标准骰子一次，样本空间为 $\Omega = \{1,2,3,4,5,6\}$。令

$$
A = \{\text{点数为偶数}\} = \{2,4,6\}, \qquad B = \{\text{点数大于 }3\} = \{4,5,6\}.
$$

则

$$
A \cap B = \{4,6\}.
$$

若骰子均匀，每个基本事件概率均为 $\tfrac{1}{6}$，故

$$
P(A \cap B) = \frac{|A \cap B|}{|\Omega|} = \frac{2}{6} = \frac{1}{3}.
$$

---

**关键定理（容斥原理）．** 对任意 $A, B \in \mathcal{F}$，

$$
P(A \cup B) = P(A) + P(B) - P(A \cap B).
$$

**证明思路：** 将 $A \cup B$ 分解为三个两两互斥的部分：$A \setminus B$、$A \cap B$、$B \setminus A$，利用概率的可列可加性分别求和，再化简即得。此公式揭示：若直接相加 $P(A)+P(B)$，则 $A \cap B$ 中的概率被计算了两次，故须减去一次 $P(A \cap B)$。

---

**实验单元（SymPy）．**

```python
from sympy import FiniteSet, Rational

Omega = FiniteSet(1, 2, 3, 4, 5, 6)
A = FiniteSet(2, 4, 6)
B = FiniteSet(4, 5, 6)

A_and_B = A.intersect(B)          # {4, 6}
prob = Rational(len(A_and_B), len(Omega))
print(f"A ∩ B = {A_and_B},  P(A ∩ B) = {prob}")  # 1/3
```

运行上述代码，可验证 $P(A \cap B) = \tfrac{1}{3}$，并可自行修改集合 $A$、$B$，观察积事件随定义变化的规律。

### independent_events (19.3s)

## 独立事件

**定义。** 设 $(\Omega, \mathcal{F}, P)$ 为一概率空间，$A, B \in \mathcal{F}$ 为两个事件。若

$$P(A \cap B) = P(A)\,P(B),$$

则称 $A$ 与 $B$ **相互独立**（mutually independent）。直观而言，独立性意味着事件 $B$ 的发生不改变事件 $A$ 的概率，即当 $P(B) > 0$ 时，条件概率满足 $P(A \mid B) = P(A)$。对于有限族 $\{A_1, A_2, \ldots, A_n\}$，若对任意下标子集 $I \subseteq \{1,\ldots,n\}$ 均有

$$P\!\Bigl(\bigcap_{i \in I} A_i\Bigr) = \prod_{i \in I} P(A_i),$$

则称该族事件**相互独立**。注意：两两独立并不蕴含相互独立，这一区别在后续例题中将予以说明。

---

**例题。** 公平地投掷一枚硬币两次。样本空间为 $\Omega = \{HH, HT, TH, TT\}$，每个基本事件的概率均为 $\tfrac{1}{4}$。设

$$A = \{\text{第一次正面}\} = \{HH, HT\}, \quad B = \{\text{第二次正面}\} = \{HH, TH\}.$$

则 $P(A) = \tfrac{1}{2}$，$P(B) = \tfrac{1}{2}$，$P(A \cap B) = P(\{HH\}) = \tfrac{1}{4}$。

验证：$P(A)\,P(B) = \tfrac{1}{2} \cdot \tfrac{1}{2} = \tfrac{1}{4} = P(A \cap B)$。故 $A$ 与 $B$ 独立，符合物理直觉——两次投掷在机制上互不影响。

---

**关键定理（独立性的等价刻画）。** 设 $P(B) > 0$，则 $A$ 与 $B$ 独立当且仅当 $P(A \mid B) = P(A)$。

*证明纲要。* 由条件概率定义，$P(A \mid B) = P(A \cap B)/P(B)$。若 $P(A \cap B) = P(A)P(B)$，则 $P(A \mid B) = P(A)$；反之亦然。$\blacksquare$

推论：若 $A$ 与 $B$ 独立，则 $A$ 与 $B^c$、$A^c$ 与 $B$、$A^c$ 与 $B^c$ 亦分别独立。

---

**实验单元（SymPy）。**

```python
from sympy import Rational, symbols
from sympy.stats import Die, P, E

# 模拟两个独立骰子
X, Y = Die('X', 6), Die('Y', 6)
A = X > 4          # P(A) = 1/3
B = Y < 3          # P(B) = 1/3
p_A  = P(A)
p_B  = P(B)
p_AB = P(A & B)    # SymPy 对独立随机变量自动处理联合分布
print(p_A, p_B, p_AB, p_A * p_B == p_AB)
```

运行后应输出 `True`，验证两事件独立。读者可将 `X > 4` 替换为与 $Y$ 相关的条件，观察独立性如何被破坏。

### dependent_events (19.9s)

## 相依事件

**定义。** 设 $(\Omega, \mathcal{F}, P)$ 为概率空间，$A, B \in \mathcal{F}$ 为两个事件。若

$$P(A \mid B) \neq P(A),$$

则称 $A$ 与 $B$ 为**相依事件**（dependent events）。等价地，$A$ 与 $B$ 相依当且仅当

$$P(A \cap B) \neq P(A)\,P(B).$$

直觉上，相依意味着事件 $B$ 的发生改变了我们对 $A$ 发生可能性的判断：知道 $B$ 已发生，为 $A$ 提供了额外的信息。

---

**例题。** 一个不透明袋中装有 $3$ 枚红球与 $2$ 枚蓝球，**不放回**地依次取出两球。设

$$A = \{\text{第二次取出红球}\}, \quad B = \{\text{第一次取出红球}\}.$$

**计算 $P(A \mid B)$ 与 $P(A)$，并判断相依性。**

*解。* 取球后不放回，故两次取球的结果相互影响。

$$P(B) = \frac{3}{5}.$$

在 $B$ 已发生的条件下，袋中剩余 $4$ 球（$2$ 红、$2$ 蓝），故

$$P(A \mid B) = \frac{2}{4} = \frac{1}{2}.$$

若 $B$ 未发生（第一次取蓝），袋中剩余 $3$ 红、$1$ 蓝，故

$$P(A \mid B^c) = \frac{3}{4}.$$

由全概率公式：

$$P(A) = P(A \mid B)\,P(B) + P(A \mid B^c)\,P(B^c) = \frac{1}{2}\cdot\frac{3}{5} + \frac{3}{4}\cdot\frac{2}{5} = \frac{3}{10} + \frac{3}{10} = \frac{3}{5}.$$

因 $P(A \mid B) = \dfrac{1}{2} \neq \dfrac{3}{5} = P(A)$，故 $A$ 与 $B$ **相依**。

---

**关键定理（乘法公式）。** 对任意事件 $A, B$，只要 $P(B) > 0$，有

$$P(A \cap B) = P(B)\,P(A \mid B).$$

当 $A, B$ 相依时，此式不可化简为 $P(A)\,P(B)$；独立性恰好是相依性的特殊退化情形。

---

**实验单元（SymPy）。**

```python
from fractions import Fraction

P_B  = Fraction(3, 5)
P_A_given_B  = Fraction(2, 4)
P_A_given_Bc = Fraction(3, 4)

P_A = P_A_given_B * P_B + P_A_given_Bc * (1 - P_B)
P_AB = P_B * P_A_given_B

print("P(A) =", P_A)          # 3/5
print("P(A∩B) =", P_AB)       # 3/10
print("P(A)·P(B) =", P_A * P_B)  # 9/25
print("相依？", P_AB != P_A * P_B)  # True
```

运行结果确认 $P(A \cap B) = \dfrac{3}{10} \neq \dfrac{9}{25} = P(A)\,P(B)$，从而验证了两事件的相依性。

### multiplication_rule (17.0s)

## 乘法规则

**定义。** 设 $A$ 与 $B$ 为同一样本空间 $\Omega$ 上的两个事件，且 $P(B) > 0$。**乘法规则**（multiplication rule）将两事件的联合概率分解为条件概率与边际概率的乘积：

$$P(A \cap B) = P(B) \cdot P(A \mid B).$$

对称地，若 $P(A) > 0$，则同样有

$$P(A \cap B) = P(A) \cdot P(B \mid A).$$

该公式直接来自条件概率的定义 $P(A \mid B) = \dfrac{P(A \cap B)}{P(B)}$，两边同乘 $P(B)$ 即得。对于三个事件 $A_1, A_2, A_3$，规则可链式推广：

$$P(A_1 \cap A_2 \cap A_3) = P(A_1) \cdot P(A_2 \mid A_1) \cdot P(A_3 \mid A_1 \cap A_2).$$

---

**例题。** 一个袋中装有 5 个红球与 3 个蓝球，共 8 个球。不放回地依次摸取两球，求两球均为红球的概率。

设 $A = \{\text{第一次取红球}\}$，$B = \{\text{第二次取红球}\}$。则

$$P(A) = \frac{5}{8}, \qquad P(B \mid A) = \frac{4}{7}.$$

由乘法规则，

$$P(A \cap B) = \frac{5}{8} \times \frac{4}{7} = \frac{20}{56} = \frac{5}{14} \approx 0.357.$$

---

**关键定理（独立事件的化简）。** 若 $A$ 与 $B$ 相互独立，则 $P(A \mid B) = P(A)$，乘法规则化简为

$$P(A \cap B) = P(A) \cdot P(B).$$

注意：**独立性与互斥性不同**。两个概率均为正的互斥事件 $A \cap B = \varnothing$ 必然不独立，因为 $P(A \cap B) = 0 \neq P(A)P(B)$。

---

**实验单元（SymPy）。**

```python
from fractions import Fraction

p_A  = Fraction(5, 8)          # P(第一次红球)
p_B_given_A = Fraction(4, 7)   # P(第二次红球 | 第一次红球)
p_AB = p_A * p_B_given_A       # 乘法规则
print(f"P(A ∩ B) = {p_AB}")    # 输出：5/14
```

运行上述代码可精确验证分数运算，避免浮点误差。将初始红球数改为变量，即可探究样本量对联合概率的影响。

### tree_diagram (18.9s)

## 树形图

**定义。** 设某随机试验由若干阶段依次进行，每个阶段的可能结果为有限集合。**树形图**（tree diagram）是一种有向无环图 $T = (V, E)$，其中根节点表示试验的初始状态，每条从父节点到子节点的有向边对应该阶段的一个可能结果，从根到任意叶节点的唯一路径则对应一个完整的样本点。若第 $i$ 阶段有 $k_i$ 个可能结果，则叶节点总数为 $\prod_{i=1}^{n} k_i$，样本空间的大小即为此乘积。

**工作示例。** 掷一枚均匀硬币两次，观察正面（H）与反面（T）。

- **第一层**：从根节点出发，分出两条边，分别标记为 $H$ 与 $T$。
- **第二层**：每个第一层节点再分出两条边，同样标记为 $H$ 与 $T$。

由此得到 $2 \times 2 = 4$ 个叶节点，对应样本空间
$$\Omega = \{HH,\; HT,\; TH,\; TT\}.$$
事件"恰好出现一次正面"对应叶节点 $\{HT, TH\}$，其概率为
$$P(\text{恰好一次 }H) = \frac{2}{4} = \frac{1}{2}.$$
沿每条路径将各边概率相乘，即可得到对应样本点的概率，这正是乘法原理在概率论中的直接体现。

**关键定理（乘法计数原理）。** 若一个试验由 $n$ 个相互独立的阶段构成，第 $i$ 阶段恰有 $k_i$ 种可能结果，则所有可能的结果总数为
$$N = k_1 \times k_2 \times \cdots \times k_n = \prod_{i=1}^{n} k_i.$$
在概率语境下，若各阶段独立且第 $i$ 阶段第 $j$ 个结果的概率为 $p_{ij}$，则某一完整路径 $(j_1, j_2, \ldots, j_n)$ 的概率为 $\prod_{i=1}^{n} p_{i,j_i}$。

**实验单元（SymPy）。**

```python
from itertools import product
from sympy import Rational

outcomes = ['H', 'T']
p = {o: Rational(1, 2) for o in outcomes}

sample_space = list(product(outcomes, repeat=2))
prob = {s: p[s[0]] * p[s[1]] for s in sample_space}

event = [s for s in sample_space if s.count('H') == 1]
print("样本空间：", sample_space)
print("事件概率：", sum(prob[s] for s in event))
```

运行上述代码将输出 $\tfrac{1}{2}$，与手算结果吻合，验证了树形图路径概率的乘法结构。

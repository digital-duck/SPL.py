## Univariate Data

**Definition.** A *univariate dataset* is a finite sequence of real-valued observations of a single measurable attribute. Formally, let $\Omega$ be a sample space and $X : \Omega \to \mathbb{R}$ a random variable. Observing $X$ on $n$ independent draws produces the dataset

$$\mathcal{D} = \{x_1, x_2, \ldots, x_n\} \subset \mathbb{R},$$

where each $x_i = X(\omega_i)$ for some outcome $\omega_i \in \Omega$. The prefix *uni-* (Latin: one) emphasises that exactly one attribute is recorded per observation; no pairing with a second variable is implied. Univariate analysis therefore concerns the distribution of a single quantity — its centre, spread, shape, and extremes.

**Worked Example.** A laboratory thermometer records the following seven daily high temperatures (°C) in a city during one week:

$$22,\ 19,\ 25,\ 23,\ 18,\ 21,\ 24.$$

This is a univariate dataset with $n = 7$. Sorting the values gives the *order statistics* $x_{(1)} \le x_{(2)} \le \cdots \le x_{(7)}$:

$$18,\ 19,\ 21,\ 22,\ 23,\ 24,\ 25.$$

The sample mean is

$$\bar{x} = \frac{1}{7}\sum_{i=1}^{7} x_i = \frac{152}{7} \approx 21.71 \text{ °C},$$

and the sample variance is

$$s^2 = \frac{1}{n-1}\sum_{i=1}^{7}(x_i - \bar{x})^2 \approx 5.90 \text{ °C}^2.$$

**Key Theorem (Law of Large Numbers).** Let $X_1, X_2, \ldots$ be independent, identically distributed random variables with finite mean $\mu = \mathbb{E}[X]$. Then the sample mean converges in probability to the true mean:

$$\bar{X}_n = \frac{1}{n}\sum_{i=1}^{n} X_i \xrightarrow{p} \mu \quad \text{as } n \to \infty.$$

This guarantees that collecting more univariate observations drives the sample mean arbitrarily close to the population mean, providing the theoretical foundation for statistical estimation from data.

**Lab Cell (SymPy/Python).**

```python
from sympy.stats import Normal, E, variance, sample
import sympy as sp

X = Normal('X', mean=sp.Rational(22), std=sp.sqrt(6))
print("Population mean    :", E(X))
print("Population variance:", variance(X))

data = [22, 19, 25, 23, 18, 21, 24]
n = len(data)
x_bar = sp.Rational(sum(data), n)
s2 = sum((sp.Rational(x) - x_bar)**2 for x in data) / (n - 1)
print("Sample mean        :", x_bar)
print("Sample variance    :", sp.nsimplify(s2))
```

Running this cell confirms the hand calculations above and illustrates how symbolic computation preserves exact rational arithmetic throughout.

## Pareto Chart

**Definition.** A *Pareto chart* is a composite display that combines a descending bar chart of categorical frequencies (or costs) with a cumulative-percentage line overlaid on a secondary axis. Given a finite set of categories $\mathcal{C} = \{c_1, c_2, \ldots, c_k\}$ with associated counts $n_1 \geq n_2 \geq \cdots \geq n_k > 0$ and total $N = \sum_{i=1}^{k} n_i$, the cumulative relative frequency after the $j$-th category is

$$F_j = \frac{1}{N}\sum_{i=1}^{j} n_i, \qquad j = 1, 2, \ldots, k.$$

The chart encodes the *Pareto principle* (the "80–20 rule"): in many empirical distributions, roughly $20\%$ of categories account for $80\%$ of the total effect. A vertical reference line at $F_j = 0.80$ identifies the *vital few* categories that dominate the aggregate.

**Worked Example.** A software team logs $N = 200$ bug reports across five defect types:

| Category | Count $n_i$ | Cumulative $F_j$ |
|---|---|---|
| UI layout | 80 | 0.40 |
| API timeout | 60 | 0.70 |
| Auth error | 30 | 0.85 |
| Data parse | 20 | 0.95 |
| Other | 10 | 1.00 |

The 80 % threshold is crossed at $j = 3$ (Auth error), meaning three categories—UI layout, API timeout, and Auth error—account for $170/200 = 85\%$ of all defects. Prioritising fixes in these three classes addresses the bulk of user-reported failures.

**Theorem (Concentration Inequality).** If counts $\{n_i\}$ follow a Zipf distribution with exponent $s > 1$, i.e. $n_i \propto i^{-s}$, then the fraction of categories required to explain proportion $p$ of the total satisfies

$$\frac{j^*}{k} \;\approx\; p^{1/(1-s^{-1})} \quad \text{as } k \to \infty.$$

For $s = 2$ this gives $j^*/k \approx p^2$; setting $p = 0.80$ yields $j^*/k \approx 0.64$, confirming that heavy-tailed distributions concentrate mass rapidly in the leading categories.

**Lab Cell (SymPy / Matplotlib)**

```python
import matplotlib.pyplot as plt
import numpy as np

categories = ["UI layout", "API timeout", "Auth error", "Data parse", "Other"]
counts     = [80, 60, 30, 20, 10]
cumulative = np.cumsum(counts) / sum(counts) * 100

fig, ax1 = plt.subplots()
ax1.bar(categories, counts, color="steelblue")
ax1.set_ylabel("Count")

ax2 = ax1.twinx()
ax2.plot(categories, cumulative, color="crimson", marker="o")
ax2.axhline(80, linestyle="--", color="gray")
ax2.set_ylabel("Cumulative %")
plt.title("Pareto Chart — Bug Reports")
plt.tight_layout()
plt.show()
```

Running this cell renders the descending bars with the cumulative curve; the dashed line at $80\%$ visually isolates the vital-few categories for immediate action.

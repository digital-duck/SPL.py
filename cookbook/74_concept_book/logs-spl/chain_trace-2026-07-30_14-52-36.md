## Bias

**Definition.** Let $\hat{\theta}$ be an estimator of an unknown parameter $\theta$. The *bias* of $\hat{\theta}$ is defined as

$$\operatorname{Bias}(\hat{\theta}) = \mathbb{E}[\hat{\theta}] - \theta,$$

where the expectation is taken over all possible samples of the data. An estimator is called *unbiased* if $\operatorname{Bias}(\hat{\theta}) = 0$, meaning its expected value equals the true parameter it seeks to estimate. Bias is a systematic error: it persists no matter how large the sample grows, distinguishing it from random sampling variability, which vanishes as $n \to \infty$.

**Worked Example.** Suppose $X_1, X_2, \ldots, X_n$ are independent draws from a population with mean $\mu$ and variance $\sigma^2$. Consider the sample variance computed with denominator $n$:

$$S_n^2 = \frac{1}{n}\sum_{i=1}^{n}(X_i - \bar{X})^2, \qquad \bar{X} = \frac{1}{n}\sum_{i=1}^{n} X_i.$$

A direct calculation shows $\mathbb{E}[S_n^2] = \frac{n-1}{n}\sigma^2$, so

$$\operatorname{Bias}(S_n^2) = \frac{n-1}{n}\sigma^2 - \sigma^2 = -\frac{\sigma^2}{n}.$$

The estimator systematically *underestimates* the true variance. Replacing the denominator with $n-1$ yields the corrected sample variance $s^2 = \frac{1}{n-1}\sum(X_i - \bar{X})^2$, which satisfies $\mathbb{E}[s^2] = \sigma^2$ and is therefore unbiased.

**Key Theorem (Bias–Variance Decomposition).** For any estimator $\hat{\theta}$ of $\theta$, the mean squared error (MSE) decomposes as

$$\operatorname{MSE}(\hat{\theta}) = \mathbb{E}\!\left[(\hat{\theta} - \theta)^2\right] = \operatorname{Var}(\hat{\theta}) + \left[\operatorname{Bias}(\hat{\theta})\right]^2.$$

This identity reveals the fundamental trade-off in statistical estimation: reducing bias often inflates variance, and vice versa. An unbiased estimator is not automatically preferable; if a small, controlled bias substantially reduces variance, the biased estimator may achieve lower MSE in practice.

**Lab Cell.**

```python
import sympy as sp

n, sigma2 = sp.symbols('n sigma^2', positive=True)

# Bias of the naive sample variance (denominator n)
E_Sn2 = (n - 1) / n * sigma2
bias   = sp.simplify(E_Sn2 - sigma2)
print("Bias(S_n^2) =", bias)          # -sigma^2/n

# Confirm corrected estimator is unbiased
E_s2 = sp.simplify((n / (n - 1)) * E_Sn2)
print("E[s^2]      =", E_s2)          # sigma^2
```

## Fairness

**Definition.** Let $\mathcal{X}$ denote a feature space, $Y \in \{0,1\}$ a binary outcome, and $A \in \{0,1\}$ a protected attribute (e.g., gender, race). A classifier $\hat{Y} = f(X)$ is said to satisfy *demographic parity* if

$$P(\hat{Y} = 1 \mid A = 0) = P(\hat{Y} = 1 \mid A = 1).$$

More generally, fairness is a family of constraints on the joint distribution of $(\hat{Y}, Y, A)$ that formalize the intuition that a model's decisions should not systematically disadvantage a protected group. Three canonical criteria are:

- **Demographic parity**: equal positive-prediction rates across groups.
- **Equalized odds**: $P(\hat{Y} = 1 \mid Y = y, A = 0) = P(\hat{Y} = 1 \mid Y = y, A = 1)$ for $y \in \{0,1\}$ — equal true-positive *and* false-positive rates.
- **Calibration**: $P(Y = 1 \mid \hat{p}, A = a)$ is the same function of $\hat{p}$ for all $a$, meaning predicted probabilities carry the same meaning across groups.

**Worked Example.** A loan-approval model yields positive decisions at rate $0.60$ for Group $A=0$ and $0.45$ for Group $A=1$. The demographic-parity gap is $|0.60 - 0.45| = 0.15$, which exceeds the commonly adopted tolerance of $0.05$, so the model fails demographic parity. To measure equalized odds one additionally inspects the confusion matrix stratified by $A$; if the false-negative rate for $A=1$ exceeds that for $A=0$, qualified applicants in the minority group are systematically denied.

**Key Theorem (Impossibility of Simultaneous Fairness, Chouldechova 2017).** When base rates differ across groups ($P(Y=1 \mid A=0) \neq P(Y=1 \mid A=1)$) and $\hat{Y}$ is a non-trivial predictor, demographic parity, equalized odds, and calibration cannot all hold simultaneously. This result implies that practitioners must consciously choose which criterion to optimize given the application's ethical priorities.

**Lab Cell.**

```python
from sympy import symbols, Rational, Abs

p0, p1 = Rational(60, 100), Rational(45, 100)   # positive-prediction rates
gap = Abs(p0 - p1)
print("Demographic-parity gap:", gap)            # 3/20

# Equalized-odds check (illustrative confusion-matrix values)
tpr0, tpr1 = Rational(80, 100), Rational(65, 100)
fpr0, fpr1 = Rational(20, 100), Rational(18, 100)
print("TPR gap:", Abs(tpr0 - tpr1))             # 3/20
print("FPR gap:", Abs(fpr0 - fpr1))             # 1/50
print("Equalized odds satisfied:", gap == 0 and Abs(tpr0-tpr1) == 0)
```

Running this cell reveals that neither demographic parity nor equalized odds is satisfied, illustrating how a single numeric threshold can encode multiple distinct forms of bias.

## Explainable Ai

**Definition.** An *explainable AI* (XAI) system is a machine-learning model $f : \mathcal{X} \to \mathcal{Y}$ paired with an explanation function $e : \mathcal{X} \times \mathcal{Y} \to \mathcal{E}$, where $\mathcal{E}$ is a human-interpretable representation space. Formally, $e(\mathbf{x}, \hat{y})$ produces a description—such as a feature-importance vector or a decision rule—that faithfully characterizes why $f(\mathbf{x}) = \hat{y}$. Faithfulness is quantified by the *fidelity* of $e$ with respect to $f$ on a neighborhood $\mathcal{N}(\mathbf{x})$:

$$\text{Fidelity}(e, f, \mathbf{x}) = 1 - \frac{1}{|\mathcal{N}(\mathbf{x})|}\sum_{\mathbf{z} \in \mathcal{N}(\mathbf{x})} \mathbf{1}\bigl[e(\mathbf{z}, f(\mathbf{z})) \neq f(\mathbf{z})\bigr].$$

A high-fidelity explanation approximates the black-box model locally, even when no globally interpretable surrogate exists.

**Worked Example.** Consider a neural network trained to approve or deny loan applications. Given an applicant vector $\mathbf{x} = (\text{income}, \text{debt}, \text{credit\_score})$, the model outputs $\hat{y} = \text{deny}$. Using the LIME algorithm (Local Interpretable Model-agnostic Explanations), we sample $N = 500$ perturbed neighbors $\mathbf{z}^{(i)}$ around $\mathbf{x}$, weight each by $\pi(\mathbf{x}, \mathbf{z}^{(i)}) = \exp\!\left(-\tfrac{\|\mathbf{x} - \mathbf{z}^{(i)}\|^2}{2\sigma^2}\right)$, and fit a weighted linear surrogate:

$$\hat{g}(\mathbf{z}) = \beta_0 + \beta_1 z_1 + \beta_2 z_2 + \beta_3 z_3.$$

Suppose the solution yields $\beta_3 = -0.72$ (the largest-magnitude coefficient). The explanation is: *credit score is the dominant negative factor for this decision*, giving the applicant actionable feedback.

**Key Theorem (LIME Consistency).** Let $g^*$ minimize the locally weighted squared loss $\mathcal{L}(g, f, \pi_\mathbf{x}) = \sum_{\mathbf{z}} \pi_\mathbf{x}(\mathbf{z})\,[f(\mathbf{z}) - g(\mathbf{z})]^2$ over a function class $\mathcal{G}$ with complexity $\Omega(g)$. Then $g^*$ converges to the first-order Taylor expansion of $f$ at $\mathbf{x}$ as $\sigma \to 0$, provided $f$ is differentiable at $\mathbf{x}$.

This theorem shows that LIME explanations are locally exact in the limit—they are not arbitrary but grounded in the model's gradient structure.

```python
from sympy import symbols, exp, diff, lambdify

```

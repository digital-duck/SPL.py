### function (0.0s)

## Function

A function is a rule that assigns to each input exactly one output. If $f$ is a function from a set $X$ (the domain) to a set $Y$ (the codomain), we write $f: X \to Y$, and for each $x \in X$ there is a unique element $f(x) \in Y$. This uniqueness condition — one output per input — is the entire content of the definition. It is what separates a function from a general relation, and it is why the vertical line test works: a curve represents a function precisely when no vertical line crosses it more than once, since two intersection points would mean one input producing two outputs.

The crucial shift for calculus is to stop thinking of a function as "a formula" and start thinking of it as a mapping — an assignment of outputs to inputs that may or may not have a closed-form expression. Consider $f(x) = x^2$, $g(x) = \sin(x)$, and the piecewise function
$$
h(x) = \begin{cases} x & x < 0 \\ x^2 & x \geq 0 \end{cases}.
$$
Despite looking structurally different, all three are functions in exactly the same sense: each obeys the one-output rule on its domain. A table of values, a graph, or even an algorithm that computes an output from an input all qualify as functions, provided the assignment is well-defined.

This mapping-first view matters for problem-solving because it tells you what to check before applying any calculus tool. Suppose you're asked whether $y^2 = x$ defines $y$ as a function of $x$. Solve for $y$: $y = \pm\sqrt{x}$. For $x = 4$, this gives $y = 2$ and $y = -2$ — two outputs for one input — so $y^2 = x$ does *not* define a function of $x$. But if you restrict to $y = \sqrt{x}$ alone (discarding the negative branch), the rule now assigns exactly one output to each $x \geq 0$, and it is a function with domain $[0, \infty)$.

This habit — asking "does exactly one output correspond to each input, and over what domain?" — is the first check you'll run before differentiating, composing, or inverting any expression, since operations like finding $f^{-1}$ or evaluating $\lim_{x \to a} f(x)$ presuppose that $f$ is a genuine function to begin with.

### vector_space (0.0s)

## Vector Space

A **vector space** is a set $V$ equipped with two operations — vector addition and scalar multiplication by elements of a field (typically $\mathbb{R}$) — that satisfy ten axioms: closure under addition, closure under scalar multiplication, commutativity of addition, associativity of addition, existence of a zero vector $\mathbf{0}$, existence of additive inverses, compatibility of scalar multiplication ($a(b\mathbf{v}) = (ab)\mathbf{v}$), the identity property ($1\mathbf{v} = \mathbf{v}$), and two distributive laws ($a(\mathbf{u}+\mathbf{v}) = a\mathbf{u}+a\mathbf{v}$ and $(a+b)\mathbf{v} = a\mathbf{v}+b\mathbf{v}$). This axiomatic definition is the substance of the concept: it is what lets a single theory govern arrows in $\mathbb{R}^3$, polynomials, matrices, and function spaces simultaneously, because none of the axioms reference "arrows" or "coordinates" — only the algebraic behavior of $+$ and scalar multiplication.

**Worked example.** Consider $V = \mathbb{R}^2$ with the usual coordinatewise addition and scaling. Verify distributivity for $\mathbf{u} = (1,2)$, $\mathbf{v} = (3,-1)$, $a = 2$:
$$
a(\mathbf{u}+\mathbf{v}) = 2\big((1,2)+(3,-1)\big) = 2(4,1) = (8,2)
$$
$$
a\mathbf{u} + a\mathbf{v} = (2,4) + (6,-2) = (8,2)
$$
The two sides agree, as the axiom guarantees for every choice of vectors and scalar — not just this one.

**Problem-solving application.** The real payoff of the axioms is recognizing vector spaces in disguise. Let $P_2$ be the set of polynomials of degree at most 2, $\{a_0 + a_1x + a_2x^2\}$, with ordinary polynomial addition and scalar multiplication. To confirm $P_2$ is a vector space, check the axioms directly: adding two such polynomials or scaling one always yields another polynomial in $P_2$ (closure), the zero polynomial serves as $\mathbf{0}$, and every polynomial has an additive inverse (negate each coefficient). Because the remaining axioms follow from ordinary arithmetic on real-number coefficients, $P_2$ qualifies — even though nothing about it looks like an arrow. This matters practically: once you prove $V$ is a vector space, every theorem about spans, linear independence, bases, and dimension — originally proved using only the ten axioms — applies automatically to $P_2$, to $2\times2$ matrices, or to solution sets of homogeneous linear differential equations, without re-deriving anything. Verifying the axioms is therefore not a formality; it's the step that unlocks an entire toolbox of linear algebra for a new mathematical object.

### linear_transformation (35.9s)

## Linear Transformation

A linear transformation is a function $T: U \to V$ between two vector spaces that preserves vector addition and scalar multiplication. Formally, $T$ is linear if for all vectors $\mathbf{u}, \mathbf{w} \in U$ and every scalar $c$,

$$T(\mathbf{u} + \mathbf{w}) = T(\mathbf{u}) + T(\mathbf{w}), \qquad T(c\mathbf{u}) = cT(\mathbf{u}).$$

Combined, these give $T(a\mathbf{u} + b\mathbf{w}) = aT(\mathbf{u}) + bT(\mathbf{w})$ for any scalars $a, b$ — the output on a combination of inputs is built from the outputs on the pieces. This built-in property of every linear transformation, rather than a separate object, is what makes the definition so useful in practice.

**Worked example.** Let $T: \mathbb{R}^2 \to \mathbb{R}^2$ be defined by $T(x, y) = (2x + y, \, x - y)$. Check linearity directly: for $\mathbf{u} = (x_1, y_1)$ and $\mathbf{w} = (x_2, y_2)$,

$$T(\mathbf{u} + \mathbf{w}) = (2(x_1+x_2) + (y_1+y_2),\, (x_1+x_2) - (y_1+y_2)) = T(\mathbf{u}) + T(\mathbf{w}),$$

and scaling by $c$ passes through each coordinate the same way, confirming $T(c\mathbf{u}) = cT(\mathbf{u})$. Notice that $T$'s formula is exactly matrix-vector multiplication in disguise: $T(\mathbf{x}) = A\mathbf{x}$ with $A = \begin{pmatrix} 2 & 1 \\ 1 & -1 \end{pmatrix}$. That match is no accident — reading the coefficients of $x$ and $y$ straight off the formula and stacking them as rows always reproduces $T$, since matrix-vector multiplication is itself linear in the vector argument.

**Problem-solving application.** Suppose you're told $T(1,0) = (2,1)$ and $T(0,1) = (1,-1)$, without being given a formula for $T$ at all. Because $T$ is linear, its defining property lets you compute $T$ on *any* input from these two values alone: $T(3,4) = 3T(1,0) + 4T(0,1) = 3(2,1) + 4(1,-1) = (10,-1)$. This is the practical payoff of linearity — a transformation on an infinite space is fully pinned down by its action on just two vectors, which is why linear transformations underlie computer graphics (rotations, scaling), quantum mechanics (operators on state spaces), and machine learning (weight matrices in neural network layers).

### matrix_vector_product (0.0s)

## Matrix Vector Product

Given an $m \times n$ matrix $A$ with columns $\mathbf{a}_1, \mathbf{a}_2, \dots, \mathbf{a}_n \in \mathbb{R}^m$, and a vector $\mathbf{u} \in \mathbb{R}^n$ with entries $u_1, \dots, u_n$, the matrix-vector product is defined as the linear combination of the columns of $A$ weighted by the entries of $\mathbf{u}$:

$$A\mathbf{u} = u_1 \mathbf{a}_1 + u_2 \mathbf{a}_2 + \cdots + u_n \mathbf{a}_n$$

This definition is the conceptual anchor for everything else linear algebra does with matrices: $A\mathbf{u}$ is not "row times column arithmetic" first and foremost — it is a weighted sum of vectors, and the result always lands in $\mathbb{R}^m$, the space spanned by $A$'s columns.

**Worked example.** Let

$$A = \begin{pmatrix} 1 & 0 & 2 \\ -1 & 3 & 1 \end{pmatrix}, \qquad \mathbf{u} = \begin{pmatrix} 2 \\ 1 \\ -1 \end{pmatrix}$$

Then

$$A\mathbf{u} = 2\begin{pmatrix}1\\-1\end{pmatrix} + 1\begin{pmatrix}0\\3\end{pmatrix} + (-1)\begin{pmatrix}2\\1\end{pmatrix} = \begin{pmatrix}2\\-2\end{pmatrix} + \begin{pmatrix}0\\3\end{pmatrix} + \begin{pmatrix}-2\\-1\end{pmatrix} = \begin{pmatrix}-2\\0\end{pmatrix}$$

The familiar row-by-row computation (dot each row of $A$ with $\mathbf{u}$) gives the identical answer, and is useful for hand computation, but the column-combination view is what reveals *why* the answer has the shape it does: it is a point reachable by scaling and adding $A$'s columns.

**Why this matters for problem-solving.** The column view converts two of the most common linear algebra questions into span/independence questions you already know how to reason about. First: "does $A\mathbf{x} = \mathbf{b}$ have a solution?" is exactly the question "is $\mathbf{b}$ in the span of $A$'s columns?" Second: "is the solution unique?" is exactly the question "are $A$'s columns linearly independent?" — if they are dependent, some nonzero $\mathbf{u}$ combines them to $\mathbf{0}$, and you can add that $\mathbf{u}$ to any solution to get another one.

For instance, if $A$'s three columns above happen to be linearly independent (verify: no nontrivial combination gives $\mathbf{0}$), then every vector in $\mathbb{R}^2$ that lies in their span has a *unique* representation as $A\mathbf{u}$ — a fact you will rely on constantly when solving linear systems, computing coordinates in a new basis, or checking whether a transformation is invertible.

### injective_linear_transformation (13.2s)

## Injective Linear Transformation

A linear transformation $T: V \to W$ is **injective** (or one-to-one) if distinct inputs always produce distinct outputs: $T(x) = T(y)$ implies $x = y$. Equivalently, $T$ never collapses two different vectors onto the same image.

Because $T$ is linear, injectivity has a remarkably clean test. Suppose $T(x) = T(y)$. By linearity, $T(x) - T(y) = T(x - y) = 0$. So $T(x) = T(y)$ forces $x = y$ exactly when $T(x-y) = 0$ forces $x - y = 0$. This proves:

$$T \text{ is injective} \iff \ker(T) = \{0\}$$

where $\ker(T) = \{v \in V : T(v) = 0\}$ is the **kernel** (null space) of $T$. This theorem is the whole reason injectivity is worth teaching for linear maps: checking "does $T(x)=T(y)$ imply $x=y$" for all pairs is infeasible, but checking whether the kernel contains only the zero vector is a single, mechanical computation — solve $T(v) = 0$ and see if $v = 0$ is the only solution.

**Worked example.** Let $T: \mathbb{R}^3 \to \mathbb{R}^3$ be given by the matrix
$$A = \begin{pmatrix} 1 & 2 & 0 \\ 0 & 1 & 1 \\ 1 & 3 & 1 \end{pmatrix}.$$
To test injectivity, solve $Av = 0$. Row-reducing $A$: row 3 minus row 1 gives $(0,1,1)$, which equals row 2 — so row 3 is redundant. The reduced system has only two independent equations in three unknowns, giving a free variable. Setting $v_3 = t$, back-substitution yields $v_2 = -t$, $v_1 = 2t$, so $v = t(2,-1,1)$ is a nonzero solution for any $t \neq 0$. Since $\ker(T) \neq \{0\}$, $T$ is **not injective**.

**Problem-solving application.** For a square matrix, this kernel test connects directly to the determinant: $T$ is injective if and only if $\det(A) \neq 0$ (equivalently, $A$ has full rank $n$). Checking $\det(A) = 0$ above confirms the failure quickly. This link matters in practice — in data compression, signal processing, and solving linear systems $Av = b$, injectivity guarantees that if a solution exists, it is unique. When designing a linear encoding (e.g., a cryptographic or error-correcting transformation), you deliberately choose $A$ with $\ker(T) = \{0\}$ so that no information is lost: every distinct input message maps to a distinct output.

### matrices_build_linear_transformations (31.2s)

## Matrices Build Linear Transformations

Every $m \times n$ matrix $A$ defines a function $T: \mathbb{C}^n \to \mathbb{C}^m$ by the rule $T(\mathbf{x}) = A\mathbf{x}$. This is not merely an analogy — matrix-vector multiplication is *constructed* precisely so that $T$ satisfies the two defining properties of a linear transformation:

$$T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v}), \qquad T(c\mathbf{u}) = cT(\mathbf{u})$$

Both hold because matrix-vector multiplication distributes over vector addition and commutes with scalar multiplication, term by term in the underlying sum $A\mathbf{x} = \sum_{j=1}^n x_j \mathbf{a}_j$, where $\mathbf{a}_j$ is the $j$-th column of $A$. So $T(\mathbf{x})$ is always a linear combination of the columns of $A$, with the entries of $\mathbf{x}$ as the coefficients.

**Worked example.** Let

$$A = \begin{pmatrix} 1 & 2 \\ 0 & -1 \\ 3 & 1 \end{pmatrix}$$

so $T: \mathbb{C}^2 \to \mathbb{C}^3$. For $\mathbf{x} = \begin{pmatrix} 2 \\ -1 \end{pmatrix}$,

$$T(\mathbf{x}) = A\mathbf{x} = 2\begin{pmatrix} 1 \\ 0 \\ 3 \end{pmatrix} - 1\begin{pmatrix} 2 \\ -1 \\ 1 \end{pmatrix} = \begin{pmatrix} 0 \\ 1 \\ 5 \end{pmatrix}$$

Notice that $T$ takes a $2$-dimensional input and produces a $3$-dimensional output — the shape of $A$ dictates the domain and codomain of $T$ exactly: $n$ columns fix the input dimension, $m$ rows fix the output dimension.

**Problem-solving application.** The worked example shows more than a single computation: the columns of $A$, namely $\begin{pmatrix}1\\0\\3\end{pmatrix}$ and $\begin{pmatrix}2\\-1\\1\end{pmatrix}$, are exactly the images $T(\mathbf{e}_1)$ and $T(\mathbf{e}_2)$ of the standard basis vectors — the vectors with a single $1$ and zeros elsewhere. This is a general strategy: to determine or verify a linear transformation, it suffices to know (or check) its action on a basis, since $T(\mathbf{x})$ for arbitrary $\mathbf{x}$ is forced by linearity once the images of basis vectors are fixed. Conversely, given any linear transformation $T$, you can recover its matrix column by column: the $j$-th column of $A$ is simply $T(\mathbf{e}_j)$. So instead of describing a transformation in words, you only ever need to specify where the basis vectors go, and matrix-vector multiplication automatically extends that rule to every input. This equivalence — every matrix gives a linear transformation, and every linear transformation between finite-dimensional spaces comes from a matrix — is the foundation for representing systems of linear equations, geometric transformations, and data transformations in machine learning all as matrix-vector products.

### preimage (11.8s)

## Preimage

Given a linear transformation $T: V \to W$ and a vector $\mathbf{w} \in W$, the **preimage** of $\mathbf{w}$ under $T$ is the set of all vectors in $V$ that $T$ sends to $\mathbf{w}$:

$$T^{-1}(\mathbf{w}) = \{\mathbf{v} \in V : T(\mathbf{v}) = \mathbf{w}\}$$

The notation $T^{-1}$ here does not imply $T$ has an inverse function — the preimage is defined for *any* linear transformation, invertible or not, and it is a set, possibly empty, possibly infinite, not a single vector.

**Worked example.** Let $T: \mathbb{R}^3 \to \mathbb{R}^2$ be defined by $T(x, y, z) = (x + y, y + z)$. Find the preimage of $\mathbf{w} = (2, 3)$. We need all $(x, y, z)$ satisfying $x + y = 2$ and $y + z = 3$. Solving in terms of a free parameter $y = t$: $x = 2 - t$, $z = 3 - t$. So

$$T^{-1}(2,3) = \{(2 - t,\; t,\; 3 - t) : t \in \mathbb{R}\}$$

This is a line in $\mathbb{R}^3$ — a one-parameter family of solutions, not a single point, because $T$ maps a 3-dimensional space onto a 2-dimensional one and necessarily collapses information.

**Structure of the preimage.** The key theorem is that $T^{-1}(\mathbf{w})$ is either empty or a coset of $\ker(T)$: if $\mathbf{v}_0$ is any one particular solution to $T(\mathbf{v}) = \mathbf{w}$, then

$$T^{-1}(\mathbf{w}) = \mathbf{v}_0 + \ker(T) = \{\mathbf{v}_0 + \mathbf{k} : \mathbf{k} \in \ker(T)\}$$

This follows from linearity: if $T(\mathbf{v}_0) = \mathbf{w}$ and $T(\mathbf{k}) = \mathbf{0}$, then $T(\mathbf{v}_0 + \mathbf{k}) = \mathbf{w}$; conversely, if $T(\mathbf{v}) = \mathbf{w}$ as well, then $T(\mathbf{v} - \mathbf{v}_0) = \mathbf{0}$, so $\mathbf{v} - \mathbf{v}_0 \in \ker(T)$. In the example above, $\ker(T)$ is the line $\{(-t, t, -t)\}$, matching the direction vector we found.

**Problem-solving application.** This structure is exactly why solving a linear system $A\mathbf{x} = \mathbf{b}$ splits into "find one particular solution, then add the general solution of the homogeneous system": the preimage of $\mathbf{b}$ under the transformation $\mathbf{x} \mapsto A\mathbf{x}$ *is* the solution set, and its size and shape are governed entirely by $\ker(T)$, which is why computing the kernel is the first step whenever a problem asks you to describe all solutions rather than just one.

### surjective_linear_transformation (10.3s)

## Surjective Linear Transformation

A linear transformation $T: V \to W$ is **surjective** (or **onto**) if every vector in the codomain $W$ is the image of at least one vector in the domain $V$. Formally, $T$ is surjective when for every $\mathbf{w} \in W$, there exists some $\mathbf{v} \in V$ such that $T(\mathbf{v}) = \mathbf{w}$. Equivalently, the range of $T$, defined as $\text{range}(T) = \{T(\mathbf{v}) : \mathbf{v} \in V\}$, equals the entire codomain: $\text{range}(T) = W$.

For transformations between finite-dimensional vector spaces, surjectivity has a clean dimensional test. The **Rank-Nullity Theorem** states:

$$
\dim(V) = \dim(\ker(T)) + \dim(\text{range}(T))
$$

Since $\text{range}(T)$ is a subspace of $W$, surjectivity requires $\dim(\text{range}(T)) = \dim(W)$. If $T$ is represented by an $m \times n$ matrix $A$ (mapping $\mathbb{R}^n \to \mathbb{R}^m$), then $T$ is surjective precisely when $\text{rank}(A) = m$ — the rows of $A$ are linearly independent, so the columns of $A$ span all of $\mathbb{R}^m$.

**Worked example.** Consider $T: \mathbb{R}^3 \to \mathbb{R}^2$ given by the matrix
$$
A = \begin{pmatrix} 1 & 0 & 2 \\ 0 & 1 & -1 \end{pmatrix}.
$$
The two rows are linearly independent, so $\text{rank}(A) = 2 = \dim(\mathbb{R}^2)$. Thus $T$ is surjective: for any target $\begin{pmatrix} a \\ b \end{pmatrix} \in \mathbb{R}^2$, choosing $\mathbf{v} = (a, b, 0)$ gives $T(\mathbf{v}) = (a, b)$, confirming a preimage exists for every output.

**Problem-solving application.** Surjectivity determines whether a linear system $A\mathbf{x} = \mathbf{b}$ is solvable for *every* possible $\mathbf{b}$, which matters in engineering when $\mathbf{b}$ represents an arbitrary target state or output signal. If $A$ is $m \times n$ with $m > n$, surjectivity onto $\mathbb{R}^m$ is impossible, since $\text{rank}(A) \le n < m$ — there simply aren't enough independent input directions to reach every output. This is why overdetermined systems (more equations than unknowns) generally fail to be surjective, and engineers instead seek least-squares approximations rather than exact solutions for arbitrary $\mathbf{b}$.

### linear_transformations_and_linear_systems (12.4s)

## Linear Transformations And Linear Systems

A linear system $A\mathbf{x} = \mathbf{b}$ is more than a list of equations to solve — its coefficient matrix $A$ defines a function $T:\mathbb{R}^n \to \mathbb{R}^m$ given by $T(\mathbf{x}) = A\mathbf{x}$. This function is a **linear transformation**: it satisfies $T(\mathbf{u}+\mathbf{v}) = T(\mathbf{u})+T(\mathbf{v})$ and $T(c\mathbf{u}) = cT(\mathbf{u})$ for all vectors $\mathbf{u},\mathbf{v}$ and scalars $c$. Solving $A\mathbf{x}=\mathbf{b}$ is exactly asking: for a given output $\mathbf{b}$, which inputs $\mathbf{x}$ map to it under $T$? This reframing converts questions about equations into questions about a function's range and one-to-one behavior.

Two properties of $T$ answer the two questions we always ask about a linear system.

**Existence of a solution** (the system is *consistent*) for every possible $\mathbf{b} \in \mathbb{R}^m$ holds exactly when $T$ is **surjective** (onto) — its range is all of $\mathbb{R}^m$. This happens precisely when the columns of $A$ span $\mathbb{R}^m$.

**Uniqueness of a solution** holds exactly when $T$ is **injective** (one-to-one). Since $T$ is linear, injectivity reduces to a clean test: $T$ is injective if and only if $T(\mathbf{x}) = \mathbf{0}$ implies $\mathbf{x} = \mathbf{0}$, i.e., the only solution to the homogeneous system $A\mathbf{x} = \mathbf{0}$ is the trivial one. Equivalently, the columns of $A$ must be linearly independent.

**Worked example.** Let
$$A = \begin{bmatrix} 1 & 2 \\ 2 & 4 \end{bmatrix}.$$
The columns $(1,2)$ and $(2,4)$ are parallel — linearly dependent — so $T:\mathbb{R}^2\to\mathbb{R}^2$ is not injective: $A\mathbf{x}=\mathbf{0}$ has nontrivial solutions like $\mathbf{x}=(2,-1)$. The columns also fail to span $\mathbb{R}^2$ (they lie on one line), so $T$ is not surjective either. Consequently $A\mathbf{x}=\mathbf{b}$ has no solution for most $\mathbf{b}$, and infinitely many when a solution exists.

**Problem-solving application.** When $A$ is square ($n=m$), injectivity and surjectivity turn out to be equivalent — both hold exactly when $\det(A) \neq 0$. So instead of separately checking existence and uniqueness for a square system, compute one determinant: if $\det(A)\neq 0$, $T$ is a bijection, and $A\mathbf{x}=\mathbf{b}$ has a unique solution for every $\mathbf{b}$. This single test collapses two structural questions about a transformation into one computational one.

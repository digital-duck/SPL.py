## Binary Search Tree

**Definition.** A *binary search tree* (BST) is a rooted binary tree in which every node $v$ stores a key $k(v)$ drawn from a totally ordered set, subject to the *BST invariant*: for every node $v$, all keys in the left subtree of $v$ are strictly less than $k(v)$, and all keys in the right subtree of $v$ are strictly greater than $k(v)$. Formally, if $L(v)$ and $R(v)$ denote the left and right subtrees,

$$\forall u \in L(v):\ k(u) < k(v), \qquad \forall u \in R(v):\ k(u) > k(v).$$

This invariant holds recursively at every node, not merely at the root.

**Worked Example.** Insert the sequence $\langle 5, 3, 7, 1, 4 \rangle$ into an initially empty BST. The first key, $5$, becomes the root. Key $3 < 5$ goes left; $7 > 5$ goes right. Key $1 < 5$, then $1 < 3$, so it becomes the left child of $3$. Key $4 < 5$, then $4 > 3$, so it becomes the right child of $3$. The resulting tree has height $h = 2$ and satisfies the BST invariant at every node. An in-order traversal (left $\to$ root $\to$ right) yields $\langle 1, 3, 4, 5, 7 \rangle$—the keys in sorted order, which is a direct consequence of the invariant.

**Key Theorem (Search Complexity).** A search, insertion, or deletion in a BST containing $n$ nodes requires $O(h)$ comparisons, where $h$ is the height of the tree. For a *balanced* BST, $h = \Theta(\log n)$, giving $O(\log n)$ worst-case operations. In the degenerate case—keys inserted in sorted order—the tree degenerates to a linked list with $h = n - 1$ and $O(n)$ operations. Self-balancing variants (AVL trees, red–black trees) maintain $h = O(\log n)$ unconditionally.

**Lab Cell (SymPy/Python).**

```python
# Minimal BST node; insert and in-order traversal
class Node:
    def __init__(self, key):
        self.key, self.left, self.right = key, None, None

def insert(root, key):
    if root is None:
        return Node(key)
    if key < root.key:
        root.left = insert(root.left, key)
    else:
        root.right = insert(root.right, key)
    return root

def inorder(root):
    return [] if root is None else inorder(root.left) + [root.key] + inorder(root.right)

root = None
for k in [5, 3, 7, 1, 4]:
    root = insert(root, k)

print(inorder(root))   # → [1, 3, 4, 5, 7]
```

## Tree Height

**Definition.** Let $T$ be a rooted tree with root $r$. The *height* of a node $v$, written $h(v)$, is the length of the longest path (measured in edges) from $v$ to any leaf in the subtree rooted at $v$. The *height of the tree*, written $h(T)$, is defined as the height of the root:

$$h(T) = h(r) = \max_{v \in \text{leaves}(T)} d(r, v),$$

where $d(r, v)$ denotes the number of edges on the unique path from $r$ to leaf $v$. Leaves themselves have height $0$. An empty tree is assigned height $-1$ by convention, which simplifies recursive formulae.

**Recursive characterisation.** For any internal node $v$ with children $c_1, c_2, \ldots, c_k$,

$$h(v) = 1 + \max_{1 \le i \le k} h(c_i).$$

This recurrence is the computational foundation of every tree-height algorithm.

**Worked example.** Consider the binary tree whose edges are $\{(A,B),(A,C),(B,D),(B,E),(C,F)\}$ with root $A$. Applying the recurrence bottom-up: $h(D)=h(E)=h(F)=0$; $h(B)=1+\max(0,0)=1$; $h(C)=1+\max(0)=1$; $h(A)=1+\max(1,1)=2$. Thus $h(T)=2$, confirmed by the path $A\to B\to D$ (or $A\to B\to E$), each containing exactly two edges.

**Theorem (height–node bound).** A binary tree with $n$ nodes satisfies

$$\lfloor \log_2 n \rfloor \le h(T) \le n-1.$$

The lower bound is achieved by a complete binary tree (levels filled left to right), where $n \approx 2^{h+1}$. The upper bound is achieved by a path graph (each node has exactly one child), which degenerates to a linked list.

*Proof sketch.* A complete binary tree of height $h$ contains at most $2^{h+1}-1$ nodes, giving $h \ge \log_2(n+1)-1 > \lfloor \log_2 n\rfloor - 1$, hence the lower bound. A path of $n$ nodes has $n-1$ edges from root to leaf, giving the upper bound. $\square$

**Lab cell.**

```python
from sympy import symbols, Function, Max, Integer
from sympy.combinatorics import *

def tree_height(adj, root):
    """Return height of rooted tree given as adjacency dict {node: [children]}."""
    children = adj.get(root, [])
    if not children:
        return 0
    return 1 + max(tree_height(adj, c) for c in children)

adj = {'A': ['B', 'C'], 'B': ['D', 'E'], 'C': ['F'], 'D': [], 'E': [], 'F': []}
print(tree_height(adj, 'A'))  # Expected: 2
```

## Avl Tree

**Definition.** An *AVL tree* (Adelson-Velsky and Landis, 1962) is a self-balancing binary search tree in which every node $v$ satisfies the *height-balance property*: the heights of its left and right subtrees differ by at most one. Formally, define the *balance factor* of $v$ as

$$\mathrm{bf}(v) = h(\text{left}(v)) - h(\text{right}(v)),$$

where $h(\emptyset) = -1$ by convention. The AVL invariant requires $\mathrm{bf}(v) \in \{-1, 0, +1\}$ for every node $v$ in the tree. Because this invariant is maintained after every insertion and deletion via *rotations*, the tree height is guaranteed to satisfy

$$h \leq 1.44 \log_2(n+2) - 1.33,$$

ensuring $O(\log n)$ worst-case time for search, insertion, and deletion.

**Worked Example.** Insert the keys $\{3, 2, 1\}$ into an empty AVL tree. After inserting 3 and 2 the balance factors are $\mathrm{bf}(3)=1$, $\mathrm{bf}(2)=0$ — the invariant holds. Inserting 1 yields $\mathrm{bf}(3)=2$, violating the invariant. This is a *left-left* case: node 3 is right-heavy on the left spine. A single *right rotation* at node 3 promotes node 2 as root, making 1 its left child and 3 its right child. After rotation: $\mathrm{bf}(2)=0$, $\mathrm{bf}(1)=0$, $\mathrm{bf}(3)=0$ — the invariant is restored.

**Key Theorem (Height Bound).** Let $N(h)$ denote the minimum number of nodes in an AVL tree of height $h$. Then $N(h) = N(h-1) + N(h-2) + 1$ with $N(-1)=0$, $N(0)=1$. This recurrence mirrors the Fibonacci sequence: $N(h) = F_{h+3} - 1$, where $F_k$ is the $k$-th Fibonacci number. Since $F_k \approx \phi^k/\sqrt{5}$ with $\phi = (1+\sqrt{5})/2$, inverting gives $h = O(\log n)$. Consequently, all standard dictionary operations run in $\Theta(\log n)$ worst-case time, unlike an unbalanced BST whose worst-case degrades to $\Theta(n)$.

**Lab Cell.**

```python
from sympy import symbols, Function, solve, log, sqrt, simplify

# Verify the height bound numerically
phi = (1 + sqrt(5)) / 2
n = symbols('n', positive=True)

# Minimum nodes at height h: N(h) ~ phi^(h+2)/sqrt(5) - 1
# Solve for h given n
h = symbols('h')
expr = phi**(h + 2) / sqrt(5) - 1 - n
h_bound = solve(expr, h)[0]
h_simplified = simplify(h_bound)
print("h ≤", h_simplified)          # ≈ 1.44 log(n)

# Confirm balance factors after right rotation on {3,2,1}
nodes = {1: (None, None), 2: (1, 3), 3: (None, None)}
def height(k):
    if k is None: return -1
    l, r = nodes[k]
    return 1 + max(height(l), height(r))

for k in [1, 2, 3]:
    l, r = nodes[k]
    print(f"bf({k}) = {height(l) - height(r)}")
```

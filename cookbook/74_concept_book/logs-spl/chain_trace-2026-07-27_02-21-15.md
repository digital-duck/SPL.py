## Natural Logarithm Integral Def

**定义（自然对数的积分定义）**

对任意实数 $x > 0$，自然对数函数定义为

$$\ln x = \int_1^x \frac{1}{t}\, dt.$$

此处积分表示以 $t$ 轴为基准、曲线 $y = \tfrac{1}{t}$ 与区间 $[1, x]$（或 $[x, 1]$，当 $x < 1$ 时取负值）所围成的有向面积。这一定义完全绕开了指数函数，从纯分析角度出发建立对数的理论基础。

---

**具体例子**

计算 $\ln 2$ 的近似值。令 $f(t) = \tfrac{1}{t}$，对区间 $[1, 2]$ 使用梯形法则，取两个子区间 $[1, 1.5]$ 与 $[1.5, 2]$，步长 $h = 0.5$：

$$\ln 2 \approx \frac{0.5}{2}\!\left(f(1) + 2f(1.5) + f(2)\right) = \frac{0.5}{2}\!\left(1 + \frac{4}{3} + \frac{1}{2}\right) = \frac{0.5}{2} \cdot \frac{17}{6} \approx 0.708.$$

精确值为 $\ln 2 \approx 0.6931$，误差约 $2.2\%$，加密分割后可系统地降低误差。

---

**核心定理**

**定理**（微积分基本定理的推论）：设 $F(x) = \int_1^x \tfrac{1}{t}\,dt$，则

1. $F'(x) = \dfrac{1}{x}$，对所有 $x > 0$ 成立；
2. $F(1) = 0$；
3. 对任意 $a, b > 0$，有 $F(ab) = F(a) + F(b)$。

**证明要点**：性质 1 直接由微积分基本定理得出。性质 3 令 $G(b) = F(ab) - F(a) - F(b)$，对 $b$ 求导得 $G'(b) = \tfrac{a}{ab} - \tfrac{1}{b} = 0$，故 $G$ 为常数；令 $b = 1$ 得 $G(1) = F(a) - F(a) - 0 = 0$，从而 $G \equiv 0$。$\blacksquare$

性质 3 正是对数法则 $\ln(ab) = \ln a + \ln b$ 的严格来源。

---

**实验单元（SymPy）**

```python
from sympy import *
t, x = symbols('t x', positive=True)

ln_def = Integral(1/t, (t, 1, x))
print("ln(x) 积分定义：", ln_def)
print("化简结果：      ", simplify(ln_def.doit()))

# 验证加法法则
a, b = symbols('a b', positive=True)
lhs = integrate(1/t, (t, 1, a*b))
rhs = integrate(1/t, (t, 1, a)) + integrate(1/t, (t, 1, b))
print("ln(ab) = ln(a)+ln(b)：", simplify(lhs - rhs) == 0)
```

运行上述代码，`simplify(lhs - rhs)` 应输出 `0`，从符号计算层面验证了性质 3。

## Exponential Function Def

### 定义

设 $a$ 为正实数且 $a \neq 1$，则**指数函数**（exponential function）定义为

$$f(x) = a^x, \quad x \in \mathbb{R}.$$

当 $a > 1$ 时，函数单调递增；当 $0 < a < 1$ 时，函数单调递减。自然指数函数取 $a = e$，其中 $e = \lim_{n \to \infty}\left(1 + \dfrac{1}{n}\right)^n \approx 2.71828$，在分析学中具有特殊地位。指数函数的定义域为 $(-\infty, +\infty)$，值域为 $(0, +\infty)$，且恒过点 $(0, 1)$，因为对任意底数均有 $a^0 = 1$。

### 例题

**问题：** 某细菌种群在理想条件下每小时数量翻倍，初始时有 $500$ 个细菌。求 $t$ 小时后的种群数量，并计算 $t = 3$ 时的结果。

**解：** 设 $N(t)$ 为 $t$ 小时后的细菌数量，则

$$N(t) = 500 \cdot 2^t.$$

当 $t = 3$ 时，

$$N(3) = 500 \cdot 2^3 = 500 \times 8 = 4000.$$

即经过 $3$ 小时，细菌数量增至 $4000$ 个。此模型体现了指数函数的核心特征：**增长量与当前量成正比**。

### 关键定理

**定理（指数函数的基本运算法则）：** 设 $a > 0$，$a \neq 1$，对任意 $x, y \in \mathbb{R}$，成立以下性质：

$$a^{x+y} = a^x \cdot a^y, \qquad a^{x-y} = \frac{a^x}{a^y}, \qquad (a^x)^y = a^{xy}.$$

**证明思路：** 对有理指数，上述性质由整数幂的定义通过归纳法可严格验证。对无理指数，利用实数的完备性将有理数列的极限延拓至无理数，从而保证运算法则在全体实数上成立。$\blacksquare$

推论：$f'(x) = a^x \ln a$，特别地，当 $a = e$ 时，$\dfrac{d}{dx} e^x = e^x$，即自然指数函数是唯一满足"导函数等于自身"的函数（至差一常数因子）。

### 实验单元（SymPy）

```python
from sympy import *
x, a = symbols('x a', positive=True)

# 定义指数函数并求导
f = a**x
df = diff(f, x)
print("f(x)  =", f)
print("f'(x) =", df)          # a**x * log(a)

# 自然指数函数的特殊性
g = exp(x)
print("d/dx e^x =", diff(g, x))  # e**x

# 数值验证：细菌模型 N(3)
N = Lambda(x, 500 * 2**x)
print("N(3) =", N(3))         # 4000
```

### exponential_decay_model (0.0s)

## Exponential Decay Model

### 定义

**指数衰减模型**描述一个量随时间以与其当前值成正比的速率减少的过程。设 $N(t)$ 为时刻 $t$ 时的量，则其变化率满足微分方程

$$\frac{dN}{dt} = -\lambda N(t), \quad \lambda > 0,$$

其中 $\lambda$ 称为**衰减常数**（decay constant），单位为时间的倒数。给定初始条件 $N(0) = N_0$，方程的唯一解为

$$N(t) = N_0 e^{-\lambda t}.$$

当 $t \to \infty$ 时，$N(t) \to 0$，体现出量的持续减少。另一常用参数为**半衰期** $t_{1/2}$，定义为量减少至初始值一半所需的时间，满足

$$N_0 e^{-\lambda t_{1/2}} = \frac{N_0}{2} \implies t_{1/2} = \frac{\ln 2}{\lambda}.$$

### 具体例题

碳-14（$^{14}\mathrm{C}$）的半衰期为 $t_{1/2} = 5730$ 年。考古学家测得某木炭样本中碳-14 的含量为初始值的 $25\%$，估算该样本的年龄。

由 $N(t) = N_0 e^{-\lambda t}$ 及条件 $N(t) = 0.25 N_0$，得

$$0.25 = e^{-\lambda t} \implies t = \frac{\ln 4}{\lambda} = \frac{2\ln 2}{\lambda} = 2 \cdot t_{1/2} = 2 \times 5730 = 11460 \text{ 年}.$$

因此，该样本距今约 $11460$ 年。

### 关键定理

**唯一性定理**：满足 $\dfrac{dN}{dt} = -\lambda N$（$\lambda > 0$）及初始条件 $N(0) = N_0$ 的连续可微函数唯一，为 $N(t) = N_0 e^{-\lambda t}$。

*证明思路*：将方程改写为 $\dfrac{dN}{N} = -\lambda\, dt$，两边积分得 $\ln N = -\lambda t + C$，由初始条件定出 $C = \ln N_0$，从而 $N(t) = N_0 e^{-\lambda t}$。唯一性由 Picard–Lindelöf 定理保证，因右端函数关于 $N$ 满足 Lipschitz 条件。$\blacksquare$

### 实验单元（SymPy）

```python
import sympy as sp

t, lam, N0 = sp.symbols('t lambda N_0', positive=True)

# 定义解析解
N = N0 * sp.exp(-lam * t)

# 验证满足微分方程
ode_check = sp.diff(N, t) + lam * N
print("ODE 验证（应为 0）：", sp.simplify(ode_check))

# 计算半衰期
t_half = sp.solve(N - N0 / 2, t)[0]
print("半衰期 t_(1/2) =", t_half)

# 碳-14 数值示例：lambda = ln2/5730
lam_val = sp.ln(2) / 5730
age = sp.solve(N0 * sp.exp(-lam_val * t) - 0.25 * N0, t)[0]
print("样本年龄（年）：", sp.simplify(age))
```

### newtons_law_of_cooling (18.9s)

## Newtons Law Of Cooling

**定义。** 设物体在时刻 $t$ 的温度为 $T(t)$，周围环境（热库）的温度为恒定常数 $T_{\text{env}}$。牛顿冷却定律断言：物体温度的变化率与其当前温度和环境温度之差成正比，即

$$\frac{dT}{dt} = -k\bigl(T(t) - T_{\text{env}}\bigr), \quad k > 0,$$

其中比例系数 $k$（单位：$\mathrm{s^{-1}}$）称为**冷却常数**，其大小取决于物体的材料性质、形状及与环境的接触方式。负号表明：当 $T > T_{\text{env}}$ 时，温度随时间下降；当 $T < T_{\text{env}}$ 时，温度随时间上升。

---

**求解过程。** 令 $u(t) = T(t) - T_{\text{env}}$，则上式化为

$$\frac{du}{dt} = -k\,u,$$

这是一阶线性齐次常微分方程。分离变量并积分：

$$\int \frac{du}{u} = -k\int dt \implies \ln|u| = -kt + C_0.$$

取指数，并将初始条件 $T(0) = T_0$ 代入，得到唯一解

$$\boxed{T(t) = T_{\text{env}} + (T_0 - T_{\text{env}})\,e^{-kt}.}$$

---

**具体例题。** 一杯咖啡初温 $T_0 = 90\,^\circ\mathrm{C}$，室温 $T_{\text{env}} = 20\,^\circ\mathrm{C}$。已知 $5$ 分钟后温度降至 $70\,^\circ\mathrm{C}$，求 $20$ 分钟后的温度。

*第一步：求 $k$。*

$$70 = 20 + 70\,e^{-5k} \implies e^{-5k} = \frac{50}{70} = \frac{5}{7} \implies k = \frac{1}{5}\ln\frac{7}{5} \approx 0.0673\,\mathrm{min^{-1}}.$$

*第二步：代入 $t = 20$。*

$$T(20) = 20 + 70\,e^{-20k} = 20 + 70\left(\frac{5}{7}\right)^4 \approx 20 + 70 \times 0.260 \approx 38.2\,^\circ\mathrm{C}.$$

---

**关键定理。** 在牛顿冷却定律的假设下，$T(t) - T_{\text{env}}$ 随时间呈**指数衰减**；半衰期为 $t_{1/2} = \dfrac{\ln 2}{k}$，与初始温差无关。这一结论是法医学中估计死亡时间的理论基础。

---

**实验代码（SymPy）**

```python
import sympy as sp

t, k, T0, Tenv = sp.symbols('t k T0 T_env', positive=True)
T = sp.Function('T')

ode = sp.Eq(T(t).diff(t), -k * (T(t) - Tenv))
sol = sp.dsolve(ode, T(t), ics={T(0): T0})
sp.pprint(sol)                          # 验证解析解

# 数值验证：咖啡例题
k_val = sp.Rational(1, 5) * sp.ln(sp.Rational(7, 5))
T_num = sol.rhs.subs({k: k_val, T0: 90, Tenv: 20})
sp.pprint(sp.simplify(T_num.subs(t, 20)))
```

## Graph

**Definition.** A graph is a pair $G = (V, E)$ where $V$ is a finite set of vertices and $E \subseteq \binom{V}{2}$ is a set of edges, each edge $\{u,v\}$ joining exactly two distinct vertices. (Variants relax this: multigraphs allow repeated edges, directed graphs replace $\binom{V}{2}$ with ordered pairs $V \times V$, and hypergraphs allow $E \subseteq 2^V$.) Write $n = |V|$, $m = |E|$. The degree $\deg(v)$ is the number of edges incident to $v$.

**Theorem (Handshake Lemma).** $\sum_{v \in V} \deg(v) = 2m$.

*Proof.* Each edge $\{u,v\}$ contributes exactly $1$ to $\deg(u)$ and $1$ to $\deg(v)$, hence $2$ to the sum over all vertices. Summing over the $m$ edges gives $2m$. $\blacksquare$

**Corollary.** The number of vertices of odd degree is even — an immediate parity argument on the sum above, and the standard opening lemma of the field (used, e.g., in the proof that Eulerian circuits require all-even degree).

**Literature context.** The abstract pair $(V,E)$ is the object of study of graph theory since Euler's 1736 Königsberg bridges paper, but the concept now bifurcates along several active axes: (i) *structural* graph theory (minors, treewidth, the Robertson–Seymour graph minor theorem) classifies which graph families are "simple," (ii) *algorithmic* graph theory studies the complexity of graph problems — many are polynomial (shortest path, matching, planarity testing), many are NP-hard (clique, coloring, Hamiltonicity), and the boundary between them is itself an object of ongoing classification (e.g., dichotomy theorems for constraint-satisfaction-flavored graph problems), and (iii) *spectral/probabilistic* graph theory studies random graph models ($G(n,p)$, preferential attachment) and eigenvalues of the adjacency/Laplacian matrix as proxies for connectivity, expansion, and mixing time. Open directions include tight complexity classifications for graph isomorphism-adjacent problems (isomorphism itself is now known to be quasipolynomial by Babai's 2015 result, but the exact complexity class remains unsettled), and extremal questions (Turán-type bounds) for many forbidden-subgraph families.

**Suggested investigation.** Implement the adjacency-list and adjacency-matrix representations of $G$ and empirically compare their asymptotic behavior: verify the handshake lemma on random graphs, then measure wall-clock and memory cost of BFS/DFS traversal, $O(n+m)$ in the list representation versus $O(n^2)$ in the matrix representation, across a sweep of $(n,m)$ with $m$ ranging from sparse ($m = O(n)$) to dense ($m = O(n^2)$). A natural extension: replicate a small piece of the Erdős–Rényi threshold phenomenon by simulating $G(n,p)$ near $p = \ln n / n$ and observing the emergence of a giant connected component.

## Graph Representation

**Definition.** A graph $G = (V, E)$ with $|V| = n$, $|E| = m$ admits several standard computational encodings:

- **Adjacency matrix**: $A \in \{0,1\}^{n \times n}$ (or $A \in \mathbb{R}^{n \times n}$ for weighted graphs), where $A_{ij} = 1$ iff $(i,j) \in E$.
- **Incidence matrix**: $B \in \{0,1\}^{n \times m}$ (undirected) or $B \in \{-1,0,1\}^{n \times m}$ (directed, oriented), where column $e = (i,j)$ has $B_{ie} = 1, B_{je} = -1$ (directed) or both entries $1$ (undirected).
- **Edge list**: the set $E$ stored as an unordered (or sorted) sequence of pairs, optionally with weights.
- **Adjacency list**: a map $v \mapsto N(v)$, the neighbor set of each vertex.

**Theorem (space tradeoffs).** For a graph with $n$ vertices and $m$ edges:

$$\text{space}(A) = \Theta(n^2), \quad \text{space}(B) = \Theta(nm), \quad \text{space}(\text{edge list}) = \Theta(m), \quad \text{space}(\text{adj. list}) = \Theta(n+m).$$

*Proof.* Immediate from the dimensions of each structure: $A$ has $n^2$ entries regardless of sparsity; $B$ has $nm$ entries; the edge list stores each edge once as an $O(1)$-size tuple; the adjacency list stores $n$ head pointers plus one list-node per edge endpoint (two per undirected edge), giving $\Theta(n+m)$. $\blacksquare$

This yields the classical **sparse/dense crossover**: when $m = o(n^2/\log n)$ (informally, $m \ll n^2$), adjacency-list or edge-list representations dominate; when $m = \Theta(n^2)$, the matrix's $O(1)$ random-access edge query ($A_{ij}$ lookup) outweighs its quadratic storage. Query-complexity tradeoffs follow directly: adjacency-matrix edge test is $O(1)$ but neighbor enumeration is $O(n)$; adjacency-list neighbor enumeration is $O(\deg(v))$ but edge test is $O(\deg(v))$ (or $O(\log \deg(v))$ if sorted/hashed).

**Literature context.** These tradeoffs are foundational and appear in every algorithms text (Cormen et al., *CLRS*, ch. 22), but the *choice* of representation remains an active systems question at scale: compressed sparse row (CSR) formats, used throughout graph-processing frameworks (GraphBLAS, Pregel-style systems), trade update flexibility for cache-efficient traversal; succinct/compressed graph representations (Boldi–Vigna's WebGraph framework) exploit locality and similarity in web-scale graphs to approach the information-theoretic lower bound of $\log_2 \binom{n^2}{m}$ bits. The incidence matrix, less emphasized algorithmically, is central to algebraic graph theory: $B B^T$ relates to the graph Laplacian $L = D - A$ for undirected graphs, linking representation choice directly to spectral graph theory. An open question of ongoing interest: for dynamic graphs (frequent edge insertion/deletion under streaming constraints), what representation achieves optimal amortized update and query cost simultaneously — this remains representation-design research, not settled practice.

**Suggested investigation.** Implement all four representations for a family of random graphs $G(n,p)$ (Erdős–Rényi) across a sweep of $p$, and empirically measure (a) memory footprint, (b) wall-clock time for BFS/DFS traversal, (c) wall-clock time for random edge queries. Fit the empirical crossover point in $p$ against the theoretical $\Theta(n^2)$ vs. $\Theta(n+m)$ prediction.

**Report-writing note.** The write-up should state the asymptotic space/time bounds precisely (with proof), present the empirical crossover plot alongside the predicted threshold, and discuss any discrepancy (e.g., cache effects, pointer overhead) between asymptotic and measured performance.

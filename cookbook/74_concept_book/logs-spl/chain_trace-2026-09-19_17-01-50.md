## Gradient Descent

Gradient descent is a first-order iterative optimization algorithm used to find the local minimum of a differentiable objective or loss function, $J(\mathbf{w})$. Given that many complex models are optimized by minimizing an error function, gradient descent provides a systematic method for adjusting the model's parameters $\mathbf{w}$ toward this minimum. The fundamental mathematical principle is that the gradient $\nabla J(\mathbf{w})$ at any point $(\mathbf{w})$ points in the direction of the *steepest ascent* of the function $J$. Therefore, to minimize $J$, we must move iteratively in the exact opposite direction: the negative gradient $(-\nabla J(\mathbf{w}))$.

The core iterative update rule is defined as:
$$ \mathbf{w}_{k+1} = \mathbf{w}_k - \eta \nabla J(\mathbf{w}_k) $$
where $\mathbf{w}_k$ represents the parameters at iteration $k$, and $\eta$ (the learning rate, $\eta > 0$) is a crucial scalar that determines the size of the step taken in the negative gradient direction. Choosing an appropriate value for $\eta$ is vital; if $\eta$ is too large, the algorithm may overshoot the minimum and fail to converge; if $\eta$ is too small, convergence will be impractically slow.

## Softmax

The softmax function is a crucial mathematical tool used extensively in machine learning, particularly for classification tasks. It takes an arbitrary vector of real numbers—often called "logits" or raw scores ($\mathbf{z}$)—and transforms it into a probability distribution $\mathbf{p}$. By definition, the resulting vector $\mathbf{p}$ must have elements that are all non-negative and whose sum equals one, satisfying the axioms of a discrete probability mass function. Given an input vector $\mathbf{z} = (z_1, z_2, \dots, z_K)$ containing $K$ raw scores, the softmax probability for the $i$-th element is defined as:

$$\text{softmax}(\mathbf{z})_i = p_i = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}$$

The mathematical rigor of this function lies in its structure. The exponentiation ($e^{z_i}$) ensures that all resulting scores are positive, and the division by the sum of exponents ($\Omega = \sum_{j=1}^{K} e^{z_j}$) normalizes the vector such that $\sum_{i=1}^{K} p_i = 1$. Intriguingly, softmax is also a monotonically increasing function: higher input scores lead to proportionally higher output probabilities, but the differences between those scores are amplified relative to their magnitude.

Consider an example where we have three mutually exclusive classes (A, B, C) and our model outputs logits $\mathbf{z} = [1.0, 2.0, 3.0]$. We calculate the softmax for each class:
$$p_A = \frac{e^{1.0}}{e^{1.0} + e^{2.0} + e^{3.0}}$$
$$p_B = \frac{e^{2.0}}{e^{1.0} + e^{2.0} + e^{3.0}}$$
$$p_C = \frac{e^{3.0}}{e^{1.0} + e^{2.0} + e^{3.0}}$$

Calculating the exponentials yields $e^1 \approx 2.718$, $e^2 \approx 7.389$, and $e^3 \approx 20.086$. The sum of exponents is $\Omega \approx 30.193$. The resulting probabilities are $p_A \approx 0.09$, $p_B \approx 0.25$, and $p_C \approx 0.76$, satisfying $0.09 + 0.25 + 0.76 = 1.1$ (due to rounding).

The key application of softmax is in training a model using cross-entropy loss, which inherently assumes the output distribution is governed by these probabilities. When solving a problem involving classification, if we are given raw scores $\mathbf{z}$ and need to find the probability distribution $\mathbf{p}$, the required step is simply applying the formal definition: calculate $e^{z_i}$ for all elements and then normalize the resulting vector by dividing each element by the sum of all exponentiated values.

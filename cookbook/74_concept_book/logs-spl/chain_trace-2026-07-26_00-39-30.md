### derivative (0.0s)

## Derivative

**Definition.** Let $f : (a, b) \to \mathbb{R}$ be a real-valued function and let $x_0 \in (a, b)$. The *derivative* of $f$ at $x_0$ is defined as the limit

$$f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h},$$

provided this limit exists and is finite. When the limit exists, $f$ is said to be *differentiable* at $x_0$. The quantity $\frac{f(x_0+h)-f(x_0)}{h}$ is the *difference quotient*, representing the slope of the secant line through $(x_0, f(x_0))$ and $(x_0+h, f(x_0+h))$; the derivative is the slope of the tangent line obtained as $h \to 0$.

**Worked Example.** Compute $f'(x)$ for $f(x) = x^3$.

Applying the definition directly:

$$f'(x) = \lim_{h \to 0} \frac{(x+h)^3 - x^3}{h}.$$

Expanding $(x+h)^3 = x^3 + 3x^2 h + 3xh^2 + h^3$ gives

$$\frac{(x^3 + 3x^2 h + 3xh^2 + h^3) - x^3}{h} = 3x^2 + 3xh + h^2.$$

Taking $h \to 0$ yields $f'(x) = 3x^2$, confirming the power rule $\frac{d}{dx} x^n = nx^{n-1}$ for $n = 3$.

**Key Theorem (Differentiability Implies Continuity).** If $f$ is differentiable at $x_0$, then $f$ is continuous at $x_0$.

*Proof sketch.* Write $f(x_0 + h) - f(x_0) = \frac{f(x_0+h)-f(x_0)}{h} \cdot h$. As $h \to 0$, the first factor converges to $f'(x_0)$ and the second factor converges to $0$, so $\lim_{h \to 0}[f(x_0+h) - f(x_0)] = f'(x_0) \cdot 0 = 0$, establishing continuity. The converse fails: $f(x) = |x|$ is continuous but not differentiable at $x = 0$. $\square$

**Lab Cell.**

```python
from sympy import symbols, diff, limit, Function, simplify

x, h = symbols('x h')
f = x**3

# Derivative via limit definition
dq = (f.subs(x, x + h) - f) / h
deriv_limit = limit(dq, h, 0)
print("Limit definition:", deriv_limit)   # 3*x**2

# Derivative via diff
deriv_diff = diff(f, x)
print("diff():", deriv_diff)              # 3*x**2

assert simplify(deriv_limit - deriv_diff) == 0
```

Both methods confirm $\frac{d}{dx} x^3 = 3x^2$, and `simplify` verifies that the two expressions are identical.

### antiderivative (13.8s)

## Antiderivative

**Definition.** Let $f$ be a function defined on an interval $I \subseteq \mathbb{R}$. A function $F : I \to \mathbb{R}$ is called an *antiderivative* of $f$ on $I$ if $F$ is differentiable on $I$ and

$$F'(x) = f(x) \quad \text{for all } x \in I.$$

Because the derivative of any constant is zero, antiderivatives are never unique: if $F$ is one antiderivative of $f$, then $F(x) + C$ for any constant $C \in \mathbb{R}$ is also an antiderivative. The family $\{F(x) + C \mid C \in \mathbb{R}\}$ is called the *general antiderivative* (or *indefinite integral*) of $f$, written

$$\int f(x)\, dx = F(x) + C.$$

**Worked Example.** Find all antiderivatives of $f(x) = 3x^2$.

We seek $F$ such that $F'(x) = 3x^2$. Applying the reverse power rule — increasing the exponent by one and dividing by the new exponent — gives $F(x) = x^3$. Verification: $(x^3)' = 3x^2$. The general antiderivative is therefore

$$\int 3x^2\, dx = x^3 + C.$$

To fix $C$, an initial condition is required. If, for instance, $F(1) = 5$, then $1 + C = 5$, so $C = 4$ and the unique solution is $F(x) = x^3 + 4$.

**Theorem (Uniqueness up to a constant).** *If $F$ and $G$ are both antiderivatives of $f$ on an interval $I$, then $F(x) - G(x) = C$ for some constant $C$.*

*Proof sketch.* Let $H = F - G$. Then $H'(x) = F'(x) - G'(x) = f(x) - f(x) = 0$ for all $x \in I$. By the Mean Value Theorem, a function with zero derivative on an interval must be constant. Hence $H(x) = C$. $\square$

This theorem is fundamental: it guarantees that once one antiderivative is found, the complete solution set is fully characterised.

**Lab Cell (SymPy).**

```python
from sympy import symbols, integrate, diff, simplify

x = symbols('x')
f = 3*x**2
F = integrate(f, x)          # indefinite integral
print("Antiderivative:", F)  # x**3
print("Verify:", simplify(diff(F, x) - f))  # 0
```

Running this cell prints `x**3` and `0`, confirming that differentiation recovers the original function.

### indefinite_integral (13.8s)

## Indefinite Integral

**Definition.** Let $f$ be a function defined on an interval $I \subseteq \mathbb{R}$. A function $F$ is called an *antiderivative* of $f$ on $I$ if $F'(x) = f(x)$ for all $x \in I$. The *indefinite integral* of $f$ is the family of all antiderivatives of $f$, written

$$\int f(x)\, dx = F(x) + C,$$

where $C \in \mathbb{R}$ is an arbitrary constant of integration. The symbol $\int$ is the integral sign, $f(x)$ is the *integrand*, and $dx$ indicates the variable of integration.

The constant $C$ is not cosmetic: if $F$ is one antiderivative of $f$, then every function of the form $F(x) + C$ is also an antiderivative, and these are the *only* antiderivatives. This follows immediately from the fact that a function with zero derivative everywhere on an interval must be constant.

**Worked example.** Find $\displaystyle\int 3x^2\, dx$.

We seek $F$ such that $F'(x) = 3x^2$. Applying the power rule in reverse,

$$F(x) = \frac{3x^3}{3} = x^3.$$

Verification: $\dfrac{d}{dx}(x^3) = 3x^2$ ✓. Hence

$$\int 3x^2\, dx = x^3 + C.$$

**Key theorem (Linearity of the indefinite integral).** Let $f$ and $g$ be functions with antiderivatives on $I$, and let $\alpha, \beta \in \mathbb{R}$. Then

$$\int \bigl(\alpha f(x) + \beta g(x)\bigr)\, dx = \alpha \int f(x)\, dx + \beta \int g(x)\, dx.$$

*Proof sketch.* Let $F' = f$ and $G' = g$. By the linearity of differentiation,

$$\frac{d}{dx}\bigl(\alpha F(x) + \beta G(x)\bigr) = \alpha F'(x) + \beta G'(x) = \alpha f(x) + \beta g(x). \qed$$

This theorem reduces integration of polynomial and trigonometric combinations to a term-by-term computation.

**Lab cell (SymPy).**

```python
from sympy import symbols, integrate, cos, exp

x = symbols('x')

# Basic power and trig examples
print(integrate(3*x**2, x))          # x**3
print(integrate(cos(x), x))          # sin(x)
print(integrate(exp(x) + 4*x, x))    # exp(x) + 2*x**2

# SymPy omits C; the constant is implicit
```

Running this cell confirms that SymPy's `integrate` returns one antiderivative; the full indefinite integral always carries the implicit $+\, C$.

## Initial Value Problem

**Definition.** An *initial value problem* (IVP) consists of an ordinary differential equation (ODE) together with a prescribed value of the unknown function at a specified point. Formally, given a function $f : \mathbb{R} \times \mathbb{R} \to \mathbb{R}$, an IVP of first order takes the form

$$\frac{dy}{dx} = f(x, y), \qquad y(x_0) = y_0,$$

where $x_0$ is the *initial point* and $y_0 \in \mathbb{R}$ is the *initial condition*. Higher-order IVPs specify the value of $y$ and its successive derivatives at $x_0$. The initial condition selects a unique solution curve from the family of all solutions to the ODE, anchoring it to a single point in the $(x, y)$-plane.

**Worked Example.** Consider the IVP

$$\frac{dy}{dx} = 2x, \qquad y(1) = 3.$$

Integrating both sides with respect to $x$ yields the general solution $y = x^2 + C$ for an arbitrary constant $C \in \mathbb{R}$. Applying the initial condition, $3 = (1)^2 + C$, gives $C = 2$. The unique solution satisfying the IVP is therefore

$$y(x) = x^2 + 2.$$

Every other member of the family $y = x^2 + C$ passes through a different point at $x = 1$; the initial condition isolates exactly one.

**Key Theorem (Picard–Lindelöf).** Let $f$ be continuous on an open rectangle $R$ containing $(x_0, y_0)$, and suppose $f$ satisfies a *Lipschitz condition* in $y$ on $R$: there exists $L > 0$ such that

$$|f(x, y_1) - f(x, y_2)| \leq L\,|y_1 - y_2|$$

for all $(x, y_1), (x, y_2) \in R$. Then there exists an interval $I$ containing $x_0$ on which the IVP has a *unique* solution. The Lipschitz condition is satisfied, for instance, whenever $\partial f / \partial y$ exists and is bounded on $R$.

**Lab Cell (SymPy).**

```python
import sympy as sp

x = sp.Symbol('x')
y = sp.Function('y')

ode = sp.Eq(y(x).diff(x), 2*x)
solution = sp.dsolve(ode, y(x), ics={y(1): 3})
print(solution)          # y(x) = x**2 + 2
sp.plot(solution.rhs, (x, -3, 3), title="IVP solution: y = x² + 2")
```

Running this cell confirms the analytic result and plots the unique parabola threading through $(1, 3)$.

## Matrix Multiplication

Matrix multiplication is a fundamental arithmetic operation that combines two matrices, $A$ and $B$, to produce a third matrix, $C$. If $A$ has dimensions $m \times n$ (meaning $m$ rows and $n$ columns) and $B$ has dimensions $p \times q$, the product $C = A B$ is only defined if the number of columns in $A$ equals the number of rows in $B$; that is, we must have $n=p$. The resulting matrix $C$ will then have dimensions $m \times q$.

The core operation involves calculating the dot product. Each element $c_{ij}$ in the resulting matrix $C$ is the dot product of the $i$-th row of $A$ and the $j$-th column of $B$. Mathematically, this is expressed as:
$$ c_{ij} = \sum_{k=1}^{n} a_{ik} b_{kj} $$

Consider matrices $A$, $B$, and their product $C$:
If $A = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}$ and $B = \begin{pmatrix} 5 & 6 \\ 7 & 8 \end{pmatrix}$, both are $2 \times 2$. The resulting matrix $C$ will also be $2 \times 2$.

To find the element $c_{11}$ (row 1 of $A$, column 1 of $B$), we compute:
$$ c_{11} = (1)(5) + (2)(7) = 5 + 14 = 19 $$

Similarly, for $c_{12}$:
$$ c_{12} = (1)(6) + (2)(8) = 6 + 16 = 22 $$
This process is repeated for all four elements, yielding:
$$ C = A B = \begin{pmatrix} 19 & 22 \\ 43 & 50 \end{pmatrix} $$

The critical application of matrix multiplication lies in its role as a representation of linear transformations. If $A$ is an $m \times n$ transformation matrix, multiplying $A$ by an $n$-dimensional vector $\mathbf{x}$ (which can be viewed as an $n \times 1$ matrix) transforms $\mathbf{x}$ into a new $m$-dimensional vector $\mathbf{y}$. This structure is essential in fields ranging from computer graphics to machine learning, where the transformation of data points through successive linear operations is modeled entirely by sequential matrix multiplications.

For instance, if you are applying a geometric rotation defined by an orthogonal matrix $R$ (e.g., rotating coordinates 90 degrees clockwise), and $\mathbf{v}$ is your vector, the new coordinates $\mathbf{v}'$ are calculated as $\mathbf{v}' = R \mathbf{v}$. The rigor of this operation ensures that the transformation preserves linear relationships in the coordinate space, making matrix multiplication the cornerstone of multivariable linear algebra.

## Softmax

The softmax function is a crucial mathematical tool used extensively in machine learning, particularly for classification tasks. It takes an arbitrary vector of real numbers—often called "logits" or raw scores ($\mathbf{z}$)—and transforms it into a probability distribution $\mathbf{p}$. By definition, the resulting vector $\mathbf{p}$ must have elements that are all non-negative and whose sum equals one, satisfying the axioms of a discrete probability mass function. Given an input vector $\mathbf{z} = (z_1, z_2, \dots, z_K)$ containing $K$ raw scores, the softmax probability for the $i$-th element is defined as:

$$\text{softmax}(\mathbf{z})_i = p_i = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}$$

The mathematical rigor of this function lies in its structure. The exponentiation ($e^{z_i}$) ensures that all resulting scores are positive, and the division by the sum of exponents ($\Omega = \sum_{j=1}^{K} e^{z_j}$) normalizes the vector such that $\sum_{i=1}^{K} p_i = 1$. Intriguingly, softmax is also a monotonically increasing function: higher input scores lead to proportionally higher output probabilities, but the differences between those scores are amplified relative to their magnitude.

Consider an example where we have three mutually exclusive classes (A, B, C) and our model outputs logits $\mathbf{z} = [1.0, 2.0, 3.0]$. We calculate the softmax for each class:
$$p_A = \frac{e^{1.0}}{e^{1.0} + e^{2.0} + e^{3.0}}$$
$$p_B = \frac{e^{2.0}}{e^{1.0} + e^{2.0} + e^{3.0}}$$
$$p_C = \frac{e^{3.0}}{e^{1.0} + e^{2.0} + e^{3.0}}$$

Calculating the exponentials yields $e^1 \approx 2.718$, $e^2 \approx 7.389$, and $e^3 \approx 20.086$. The sum of exponents is $\Omega \approx 30.193$. The resulting probabilities are $p_A \approx 0.09$, $p_B \approx 0.25$, and $p_C \approx 0.76$, satisfying $0.09 + 0.25 + 0.76 = 1.1$ (due to rounding).

The key application of softmax is in training a model using cross-entropy loss, which inherently assumes the output distribution is governed by these probabilities. When solving a problem involving classification, if we are given raw scores $\mathbf{z}$ and need to find the probability distribution $\mathbf{p}$, the required step is simply applying the formal definition: calculate $e^{z_i}$ for all elements and then normalize the resulting vector by dividing each element by the sum of all exponentiated values.

## Vector

A vector is an ordered list of $n$ real numbers, written as $\mathbf{v} = \langle v_1, v_2, \dots, v_n \rangle$. Mathematically, we consider vectors as elements of the $n$-dimensional Euclidean space, denoted $\mathbb{R}^n$. In computational linguistics and machine learning, a vector is used to translate abstract data—such as the meaning of a word (a token)—into a numerical format that algorithms can process. These representations are known as *embeddings*. Each dimension within the vector often corresponds to a specific feature or latent property of the data set (e.g., whether the word relates to nature, time, or action).

## Attention Score

The attention score quantifies the relevance or relationship between two tokens within a sequence. Mathematically, it is computed by comparing a token's Query vector ($Q$) against all other tokens' Key vectors ($K$). The resulting matrix of raw similarity scores indicates how much focus one token should pay to every other token in the context. This process utilizes the dot product, which intrinsically measures the angular closeness between two high-dimensional vectors. For an attention mechanism operating on a set of tokens $\{T_1, T_2, \dots, T_N\}$, the raw similarity score $e_{i j}$ between token $i$ and token $j$ is calculated as the dot product of their respective Query and Key vectors:

$$ e_{i j} = Q_i \cdot K_j $$

To stabilize gradients during training, this raw score must be scaled by $\frac{1}{\sqrt{d_k}}$, where $d_k$ is the dimension of the key vectors. Finally, the Softmax function normalizes these scores into a probability distribution, yielding the attention weight matrix $A$. The actual context vector for token $i$ is then found by taking the weighted sum of all Value vectors ($V$), using $A$ as the weights:

$$\text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

### point_estimate (0.0s)

## Point Estimate

**Definition.** Let $X_1, X_2, \ldots, X_n$ be a random sample drawn from a population with an unknown parameter $\theta$. A *point estimate* of $\theta$ is a single numerical value $\hat{\theta}$ computed from the sample data. Formally, $\hat{\theta} = g(X_1, \ldots, X_n)$ for some function $g$, called an *estimator*. The distinction matters: the estimator is a random variable (a rule), while the point estimate is the specific number produced once the data are observed.

Two fundamental criteria govern estimator quality. An estimator is *unbiased* if $\mathbb{E}[\hat{\theta}] = \theta$ for all admissible $\theta$, meaning it neither systematically overshoots nor undershoots the true value. Its *mean squared error* (MSE) decomposes as

$$\mathrm{MSE}(\hat{\theta}) = \mathrm{Var}(\hat{\theta}) + \bigl(\mathrm{Bias}(\hat{\theta})\bigr)^2,$$

revealing that low variance and low bias jointly determine accuracy.

**Worked example.** Suppose a quality engineer measures the lifetimes (in hours) of $n = 5$ light bulbs:

$$\{1020,\; 980,\; 1005,\; 1015,\; 990\}.$$

The unknown parameter is the population mean $\mu$. The sample mean

$$\hat{\mu} = \bar{X} = \frac{1020 + 980 + 1005 + 1015 + 990}{5} = \frac{5010}{5} = 1002 \text{ hours}$$

is a point estimate of $\mu$. Similarly, the sample variance $s^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2 = 262.5$ is a point estimate of the population variance $\sigma^2$.

**Theorem (Unbiasedness of $\bar{X}$).** If $X_1, \ldots, X_n$ are i.i.d. with mean $\mu$, then $\mathbb{E}[\bar{X}] = \mu$.

*Proof sketch.* By linearity of expectation, $\mathbb{E}[\bar{X}] = \frac{1}{n}\sum_{i=1}^n \mathbb{E}[X_i] = \frac{1}{n} \cdot n\mu = \mu$. $\square$

The divisor $n-1$ in $s^2$ (Bessel's correction) similarly ensures $\mathbb{E}[s^2] = \sigma^2$.

**Lab cell.**

```python
import sympy as sp

data = [1020, 980, 1005, 1015, 990]
n = len(data)
x_bar = sp.Rational(sum(data), n)
s_sq  = sum((sp.Rational(x) - x_bar)**2 for x in data) / (n - 1)
print(f"Point estimate of mu:    {x_bar}")
print(f"Point estimate of sigma^2: {s_sq}")
```

Running this cell confirms $\hat{\mu} = 1002$ and $\hat{\sigma}^2 = \tfrac{525}{2} = 262.5$, matching the hand calculation and illustrating how symbolic arithmetic avoids floating-point rounding errors in pedagogical settings.

### null_hypothesis (0.0s)

## Null Hypothesis

**Definition.** In statistical hypothesis testing, the *null hypothesis*, denoted $H_0$, is a precise, falsifiable statement about a population parameter that asserts no effect, no difference, or no relationship between variables. It serves as the default position that data must provide sufficient evidence to overturn. Formally, given a parameter $\theta$, the null hypothesis takes the form $H_0\colon \theta = \theta_0$ for some specified value $\theta_0$, while the *alternative hypothesis* $H_1$ specifies the region of departure (e.g., $H_1\colon \theta \neq \theta_0$, $\theta > \theta_0$, or $\theta < \theta_0$). The null hypothesis is never "accepted"; it is either *rejected* or *not rejected* based on evidence.

**Worked Example.** A pharmaceutical researcher claims a new analgesic reduces mean recovery time below the historical mean of $\mu_0 = 72$ hours. She records recovery times $x_1, \ldots, x_{n}$ for $n = 40$ patients and computes the sample mean $\bar{x} = 68.3$ hours with sample standard deviation $s = 11.2$ hours. The hypotheses are:

$$H_0\colon \mu = 72 \qquad \text{vs.} \qquad H_1\colon \mu < 72.$$

The test statistic under $H_0$ is the one-sample $t$-statistic:

$$t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}} = \frac{68.3 - 72}{11.2/\sqrt{40}} \approx -2.09.$$

With $n - 1 = 39$ degrees of freedom, the one-tailed $p$-value is $P(T_{39} \leq -2.09) \approx 0.022$. At significance level $\alpha = 0.05$, since $p < \alpha$, she rejects $H_0$.

**Key Theorem (Neyman–Pearson Lemma).** For testing a simple null $H_0\colon \theta = \theta_0$ against a simple alternative $H_1\colon \theta = \theta_1$, the most powerful test of size $\alpha$ rejects $H_0$ when the *likelihood ratio* exceeds a critical threshold:

$$\Lambda(x) = \frac{\mathcal{L}(\theta_1 \mid x)}{\mathcal{L}(\theta_0 \mid x)} > k_\alpha,$$

where $\mathcal{L}(\theta \mid x)$ denotes the likelihood of parameter $\theta$ given the observed data $x$. This lemma establishes that rejecting $H_0$ in favour of $H_1$ should be driven by how much more probable the data are under $H_1$ than under $H_0$.

**Lab Cell.**
```python
from scipy import stats
import numpy as np

rng = np.random.default_rng(42)
sample = rng.normal(loc=68.3, scale=11.2, size=40)

t_stat, p_value = stats.ttest_1samp(sample, popmean=72, alternative='less')
print(f"t = {t_stat:.3f},  p = {p_value:.4f}")
# Reject H₀ if p < 0.05
```

### alternative_hypothesis (0.0s)

## Alternative Hypothesis

**Definition.** In classical hypothesis testing, a statistical test is built around two competing claims about a population parameter $\theta$. The *null hypothesis* $H_0$ asserts a specific or restricted value of $\theta$, typically representing the status quo or no effect. The *alternative hypothesis* $H_1$ (also written $H_a$) specifies the set of parameter values that would be supported if $H_0$ is rejected. Formally, if $\Theta$ is the full parameter space, then $H_0: \theta \in \Theta_0$ and $H_1: \theta \in \Theta_1$, where $\Theta_0 \cap \Theta_1 = \emptyset$ and $\Theta_0 \cup \Theta_1 = \Theta$. The alternative hypothesis is *simple* when $\Theta_1$ contains exactly one value and *composite* when it contains more than one.

The directionality of $H_1$ determines the structure of the rejection region. A *two-sided* alternative $H_1: \theta \neq \theta_0$ places critical mass in both tails of the sampling distribution. A *one-sided* alternative—either $H_1: \theta > \theta_0$ or $H_1: \theta < \theta_0$—concentrates the rejection region in a single tail, yielding greater power against departures in that specific direction.

**Worked Example.** A pharmaceutical company claims its new analgesic reduces mean recovery time to $\mu_0 = 5$ days. A clinical investigator suspects the true mean is *longer* and records recovery times $x_1, \dots, x_{25}$ from a random sample. The competing hypotheses are:

$$H_0: \mu = 5 \quad \text{vs.} \quad H_1: \mu > 5.$$

The one-sided alternative reflects the investigator's prior belief and directs the test statistic $T = \dfrac{\bar{X} - 5}{S/\sqrt{25}}$ toward the upper tail of the $t_{24}$ distribution.

**Key Theorem (Neyman–Pearson Lemma).** For a simple null $H_0: \theta = \theta_0$ against a simple alternative $H_1: \theta = \theta_1$, the most powerful test of size $\alpha$ rejects $H_0$ whenever the likelihood ratio satisfies

$$\Lambda(x) = \frac{L(\theta_1 \mid x)}{L(\theta_0 \mid x)} > k_\alpha,$$

where $k_\alpha$ is chosen so that $P(\Lambda(X) > k_\alpha \mid H_0) = \alpha$. This lemma guarantees no other size-$\alpha$ test achieves higher power $1 - \beta = P(\text{reject } H_0 \mid H_1)$, making the alternative hypothesis not merely a logical complement but an active driver of optimal test design.

```python
from sympy.stats import Normal, P
from sympy import symbols, sqrt

mu, sigma, n = 5.5, 2, 25          # assumed true mean under H1
mu0 = 5
Z = Normal('Z', 0, 1)
se = sigma / sqrt(n)
z_obs = (mu - mu0) / se            # non-centrality for illustration
power = P(Z > 1.645 - z_obs)       # one-sided alpha = 0.05
print(f"Approximate power: {float(power):.4f}")
```

### critical_value (0.0s)

## Critical Value

**Definition.** Let $f : I \to \mathbb{R}$ be a differentiable function on an open interval $I$. A point $c \in I$ is called a *critical point* of $f$ if

$$f'(c) = 0 \quad \text{or} \quad f'(c) \text{ does not exist.}$$

The corresponding output $f(c)$ is called a *critical value* of $f$. Critical values are candidates for local extrema — the highest or lowest outputs in some neighborhood of $c$ — though not every critical value need be an extremum.

**Worked Example.** Consider $f(x) = x^3 - 3x + 1$ on $\mathbb{R}$.

Computing the derivative:
$$f'(x) = 3x^2 - 3 = 3(x-1)(x+1).$$

Setting $f'(x) = 0$ gives critical points $c = 1$ and $c = -1$. The corresponding critical values are:
$$f(1) = 1 - 3 + 1 = -1, \qquad f(-1) = -1 + 3 + 1 = 3.$$

To classify each, apply the **Second Derivative Test**: $f''(x) = 6x$, so $f''(1) = 6 > 0$ (local minimum, critical value $-1$) and $f''(-1) = -6 < 0$ (local maximum, critical value $3$). Neither is a global extremum since $f(x) \to \pm\infty$ as $x \to \pm\infty$.

**Key Theorem (Fermat's Theorem).** *If $f$ has a local extremum at an interior point $c$ of its domain and $f'(c)$ exists, then $f'(c) = 0$.*

*Proof sketch.* Suppose $f$ has a local maximum at $c$. For small $h > 0$, the difference quotient satisfies $\frac{f(c+h)-f(c)}{h} \le 0$ and $\frac{f(c-h)-f(c)}{-h} \ge 0$. Taking $h \to 0^+$ in both inequalities forces $f'(c) \le 0$ and $f'(c) \ge 0$, hence $f'(c) = 0$. The minimum case is symmetric. $\blacksquare$

Fermat's Theorem provides a necessary, not sufficient, condition: $f'(c) = 0$ guarantees only that $c$ is a *candidate*, as the example $f(x) = x^3$ at $c = 0$ illustrates (a critical point that is neither maximum nor minimum).

**Lab Cell (SymPy).**

```python
fp = diff(f, x)
critical_pts = solve(fp, x)
critical_vals = {c: f.subs(x, c) for c in critical_pts}
print(critical_vals)   # {-1: 3, 1: -1}
```

### level_of_significance (0.0s)

## Level Of Significance

**Definition.** The *level of significance*, denoted $\alpha$, is the maximum probability of committing a Type I error that an investigator is willing to tolerate before observing any data. Formally, if $H_0$ denotes the null hypothesis and $R$ denotes the rejection region of a test statistic $T$, then

$$\alpha = P(T \in R \mid H_0 \text{ is true}).$$

The value $\alpha$ is chosen a priori—typically $0.05$, $0.01$, or $0.10$ depending on the field—and it fixes the boundary of the rejection region entirely. A smaller $\alpha$ demands stronger evidence before rejecting $H_0$, but simultaneously raises the chance of failing to reject a false $H_0$.

---

**Worked Example.** A pharmaceutical company claims a drug reduces systolic blood pressure by a mean of $\mu_0 = 10$ mmHg. A clinical trial measures $n = 25$ patients, yielding $\bar{x} = 8.2$ mmHg and sample standard deviation $s = 4.5$ mmHg. We test $H_0: \mu = 10$ against $H_1: \mu \neq 10$ at $\alpha = 0.05$.

The test statistic is

$$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}} = \frac{8.2 - 10}{4.5 / 5} = \frac{-1.8}{0.9} = -2.00.$$

With $\nu = 24$ degrees of freedom, the two-tailed critical value is $t_{0.025,\,24} \approx 2.064$. Since $|{-2.00}| = 2.00 < 2.064$, we fail to reject $H_0$ at the 5 % level. Had we chosen $\alpha = 0.10$, the critical value would be $t_{0.05,\,24} \approx 1.711$, and the conclusion would reverse. This illustrates why $\alpha$ must be declared before data collection.

---

**Key Theorem (Neyman–Pearson).** For a simple null $H_0: \theta = \theta_0$ versus a simple alternative $H_1: \theta = \theta_1$, the most powerful test at level $\alpha$ is obtained by rejecting $H_0$ when the ratio of likelihoods $L(\theta_1 \mid \mathbf{x}) / L(\theta_0 \mid \mathbf{x})$ exceeds a threshold determined by $\alpha$ alone. No other test of the same size achieves higher power.

---

**Lab Cell (SymPy).**

```python
from sympy.stats import StudentT, P
from sympy import N

t_stat = -2.00
nu = 24
T = StudentT('T', nu)

# Two-tailed p-value
p_value = float(N(2 * P(T < t_stat)))
print(f"p-value = {p_value:.4f}")          # → 0.0573
print("Reject H0 at α=0.05?", p_value < 0.05)  # → False
print("Reject H0 at α=0.10?", p_value < 0.10)  # → True
```

The output confirms the dual conclusion above, making the dependence of the decision on the pre-specified $\alpha$ concrete and reproducible.

### scatterplot (0.0s)

## Scatterplot

**Definition.** A *scatterplot* is a two-dimensional graphical display in which each observation in a dataset is represented by a single point. Given $n$ paired measurements $\{(x_i, y_i)\}_{i=1}^{n}$, the scatterplot maps each pair to Cartesian coordinates, placing $x_i$ on the horizontal axis and $y_i$ on the vertical axis. The resulting cloud of points allows the analyst to visualise the *joint distribution* of two quantitative variables and to detect patterns such as linear or nonlinear association, clustering, and the presence of outliers.

Formally, let $X$ and $Y$ be two random variables with joint density $f_{X,Y}$. A scatterplot of a sample $\{(x_i, y_i)\}_{i=1}^n$ drawn from $f_{X,Y}$ provides a nonparametric visual estimate of the support and shape of that joint distribution.

---

**Worked example.** Suppose a student records the number of hours studied, $x_i$, and the exam score, $y_i$, for $n = 5$ classmates:

| $i$ | $x_i$ (hours) | $y_i$ (score) |
|-----|--------------|--------------|
| 1   | 2            | 55           |
| 2   | 4            | 68           |
| 3   | 6            | 74           |
| 4   | 8            | 83           |
| 5   | 10           | 91           |

Plotting the five points reveals an upward trend: as $x$ increases, $y$ tends to increase. The sample Pearson correlation coefficient,

$$r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i-\bar{x})^2}\,\sqrt{\sum_{i=1}^{n}(y_i-\bar{y})^2}},$$

quantifies this visual impression; here $r \approx 0.997$, confirming a near-perfect positive linear relationship.

---

**Key theorem (Anscombe, 1973).** Four datasets can share identical values of $\bar{x}$, $\bar{y}$, $r$, and the least-squares regression line yet exhibit radically different scatterplot shapes — linear, curved, with a single influential outlier, or nearly constant. This result, known as *Anscombe's Quartet*, establishes that summary statistics alone are insufficient; graphical inspection via the scatterplot is an indispensable step in exploratory data analysis.

---

**Lab cell.**

```python

import matplotlib.pyplot as plt

ys = [55, 68, 74, 83, 91]

plt.xlabel("Hours studied ($x$)")
plt.ylabel("Exam score ($y$)")
plt.title("Scatterplot: study time vs. exam score")
plt.grid(True, linestyle="--", alpha=0.5)
plt.tight_layout()
plt.show()
```

Running this cell produces the scatterplot and visually confirms the positive linear trend quantified by $r \approx 0.997$.

### test_statistic (0.0s)

## Test Statistic

**Definition.** A *test statistic* is a real-valued function $T = T(X_1, X_2, \ldots, X_n)$ of the sample data whose sampling distribution under the null hypothesis $H_0$ is completely or approximately known. It compresses the evidence in the data into a single number that can be compared against a reference distribution to assess whether observed deviations from $H_0$ are attributable to chance.

Formally, given a null hypothesis $H_0 : \theta \in \Theta_0$ and a sample of $n$ independent observations from a population with parameter $\theta$, a test statistic satisfies two requirements: (i) it is a measurable function of the data alone—no unknown parameters may appear in its computed value—and (ii) its distribution under $H_0$ is tractable, enabling the computation of a $p$-value or a critical region.

**Worked Example.** Suppose $X_1, \ldots, X_n \overset{\text{iid}}{\sim} \mathcal{N}(\mu, \sigma^2)$ with $\sigma^2$ unknown, and we test $H_0 : \mu = \mu_0$ against $H_1 : \mu \neq \mu_0$. Define the one-sample $t$-statistic:

$$T = \frac{\bar{X} - \mu_0}{S / \sqrt{n}},$$

where $\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$ is the sample mean and $S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$ is the sample variance. For $n = 16$, $\bar{x} = 52.4$, $s = 4.8$, and $\mu_0 = 50$:

$$t_{\text{obs}} = \frac{52.4 - 50}{4.8 / \sqrt{16}} = \frac{2.4}{1.2} = 2.0.$$

Under $H_0$, $T \sim t_{15}$. The two-tailed $p$-value is $P(|t_{15}| \geq 2.0) \approx 0.064$.

**Key Theorem (Pivotal Distribution).** If $X_i \overset{\text{iid}}{\sim} \mathcal{N}(\mu, \sigma^2)$, then under $H_0 : \mu = \mu_0$ the statistic $T = (\bar{X} - \mu_0)/(S/\sqrt{n})$ follows a Student's $t$-distribution with $n - 1$ degrees of freedom, regardless of the true value of $\sigma^2$. This *pivotal* property—that the distribution of $T$ is free of nuisance parameters—is what makes $T$ a valid test statistic.

**Lab Cell.**

```python
from scipy import stats
import numpy as np

rng = np.random.default_rng(42)
data = rng.normal(loc=52.4, scale=4.8, size=16)

t_stat, p_value = stats.ttest_1samp(data, popmean=50)
print(f"t = {t_stat:.4f},  p = {p_value:.4f}")

# Visualise the t_{15} distribution and mark t_obs
import sympy as sp
x = sp.Symbol('x')
sp.plot(sp.stats.density(sp.stats.StudentT('T', 15))(x), (x, -4, 4))
```

### correlation_coefficient (0.0s)

## Correlation Coefficient

**Definition.** Given two random variables $X$ and $Y$ with finite variances, the *Pearson correlation coefficient* is defined as

$$\rho(X, Y) = \frac{\operatorname{Cov}(X, Y)}{\sigma_X \, \sigma_Y}$$

where $\operatorname{Cov}(X, Y) = \mathbb{E}[(X - \mu_X)(Y - \mu_Y)]$ is the covariance, and $\sigma_X, \sigma_Y > 0$ are the respective standard deviations. For a finite sample of $n$ paired observations $\{(x_i, y_i)\}_{i=1}^n$, the sample correlation coefficient is

$$r = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^n (x_i - \bar{x})^2}\,\sqrt{\sum_{i=1}^n (y_i - \bar{y})^2}}.$$

The coefficient $r$ is dimensionless and satisfies $-1 \le r \le 1$. A value of $r = 1$ indicates perfect positive linear association, $r = -1$ perfect negative linear association, and $r = 0$ the absence of linear association (though nonlinear dependence may still be present).

**Worked Example.** Consider the five data pairs $(1, 2),\,(2, 4),\,(3, 5),\,(4, 4),\,(5, 5)$. The sample means are $\bar{x} = 3$ and $\bar{y} = 4$. Computing termwise:

$$\sum (x_i - \bar{x})(y_i - \bar{y}) = (-2)(-2) + (-1)(0) + (0)(1) + (1)(0) + (2)(1) = 6.$$

$$\sum (x_i - \bar{x})^2 = 4+1+0+1+4 = 10, \qquad \sum (y_i - \bar{y})^2 = 4+0+1+0+1 = 6.$$

Therefore $r = 6 / \sqrt{10 \cdot 6} = 6/\sqrt{60} \approx 0.775$, indicating a moderately strong positive linear relationship.

**Theorem (Cauchy–Schwarz Bound).** For any sample, $|r| \le 1$, with equality if and only if the points are collinear. This follows directly from the Cauchy–Schwarz inequality applied to the vectors $\mathbf{u} = (x_i - \bar{x})$ and $\mathbf{v} = (y_i - \bar{y})$ in $\mathbb{R}^n$: $|\mathbf{u} \cdot \mathbf{v}| \le \|\mathbf{u}\|\,\|\mathbf{v}\|$.

**Lab Cell (SymPy).**

```python
from sympy.stats import correlation, Normal, E
import numpy as np

x = [1, 2, 3, 4, 5]
y = [2, 4, 5, 4, 5]

x_bar, y_bar = np.mean(x), np.mean(y)
num   = sum((xi - x_bar)*(yi - y_bar) for xi, yi in zip(x, y))
denom = (sum((xi - x_bar)**2 for xi in x) *
         sum((yi - y_bar)**2 for yi in y))**0.5
r = num / denom
print(f"r = {r:.4f}")   # Expected: 0.7746
```

### f_distribution (0.0s)

## F Distribution

**Definition.** Let $U \sim \chi^2(d_1)$ and $V \sim \chi^2(d_2)$ be independent chi-squared random variables with $d_1$ and $d_2$ degrees of freedom, respectively. The *F distribution* with parameters $d_1$ and $d_2$, written $F \sim F(d_1, d_2)$, is defined by the ratio

$$F = \frac{U/d_1}{V/d_2}.$$

Its probability density function for $x > 0$ is

$$f(x;\,d_1,d_2) = \frac{1}{B\!\left(\tfrac{d_1}{2},\tfrac{d_2}{2}\right)} \left(\frac{d_1}{d_2}\right)^{d_1/2} \frac{x^{d_1/2 - 1}}{\left(1 + \tfrac{d_1}{d_2}x\right)^{(d_1+d_2)/2}},$$

where $B(\cdot,\cdot)$ denotes the beta function. The mean exists when $d_2 > 2$ and equals $\mu = d_2/(d_2-2)$; the variance exists when $d_2 > 4$.

**Worked Example.** Suppose two independent samples are drawn from normal populations: sample A has $n_1 = 6$ observations with sample variance $s_1^2 = 8$, and sample B has $n_2 = 11$ observations with $s_2^2 = 4$. Under the null hypothesis $H_0\colon \sigma_1^2 = \sigma_2^2$, the test statistic

$$F = \frac{s_1^2}{s_2^2} = \frac{8}{4} = 2.0$$

follows an $F(5, 10)$ distribution (degrees of freedom $d_i = n_i - 1$). Consulting an $F$-table or software, the upper 5% critical value $F_{0.05}(5,10) \approx 3.33$. Since $2.0 < 3.33$, we fail to reject $H_0$ at the 5% significance level, concluding no significant evidence that the population variances differ.

**Key Theorem (Variance-Ratio Theorem).** Let $S_1^2$ and $S_2^2$ be the sample variances from independent normal populations with true variances $\sigma_1^2$ and $\sigma_2^2$. Then

$$\frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} \sim F(n_1-1,\, n_2-1).$$

This result underpins the $F$-test in one-way ANOVA, where the ratio of between-group to within-group mean squares follows an $F$ distribution under $H_0$.

**Lab Cell.**

```python
from sympy import symbols, beta, Rational, simplify, stats
from sympy.stats import F, density, cdf, E

d1, d2, x = symbols('d1 d2 x', positive=True)

# Define F(5, 10) random variable
F_rv = F('F', 5, 10)

# Compute density at x = 2
f_pdf = density(F_rv)(x)
print("PDF at x=2:", simplify(f_pdf.subs(x, 2)))

# Compute P(F > 2) — upper-tail probability
upper_tail = 1 - cdf(F_rv)(2)
print("P(F > 2):", simplify(upper_tail))
```

### hypothesis_testing (0.0s)

## Hypothesis Testing

**Definition.** A *hypothesis test* is a formal decision procedure that uses sample data to evaluate a claim about a population parameter. The procedure is built from four components that together constitute a single new object: (1) a *null hypothesis* $H_0$, representing the default position; (2) an *alternative hypothesis* $H_1$, representing the claim we seek evidence for; (3) a *test statistic* $T = T(X_1, \ldots, X_n)$ computed from the sample; and (4) a *rejection region* $\mathcal{R}$ such that $H_0$ is rejected whenever $T \in \mathcal{R}$. The *significance level* $\alpha \in (0,1)$ calibrates the size of $\mathcal{R}$ by bounding the probability of incorrectly rejecting a true null hypothesis:

$$\alpha = P(T \in \mathcal{R} \mid H_0 \text{ true}).$$

**Worked Example.** A beverage manufacturer claims its cans contain $\mu_0 = 355\,\text{mL}$ on average. A quality inspector draws $n = 36$ cans and finds $\bar{x} = 352\,\text{mL}$ with known population standard deviation $\sigma = 9\,\text{mL}$. We test $H_0{:}\;\mu = 355$ against $H_1{:}\;\mu < 355$ at level $\alpha = 0.05$. Because $\sigma$ is known and $n$ is large, the test statistic

$$Z = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}} = \frac{352 - 355}{9/6} = -2.00$$

follows a standard normal distribution under $H_0$. The rejection region for a left-tailed test at $\alpha = 0.05$ is $\mathcal{R} = \{Z < -1.645\}$. Since $-2.00 < -1.645$, we reject $H_0$ and conclude there is significant evidence that the true mean fill is below $355\,\text{mL}$.

**Key Theorem (Neyman–Pearson Lemma).** Among all tests of $H_0{:}\;\theta = \theta_0$ versus $H_1{:}\;\theta = \theta_1$ at level $\alpha$, the *likelihood ratio test*, which rejects when

$$\Lambda = \frac{L(\theta_1 \mid \mathbf{x})}{L(\theta_0 \mid \mathbf{x})} > k_\alpha,$$

is the *most powerful* test; no other level-$\alpha$ test achieves higher power $1 - \beta = P(T \in \mathcal{R} \mid H_1)$ for the same sample size.

```python
from scipy import stats

x_bar, mu_0, sigma, n = 352, 355, 9, 36
z_stat = (x_bar - mu_0) / (sigma / n**0.5)
p_value = stats.norm.cdf(z_stat)          # left-tailed
print(f"z = {z_stat:.4f},  p = {p_value:.4f}")
# Reject H0 if p <= 0.05
print("Reject H0:", p_value <= 0.05)
```

### margin_of_error (0.0s)

## Margin Of Error

**Definition.** Let $\hat{p}$ be a sample proportion computed from a simple random sample of size $n$, and let $z_{\alpha/2}$ be the critical value corresponding to a confidence level of $(1-\alpha)\times 100\%$. The *margin of error* is the quantity

$$E = z_{\alpha/2}\sqrt{\frac{\hat{p}(1-\hat{p})}{n}},$$

so that the confidence interval for the true population proportion $p$ is $\hat{p} \pm E$. More generally, when estimating a population mean $\mu$ with known standard deviation $\sigma$, the margin of error takes the form

$$E = z_{\alpha/2}\frac{\sigma}{\sqrt{n}}.$$

The margin of error quantifies the maximum expected distance between the sample estimate and the true parameter value, at the stated confidence level.

---

**Worked Example.** A university surveys $n = 400$ students and finds that $\hat{p} = 0.62$ favour extending library hours. Construct a $95\%$ confidence interval for the true proportion $p$.

For $95\%$ confidence, $z_{0.025} = 1.96$. The margin of error is

$$E = 1.96\sqrt{\frac{0.62 \times 0.38}{400}} = 1.96\sqrt{\frac{0.2356}{400}} = 1.96 \times 0.02426 \approx 0.0475.$$

The confidence interval is therefore $0.62 \pm 0.0475$, or $(0.5725,\; 0.6675)$. We interpret this as: were the survey repeated many times under identical conditions, approximately $95\%$ of the resulting intervals would contain the true value of $p$.

---

**Key Theorem (Sample-Size Determination).** To achieve a margin of error no greater than $E_0$ at confidence level $(1-\alpha)$, the required sample size satisfies

$$n \geq \left(\frac{z_{\alpha/2}}{E_0}\right)^2 \hat{p}(1-\hat{p}).$$

When $\hat{p}$ is unknown in advance, the conservative bound $\hat{p}(1-\hat{p}) \leq \tfrac{1}{4}$ gives $n \geq \tfrac{z_{\alpha/2}^2}{4E_0^2}$, which guarantees the desired precision regardless of the true proportion.

---

**Lab Cell.**

```python
from sympy import sqrt, Rational, N

p_hat = Rational(62, 100)
n     = 400
z     = Rational(196, 100)          # z_{0.025} ≈ 1.96

E = z * sqrt(p_hat * (1 - p_hat) / n)
print("Margin of error:", N(E, 4))
print("CI lower:", N(p_hat - E, 4))
print("CI upper:", N(p_hat + E, 4))
```

Running this cell confirms $E \approx 0.0475$ and the interval $(0.5725, 0.6675)$, reproducing the hand calculation exactly.

### anova (0.0s)

## Anova

**Analysis of Variance (ANOVA)** is a statistical procedure for testing whether the means of two or more independent groups are equal by partitioning the total variability in a dataset into components attributable to different sources. Formally, given $k$ groups with sample sizes $n_1, n_2, \ldots, n_k$ and a grand total of $N = \sum_{i=1}^k n_i$ observations, the one-way ANOVA model assumes

$$y_{ij} = \mu + \alpha_i + \varepsilon_{ij}, \quad \varepsilon_{ij} \overset{\text{iid}}{\sim} \mathcal{N}(0, \sigma^2),$$

where $\mu$ is the grand mean, $\alpha_i$ is the effect of group $i$, and $\varepsilon_{ij}$ is random error. The null hypothesis is $H_0: \alpha_1 = \alpha_2 = \cdots = \alpha_k = 0$, meaning no group differs from the grand mean.

**Worked Example.** Suppose three fertiliser treatments are applied to crops, yielding the following weekly growth (cm): Group A: $\{4, 5, 6\}$, Group B: $\{7, 8, 9\}$, Group C: $\{5, 5, 5\}$. The grand mean is $\bar{y} = (15+24+15)/9 = 6$. The group means are $\bar{y}_1 = 5$, $\bar{y}_2 = 8$, $\bar{y}_3 = 5$. The **Sum of Squares Between** groups is $SS_B = \sum_{i=1}^k n_i(\bar{y}_i - \bar{y})^2 = 3(1+4+1) = 18$. The **Sum of Squares Within** groups is $SS_W = \sum_{i,j}(y_{ij}-\bar{y}_i)^2 = 2+2+0 = 4$. With $df_B = k-1 = 2$ and $df_W = N-k = 6$, the $F$-statistic is

$$F = \frac{SS_B / df_B}{SS_W / df_W} = \frac{18/2}{4/6} = \frac{9}{0.\overline{6}} = 13.5.$$

Comparing to $F_{2,6}$ at $\alpha = 0.05$ (critical value $\approx 5.14$), we reject $H_0$: the fertilisers differ significantly.

**Key Theorem (Fisher Decomposition).** The total sum of squares decomposes orthogonally as $SS_T = SS_B + SS_W$, where $SS_B/\sigma^2 \sim \chi^2_{k-1}$ and $SS_W/\sigma^2 \sim \chi^2_{N-k}$ are independent under $H_0$. Consequently, $F = (SS_B/df_B)/(SS_W/df_W) \sim F_{k-1,\, N-k}$, which is the reference distribution for the test.

**Lab Cell.**

```python
from scipy import stats
import sympy as sp

group_a = [4, 5, 6]
group_b = [7, 8, 9]
group_c = [5, 5, 5]

F_stat, p_value = stats.f_oneway(group_a, group_b, group_c)
print(f"F = {F_stat:.4f},  p = {p_value:.4f}")
# Verify SS decomposition symbolically
y = sp.symbols('y')
```

### confidence_interval (0.0s)

## Confidence Interval

**Definition.** Let $X_1, X_2, \ldots, X_n$ be independent and identically distributed random variables from a population with unknown parameter $\theta$. A **confidence interval** at confidence level $1 - \alpha$ is a pair of statistics $(L, U)$, both functions of the sample, such that

$$P(L \leq \theta \leq U) = 1 - \alpha.$$

The value $1 - \alpha$ is called the **coverage probability**. Common choices are $0.90$, $0.95$, and $0.99$. A critical point of interpretation: the interval $(L, U)$ is random — it varies from sample to sample — while $\theta$ is fixed. The correct reading is therefore "95% of all intervals constructed by this procedure will contain $\theta$," not "there is a 95% probability that $\theta$ lies in this particular interval."

**Worked Example.** A quality engineer measures the fill volume (mL) of $n = 36$ bottles and obtains a sample mean $\bar{x} = 500.4$ mL and sample standard deviation $s = 1.8$ mL. Construct a 95% confidence interval for the true mean fill $\mu$.

Because $n$ is large, the Central Limit Theorem justifies using the standard normal. The critical value is $z_{0.025} = 1.96$. The standard error is

$$\text{SE} = \frac{s}{\sqrt{n}} = \frac{1.8}{\sqrt{36}} = 0.30.$$

The 95% confidence interval is therefore

$$\bar{x} \pm z_{0.025} \cdot \text{SE} = 500.4 \pm 1.96 \times 0.30 = (499.81,\ 500.99) \text{ mL}.$$

**Key Theorem (Coverage of the Z-Interval).** If $X_1, \ldots, X_n \overset{\text{iid}}{\sim} \mathcal{N}(\mu, \sigma^2)$ with $\sigma^2$ known, the interval

$$\left(\bar{X} - z_{\alpha/2}\frac{\sigma}{\sqrt{n}},\; \bar{X} + z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right)$$

has exact coverage $1 - \alpha$. When $\sigma$ is unknown and replaced by the sample standard deviation $s$, the exact interval uses the $t_{n-1}$ distribution; the $z$-approximation remains valid for $n \geq 30$ by the Central Limit Theorem.

**Lab Cell.**

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(42)
sample = rng.normal(loc=500, scale=1.8, size=36)

mean = sample.mean()
se   = sample.std(ddof=1) / np.sqrt(len(sample))
ci   = stats.t.interval(0.95, df=len(sample)-1, loc=mean, scale=se)

print(f"Sample mean : {mean:.3f} mL")
print(f"95% CI      : ({ci[0]:.3f}, {ci[1]:.3f}) mL")
```

Running this cell prints a $t$-based interval that tightens as $n$ grows, illustrating how larger samples yield more precise estimates of $\mu$.

### linear_regression (0.0s)

## Linear Regression

**Definition.** Given a dataset of $n$ observations $\{(x_i, y_i)\}_{i=1}^n$ with $x_i \in \mathbb{R}^p$ and $y_i \in \mathbb{R}$, *linear regression* models the response as

$$y_i = \beta_0 + \beta_1 x_{i1} + \cdots + \beta_p x_{ip} + \varepsilon_i = \mathbf{x}_i^\top \boldsymbol{\beta} + \varepsilon_i,$$

where $\boldsymbol{\beta} \in \mathbb{R}^{p+1}$ is the vector of unknown coefficients (absorbing the intercept into $\mathbf{x}_i$ by prepending a 1), and $\varepsilon_i \stackrel{\text{iid}}{\sim} \mathcal{N}(0, \sigma^2)$ are independent error terms. In matrix form, with $\mathbf{y} \in \mathbb{R}^n$ and design matrix $X \in \mathbb{R}^{n \times (p+1)}$, the model becomes $\mathbf{y} = X\boldsymbol{\beta} + \boldsymbol{\varepsilon}$. The *ordinary least-squares* (OLS) estimator minimises the residual sum of squares:

$$\hat{\boldsymbol{\beta}} = \arg\min_{\boldsymbol{\beta}} \|{\mathbf{y} - X\boldsymbol{\beta}}\|^2.$$

**Worked Example.** Suppose $n = 3$ with observations $(1, 2)$, $(2, 4)$, $(3, 5)$. Form

$$X = \begin{pmatrix} 1 & 1 \\ 1 & 2 \\ 1 & 3 \end{pmatrix}, \quad \mathbf{y} = \begin{pmatrix} 2 \\ 4 \\ 5 \end{pmatrix}.$$

Then $X^\top X = \begin{pmatrix} 3 & 6 \\ 6 & 14 \end{pmatrix}$ and $X^\top \mathbf{y} = \begin{pmatrix} 11 \\ 25 \end{pmatrix}$. Solving $(X^\top X)\hat{\boldsymbol{\beta}} = X^\top \mathbf{y}$ gives $\hat{\beta}_0 = 2/3$ and $\hat{\beta}_1 = 3/2$, so the fitted line is $\hat{y} = \tfrac{2}{3} + \tfrac{3}{2}x$.

**Key Theorem (Normal Equations).** If $X$ has full column rank, the unique OLS solution satisfies the *normal equations*

$$X^\top X\,\hat{\boldsymbol{\beta}} = X^\top \mathbf{y} \implies \hat{\boldsymbol{\beta}} = (X^\top X)^{-1} X^\top \mathbf{y}.$$

*Proof sketch.* The squared loss $\mathcal{L}(\boldsymbol{\beta}) = \|\mathbf{y} - X\boldsymbol{\beta}\|^2$ is convex and differentiable. Setting $\nabla_{\boldsymbol{\beta}}\mathcal{L} = -2X^\top(\mathbf{y} - X\boldsymbol{\beta}) = \mathbf{0}$ yields the normal equations directly. Full-rank $X$ ensures $X^\top X$ is invertible, guaranteeing a unique minimiser. $\square$

### python_statistical_computing (0.0s)

## Python Statistical Computing

**Definition.** Statistical computing is the discipline of implementing probabilistic and inferential methods on finite, discrete data structures. In Python, this is primarily realized through the `scipy.stats` module and the `numpy` library, which together provide probability distributions, hypothesis tests, and descriptive statistics as first-class objects. A *probability distribution object* in `scipy.stats` encapsulates the probability density function (PDF), cumulative distribution function (CDF), and random variate generation under a unified interface.

For a continuous random variable $X$ with PDF $f_X(x)$, the CDF is defined as

$$F_X(t) = \int_{-\infty}^{t} f_X(x)\, dx,$$

and the expectation and variance are given by

$$\mathbb{E}[X] = \int_{-\infty}^{\infty} x\, f_X(x)\, dx, \qquad \mathrm{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2.$$

**Worked Example.** Suppose exam scores at a large university are modeled as $X \sim \mathcal{N}(\mu, \sigma^2)$ with $\mu = 72$ and $\sigma = 8$. We wish to determine the proportion of students scoring below 60. Using the CDF:

$$P(X < 60) = F_X(60) = \Phi\!\left(\frac{60 - 72}{8}\right) = \Phi(-1.5) \approx 0.0668,$$

where $\Phi$ denotes the standard normal CDF. Thus approximately 6.7% of students score below 60.

**Key Theorem (Central Limit Theorem).** Let $X_1, X_2, \ldots, X_n$ be independent and identically distributed random variables with mean $\mu$ and finite variance $\sigma^2$. Then, as $n \to \infty$,

$$\sqrt{n}\,\frac{\bar{X}_n - \mu}{\sigma} \xrightarrow{d} \mathcal{N}(0,1),$$

where $\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i$. This theorem underpins virtually every confidence interval and hypothesis test encountered in applied statistics, justifying normal approximations for large samples regardless of the population distribution.

**Lab Cell.**

```python
from scipy import stats
import numpy as np

dist = stats.norm(loc=72, scale=8)

# P(X < 60)
prob_below_60 = dist.cdf(60)
print(f"P(X < 60) = {prob_below_60:.4f}")

# Verify CLT empirically
rng = np.random.default_rng(42)
sample_means = [rng.normal(72, 8, 50).mean() for _ in range(5000)]
se = 8 / np.sqrt(50)
z_scores = (np.array(sample_means) - 72) / se
print(f"Empirical std of Z-scores: {z_scores.std():.4f}")  # ≈ 1.0
```

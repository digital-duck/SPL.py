### relation (0.2s)

## Relation

A **relation** from a set $A$ to a set $B$ is any subset $R \subseteq A \times B$, where $A \times B$ is the Cartesian product — the set of all ordered pairs $(a, b)$ with $a \in A$ and $b \in B$. Writing $a \mathrel{R} b$ means the pair $(a, b)$ belongs to $R$. When $A = B$, we call $R$ a **relation on** $A$.

This definition is more general than it first appears. "Is less than" on $\mathbb{Z}$ is a relation: $3 \mathrel{<} 7$ simply means $(3, 7) \in \{(a,b) \mid a < b\}$. "Is a sibling of" on a set of people is a relation. Even a function $f : A \to B$ is a special relation — specifically, one where every $a \in A$ appears in exactly one pair. Relations are the broader category; functions are the well-behaved special case.

**Worked example.** Let $A = \{1, 2, 3\}$ and define $R = \{(1,1),(2,2),(3,3),(1,2),(2,1)\}$. Is $(1,3) \in R$? No — check the list. Is $(2,1) \in R$? Yes. Notice that $R$ satisfies three useful properties: every element is related to itself (reflexive), whenever $a \mathrel{R} b$ then $b \mathrel{R} a$ (symmetric), and whenever $a \mathrel{R} b$ and $b \mathrel{R} c$ then $a \mathrel{R} c$ (transitive — you can verify this holds here). A relation with all three properties is called an **equivalence relation**, and it partitions $A$ into disjoint clusters called **equivalence classes**.

**Problem-solving application.** Suppose you must decide whether "has the same remainder when divided by 3" is an equivalence relation on $\mathbb{Z}$. Work through each property:

- *Reflexive*: $a - a = 0$, which is divisible by 3, so $a \mathrel{R} a$. ✓
- *Symmetric*: if $3 \mid (a - b)$, then $3 \mid (b - a)$. ✓
- *Transitive*: if $3 \mid (a - b)$ and $3 \mid (b - c)$, then $3 \mid (a - c)$ because $(a - c) = (a - b) + (b - c)$. ✓

All three hold, so $R$ is an equivalence relation, and it partitions $\mathbb{Z}$ into exactly three equivalence classes: $\{..., -3, 0, 3, 6, ...\}$, $\{..., -2, 1, 4, 7, ...\}$, and $\{..., -1, 2, 5, 8, ...\}$. This structure — modular arithmetic — is the foundation of cryptography, hash tables, and error-correcting codes.

### function (0.3s)

## Function

A **function** is a rule that assigns to each input exactly one output. More precisely, a function $f$ from a set $A$ to a set $B$, written $f: A \to B$, pairs every element $x \in A$ with a unique element $f(x) \in B$. The set $A$ is called the **domain**, $B$ is the **codomain**, and the collection of all actual outputs $\{f(x) : x \in A\}$ is the **range** (or image). The uniqueness requirement is the defining constraint: one input cannot produce two different outputs. The reverse is allowed — two inputs can share an output — but ambiguity in the forward direction is forbidden.

This is why $f(x) = x^2$ qualifies as a function ($x = -3$ and $x = 3$ both map to $9$, which is fine), while the relation $x = y^2$ does not define $y$ as a function of $x$ (the input $x = 9$ maps to both $y = 3$ and $y = -3$).

**Worked example.** A cell-phone plan charges a \$20 base fee plus \$0.05 per text message. Define the monthly cost as a function of messages sent:

$$C(n) = 20 + 0.05n, \quad n \in \{0, 1, 2, \ldots\}$$

Evaluate $C(200)$: $C(200) = 20 + 0.05(200) = 20 + 10 = \$30$. For each number of texts there is exactly one cost — the function condition holds.

**Problem-solving application.** Functions become powerful when you need to find inputs that produce a target output, or compare two functions to locate where they agree.

*Find the break-even point* between Plan A ($C_A(n) = 20 + 0.05n$) and Plan B ($C_B(n) = 35 + 0.02n$):

$$C_A(n) = C_B(n)$$
$$20 + 0.05n = 35 + 0.02n$$
$$0.03n = 15 \implies n = 500$$

Below 500 texts, Plan A is cheaper; above 500, Plan B wins. Setting two function expressions equal and solving for the input is one of the most recurring moves in applied mathematics — it appears in physics (when do two objects meet?), economics (break-even analysis), and computer science (when does one algorithm outperform another?). Recognizing that a quantity *is* a function of another variable is the first step toward asking and answering those questions precisely.

### one_to_one_function (17.2s)

## One To One Function

A function $f$ is **one-to-one** (also called *injective*) if every output value comes from exactly one input. Formally: $f$ is one-to-one if $f(a) = f(b)$ implies $a = b$ for all $a, b$ in the domain. Equivalently, distinct inputs always produce distinct outputs — no two x-values share the same y-value.

The geometric test for this is the **horizontal line test**: a function is one-to-one if and only if every horizontal line intersects its graph at most once. Compare $f(x) = x^3$ (passes — each output is hit exactly once) with $g(x) = x^2$ (fails — for example, $g(2) = g(-2) = 4$).

**Worked Example.** Determine whether $f(x) = 2x + 5$ is one-to-one.

Suppose $f(a) = f(b)$. Then:
$$2a + 5 = 2b + 5 \implies 2a = 2b \implies a = b$$

Since $f(a) = f(b)$ forces $a = b$, the function is one-to-one. Geometrically, it is a non-horizontal line, so every horizontal line crosses it exactly once.

Now try $h(x) = x^2 - 4$ on the domain $\mathbb{R}$. Take $a = 3$ and $b = -3$:
$$h(3) = 9 - 4 = 5, \qquad h(-3) = 9 - 4 = 5$$

Same output, different inputs — so $h$ is **not** one-to-one on $\mathbb{R}$. However, if we restrict the domain to $x \geq 0$, it becomes one-to-one. Domain restriction is a standard technique for recovering the one-to-one property.

**Why it matters: inverse functions.** A function has an inverse $f^{-1}$ if and only if it is one-to-one. The inverse "undoes" $f$: $f^{-1}(f(x)) = x$. For $f(x) = 2x + 5$, solve $y = 2x + 5$ for $x$ to get $f^{-1}(x) = \frac{x - 5}{2}$. This works precisely because each output traces back to a unique input.

When you encounter a function and need its inverse — for solving equations, decoding transformations, or building cryptographic schemes — always verify one-to-one first. If the function fails the horizontal line test, restrict its domain before proceeding.

### exponential_function (0.3s)

## Exponential Function

**Definition.** An exponential function has the form $f(x) = a \cdot b^x$, where $a$ is the initial value, $b > 0$ is the base, and $x$ is the exponent. The defining feature is that the *input is in the exponent* — which makes the function grow (or decay) by a constant *multiplicative factor* for every unit increase in $x$. When $b > 1$ the function grows; when $0 < b < 1$ it decays. The natural exponential $f(x) = e^x$, where $e \approx 2.71828$, appears throughout science because it is its own derivative — the rate of change equals the current value.

**Worked example.** A colony of bacteria doubles every 3 hours. You start with 500 cells. How many cells are there after 12 hours?

The doubling period is 3 hours, so after $t$ hours the number of doublings is $t/3$. The population model is:

$$P(t) = 500 \cdot 2^{t/3}$$

At $t = 12$:

$$P(12) = 500 \cdot 2^{12/3} = 500 \cdot 2^4 = 500 \cdot 16 = 8{,}000$$

Notice the mechanics: each 3-hour interval multiplies the population by 2, regardless of how large it already is. That multiplicative consistency is what makes the function exponential.

**Problem-solving application.** Exponential functions appear whenever a quantity changes proportionally to its current size — compound interest, radioactive decay, viral spread, drug clearance. The key problem-solving move is identifying the *base* and the *period*.

For compound interest, $A = P\left(1 + \frac{r}{n}\right)^{nt}$, the base is $(1 + r/n)$ and each compounding period multiplies the balance by that factor. For radioactive decay with half-life $h$, the base is $1/2$ and the period is $h$:

$$N(t) = N_0 \cdot \left(\frac{1}{2}\right)^{t/h}$$

A practical check: if the ratio $P(t+k)/P(t)$ is constant for all $t$, the relationship is exponential. If that ratio keeps changing, look for a different model (polynomial, logistic, etc.). Plotting data on a log scale turns an exponential into a straight line — a quick visual test that practitioners use before fitting any model.

### inverse_function (17.3s)

## Inverse Function

A function $f$ takes an input $x$ and produces an output $y = f(x)$. The **inverse function**, written $f^{-1}$, reverses that process: it takes $y$ as input and returns the original $x$. Formally, $f^{-1}(y) = x$ whenever $f(x) = y$. An inverse exists only when $f$ is **one-to-one** (bijective on its domain) — every output must trace back to exactly one input, so no two different inputs can share the same output.

A quick visual test: draw horizontal lines across the graph of $f$. If every horizontal line hits the curve at most once, the function is one-to-one and an inverse exists. This is the **horizontal line test**, the counterpart to the familiar vertical line test.

**Worked example.** Let $f(x) = 2x + 3$. To find $f^{-1}$, write $y = 2x + 3$, then solve for $x$:

$$y - 3 = 2x \implies x = \frac{y - 3}{2}$$

Swapping variable names (so the inverse is also written as a function of $x$):

$$f^{-1}(x) = \frac{x - 3}{2}$$

Verification: $f(f^{-1}(x)) = 2\cdot\dfrac{x-3}{2} + 3 = x$ ✓ and $f^{-1}(f(x)) = \dfrac{(2x+3)-3}{2} = x$ ✓. This double-check — confirming $f(f^{-1}(x)) = x$ and $f^{-1}(f(x)) = x$ — is always the right way to verify an inverse.

**Problem-solving application.** Inverses appear any time you need to "undo" a known process. Suppose a temperature sensor converts Celsius to Fahrenheit via $F(c) = \tfrac{9}{5}c + 32$. A recorded reading is 98.6 °F — what was the Celsius temperature? Rather than rearranging from scratch each time, find $F^{-1}$ once:

$$F^{-1}(f) = \frac{5}{9}(f - 32)$$

Then $F^{-1}(98.6) = \tfrac{5}{9}(66.6) = 37$ °C. The same pattern applies to logarithms undoing exponentials ($\log_b$ is the inverse of $b^x$), arcsine undoing sine, and decryption undoing encryption. Recognizing that you need an inverse — and checking the domain to confirm one exists — is the core problem-solving move.

### logarithmic_function (15.5s)

## Logarithmic Function

**Definition.** The logarithm answers the question: *to what power must a base be raised to produce a given number?* If $b^x = y$, then $\log_b y = x$, where $b > 0$ and $b \neq 1$. Two bases dominate in practice: the common logarithm $\log_{10}$ (written $\log$) and the natural logarithm $\log_e$ (written $\ln$), where $e \approx 2.71828$. The logarithmic function $f(x) = \log_b x$ is defined only for $x > 0$, increases monotonically when $b > 1$, and passes through $(1, 0)$ for any base, since $b^0 = 1$ always.

Key algebraic properties follow directly from exponent rules:

$$\log_b(mn) = \log_b m + \log_b n$$
$$\log_b\!\left(\frac{m}{n}\right) = \log_b m - \log_b n$$
$$\log_b(m^k) = k\log_b m$$

The change-of-base formula $\log_b x = \dfrac{\ln x}{\ln b}$ lets you compute any logarithm with a calculator.

**Worked Example.** A bacterial culture starts at 500 cells and doubles every 3 hours. After how many hours does the population reach 16,000?

Model the growth as $P(t) = 500 \cdot 2^{t/3}$. Set $P = 16000$:

$$500 \cdot 2^{t/3} = 16000$$
$$2^{t/3} = 32 = 2^5$$
$$\frac{t}{3} = 5 \implies t = 15 \text{ hours}$$

When the exponent isn't a clean integer, apply $\ln$ to both sides: $\dfrac{t}{3} = \dfrac{\ln 32}{\ln 2}$, then solve.

**Problem-Solving Application.** Logarithms compress wide-ranging data into manageable scales. The Richter scale measures earthquake intensity as $M = \log_{10}(I/I_0)$, so a magnitude-7 quake is *ten times* more intense than magnitude 6, not one unit more. Similarly, $\text{pH} = -\log_{10}[\text{H}^+]$ — a pH drop from 7 to 5 means hydrogen-ion concentration increased by a factor of 100.

A common exam strategy: whenever an unknown appears as an exponent, take a logarithm of both sides to bring it down as a coefficient. Conversely, when a logarithm is isolated on one side of an equation, rewrite in exponential form to solve. Mastering this two-way translation — between $b^x = y$ and $\log_b y = x$ — is the central skill.

### richter_scale_application (18.8s)

## Richter Scale Application

The Richter scale measures earthquake magnitude using a base-10 logarithm of the maximum seismic wave amplitude recorded by a standardized seismograph. If $A$ is the measured amplitude and $A_0$ is a reference amplitude (the smallest detectable tremor), the magnitude is:

$$M = \log_{10}\!\left(\frac{A}{A_0}\right)$$

Because the scale is logarithmic, each whole-number step up represents a **10× increase in wave amplitude**. Energy release grows even faster — roughly $10^{1.5} \approx 32$ times more energy per step. A magnitude 7.0 earthquake releases about 1,000 times the energy of a magnitude 5.0.

**Worked Example**

Two earthquakes are recorded at the same seismograph station. Earthquake A has a wave amplitude 500 times the reference amplitude; Earthquake B has an amplitude 15,000 times the reference.

Magnitudes:
$$M_A = \log_{10}(500) \approx 2.70$$
$$M_B = \log_{10}(15{,}000) \approx 4.18$$

Difference in magnitude:
$$\Delta M = M_B - M_A = \log_{10}(15{,}000) - \log_{10}(500) = \log_{10}\!\left(\frac{15{,}000}{500}\right) = \log_{10}(30) \approx 1.48$$

So Earthquake B is about 1.5 Richter units stronger, meaning its waves are 30 times larger in amplitude.

**Problem-Solving Application**

The real power of this framework is working backwards from magnitude differences to amplitude or energy ratios — the kind of question that appears in seismology reports and physics courses alike.

*How many times more energetic is a 6.5 earthquake than a 4.0?*

The magnitude difference is $6.5 - 4.0 = 2.5$. Energy scales as $10^{1.5 \cdot \Delta M}$:

$$\text{Energy ratio} = 10^{1.5 \times 2.5} = 10^{3.75} \approx 5{,}623$$

The 6.5 event releases over 5,600 times as much energy — a striking result that pure intuition would badly underestimate.

When comparing two earthquakes of known magnitudes $M_1$ and $M_2$, the amplitude ratio is always $10^{M_2 - M_1}$ and the energy ratio is $10^{1.5(M_2 - M_1)}$. Keeping these two formulas straight — amplitude versus energy — is the most common source of error, so always ask: *is the question asking how the ground shakes, or how much energy is released?*

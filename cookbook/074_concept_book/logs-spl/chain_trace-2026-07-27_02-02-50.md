### difference_quotient (0.0s)

## Difference Quotient

**定义。** 设函数 $f$ 在包含点 $x$ 的某开区间上有定义，给定非零增量 $h$，称比值

$$
\frac{f(x+h)-f(x)}{h}
$$

为 $f$ 在点 $x$ 处关于增量 $h$ 的**差商**（difference quotient）。几何上，它等于曲线 $y=f(x)$ 上两点 $(x,\,f(x))$ 与 $(x+h,\,f(x+h))$ 所确定的割线（secant line）的斜率。

---

**例题。** 设 $f(x)=x^2$，计算差商并观察 $h\to 0$ 时的极限行为。

$$
\frac{f(x+h)-f(x)}{h}
=\frac{(x+h)^2-x^2}{h}
=\frac{x^2+2xh+h^2-x^2}{h}
=\frac{2xh+h^2}{h}
=2x+h.
$$

当 $h=1$ 时差商为 $2x+1$；当 $h=0.1$ 时差商为 $2x+0.1$。可以看出，随着 $h$ 趋近于零，差商趋近于 $2x$——这正是 $f(x)=x^2$ 的导数 $f'(x)=2x$。

---

**核心定理（导数的差商定义）。** 若极限

$$
\lim_{h\to 0}\frac{f(x+h)-f(x)}{h}
$$

存在且有限，则称 $f$ 在点 $x$ 处**可微**，该极限值记为 $f'(x)$，即 $f$ 在 $x$ 处的导数。差商是连接"平均变化率"与"瞬时变化率"这两个概念的桥梁：令 $h\to 0$，割线斜率趋近于切线斜率。可微性蕴含连续性，但反之不然（如 $f(x)=|x|$ 在 $x=0$ 处连续却不可微）。

---

**实验单元（SymPy）。**

```python
from sympy import symbols, limit, simplify

x, h = symbols('x h')
f = x**2

dq = (f.subs(x, x + h) - f) / h
dq_simplified = simplify(dq)
print("差商化简:", dq_simplified)          # 2*x + h

derivative = limit(dq, h, 0)
print("导数（h→0 的极限）:", derivative)   # 2*x
```

修改 `f` 为 `x**3` 或 `sin(x)`，观察差商的代数形式如何随函数变化，并验证极限结果与已知导数公式一致。

### limit (0.0s)

## 极限

**定义**

设函数 $f$ 定义在点 $a$ 的某个去心邻域内。若对任意 $\varepsilon > 0$，存在 $\delta > 0$，使得当 $0 < |x - a| < \delta$ 时，均有

$$|f(x) - L| < \varepsilon,$$

则称 $L$ 为 $f(x)$ 在 $x \to a$ 时的**极限**，记作

$$\lim_{x \to a} f(x) = L.$$

此定义（称为 $\varepsilon$-$\delta$ 定义）的核心在于：无论我们对 $f(x)$ 与 $L$ 之间的误差要求多么严苛（即 $\varepsilon$ 多么小），总能找到一个充分小的 $\delta$，使 $x$ 足够接近 $a$ 时误差得到控制。注意，$x = a$ 处 $f$ 是否有定义与极限值无关。

**例题**

证明 $\displaystyle\lim_{x \to 2}(3x - 1) = 5$。

**证明**：需要对给定的 $\varepsilon > 0$ 找到合适的 $\delta$。计算

$$|f(x) - 5| = |(3x - 1) - 5| = |3x - 6| = 3|x - 2|.$$

要使 $3|x - 2| < \varepsilon$，只需 $|x - 2| < \dfrac{\varepsilon}{3}$。故取 $\delta = \dfrac{\varepsilon}{3}$，则当 $0 < |x - 2| < \delta$ 时，

$$|f(x) - 5| = 3|x - 2| < 3\delta = \varepsilon. \qquad \square$$

**关键定理（极限的唯一性）**

若 $\displaystyle\lim_{x \to a} f(x)$ 存在，则其值唯一。

**证明思路**：设 $\lim_{x\to a}f(x)=L$ 且 $\lim_{x\to a}f(x)=M$，$L\neq M$。取 $\varepsilon=\dfrac{|L-M|}{2}>0$，则由定义可得

$$|L - M| \leq |f(x)-L| + |f(x)-M| < \varepsilon + \varepsilon = |L-M|,$$

矛盾，故 $L = M$。$\square$

**实验单元（SymPy）**

```python
from sympy import symbols, limit, oo

x = symbols('x')

# 验证上述例题
print(limit(3*x - 1, x, 2))          # 输出: 5

# 探索经典极限
print(limit((1 + 1/x)**x, x, oo))    # 输出: E（即自然常数 e）
print(limit(sin(x)/x, x, 0))         # 输出: 1
```

运行以上代码，观察 SymPy 如何通过符号运算直接给出极限值，从而验证 $\varepsilon$-$\delta$ 推导的正确性。

### derivative_at_a_point (0.0s)

## Derivative At A Point

**定义**

设函数 $f$ 在点 $x = a$ 的某个开区间内有定义。若极限

$$
f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}
$$

存在且有限，则称 $f$ 在点 $a$ 处**可微**，并将此极限值称为 $f$ 在 $a$ 处的**导数**，记作 $f'(a)$，亦可写作 $\left.\dfrac{df}{dx}\right|_{x=a}$。几何上，$f'(a)$ 等于曲线 $y = f(x)$ 在点 $(a,\, f(a))$ 处切线的斜率。

---

**例题**

设 $f(x) = x^2$，求 $f'(3)$。

$$
f'(3) = \lim_{h \to 0} \frac{(3+h)^2 - 3^2}{h} = \lim_{h \to 0} \frac{9 + 6h + h^2 - 9}{h} = \lim_{h \to 0} \frac{6h + h^2}{h} = \lim_{h \to 0}(6 + h) = 6.
$$

因此，抛物线 $y = x^2$ 在点 $(3,\, 9)$ 处的切线斜率为 $6$，切线方程为 $y - 9 = 6(x - 3)$，即 $y = 6x - 9$。

---

**关键定理**

> **定理（可微蕴含连续）**：若 $f$ 在点 $a$ 处可微，则 $f$ 在点 $a$ 处连续。

**证明思路**：利用恒等式 $f(a+h) - f(a) = \dfrac{f(a+h)-f(a)}{h} \cdot h$，对两端取 $h \to 0$ 的极限。左端极限即为 $f(a+h) - f(a)$ 趋向的值；右端由极限的乘法法则得 $f'(a) \cdot 0 = 0$，故 $\lim_{h\to 0} f(a+h) = f(a)$，连续性得证。注意逆命题不成立，$f(x) = |x|$ 在 $x=0$ 处连续但不可微即为反例。$\blacksquare$

---

**实验单元（SymPy）**

```python
from sympy import symbols, limit, sqrt

x, h = symbols('x h')

f = x**2
dfdx_at_3 = limit((f.subs(x, 3 + h) - f.subs(x, 3)) / h, h, 0)
print("f'(3) =", dfdx_at_3)          # 输出：6

# 验证 |x| 在 0 处不可微
g = sqrt(x**2)
dg_at_0 = limit((g.subs(x, h) - g.subs(x, 0)) / h, h, 0)
print("g'(0) 的极限：", dg_at_0)     # 输出：nan 或 zoo，表明极限不存在
```

运行上述代码，观察 $f'(3) = 6$ 被精确计算，而 $|x|$ 在原点的差商极限不存在，从而以符号计算直观验证定理中的反例。

### instantaneous_rate_of_change (0.0s)

## 瞬时变化率

**定义**

设函数 $f$ 在点 $x = a$ 的某邻域内有定义。若极限

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$

存在且有限，则称此极限值为 $f$ 在 $x = a$ 处的**瞬时变化率**，亦即 $f$ 在该点的导数。差商 $\dfrac{f(a+h)-f(a)}{h}$ 表示割线斜率，当 $h \to 0$ 时，割线趋近于曲线在 $x = a$ 处的切线，斜率趋近于瞬时变化率。

**例题**

设 $f(x) = x^2$，求 $f$ 在 $x = 3$ 处的瞬时变化率。

$$f'(3) = \lim_{h \to 0} \frac{(3+h)^2 - 9}{h} = \lim_{h \to 0} \frac{9 + 6h + h^2 - 9}{h} = \lim_{h \to 0} (6 + h) = 6.$$

几何意义：抛物线 $y = x^2$ 在点 $(3,\,9)$ 处切线斜率为 $6$，即函数在该点每增加一个单位 $x$，函数值瞬时增加约 $6$ 个单位。

**核心定理**

> **可微蕴含连续性**：若 $f'(a)$ 存在，则 $f$ 在 $x = a$ 处连续。

*证明概要*：由于

$$f(a+h) - f(a) = \frac{f(a+h)-f(a)}{h} \cdot h \xrightarrow{h\to 0} f'(a) \cdot 0 = 0,$$

故 $\lim_{h\to 0} f(a+h) = f(a)$，连续性成立。反之不然：$f(x) = |x|$ 在 $x=0$ 处连续但不可微。

**实验单元（SymPy）**

```python
from sympy import symbols, limit, diff, simplify

x, h = symbols('x h')
f = x**2

# 用极限定义计算瞬时变化率
difference_quotient = (f.subs(x, x + h) - f) / h
iroc_limit = limit(difference_quotient, h, 0)
print("极限定义:", iroc_limit)          # 输出：2*x

# 用 diff 直接求导验证
iroc_diff = diff(f, x)
print("diff 验证:", iroc_diff)          # 输出：2*x

# 在 x=3 处求值
print("x=3 处的值:", iroc_diff.subs(x, 3))  # 输出：6
```

运行以上代码，可验证两种方法给出相同结果，加深对瞬时变化率作为极限过程的直觉。

### derivative_function (19.2s)

## Derivative Function

**定义。** 设函数 $f$ 在点 $x_0$ 的某邻域内有定义。若极限

$$
f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h}
$$

存在且有限，则称 $f$ 在 $x_0$ 处**可微**，并将该极限值称为 $f$ 在 $x_0$ 处的**导数**。若 $f$ 在区间 $I$ 上每一点均可微，则映射 $x \mapsto f'(x)$ 称为 $f$ 的**导函数**，记作 $f'$、$\dfrac{df}{dx}$ 或 $Df$。直观上，$f'(x)$ 度量了函数值随自变量变化而变化的瞬时速率，几何上对应曲线 $y = f(x)$ 在点 $(x, f(x))$ 处切线的斜率。

---

**例题。** 求 $f(x) = x^3$ 的导函数。

由定义，

$$
f'(x) = \lim_{h \to 0} \frac{(x+h)^3 - x^3}{h}.
$$

展开分子：

$$
(x+h)^3 - x^3 = 3x^2 h + 3x h^2 + h^3.
$$

除以 $h$ 后取极限：

$$
f'(x) = \lim_{h \to 0} \left(3x^2 + 3xh + h^2\right) = 3x^2.
$$

这与幂次法则 $\dfrac{d}{dx}x^n = nx^{n-1}$ 在 $n=3$ 时的结论完全一致。

---

**关键定理（可微蕴含连续）。** 若 $f$ 在 $x_0$ 处可微，则 $f$ 在 $x_0$ 处连续。

*证明概要：* 将增量写为

$$
f(x_0+h) - f(x_0) = \frac{f(x_0+h)-f(x_0)}{h} \cdot h.
$$

当 $h \to 0$ 时，右侧第一个因子趋于 $f'(x_0)$（有限值），第二个因子趋于 $0$，故乘积趋于 $0$，即 $\lim_{h\to 0} f(x_0+h) = f(x_0)$。$\blacksquare$

注意：逆命题不成立。$f(x) = |x|$ 在 $x=0$ 处连续但不可微，因为左右差商的极限分别为 $-1$ 与 $1$，不相等。

---

**实验单元（SymPy）。**

```python
from sympy import symbols, diff, limit, Function

x, h = symbols('x h')
f = x**3

# 用极限定义验证
difference_quotient = (f.subs(x, x+h) - f) / h
derivative_from_def = limit(difference_quotient, h, 0)

# 直接求导
derivative_direct = diff(f, x)

print("极限定义：", derivative_from_def)   # 3*x**2
print("diff 函数：", derivative_direct)    # 3*x**2
```

运行上述代码，两种方法均输出 $3x^2$，从而在计算层面验证了定义与求导规则的等价性。读者可将 `f` 替换为其他表达式，探索不同函数的导函数行为。

### higher_order_derivatives (18.2s)

## Higher Order Derivatives

**定义。** 设函数 $f$ 在开区间 $I$ 上可微，其导函数 $f'$ 仍为 $I$ 上的函数。若 $f'$ 在某点 $x$ 处可微，则称该导数为 $f$ 的**二阶导数**，记作

$$f''(x) = \frac{d^2f}{dx^2} = \frac{d}{dx}\!\left(\frac{df}{dx}\right).$$

一般地，$f$ 的 $n$ 阶导数递归定义为

$$f^{(n)}(x) = \frac{d}{dx}f^{(n-1)}(x), \quad n \geq 1,$$

其中约定 $f^{(0)} = f$。称 $f$ 在 $I$ 上 $n$ 次可微，若 $f^{(n)}$ 在 $I$ 上处处存在。

---

**例题。** 求 $f(x) = x^4 - 3x^2 + 2x$ 的各阶导数，并确定何时高阶导数恒为零。

逐阶求导：

$$f'(x) = 4x^3 - 6x + 2,$$
$$f''(x) = 12x^2 - 6,$$
$$f'''(x) = 24x,$$
$$f^{(4)}(x) = 24,$$
$$f^{(n)}(x) = 0, \quad n \geq 5.$$

由此可见，$n$ 次多项式的第 $n+1$ 阶及更高阶导数恒为零。$f''(x) = 12x^2 - 6$ 的零点为 $x = \pm\tfrac{1}{\sqrt{2}}$，这两点正是 $f$ 的**拐点**所在位置，即凹凸性发生改变之处。

---

**关键定理（Taylor 展开的局部形式）。** 设 $f$ 在 $x = a$ 处 $n$ 次可微，则

$$f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x-a)^k + o\!\left((x-a)^n\right), \quad x \to a.$$

此定理表明，高阶导数完整刻画了函数在一点附近的局部行为：$f^{(n)}(a)$ 控制着 $(x-a)^n$ 项的系数，从而决定曲线的弯曲程度与高阶振荡特征。

---

**实验单元（SymPy）。**

```python
import sympy as sp

x = sp.Symbol('x')
f = x**4 - 3*x**2 + 2*x

for n in range(6):
    dn = sp.diff(f, x, n)
    print(f"f^({n}) =", dn)

# 求 f'' 的零点（拐点候选）
inflections = sp.solve(sp.diff(f, x, 2), x)
print("拐点候选 x =", inflections)
```

运行后观察：随着求导阶数增加，多项式次数逐步降低，直至为零。修改 $f$ 为 $\sin x$ 或 $e^x$，体会无穷次可微函数的周期性与自相似性。

### velocity (0.0s)

## 速度

**定义．** 设质点在直线上运动，其位置由函数 $x(t)$ 描述，其中 $t$ 表示时间。在时刻 $t_0$ 处，质点的**瞬时速度**定义为位移关于时间的导数：

$$v(t_0) = \lim_{\Delta t \to 0} \frac{x(t_0 + \Delta t) - x(t_0)}{\Delta t} = x'(t_0).$$

若此极限存在，则称质点在 $t_0$ 处可微，且速度有确定值。速度为标量（在一维情形下），其正负号表示运动方向：$v > 0$ 表示沿正方向运动，$v < 0$ 表示沿负方向运动。速度的绝对值 $|v(t)|$ 称为**速率**。

---

**例题．** 设质点的位置函数为

$$x(t) = 3t^2 - 2t + 1 \quad (t \geq 0, \text{ 单位：米，秒}).$$

求 $t = 2\,\text{s}$ 时的瞬时速度。

**解：** 对 $x(t)$ 关于 $t$ 求导：

$$v(t) = x'(t) = 6t - 2.$$

代入 $t = 2$：

$$v(2) = 6 \times 2 - 2 = 10 \,\text{m/s}.$$

因 $v(2) > 0$，质点此时沿正方向以 $10\,\text{m/s}$ 的速率运动。

---

**定理（速度与位移的关系）．** 设 $v(t)$ 在区间 $[a,b]$ 上连续，则质点在该时间段内的**净位移**为

$$\Delta x = \int_a^b v(t)\,dt = x(b) - x(a).$$

若需求**路程**（即总行驶距离），则需对速率积分：

$$s = \int_a^b |v(t)|\,dt.$$

两者之差体现了方向往返所导致的"抵消"效应。

---

**实验单元（SymPy）．**

```python
import sympy as sp

t = sp.Symbol('t')
x = 3*t**2 - 2*t + 1          # 位置函数

v = sp.diff(x, t)              # 求速度
print("速度函数 v(t) =", v)

v_at_2 = v.subs(t, 2)
print("t=2 时的速度 =", v_at_2, "m/s")

# 在 [0, 3] 上的净位移
displacement = sp.integrate(v, (t, 0, 3))
print("净位移 =", displacement, "m")
```

运行上述代码，应输出 `v(t) = 6t - 2`，`t=2` 处速度为 `10 m/s`，净位移为 `21 m`。修改位置函数，观察速度零点如何将运动分为加速与减速两个阶段，加深对瞬时速度几何意义的直觉认识。

### acceleration (17.7s)

## 加速度

**定义。** 设质点的位置向量为 $\mathbf{r}(t)$，则速度定义为 $\mathbf{v}(t) = \dfrac{d\mathbf{r}}{dt}$。**加速度**（acceleration）是速度对时间的导数：

$$\mathbf{a}(t) = \frac{d\mathbf{v}}{dt} = \frac{d^2\mathbf{r}}{dt^2}.$$

在国际单位制中，加速度的单位为 $\mathrm{m\,s^{-2}}$。加速度是向量量，其方向与速度变化量 $\Delta\mathbf{v}$ 在极限意义下一致，未必沿运动方向。

---

**例题。** 一质点在平面内运动，位置由参数方程

$$x(t) = 3t^2 - t, \qquad y(t) = 2t^3$$

给出（单位：米，秒）。求 $t = 1\,\mathrm{s}$ 时的加速度向量及其大小。

**解。** 对各分量逐次求导：

$$v_x = \frac{dx}{dt} = 6t - 1, \qquad v_y = \frac{dy}{dt} = 6t^2.$$

$$a_x = \frac{dv_x}{dt} = 6, \qquad a_y = \frac{dv_y}{dt} = 12t.$$

代入 $t = 1$：

$$\mathbf{a}(1) = 6\,\hat{x} + 12\,\hat{y} \quad (\mathrm{m\,s^{-2}}).$$

加速度大小为

$$|\mathbf{a}(1)| = \sqrt{6^2 + 12^2} = \sqrt{180} = 6\sqrt{5} \approx 13.4\,\mathrm{m\,s^{-2}}.$$

---

**关键定理（牛顿第二定律）。** 对质量为 $m$ 的质点，若所受合外力为 $\mathbf{F}$，则

$$\mathbf{F} = m\,\mathbf{a}.$$

这一关系将运动学量（加速度）与动力学量（力）联系起来，是经典力学的核心方程。特别地，在匀加速直线运动中，$\mathbf{a}$ 为常向量，位移满足 $s = v_0 t + \tfrac{1}{2}at^2$。

---

**实验单元（SymPy）。**

```python
import sympy as sp

t = sp.Symbol('t')
x = 3*t**2 - t
y = 2*t**3

ax = sp.diff(x, t, 2)
ay = sp.diff(y, t, 2)

t_val = 1
a_vec = (ax.subs(t, t_val), ay.subs(t, t_val))
magnitude = sp.sqrt(a_vec[0]**2 + a_vec[1]**2)

print("加速度分量:", a_vec)          # (6, 12)
print("加速度大小:", sp.simplify(magnitude))  # 6*sqrt(5)
```

运行上述代码，输出结果与手算完全吻合，验证了符号微分的正确性。读者可将位置函数替换为任意可微表达式，探究更复杂运动的加速度特征。

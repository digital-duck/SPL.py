### variable (19.3s)

## 变量

**定义。** 设 $S$ 为某个非空集合，称之为**值域**（domain）。**变量**（variable）是一个符号 $x$，它充当 $S$ 中元素的占位符，即 $x$ 可以取 $S$ 中的任意一个值，而不固定为某个特定元素。形式上，变量由一个有序对 $(x, S)$ 确定，其中 $x$ 为名称，$S$ 为允许赋值的集合。当 $S = \mathbb{R}$ 时，称 $x$ 为**实变量**；当 $S = \{0,1\}$ 时，称 $x$ 为**布尔变量**。变量与**常量**（constant）的本质区别在于：常量的值唯一且固定，而变量在不同上下文或赋值下可以表示不同的量。

**例题。** 考虑二次函数

$$f(x) = x^2 - 4x + 3, \quad x \in \mathbb{R}.$$

此处 $x$ 是实变量，$f$ 是由 $x$ 决定的因变量（dependent variable）。令 $x = 1$：

$$f(1) = 1^2 - 4 \cdot 1 + 3 = 0.$$

令 $x = 3$：

$$f(3) = 9 - 12 + 3 = 0.$$

因此 $x=1$ 与 $x=3$ 均为方程 $f(x)=0$ 的解。这里可以清楚地看到，同一符号 $x$ 在不同赋值下产生不同的函数输出，体现了"变量"的核心含义。

**关键定理（替换定理）。** 设 $P(x)$ 为含变量 $x$ 的命题，若对值域 $S$ 中的某元素 $a$ 有 $P(a)$ 为真，则称 $a$ 为 $P(x)$ 在 $S$ 上的一个**特解**（particular solution）。具体地，若 $P(x) \equiv (f(x) = 0)$，则所有特解的集合

$$\mathcal{S} = \{a \in S \mid f(a) = 0\}$$

称为方程的**解集**。上述例题中 $\mathcal{S} = \{1, 3\}$。

**实验单元（SymPy）。**

```python
from sympy import symbols, factor, solve

x = symbols('x')
f = x**2 - 4*x + 3
print(factor(f))          # (x - 1)*(x - 3)
print(solve(f, x))        # [1, 3]
```

运行上述代码，`symbols('x')` 在 SymPy 中声明了一个符号变量 $x$；`solve(f, x)` 则求出解集 $\mathcal{S}$，验证了手算结果。通过改变传入 `solve` 的表达式，学生可以直观地体验变量在不同方程中的行为，从而加深对"变量作为占位符"这一概念的理解。

### explanatory_response_variable (21.8s)

## 解释变量与响应变量

**定义。** 在统计模型中，**响应变量**（response variable）$Y$ 是研究者希望理解或预测的随机量，而**解释变量**（explanatory variable）$X_1, X_2, \ldots, X_p$ 是被认为对 $Y$ 产生系统性影响的可观测量。线性回归模型将二者的关系形式化为

$$Y = \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p + \varepsilon,$$

其中 $\beta_j \in \mathbb{R}$ 为未知参数，$\varepsilon \sim \mathcal{N}(0, \sigma^2)$ 为随机误差项，满足 $\mathbb{E}[\varepsilon \mid X_1, \ldots, X_p] = 0$。响应变量在条件分布意义下依赖于解释变量，因此也称**因变量**（dependent variable）；解释变量则对应**自变量**（independent variable）。

**具体例子。** 某研究记录了 $n = 50$ 名学生每周自习时间 $X$（小时）与期末考试成绩 $Y$（百分制）。设拟合方程为

$$\hat{Y} = 42.3 + 3.8X.$$

当 $X = 10$ 时，$\hat{Y} = 42.3 + 3.8 \times 10 = 80.3$。此处 $Y$（成绩）是响应变量，$X$（自习时长）是解释变量；斜率 $\hat{\beta}_1 = 3.8$ 表明每增加一小时自习，预测成绩平均提升 $3.8$ 分。

**关键定理（普通最小二乘估计量的无偏性）。** 设设计矩阵 $\mathbf{X} \in \mathbb{R}^{n \times (p+1)}$ 满足 $\operatorname{rank}(\mathbf{X}) = p+1$，则普通最小二乘估计量

$$\hat{\boldsymbol{\beta}} = (\mathbf{X}^\top \mathbf{X})^{-1} \mathbf{X}^\top \mathbf{Y}$$

满足 $\mathbb{E}[\hat{\boldsymbol{\beta}}] = \boldsymbol{\beta}$，且在所有线性无偏估计量中方差最小（Gauss–Markov 定理）。**证明要点：** 将 $\mathbf{Y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}$ 代入，利用 $\mathbb{E}[\boldsymbol{\varepsilon}] = \mathbf{0}$ 即得无偏性；方差最优性由 $\operatorname{Cov}(\boldsymbol{\varepsilon}) = \sigma^2 \mathbf{I}_n$ 的假设推导得出。

**实验单元（SymPy）。**

```python
import sympy as sp

x_data = [5, 8, 10, 12, 15]
y_data = [61, 72, 80, 85, 98]

x, b0, b1 = sp.symbols('x b0 b1')
n = len(x_data)
sx  = sum(x_data)
sy  = sum(y_data)
sxx = sum(xi**2 for xi in x_data)
sxy = sum(xi*yi for xi, yi in zip(x_data, y_data))

b1_val = sp.Rational(n*sxy - sx*sy, n*sxx - sx**2)
b0_val = sp.Rational(sy, n) - b1_val * sp.Rational(sx, n)
print(f"β̂₀ = {b0_val},  β̂₁ = {b1_val}")

model = b0_val + b1_val * x
print("当 x=10 时，Ŷ =", model.subs(x, 10))
```

运行此单元，学生可直接验证最小二乘公式，并观察响应变量预测值随解释变量取值的变化规律。

### population (19.1s)

## 总体

**定义。** 在统计学中，**总体**（population）是指研究者感兴趣的所有个体或观测值的完整集合。设总体为 $\Omega$，其中每个元素 $\omega \in \Omega$ 对应一个随机变量 $X(\omega)$ 的取值。若 $|\Omega| < \infty$，称为**有限总体**；若 $|\Omega| = \infty$，称为**无限总体**。总体由其概率分布完全刻画：对连续型总体，存在概率密度函数 $f(x)$ 使得

$$P(a \leq X \leq b) = \int_a^b f(x)\,dx;$$

对离散型总体，则由概率质量函数 $p(x_k) = P(X = x_k)$ 描述。总体的**均值**与**方差**分别定义为

$$\mu = E[X] = \int_{-\infty}^{\infty} x\,f(x)\,dx, \qquad \sigma^2 = \mathrm{Var}(X) = E\!\left[(X-\mu)^2\right].$$

**例题。** 某城市高中生的数学成绩构成一个有限总体，共 $N = 10{,}000$ 名学生。假设成绩服从正态分布 $X \sim \mathcal{N}(\mu,\,\sigma^2)$，其中 $\mu = 72$，$\sigma = 8$。求成绩超过 $88$ 分的学生比例。

**解：** 标准化得 $Z = \dfrac{X - 72}{8}$，于是

$$P(X > 88) = P\!\left(Z > \frac{88-72}{8}\right) = P(Z > 2) = 1 - \Phi(2) \approx 1 - 0.9772 = 0.0228.$$

故约有 $2.28\%$ 的学生成绩超过 $88$ 分，即约 $228$ 人。

**关键定理（大数定律）。** 设 $X_1, X_2, \ldots, X_n$ 为从总体 $X$ 中独立同分布抽取的样本，且 $E[X] = \mu$ 存在。则样本均值 $\bar{X}_n = \dfrac{1}{n}\sum_{i=1}^n X_i$ 依概率收敛于总体均值：

$$\bar{X}_n \xrightarrow{P} \mu \quad (n \to \infty).$$

此定理是统计推断的理论基石：样本量足够大时，样本统计量可有效估计总体参数。

**实验单元（SymPy）。**

```python
from sympy import symbols, integrate, exp, pi, sqrt, oo, N

x, mu, sigma = symbols('x mu sigma', real=True)
mu_val, sigma_val = 72, 8

# 正态分布密度函数
f = 1/(sigma_val * sqrt(2*pi)) * exp(-((x - mu_val)**2)/(2*sigma_val**2))

# 计算 P(X > 88)
prob = integrate(f, (x, 88, oo))
print("P(X > 88) =", N(prob, 4))  # 输出约 0.02275
```

### treatments_experimental_unit (20.7s)

## Treatments Experimental Unit

**定义。** 在实验设计中，**实验单元**（experimental unit）是指能够独立接受某一处理并产生响应的最小物理或概念实体。**处理**（treatment）是研究者有意施加于实验单元的条件或干预，通常记为 $t_1, t_2, \ldots, t_k$，其中 $k$ 为处理数量。若实验共有 $n$ 个实验单元，每个单元 $i$ 被随机分配到某处理 $\tau_j$，则其观测响应可写为

$$Y_{ij} = \mu + \tau_j + \varepsilon_{ij}, \quad \varepsilon_{ij} \overset{\text{i.i.d.}}{\sim} \mathcal{N}(0,\sigma^2),$$

其中 $\mu$ 为总体均值，$\tau_j$ 为第 $j$ 个处理效应，$\varepsilon_{ij}$ 为随机误差。通常施加约束 $\sum_{j=1}^{k} \tau_j = 0$ 以使模型可识别。

**典型例题。** 某农学研究者希望比较三种施肥方案（$k=3$）对小麦产量的影响。实验中有 $15$ 块相互独立的田地，每种处理随机分配至 $5$ 块。此处，**一块田地即为一个实验单元**，而"施肥方案"即为处理。若将产量（kg/亩）记为 $Y_{ij}$，假设三种处理的样本均值分别为 $\bar{Y}_{1\cdot}=320$、$\bar{Y}_{2\cdot}=345$、$\bar{Y}_{3\cdot}=310$，总均值 $\bar{Y}_{\cdot\cdot}=325$，则各处理效应估计为

$$\hat{\tau}_1 = 320 - 325 = -5, \quad \hat{\tau}_2 = 20, \quad \hat{\tau}_3 = -15.$$

可见方案二使产量显著高于总体均值。

**核心定理（处理效应可估性）。** 在完全随机化设计下，处理效应的最小二乘估计 $\hat{\tau}_j = \bar{Y}_{j\cdot} - \bar{Y}_{\cdot\cdot}$ 是 $\tau_j$ 的最优线性无偏估计（BLUE），且 $\text{Var}(\hat{\tau}_j) = \sigma^2\!\left(\tfrac{1}{n_j} - \tfrac{1}{n}\right)$，其中 $n_j$ 为第 $j$ 个处理的重复数，$n = \sum_j n_j$。

**实验室单元（SymPy）。**

```python
from sympy import symbols, Rational, simplify

mu, tau1, tau2, tau3 = symbols('mu tau_1 tau_2 tau_3')
y_bar = {1: 320, 2: 345, 3: 310}
grand_mean = sum(y_bar.values()) / len(y_bar)
tau_hat = {j: y_bar[j] - grand_mean for j in y_bar}
print("总均值:", grand_mean)
print("处理效应估计:", tau_hat)
print("约束验证（和为零）:", sum(tau_hat.values()))
```

运行此代码可验证 $\sum_j \hat{\tau}_j = 0$，并直观展示实验单元与处理之间的映射关系。

### control_group_placebo (20.3s)

## Control Group Placebo

**定义。** 在实验设计中，*对照组*（control group）是指不接受实验干预的参与者群体，其作用是提供基准测量值，以便与实验组进行比较。*安慰剂*（placebo）是一种外观、味道或感觉上与真实干预完全相同，但不含有效成分的惰性处理。将两者结合，即令对照组接受安慰剂，可系统地消除*安慰剂效应*——即受试者仅因相信自己接受了治疗而产生的主观或生理变化——从而使实验结论仅归因于干预本身。

设实验组测量值为 $Y_T$，安慰剂对照组测量值为 $Y_C$，则干预的*平均处理效应*定义为

$$\tau = \mathbb{E}[Y_T] - \mathbb{E}[Y_C].$$

若不设安慰剂，$Y_C$ 中将混入安慰剂效应 $\delta$，导致 $\hat{\tau}$ 产生偏差 $\delta$。

**具体示例。** 某临床试验评估新型止痛药的效果。100名受试者随机分为两组：实验组50人服用含有效成分的药片，对照组50人服用外形相同的糖片（安慰剂）。试验结束后，实验组疼痛评分（0–10分）均值为 $\bar{Y}_T = 3.2$，对照组均值为 $\bar{Y}_C = 5.1$。估计处理效应为

$$\hat{\tau} = 3.2 - 5.1 = -1.9,$$

即新药使疼痛平均降低1.9分。若对照组不使用安慰剂，部分改善可能源于受试者的心理预期，$\hat{\tau}$ 将被高估。

**关键定理（无偏性条件）。** 设受试者随机分配至实验组与安慰剂对照组，且两组的安慰剂效应 $\delta$ 相等，则估计量

$$\hat{\tau} = \bar{Y}_T - \bar{Y}_C$$

是 $\tau$ 的无偏估计量，即 $\mathbb{E}[\hat{\tau}] = \tau$。

*证明思路：* 随机分配保证 $\mathbb{E}[Y_T] = \mu + \tau + \delta$ 且 $\mathbb{E}[Y_C] = \mu + \delta$，其中 $\mu$ 为基线均值。两式相减，$\delta$ 项抵消，得 $\mathbb{E}[\hat{\tau}] = \tau$。$\blacksquare$

**实验室练习（SymPy）。**

```python
import sympy as sp

mu, tau, delta = sp.symbols('mu tau delta')

E_YT = mu + tau + delta  # 实验组期望
E_YC = mu + delta        # 安慰剂对照组期望

tau_hat = sp.simplify(E_YT - E_YC)
print("估计处理效应:", tau_hat)  # 输出: tau
```

运行上述代码，验证 $\delta$ 在相减后完全消除，从而确认安慰剂对照组设计的无偏性。

### blinding (24.5s)

## 盲法

**定义。** 在实验设计中，*盲法*（blinding）是指对实验参与者——受试者、研究者或两者——隐藏处理分配信息的系统性程序，目的是消除由主观期望引起的偏差。设共有 $n$ 个受试者，随机分配到处理组 $T$ 和对照组 $C$，令 $X_i \in \{0,1\}$ 为第 $i$ 个受试者的分配指示变量。若受试者不知晓 $X_i$ 的值，则称方案为**单盲**；若受试者与评估者均不知晓，则称为**双盲**。设 $Y_i(0)$ 和 $Y_i(1)$ 分别为潜在结局，盲法旨在保证观测结局满足
$$
\mathbb{E}[Y_i^{\text{obs}} \mid X_i, \text{知晓} X_i] = \mathbb{E}[Y_i^{\text{obs}} \mid X_i, \text{不知晓} X_i],
$$
即消除"知晓分配"这一混杂因素对结局的影响。

**具体示例。** 考虑一项评估止痛药疗效的临床试验，共招募 $n = 100$ 名受试者，其中 50 人随机接受新药，50 人接受外观相同的安慰剂。若采用双盲设计，受试者不知晓自己服用的是新药还是安慰剂，评估疼痛程度的医生也不知晓分配情况。设受试者 $i$ 的报告疼痛评分为 $Y_i \in [0,10]$，则平均处理效应估计量为
$$
\hat{\tau} = \frac{1}{50}\sum_{i: X_i=1} Y_i - \frac{1}{50}\sum_{i: X_i=0} Y_i.
$$
若未实施盲法，安慰剂组受试者因知晓自己未接受真实治疗而可能高报疼痛值，导致 $\hat{\tau}$ 被高估，产生系统性偏差。

**关键定理（盲法无偏性）。** 设处理分配满足强可忽略性条件 $\{Y_i(0), Y_i(1)\} \perp X_i$，且盲法成功消除了由知晓分配引起的安慰剂效应偏差，则差值估计量 $\hat{\tau}$ 是平均处理效应 $\tau = \mathbb{E}[Y_i(1) - Y_i(0)]$ 的无偏估计，即 $\mathbb{E}[\hat{\tau}] = \tau$。

**实验室练习（SymPy）。**

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(42)
# 模拟双盲试验：处理组效应为 2，安慰剂效应为 0
Y_treat  = rng.normal(loc=7, scale=1.5, size=50)  # 新药组
Y_control = rng.normal(loc=5, scale=1.5, size=50) # 安慰剂组（盲法消除偏差）

tau_hat = Y_treat.mean() - Y_control.mean()
t_stat, p_val = stats.ttest_ind(Y_treat, Y_control)
print(f"估计处理效应 τ̂ = {tau_hat:.3f}, p 值 = {p_val:.4f}")
```

### lurking_variable (21.8s)

## Lurking Variable

**定义。** 设 $X$、$Y$ 为两个可观测变量，$Z$ 为一个未被纳入研究的变量。若 $Z$ 同时影响 $X$ 与 $Y$，且在统计分析中未加以控制，则称 $Z$ 为**潜伏变量**（lurking variable）。潜伏变量的存在会使研究者错误地将 $X$ 与 $Y$ 之间的相关性解释为因果关系，从而导致**混淆偏差**（confounding bias）。

形式地，设真实数据生成过程为

$$Y = \alpha Z + \varepsilon_Y, \quad X = \beta Z + \varepsilon_X,$$

其中 $\varepsilon_X, \varepsilon_Y$ 相互独立，$\alpha, \beta \neq 0$。若忽略 $Z$，对 $X$ 与 $Y$ 做简单线性回归，所估计的斜率为

$$\hat{b} = \frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}(X)} = \frac{\alpha\beta\operatorname{Var}(Z)}{\beta^2\operatorname{Var}(Z)+\operatorname{Var}(\varepsilon_X)},$$

此值一般不为零，即便 $X$ 对 $Y$ 不存在直接因果效应。

**例题。** 某城市数据显示，冰淇淋日销售量 $X$（万份）与溺水事故数 $Y$（起）之间存在强正相关，皮尔逊相关系数 $r \approx 0.85$。若据此推断"食用冰淇淋导致溺水"，则犯了混淆推断的错误。实际上，气温 $Z$ 既促使居民购买冰淇淋，又增加游泳人数从而提高溺水风险。$Z$ 是此处的潜伏变量；控制 $Z$（例如在相同气温层内分析）后，$X$ 与 $Y$ 的偏相关系数接近于零。

**关键定理（Frisch–Waugh–Lovell，简化版）。** 设多元线性模型为 $Y = \beta_1 X + \beta_2 Z + \varepsilon$。若在回归中遗漏 $Z$，则 $\hat{\beta}_1^{\text{短}}$ 的期望值为

$$\mathbb{E}[\hat{\beta}_1^{\text{短}}] = \beta_1 + \beta_2 \delta_{XZ},$$

其中 $\delta_{XZ}$ 是将 $Z$ 对 $X$ 回归所得斜率。偏差项 $\beta_2\delta_{XZ}$ 称为**遗漏变量偏差**，仅当 $\beta_2 = 0$（$Z$ 与 $Y$ 无关）或 $\delta_{XZ} = 0$（$Z$ 与 $X$ 无关）时消失。

**实验单元（SymPy）。**

```python
import sympy as sp

# 定义符号
b1, b2, d = sp.symbols('beta_1 beta_2 delta')

# 遗漏变量偏差公式
bias = b2 * d
sp.pprint(sp.Eq(sp.Symbol('E[hat_beta_1_short]'), b1 + bias))

# 数值示例：b1=0, b2=2, d=0.5 → 偏差 = 1
print("偏差 =", bias.subs([(b2, 2), (d, sp.Rational(1,2))]))
```

运行结果表明：即使 $\beta_1 = 0$（$X$ 对 $Y$ 无直接影响），遗漏 $Z$ 后估计值仍为 $1$，与真实值相差整整一个单位，印证了潜伏变量对推断的严重干扰。

### random_assignment (19.7s)

## Random Assignment

**定义。** 设实验单元集合为 $\mathcal{U} = \{u_1, u_2, \ldots, u_n\}$，处理集合为 $\mathcal{T} = \{T_1, T_2, \ldots, T_k\}$。**随机分配**（random assignment）是指通过某一概率机制 $\pi$，将每个单元 $u_i$ 独立地映射到某一处理 $T_j$ 上，使得在分配实施前，每个单元接受任意特定处理的概率完全由 $\pi$ 决定，而非由实验者的主观判断或单元自身特征所决定。最简单的情形是完全随机分配（completely randomized design）：将 $n$ 个单元随机划分为 $k$ 组，第 $j$ 组大小为 $n_j$（满足 $\sum_{j=1}^k n_j = n$），则任一特定分配方案出现的概率为

$$
\Pr(\text{给定分配}) = \frac{\prod_{j=1}^{k} n_j!}{n!}.
$$

**例题。** 设 $n = 6$，$k = 2$，$n_1 = n_2 = 3$。将六名学生 $\{A, B, C, D, E, F\}$ 随机分为实验组与对照组，各三人。全部可能的分配数为 $\binom{6}{3} = 20$，每种分配出现的概率均为 $1/20 \approx 0.05$。假设学生 $A$ 和 $B$ 均为高分群体，在完全随机分配下，两人同时进入实验组的概率为

$$
\Pr(A, B \in \text{实验组}) = \frac{\binom{4}{1}}{\binom{6}{3}} = \frac{4}{20} = 0.20.
$$

这说明随机分配并不能保证每次分配都"均衡"，但从期望意义上消除了系统性偏误。

**核心定理（无混淆定理）。** 若分配机制 $\pi$ 与潜在结果 $\{Y_i(T_j)\}$ 相互独立，则处理指示变量 $W_i$ 与潜在结果向量独立，即

$$
W_i \perp \!\!\! \perp \bigl(Y_i(T_1), Y_i(T_2), \ldots, Y_i(T_k)\bigr).
$$

由此，观测到的组间均值差 $\bar{Y}_{\text{实验}} - \bar{Y}_{\text{对照}}$ 是平均处理效应（ATE）的无偏估计量。这是因果推断的基石：随机分配赋予实验内部效度，使相关关系得以上升为因果结论。

**实验室代码（SymPy）。**

```python

from math import comb

n, n1 = 6, 3
total = comb(n, n1)                  # 所有分配方案总数
prob_both_in = comb(4, 1) / total    # A 和 B 同在实验组的概率
print(f"总分配数: {total}, P(A,B同组) = {prob_both_in:.4f}")
```

## 随机实验

**定义。** 若一个实验满足以下三个条件，则称其为**随机实验**（randomized experiment），记作 $\mathcal{E}$：

1. **可重复性**：实验可在相同条件下重复进行；
2. **可列性**：所有可能的结果构成一个已知的集合，称为**样本空间**（sample space），记作 $\Omega$；
3. **随机性**：每次实验前，无法确定哪个具体结果将会发生。

样本空间中的每个元素 $\omega \in \Omega$ 称为一个**样本点**（sample point）。$\Omega$ 的任意子集 $A \subseteq \Omega$ 称为一个**事件**（event）。若实验结果 $\omega \in A$，则称事件 $A$ **发生**。

---

**例题。** 掷一枚均匀六面骰子一次。

- 样本空间：$\Omega = \{1, 2, 3, 4, 5, 6\}$，共 6 个样本点。
- 事件"出现偶数"：$A = \{2, 4, 6\}$。
- 事件"点数大于 4"：$B = \{5, 6\}$。
- 复合事件 $A \cap B = \{6\}$，即"出现大于 4 的偶数"。

由于骰子均匀，每个样本点出现的可能性相同，因此 $P(A) = \tfrac{3}{6} = \tfrac{1}{2}$，$P(B) = \tfrac{2}{6} = \tfrac{1}{3}$，$P(A \cap B) = \tfrac{1}{6}$。

---

**定理（古典概型）。** 若样本空间 $\Omega$ 为有限集，且每个样本点等可能出现，则对任意事件 $A$，有

$$
P(A) = \frac{|A|}{|\Omega|}
$$

其中 $|A|$ 表示 $A$ 中样本点的个数。

**证明思路。** 设 $|\Omega| = n$，每个样本点的概率均为 $p$。由概率的归一化公理 $\sum_{\omega \in \Omega} p = 1$，得 $p = \tfrac{1}{n}$。事件 $A$ 含 $|A|$ 个样本点，故 $P(A) = |A| \cdot \tfrac{1}{n}$。$\blacksquare$

---

**实验单元（SymPy）。**

```python
from sympy import FiniteSet, Rational

Omega = FiniteSet(1, 2, 3, 4, 5, 6)
A = FiniteSet(2, 4, 6)          # 偶数事件
B = FiniteSet(5, 6)             # 大于4事件

P_A = Rational(len(A), len(Omega))
P_B = Rational(len(B), len(Omega))
P_AB = Rational(len(A & B), len(Omega))

print(f"P(A) = {P_A}, P(B) = {P_B}, P(A∩B) = {P_AB}")
```

运行结果：`P(A) = 1/2, P(B) = 1/3, P(A∩B) = 1/6`，与手工计算完全一致。

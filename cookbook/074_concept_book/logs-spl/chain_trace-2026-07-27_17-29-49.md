### matching (14.6s)

## Matching

**Definition.** Let $G = (V, E)$ be an undirected graph. A *matching* in $G$ is a set $M \subseteq E$ of edges such that no two edges in $M$ share a common endpoint. Formally,

$$\forall\, e_1, e_2 \in M,\; e_1 \neq e_2 \implies e_1 \cap e_2 = \emptyset.$$

A vertex $v$ is *matched* if some edge in $M$ is incident to $v$; otherwise $v$ is *free* (or *exposed*). A matching is *perfect* if every vertex is matched, and *maximum* if no matching of larger cardinality exists in $G$.

---

**Worked Example.** Consider the graph $G$ with vertex set $V = \{1, 2, 3, 4, 5, 6\}$ and edge set

$$E = \{\{1,2\},\{1,3\},\{2,4\},\{3,4\},\{4,5\},\{5,6\}\}.$$

The set $M_1 = \{\{1,2\},\{3,4\},\{5,6\}\}$ is a matching of size 3: vertices 1, 2, 3, 4, 5, and 6 are all matched. Since $|M_1| = 3 = |V|/2$, this is a perfect matching (and hence also maximum). By contrast, $M_2 = \{\{1,3\},\{2,4\}\}$ is a valid matching of size 2, leaving vertices 5 and 6 free; it is neither perfect nor maximum.

---

**Key Theorem (Berge, 1957).** A matching $M$ in a graph $G$ is maximum if and only if $G$ contains no *$M$-augmenting path* — a path that begins and ends at free vertices and whose edges alternate between $E \setminus M$ and $M$.

*Proof sketch.* If an augmenting path $P$ exists, the symmetric difference $M \oplus E(P)$ is a matching of size $|M|+1$, contradicting maximality. Conversely, if no augmenting path exists, one shows by contradiction that $M$ must be maximum. $\square$

This theorem underpins the Blossom algorithm, which finds a maximum matching in $O(|V|^3)$ time.

---

### preference_list (19.7s)

## Preference List

**Definition.** Let $A = \{a_1, a_2, \ldots, a_n\}$ and $B = \{b_1, b_2, \ldots, b_n\}$ be two finite sets of agents. A *preference list* for agent $a_i \in A$ is a strict total order $\succ_{a_i}$ over the elements of $B$, written as an ordered tuple

$$P(a_i) = (b_{\sigma(1)},\, b_{\sigma(2)},\, \ldots,\, b_{\sigma(n)}),$$

where $\sigma$ is a permutation of $\{1, \ldots, n\}$ and $b_{\sigma(k)} \succ_{a_i} b_{\sigma(k+1)}$ for all $k$. Informally, $P(a_i)$ ranks every element of $B$ from most preferred to least preferred. A *preference profile* is the collection $\mathcal{P} = \{P(a_i)\}_{i=1}^n \cup \{P(b_j)\}_{j=1}^n$ of all agents' preference lists on both sides.

**Worked Example.** Suppose $A = \{\text{Alice}, \text{Bob}\}$ and $B = \{\text{Xavier}, \text{Yara}\}$ with the following preference lists:

| Agent | Rank 1 | Rank 2 |
|-------|--------|--------|
| Alice | Xavier | Yara |
| Bob | Yara | Xavier |
| Xavier | Alice | Bob |
| Yara | Bob | Alice |

Alice's list is $P(\text{Alice}) = (\text{Xavier}, \text{Yara})$, meaning Xavier $\succ_{\text{Alice}}$ Yara. To check whether agent $a_i$ prefers $b$ over $b'$, we locate both in $P(a_i)$: whichever appears earlier is preferred. The *rank function* $r_{a_i}(b) \in \{1, \ldots, n\}$ assigns the position of $b$ in $P(a_i)$, so $b \succ_{a_i} b'$ if and only if $r_{a_i}(b) < r_{a_i}(b')$.

**Key Theorem (Existence of a Stable Matching, Gale–Shapley 1962).** Given any preference profile $\mathcal{P}$ with $|A| = |B| = n$, the deferred-acceptance algorithm terminates in at most $n^2$ rounds and outputs a *stable matching* $M \subseteq A \times B$ — a perfect matching in which no pair $(a, b) \notin M$ satisfies both $b \succ_a M(a)$ and $a \succ_b M^{-1}(b)$. The proof proceeds by the invariant that once $b$ holds a proposal from $a$, $b$'s held partner can only improve, guaranteeing termination and stability.

### stable_matching_problem (17.7s)

## Stable Matching Problem

**Definition.** Let $A = \{a_1, a_2, \ldots, a_n\}$ and $B = \{b_1, b_2, \ldots, b_n\}$ be two disjoint sets of $n$ agents, each equipped with a strict total preference ordering over the elements of the opposite set. A *matching* $\mu : A \to B$ is a bijection. A matching is called **stable** if there exists no *blocking pair*: a pair $(a_i, b_j)$ such that $a_i$ prefers $b_j$ to $\mu(a_i)$ and $b_j$ prefers $a_i$ to $\mu^{-1}(b_j)$. The **Stable Matching Problem** asks: given arbitrary preference lists, does a stable matching always exist, and if so, how can one be found efficiently?

**Worked Example.** Consider $A = \{a_1, a_2\}$ and $B = \{b_1, b_2\}$ with preferences:

$$a_1: b_1 \succ b_2, \qquad a_2: b_1 \succ b_2$$
$$b_1: a_2 \succ a_1, \qquad b_2: a_1 \succ a_2$$

The matching $\mu = \{(a_1, b_1),\, (a_2, b_2)\}$ is *unstable*: $a_2$ prefers $b_1$ and $b_1$ prefers $a_2$, forming a blocking pair. The matching $\mu^* = \{(a_1, b_2),\, (a_2, b_1)\}$ admits no blocking pair and is therefore stable.

**Key Theorem (Gale–Shapley, 1962).** *A stable matching always exists and can be constructed in $O(n^2)$ time by the deferred acceptance algorithm.* In the $A$-proposing variant, each $a_i$ proposes to its most preferred available partner; each $b_j$ tentatively accepts its most preferred current proposal and rejects the rest. Rejected proposers proceed to their next choice. Termination is guaranteed since each agent proposes to each partner at most once. The resulting matching is $A$-optimal: every $a_i$ receives the best partner they obtain in any stable matching. Symmetrically, it is $B$-pessimal.

**Lab Cell.**

```python
from sympy.combinatorics.graycode import GrayCode  # for permutation tools
# Gale-Shapley implementation
def gale_shapley(a_prefs, b_prefs):
    n = len(a_prefs)
    b_rank = [{b_prefs[b][i]: i for i in range(n)} for b in range(n)]
    next_prop = [0] * n
    b_partner = [-1] * n
    free_a = list(range(n))
    while free_a:
        a = free_a.pop(0)
        b = a_prefs[a][next_prop[a]]
        next_prop[a] += 1
        if b_partner[b] == -1:
            b_partner[b] = a
        elif b_rank[b][a] < b_rank[b][b_partner[b]]:
            free_a.append(b_partner[b])
            b_partner[b] = a
        else:
            free_a.append(a)
    return {b_partner[b]: b for b in range(n)}

a_prefs = [[0, 1], [0, 1]]
b_prefs = [[1, 0], [0, 1]]
print(gale_shapley(a_prefs, b_prefs))  # {1: 0, 0: 1}
```

### gale_shapley_algorithm (22.5s)

## Gale Shapley Algorithm

**Definition.** Let $A = \{a_1, \dots, a_n\}$ and $B = \{b_1, \dots, b_n\}$ be two disjoint sets of $n$ agents, each agent holding a strict total preference ordering over all members of the opposite set. A *matching* $\mu : A \to B$ is a bijection. The matching is *stable* if no unmatched pair $(a_i, b_j)$ with $\mu(a_i) \neq b_j$ satisfies both: $a_i$ prefers $b_j$ over $\mu(a_i)$, and $b_j$ prefers $a_i$ over $\mu^{-1}(b_j)$. Such a pair is called a *blocking pair*; its existence would give both agents a mutual incentive to defect from the matching.

The **Gale–Shapley algorithm** (1962) produces a stable matching in $O(n^2)$ time via iterated proposals. In the $A$-proposing variant:

1. Each unmatched $a_i$ proposes to the most preferred $b_j$ on their list not yet proposed to.
2. $b_j$ *tentatively accepts* the best proposal received so far and *rejects* the rest.
3. Rejected proposers advance to their next candidate. Repeat until no proposals remain.

**Worked Example.** Take $A = \{a_1, a_2\}$ and $B = \{b_1, b_2\}$ with preferences:

$$a_1 : b_1 \succ b_2, \quad a_2 : b_1 \succ b_2, \quad b_1 : a_2 \succ a_1, \quad b_2 : a_1 \succ a_2.$$

*Round 1:* Both $a_1$ and $a_2$ propose to $b_1$. Since $b_1$ prefers $a_2$, she tentatively accepts $a_2$ and rejects $a_1$. *Round 2:* $a_1$ now proposes to $b_2$, who accepts (only offer). Final matching: $\mu(a_1) = b_2,\ \mu(a_2) = b_1$. Verify stability: the only candidate blocking pair $(a_2, b_2)$ fails because $b_2$ prefers $a_1$ over $a_2$. No blocking pair exists; the matching is stable.

**Theorem (Gale–Shapley, 1962).** *For any instance with $n$ agents on each side, the algorithm terminates after at most $n^2$ proposals and returns a stable matching. Moreover, the $A$-proposing variant is $A$-optimal: every $a_i$ is matched to the best partner they receive in any stable matching.*

*Proof sketch.* Termination follows because each proposer advances monotonically down their list and never revisits a rejected candidate. Stability is proved by contradiction: if $(a_i, b_j)$ were a blocking pair, $a_i$ must have proposed to $b_j$ before their final match, meaning $b_j$ rejected $a_i$ for a weakly better partner — contradicting $b_j$'s preference for $a_i$.

```python
# Lab: Gale–Shapley in SymPy-friendly Python
from sympy import symbols

def gale_shapley(a_prefs, b_prefs):
    n = len(a_prefs)
    next_prop = [0] * n          # next index each a_i proposes to
    match_a   = [None] * n
    match_b   = [None] * n
    rank_b    = [{a: r for r, a in enumerate(b_prefs[b])} for b in range(n)]
    free_a    = list(range(n))
    while free_a:
        a = free_a.pop(0)
        b = a_prefs[a][next_prop[a]]
        next_prop[a] += 1
        if match_b[b] is None:
            match_a[a], match_b[b] = b, a
        elif rank_b[b][a] < rank_b[b][match_b[b]]:
            free_a.append(match_b[b])
            match_a[a], match_b[b] = b, a
        else:
            free_a.append(a)
    return match_a

a_prefs = [[0, 1], [0, 1]]
b_prefs = [[1, 0], [0, 1]]
print(gale_shapley(a_prefs, b_prefs))  # [1, 0]
```

## National Resident Matching Program

**Definition.** The *National Resident Matching Program* (NRMP) is a centralized clearinghouse that matches graduating medical students (applicants) to hospital residency positions (programs) using the *Deferred Acceptance algorithm* (DA), introduced by Gale and Shapley (1962). Formally, let $A = \{a_1, \ldots, a_m\}$ be a set of applicants and $P = \{p_1, \ldots, p_n\}$ be a set of programs, each program $p_j$ having capacity $q_j \geq 1$. Each applicant holds a strict preference ordering over programs, and each program holds a strict preference ordering over applicants. A *matching* $\mu : A \to P \cup \{\emptyset\}$ assigns each applicant to at most one program, respecting capacities. A matching is *stable* if no applicant–program pair $(a_i, p_j)$ exists such that $a_i$ prefers $p_j$ to $\mu(a_i)$ and $p_j$ prefers $a_i$ to some matched applicant (or has an unfilled slot).

**Worked Example.** Suppose $A = \{a_1, a_2\}$ and $P = \{p_1, p_2\}$, each with capacity 1, and preferences:

$$a_1: p_1 \succ p_2, \quad a_2: p_1 \succ p_2$$
$$p_1: a_1 \succ a_2, \quad p_2: a_1 \succ a_2$$

In Round 1, both applicants propose to $p_1$. Program $p_1$ tentatively holds $a_1$ (preferred) and rejects $a_2$. In Round 2, $a_2$ proposes to $p_2$, which accepts. The stable matching is $\mu(a_1) = p_1$, $\mu(a_2) = p_2$.

**Key Theorem (Gale–Shapley, 1962).** *The applicant-proposing Deferred Acceptance algorithm always terminates and produces a stable matching. Moreover, this matching is* applicant-optimal: *every applicant receives the best program they can obtain in any stable matching.*

*Proof sketch.* Termination follows because each applicant proposes to each program at most once, bounding iterations by $|A| \cdot |P|$. Stability is verified by contradiction: any blocking pair $(a_i, p_j)$ would require $p_j$ to have rejected $a_i$ in favor of a weakly better applicant, contradicting the definition of blocking. Applicant-optimality follows by induction on the round in which any applicant is first rejected from their true best achievable program.

**Lab Cell.**

```python
from sympy.combinatorics.graycode import GrayCode  # symbolic setup only

def deferred_acceptance(applicant_prefs, program_prefs, capacities):
    free = list(applicant_prefs.keys())
    next_proposal = {a: 0 for a in free}
    held = {p: [] for p in program_prefs}
    while free:
        a = free.pop(0)
        p = applicant_prefs[a][next_proposal[a]]
        next_proposal[a] += 1
        held[p].append(a)
        held[p].sort(key=lambda x: program_prefs[p].index(x))
        if len(held[p]) > capacities[p]:
            free.append(held[p].pop())  # reject least preferred
    return {p: held[p] for p in held}
```

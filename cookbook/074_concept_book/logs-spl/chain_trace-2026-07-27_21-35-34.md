### dist_pred_labels (20.1s)

## Dist Pred Labels

**Definition.** Let $\mathcal{Y} = \{1, 2, \ldots, K\}$ be a finite label set and let $\hat{Y}$ be the random variable representing the output of a classifier applied to a test point drawn from some distribution $P_X$. The *distribution of predicted labels*, denoted $\hat{p}$, is the probability mass function

$$\hat{p}(k) = \Pr(\hat{Y} = k), \quad k \in \mathcal{Y},$$

where the probability is taken jointly over the randomness of the test input and any stochasticity in the classifier. Equivalently, given $n$ test predictions $\hat{y}_1, \ldots, \hat{y}_n$, the empirical estimate is

$$\hat{p}(k) = \frac{1}{n}\sum_{i=1}^{n} \mathbf{1}[\hat{y}_i = k].$$

This distribution characterises how a model *uses* its label space and is distinct from the true label distribution $p^*(k) = \Pr(Y = k)$.

**Worked Example.** Consider a three-class sentiment classifier ($K = 3$: negative, neutral, positive) evaluated on $n = 200$ held-out sentences. Suppose the model predicts: 40 negative, 120 neutral, 40 positive. Then

$$\hat{p}(1) = \frac{40}{200} = 0.20, \quad \hat{p}(2) = \frac{120}{200} = 0.60, \quad \hat{p}(3) = \frac{40}{200} = 0.20.$$

If the true label distribution is $p^* = (0.30, 0.40, 0.30)$, the model over-predicts the neutral class. The total variation distance $\mathrm{TV}(\hat{p}, p^*) = \frac{1}{2}\sum_k |\hat{p}(k) - p^*(k)| = 0.20$ quantifies this systematic shift.

**Key Theorem (Label-Shift Decomposition).** Under the label-shift assumption—where $P(X \mid Y)$ is identical across train and test but $p^* \neq p_{\text{train}}$—the calibration error satisfies

$$\mathbb{E}[|\hat{p}(k) - p^*(k)|] \leq \varepsilon_{\text{cal}} + \mathrm{TV}(p^*_{\text{train}}, p^*),$$

where $\varepsilon_{\text{cal}}$ is the expected calibration error of the model. This shows that a perfectly calibrated model still produces a distorted $\hat{p}$ whenever training and test label marginals differ.

### edge_weight (45.1s)

## Edge Weight

**Definition.** Let $G = (V, E)$ be a graph. An *edge weight function* is a map $w : E \to \mathbb{R}$ that assigns a real number $w(u,v)$ to each edge $\{u,v\} \in E$. The pair $(G, w)$ is called a *weighted graph*. When all weights are non-negative, the weight of an edge is typically interpreted as a cost, distance, or capacity. A graph without an explicit weight function is treated as uniformly weighted: $w(e) = 1$ for all $e \in E$.

The *weight of a path* $P = (v_0, v_1, \ldots, v_k)$ is the sum of its constituent edge weights:

$$w(P) = \sum_{i=0}^{k-1} w(v_i,\, v_{i+1}).$$

This additive structure is what makes edge weights analytically tractable and computationally useful.

**Worked example.** Consider the weighted graph $G$ with vertex set $V = \{A, B, C, D\}$ and edges

$$E = \{\{A,B\},\{B,C\},\{A,C\},\{C,D\}\}$$

with weights $w(A,B)=4$, $w(B,C)=1$, $w(A,C)=3$, $w(C,D)=2$. Two paths connect $A$ to $D$:

- $P_1 = A \to C \to D$: $\;w(P_1) = 3 + 2 = 5$.
- $P_2 = A \to B \to C \to D$: $\;w(P_2) = 4 + 1 + 2 = 7$.

Thus $P_1$ is the lighter path, demonstrating that the shortest path by hop count ($P_2$ uses two hops from $A$) need not coincide with the minimum-weight path.

**Theorem (Minimum-weight path).** Let $(G, w)$ be a finite connected weighted graph with $w(e) \geq 0$ for all $e \in E$. For any two vertices $s, t \in V$, there exists a path $P^*$ from $s$ to $t$ satisfying $w(P^*) \leq w(P)$ for every path $P$ from $s$ to $t$. Moreover, $P^*$ contains no repeated vertices: any cycle appearing in a path can be excised without increasing its total weight, since all cycle edges contribute non-negatively.

### shortest_path (16.5s)

## Shortest Path

**Definition.** Let $G = (V, E, w)$ be a weighted directed graph, where $V$ is a finite set of vertices, $E \subseteq V \times V$ is the edge set, and $w : E \to \mathbb{R}_{\geq 0}$ assigns a non-negative weight to each edge. A *path* from source $s \in V$ to target $t \in V$ is a sequence of vertices $\pi = (v_0, v_1, \ldots, v_k)$ with $v_0 = s$, $v_k = t$, and $(v_{i-1}, v_i) \in E$ for all $i$. The *cost* of $\pi$ is $c(\pi) = \sum_{i=1}^{k} w(v_{i-1}, v_i)$. The **shortest path** from $s$ to $t$ is any path $\pi^*$ satisfying $c(\pi^*) = \min_{\pi : s \rightsquigarrow t} c(\pi)$; its cost is called the *shortest-path distance* $d(s, t)$.

**Worked Example.** Consider the graph with vertices $V = \{A, B, C, D\}$ and weighted edges $w(A,B)=1$, $w(A,C)=4$, $w(B,C)=2$, $w(B,D)=6$, $w(C,D)=1$. To find $d(A, D)$, enumerate candidate paths:

$$\pi_1 = A \to B \to D, \quad c(\pi_1) = 1 + 6 = 7$$
$$\pi_2 = A \to B \to C \to D, \quad c(\pi_2) = 1 + 2 + 1 = 4$$
$$\pi_3 = A \to C \to D, \quad c(\pi_3) = 4 + 1 = 5$$

Thus $d(A, D) = 4$, achieved by $\pi_2$. Dijkstra's algorithm discovers this efficiently by greedily relaxing vertices in order of their current tentative distance.

**Key Theorem (Optimal Substructure).** *If $\pi^* = (v_0, \ldots, v_k)$ is a shortest path from $v_0$ to $v_k$, then for any $0 \leq i \leq j \leq k$, the subpath $(v_i, \ldots, v_j)$ is a shortest path from $v_i$ to $v_j$.*

*Proof sketch.* Suppose subpath $(v_i, \ldots, v_j)$ is not optimal; let $\pi'$ be a cheaper path from $v_i$ to $v_j$. Replacing that segment in $\pi^*$ with $\pi'$ yields a path from $v_0$ to $v_k$ with strictly lower cost, contradicting the optimality of $\pi^*$. $\square$

This property underpins both Dijkstra's algorithm ($O((|V|+|E|)\log|V|)$ with a min-heap) and the Bellman–Ford algorithm ($O(|V||E|)$, handling negative weights).

**Lab Cell.**
```python
import sympy as sp
import heapq

def dijkstra(graph, source):
    dist = {v: sp.oo for v in graph}
    dist[source] = 0
    pq = [(0, source)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            alt = dist[u] + w
            if alt < dist[v]:
                dist[v] = alt
                heapq.heappush(pq, (alt, v))
    return dist

graph = {
    'A': [('B', 1), ('C', 4)],
    'B': [('C', 2), ('D', 6)],
    'C': [('D', 1)],
    'D': []
}
print(dijkstra(graph, 'A'))  # {'A': 0, 'B': 1, 'C': 3, 'D': 4}
```

### tense_edge (31.2s)

## Tense Edge

**Definition.** Let $G = (V, E)$ be a simple graph equipped with an orientation $\vec{G}$, so each edge $\{u,v\}$ is directed as either $(u \to v)$ or $(v \to u)$. Fix a positive integer $k \geq 2$. A *$k$-tension* on $\vec{G}$ is a function $\phi : E \to \mathbb{Z}$ satisfying two conditions:

1. **Range condition:** $1 - k \leq \phi(e) \leq k - 1$ and $\phi(e) \neq 0$ for every $e \in E$.
2. **Cycle condition:** for every directed cycle $C$ in $\vec{G}$, $\displaystyle\sum_{e \in C^+} \phi(e) - \sum_{e \in C^-} \phi(e) = 0$, where $C^+$ (resp. $C^-$) denotes edges of $C$ traversed forward (resp. backward).

An edge $e \in E$ is called **tense** with respect to a $k$-tension $\phi$ if $|\phi(e)| = k - 1$, that is, if $\phi(e)$ attains the extreme permissible value.

**Worked Example.** Consider the triangle $K_3$ with vertices $\{a, b, c\}$ directed cyclically: $a \to b$, $b \to c$, $c \to a$. Define $k = 3$ and assign $\phi(a \to b) = 2$, $\phi(b \to c) = 2$, $\phi(c \to a) = -4$. Check the cycle condition: $2 + 2 + (-4) = 0$. However, $\phi(c \to a) = -4$ lies outside $[1-3,\, 3-1] = [-2, 2]$, so this is not a valid $3$-tension. A valid choice is $\phi(a \to b) = 1$, $\phi(b \to c) = 1$, $\phi(c \to a) = -2$: cycle sum $= 1 + 1 - 2 = 0$ and all values lie in $[-2, 2] \setminus \{0\}$. Here $|{-2}| = 2 = k-1$, so the edge $c \to a$ is tense.

**Key Theorem (Tension–Coloring Duality).** A graph $G$ admits a proper $k$-coloring if and only if it admits a $k$-tension on some orientation. Moreover, if $f : V \to \{0, 1, \ldots, k-1\}$ is a proper coloring, then orienting each edge $\{u,v\}$ as $u \to v$ whenever $f(u) < f(v)$ and setting $\phi(u \to v) = f(v) - f(u)$ yields a $k$-tension. An edge is tense precisely when its two endpoint colors are maximally separated, i.e., $|f(u) - f(v)| = k - 1$.

*Proof sketch.* The cycle condition for $\phi$ is equivalent to $f$ being consistently defined (no "potential drift" around any cycle), which holds because $f$ is single-valued on vertices. Conversely, given a tension $\phi$, one recovers $f$ by summing $\phi$ along any path from a fixed root, and the nonzero range condition ensures $f(u) \neq f(v)$ for adjacent $u, v$.

**Lab Cell (SymPy).**

```python
from sympy import symbols, Eq, solve

# Verify the cycle condition for a 3-tension on the directed triangle
phi_ab, phi_bc, phi_ca = symbols('phi_ab phi_bc phi_ca')
cycle_eq = Eq(phi_ab + phi_bc + phi_ca, 0)
# Fix two tensions, solve for the third
sol = solve(cycle_eq.subs({phi_ab: 1, phi_bc: 1}), phi_ca)
print("phi_ca =", sol)            # [-2]
print("Tense?", abs(sol[0]) == 2) # True (k-1 = 2)
```

### edge_relaxation (19.1s)

## Edge Relaxation

**Definition.** Let $G = (V, E, w)$ be a weighted directed graph with weight function $w : E \to \mathbb{R}$. For each vertex $v \in V$, maintain a tentative distance estimate $d[v]$, initialized as $d[s] = 0$ for a fixed source $s$ and $d[v] = +\infty$ for all $v \neq s$. The **relaxation** of an edge $(u, v) \in E$ is the conditional update

$$
\text{if } d[u] + w(u, v) < d[v] \text{ then } d[v] \leftarrow d[u] + w(u, v).
$$

Geometrically, relaxation tests whether the known shortest path to $u$, extended by the single edge $(u, v)$, improves the current best-known path to $v$. The operation is called *relaxation* because it loosens (weakens) an upper bound: each application can only decrease $d[v]$, never increase it.

**Worked example.** Consider the graph with vertices $\{s, a, b\}$ and edges $s \to a$ with $w = 4$, $s \to b$ with $w = 7$, and $a \to b$ with $w = 1$. Initialize $d[s]=0$, $d[a]=d[b]=+\infty$.

1. Relax $(s, a)$: $0 + 4 < \infty$, so $d[a] \leftarrow 4$.
2. Relax $(s, b)$: $0 + 7 < \infty$, so $d[b] \leftarrow 7$.
3. Relax $(a, b)$: $4 + 1 = 5 < 7$, so $d[b] \leftarrow 5$.

After these three relaxations, $d[b] = 5$, correctly reflecting the shortest path $s \to a \to b$ of total weight $5$.

**Theorem (Convergence of Relaxation).** Let $\delta(s, v)$ denote the true shortest-path distance from $s$ to $v$. If the edges on a shortest path $s = v_0, v_1, \ldots, v_k = v$ are relaxed in the order $(v_0, v_1), (v_1, v_2), \ldots, (v_{k-1}, v_k)$, then after those $k$ relaxations we have $d[v] = \delta(s, v)$.

*Proof sketch.* By induction on path length $k$. Base case $k = 0$: $d[s] = 0 = \delta(s,s)$. Inductive step: assume $d[v_{k-1}] = \delta(s, v_{k-1})$ before relaxing $(v_{k-1}, v_k)$. Then $d[v_{k-1}] + w(v_{k-1}, v_k) = \delta(s, v_k)$ by optimality of the subpath, so the relaxation sets $d[v_k] \leq \delta(s, v_k)$. Since no estimate can undercut a true shortest-path distance, equality holds. $\blacksquare$

**Lab cell.**

```python
import sympy as sp

# Graph as adjacency list: {u: [(v, weight), ...]}
graph = {'s': [('a', 4), ('b', 7)], 'a': [('b', 1)], 'b': []}
d = {'s': 0, 'a': sp.oo, 'b': sp.oo}

def relax(u, v, w):
    if d[u] + w < d[v]:
        d[v] = d[u] + w
        print(f"  Relaxed ({u},{v}): d[{v}] = {d[v]}")

for u, neighbors in graph.items():
    for v, w in neighbors:
        relax(u, v, w)

print("Final distances:", d)
```

Running this cell reproduces the worked example and prints `d[b] = 5`, confirming that a single pass over the edges in topological order suffices when the graph is a DAG.

### negative_edge_weight (45.5s)

## Negative Edge Weight

**Definition.** Let $G = (V, E, w)$ be a weighted directed graph, where $V$ is the set of vertices, $E \subseteq V \times V$ is the set of directed edges, and $w : E \to \mathbb{R}$ is the weight function. An edge $(u, v) \in E$ is called a *negative edge* if $w(u, v) < 0$. A graph containing at least one such edge is said to have *negative edge weights*. A *negative-weight cycle* is a directed cycle $v_1 \to v_2 \to \cdots \to v_k \to v_1$ whose total weight $\sum_{i=1}^{k} w(v_i, v_{i+1})$ is strictly negative.

Negative weights arise naturally in practice: a financial transaction graph may assign negative weights to represent costs or taxes, while a routing network may encode energy recovered by a downhill segment as a negative traversal cost.

**Worked Example.** Consider the graph with vertices $V = \{A, B, C\}$ and edges:

$$w(A, B) = 4, \quad w(B, C) = -6, \quad w(A, C) = 1.$$

The shortest path from $A$ to $C$ is not the direct edge of cost $1$, but the two-hop path $A \to B \to C$ with total weight $4 + (-6) = -2$. Dijkstra's algorithm, which assumes all edge weights are non-negative, would incorrectly return $1$. This example shows that non-negative weight is a necessary precondition for Dijkstra's correctness.

**Key Theorem (Shortest-Path Existence).** *Let $G = (V, E, w)$ be a weighted directed graph with source $s \in V$. A finite shortest-path distance $\delta(s, v)$ exists for every vertex $v$ reachable from $s$ if and only if no negative-weight cycle is reachable from $s$.*

The forward direction is immediate: if a negative-weight cycle lies on a path to $v$, traversing it repeatedly drives the path weight to $-\infty$, so no minimum exists. For the converse, observe that any walk of minimum weight visiting a vertex more than once could have the repeated segment removed without increasing cost; hence a shortest path, when it exists, is a simple path with at most $|V| - 1$ edges, and its weight is finite.

**Lab Cell.**

```python
import sympy as sp

# Edge list: (u, v, weight)
edges = [('A', 'B', 4), ('B', 'C', -6), ('A', 'C', 1)]

# Enumerate all paths from A to C and compute their weights
paths = {
    'A -> C':       [('A', 'C', 1)],
    'A -> B -> C':  [('A', 'B', 4), ('B', 'C', -6)],
}

for name, path in paths.items():
    total = sum(w for _, _, w in path)
    print(f"{name}: weight = {total}")

# Output:
# A -> C:       weight = 1
# A -> B -> C:  weight = -2
```

Running this cell enumerates both candidate paths and confirms that $A \to B \to C$ achieves the minimum weight of $-2$, consistent with the worked example above.

### sssp_problem (17.4s)

## Sssp Problem

**Definition.** Let $G = (V, E, w)$ be a weighted directed graph, where $V$ is a finite set of vertices, $E \subseteq V \times V$ is a set of directed edges, and $w : E \to \mathbb{R}$ assigns a real-valued weight to each edge. A *path* from vertex $s$ to vertex $t$ is a sequence of vertices $\langle v_0, v_1, \dots, v_k \rangle$ with $v_0 = s$, $v_k = t$, and $(v_{i-1}, v_i) \in E$ for all $i$. The *weight* of this path is $W(p) = \sum_{i=1}^{k} w(v_{i-1}, v_i)$. The *shortest-path weight* from $s$ to $t$ is

$$\delta(s, t) = \begin{cases} \min_{p : s \leadsto t} W(p) & \text{if a path exists,} \\ \infty & \text{otherwise.} \end{cases}$$

The **Single-Source Shortest Path (SSSP) problem** asks: given a source vertex $s \in V$, compute $\delta(s, v)$ for every $v \in V$.

---

**Worked Example.** Consider the graph $G$ with $V = \{A, B, C, D\}$ and weighted edges

$$A \xrightarrow{1} B, \quad A \xrightarrow{4} C, \quad B \xrightarrow{2} C, \quad B \xrightarrow{5} D, \quad C \xrightarrow{1} D.$$

With source $s = A$, the direct path $A \to C$ has weight $4$, but the path $A \to B \to C$ has weight $1 + 2 = 3$. Continuing, $A \to B \to C \to D$ has weight $3 + 1 = 4$, whereas $A \to B \to D$ costs $1 + 5 = 6$. Therefore $\delta(A, B) = 1$, $\delta(A, C) = 3$, $\delta(A, D) = 4$.

---

**Key Theorem (Optimal Substructure).** *Any subpath of a shortest path is itself a shortest path.* Formally, if $\langle v_0, v_1, \dots, v_k \rangle$ is a shortest path from $v_0$ to $v_k$, then for any $0 \le i \le j \le k$, the subpath $\langle v_i, v_{i+1}, \dots, v_j \rangle$ is a shortest path from $v_i$ to $v_j$.

*Proof sketch.* Suppose the subpath were not optimal; then a shorter path $p'$ from $v_i$ to $v_j$ exists. Substituting $p'$ into the original path would yield a lighter path from $v_0$ to $v_k$, contradicting the optimality assumption. $\blacksquare$

This property justifies greedy and dynamic-programming algorithms—most notably **Dijkstra's algorithm** (for non-negative weights, $O((|V| + |E|)\log |V|)$) and the **Bellman–Ford algorithm** (for general weights, $O(|V||E|)$).

---

**Lab Cell.**

```python
import sympy as sp
import heapq

def dijkstra(graph, source):
    dist = {v: sp.oo for v in graph}
    dist[source] = 0
    pq = [(0, source)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            alt = dist[u] + w
            if alt < dist[v]:
                dist[v] = alt
                heapq.heappush(pq, (alt, v))
    return dist

G = {'A': [('B',1),('C',4)], 'B': [('C',2),('D',5)],
     'C': [('D',1)],         'D': []}
print(dijkstra(G, 'A'))
# {'A': 0, 'B': 1, 'C': 3, 'D': 4}
```

### fords_generic_algorithm (18.3s)

## Ford's Generic Algorithm

**Definition.** Let $G = (V, E, w)$ be a directed graph with vertex set $V$, edge set $E$, and weight function $w : E \to \mathbb{R}$. Fix a source vertex $s \in V$. For each vertex $v$, maintain a *tentative distance label* $d[v]$, initialized as

$$d[s] = 0, \quad d[v] = +\infty \quad \text{for all } v \neq s.$$

The **relaxation** of an edge $(u, v) \in E$ replaces $d[v]$ with $\min(d[v],\, d[u] + w(u,v))$ whenever the right-hand side is strictly smaller. Ford's Generic Algorithm repeatedly selects *any* edge $(u,v)$ for which $d[u] + w(u,v) < d[v]$ and relaxes it, until no such edge exists. The order in which edges are selected is left unspecified; specific scheduling choices yield Dijkstra's algorithm, the Bellman–Ford algorithm, and other classical variants.

**Worked Example.** Consider $G$ with $V = \{s, a, b, t\}$ and edges

$$s \to a : 4,\quad s \to b : 2,\quad b \to a : 1,\quad a \to t : 3,\quad b \to t : 6.$$

Initialize $d = [s:0,\, a:\infty,\, b:\infty,\, t:\infty]$. Relax $s\to b$: $d[b]=2$. Relax $b\to a$: $d[a]=3$. Relax $s\to a$: $3 < \infty$ but $4 > 3$, so no update. Relax $a\to t$: $d[t]=6$. Relax $b\to t$: $8 > 6$, no update. No eligible edge remains; the shortest path $s\to b\to a\to t$ has cost $6$.

**Key Theorem (Correctness).** If $G$ contains no negative-weight cycle reachable from $s$, then Ford's Generic Algorithm terminates and, upon termination, $d[v]$ equals the true shortest-path distance $\delta(s,v)$ for every $v \in V$.

*Proof sketch.* One shows by induction on the number of edges in an optimal path that each $d[v]$ is an upper bound throughout execution and that it can decrease to $\delta(s,v)$ after finitely many relaxations. The absence of a negative cycle guarantees shortest paths are simple and the process terminates.

### negative_cycle (15.4s)

## Negative Cycle

**Definition.** Let $G = (V, E, w)$ be a directed weighted graph where $w : E \to \mathbb{R}$ assigns a real-valued weight to each edge. A *negative cycle* is a directed cycle $C = (v_0, v_1, \ldots, v_k, v_0)$ whose total weight is strictly negative:

$$W(C) = \sum_{i=0}^{k-1} w(v_i, v_{i+1}) < 0.$$

Negative cycles are not merely a curiosity — they render the shortest-path problem ill-defined. If a negative cycle is reachable from a source $s$, one can traverse the cycle arbitrarily many times, driving the path weight toward $-\infty$. No finite shortest path exists for any vertex reachable from that cycle.

**Worked Example.** Consider the graph with vertices $\{A, B, C\}$ and directed edges:

$$w(A,B) = 4,\quad w(B,C) = -7,\quad w(C,A) = 2.$$

The cycle $A \to B \to C \to A$ has total weight $4 + (-7) + 2 = -1 < 0$. Hence this graph contains a negative cycle. Any path passing through $A$, $B$, or $C$ has no well-defined minimum, since each additional traversal of the cycle reduces the path cost by $1$.

**Key Theorem (Bellman–Ford Detection).** *A directed weighted graph $G$ contains a negative cycle reachable from source $s$ if and only if, after $|V| - 1$ relaxation passes of the Bellman–Ford algorithm, at least one edge $(u,v)$ still satisfies*

$$d[v] > d[u] + w(u,v),$$

*where $d[v]$ denotes the current shortest-path estimate to $v$.*

*Proof sketch.* After $|V|-1$ passes, Bellman–Ford guarantees $d[v] = \delta(s,v)$ for all vertices reachable without negative cycles ($\delta$ denotes the true shortest-path distance). A further relaxation can improve an estimate only if some cycle on the shortest path has negative total weight, contradicting the finiteness of $\delta$.

**Lab Cell.**

```python
import sympy as sp

# Edge list: (u, v, weight)
edges = [(0, 1, 4), (1, 2, -7), (2, 0, 2)]
n = 3
dist = [sp.oo] * n
dist[0] = 0

for _ in range(n - 1):
    for u, v, w in edges:
        if dist[u] + w < dist[v]:
            dist[v] = dist[u] + w

negative_cycle = any(dist[u] + w < dist[v] for u, v, w in edges)
print("Negative cycle detected:", negative_cycle)  # True
print("Distances:", dist)
```

Running this cell confirms detection: one further relaxation pass succeeds, revealing the negative cycle $A \to B \to C \to A$.

### bellman_ford (44.2s)

## Bellman–Ford

**Definition.** Let $G = (V, E)$ be a directed weighted graph with weight function $w : E \to \mathbb{R}$, and let $s \in V$ be a designated source vertex. The *Bellman–Ford algorithm* computes, for every vertex $v \in V$, the shortest-path distance $\delta(s, v)$ — the minimum total weight over all simple walks from $s$ to $v$. The algorithm is built on one central operation: *edge relaxation*. To relax an edge $(u, v)$, inspect whether the currently known distance to $v$ can be improved by routing through $u$:

$$d(v) \;\leftarrow\; \min\!\bigl(d(v),\; d(u) + w(u,v)\bigr).$$

Formally, define $d_k(v)$ as the weight of the shortest path from $s$ to $v$ using at most $k$ edges. The recurrence is

$$d_0(s) = 0, \quad d_0(v) = +\infty \text{ for } v \neq s,$$

$$d_k(v) = \min\!\Bigl(d_{k-1}(v),\; \min_{(u,v)\in E}\bigl[d_{k-1}(u) + w(u,v)\bigr]\Bigr).$$

The algorithm applies relaxation to every edge in each of $|V|-1$ rounds.

**Worked Example.** Consider four vertices $\{s, a, b, c\}$ with edges $s \to a$ (weight $6$), $s \to b$ (weight $7$), $a \to b$ (weight $-3$), $b \to c$ (weight $9$), $a \to c$ (weight $5$). Initially $d = [0, \infty, \infty, \infty]$. After round 1, relaxing all edges yields $d(a)=6$, $d(b)=7$, $d(c)=\infty$. After round 2, relaxing $a \to b$ gives $d(b) = \min(7,\, 6 + (-3)) = 3$, and relaxing $b \to c$ gives $d(c) = \min(\infty,\, 7+9) = 16$. After round 3, relaxing $b \to c$ again gives $d(c) = \min(16,\, 3+9) = 12$. The shortest path $s \to a \to b \to c$ carries total weight $12$.

**Key Theorem.** *Correctness of Bellman–Ford.* If $G$ contains no negative-weight cycle reachable from $s$, then after $|V|-1$ relaxation rounds $d_{|V|-1}(v) = \delta(s,v)$ for all $v \in V$. The proof proceeds by induction on $k$: any shortest path is simple and therefore uses at most $|V|-1$ edges, so $k$ rounds of relaxation suffice to propagate optimal distances along all paths of length at most $k$. Time complexity is $O(|V| \cdot |E|)$.

**Lab Cell.**

```python
import sympy as sp

def bellman_ford(edges, n_vertices, source):
    INF = sp.oo
    dist = [INF] * n_vertices
    dist[source] = 0
    for _ in range(n_vertices - 1):
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w  # edge relaxation
    return dist

edges = [(0,1,6),(0,2,7),(1,2,-3),(2,3,9),(1,3,5)]
print(bellman_ford(edges, 4, source=0))  # [0, 6, 3, 12]
```

### fifo_queue (17.5s)

## Fifo Queue

**Definition.** A *first-in, first-out queue* (FIFO queue) is an abstract data type that maintains a linearly ordered collection of elements subject to two primary operations: **enqueue**, which inserts an element at one end (the *rear*), and **dequeue**, which removes an element from the opposite end (the *front*). Formally, let $Q = (q_1, q_2, \ldots, q_n)$ denote the state of a queue with $n$ elements. An enqueue of element $x$ produces $Q' = (q_1, q_2, \ldots, q_n, x)$, while a dequeue yields element $q_1$ and leaves $Q' = (q_2, \ldots, q_n)$. The invariant is strict: the element that has waited longest is always the next to be served. A dequeue on an empty queue is undefined and raises an error.

**Worked Example.** Suppose a print server processes jobs in arrival order. Jobs arrive in the sequence $J_1, J_2, J_3$ with arrival times $t = 0, 2, 5$ (seconds). Enqueuing each job in order gives $Q = (J_1, J_2, J_3)$. The server dequeues $J_1$ first, completing it at time $t = 3$; then dequeues $J_2$, completing it at time $t = 6$; finally $J_3$ completes at $t = 9$. The average waiting time is

$$\bar{W} = \frac{(0-0) + (3-2) + (6-5)}{3} = \frac{0 + 1 + 1}{3} \approx 0.67 \text{ s},$$

illustrating that FIFO scheduling minimises the maximum unfairness: no job is bypassed by a later arrival.

**Key Theorem (Amortised $O(1)$ per Operation).** When a FIFO queue is implemented with two stacks $S_\text{in}$ and $S_\text{out}$, each element is pushed onto $S_\text{in}$ exactly once and transferred to $S_\text{out}$ exactly once. Therefore the total cost of $n$ enqueue–dequeue pairs is $O(n)$, giving an *amortised* cost of $O(1)$ per operation, even though an individual dequeue may trigger an $O(k)$ transfer when $S_\text{out}$ is empty.

**Lab Cell.**

```python
from collections import deque
import sympy as sp

# Build a FIFO queue and track waiting times symbolically
arrival = [0, 2, 5]        # arrival times
service = [3, 3, 3]        # service durations

Q = deque()
for j, (a, s) in enumerate(zip(arrival, service), start=1):
    Q.append((f"J{j}", a, s))

t = sp.Rational(0)
wait_times = []
for name, arr, svc in Q:
    start = max(t, sp.Rational(arr))
    wait  = start - sp.Rational(arr)
    wait_times.append(wait)
    t = start + sp.Rational(svc)

avg_wait = sp.Rational(sum(wait_times), len(wait_times))
sp.pprint(sp.Eq(sp.Symbol(r'\bar{W}'), avg_wait))
```

Running this cell confirms $\bar{W} = \tfrac{2}{3}$, matching the analytic result above.

### moores_algorithm (25.3s)

## Moore's Algorithm

### Definition

A **deterministic finite automaton (DFA)** $M = (Q, \Sigma, \delta, q_0, F)$ may contain redundant states: distinct states $p, q \in Q$ such that for every string $w \in \Sigma^*$, $\delta^*(p, w) \in F \iff \delta^*(q, w) \in F$. Such states are called **equivalent** (written $p \sim q$), and their merger yields a smaller automaton recognising the same language. **Moore's algorithm** (Edward F. Moore, 1956) computes the coarsest congruence on $Q$ consistent with $\delta$ and $F$, producing the unique minimal DFA up to isomorphism.

The algorithm maintains a partition $\Pi$ of $Q$ and refines it iteratively. Formally, two states $p, q$ are **$k$-equivalent** if they agree on all strings of length at most $k$:

$$p \sim_0 q \iff (p \in F \iff q \in F),$$
$$p \sim_{k+1} q \iff p \sim_k q \;\land\; \forall a \in \Sigma,\; \delta(p,a) \sim_k \delta(q,a).$$

The sequence $\Pi_0, \Pi_1, \ldots$ of induced partitions is monotonically refining. Because $Q$ is finite, it stabilises at some step $n \leq |Q|-1$, yielding the equivalence ${\sim} = {\sim_n}$.

### Worked Example

Consider the DFA over $\Sigma = \{0, 1\}$ with states $Q = \{A, B, C, D\}$, $q_0 = A$, $F = \{C, D\}$, and transitions:

| State | 0 | 1 |
|-------|---|---|
| $A$   | $B$ | $C$ |
| $B$   | $A$ | $D$ |
| $C$   | $D$ | $C$ |
| $D$   | $C$ | $D$ |

**Step 0.** $\Pi_0 = \{\{A,B\},\{C,D\}\}$ (non-accepting vs. accepting).

**Step 1.** Check $A \sim_1 B$: on input $0$, $\delta(A,0)=B \in \{A,B\}$ and $\delta(B,0)=A \in \{A,B\}$; on input $1$, $\delta(A,1)=C \in \{C,D\}$ but $\delta(B,1)=D \in \{C,D\}$. Both transitions stay in the same block, so $A \sim_1 B$. Similarly $C \sim_1 D$. Thus $\Pi_1 = \Pi_0$ — the partition has stabilised. The minimal DFA has two states.

### Key Theorem

**Theorem (Myhill–Nerode / Moore minimisation).** The DFA produced by Moore's algorithm is isomorphic to the Myhill–Nerode minimal automaton of the language. If $|Q| = n$, the algorithm terminates in at most $n-1$ refinement steps with time complexity $O(n^2 |\Sigma|)$.

*Proof sketch.* Each refinement that strictly splits a block reduces the number of blocks by at least one; with at most $n$ blocks possible, convergence in $n-1$ steps is guaranteed. Correctness follows because $\sim$ is the largest right-congruence on $Q$ compatible with $F$.

### Lab Cell

```python
from sympy import symbols, Function, Eq, simplify

# Encode the example DFA as transition tables and verify block stability
Q = ['A', 'B', 'C', 'D']
F = {'C', 'D'}
delta = {('A','0'):'B', ('A','1'):'C',
         ('B','0'):'A', ('B','1'):'D',
         ('C','0'):'D', ('C','1'):'C',
         ('D','0'):'C', ('D','1'):'D'}

def refine(partition, delta, alphabet='01'):
    block_of = {s: i for i, blk in enumerate(partition) for s in blk}
    new_partition = []
    for blk in partition:
        groups = {}
        for s in blk:
            key = tuple(block_of[delta[(s, a)]] for a in alphabet)
            groups.setdefault(key, []).append(s)
        new_partition.extend(groups.values())
    return [sorted(b) for b in new_partition]

partition = [sorted(set(Q) - F), sorted(F)]
while True:
    next_p = refine(partition, delta)
    if next_p == partition:
        break
    partition = next_p

print("Minimal DFA blocks:", partition)
# Output: [['A', 'B'], ['C', 'D']]
```

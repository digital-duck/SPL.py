### derivative (0.0s)

## 导数

**定义。** 设函数 $f$ 在点 $x_0$ 的某邻域内有定义。若极限

$$f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h}$$

存在且有限，则称 $f$ 在点 $x_0$ **可微**，并将该极限值称为 $f$ 在 $x_0$ 处的**导数**（derivative）。几何上，$f'(x_0)$ 即曲线 $y = f(x)$ 在点 $(x_0,\, f(x_0))$ 处切线的斜率；物理上，若 $f(t)$ 表示位移，则 $f'(t)$ 表示瞬时速度。

---

**例题。** 求 $f(x) = x^2$ 在 $x_0 = 3$ 处的导数。

按定义展开差商：

$$\frac{f(3+h) - f(3)}{h} = \frac{(3+h)^2 - 9}{h} = \frac{9 + 6h + h^2 - 9}{h} = 6 + h.$$

令 $h \to 0$，得

$$f'(3) = \lim_{h \to 0}(6 + h) = 6.$$

几何验证：曲线 $y = x^2$ 在点 $(3, 9)$ 处的切线方程为 $y - 9 = 6(x - 3)$，即 $y = 6x - 9$。

---

**定理（可微必连续）。** 若 $f$ 在 $x_0$ 处可微，则 $f$ 在 $x_0$ 处连续。

**证明思路。** 将函数增量写成

$$f(x_0 + h) - f(x_0) = \frac{f(x_0+h)-f(x_0)}{h} \cdot h.$$

当 $h \to 0$ 时，右端第一个因子趋向 $f'(x_0)$（有限值），第二个因子 $h \to 0$，故乘积趋向 $0$，即 $\lim_{h\to 0} f(x_0+h) = f(x_0)$，连续性得证。$\blacksquare$

注意逆命题不成立：$f(x) = |x|$ 在 $x = 0$ 处连续但不可微，因为左右极限 $\lim_{h\to 0^-} h/|h| = -1 \neq 1 = \lim_{h\to 0^+} h/|h|$ 不相等。

---

**实验单元（SymPy）。**

```python
import sympy as sp

x, h = sp.symbols('x h')
f = x**2

# 用极限定义计算导数
diff_quot = (f.subs(x, x + h) - f) / h
derivative = sp.limit(diff_quot, h, 0)
print(derivative)          # 输出：2*x

# 符号求导验证
print(sp.diff(f, x))       # 输出：2*x
```

运行上述代码，两种方式均输出 $2x$，与幂函数求导公式 $(x^n)' = nx^{n-1}$（取 $n=2$）完全一致。

### antiderivative (16.8s)

## Antiderivative

### 定义

设函数 $F(x)$ 在区间 $I$ 上可微，若对所有 $x \in I$ 均满足

$$F'(x) = f(x),$$

则称 $F(x)$ 为 $f(x)$ 在区间 $I$ 上的一个**原函数**（antiderivative）。由于任意常数 $C$ 的导数为零，故若 $F(x)$ 是 $f(x)$ 的一个原函数，则 $F(x) + C$（$C \in \mathbb{R}$）也是 $f(x)$ 的原函数。全体原函数的集合称为 $f(x)$ 的**不定积分**，记作

$$\int f(x)\,\mathrm{d}x = F(x) + C.$$

此处积分号 $\int$ 与微分元 $\mathrm{d}x$ 共同指定积分变量，常数 $C$ 称为**积分常数**。

### 例题

求 $f(x) = 3x^2$ 的不定积分。

**解：** 猜测原函数具有形式 $F(x) = x^n$，对其求导得 $F'(x) = nx^{n-1}$。令 $n = 3$，则 $(x^3)' = 3x^2 = f(x)$，验证成立。因此

$$\int 3x^2\,\mathrm{d}x = x^3 + C.$$

验证：对 $x^3 + C$ 求导，得 $3x^2$，与原函数定义吻合。

### 核心定理

**定理（原函数存在性与唯一性）。** 若 $f(x)$ 在区间 $I$ 上连续，则 $f(x)$ 在 $I$ 上必存在原函数。进一步，若 $F(x)$ 与 $G(x)$ 均为 $f(x)$ 在 $I$ 上的原函数，则存在常数 $C$ 使得

$$G(x) = F(x) + C, \quad \forall x \in I.$$

**证明思路：** 令 $H(x) = G(x) - F(x)$，则 $H'(x) = G'(x) - F'(x) = f(x) - f(x) = 0$。由拉格朗日中值定理，导数恒为零的函数在连通区间上必为常数，故 $H(x) = C$，即 $G(x) = F(x) + C$。$\blacksquare$

### 实验单元（SymPy）

```python
from sympy import symbols, integrate, diff

x = symbols('x')
f = 3*x**2

F = integrate(f, x)
print("不定积分：", F)          # 输出：x**3
print("验证求导：", diff(F, x)) # 输出：3*x**2
```

运行上述代码，SymPy 自动省略积分常数 $C$；在实际应用中，务必手动添加 $+\, C$ 以表示完整的原函数族。

### indefinite_integral (16.2s)

## 不定积分

**定义。** 设函数 $f(x)$ 在区间 $I$ 上有定义。若存在函数 $F(x)$，使得对所有 $x \in I$ 均有

$$F'(x) = f(x),$$

则称 $F(x)$ 为 $f(x)$ 在 $I$ 上的一个**原函数**。$f(x)$ 的全体原函数构成的集合称为 $f(x)$ 的**不定积分**，记作

$$\int f(x)\,dx = F(x) + C,$$

其中 $C \in \mathbb{R}$ 为任意常数，称为**积分常数**。符号 $\int$ 称为积分号，$f(x)$ 称为被积函数，$x$ 称为积分变量。

由于任意两个原函数之差为常数，不定积分所表示的并非单一函数，而是一族彼此相差常数的函数。

---

**例题。** 求 $\displaystyle\int 3x^2\,dx$。

**解：** 注意到 $\dfrac{d}{dx}(x^3) = 3x^2$，故 $x^3$ 是 $3x^2$ 的一个原函数。由定义，

$$\int 3x^2\,dx = x^3 + C.$$

验证：对 $x^3 + C$ 求导，得 $(x^3 + C)' = 3x^2$，与被积函数一致。$\blacksquare$

---

**定理（不定积分的线性性质）。** 设 $f(x)$ 与 $g(x)$ 均在区间 $I$ 上存在原函数，$\alpha, \beta \in \mathbb{R}$，则

$$\int [\alpha f(x) + \beta g(x)]\,dx = \alpha \int f(x)\,dx + \beta \int g(x)\,dx.$$

**证明思路：** 设 $F'(x) = f(x)$，$G'(x) = g(x)$。令 $H(x) = \alpha F(x) + \beta G(x)$，则

$$H'(x) = \alpha F'(x) + \beta G'(x) = \alpha f(x) + \beta g(x),$$

故 $H(x)$ 是 $\alpha f(x) + \beta g(x)$ 的原函数，命题成立。$\square$

线性性质使复杂函数的积分可逐项分解处理，是后续计算的基础。

---

**实验单元（SymPy）**

```python
from sympy import symbols, integrate, cos, exp

x = symbols('x')

# 多项式积分
print(integrate(3*x**2, x))          # x**3

# 三角函数积分
print(integrate(cos(x), x))          # sin(x)

# 指数函数积分
print(integrate(exp(x), x))          # exp(x)

# 线性组合
print(integrate(2*x + cos(x), x))    # x**2 + sin(x)
```

运行上述代码可验证：SymPy 返回的结果均省略常数 $C$，实际使用时应手动补充。

### initial_value_problem (16.8s)

## Initial Value Problem

**定义。** 设 $F$ 为定义在某区域 $D \subseteq \mathbb{R}^2$ 上的函数，**初值问题**（Initial Value Problem，简称 IVP）是指求满足以下条件的函数 $y(x)$：

$$
\frac{dy}{dx} = F(x,\, y), \qquad y(x_0) = y_0,
$$

其中 $(x_0, y_0) \in D$ 称为**初始条件**（initial condition）。与一般微分方程不同，初值问题要求解曲线必须过指定点 $(x_0, y_0)$，从而在满足存在性的前提下唯一确定解。

---

**例题。** 求解初值问题

$$
\frac{dy}{dx} = 2x, \qquad y(1) = 3.
$$

**解：** 对方程两边关于 $x$ 积分，得

$$
y = \int 2x\, dx = x^2 + C,
$$

其中 $C$ 为任意常数。代入初始条件 $y(1) = 3$：

$$
3 = 1^2 + C \implies C = 2.
$$

故唯一解为 $y(x) = x^2 + 2$。可验证：$y'(x) = 2x$ 且 $y(1) = 3$，满足题设。

---

**关键定理（Picard–Lindelöf 定理）。** 若 $F(x, y)$ 在以 $(x_0, y_0)$ 为中心的矩形区域上连续，且关于 $y$ 满足 **Lipschitz 条件**，即存在常数 $L > 0$ 使得

$$
|F(x, y_1) - F(x, y_2)| \leq L\,|y_1 - y_2|,
$$

则初值问题在 $x_0$ 的某邻域内存在**唯一**连续可微解。该定理保证了物理模型（如质点运动、电路响应）由初始状态唯一决定未来演化这一直觉的严格数学基础。

---

**实验单元（SymPy）。**

```python
import sympy as sp

x = sp.Symbol('x')
y = sp.Function('y')

ode = sp.Eq(y(x).diff(x), 2*x)
sol = sp.dsolve(ode, y(x), ics={y(1): 3})
print(sol)          # 输出: Eq(y(x), x**2 + 2)
sp.plot(sol.rhs, (x, 0, 3), title='初值问题的解')
```

运行上述代码，SymPy 将自动施加初始条件并化简积分常数，所得曲线图直观展示解在 $(1, 3)$ 处穿过的几何意义。

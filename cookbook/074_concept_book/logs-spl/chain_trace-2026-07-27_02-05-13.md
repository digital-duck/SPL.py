### absolute_extrema (18.4s)

## Absolute Extrema

**定义。** 设函数 $f$ 定义在区间 $I$ 上。若存在点 $c \in I$，使得对所有 $x \in I$ 均有 $f(c) \geq f(x)$，则称 $f(c)$ 为 $f$ 在 $I$ 上的**绝对最大值**（全局最大值）；若对所有 $x \in I$ 均有 $f(c) \leq f(x)$，则称 $f(c)$ 为 $f$ 在 $I$ 上的**绝对最小值**（全局最小值）。绝对最大值与绝对最小值统称为**绝对极值**（绝对极端值）。

**极值存在定理（闭区间定理）。** 若函数 $f$ 在闭区间 $[a, b]$ 上连续，则 $f$ 在 $[a, b]$ 上必同时取得绝对最大值与绝对最小值。该定理的两个条件——连续性与闭区间——缺一不可：开区间 $(0,1)$ 上的函数 $f(x)=x$ 连续却无绝对最大值；闭区间 $[0,1]$ 上的分段函数若含跳跃间断点，同样可能失去极值。

**求法（候选点法）。** 绝对极值只能在以下三类点上取得：（1）区间端点 $a$、$b$；（2）区间内部满足 $f'(c)=0$ 的**驻点**；（3）区间内部 $f'$ 不存在的**奇异点**。依次计算这些候选点处的函数值，最大者为绝对最大值，最小者为绝对最小值。

**例题。** 求 $f(x) = x^3 - 3x^2 + 1$ 在 $[-\tfrac{1}{2},\, 3]$ 上的绝对极值。

*解：* 首先求导：$f'(x) = 3x^2 - 6x = 3x(x-2)$。令 $f'(x)=0$，得驻点 $x=0$ 与 $x=2$，均在区间内。列表计算各候选点处的函数值：

| 候选点 | $f$ 值 |
|--------|--------|
| $x = -\tfrac{1}{2}$ | $(-\tfrac{1}{2})^3 - 3(\tfrac{1}{4}) + 1 = \tfrac{1}{8}$ |
| $x = 0$ | $1$ |
| $x = 2$ | $8 - 12 + 1 = -3$ |
| $x = 3$ | $27 - 27 + 1 = 1$ |

比较可知，绝对最大值为 $\boxed{1}$（在 $x=0$ 与 $x=3$ 处同时取得），绝对最小值为 $\boxed{-3}$（在 $x=2$ 处取得）。

**实验单元（SymPy）。**

```python
from sympy import *
x = symbols('x')
f = x**3 - 3*x**2 + 1
interval = Rational(-1,2), 3

crit = solve(diff(f, x), x)
candidates = list(interval) + [c for c in crit if interval[0] < c < interval[1]]
vals = {c: f.subs(x, c) for c in candidates}
print("绝对最大值:", max(vals, key=vals.get), "→", max(vals.values()))
print("绝对最小值:", min(vals, key=vals.get), "→", min(vals.values()))
```

### derivative (0.0s)

## 导数

**定义。** 设函数 $f$ 在点 $x_0$ 的某邻域内有定义。若极限

$$f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h}$$

存在且有限，则称 $f$ 在点 $x_0$ **可微**，并将该极限值称为 $f$ 在 $x_0$ 处的**导数**（derivative）。几何上，$f'(x_0)$ 即曲线 $y = f(x)$ 在点 $(x_0,\, f(x_0))$ 处切线的斜率；物理上，若 $f(t)$ 表示位移，则 $f'(t)$ 表示瞬时速度。

---

**例题。** 求 $f(x) = x^2$ 在 $x_0 = 3$ 处的导数。

按定义展开差商：

$$\frac{f(3+h) - f(3)}{h} = \frac{(3+h)^2 - 9}{h} = \frac{9 + 6h + h^2 - 9}{h} = 6 + h.$$

令 $h \to 0$，得

$$f'(3) = \lim_{h \to 0}(6 + h) = 6.$$

几何验证：曲线 $y = x^2$ 在点 $(3, 9)$ 处的切线方程为 $y - 9 = 6(x - 3)$，即 $y = 6x - 9$。

---

**定理（可微必连续）。** 若 $f$ 在 $x_0$ 处可微，则 $f$ 在 $x_0$ 处连续。

**证明思路。** 将函数增量写成

$$f(x_0 + h) - f(x_0) = \frac{f(x_0+h)-f(x_0)}{h} \cdot h.$$

当 $h \to 0$ 时，右端第一个因子趋向 $f'(x_0)$（有限值），第二个因子 $h \to 0$，故乘积趋向 $0$，即 $\lim_{h\to 0} f(x_0+h) = f(x_0)$，连续性得证。$\blacksquare$

注意逆命题不成立：$f(x) = |x|$ 在 $x = 0$ 处连续但不可微，因为左右极限 $\lim_{h\to 0^-} h/|h| = -1 \neq 1 = \lim_{h\to 0^+} h/|h|$ 不相等。

---

**实验单元（SymPy）。**

```python
import sympy as sp

x, h = sp.symbols('x h')
f = x**2

# 用极限定义计算导数
diff_quot = (f.subs(x, x + h) - f) / h
derivative = sp.limit(diff_quot, h, 0)
print(derivative)          # 输出：2*x

# 符号求导验证
print(sp.diff(f, x))       # 输出：2*x
```

运行上述代码，两种方式均输出 $2x$，与幂函数求导公式 $(x^n)' = nx^{n-1}$（取 $n=2$）完全一致。

### critical_point (18.7s)

## 极值点

**定义。** 设函数 $f$ 在开区间 $I$ 上可微。若某点 $c \in I$ 满足

$$f'(c) = 0$$

或 $f'(c)$ 不存在，则称 $c$ 为 $f$ 的**极值点**（临界点）。极值点是函数局部极大值或局部极小值的*必要候选*，但并非所有极值点都对应极值。

几何上，$f'(c)=0$ 意味着曲线 $y=f(x)$ 在 $x=c$ 处的切线为水平线；导数不存在的点（如尖角或竖直切线处）同样需要检验。

---

**例题。** 设 $f(x) = x^3 - 3x + 2$，求其所有极值点并判断类型。

**第一步：求导并令导数为零。**

$$f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$$

令 $f'(x)=0$，解得 $x=1$ 与 $x=-1$，均为极值点候选。

**第二步：用第二导数检验。**

$$f''(x) = 6x$$

- $x=-1$：$f''(-1)=-6<0$，故 $f$ 在 $x=-1$ 处取得**局部极大值** $f(-1)=4$。  
- $x=1$：$f''(1)=6>0$，故 $f$ 在 $x=1$ 处取得**局部极小值** $f(1)=0$。

---

**关键定理（费马定理）。** 若 $f$ 在点 $c$ 处可微，且 $c$ 为局部极值点，则

$$f'(c) = 0.$$

**证明思路：** 不妨设 $c$ 为局部极大值点，则存在 $\delta>0$，对一切 $|h|<\delta$ 有 $f(c+h)\le f(c)$。

$$\lim_{h\to 0^+}\frac{f(c+h)-f(c)}{h}\le 0, \qquad \lim_{h\to 0^-}\frac{f(c+h)-f(c)}{h}\ge 0.$$

由于导数存在，两个单侧极限相等，故必有 $f'(c)=0$。$\blacksquare$

注意：定理的逆命题不成立。$g(x)=x^3$ 在 $x=0$ 处有 $g'(0)=0$，但该点为**鞍点**（拐点），并非极值。

---

**实验单元（SymPy）**

```python
from sympy import symbols, diff, solve, latex

x = symbols('x')
f = x**3 - 3*x + 2
fp  = diff(f, x)
fpp = diff(fp, x)

critical_pts = solve(fp, x)
for c in critical_pts:
    val   = f.subs(x, c)
    test  = fpp.subs(x, c)
    kind  = "局部极小" if test > 0 else "局部极大" if test < 0 else "需进一步检验"
    print(f"x = {c}: f(x) = {val}, f''(x) = {test} → {kind}")
```

运行后将输出 $x=-1$（局部极大，$f=4$）与 $x=1$（局部极小，$f=0$），与手算结果完全一致。

### local_extrema (17.4s)

## Local Extrema

**定义。** 设函数 $f$ 在点 $c$ 的某邻域内有定义。若存在 $\delta > 0$，使得对所有满足 $|x - c| < \delta$ 的 $x$，均有 $f(x) \leq f(c)$，则称 $c$ 为 $f$ 的**局部极大值点**，$f(c)$ 为对应的**局部极大值**。类似地，若 $f(x) \geq f(c)$ 对上述邻域内所有 $x$ 成立，则 $c$ 为**局部极小值点**。局部极大值点与局部极小值点统称为**局部极值点**（local extrema）。

**费马定理（必要条件）。** 若 $f$ 在 $c$ 处可微且 $c$ 为局部极值点，则 $f'(c) = 0$。

> *证明思路：* 不妨设 $c$ 为局部极大值点。对 $h > 0$ 充分小，有
> $$\frac{f(c+h)-f(c)}{h} \leq 0, \quad \frac{f(c-h)-f(c)}{-h} \geq 0.$$
> 令 $h \to 0^+$，两侧均趋向 $f'(c)$，故 $f'(c) \leq 0$ 且 $f'(c) \geq 0$，即 $f'(c) = 0$。

注意费马定理仅给出必要条件：$f'(c) = 0$ 的点称为**驻点**，驻点未必是极值点（如 $f(x) = x^3$ 在 $x = 0$ 处）。

**二阶导数判别法（充分条件）。** 设 $f'(c) = 0$ 且 $f''(c)$ 存在。若 $f''(c) < 0$，则 $c$ 为局部极大值点；若 $f''(c) > 0$，则 $c$ 为局部极小值点；若 $f''(c) = 0$，则此判别法失效，需进一步分析。

**例题。** 求 $f(x) = x^3 - 3x$ 的局部极值。

令 $f'(x) = 3x^2 - 3 = 0$，解得 $x = \pm 1$。计算二阶导数：$f''(x) = 6x$。

- 在 $x = -1$：$f''(-1) = -6 < 0$，故 $x = -1$ 为局部极大值点，$f(-1) = 2$。
- 在 $x = 1$：$f''(1) = 6 > 0$，故 $x = 1$ 为局部极小值点，$f(1) = -2$。

**实验单元（SymPy）。**

```python
from sympy import symbols, diff, solve, latex

x = symbols('x')
f = x**3 - 3*x
fp = diff(f, x)
critical = solve(fp, x)
fpp = diff(fp, x)
for c in critical:
    print(f"x={c}: f''={fpp.subs(x,c)}, f(c)={f.subs(x,c)}")
```

### extreme_value_theorem (19.6s)

## Extreme Value Theorem

**定义.** 设 $f$ 为定义在闭区间 $[a, b]$ 上的连续函数。**极值定理**（Extreme Value Theorem，EVT）断言：$f$ 在 $[a, b]$ 上必然取得其最大值与最小值，即存在点 $c, d \in [a, b]$，使得对所有 $x \in [a, b]$，均有

$$
f(d) \leq f(x) \leq f(c).
$$

此处，$f(c)$ 称为 $f$ 在 $[a, b]$ 上的**全局最大值**，$f(d)$ 称为**全局最小值**。定理成立的两个关键条件缺一不可：区间必须**有界且闭合**，函数必须**连续**。若去掉任一条件，结论可能失效——例如 $f(x) = x$ 在开区间 $(0, 1)$ 上连续，却无最大值。

---

**例题.** 求 $f(x) = x^3 - 3x$ 在 $[-2, 2]$ 上的全局极值。

**解：** 首先求驻点。令

$$
f'(x) = 3x^2 - 3 = 0 \implies x = \pm 1.
$$

两个驻点均属于 $(-2, 2)$，因此候选点为端点与驻点共四处：

| $x$ | $f(x)$ |
|-----|--------|
| $-2$ | $(-8)+6 = -2$ |
| $-1$ | $-1+3 = 2$ |
| $1$ | $1-3 = -2$ |
| $2$ | $8-6 = 2$ |

比较可得：**全局最大值**为 $f(-1) = f(2) = 2$，**全局最小值**为 $f(-2) = f(1) = -2$。

---

**关键定理（证明思路）.** 极值定理的严格证明依赖实数完备性。其核心步骤如下：

1. 因 $[a,b]$ 为紧集，$f$ 连续，故 $f([a,b])$ 亦为紧集（连续映射保紧性）。
2. $\mathbb{R}$ 中的紧子集有界且闭合，因而其上确界 $M = \sup_{x\in[a,b]} f(x)$ 属于该集合。
3. 故存在 $c \in [a,b]$ 使 $f(c) = M$；最小值同理可证。$\blacksquare$

---

**实验单元（SymPy）.**

```python
from sympy import *
x = symbols('x')
f = x**3 - 3*x
interval = (-2, 2)

candidates = [interval[0], interval[1]] + solve(diff(f, x), x)
values = {c: f.subs(x, c) for c in candidates if interval[0] <= c <= interval[1]}

print("全局最大值:", max(values, key=values.get), "→", max(values.values()))
print("全局最小值:", min(values, key=values.get), "→", min(values.values()))
```

运行结果将验证上述手算结论，并展示如何利用符号计算系统性地搜索极值候选点。

### fermats_theorem (19.1s)

## 费马定理

### 定义

设 $p$ 为素数，$a$ 为整数且 $\gcd(a, p) = 1$（即 $p \nmid a$），则

$$a^{p-1} \equiv 1 \pmod{p}.$$

这一结论称为**费马小定理**（Fermat's Little Theorem），是初等数论中最基本的同余结果之一。其等价形式为：对任意整数 $a$ 及素数 $p$，均有

$$a^p \equiv a \pmod{p},$$

此形式无需对 $p \nmid a$ 加以额外假设。

### 证明思路

考虑集合 $S = \{1, 2, \ldots, p-1\}$，共 $p-1$ 个元素。将 $S$ 中每个元素乘以 $a$ 后对 $p$ 取余，得到集合 $\{a \cdot 1,\, a \cdot 2,\, \ldots,\, a \cdot (p-1)\} \pmod{p}$。由于 $\gcd(a,p)=1$，乘法映射在 $\mathbb{Z}/p\mathbb{Z}^*$ 上是双射，故该集合仍为 $S$ 的一个排列。于是

$$\prod_{k=1}^{p-1}(ak) \equiv \prod_{k=1}^{p-1} k \pmod{p},$$

即 $a^{p-1}(p-1)! \equiv (p-1)! \pmod{p}$。因 $\gcd((p-1)!, p) = 1$，两边约去 $(p-1)!$ 得 $a^{p-1} \equiv 1 \pmod{p}$。$\blacksquare$

### 具体例子

取素数 $p = 7$，$a = 3$。费马小定理预言 $3^6 \equiv 1 \pmod{7}$。

逐步验证：

$$3^1 = 3,\quad 3^2 = 9 \equiv 2,\quad 3^3 \equiv 6,\quad 3^4 \equiv 18 \equiv 4,\quad 3^5 \equiv 12 \equiv 5,\quad 3^6 \equiv 15 \equiv 1 \pmod{7}.$$

结果与定理完全吻合。

### 关键定理（推论：模逆元）

若 $p$ 为素数且 $p \nmid a$，则 $a$ 在模 $p$ 意义下的乘法逆元为

$$a^{-1} \equiv a^{p-2} \pmod{p}.$$

这是费马小定理在密码学（如 RSA 算法）和组合数学中计算模逆元的核心应用。

### 实验单元（SymPy）

```python
from sympy import isprime, mod_inverse

p, a = 7, 3
assert isprime(p)

# 验证费马小定理
print(pow(a, p - 1, p))          # 输出 1

# 利用费马定理计算逆元
inv_fermat = pow(a, p - 2, p)
inv_sympy  = mod_inverse(a, p)
print(inv_fermat, inv_sympy)      # 均输出 5，因为 3×5=15≡1 (mod 7)
```

### locating_absolute_extrema (20.3s)

## Locating Absolute Extrema

**定义。** 设函数 $f$ 在闭区间 $[a, b]$ 上连续。若存在 $c \in [a, b]$ 使得对所有 $x \in [a, b]$ 均有 $f(c) \ge f(x)$，则称 $f(c)$ 为 $f$ 在 $[a, b]$ 上的**绝对最大值**（全局最大值）；若对所有 $x \in [a, b]$ 均有 $f(c) \le f(x)$，则称 $f(c)$ 为**绝对最小值**（全局最小值）。两者统称为**绝对极值**。由魏尔斯特拉斯极值定理，闭区间上的连续函数必然同时取得绝对最大值与绝对最小值。

**求解步骤。** 绝对极值只能在以下三类点处取得：①区间端点 $a$ 与 $b$；②区间内部使 $f'(x) = 0$ 的**驻点**；③区间内部使 $f'(x)$ 不存在的**奇异点**。算法如下：

1. 求导数 $f'(x)$，解方程 $f'(x) = 0$ 及确定 $f'(x)$ 不存在之点，找出 $[a,b]$ 内的所有候选点。
2. 计算 $f$ 在所有候选点及两端点处的函数值。
3. 比较上述函数值，最大者为绝对最大值，最小者为绝对最小值。

**例题。** 求 $f(x) = x^3 - 3x^2 + 1$ 在 $[-1, 3]$ 上的绝对极值。

**解：** 求导得
$$f'(x) = 3x^2 - 6x = 3x(x-2).$$
令 $f'(x) = 0$，解得驻点 $x = 0$ 与 $x = 2$，均在 $[-1, 3]$ 内。计算各候选点处的函数值：

| $x$ | $f(x)$ |
|-----|--------|
| $-1$ | $(-1)^3 - 3(-1)^2 + 1 = -3$ |
| $0$ | $0 - 0 + 1 = 1$ |
| $2$ | $8 - 12 + 1 = -3$ |
| $3$ | $27 - 27 + 1 = 1$ |

比较可知，$f$ 在 $x = 0$ 与 $x = 3$ 处取得绝对最大值 $1$，在 $x = -1$ 与 $x = 2$ 处取得绝对最小值 $-3$。

**关键定理（闭区间法）。** 若 $f$ 在 $[a,b]$ 上连续，则
$$\max_{[a,b]} f = \max\bigl\{f(a),\, f(b),\, f(c_1),\dots,f(c_k)\bigr\},$$
其中 $c_1, \dots, c_k$ 为所有内部临界点。此结论将无界搜索问题化为有限点的比较问题。

```python
# 实验单元：用 SymPy 验证上述结果
from sympy import *

x = symbols('x')
f = x**3 - 3*x**2 + 1
a, b = -1, 3

crit = solve(diff(f, x), x)
candidates = [a, b] + [c for c in crit if a <= c <= b]
values = {c: f.subs(x, c) for c in candidates}
print("函数值表：", values)
print("绝对最大值：", max(values.values()))
print("绝对最小值：", min(values.values()))
```

## Flow Network

**Definition.** A *flow network* is a directed graph $G = (V, E)$ equipped with a non-negative *capacity function* $c : E \to \mathbb{R}_{\geq 0}$, a designated *source* $s \in V$, and a designated *sink* $t \in V$. Given such a network, a *flow* is any assignment $f : E \to \mathbb{R}_{\geq 0}$ that obeys two rules at every edge and every interior vertex:

1. **Capacity constraint:** $0 \leq f(u,v) \leq c(u,v)$ for every edge $(u,v) \in E$.
2. **Flow conservation:** For every vertex $v \in V \setminus \{s, t\}$, total inflow equals total outflow:
$$\sum_{u:(u,v)\in E} f(u,v) \;=\; \sum_{w:(v,w)\in E} f(v,w).$$

The *value* of a flow is the net amount leaving the source: $|f| = \sum_{w:(s,w)\in E} f(s,w) - \sum_{u:(u,s)\in E} f(u,s)$.

**Worked Example.** Take $V = \{s, A, B, t\}$ with capacities $c(s,A)=3$, $c(s,B)=2$, $c(A,t)=2$, $c(B,t)=3$, $c(A,B)=1$. Set $f(s,A)=3$, $f(s,B)=2$, $f(A,t)=2$, $f(A,B)=1$, $f(B,t)=3$. At vertex $A$: inflow $= 3$, outflow $= 2 + 1 = 3$ ✓. At vertex $B$: inflow $= 2 + 1 = 3$, outflow $= 3$ ✓. Each edge respects its capacity, and $|f| = 3 + 2 = 5$.

**Key Theorem (Max-Flow Min-Cut).** The maximum achievable flow value from $s$ to $t$ equals the minimum total capacity of any set of edges whose removal disconnects $s$ from $t$. The proof identifies a maximum flow with a residual graph that admits no augmenting path; the vertices reachable from $s$ in that residual graph then define the separating edge set of minimum capacity.

**Lab Cell (NetworkX).**
```python
import networkx as nx

G = nx.DiGraph()
G.add_edge('s', 'A', capacity=3)
G.add_edge('s', 'B', capacity=2)
G.add_edge('A', 't', capacity=2)
G.add_edge('B', 't', capacity=3)
G.add_edge('A', 'B', capacity=1)

flow_value, flow_dict = nx.maximum_flow(G, 's', 't')
print("Max flow:", flow_value)          # Expected: 5
print("Flow on each edge:", flow_dict)
```

### capacity_function (0.0s)

## Capacity Function

**Definition.** Let $G = (V, E)$ be a directed graph. A *capacity function* is a map $c : E \to \mathbb{R}_{\geq 0}$ that assigns to each directed edge $(u, v) \in E$ a non-negative real number $c(u, v)$, called the *capacity* of that edge. For any ordered pair $(u, v)$ where no directed edge exists, we set $c(u, v) = 0$ by convention. Intuitively, $c(u, v)$ represents the maximum rate at which some commodity — data, fluid, traffic — can be transported from $u$ to $v$ per unit time.

A *flow network* is a quadruple $(G, c, s, t)$ where $s \in V$ is the designated *source* and $t \in V$ is the designated *sink*. Every quantitative question about routing — how much can be sent, where the bottleneck lies — is ultimately answered in terms of $c$. Subsequent sections introduce feasible flows and the Max-Flow Min-Cut Theorem; the present goal is to read and construct $c$ correctly.

**Worked Example.** Consider the network with vertex set $\{s, a, b, t\}$ and the following capacity assignments:

$$c(s,a) = 3,\quad c(s,b) = 2,\quad c(a,t) = 2,\quad c(b,t) = 3,\quad c(a,b) = 1.$$

All other ordered pairs, such as $(a, s)$ or $(b, a)$, receive capacity $0$ by the default convention. Observe that the total capacity leaving $s$ is $c(s,a)+c(s,b)=5$ and the total capacity entering $t$ is $c(a,t)+c(b,t)=5$ — a balance that will prove significant when maximum flows are studied. For now, verify that every listed value is non-negative and that unlisted directed pairs default to $0$.

**Theorem (Asymmetry of $c$).** In a capacity function, it is possible that $c(u,v) \neq c(v,u)$ for the same pair of vertices. Consequently, the direction of each edge is essential: reversing it may reduce the capacity to zero. This asymmetry is precisely what allows flow networks to model one-way pipes, directed highways, and asymmetric bandwidth links.

```python
# Lab: build and inspect a capacity function
capacities = {('s','a'): 3, ('s','b'): 2,
              ('a','t'): 2, ('b','t'): 3, ('a','b'): 1}

def c(u, v):
    return capacities.get((u, v), 0)

assert all(val >= 0 for val in capacities.values())

print(f"c(a,b) = {c('a','b')}, c(b,a) = {c('b','a')}")  # c(a,b) = 1, c(b,a) = 0

out_s = c('s', 'a') + c('s', 'b')
print(f"Total capacity leaving s: {out_s}")  # 5
```

### cut (19.3s)

## Cut

**Definition.** Let $G = (V, E)$ be an undirected graph. A *cut* is a partition of the vertex set $V$ into two non-empty, disjoint subsets $S$ and $\bar{S} = V \setminus S$. The *cut-set* associated with this partition is the collection of edges with exactly one endpoint in each part:

$$C(S, \bar{S}) = \{\{u, v\} \in E : u \in S,\; v \in \bar{S}\}.$$

The *size* of a cut is $|C(S, \bar{S})|$ for unweighted graphs; for a weighted graph with edge-weight function $w : E \to \mathbb{R}_{>0}$, the *capacity* of the cut is

$$\mathrm{cap}(S, \bar{S}) = \sum_{\{u,v\} \in C(S,\bar{S})} w(u, v).$$

A cut is called an *$s$–$t$ cut* when a designated source $s \in S$ and sink $t \in \bar{S}$ lie on opposite sides of the partition.

**Worked example.** Consider the weighted graph on five vertices $\{s, a, b, c, t\}$ with edges $s$–$a$ (4), $s$–$b$ (2), $a$–$c$ (3), $b$–$c$ (1), $b$–$t$ (5), $c$–$t$ (2). Take $S = \{s, a\}$ and $\bar{S} = \{b, c, t\}$. The cut-set is $\{s\text{-}b,\; a\text{-}c\}$ and its capacity is $2 + 3 = 5$. Choosing instead $S = \{s\}$ gives cut-set $\{s\text{-}a,\; s\text{-}b\}$ with capacity $4 + 2 = 6$. The first partition is therefore tighter, carrying less total weight across the divide.

**Key theorem (Max-Flow Min-Cut).** For any network with non-negative edge capacities, the value of a maximum $s$–$t$ flow equals the capacity of a minimum $s$–$t$ cut:

$$\max_{f} |f| = \min_{(S,\bar{S}):\, s\in S,\, t\in\bar{S}} \mathrm{cap}(S, \bar{S}).$$

*Proof sketch.* By flow conservation, no flow value can exceed any cut capacity (weak duality). The Ford–Fulkerson algorithm terminates with a residual graph in which $t$ is unreachable from $s$; the set of vertices reachable from $s$ in that residual graph defines a cut whose capacity exactly matches the achieved flow, closing the duality gap.

**Lab cell.**

```python
import networkx as nx

G = nx.DiGraph()
G.add_edge('s', 'a', capacity=4)
G.add_edge('s', 'b', capacity=2)
G.add_edge('a', 'c', capacity=3)
G.add_edge('b', 'c', capacity=1)
G.add_edge('b', 't', capacity=5)
G.add_edge('c', 't', capacity=2)

flow_value, partition = nx.minimum_cut(G, 's', 't')
S, T = partition
print(f"Min-cut value : {flow_value}")
print(f"S = {S},  T = {T}")
```

Running this cell returns a min-cut value of $4$, achieved by isolating $t$ with the partition $T = \{t\}$, confirming that the bottleneck of the network is the two edges entering the sink.

### cut_capacity (16.0s)

## Cut Capacity

**Definition.** Let $G = (V, E)$ be a directed graph with a distinguished source $s \in V$ and sink $t \in V$. Each edge $(u, v) \in E$ carries a non-negative capacity $c(u, v) \geq 0$. An **$s$-$t$ cut** is a partition $(S, T)$ of $V$ such that $s \in S$ and $t \in T$. The **cut capacity** is the total capacity of edges crossing from $S$ to $T$:

$$\text{cap}(S, T) = \sum_{\substack{u \in S,\, v \in T \\ (u,v) \in E}} c(u, v).$$

Note carefully that only forward-crossing edges—those directed from $S$ into $T$—contribute to $\text{cap}(S, T)$. Edges directed from $T$ back into $S$ are ignored in the capacity sum, though they matter when computing the net flow across the cut.

**Worked Example.** Consider the graph with $V = \{s, a, b, t\}$ and edges $c(s,a)=3$, $c(s,b)=2$, $c(a,t)=2$, $c(b,t)=3$, $c(a,b)=1$. Take the cut $S = \{s, a\}$, $T = \{b, t\}$. The forward-crossing edges are $(s,b)$ and $(a,t)$ and $(a,b)$, giving

$$\text{cap}(S,T) = c(s,b) + c(a,t) + c(a,b) = 2 + 2 + 1 = 5.$$

The cut $S' = \{s\}$, $T' = \{a,b,t\}$ yields $\text{cap}(S',T') = c(s,a)+c(s,b) = 3+2 = 5$ as well. The minimum cut in this network has capacity $4$, achieved by $S^* = \{s,a,b\}$, $T^* = \{t\}$ with forward edges $(a,t)$ and $(b,t)$.

**Max-Flow Min-Cut Theorem (Ford–Fulkerson, 1956).** For any $s$-$t$ network, the maximum value of any feasible $s$-$t$ flow equals the minimum capacity over all $s$-$t$ cuts:

$$\max_f |f| = \min_{(S,T)} \text{cap}(S, T).$$

The proof proceeds by showing that when no augmenting path remains in the residual graph, the reachable set from $s$ in the residual graph defines a cut whose capacity exactly equals the current flow value, establishing both bounds simultaneously.

```python
import sympy as sp

S = {'s', 'a'}
```

### minimum_cut_problem (16.2s)

## Minimum Cut Problem

**Definition.** Let $G = (V, E)$ be a connected, undirected graph in which each edge $e \in E$ carries a non-negative capacity $c(e) \in \mathbb{R}_{\geq 0}$. A *cut* is a partition of $V$ into two non-empty, disjoint subsets $S$ and $T = V \setminus S$. The *capacity* of a cut $(S, T)$ is the total capacity of edges crossing from $S$ to $T$:

$$\kappa(S, T) = \sum_{\substack{u \in S,\, v \in T \\ (u,v) \in E}} c(u, v).$$

A *minimum cut* (or *min-cut*) is a cut $(S^*, T^*)$ such that $\kappa(S^*, T^*) \leq \kappa(S, T)$ for every other cut $(S, T)$. Intuitively, removing the edges of the min-cut disconnects $G$ at minimum cost.

**Worked Example.** Consider the graph with vertices $\{s, a, b, t\}$ and edges:

| Edge | Capacity |
|------|----------|
| $(s, a)$ | 3 |
| $(s, b)$ | 2 |
| $(a, b)$ | 1 |
| $(a, t)$ | 2 |
| $(b, t)$ | 3 |

Evaluate two candidate cuts. For $S = \{s\}$, $T = \{a, b, t\}$: crossing edges are $(s,a)$ and $(s,b)$, giving $\kappa = 3 + 2 = 5$. For $S = \{s, a, b\}$, $T = \{t\}$: crossing edges are $(a,t)$ and $(b,t)$, giving $\kappa = 2 + 3 = 5$. For $S = \{s, b\}$, $T = \{a, t\}$: crossing edges are $(s,a)$, $(b,a)$, and $(b,t)$, giving $\kappa = 3 + 1 + 3 = 7$. The minimum capacity found is $5$, achieved by the first two cuts.

**Max-Flow Min-Cut Theorem.** The central result connecting flow and connectivity is due to Ford and Fulkerson (1956):

> *For any flow network with source $s$ and sink $t$, the value of a maximum $s$–$t$ flow equals the capacity of a minimum $s$–$t$ cut.*

Formally, if $f^*$ denotes the maximum feasible flow value, then

$$|f^*| = \min_{(S,T):\, s \in S,\, t \in T} \kappa(S, T).$$

This theorem transforms the combinatorial cut problem into a linear program solvable in polynomial time. Algorithms such as Edmonds–Karp achieve $O(|V||E|^2)$ complexity.

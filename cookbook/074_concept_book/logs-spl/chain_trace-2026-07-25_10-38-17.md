## Normal Matrix

**Definition.** A square matrix $A \in \mathbb{C}^{n \times n}$ is called *normal* if it commutes with its conjugate transpose:

$$A^*A = AA^*,$$

where $A^* = \bar{A}^\top$ denotes the conjugate transpose. Over $\mathbb{R}$, this reduces to $A^\top A = A A^\top$. The class of normal matrices is broad: every Hermitian matrix ($A^* = A$), skew-Hermitian matrix ($A^* = -A$), and unitary matrix ($A^*A = I$) is normal.

**Worked Example.** Let

$$A = \begin{pmatrix} 2 & 1+i \\ 1-i & 3 \end{pmatrix}.$$

Compute $A^* = \begin{pmatrix} 2 & 1+i \\ 1-i & 3 \end{pmatrix}$. Since $A$ is Hermitian ($A^* = A$), it is automatically normal. Verify directly:

$$A^*A = A^2 = \begin{pmatrix} 2(2)+(1+i)(1-i) & \cdots \\ \cdots & \cdots \end{pmatrix} = AA^*. \checkmark$$

For a non-Hermitian normal example, take the rotation matrix $R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$. One verifies $R^\top R = I = RR^\top$, confirming normality.

**Key Theorem (Spectral Theorem for Normal Matrices).** *A matrix $A \in \mathbb{C}^{n \times n}$ is normal if and only if it is unitarily diagonalisable: there exists a unitary matrix $U$ (satisfying $U^*U = I$) such that*

$$A = U \Lambda U^*,$$

*where $\Lambda = \operatorname{diag}(\lambda_1, \dots, \lambda_n)$ contains the eigenvalues of $A$.*

*Proof sketch.* The forward direction follows from Schur's theorem: every matrix is unitarily triangularisable as $A = UTU^*$. If $A$ is normal, substituting into $A^*A = AA^*$ forces $T^*T = TT^*$, which for upper-triangular $T$ implies $T$ is diagonal. $\square$

This theorem is foundational because orthonormal eigenvectors form a basis, making computations—particularly least-squares problems, operator exponentials, and stability analysis—tractable.

**Lab Cell (SymPy).**

```python
from sympy import Matrix, I, eye

A = Matrix([[2, 1+I], [1-I, 3]])
Astar = A.conjugate().T

print("A*A =", Astar * A)
print("AA* =", A * Astar)
print("Normal?", Astar * A == A * Astar)

P, D = A.diagonalize()   # columns of P are eigenvectors
print("Eigenvalues:", D)
```

## Orthonormal Diagonalization

**Definition.** A real symmetric matrix $A \in \mathbb{R}^{n \times n}$ is *orthonormally diagonalizable* if there exists an orthogonal matrix $Q$ (satisfying $Q^T Q = I$) and a diagonal matrix $\Lambda = \operatorname{diag}(\lambda_1, \lambda_2, \ldots, \lambda_n)$ such that

$$A = Q \Lambda Q^T.$$

Equivalently, the columns $\mathbf{q}_1, \mathbf{q}_2, \ldots, \mathbf{q}_n$ of $Q$ form an orthonormal basis of $\mathbb{R}^n$ consisting entirely of eigenvectors of $A$, with $A\mathbf{q}_i = \lambda_i \mathbf{q}_i$. The Spectral Theorem guarantees that every real symmetric matrix admits such a decomposition.

**Worked Example.** Let

$$A = \begin{pmatrix} 3 & 1 \\ 1 & 3 \end{pmatrix}.$$

The characteristic polynomial is $\det(A - \lambda I) = (3-\lambda)^2 - 1 = 0$, giving eigenvalues $\lambda_1 = 2$ and $\lambda_2 = 4$. For $\lambda_1 = 2$, solving $(A - 2I)\mathbf{v} = \mathbf{0}$ yields the eigenvector $\mathbf{v}_1 = (1, -1)^T$; for $\lambda_2 = 4$, one obtains $\mathbf{v}_2 = (1, 1)^T$. Normalizing each vector produces

$$Q = \frac{1}{\sqrt{2}}\begin{pmatrix} 1 & 1 \\ -1 & 1 \end{pmatrix}, \qquad \Lambda = \begin{pmatrix} 2 & 0 \\ 0 & 4 \end{pmatrix}.$$

One may verify directly that $Q^T A Q = \Lambda$ and $Q Q^T = I$.

**Key Theorem (Spectral Theorem).** Every real symmetric matrix $A$ has $n$ real eigenvalues (counted with multiplicity) and eigenvectors corresponding to distinct eigenvalues are mutually orthogonal. Consequently, $A$ possesses an orthonormal eigenbasis and is orthonormally diagonalizable. The proof relies on two facts: (i) all roots of the characteristic polynomial of a real symmetric matrix are real, established via $\bar{\mathbf{v}}^T A \mathbf{v} = \bar{\mathbf{v}}^T \overline{A\mathbf{v}}$; and (ii) if $\lambda_i \neq \lambda_j$, then $(\lambda_i - \lambda_j)\langle \mathbf{q}_i, \mathbf{q}_j \rangle = 0$, forcing $\langle \mathbf{q}_i, \mathbf{q}_j \rangle = 0$.

**Lab Cell.**

```python
from sympy import Matrix, sqrt, Rational

A = Matrix([[3, 1], [1, 3]])
P, D = A.diagonalize()          # P: eigenvectors as columns
# Orthonormalize columns of P
Q = Matrix([col / sqrt((col.T * col)[0]) for col in P.columnspace()]).T
print("Q =", Q)
print("Lambda =", D)
print("Verify Q^T A Q = D:", (Q.T * A * Q).equals(D))
```

## Orthonormal Basis Normal Matrix

**Definition.** A square matrix $A \in \mathbb{C}^{n \times n}$ is called *normal* if it commutes with its conjugate transpose:
$$A A^* = A^* A,$$
where $A^* = \bar{A}^\top$. The class of normal matrices includes Hermitian matrices ($A^* = A$), skew-Hermitian matrices ($A^* = -A$), and unitary matrices ($A A^* = I$). A collection of vectors $\{v_1, v_2, \ldots, v_n\}$ in $\mathbb{C}^n$ forms an *orthonormal basis* if $\langle v_i, v_j \rangle = \delta_{ij}$ for all $i, j$, where $\delta_{ij}$ is the Kronecker delta.

**Worked Example.** Consider the real symmetric matrix
$$A = \begin{pmatrix} 3 & 1 \\ 1 & 3 \end{pmatrix}.$$
Since $A = A^\top$, it is Hermitian and hence normal. Its characteristic polynomial is $(\lambda - 3)^2 - 1 = 0$, giving eigenvalues $\lambda_1 = 2$ and $\lambda_2 = 4$. The corresponding eigenvectors are $u_1 = \tfrac{1}{\sqrt{2}}(-1, 1)^\top$ and $u_2 = \tfrac{1}{\sqrt{2}}(1, 1)^\top$. One verifies $\langle u_1, u_2 \rangle = 0$ and $\|u_i\| = 1$, so $\{u_1, u_2\}$ is an orthonormal basis of $\mathbb{R}^2$ composed entirely of eigenvectors of $A$.

**Key Theorem (Spectral Theorem for Normal Matrices).** *A matrix $A \in \mathbb{C}^{n \times n}$ is normal if and only if there exists a unitary matrix $U$ such that $A = U \Lambda U^*$, where $\Lambda = \mathrm{diag}(\lambda_1, \ldots, \lambda_n)$ contains the eigenvalues of $A$.*

*Proof sketch.* By Schur's theorem, every square matrix is unitarily triangularizable: $A = U T U^*$ for some upper triangular $T$. If $A$ is normal, then $TT^* = T^*T$. A direct computation on diagonal entries shows that $T$ must be diagonal, so $T = \Lambda$. $\square$

The columns of $U$ form an orthonormal basis of eigenvectors — the central structural fact that makes normal matrices analytically tractable.

**Lab Cell (SymPy).**
```python
from sympy import Matrix, GramSchmidt

A = Matrix([[3, 1], [1, 3]])
eigvecs = [v for _, _, vs in A.eigenvects() for v in vs]
ortho = GramSchmidt(eigvecs, orthonormal=True)
U = Matrix(ortho).T          # columns are the orthonormal eigenvectors
print("U =", U)
print("Diagonalization check:", U.T * A * U)  # should be diagonal
```

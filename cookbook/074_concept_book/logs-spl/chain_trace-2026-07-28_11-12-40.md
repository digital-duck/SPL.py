### data (18.7s)

## 数据

**定义。** 设 $\mathcal{U}$ 为某一现象的全体可观测状态构成的集合，称为**全域**（universe）。一次**观测**是从 $\mathcal{U}$ 到某测量空间 $\mathcal{X}$ 的映射 $f: \mathcal{U} \to \mathcal{X}$，其输出称为一个**数据点**（datum）。由 $n$ 次独立观测所得的有序集合

$$\mathcal{D} = \{(x_i, y_i)\}_{i=1}^{n}, \quad x_i \in \mathcal{X},\; y_i \in \mathcal{Y}$$

称为一个**数据集**（dataset），其中 $\mathcal{X}$ 为输入空间，$\mathcal{Y}$ 为输出空间或标签空间。当 $\mathcal{Y} = \emptyset$ 时，称数据为**无标签数据**；否则称为**有标签数据**。

**具体示例。** 考虑对某班级 $n = 5$ 名学生的数学成绩进行测量，得到以下数据集：

$$\mathcal{D} = \{(1, 82),\,(2, 76),\,(3, 91),\,(4, 68),\,(5, 85)\}$$

其中第一个分量为学生编号 $x_i \in \{1,2,3,4,5\}$，第二个分量为成绩 $y_i \in [0,100]$。此数据集的**样本均值**定义为

$$\bar{y} = \frac{1}{n}\sum_{i=1}^{n} y_i = \frac{82+76+91+68+85}{5} = 80.4$$

**样本方差**定义为

$$s^2 = \frac{1}{n-1}\sum_{i=1}^{n}(y_i - \bar{y})^2 \approx 72.3$$

这两个统计量分别刻画了数据的集中趋势与离散程度。

**关键定理（大数定律）。** 设 $\{X_i\}_{i=1}^{n}$ 为独立同分布的随机变量序列，期望 $\mu = \mathbb{E}[X_i]$ 存在有限。则样本均值 $\bar{X}_n = \frac{1}{n}\sum_{i=1}^{n}X_i$ 依概率收敛于 $\mu$，即对任意 $\varepsilon > 0$，

$$\lim_{n\to\infty} P\!\left(|\bar{X}_n - \mu| > \varepsilon\right) = 0.$$

此定理保证了：当观测次数足够大时，数据集所蕴含的统计规律将趋近于总体的真实分布，这是一切数据驱动方法的理论基石。

**实验单元（SymPy）。**

```python
from sympy import symbols, Rational, sqrt, simplify

y = [82, 76, 91, 68, 85]
n = len(y)
mu = Rational(sum(y), n)
var = sum((Rational(yi) - mu)**2 for yi in y) / (n - 1)
print("均值 =", mu, "  方差 =", simplify(var))
```

### frequency (18.7s)

## 频率

**定义**

设随机试验 $E$ 在相同条件下重复进行 $n$ 次，事件 $A$ 发生的次数称为**频数**，记为 $n(A)$。比值

$$
f_n(A) = \frac{n(A)}{n}$$

称为事件 $A$ 在 $n$ 次试验中的**频率**（relative frequency）。显然，$0 \le f_n(A) \le 1$，且对必然事件 $\Omega$ 有 $f_n(\Omega) = 1$，对不可能事件 $\varnothing$ 有 $f_n(\varnothing) = 0$。若事件 $A_1, A_2, \ldots, A_k$ 两两互斥，则

$$f_n\!\left(\bigcup_{i=1}^{k} A_i\right) = \sum_{i=1}^{k} f_n(A_i).$$

**例题**

掷一枚均匀硬币 $n = 1000$ 次，正面朝上共出现 $513$ 次。则事件 $A = \{\text{正面朝上}\}$ 的频率为

$$f_{1000}(A) = \frac{513}{1000} = 0.513.$$

反面朝上的事件 $\bar{A}$ 的频率为 $f_{1000}(\bar{A}) = 1 - 0.513 = 0.487$，与理论概率 $0.5$ 均接近，体现了频率的稳定性。

**频率稳定性定理（大数定律的直观形式）**

**定理**（Bernoulli 大数定律）　设事件 $A$ 在每次试验中发生的概率为 $p$，$f_n(A)$ 为 $n$ 次独立重复试验中 $A$ 的频率。则对任意 $\varepsilon > 0$，

$$\lim_{n \to \infty} P\!\left(\left|f_n(A) - p\right| \ge \varepsilon\right) = 0.$$

**证明思路**：设 $X_i$ 为第 $i$ 次试验中 $A$ 是否发生的指示变量，则 $f_n(A) = \frac{1}{n}\sum_{i=1}^n X_i$，期望为 $p$，方差为 $\frac{p(1-p)}{n}$。由 Chebyshev 不等式，

$$P\!\left(\left|f_n(A) - p\right| \ge \varepsilon\right) \le \frac{p(1-p)}{n\varepsilon^2} \xrightarrow{n\to\infty} 0.$$

这说明频率是概率的相合估计量，奠定了概率的频率解释的数学基础。

**实验单元（SymPy / Python）**

```python
import random, sympy as sp

def freq_simulation(p, n):
    count = sum(1 for _ in range(n) if random.random() < p)
    return sp.Rational(count, n)

# 投掷硬币 p=1/2，观察频率随 n 增大趋近 1/2
for n in [10, 100, 1000, 10000]:
    print(f"n={n:>6},  频率 = {float(freq_simulation(0.5, n)):.4f}")
```

运行上述代码，可直观验证：随着 $n$ 增大，频率 $f_n(A)$ 在概率 $p = 0.5$ 附近的波动逐渐缩小，从而在实验层面印证大数定律。

### relative_frequency (20.8s)

## 相对频率

**定义.** 设某随机试验在相同条件下重复进行 $n$ 次，事件 $A$ 恰好发生了 $k$ 次，则称比值

$$
f_n(A) = \frac{k}{n}
$$

为事件 $A$ 在 $n$ 次试验中的**相对频率**（relative frequency）。其中 $k$ 称为**频数**（frequency count），$n$ 称为**试验总次数**。由定义直接得到：$0 \leq f_n(A) \leq 1$，且若 $A_1, A_2, \ldots, A_m$ 两两互斥并满足 $A_1 \cup A_2 \cup \cdots \cup A_m = \Omega$，则

$$
\sum_{i=1}^{m} f_n(A_i) = 1.
$$

这表明相对频率在结构上与概率公理高度吻合，是概率论公理化的经验基础。

---

**例题.** 掷一枚均匀硬币 $n$ 次，记录正面朝上的次数 $k$。

| $n$ | $k$ | $f_n(\text{正面})$ |
|-----|-----|-------------------|
| 10  | 4   | 0.400 |
| 100 | 53  | 0.530 |
| 1000 | 498 | 0.498 |
| 10000 | 5012 | 0.5012 |

随着 $n$ 增大，$f_n(\text{正面})$ 稳定地向 $0.5$ 收敛，这正是理论概率 $P(\text{正面}) = \tfrac{1}{2}$ 的经验体现。

---

**定理（大数定律，频率表述）.** 设事件 $A$ 在每次试验中独立发生，且其概率为 $p$。则对任意 $\varepsilon > 0$，有

$$
\lim_{n \to \infty} P\!\left(\left|f_n(A) - p\right| \geq \varepsilon\right) = 0.
$$

此结论由切比雪夫不等式可得证明轮廓：令 $X_i \in \{0,1\}$ 为第 $i$ 次试验的指示随机变量，则 $f_n(A) = \tfrac{1}{n}\sum_{i=1}^n X_i$，其均值为 $p$，方差为 $\tfrac{p(1-p)}{n}$。由切比雪夫不等式，

$$
P\!\left(\left|f_n(A) - p\right| \geq \varepsilon\right) \leq \frac{p(1-p)}{n\varepsilon^2} \xrightarrow{n\to\infty} 0.
$$

---

**实验单元（SymPy / Python）.**

```python
import random
from sympy import Rational

def relative_frequency(n: int, p_true=0.5) -> float:
    outcomes = [random.random() < p_true for _ in range(n)]
    k = sum(outcomes)
    return Rational(k, n)          # 精确有理数表示

for n in [10, 100, 1000, 10_000]:
    rf = relative_frequency(n)
    print(f"n={n:>6}  f_n = {rf}  ≈ {float(rf):.4f}")
```

运行上述代码，观察 `f_n` 随 $n$ 增大趋近于 $\tfrac{1}{2}$ 的过程，从而在计算机模拟层面直观验证大数定律。

### cumulative_relative_frequency (17.4s)

## Cumulative Relative Frequency

### 定义

设有一组含 $n$ 个观测值的数据集，将其划分为 $k$ 个互不重叠的区间（组距类）。设第 $i$ 个类的频数为 $f_i$，则该类的**相对频率**定义为

$$
r_i = \frac{f_i}{n}, \quad i = 1, 2, \ldots, k.
$$

**累积相对频率**（cumulative relative frequency）是指所有不超过某一上界的类的相对频率之和。具体地，第 $j$ 类的累积相对频率为

$$
F_j = \sum_{i=1}^{j} r_i = \frac{1}{n}\sum_{i=1}^{j} f_i, \quad j = 1, 2, \ldots, k.
$$

直观上，$F_j$ 给出了观测值落在第 $j$ 类及其之前所有类中的比例。注意 $F_k = 1$，因为所有观测值必然落在某一类中。

### 例题

某班 20 名学生的数学考试成绩（满分 100 分）如下：

| 分数区间 | 频数 $f_i$ | 相对频率 $r_i$ | 累积相对频率 $F_j$ |
|----------|-----------|--------------|-----------------|
| $[60, 70)$ | 4 | $0.20$ | $0.20$ |
| $[70, 80)$ | 8 | $0.40$ | $0.60$ |
| $[80, 90)$ | 6 | $0.30$ | $0.90$ |
| $[90, 100]$ | 2 | $0.10$ | $1.00$ |

由此可读出：成绩低于 80 分的学生占总人数的 $F_2 = 0.60$，即 60%。

### 关键定理

**命题**：当样本量 $n \to \infty$ 时，经验累积相对频率函数逐点收敛于总体的累积分布函数（CDF）$F(x)$。更精确的表述由 Glivenko–Cantelli 定理给出：

$$
\sup_{x \in \mathbb{R}} \left| F_n(x) - F(x) \right| \xrightarrow{\text{a.s.}} 0,
$$

其中 $F_n(x)$ 为经验分布函数。这一结果保证了以样本频率估计总体概率的合理性。

### 实验单元（SymPy）

```python
import sympy as sp
from sympy.stats import Normal, cdf

scores = [4, 8, 6, 2]          # 各组频数
n = sum(scores)
rel_freq = [f / n for f in scores]

cum_rel = []
running = 0
for r in rel_freq:
    running += r
    cum_rel.append(running)

print("累积相对频率：", cum_rel)
# 输出: [0.2, 0.6, 0.9, 1.0]
```

### frequency_table (18.6s)

## 频率分布表

**定义。** 设 $X$ 为一个离散随机变量，其样本空间为 $\Omega = \{x_1, x_2, \ldots, x_k\}$。给定容量为 $n$ 的观测样本 $\{x^{(1)}, x^{(2)}, \ldots, x^{(n)}\}$，定义第 $i$ 个取值的**绝对频数**为

$$
f_i = \#\{j : x^{(j)} = x_i\}, \quad i = 1, 2, \ldots, k,
$$

相应的**相对频率**（归一化频率）为

$$
\hat{p}_i = \frac{f_i}{n}.
$$

**频率分布表**是将所有取值 $x_i$、对应绝对频数 $f_i$ 及相对频率 $\hat{p}_i$ 排列成表格的统计工具，满足约束条件 $\sum_{i=1}^{k} f_i = n$ 以及 $\sum_{i=1}^{k} \hat{p}_i = 1$。

---

**例题。** 某班 $20$ 名学生期末成绩等级如下：

$$
\text{A, B, B, C, A, B, C, A, D, B, C, B, A, C, B, A, B, C, D, B}
$$

逐一统计各等级出现次数，得到下表：

| 等级 $x_i$ | 频数 $f_i$ | 相对频率 $\hat{p}_i$ |
|:-----------:|:----------:|:--------------------:|
| A           | 5          | $0.25$              |
| B           | 8          | $0.40$              |
| C           | 5          | $0.25$              |
| D           | 2          | $0.10$              |
| **合计**    | **20**     | **1.00**            |

由表可见，等级 B 的相对频率最高，为 $0.40$，因此 B 为该样本的**众数**（mode）。

---

**基本定理（大数定律的频率解释）。** 设 $X$ 服从分布律 $P(X = x_i) = p_i$。当样本容量 $n \to \infty$ 时，相对频率依概率收敛于真实概率：

$$
\hat{p}_i \xrightarrow{\,P\,} p_i, \quad \forall\, i.
$$

此定理保证了以频率分布表估计总体概率分布的合理性——样本量越大，估计越精确。

---

**实验单元（SymPy）。**

```python
from sympy import *
from collections import Counter

grades = ['A','B','B','C','A','B','C','A','D','B',
          'C','B','A','C','B','A','B','C','D','B']

n = len(grades)
counts = Counter(grades)

print(f"{'等级':^6} {'频数':^6} {'相对频率':^10}")
for g in sorted(counts):
    fi = counts[g]
    pi = Rational(fi, n)          # 精确有理数
    print(f"{g:^6} {fi:^6} {pi!s:^10}")
```

运行输出将以精确有理数（如 $\tfrac{2}{5}$）呈现相对频率，避免浮点舍入误差，体现符号计算的优势。

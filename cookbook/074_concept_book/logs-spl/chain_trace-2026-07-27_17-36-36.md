### graph (0.0s)

## Graph

**Definition.** A *graph* $G$ is an ordered pair $G = (V, E)$, where $V$ is a finite nonempty set whose elements are called *vertices* (or *nodes*), and $E \subseteq \{\{u, v\} : u, v \in V,\, u \neq v\}$ is a set of two-element subsets of $V$ called *edges*. The *order* of $G$ is $|V|$ and the *size* is $|E|$. When an edge $\{u, v\} \in E$ exists, the vertices $u$ and $v$ are said to be *adjacent*, and each is a *neighbor* of the other. The *degree* of a vertex $v$, written $\deg(v)$, counts the number of edges incident to $v$.

**Worked Example.** Let $V = \{1, 2, 3, 4\}$ and $E = \{\{1,2\},\{1,3\},\{2,4\},\{3,4\}\}$. This graph has order 4 and size 4. Computing degrees: $\deg(1) = 2$ (adjacent to 2 and 3), $\deg(2) = 2$, $\deg(3) = 2$, $\deg(4) = 2$. The sum of all degrees equals $2 + 2 + 2 + 2 = 8 = 2|E|$, which illustrates the handshaking identity below.

**Key Theorem (Handshaking Lemma).** For any graph $G = (V, E)$,
$$\sum_{v \in V} \deg(v) = 2|E|.$$
*Proof sketch.* Each edge $\{u,v\}$ contributes exactly 1 to $\deg(u)$ and exactly 1 to $\deg(v)$, so it is counted exactly twice in the sum over all vertices. Summing over all $|E|$ edges gives $2|E|$. $\square$

An immediate corollary is that the number of vertices of odd degree is always even, a fact with far-reaching consequences in the theory of Eulerian paths.

### walk_path (0.0s)

## Walk Path

**Definition.** Let $G = (V, E)$ be a graph with vertex set $V$ and edge set $E$. A *walk* of length $k$ in $G$ is a finite sequence

$$W = (v_0, e_1, v_1, e_2, v_2, \ldots, e_k, v_k)$$

where each $e_i = \{v_{i-1}, v_i\} \in E$. A *walk path* (or simply a *path*) is a walk in which all vertices $v_0, v_1, \ldots, v_k$ are distinct; equivalently, no vertex is revisited. The vertex $v_0$ is called the *origin* and $v_k$ the *terminus*. When $v_0 = v_k$ and all intermediate vertices are distinct, the sequence is instead called a *cycle*.

The distinction between a walk and a walk path matters for counting and complexity: walks permit repetition, while paths impose a global distinctness constraint that makes enumeration NP-hard in general.

**Worked Example.** Consider the graph $G$ with vertices $V = \{A, B, C, D\}$ and edges $E = \{\{A,B\}, \{B,C\}, \{C,D\}, \{A,C\}\}$.

The sequence $(A, B, C, A, C, D)$ is a *walk* from $A$ to $D$ of length 5, but it is **not** a path because vertex $C$ appears twice (at positions 2 and 4).

The sequence $(A, B, C, D)$ is a walk path of length 3: all four vertices are distinct. Similarly, $(A, C, D)$ is a walk path of length 2. Both are valid $A$-$D$ paths; shortest path algorithms select among such alternatives by some cost criterion.

**Theorem (Existence of a Path from a Walk).** *If a walk from $u$ to $v$ exists in $G$, then a walk path from $u$ to $v$ also exists.*

*Proof sketch.* Let $W$ be a walk of minimum length from $u$ to $v$. If $W$ repeated some vertex $w$, say at positions $i < j$, then the sub-sequence obtained by deleting $(v_i, \ldots, v_{j-1})$ yields a shorter walk from $u$ to $v$, contradicting minimality. Hence the minimum-length walk is already a path. $\blacksquare$

This theorem guarantees that connectivity via a walk is equivalent to connectivity via a path—a foundational fact underlying shortest-path algorithms such as BFS and Dijkstra's.

### reachability (0.0s)

## Reachability

**Definition.** Let $G = (V, E)$ be a directed graph with vertex set $V$ and edge set $E \subseteq V \times V$. A vertex $v \in V$ is said to be *reachable* from a vertex $u \in V$ if there exists a finite directed path $u = v_0, v_1, \ldots, v_k = v$ such that $(v_i, v_{i+1}) \in E$ for all $0 \le i < k$. The *reachability relation* $\mathcal{R} \subseteq V \times V$ is the set of all pairs $(u, v)$ for which $v$ is reachable from $u$. By convention, every vertex is reachable from itself (via the empty path, $k = 0$), so $\mathcal{R}$ is reflexive. The *reachability set* of $u$, written $R(u)$, is $\{v \in V : (u, v) \in \mathcal{R}\}$.

**Worked Example.** Consider the directed graph $G$ with $V = \{1, 2, 3, 4\}$ and $E = \{(1,2),(2,3),(3,1),(2,4)\}$. Starting from vertex $1$: following $(1,2)$ reaches $2$; then $(2,3)$ reaches $3$; then $(3,1)$ loops back to $1$; and $(2,4)$ reaches $4$. Hence $R(1) = \{1, 2, 3, 4\}$. Starting from vertex $4$: no edge leaves $4$, so $R(4) = \{4\}$. Observe that $1$ is reachable from $2$ but $4$ is not reachable from $1$ via $4$—reachability is in general not symmetric.

**Key Theorem (Transitive Closure).** The reachability relation $\mathcal{R}$ equals the *transitive closure* of $E$, denoted $E^+$, together with the diagonal $\Delta = \{(v,v) : v \in V\}$. Equivalently, defining the adjacency matrix $A \in \{0,1\}^{|V| \times |V|}$ by $A_{ij} = 1$ iff $(i,j) \in E$, the Boolean reachability matrix $\mathbf{R}$ satisfies

$$\mathbf{R} = \bigvee_{k=0}^{|V|-1} A^k,$$

where matrix powers and the join $\bigvee$ are computed under Boolean arithmetic ($1 + 1 = 1$). This follows from the fact that any simple path in $G$ visits at most $|V|$ vertices, so paths of length $\ge |V|$ cannot introduce new reachable pairs. The Floyd–Warshall algorithm computes $\mathbf{R}$ in $O(|V|^3)$ time.


### directed_edge (0.0s)

## Directed Edge

**Definition.** Let $G = (V, E)$ be a directed graph (digraph), where $V$ is a finite set of *vertices* and $E$ is a set of ordered pairs of distinct vertices. A **directed edge** (also called an *arc*) is an element $e = (u, v) \in E$, where $u, v \in V$ and $u \neq v$. The vertex $u$ is the **tail** (or *source*) of $e$, and $v$ is the **head** (or *target*). The direction is essential: $(u, v)$ and $(v, u)$ are distinct edges and need not both belong to $E$.

The **out-degree** of a vertex $u$, written $\deg^+(u)$, counts the number of directed edges with tail at $u$; the **in-degree** $\deg^-(u)$ counts those with head at $u$. For a digraph on $n$ vertices and $m$ edges, the handshaking identity generalises to

$$\sum_{u \in V} \deg^+(u) \;=\; \sum_{u \in V} \deg^-(u) \;=\; m.$$

**Worked example.** Consider the digraph $G = (V, E)$ with $V = \{1, 2, 3\}$ and $E = \{(1,2),\,(1,3),\,(2,3)\}$. The directed edge $(1, 2)$ runs from vertex $1$ to vertex $2$, but $(2, 1) \notin E$, so information (or flow) travels one way only. Computing degrees: $\deg^+(1) = 2$, $\deg^+(2) = 1$, $\deg^+(3) = 0$; $\deg^-(1) = 0$, $\deg^-(2) = 1$, $\deg^-(3) = 2$. Both sums equal $m = 3$, confirming the identity.

**Theorem (Degree-Sum for Digraphs).** For any digraph $G = (V, E)$ with $|E| = m$,
$$\sum_{v \in V} \deg^+(v) = \sum_{v \in V} \deg^-(v) = m.$$

*Proof sketch.* Each directed edge $(u, v)$ contributes exactly $1$ to $\deg^+(u)$ and exactly $1$ to $\deg^-(v)$, so every edge is counted once in each sum.

### connectivity (0.0s)

## Connectivity

**Definition.** Let $G = (V, E)$ be an undirected graph. A *path* from vertex $u$ to vertex $v$ is a sequence of distinct vertices $u = v_0, v_1, \ldots, v_k = v$ such that $\{v_{i-1}, v_i\} \in E$ for each $i \in \{1, \ldots, k\}$. The graph $G$ is called *connected* if for every pair of vertices $u, v \in V$ there exists at least one path between them. If no such path exists for some pair, $G$ is *disconnected*. A maximal connected subgraph of $G$ is called a *connected component*. The number of connected components of $G$ is denoted $\kappa(G)$; a connected graph satisfies $\kappa(G) = 1$.

**Worked Example.** Consider the graph $G$ with vertex set $V = \{1, 2, 3, 4, 5\}$ and edge set $E = \{\{1,2\}, \{2,3\}, \{4,5\}\}$. Vertices $1, 2, 3$ are mutually reachable: the path $1 \to 2 \to 3$ exists, as do its subpaths. Vertices $4$ and $5$ are connected to each other but not to $\{1,2,3\}$: no edge crosses between the two groups. Therefore $G$ has two connected components, $\{1,2,3\}$ and $\{4,5\}$, so $\kappa(G) = 2$ and $G$ is disconnected.

**Key Theorem (Component Counting via Depth-First Search).** For a graph $G = (V, E)$ with $|V| = n$ and $|E| = m$, a depth-first search traversal identifies all connected components in time $O(n + m)$. Each tree in the resulting DFS forest corresponds to exactly one connected component. As a corollary, $G$ is connected if and only if the DFS forest consists of a single spanning tree rooted at any chosen vertex.

*Proof sketch.* DFS maintains a set of visited vertices. Starting from an arbitrary root, it exhausts all reachable vertices before returning. Any vertex left unvisited after one DFS call belongs to a different component; restarting from an unvisited vertex begins the next tree. Since each vertex and each edge is processed at most once, the $O(n + m)$ bound follows. $\square$

**Lab Cell.**

```python
import sympy.combinatorics as sc
from sympy.combinatorics.prufer import Prufer

# Represent the example graph as an adjacency dictionary
from collections import defaultdict, deque

def components(adj, n):
    visited = [False] * (n + 1)
    count = 0
    for start in range(1, n + 1):
        if not visited[start]:
            count += 1
            queue = deque([start])
            while queue:
                v = queue.popleft()
                if visited[v]:
                    continue
                visited[v] = True
                queue.extend(adj[v])
    return count

adj = defaultdict(list)
for u, v in [(1,2),(2,3),(4,5)]:
    adj[u].append(v); adj[v].append(u)

print("Number of components:", components(adj, 5))  # Expected: 2
```

### cycle_acyclic (0.0s)

## Cycle Acyclic

**Definition.** Let $G = (V, E)$ be an undirected graph. A *walk* in $G$ is a sequence of vertices $v_0, v_1, \ldots, v_k$ such that $\{v_i, v_{i+1}\} \in E$ for each $0 \le i < k$. A walk is a *path* if all vertices are distinct. A *cycle* is a closed walk $v_0, v_1, \ldots, v_k = v_0$ of length $k \ge 3$ in which $v_0, v_1, \ldots, v_{k-1}$ are pairwise distinct. A graph is called *acyclic* if it contains no cycle; an undirected acyclic graph is also called a *forest*. A connected forest is a *tree*.

**Worked Example.** Consider the graph $G$ with vertex set $V = \{1, 2, 3, 4\}$ and edge set $E = \{\{1,2\},\{2,3\},\{3,4\},\{4,2\}\}$. The walk $2 \to 3 \to 4 \to 2$ has length 3, returns to its starting vertex, and visits $2, 3, 4$ without repetition, so it is a cycle. Adding the edge $\{1,2\}$ does not create a new cycle because vertex $1$ is a leaf. Removing any one of $\{2,3\}$, $\{3,4\}$, or $\{4,2\}$ destroys the cycle and renders the graph acyclic; what remains is a tree on four vertices with exactly three edges, illustrating the identity $|E| = |V| - 1$ for trees.

**Key Theorem (Cycle Characterisation of Trees).** A connected graph $G = (V, E)$ is a tree if and only if it is acyclic and $|E| = |V| - 1$.

*Proof sketch.* ($\Rightarrow$) By induction on $|V|$: a single vertex satisfies both conditions. For $|V| > 1$, every tree has a leaf $\ell$; removing $\ell$ gives a tree on $|V|-1$ vertices with $|V|-2$ edges by hypothesis, so restoring $\ell$ adds one vertex and one edge, preserving $|E| = |V| - 1$ and acyclicity (a leaf cannot close a cycle). ($\Leftarrow$) If $|E| = |V| - 1$ and $G$ is connected and acyclic, any edge removal disconnects $G$, which is the defining property of a tree. $\square$

### directed_graph_concepts (0.0s)

## Directed Graph Concepts

**Definition.** A *directed graph* (or *digraph*) is an ordered pair $G = (V, E)$ where $V$ is a finite set of *vertices* and $E \subseteq V \times V$ is a set of ordered pairs called *directed edges* (or *arcs*). An arc $(u, v) \in E$ is said to *leave* vertex $u$ and *enter* vertex $v$; we write $u \to v$. The *out-degree* of a vertex $v$, denoted $\deg^+(v)$, counts arcs leaving $v$; the *in-degree* $\deg^-(v)$ counts arcs entering $v$. A *directed path* from $s$ to $t$ is a sequence $v_0, v_1, \ldots, v_k$ with $v_0 = s$, $v_k = t$, and $(v_{i-1}, v_i) \in E$ for all $1 \le i \le k$. If such a path exists, $t$ is said to be *reachable* from $s$.

**Worked Example.** Consider the digraph with vertex set $V = \{1, 2, 3, 4\}$ and arc set

$$E = \{(1,2),\,(1,3),\,(2,4),\,(3,4)\}.$$

Here $\deg^+(1) = 2$, $\deg^-(4) = 2$, and $\deg^-(1) = \deg^+(4) = 0$. Vertex $4$ is reachable from $1$ via the path $1 \to 2 \to 4$ (length $2$) and also via $1 \to 3 \to 4$. The *adjacency matrix* $A \in \{0,1\}^{4\times 4}$ has $A_{ij} = 1$ iff $(i,j) \in E$; a non-zero entry in $A^k$ at position $(i,j)$ certifies the existence of a directed walk of length exactly $k$ from $i$ to $j$.

**Theorem (Handshaking for Digraphs).** For any digraph $G = (V, E)$,

$$\sum_{v \in V} \deg^+(v) = \sum_{v \in V} \deg^-(v) = |E|.$$

*Proof sketch.* Each arc $(u,v)$ contributes exactly $1$ to $\deg^+(u)$ and exactly $1$ to $\deg^-(v)$, so both sums count $|E|$ once over all arcs. $\square$

### finite_state_automaton_graph (0.0s)

## Finite State Automaton Graph

**Definition.** A *finite state automaton* (FSA) is a tuple $M = (Q, \Sigma, \delta, q_0, F)$, where $Q$ is a finite nonempty set of *states*, $\Sigma$ is a finite *input alphabet*, $\delta : Q \times \Sigma \to Q$ is the *transition function*, $q_0 \in Q$ is the *initial state*, and $F \subseteq Q$ is the set of *accepting states*. The *automaton graph* of $M$ is the directed graph $G_M = (Q, E)$ with edge set

$$E = \bigl\{\,(q,\, \delta(q,a)) \mid q \in Q,\; a \in \Sigma\bigr\},$$

where each edge is labelled by the symbol $a$ that triggers the transition. Recognising a string $w = a_1 a_2 \cdots a_n \in \Sigma^*$ amounts to following the unique walk $q_0, q_1, \ldots, q_n$ in $G_M$ defined by $q_i = \delta(q_{i-1}, a_i)$; the string is *accepted* if and only if $q_n \in F$.

**Worked Example.** Let $Q = \{q_0, q_1, q_2\}$, $\Sigma = \{0, 1\}$, $F = \{q_0\}$, and define $\delta$ by the table

| | $0$ | $1$ |
|---|---|---|
| $q_0$ | $q_0$ | $q_1$ |
| $q_1$ | $q_2$ | $q_0$ |
| $q_2$ | $q_1$ | $q_2$ |

This FSA accepts all binary strings whose number of $1$s is divisible by $2$. Tracing $w = 110$: the walk is $q_0 \xrightarrow{1} q_1 \xrightarrow{1} q_0 \xrightarrow{0} q_0$, ending in $q_0 \in F$, so $w$ is accepted. Tracing $w = 10$: the walk $q_0 \xrightarrow{1} q_1 \xrightarrow{0} q_2$ ends outside $F$, so $w$ is rejected.

**Key Theorem** *(Kleene, 1956).* A language $L \subseteq \Sigma^*$ is accepted by some FSA if and only if $L$ is *regular*, i.e., describable by a regular expression. The proof uses the automaton graph directly: the set of strings labelling walks from $q_0$ to any $q \in F$ is shown to satisfy the algebraic closure properties (union, concatenation, Kleene star) that characterise regular languages.

## Subset Construction

**Definition.** Let $N = (Q, \Sigma, \delta, q_0, F)$ be a nondeterministic finite automaton (NFA), where $Q$ is a finite set of states, $\Sigma$ an input alphabet, $\delta : Q \times \Sigma \to \mathcal{P}(Q)$ the nondeterministic transition function, $q_0 \in Q$ the start state, and $F \subseteq Q$ the set of accepting states. The *subset construction* (also called the *powerset construction*) produces a deterministic finite automaton (DFA) $D = (Q', \Sigma, \delta', q_0', F')$ that accepts exactly the same language as $N$. The states of $D$ are elements of the powerset $\mathcal{P}(Q)$: each DFA state represents the *set* of NFA states reachable under a given input history. Formally,

$$Q' \subseteq \mathcal{P}(Q), \quad q_0' = \varepsilon\text{-closure}(\{q_0\}), \quad \delta'(S, a) = \varepsilon\text{-closure}\!\Bigl(\bigcup_{q \in S} \delta(q, a)\Bigr),$$

$$F' = \{ S \in Q' \mid S \cap F \neq \emptyset \}.$$

The $\varepsilon$-closure of a set $S$ is the set of all NFA states reachable from any state in $S$ by zero or more $\varepsilon$-transitions.

**Worked Example.** Consider an NFA over $\Sigma = \{0, 1\}$ with states $\{A, B, C\}$, start state $A$, accepting state $C$, and transitions $\delta(A, 0) = \{A, B\}$, $\delta(A, 1) = \{A\}$, $\delta(B, 1) = \{C\}$, all others empty (no $\varepsilon$-transitions). The subset construction begins with $q_0' = \{A\}$. Reading $0$ from $\{A\}$ gives $\{A, B\}$; reading $1$ from $\{A\}$ gives $\{A\}$. From $\{A, B\}$, reading $0$ gives $\{A, B\}$ and reading $1$ gives $\{A, C\}$. Since $C \in F$, the DFA state $\{A, C\}$ is accepting. Continuing until no new subsets appear yields a DFA that recognizes strings over $\{0,1\}$ containing the substring $01$.

**Key Theorem (Rabin–Scott, 1959).** For every NFA $N$, the subset construction produces a DFA $D$ such that $\mathcal{L}(D) = \mathcal{L}(N)$. If $|Q| = n$, then $|Q'| \leq 2^n$, and this bound is tight in the worst case.

*Proof sketch.* By induction on input length, one verifies that the DFA state reached after reading $w$ is precisely the set of NFA states reachable from $q_0$ via $w$. Acceptance conditions then coincide by definition of $F'$. $\square$

**Lab Cell (SymPy / Python).**

```python
from itertools import chain

def epsilon_closure(states, eps_map):
    closure = set(states)
    stack = list(states)
    while stack:
        s = stack.pop()
        for t in eps_map.get(s, []):
            if t not in closure:
                closure.add(t); stack.append(t)
    return frozenset(closure)

def subset_construction(Q, Sigma, delta, q0, F, eps_map=None):
    eps_map = eps_map or {}
    start = epsilon_closure({q0}, eps_map)
    dfa, worklist = {}, [start]
    while worklist:
        S = worklist.pop()
        dfa[S] = {}
        for a in Sigma:
            nxt = epsilon_closure(chain.from_iterable(delta.get((q, a), []) for q in S), eps_map)
            dfa[S][a] = nxt
            if nxt not in dfa:
                worklist.append(nxt)
    accepting = {S for S in dfa if S & set(F)}
    return dfa, start, accepting
```

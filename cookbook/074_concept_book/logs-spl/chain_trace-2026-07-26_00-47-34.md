### natural_logarithm_integral_def (20.2s)

## Natural Logarithm Integral Definition

**Definition.** For any real number $x > 0$, the *natural logarithm* is defined by the definite integral

$$\ln x = \int_1^x \frac{1}{t}\,dt.$$

This definition is logically prior to the exponential function: rather than treating $\ln$ as the inverse of $e^x$, we construct it directly from the area under the hyperbola $y = 1/t$. When $x > 1$ the integral accumulates positive area; when $0 < x < 1$ the limits are reversed and the value is negative; at $x = 1$ the integral is zero, so $\ln 1 = 0$ follows immediately.

**Worked Example.** Estimate $\ln 2$ using a left-endpoint Riemann sum with $n = 4$ subintervals on $[1, 2]$.

Each subinterval has width $\Delta t = \tfrac{1}{4}$. The left endpoints are $t_0 = 1,\, t_1 = 1.25,\, t_2 = 1.5,\, t_3 = 1.75$. Thus

$$\ln 2 \approx \frac{1}{4}\left(\frac{1}{1} + \frac{1}{1.25} + \frac{1}{1.5} + \frac{1}{1.75}\right) = \frac{1}{4}(1 + 0.8 + 0.\overline{6} + 0.571\ldots) \approx 0.760.$$

The exact value is $\ln 2 \approx 0.6931$; the left-endpoint sum overshoots because $1/t$ is decreasing.

**Key Theorem (Properties from the Definition).** Let $a, b > 0$ and $r \in \mathbb{Q}$. Then:

1. $\ln(ab) = \ln a + \ln b$,
2. $\ln(a/b) = \ln a - \ln b$,
3. $\ln(a^r) = r\ln a$,
4. $\dfrac{d}{dx}\ln x = \dfrac{1}{x}$ for all $x > 0$.

*Proof sketch of (1).* Fix $a$ and define $f(x) = \ln(ax)$. By the chain rule, $f'(x) = 1/x = (\ln x)'$, so $f(x) - \ln x$ is constant. Evaluating at $x = 1$ gives the constant as $\ln a$, hence $\ln(ax) = \ln a + \ln x$. $\square$

**Lab Cell (SymPy).**

```python
from sympy import symbols, integrate, ln, N

# Verify the definition agrees with sympy's ln

print(N(integral_def.subs(x, 2), 10))  # 0.6931471806
```

Running this cell confirms that SymPy evaluates $\int_1^2 t^{-1}\,dt$ to the familiar constant $\ln 2 \approx 0.6931$, validating the integral definition numerically.

### exponential_function_def (13.9s)

## Exponential Function Def

**Definition.** Let $b > 0$ with $b \neq 1$. The *exponential function with base $b$* is the function $f : \mathbb{R} \to (0, \infty)$ defined by

$$f(x) = b^x.$$

More precisely, for rational $x = p/q$ we set $b^x = \sqrt[q]{b^p}$, and we extend to all real $x$ by continuity: $b^x = \lim_{r \to x} b^r$ where the limit is taken over rationals $r$. The *natural exponential function* corresponds to the base $b = e \approx 2.71828$, where $e$ is Euler's number, and is written $\exp(x) = e^x$.

**Worked Example.** Evaluate and compare $2^{3/2}$ and $e^1$.

For $2^{3/2}$, write $2^{3/2} = (2^3)^{1/2} = 8^{1/2} = 2\sqrt{2} \approx 2.828$. For $e^1 = e \approx 2.718$. Thus $e^1 < 2^{3/2}$, illustrating that the ordering of exponential values depends on both the base and the exponent.

**Key Theorem** *(Fundamental Properties of Exponentials).* Let $b > 0$, $b \neq 1$, and let $x, y \in \mathbb{R}$. Then:

1. $b^{x+y} = b^x \cdot b^y$
2. $b^{x-y} = b^x / b^y$
3. $(b^x)^y = b^{xy}$
4. $\dfrac{d}{dx} e^x = e^x$

*Proof sketch of (4).* Using the limit definition of the derivative,

$$\frac{d}{dx} e^x = \lim_{h \to 0} \frac{e^{x+h} - e^x}{h} = e^x \lim_{h \to 0} \frac{e^h - 1}{h}.$$

One shows via the Taylor series $e^h = 1 + h + h^2/2! + \cdots$ that the remaining limit equals $1$, giving $\tfrac{d}{dx} e^x = e^x$. This self-replicating derivative is the defining characteristic of the natural exponential. $\square$

**Lab Cell.**

```python
from sympy import symbols, exp, E, sqrt, simplify, diff

x = symbols('x')

# Verify 2^(3/2) and e^1

```

### exponential_growth_model (16.1s)

## Exponential Growth Model

**Definition.** A quantity $N(t)$ exhibits *exponential growth* when its rate of change is proportional to its current value. Formally, $N$ satisfies the ordinary differential equation

$$\frac{dN}{dt} = r\,N(t), \qquad N(0) = N_0,$$

where $r > 0$ is the *growth rate* (units: time$^{-1}$) and $N_0 > 0$ is the initial value. Separating variables and integrating both sides yields the closed-form solution

$$N(t) = N_0\,e^{rt}.$$

The quantity $T_{2} = \ln 2 / r$ is called the *doubling time*: the elapsed time required for $N$ to double from any starting value.

---

**Worked Example.** A bacterial colony begins with $N_0 = 500$ cells and doubles every $3$ hours. Determine $r$ and predict the population after $12$ hours.

*Step 1 — find $r$.* The doubling time is $T_2 = 3$ h, so

$$r = \frac{\ln 2}{T_2} = \frac{\ln 2}{3} \approx 0.2310 \text{ h}^{-1}.$$

*Step 2 — evaluate $N(12)$.*

$$N(12) = 500\,e^{0.2310 \times 12} = 500\,e^{2.773} \approx 500 \times 16 = 8000 \text{ cells}.$$

This result is exact in integer arithmetic because $12/3 = 4$ doublings give $N_0 \cdot 2^4 = 8000$.

---

**Key Theorem (Uniqueness of Exponential Growth).** *Let $N : [0,\infty) \to \mathbb{R}$ be differentiable and satisfy $dN/dt = rN$ with $N(0) = N_0 > 0$. Then $N(t) = N_0 e^{rt}$ is the unique solution.*

*Proof sketch.* Define $f(t) = N(t)e^{-rt}$. Differentiating gives $f'(t) = N'(t)e^{-rt} - rN(t)e^{-rt} = (N' - rN)e^{-rt} = 0$. Hence $f$ is constant, and evaluating at $t = 0$ yields $f(t) = N_0$ for all $t \geq 0$. $\blacksquare$

---

**Lab Cell.**

```python
import sympy as sp

t, r, N0 = sp.symbols('t r N_0', positive=True)
N = N0 * sp.exp(r * t)

# Verify the ODE
ode_check = sp.simplify(sp.diff(N, t) - r * N)
print("ODE residual:", ode_check)          # 0

# Doubling time
T2 = sp.solve(sp.Eq(N, 2 * N0), t)[0]
print("Doubling time:", T2)                # log(2)/r

# Numeric example
N_numeric = N.subs([(N0, 500), (r, sp.ln(2)/3)])
print("N(12) =", N_numeric.subs(t, 12))   # 8000
```

## Bayes Theorem

**Definition.** Let $A$ and $B$ be events in a sample space $\Omega$ with $P(B) > 0$. The *conditional probability* of $A$ given $B$ is

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}.$$

Bayes' Theorem inverts this conditioning. If $\{A_1, A_2, \ldots, A_n\}$ is a partition of $\Omega$ (mutually exclusive, collectively exhaustive events) and $P(A_i) > 0$ for all $i$, then for any event $B$ with $P(B) > 0$:

$$P(A_k \mid B) = \frac{P(B \mid A_k)\, P(A_k)}{\displaystyle\sum_{i=1}^{n} P(B \mid A_i)\, P(A_i)}.$$

The term $P(A_k)$ is called the **prior** (belief before observing $B$), $P(B \mid A_k)$ is the **likelihood** (how probable the evidence is under hypothesis $A_k$), and $P(A_k \mid B)$ is the **posterior** (updated belief after observing $B$). The denominator is $P(B)$ expanded via the Law of Total Probability.

**Worked Example.** A diagnostic test for a rare disease has sensitivity $P(\text{pos} \mid \text{disease}) = 0.99$ and specificity $P(\text{neg} \mid \text{no disease}) = 0.95$. The disease prevalence is $P(\text{disease}) = 0.001$. What is the probability that a patient who tests positive actually has the disease?

Applying Bayes' Theorem:

$$P(\text{disease} \mid \text{pos}) = \frac{0.99 \times 0.001}{0.99 \times 0.001 + 0.05 \times 0.999} \approx \frac{0.00099}{0.05094} \approx 0.019.$$

Despite the high sensitivity, only about $1.9\%$ of positive tests indicate true disease — a counterintuitive result driven by the very low prior $P(\text{disease})$.

**Key Theorem (Posterior Convergence).** As independent observations $B_1, B_2, \ldots$ accumulate, repeated application of Bayes' Theorem causes the posterior to concentrate around the true parameter value under mild regularity conditions, regardless of the prior. This provides a formal foundation for learning from data.

**Lab Cell.**

```python
from sympy import Rational, simplify

p_disease   = Rational(1, 1000)
sensitivity = Rational(99, 100)
fpr         = Rational(5, 100)          # 1 - specificity

p_pos = sensitivity * p_disease + fpr * (1 - p_disease)
posterior = simplify(sensitivity * p_disease / p_pos)
print(f"P(disease | positive) = {posterior} ≈ {float(posterior):.4f}")
```

## Binary Multiclass Classification

**Definition.** A *classification* problem assigns each input $\mathbf{x} \in \mathbb{R}^d$ to one of $K$ discrete classes $\mathcal{Y} = \{1, 2, \ldots, K\}$. When $K = 2$ the problem is called *binary*; when $K > 2$ it is called *multiclass*. Formally, we seek a hypothesis $h : \mathbb{R}^d \to \mathcal{Y}$ that minimises the expected 0–1 loss

$$
\mathcal{L}(h) = \mathbb{E}_{(\mathbf{x},y)}\bigl[\mathbf{1}[h(\mathbf{x}) \neq y]\bigr].
$$

In the binary case ($K = 2$) it is conventional to encode labels as $y \in \{-1, +1\}$ and learn a real-valued *score function* $f(\mathbf{x})$, setting $h(\mathbf{x}) = \operatorname{sgn}(f(\mathbf{x}))$. For multiclass problems the score generalises to a vector $\mathbf{f}(\mathbf{x}) = (f_1(\mathbf{x}), \ldots, f_K(\mathbf{x}))$, and the predicted class is

$$
h(\mathbf{x}) = \arg\max_{k \in \mathcal{Y}}\, f_k(\mathbf{x}).
$$

**Worked Example.** Suppose $K = 3$ (species identification: setosa, versicolor, virginica) and a linear model produces scores $\mathbf{f}(\mathbf{x}) = (1.2,\; 3.7,\; 2.1)$. Then $h(\mathbf{x}) = \arg\max = 2$ (versicolor). To obtain calibrated probabilities, the *softmax* transform is applied:

$$
p_k = \frac{e^{f_k}}{\sum_{j=1}^{K} e^{f_j}}, \qquad k = 1, \ldots, K.
$$

With the scores above, $\sum_j e^{f_j} = e^{1.2} + e^{3.7} + e^{2.1} \approx 3.32 + 40.45 + 8.17 = 51.94$, giving $p_2 \approx 0.779$—a strong prediction toward versicolor.

**Key Theorem (Reduction to Binary).** Any $K$-class problem can be solved by training $\binom{K}{2}$ binary classifiers, one for each pair of classes (*one-vs-one*), and predicting by majority vote. Alternatively, $K$ binary classifiers of the form "class $k$ vs. all others" (*one-vs-rest*) suffice, with prediction via $\arg\max_k f_k(\mathbf{x})$. Both reductions preserve PAC-learnability: if each binary learner has sample complexity $m_0(\epsilon, \delta)$, the multiclass error is bounded by $\epsilon$ with probability $1 - \delta$ using $O(K^2 m_0)$ or $O(K m_0)$ samples, respectively.

**Lab Cell.**

```python
from sympy import symbols, exp, Rational, N

f1, f2, f3 = Rational(12, 10), Rational(37, 10), Rational(21, 10)
scores = [f1, f2, f3]
denom = sum(exp(s) for s in scores)
probs = [exp(s) / denom for s in scores]
for k, p in enumerate(probs, 1):
    print(f"p_{k} =", N(p, 4))
predicted_class = max(range(3), key=lambda i: scores[i]) + 1
print("Predicted class:", predicted_class)
```

## Naive Bayes Classifier

**Definition.** Let $\mathbf{x} = (x_1, x_2, \ldots, x_n)$ be a feature vector and $C$ a discrete class variable taking values in $\{c_1, c_2, \ldots, c_k\}$. The *Naive Bayes classifier* assigns to $\mathbf{x}$ the class

$$\hat{c} = \arg\max_{c \in \mathcal{C}} P(C = c) \prod_{i=1}^{n} P(X_i = x_i \mid C = c),$$

where the product follows from the *naive conditional independence assumption*: given the class label $c$, the features $X_1, \ldots, X_n$ are mutually independent. This assumption simplifies the joint likelihood $P(\mathbf{x} \mid c)$ from an intractable $n$-dimensional distribution to a product of univariate terms, making estimation feasible even with small training sets.

The rule above is derived directly from Bayes' theorem,

$$P(C = c \mid \mathbf{x}) = \frac{P(\mathbf{x} \mid C = c)\,P(C = c)}{P(\mathbf{x})},$$

by noting that $P(\mathbf{x})$ is constant across classes and therefore irrelevant to the $\arg\max$.

**Worked Example.** A spam filter classifies emails as *spam* ($s$) or *ham* ($h$) using two binary features: $X_1$ = contains "free" and $X_2$ = contains "offer". Training data yields

$$P(s) = 0.4,\quad P(h) = 0.6,$$
$$P(X_1=1 \mid s) = 0.8,\quad P(X_2=1 \mid s) = 0.7,$$
$$P(X_1=1 \mid h) = 0.1,\quad P(X_2=1 \mid h) = 0.2.$$

For a new email with $\mathbf{x} = (1, 1)$:

$$\text{score}(s) = 0.4 \times 0.8 \times 0.7 = 0.224,$$
$$\text{score}(h) = 0.6 \times 0.1 \times 0.2 = 0.012.$$

Since $0.224 > 0.012$, the classifier labels the email as spam.

**Key Theorem (Zero-Frequency Problem and Laplace Smoothing).** If any training frequency $P(X_i = x_i \mid c) = 0$, the entire product collapses to zero, eliminating potentially valid classes. Laplace (additive) smoothing resolves this by replacing raw counts:

$$P(X_i = v \mid c) = \frac{\text{count}(X_i = v, C = c) + \alpha}{\text{count}(C = c) + \alpha \lvert V_i \rvert},$$

where $\alpha > 0$ (typically $\alpha = 1$) and $|V_i|$ is the number of distinct values of $X_i$. This guarantees strictly positive probabilities while remaining asymptotically consistent as training data grows.

**Lab Cell.**

```python
from sympy import Rational, prod

# Prior probabilities
priors = {'spam': Rational(2, 5), 'ham': Rational(3, 5)}

# Likelihoods P(feature=1 | class)
likelihoods = {
    'spam': [Rational(4, 5), Rational(7, 10)],
    'ham':  [Rational(1, 10), Rational(1, 5)],
}

x = [1, 1]  # observed feature vector
scores = {
    c: priors[c] * prod(likelihoods[c][i] for i in range(len(x)) if x[i])
    for c in priors
}
print(scores)           # {'spam': 7/25, 'ham': 3/250}
print(max(scores, key=scores.get))   # spam
```

## Spam Filtering

**Definition.** Spam filtering is the problem of binary classification: given a message $x$ drawn from a feature space $\mathcal{X}$, assign a label $y \in \{0, 1\}$ where $y = 1$ denotes spam. The dominant probabilistic approach uses Bayes' theorem to compute the posterior probability of each class given the observed features:

$$P(y = 1 \mid x) = \frac{P(x \mid y = 1)\, P(y = 1)}{P(x)}$$

The classifier decides spam when $P(y = 1 \mid x) > P(y = 0 \mid x)$, equivalently when the log-odds ratio exceeds zero:

$$\log \frac{P(y = 1 \mid x)}{P(y = 0 \mid x)} > 0$$

Under the **Naïve Bayes** assumption, features $x_1, x_2, \ldots, x_n$ (word-presence indicators) are conditionally independent given the class label, so the likelihood factorises as $P(x \mid y) = \prod_{i=1}^{n} P(x_i \mid y)$. This reduces parameter estimation from an exponential table to $2n$ scalar probabilities.

**Worked Example.** Suppose a training corpus yields $P(\text{spam}) = 0.4$ and, for the word "prize", $P(\text{prize} \mid \text{spam}) = 0.8$ and $P(\text{prize} \mid \text{ham}) = 0.05$. For a one-word message containing only "prize":

$$\log \frac{P(y=1 \mid \text{prize})}{P(y=0 \mid \text{prize})} = \log \frac{0.8 \times 0.4}{0.05 \times 0.6} = \log \frac{0.32}{0.03} \approx 2.37 > 0$$

The classifier correctly flags this message as spam.

**Key Theorem (Optimality of the Bayes Classifier).** Among all classifiers mapping $\mathcal{X} \to \{0,1\}$, the Bayes classifier $h^*(x) = \arg\max_y P(y \mid x)$ minimises the expected 0–1 loss. Its error rate, the **Bayes error**, is $\mathbb{E}_x[\min(P(y=1\mid x),\, P(y=0\mid x))]$, and no classifier can achieve lower error on the same distribution.

**Lab Cell.**

```python
from sympy import symbols, log, Rational, simplify

p_spam, p_word_spam, p_word_ham = Rational(4,10), Rational(8,10), Rational(5,100)
p_ham = 1 - p_spam

log_odds = log(p_word_spam * p_spam) - log(p_word_ham * p_ham)
print("Log-odds:", simplify(log_odds).evalf())  # ≈ 2.37
```

Running this cell confirms the hand calculation and illustrates how symbolic arithmetic eliminates floating-point rounding during parameter estimation.

### outcome (0.0s)

## Outcome

**Definition.** In probability theory, an *outcome* is a single, indivisible result of a random experiment. A random experiment is any procedure that (i) can be repeated under identical conditions, (ii) has a well-defined set of possible results, and (iii) produces exactly one result per trial that cannot be predicted with certainty in advance. The set of all possible outcomes of an experiment is called the *sample space* and is denoted $\Omega$; each element $\omega \in \Omega$ is one outcome. The sample space is introduced here only as the container that gives outcomes their precise meaning — it will be studied on its own terms in the next section.

**Worked Example.** Roll a standard six-sided die once. The sample space is

$$\Omega = \{1, 2, 3, 4, 5, 6\}.$$

Each integer represents a distinct outcome. When the die lands showing the face labelled $3$, the outcome of that trial is $\omega = 3$. No further decomposition is possible: $3$ is not "the sum of smaller sub-results" within this experiment. Now contrast this with rolling the die *twice*. The sample space becomes

$$\Omega' = \{(i,j) : i, j \in \{1,\dots,6\}\},$$

which contains $36$ ordered-pair outcomes. The pair $(2, 5)$ — first roll yields $2$, second yields $5$ — is a single outcome of the two-roll experiment, even though it encodes two die values. The key point is that what counts as an outcome depends entirely on how the experiment is defined; the same physical objects can generate different sample spaces depending on what question is being asked.

**Key Theorem (Uniqueness of Outcome per Trial).** For any well-defined random experiment, each trial produces *exactly one* outcome $\omega \in \Omega$. That is, the outcomes in $\Omega$ are mutually exclusive (no trial can simultaneously produce two distinct outcomes) and collectively exhaustive (every trial must produce some outcome in $\Omega$). This two-part requirement is not an empirical claim but a logical constraint on how experiments and their sample spaces must be constructed: if two results could occur simultaneously, they would be redefined as a single compound outcome.

**Lab Cell.**

```python
from sympy import FiniteSet

Omega = FiniteSet(*range(1, 7))          # sample space for one die roll
print("Sample space:", Omega)
print("Number of outcomes:", len(Omega))

Omega_two = FiniteSet(*[(i, j) for i in range(1, 7) for j in range(1, 7)])
print("Two-roll outcome count:", len(Omega_two))  # expected: 36
```

Running this cell enumerates both sample spaces and confirms that extending the experiment from one roll to two multiplies the number of outcomes by a factor of six, illustrating how the structure of outcomes depends on the experiment's definition.

### sample_space (0.0s)

## Sample Space

**Definition.** A *sample space* is the set of all possible outcomes of a random experiment. It is conventionally denoted $\Omega$ (or $S$). Each element $\omega \in \Omega$ is called a *sample point* or *elementary outcome*. A sample space may be finite, countably infinite, or uncountably infinite, depending on the nature of the experiment.

Formally, given a random experiment $\mathcal{E}$, the sample space $\Omega$ satisfies two properties: (i) every conceivable result of $\mathcal{E}$ corresponds to exactly one element of $\Omega$, and (ii) exactly one element of $\Omega$ is realized each time $\mathcal{E}$ is performed. These two properties are sometimes stated as *exhaustiveness* (no outcome is missing) and *mutual exclusivity* (no two distinct elements can both be realized simultaneously). Specifying $\Omega$ completely and unambiguously is the first step in any probabilistic model; subsequent constructs — events, probability measures — are built on top of it.

**Worked Example.** Consider rolling a standard fair die once. The experiment $\mathcal{E}$ produces one face value from $\{1, 2, 3, 4, 5, 6\}$, so

$$\Omega = \{1,\, 2,\, 3,\, 4,\, 5,\, 6\}.$$

This sample space is finite with $|\Omega| = 6$. Now suppose instead that we record the exact time (in seconds) until a radioactive atom decays. Any non-negative real value is physically possible, giving the uncountable sample space $\Omega = [0, \infty)$. The two examples illustrate how the same modelling choice — what counts as one outcome — determines the entire structure of $\Omega$.

**Key Theorem (Uniqueness of the Sample Space).** Given a precise description of a random experiment $\mathcal{E}$, there exists a unique minimal sample space $\Omega^*$ such that every other valid sample space for $\mathcal{E}$ can be obtained from $\Omega^*$ by partitioning its elements. In other words, coarser descriptions of outcomes correspond to quotients of $\Omega^*$, never to genuinely different foundations. This theorem underscores why precision in defining $\Omega$ matters: a poorly specified sample space cannot be recovered by later refinement — it must be replaced entirely.

**Lab Cell (SymPy).**

```python
from sympy import FiniteSet, Interval, oo

# Finite sample space: one roll of a fair six-sided die
omega_die = FiniteSet(1, 2, 3, 4, 5, 6)
print("Sample space (die):", omega_die)
print("Cardinality:", len(omega_die))   # 6

# Uncountable sample space: radioactive decay time
omega_decay = Interval(0, oo)
print("Sample space (decay):", omega_decay)

# Verify membership for a candidate outcome
t = 2.5                                 # seconds
print(f"Is t={t} a valid outcome?", t in omega_decay)  # True
```

Running this cell confirms that `omega_die` contains exactly six elements and that any non-negative real number is a valid member of `omega_decay`. The contrast between `FiniteSet` and `Interval` in SymPy mirrors the mathematical distinction between finite and uncountably infinite sample spaces — a distinction that will matter when assigning probabilities in the next section.

### event (0.0s)

## Event

**Definition.** Let $\Omega$ be the sample space introduced in the previous section — the set of all possible outcomes of a random experiment. An **event** is any subset $A \subseteq \Omega$ to which a probability can be assigned. In the finite and countable settings covered in this course, every subset qualifies; in more advanced treatments, the assignable subsets are organised into a $\sigma$-algebra, but that structure is not needed here. The probability function $P$ maps each event to a number in $[0, 1]$ and satisfies the Kolmogorov axioms: $P(\Omega) = 1$, $P(\emptyset) = 0$, and countable additivity for mutually exclusive events.

Events are the fundamental objects on which probability operates. Because events are sets, the full language of set algebra is available: if $A$ and $B$ are events, then so are the complement $A^c$ (outcomes not in $A$), the union $A \cup B$ (at least one occurs), and the intersection $A \cap B$ (both occur). This lets compound logical statements about outcomes be handled with standard set operations.

**Worked Example.** Roll a fair six-sided die. The sample space is $\Omega = \{1, 2, 3, 4, 5, 6\}$. Define the event $A = \{2, 4, 6\}$ ("the outcome is even") and $B = \{1, 2, 3\}$ ("the outcome is at most 3"). Then:

$$A \cap B = \{2\}, \qquad A \cup B = \{1,2,3,4,6\}, \qquad A^c = \{1,3,5\}.$$

Assigning uniform probability $P(\{\omega\}) = \tfrac{1}{6}$ to each singleton yields $P(A) = \tfrac{1}{2}$, $P(B) = \tfrac{1}{2}$, and $P(A \cap B) = \tfrac{1}{6}$.

**Theorem (Inclusion–Exclusion).** For any two events $A, B \subseteq \Omega$,

$$P(A \cup B) = P(A) + P(B) - P(A \cap B).$$

*Proof sketch.* Each outcome in $A \cap B$ is counted twice in $P(A) + P(B)$ but belongs to $A \cup B$ exactly once; subtracting $P(A \cap B)$ corrects the double-counting. $\square$

In the example above: $P(A \cup B) = \tfrac{1}{2} + \tfrac{1}{2} - \tfrac{1}{6} = \tfrac{5}{6}$, matching the direct count $|\{1,2,3,4,6\}|/6$.

**Lab Cell (SymPy).**

```python
from sympy import Rational, FiniteSet

Omega = FiniteSet(1, 2, 3, 4, 5, 6)
A = FiniteSet(2, 4, 6)
B = FiniteSet(1, 2, 3)

p = lambda S: Rational(len(S), len(Omega))

print(p(A | B))                    # 5/6
print(p(A) + p(B) - p(A & B))     # 5/6  — inclusion–exclusion
```

### probability (0.0s)

## Probability

**Definition.** A *probability space* is a triple $(\Omega, \mathcal{F}, P)$, where $\Omega$ is the *sample space* (the set of all possible outcomes), $\mathcal{F}$ is a collection of subsets of $\Omega$ called *events*, and $P : \mathcal{F} \to [0,1]$ is a *probability measure* satisfying the Kolmogorov axioms:

1. $P(A) \geq 0$ for every event $A \in \mathcal{F}$,
2. $P(\Omega) = 1$,
3. For any countable collection of mutually disjoint events $A_1, A_2, \ldots$,
$$P\!\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i).$$

These three axioms are sufficient to derive the entire calculus of probability, including complementation ($P(A^c) = 1 - P(A)$), monotonicity, and inclusion–exclusion. The one new primitive introduced here is the probability measure $P$ itself — a function that assigns a number in $[0,1]$ to each event in a principled, consistent way.

**Worked Example.** A fair six-sided die is rolled once. Here $\Omega = \{1, 2, 3, 4, 5, 6\}$, and $P(\{k\}) = \tfrac{1}{6}$ for each outcome $k$. Let $A = \{\text{even}\} = \{2, 4, 6\}$ and $B = \{\text{greater than 4}\} = \{5, 6\}$. By axiom 3,
$$P(A) = \frac{3}{6} = \frac{1}{2}, \qquad P(B) = \frac{2}{6} = \frac{1}{3}.$$
Since $A \cap B = \{6\}$, the inclusion–exclusion formula gives
$$P(A \cup B) = P(A) + P(B) - P(A \cap B) = \frac{1}{2} + \frac{1}{3} - \frac{1}{6} = \frac{2}{3}.$$

**Theorem (Inclusion–Exclusion).** For any two events $A, B \in \mathcal{F}$,
$$P(A \cup B) = P(A) + P(B) - P(A \cap B).$$
*Proof sketch.* Write $A \cup B = A \sqcup (B \setminus A)$ as a disjoint union. Applying axiom 3 and noting $B = (A \cap B) \sqcup (B \setminus A)$ yields the result after cancellation. $\square$

**Lab Cell (SymPy).**
```python
from sympy.stats import Die, P

X = Die('X', 6)                          # fair six-sided die
p_even    = P(X % 2 == 0)               # P(A)
p_gt4     = P(X > 4)                     # P(B)
p_union   = P((X % 2 == 0) | (X > 4))  # P(A ∪ B)
print(p_even, p_gt4, p_union)            # 1/2  1/3  2/3
```

### conditional_probability (0.0s)

## Conditional Probability

**Definition.** Let $(\Omega, \mathcal{F}, P)$ be a probability space and let $B \in \mathcal{F}$ be an event with $P(B) > 0$. The *conditional probability* of event $A$ given event $B$ is defined as

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}.$$

Intuitively, conditioning on $B$ restricts the sample space from $\Omega$ to $B$, then re-normalizes the measure so that $P(B \mid B) = 1$. The function $A \mapsto P(A \mid B)$ is itself a valid probability measure on $(\Omega, \mathcal{F})$.

---

**Worked Example.** A standard deck of 52 cards is shuffled and one card is drawn. Let $A$ = {card is an Ace} and $B$ = {card is a Spade}. We wish to compute $P(A \mid B)$.

- $P(B) = 13/52 = 1/4$, since there are 13 spades.
- $P(A \cap B) = 1/52$, since only the Ace of Spades satisfies both conditions.

Therefore,

$$P(A \mid B) = \frac{1/52}{1/4} = \frac{1}{13}.$$

This equals the unconditional probability $P(A) = 4/52 = 1/13$, which will shortly motivate the concept of *independence*.

---

**Theorem (Multiplication Rule).** For any events $A$ and $B$ with $P(B) > 0$,

$$P(A \cap B) = P(A \mid B)\, P(B).$$

More generally, for events $A_1, A_2, \ldots, A_n$ with $P(A_1 \cap \cdots \cap A_{n-1}) > 0$,

$$P\!\left(\bigcap_{i=1}^{n} A_i\right) = P(A_1)\, P(A_2 \mid A_1)\, P(A_3 \mid A_1 \cap A_2) \cdots P\!\left(A_n \,\Big|\, \bigcap_{i=1}^{n-1} A_i\right).$$

*Proof sketch.* The base case follows directly from the definition by algebraic rearrangement. The general case follows by induction, applying the definition at each step to the accumulated intersection.

---

**Lab Cell (SymPy).**

```python
from sympy import Rational

# Card-draw example
P_B       = Rational(13, 52)   # P(Spade)
P_A_and_B = Rational(1, 52)    # P(Ace ∩ Spade)
P_A_given_B = P_A_and_B / P_B

print(f"P(A | B) = {P_A_given_B}")   # 1/13
```

Running this cell confirms $P(A \mid B) = \tfrac{1}{13}$, matching the hand calculation above. Students are encouraged to modify the numerators to explore how conditioning on smaller sets concentrates probability mass.

### and_event (0.0s)

## And Event

**Definition.** Let $(\Omega, \mathcal{F}, P)$ be a probability space. Given two events $A, B \in \mathcal{F}$, the *and event* (also called the *intersection*) is the event

$$A \cap B \;=\; \{\,\omega \in \Omega \mid \omega \in A \text{ and } \omega \in B\,\}.$$

Informally, $A \cap B$ occurs precisely when *both* $A$ and $B$ occur on the same trial. The probability of the and event satisfies

$$P(A \cap B) \;=\; P(A)\,P(B \mid A), \qquad P(A) > 0,$$

where $P(B \mid A)$ denotes the conditional probability of $B$ given $A$. When $A$ and $B$ are *independent*, $P(B \mid A) = P(B)$, so the formula reduces to $P(A \cap B) = P(A)\,P(B)$.

**Worked Example.** A standard deck contains 52 cards. Define $A$ = "the drawn card is a King" and $B$ = "the drawn card is a Heart." Then $|A| = 4$, $|B| = 13$, and $|A \cap B| = 1$ (the King of Hearts). Sampling uniformly without replacement for a single draw gives

$$P(A) = \frac{4}{52}, \quad P(B) = \frac{13}{52}, \quad P(A \cap B) = \frac{1}{52}.$$

Since $P(A)\,P(B) = \frac{4}{52} \cdot \frac{13}{52} = \frac{52}{2704} = \frac{1}{52} = P(A \cap B)$, the events are independent in this single-draw setting.

**Theorem (Inclusion–Exclusion for Two Events).** For any $A, B \in \mathcal{F}$,

$$P(A \cup B) \;=\; P(A) + P(B) - P(A \cap B).$$

*Proof sketch.* Every $\omega \in A \cup B$ is counted once in $P(A) + P(B)$, except elements of $A \cap B$, which are counted twice. Subtracting $P(A \cap B)$ once corrects the double count. $\square$

This theorem reveals that computing $P(A \cap B)$ is essential to any union calculation, making the and event a foundational building block of probability arithmetic.

**Lab Cell (SymPy).**

```python
from sympy import Rational, symbols

P_A = Rational(4, 52)
P_B = Rational(13, 52)
P_A_and_B = Rational(1, 52)

print("P(A ∩ B) =", P_A_and_B)
print("P(A)·P(B) =", P_A * P_B)
print("Independent?", P_A * P_B == P_A_and_B)
print("P(A ∪ B) =", P_A + P_B - P_A_and_B)
```

Running this cell confirms independence and computes $P(A \cup B) = \tfrac{16}{52} = \tfrac{4}{13}$.

### independent_events (18.3s)

## Independent Events

**Definition.** Two events $A$ and $B$ defined on a sample space $\Omega$ are said to be *independent* if the occurrence of one provides no information about the occurrence of the other. Formally, $A$ and $B$ are independent if and only if

$$P(A \cap B) = P(A)\,P(B).$$

An equivalent characterization is that $P(A \mid B) = P(A)$ whenever $P(B) > 0$, which follows immediately from the definition of conditional probability: $P(A \mid B) = P(A \cap B)/P(B) = P(A)$. Independence is a symmetric relation; if $A$ is independent of $B$, then $B$ is independent of $A$.

This definition extends to finite collections. Events $A_1, A_2, \ldots, A_n$ are *mutually independent* if for every subset $\{A_{i_1}, \ldots, A_{i_k}\} \subseteq \{A_1, \ldots, A_n\}$,

$$P\!\left(A_{i_1} \cap \cdots \cap A_{i_k}\right) = P(A_{i_1})\cdots P(A_{i_k}).$$

Note that pairwise independence does not imply mutual independence.

**Worked Example.** A fair six-sided die is rolled once. Let $A = \{\text{result is even}\} = \{2,4,6\}$ and $B = \{\text{result is greater than 3}\} = \{4,5,6\}$. Then $P(A) = 1/2$, $P(B) = 1/2$, and $A \cap B = \{4,6\}$, so $P(A \cap B) = 1/3$. Because $P(A)P(B) = 1/4 \neq 1/3$, the events $A$ and $B$ are *not* independent. Now let $C = \{\text{result is odd}\} = \{1,3,5\}$. Then $A \cap C = \emptyset$, so $P(A \cap C) = 0$, while $P(A)P(C) = 1/4 \neq 0$. This illustrates that mutually exclusive events with positive probability are always *dependent*.

**Key Theorem.** If $A$ and $B$ are independent, then so are each of the pairs $(A, B^c)$, $(A^c, B)$, and $(A^c, B^c)$.

*Proof sketch.* Using the complement rule, $P(A \cap B^c) = P(A) - P(A \cap B) = P(A) - P(A)P(B) = P(A)(1 - P(B)) = P(A)P(B^c)$. The remaining cases follow by symmetry. $\square$

**Lab Cell (SymPy).**

```python
from sympy import Rational, simplify

PA, PB = Rational(1, 2), Rational(1, 3)
P_AB_independent = PA * PB          # product rule under independence
print("P(A ∩ B) =", P_AB_independent)          # 1/6

# Verify complement independence
P_A_Bc = PA * (1 - PB)
print("P(A ∩ Bᶜ) =", P_A_Bc)                  # 1/3
print("P(A)·P(Bᶜ) =", PA * (1 - PB))          # 1/3
print("Equal:", simplify(P_A_Bc - PA*(1-PB)) == 0)
```

Running this cell confirms the theorem: independence is preserved under complementation, and the product rule holds exactly.

### dependent_events (17.7s)

## Dependent Events

**Definition.** Two events $A$ and $B$, defined on a common sample space $\Omega$, are said to be *dependent* if the occurrence of one alters the probability of the other. Formally, $A$ and $B$ are dependent whenever

$$P(A \mid B) \neq P(A) \qquad \text{or equivalently} \qquad P(A \cap B) \neq P(A)\,P(B).$$

The conditional probability $P(A \mid B)$ is defined as

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}, \qquad P(B) > 0,$$

and measures the likelihood of $A$ given that $B$ is known to have occurred. Dependence arises whenever the information that $B$ has occurred is *informative* about $A$—the two events share some structural or causal link.

**Worked Example.** Draw two cards *without replacement* from a standard 52-card deck. Let $A$ = "first card is an Ace" and $B$ = "second card is an Ace."

- $P(A) = \tfrac{4}{52} = \tfrac{1}{13}$.
- Given $A$ has occurred, only 3 Aces remain among 51 cards, so $P(B \mid A) = \tfrac{3}{51} = \tfrac{1}{17}$.
- Since $P(B \mid A) = \tfrac{1}{17} \neq \tfrac{1}{13} = P(B)$, the events are dependent.

The joint probability is $P(A \cap B) = \tfrac{4}{52} \cdot \tfrac{3}{51} = \tfrac{12}{2652} = \tfrac{1}{221}$, which differs from $P(A)P(B) = \tfrac{1}{169}$, confirming dependence. Sampling *without replacement* is the canonical source of dependence in combinatorial probability.

**Key Theorem (Multiplication Rule for Dependent Events).** For any two events $A$ and $B$ with $P(B) > 0$,

$$P(A \cap B) = P(B)\,P(A \mid B).$$

This identity extends by induction: for events $A_1, A_2, \dots, A_n$,

$$P\!\left(\bigcap_{i=1}^{n} A_i\right) = P(A_1)\,P(A_2 \mid A_1)\,P(A_3 \mid A_1 \cap A_2)\cdots$$

The multiplication rule reduces the computation of joint probabilities to a chain of conditional probabilities, each of which may be easier to assess from the problem structure.

**Lab Cell.**

```python
from sympy import Rational, simplify

# P(A): first card is an Ace
P_A = Rational(4, 52)

# P(B | A): second card is an Ace given first was an Ace
P_B_given_A = Rational(3, 51)

# Joint probability via multiplication rule
P_A_and_B = P_A * P_B_given_A

# P(B) by total probability: P(B|A)P(A) + P(B|A^c)P(A^c)
P_Ac = 1 - P_A
P_B_given_Ac = Rational(4, 51)
P_B = P_B_given_A * P_A + P_B_given_Ac * P_Ac

print("P(A ∩ B) =", P_A_and_B)          # 1/221
print("P(A)·P(B) =", simplify(P_A * P_B))  # 1/169
print("Dependent:", P_A_and_B != P_A * P_B)
```

Running this cell confirms $P(A \cap B) \neq P(A)P(B)$, establishing dependence rigorously through exact rational arithmetic.

### multiplication_rule (14.9s)

## Multiplication Rule

**Definition.** Let $A$ and $B$ be events defined on a sample space $\Omega$. The *multiplication rule* expresses the probability of both events occurring simultaneously:

$$P(A \cap B) = P(A) \cdot P(B \mid A),$$

where $P(B \mid A)$ denotes the conditional probability of $B$ given that $A$ has already occurred, defined (whenever $P(A) > 0$) by

$$P(B \mid A) = \frac{P(A \cap B)}{P(A)}.$$

The multiplication rule is therefore a direct algebraic rearrangement of the definition of conditional probability, elevated to a computational tool. If $A$ and $B$ are *independent* — meaning the occurrence of $A$ carries no information about $B$ — then $P(B \mid A) = P(B)$, and the rule reduces to the familiar product $P(A \cap B) = P(A) \cdot P(B)$.

**Worked Example.** A standard deck of 52 cards is shuffled. Two cards are drawn without replacement. What is the probability that both cards are aces?

Let $A$ = "first card is an ace" and $B$ = "second card is an ace." There are 4 aces among 52 cards, so $P(A) = \tfrac{4}{52}$. After one ace is removed, 3 aces remain among 51 cards, giving $P(B \mid A) = \tfrac{3}{51}$. Applying the multiplication rule:

$$P(A \cap B) = \frac{4}{52} \cdot \frac{3}{51} = \frac{12}{2652} = \frac{1}{221} \approx 0.00452.$$

**Key Theorem (Chain Rule of Probability).** The multiplication rule extends to any finite collection of events $A_1, A_2, \ldots, A_n$:

$$P\!\left(\bigcap_{i=1}^{n} A_i\right) = P(A_1)\cdot P(A_2 \mid A_1)\cdot P(A_3 \mid A_1 \cap A_2)\cdots P\!\left(A_n \;\middle|\; \bigcap_{i=1}^{n-1} A_i\right).$$

This chain rule is foundational in Bayesian networks and sequential inference, where joint distributions over many variables are decomposed into tractable conditional factors.

**Lab Cell.**

```python
from fractions import Fraction
from sympy import symbols, simplify

# Multiplication rule: drawing 2 aces without replacement
p_A  = Fraction(4, 52)          # P(first card is an ace)
p_BA = Fraction(3, 51)          # P(second ace | first was ace)
p_AB = p_A * p_BA               # P(both aces)

print(f"P(A)        = {p_A}")
print(f"P(B|A)      = {p_BA}")
print(f"P(A ∩ B)    = {p_AB}")  # 1/221
```

Running this cell confirms $P(A \cap B) = \tfrac{1}{221}$, matching the hand calculation above.

### tree_diagram (55.4s)

## Tree Diagram

**Definition.** A *tree diagram* is a branching diagram used to enumerate all possible outcomes of a multi-stage random experiment. At each stage, every branch splits into one branch per available outcome, and each branch is labeled with the probability of that outcome given the outcomes already observed. A complete path from the leftmost root to any terminal node encodes one full outcome of the experiment; its probability is the product of the probabilities labeling the edges along that path.

**Worked Example.** A box contains 3 red balls and 2 blue balls. Two balls are drawn *without* replacement. Construct a tree diagram and find $P(\text{both red})$.

- **Stage 1:** Draw first ball. $P(R_1) = \tfrac{3}{5}$; $P(B_1) = \tfrac{2}{5}$.
- **Stage 2 (given $R_1$):** 2 red, 2 blue remain. $P(R_2 \mid R_1) = \tfrac{2}{4} = \tfrac{1}{2}$; $P(B_2 \mid R_1) = \tfrac{1}{2}$.
- **Stage 2 (given $B_1$):** 3 red, 1 blue remain. $P(R_2 \mid B_1) = \tfrac{3}{4}$; $P(B_2 \mid B_1) = \tfrac{1}{4}$.

The tree yields four terminal nodes. The probability of each is the product of the edge labels along its path:

$$P(R_1 \cap R_2) = \frac{3}{5} \cdot \frac{1}{2} = \frac{3}{10}.$$

Summing all four terminal-node probabilities confirms $\tfrac{3}{10} + \tfrac{3}{10} + \tfrac{3}{10} + \tfrac{1}{10} = 1$, a useful self-check that all outcomes have been accounted for.

**Key Theorem (Multiplication Rule).** For any sequence of events $A_1, A_2, \ldots, A_k$,

$$P(A_1 \cap A_2 \cap \cdots \cap A_k) = P(A_1)\,P(A_2 \mid A_1)\,P(A_3 \mid A_1 \cap A_2)\cdots P(A_k \mid A_1 \cap \cdots \cap A_{k-1}).$$

A tree diagram makes this chain of conditional probabilities visually explicit: each edge label is one factor, and each terminal-node value is their product.

**Lab Cell.**
```python
from sympy import Rational

# Edge probabilities
p_R1 = Rational(3, 5);  p_B1 = Rational(2, 5)
p_R2_given_R1 = Rational(2, 4);  p_B2_given_R1 = Rational(2, 4)
p_R2_given_B1 = Rational(3, 4);  p_B2_given_B1 = Rational(1, 4)

leaves = {
    "RR": p_R1 * p_R2_given_R1,
    "RB": p_R1 * p_B2_given_R1,
    "BR": p_B1 * p_R2_given_B1,
    "BB": p_B1 * p_B2_given_B1,
}
for outcome, prob in leaves.items():
    print(f"P({outcome}) = {prob}")
print("Sum =", sum(leaves.values()))
```

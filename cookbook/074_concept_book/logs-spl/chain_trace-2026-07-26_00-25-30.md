## Relation

**Definition.** Let $A$ and $B$ be sets. A *binary relation* from $A$ to $B$ is any subset $R \subseteq A \times B$ of the Cartesian product. When $A = B$ we call $R$ a relation *on* $A$. We write $a \mathrel{R} b$ as shorthand for $(a, b) \in R$.

A relation on $A$ may satisfy one or more structural properties. It is *reflexive* if $a \mathrel{R} a$ for every $a \in A$; *symmetric* if $a \mathrel{R} b$ implies $b \mathrel{R} a$; *antisymmetric* if $a \mathrel{R} b$ and $b \mathrel{R} a$ together imply $a = b$; and *transitive* if $a \mathrel{R} b$ and $b \mathrel{R} c$ imply $a \mathrel{R} c$. These four properties are the building blocks from which all standard relations are assembled.

**Worked example.** Let $A = \{1, 2, 3, 6\}$ and define $R = \{(a,b) \mid a \text{ divides } b\}$. Listing all pairs explicitly:

$$R = \{(1,1),(1,2),(1,3),(1,6),(2,2),(2,6),(3,3),(3,6),(6,6)\}.$$

Checking properties: every element divides itself, so $R$ is reflexive. If $a \mid b$ and $b \mid a$ with $a, b \in A$, then $a = b$, so $R$ is antisymmetric. If $a \mid b$ and $b \mid c$ then $a \mid c$, so $R$ is transitive. Because $2 \mid 6$ but $6 \nmid 2$, symmetry fails. A reflexive, antisymmetric, transitive relation is called a *partial order*; the divisibility relation is the canonical example.

**Theorem (Equivalence-relation partition).** A relation $R$ on $A$ is an *equivalence relation* — reflexive, symmetric, and transitive — if and only if it partitions $A$ into disjoint, non-empty *equivalence classes* $[a] = \{b \in A \mid a \mathrel{R} b\}$ whose union is $A$.

*Proof sketch.* Given an equivalence relation, define $[a]$ as above. Reflexivity ensures $a \in [a]$, so every element belongs to some class. If $[a] \cap [b] \neq \emptyset$, pick $c$ in both; by symmetry and transitivity every element of $[a]$ is in $[b]$ and vice versa, so $[a] = [b]$. The converse follows by reading these steps in reverse. $\square$

**Lab cell.**

```python
from sympy import divisors
A = [1, 2, 3, 6]
R = [(a, b) for a in A for b in A if b % a == 0]
reflexive    = all((a, a) in R for a in A)
antisymmetric = all(a == b for (a, b) in R if (b, a) in R)
transitive   = all((a, c) in R for (a, b) in R for (c, d) in R if b == c)
print(reflexive, antisymmetric, transitive)   # True True True
```

### function (0.0s)

## Function

**Definition.** A *function* $f$ from a set $A$ to a set $B$, written $f: A \to B$, is a rule that assigns to each element $x \in A$ exactly one element $f(x) \in B$. The set $A$ is the *domain* of $f$, the set $B$ is the *codomain*, and the *range* (or image) is $\{f(x) \mid x \in A\} \subseteq B$. The defining requirement — that every input produces *exactly one* output — distinguishes a function from a general relation. A relation $R \subseteq A \times B$ is a function if and only if for every $a \in A$ there exists a unique $b \in B$ such that $(a, b) \in R$.

Two functions $f$ and $g$ are *equal* if they share the same domain and codomain and satisfy $f(x) = g(x)$ for all $x$ in the domain. The expression $f$ refers to the function object itself; $f(x)$ refers to its value at a particular input $x$.

**Worked Example.** Let $f: \mathbb{R} \to \mathbb{R}$ be defined by $f(x) = x^2 - 3x + 2$. To evaluate $f$ at $x = 4$:

$$f(4) = (4)^2 - 3(4) + 2 = 16 - 12 + 2 = 6.$$

To find the range, we complete the square: $f(x) = \left(x - \tfrac{3}{2}\right)^2 - \tfrac{1}{4}$. Since the squared term is non-negative, $f(x) \geq -\tfrac{1}{4}$ for all $x \in \mathbb{R}$, and the minimum is attained at $x = \tfrac{3}{2}$. Hence the range is $\left[-\tfrac{1}{4}, \infty\right)$, which is a proper subset of the codomain $\mathbb{R}$.

**Key Theorem (Composition).** If $f: A \to B$ and $g: B \to C$, the *composite function* $g \circ f: A \to C$ defined by $(g \circ f)(x) = g(f(x))$ is itself a function. Composition is associative — $(h \circ g) \circ f = h \circ (g \circ f)$ — but generally not commutative: $g \circ f \neq f \circ g$.


### one_to_one_function (13.0s)

## One To One Function

**Definition.** A function $f: A \to B$ is called *one-to-one* (or *injective*) if distinct elements of the domain map to distinct elements of the codomain. Formally,

$$f(x_1) = f(x_2) \implies x_1 = x_2 \qquad \text{for all } x_1, x_2 \in A.$$

Equivalently, $x_1 \neq x_2 \implies f(x_1) \neq f(x_2)$. A function that fails this condition is called *many-to-one*: at least two inputs share an output. Geometrically, injectivity is characterized by the **horizontal line test** — every horizontal line $y = c$ intersects the graph of $f$ at most once.

**Worked Example.** Consider $f: \mathbb{R} \to \mathbb{R}$ defined by $f(x) = 3x - 5$.

Suppose $f(x_1) = f(x_2)$. Then $3x_1 - 5 = 3x_2 - 5$, which gives $3x_1 = 3x_2$, hence $x_1 = x_2$. Therefore $f$ is injective.

By contrast, $g(x) = x^2$ is *not* injective on $\mathbb{R}$: $g(2) = g(-2) = 4$ with $2 \neq -2$. Restricting the domain to $[0, \infty)$ restores injectivity, illustrating that injectivity depends on the choice of domain.

**Key Theorem.** *A differentiable function $f$ on an interval $I$ is injective on $I$ if $f'(x) > 0$ for all $x \in I$, or if $f'(x) < 0$ for all $x \in I$.*

*Proof sketch.* Suppose $f' > 0$ on $I$ and let $x_1 < x_2$ in $I$. By the Mean Value Theorem, $f(x_2) - f(x_1) = f'(c)(x_2 - x_1)$ for some $c \in (x_1, x_2)$. Since $f'(c) > 0$ and $x_2 - x_1 > 0$, we get $f(x_2) > f(x_1)$, so $f(x_1) \neq f(x_2)$. $\square$

This theorem is practically useful: a strictly monotone function is automatically injective, and its inverse function exists on the range.

**Lab Cell (SymPy).**

```python
from sympy import symbols, solve, Function

# Verify injectivity: solve f(x1) = f(x2) for x1

```

Running this cell returns `[x2]`, confirming that $f(x_1) = f(x_2)$ forces $x_1 = x_2$ and the function is injective.

### exponential_function (0.0s)

## Exponential Function

**Definition.** Let $b > 0$ with $b \neq 1$. The *exponential function with base $b$* is the function $f : \mathbb{R} \to (0, \infty)$ defined by

$$f(x) = b^x.$$

The most important special case is $b = e$, where $e = \lim_{n \to \infty}\left(1 + \tfrac{1}{n}\right)^n \approx 2.71828\ldots$ is Euler's number. The function $\exp(x) = e^x$ is distinguished by the property that it is its own derivative: $\tfrac{d}{dx}e^x = e^x$, making it the unique solution to the initial-value problem $y' = y,\ y(0) = 1$.

For $b > 1$ the function is strictly increasing; for $0 < b < 1$ it is strictly decreasing. In both cases the horizontal axis is a horizontal asymptote as $x \to -\infty$ (when $b > 1$) or $x \to +\infty$ (when $b < 1$), and the $y$-intercept is always $f(0) = b^0 = 1$.

**Worked Example.** A bacterial culture begins with $500$ cells and doubles every $3$ hours. Express the population $P(t)$ after $t$ hours and find $P(9)$.

The doubling period gives base $b = 2$ and rate $t/3$ doublings per hour, so

$$P(t) = 500 \cdot 2^{t/3}.$$

At $t = 9$: $P(9) = 500 \cdot 2^{9/3} = 500 \cdot 2^3 = 500 \cdot 8 = 4000$ cells. Equivalently, writing $k = \tfrac{\ln 2}{3}$, one obtains $P(t) = 500\,e^{kt}$, illustrating that every exponential function can be re-expressed in base $e$.

**Key Theorem (Laws of Exponents).** For any $b > 0$, $b \neq 1$, and all $x, y \in \mathbb{R}$:

$$b^{x+y} = b^x b^y, \qquad b^{xy} = (b^x)^y, \qquad b^0 = 1.$$

These identities, combined with continuity, uniquely characterize the exponential function among measurable functions satisfying $f(x+y) = f(x)f(y)$.

**Lab Cell.**

```python

plot(exp(x), (x, -3, 3), ylabel='exp(x)')
```

### inverse_function (12.5s)

## Inverse Function

**Definition.** Let $f : A \to B$ be a function. We say $f$ is *invertible* if there exists a function $g : B \to A$ such that

$$g(f(x)) = x \quad \text{for all } x \in A, \qquad \text{and} \qquad f(g(y)) = y \quad \text{for all } y \in B.$$

When such a $g$ exists it is unique, and we denote it $f^{-1}$. A function is invertible if and only if it is **bijective** — that is, both injective (one-to-one) and surjective (onto). Geometrically, the graph of $f^{-1}$ is the reflection of the graph of $f$ across the line $y = x$.

**Worked Example.** Consider $f : \mathbb{R} \to \mathbb{R}^{+}$ defined by $f(x) = e^x$. To find $f^{-1}$, set $y = e^x$ and solve for $x$:

$$y = e^x \implies x = \ln y.$$

Hence $f^{-1}(y) = \ln y$, i.e.\ the natural logarithm is the inverse of the exponential. We verify both composition conditions:

$$f^{-1}(f(x)) = \ln(e^x) = x, \qquad f(f^{-1}(y)) = e^{\ln y} = y. \checkmark$$

Note that $f$ is bijective on the stated domain and codomain, which is why the inverse exists globally.

**Key Theorem (Inverse Function Theorem).** Let $f$ be continuously differentiable on an open interval containing $a$, with $f'(a) \neq 0$. Then $f$ is locally invertible near $a$, and

$$\left(f^{-1}\right)'(b) = \frac{1}{f'(a)}, \qquad \text{where } b = f(a).$$

*Proof sketch.* The condition $f'(a) \neq 0$ guarantees, via the implicit function theorem, that the equation $f(x) - b = 0$ can be solved uniquely for $x$ near $a$. Differentiating the identity $f(f^{-1}(y)) = y$ with respect to $y$ and applying the chain rule yields the derivative formula directly.

**Lab Cell (SymPy).**

```python
import sympy as sp

x = sp.Symbol('x', positive=True)
f = sp.exp(x)
f_inv = sp.ln(x)

# verify compositions
print(sp.simplify(f_inv.subs(x, f)))   # expects x
print(sp.simplify(f.subs(x, f_inv)))   # expects x

# derivative of inverse at a point
a = sp.Symbol('a', positive=True)
deriv_inv = 1 / sp.diff(f, x).subs(x, a)
print(deriv_inv)                        # expects exp(-a)
```

### logarithmic_function (14.8s)

## Logarithmic Function

**Definition.** Let $b > 0$ and $b \neq 1$. The *logarithm base $b$* is the function $\log_b : (0, \infty) \to \mathbb{R}$ defined by

$$\log_b x = y \iff b^y = x.$$

In other words, $\log_b x$ answers the question: *to what power must $b$ be raised to produce $x$?* The two most common specializations are the *common logarithm* $\log_{10} x$ (written $\log x$ in applied sciences) and the *natural logarithm* $\log_e x = \ln x$, where $e \approx 2.71828$.

Because the exponential function $f(x) = b^x$ is strictly monotone and maps $\mathbb{R}$ onto $(0, \infty)$, its inverse is well-defined on $(0, \infty)$. Consequently, $\log_b$ and $b^x$ are inverses:

$$b^{\log_b x} = x \quad (x > 0), \qquad \log_b(b^x) = x \quad (x \in \mathbb{R}).$$

**Worked Example.** Solve $3^{2x-1} = 81$.

Observe that $81 = 3^4$, so the equation becomes $3^{2x-1} = 3^4$. Equating exponents gives $2x - 1 = 4$, hence $x = \tfrac{5}{2}$. Alternatively, apply $\log_3$ to both sides: $\log_3(3^{2x-1}) = \log_3 81 \Rightarrow 2x - 1 = 4$.

**Key Theorem (Logarithm Laws).** For $b > 0$, $b \neq 1$, and positive reals $u$, $v$:

$$\log_b(uv) = \log_b u + \log_b v, \qquad \log_b\!\left(\frac{u}{v}\right) = \log_b u - \log_b v, \qquad \log_b(u^r) = r\log_b u.$$

The *change-of-base formula* $\log_b u = \dfrac{\ln u}{\ln b}$ reduces any logarithm to natural logarithms and is essential for calculus, where $\dfrac{d}{dx}\ln x = \dfrac{1}{x}$.

*Proof sketch.* Set $\alpha = \log_b u$ and $\beta = \log_b v$, so $u = b^\alpha$ and $v = b^\beta$. Then $uv = b^{\alpha+\beta}$, and applying $\log_b$ to both sides gives the product rule. The remaining identities follow similarly from exponent laws. $\square$

**Lab Cell.**

```python
from sympy import symbols, log, solve, simplify

x = symbols('x')
expr = log(3**(2*x - 1), 3) - log(81, 3)
solution = solve(expr, x)
print(solution)                      # [5/2]

# Verify change-of-base
print(simplify(log(81, 3) - log(81)/log(3)))  # 0
```

### richter_scale_application (14.2s)

## Richter Scale Application

**Definition.** The Richter magnitude scale quantifies the energy released by an earthquake using a base-10 logarithmic function. Given the maximum amplitude $A$ recorded by a seismograph and a correction term $A_0$ that accounts for distance from the epicenter, the local magnitude is defined as

$$M_L = \log_{10}\!\left(\frac{A}{A_0}\right).$$

Because the scale is logarithmic, each integer increase in $M_L$ corresponds to a tenfold increase in wave amplitude and approximately a 31.6-fold increase in energy released. This compression is essential: earthquakes span roughly twelve orders of magnitude in amplitude, making a linear scale impractical.

**Worked Example.** Suppose Seismograph A records an amplitude of $A_1 = 1{,}000\,\mu\text{m}$ and Seismograph B, at the same distance, records $A_2 = 50\,\mu\text{m}$, with a common correction value $A_0 = 1\,\mu\text{m}$. The magnitudes are

$$M_1 = \log_{10}(1000) = 3.00, \qquad M_2 = \log_{10}(50) \approx 1.70.$$

The difference in magnitude is $\Delta M = 3.00 - 1.70 = 1.30$. The ratio of amplitudes is

$$\frac{A_1}{A_2} = \frac{1000}{50} = 20,$$

which is consistent with $10^{1.30} \approx 20.0$, confirming the logarithmic relationship.

**Key Theorem.** *For two earthquakes with magnitudes $M_1$ and $M_2$, the ratio of their recorded amplitudes satisfies*

$$\frac{A_1}{A_2} = 10^{M_1 - M_2}.$$

*Proof sketch.* From the definition, $M_1 - M_2 = \log_{10}(A_1/A_0) - \log_{10}(A_2/A_0) = \log_{10}(A_1/A_2)$. Exponentiating both sides with base 10 yields the result. $\blacksquare$

This theorem immediately implies that a magnitude-7 earthquake releases $10^2 = 100$ times the amplitude energy of a magnitude-5 event.


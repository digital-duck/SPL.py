## Graph

**Definition.** A *graph* $G$ is an ordered pair $G = (V, E)$, where $V$ is a finite nonempty set whose elements are called *vertices* (or *nodes*), and $E \subseteq \{\{u, v\} : u, v \in V,\, u \neq v\}$ is a set of two-element subsets of $V$ called *edges*. The *order* of $G$ is $|V|$ and the *size* is $|E|$. When an edge $\{u, v\} \in E$ exists, the vertices $u$ and $v$ are said to be *adjacent*, and each is a *neighbor* of the other. The *degree* of a vertex $v$, written $\deg(v)$, counts the number of edges incident to $v$.

**Worked Example.** Let $V = \{1, 2, 3, 4\}$ and $E = \{\{1,2\},\{1,3\},\{2,4\},\{3,4\}\}$. This graph has order 4 and size 4. Computing degrees: $\deg(1) = 2$ (adjacent to 2 and 3), $\deg(2) = 2$, $\deg(3) = 2$, $\deg(4) = 2$. The sum of all degrees equals $2 + 2 + 2 + 2 = 8 = 2|E|$, which illustrates the handshaking identity below.

**Key Theorem (Handshaking Lemma).** For any graph $G = (V, E)$,
$$\sum_{v \in V} \deg(v) = 2|E|.$$
*Proof sketch.* Each edge $\{u,v\}$ contributes exactly 1 to $\deg(u)$ and exactly 1 to $\deg(v)$, so it is counted exactly twice in the sum over all vertices. Summing over all $|E|$ edges gives $2|E|$. $\square$

An immediate corollary is that the number of vertices of odd degree is always even, a fact with far-reaching consequences in the theory of Eulerian paths.

```python
import sympy as sp
import networkx as nx          # standard companion to SymPy for graph work

G = nx.Graph()
G.add_edges_from([(1,2),(1,3),(2,4),(3,4)])

degrees = dict(G.degree())
degree_sum = sum(degrees.values())

print("Degrees:", degrees)
print("Sum of degrees:", degree_sum)
print("2|E|         :", 2 * G.number_of_edges())
print("Handshaking identity holds:", degree_sum == 2 * G.number_of_edges())
```

## Intersection Graph

**Definition.** Let $\mathcal{F} = \{S_1, S_2, \ldots, S_n\}$ be a finite family of sets. The *intersection graph* of $\mathcal{F}$, denoted $\Omega(\mathcal{F})$, is the graph $G = (V, E)$ where $V = \{v_1, v_2, \ldots, v_n\}$ and

$$\{v_i, v_j\} \in E \iff S_i \cap S_j \neq \emptyset, \quad i \neq j.$$

Each vertex represents one set in the family; an edge joins two vertices precisely when their corresponding sets share at least one element. The underlying ground set $U = \bigcup_{i=1}^n S_i$ need not appear explicitly in the graph — only the overlap structure matters.

**Worked Example.** Consider the family $\mathcal{F} = \{A, B, C, D\}$ with

$$A = \{1,2,3\},\quad B = \{2,4\},\quad C = \{4,5,6\},\quad D = \{7\}.$$

Computing pairwise intersections: $A \cap B = \{2\} \neq \emptyset$, $A \cap C = \emptyset$, $A \cap D = \emptyset$, $B \cap C = \{4\} \neq \emptyset$, $B \cap D = \emptyset$, $C \cap D = \emptyset$. Hence $E(\Omega(\mathcal{F})) = \{\{v_A, v_B\},\, \{v_B, v_C\}\}$, yielding a path graph $P_3$. Vertex $v_D$ is isolated because $D$ meets no other set. This illustrates how the connectivity of $\Omega(\mathcal{F})$ encodes which sets are "reachable" from one another through shared elements.

**Key Theorem (Erdős–Goodman–Pósa, representation).** *Every graph is an intersection graph.* More precisely, for any graph $G = (V, E)$ one can construct a set family $\mathcal{F}$ such that $\Omega(\mathcal{F}) \cong G$. One canonical construction assigns to each vertex $v_i$ the set $S_i = \{v_i\} \cup \{e \in E : v_i \in e\}$; then $S_i \cap S_j \neq \emptyset$ if and only if $\{v_i, v_j\} \in E$. This universality result underpins the importance of intersection graphs: studying restricted families (intervals on $\mathbb{R}$, discs in $\mathbb{R}^2$, subtrees of a tree) defines classical graph classes — interval graphs, unit-disk graphs, and chordal graphs, respectively — each with tractable algorithmic properties not shared by general graphs.

**Lab Cell.**

```python
from itertools import combinations
import sympy as sp
import networkx as nx

sets = {'A': {1,2,3}, 'B': {2,4}, 'C': {4,5,6}, 'D': {7}}
labels = list(sets.keys())

G = nx.Graph()
G.add_nodes_from(labels)
for u, v in combinations(labels, 2):
    if sets[u] & sets[v]:          # non-empty intersection
        G.add_edge(u, v)

print("Edges:", list(G.edges()))   # Expected: [('A','B'), ('B','C')]
print("Isolated nodes:", list(nx.isolates(G)))  # Expected: ['D']
```

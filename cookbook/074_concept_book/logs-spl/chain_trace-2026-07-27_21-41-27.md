## Bellman Ford Algorithm

**Definition.** Let $G = (V, E)$ be a directed weighted graph with $n = |V|$ vertices and $m = |E|$ edges, where each edge $(u, v) \in E$ carries a real-valued weight $w(u, v) \in \mathbb{R}$. Given a source vertex $s \in V$, the *Bellman–Ford algorithm* computes the shortest-path distance $d[v]$ from $s$ to every vertex $v \in V$, or reports that a negative-weight cycle reachable from $s$ exists. The algorithm maintains a distance estimate $d[v]$ for each vertex, initialised as

$$d[s] = 0, \qquad d[v] = +\infty \text{ for all } v \neq s,$$

and iteratively *relaxes* every edge: for each $(u,v) \in E$, if $d[u] + w(u,v) < d[v]$, set $d[v] \leftarrow d[u] + w(u,v)$. This relaxation pass is repeated $n - 1$ times.

**Worked Example.** Consider the graph $V = \{A, B, C, D\}$ with edges and weights:

$$A \xrightarrow{6} B, \quad A \xrightarrow{7} C, \quad B \xrightarrow{-4} D, \quad C \xrightarrow{2} B, \quad D \xrightarrow{1} A.$$

Starting from $s = A$, after pass 1 we obtain $d[B] = 6$, $d[C] = 7$. After pass 2, relaxing $C \to B$ yields $d[B] = \min(6, 7+2) = 6$, and $B \to D$ gives $d[D] = 2$. After pass 3, $D \to A$ would set $d[A] = 3$, but $A$ is the source and no further improvement propagates usefully. Final distances: $d[A]=0,\ d[B]=6,\ d[C]=7,\ d[D]=2$.

**Key Theorem (Correctness and Complexity).** *After at most $n-1$ relaxation passes, $d[v]$ equals the true shortest-path distance from $s$ to $v$ for all $v$ reachable from $s$, provided no negative-weight cycle exists.* The proof follows from the observation that any simple shortest path contains at most $n-1$ edges; by induction, the $k$-th pass correctly settles all shortest paths using at most $k$ edges. A negative-weight cycle is detected by performing one additional ($n$-th) pass: if any distance decreases, a cycle exists. The time complexity is $\Theta(nm)$.

**Lab Cell.**

```python
import sympy as sp

def bellman_ford(edges, n_vertices, source):
    INF = sp.oo
    dist = {v: INF for v in range(n_vertices)}
    dist[source] = 0
    for _ in range(n_vertices - 1):
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
    # negative-cycle check
    for u, v, w in edges:
        if dist[u] + w < dist[v]:
            return None  # negative cycle detected
    return dist

edges = [(0,1,6),(0,2,7),(1,3,-4),(2,1,2),(3,0,1)]
print(bellman_ford(edges, n_vertices=4, source=0))
```

Running this cell yields `{0: 0, 1: 6, 2: 7, 3: 2}`, confirming the worked example.

## Negative Cycle

**Definition.** Let $G = (V, E, w)$ be a directed weighted graph where $w : E \to \mathbb{R}$ assigns a real-valued weight to each edge. A *negative cycle* is a directed cycle $C = (v_0, v_1, \ldots, v_k, v_0)$ whose total weight is strictly negative:

$$W(C) = \sum_{i=0}^{k-1} w(v_i, v_{i+1}) < 0.$$

Negative cycles are not merely a curiosity — they render the shortest-path problem ill-defined. If a negative cycle is reachable from a source $s$, one can traverse the cycle arbitrarily many times, driving the path weight toward $-\infty$. No finite shortest path exists for any vertex reachable from that cycle.

**Worked Example.** Consider the graph with vertices $\{A, B, C\}$ and directed edges:

$$w(A,B) = 4,\quad w(B,C) = -7,\quad w(C,A) = 2.$$

The cycle $A \to B \to C \to A$ has total weight $4 + (-7) + 2 = -1 < 0$. Hence this graph contains a negative cycle. Any path passing through $A$, $B$, or $C$ has no well-defined minimum, since each additional traversal of the cycle reduces the path cost by $1$.

**Key Theorem (Bellman–Ford Detection).** *A directed weighted graph $G$ contains a negative cycle reachable from source $s$ if and only if, after $|V| - 1$ relaxation passes of the Bellman–Ford algorithm, at least one edge $(u,v)$ still satisfies*

$$d[v] > d[u] + w(u,v),$$

*where $d[v]$ denotes the current shortest-path estimate to $v$.*

*Proof sketch.* After $|V|-1$ passes, Bellman–Ford guarantees $d[v] = \delta(s,v)$ for all vertices reachable without negative cycles ($\delta$ denotes the true shortest-path distance). A further relaxation can improve an estimate only if some cycle on the shortest path has negative total weight, contradicting the finiteness of $\delta$.

**Lab Cell.**

```python
import sympy as sp

# Edge list: (u, v, weight)
edges = [(0, 1, 4), (1, 2, -7), (2, 0, 2)]
n = 3
dist = [sp.oo] * n
dist[0] = 0

for _ in range(n - 1):
    for u, v, w in edges:
        if dist[u] + w < dist[v]:
            dist[v] = dist[u] + w

negative_cycle = any(dist[u] + w < dist[v] for u, v, w in edges)
print("Negative cycle detected:", negative_cycle)  # True
print("Distances:", dist)
```

Running this cell confirms detection: one further relaxation pass succeeds, revealing the negative cycle $A \to B \to C \to A$.

## Arbitrage Detection

**Definition.** An *arbitrage opportunity* in a financial market is a sequence of trades that requires no initial capital, carries no risk of loss, and yields a strictly positive profit with certainty. Formally, let $G = (V, E)$ be a directed graph where each vertex $v_i \in V$ represents a currency (or asset) and each directed edge $(v_i, v_j) \in E$ carries a weight $w_{ij} > 0$ denoting the exchange rate from asset $i$ to asset $j$. A cycle $v_{i_1} \to v_{i_2} \to \cdots \to v_{i_k} \to v_{i_1}$ constitutes an arbitrage if

$$\prod_{\ell=1}^{k} w_{i_\ell,\, i_{\ell+1}} > 1.$$

Taking logarithms, this product condition becomes a sum: define $c_{ij} = -\ln w_{ij}$. The cycle is an arbitrage if and only if the corresponding directed cycle has *negative total weight* under the transformed costs $c_{ij}$, i.e.,

$$\sum_{\ell=1}^{k} c_{i_\ell,\, i_{\ell+1}} < 0.$$

Arbitrage detection therefore reduces to detecting a **negative-weight cycle** in a weighted directed graph.

**Worked Example.** Suppose three currencies USD, EUR, GBP have rates: $w_{\text{USD}\to\text{EUR}} = 0.93$, $w_{\text{EUR}\to\text{GBP}} = 0.86$, $w_{\text{GBP}\to\text{USD}} = 1.25$. The cycle product is $0.93 \times 0.86 \times 1.25 = 1.00\overline{0}$... computing precisely: $0.93 \times 0.86 = 0.7998$, then $0.7998 \times 1.25 = 0.99975 < 1$, so no arbitrage exists here. Modify $w_{\text{GBP}\to\text{USD}} = 1.28$; then the product becomes $0.93 \times 0.86 \times 1.28 = 1.02\overline{3} > 1$, revealing an arbitrage: start with \$1, obtain €0.93, convert to £0.7998, convert back to \$1.0237—a 2.37% riskless gain.

**Key Theorem (Bellman–Ford).** Given a directed graph $G = (V, E)$ with $|V| = n$ vertices, the Bellman–Ford algorithm detects whether any negative-weight cycle is reachable from a source in $O(n \cdot |E|)$ time. The algorithm relaxes all edges $n-1$ times; if a further relaxation on the $n$-th pass still decreases any shortest-path estimate, a negative-weight cycle exists.

**Lab Cell.**

```python
import sympy as sp

rates = {('USD','EUR'): sp.Rational(93,100),
         ('EUR','GBP'): sp.Rational(86,100),
         ('GBP','USD'): sp.Rational(128,100)}

product = sp.prod(list(rates.values()))
print("Cycle product:", product)
print("Arbitrage exists:", product > 1)
```

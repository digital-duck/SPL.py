## Base Case

**Definition.** Let $P(n)$ be a predicate defined on the natural numbers $\mathbb{N}$. The *base case* of a proof by mathematical induction is the direct verification that $P(n_0)$ holds for some initial value $n_0 \in \mathbb{N}$, typically $n_0 = 0$ or $n_0 = 1$. Without this anchor, the inductive step — which asserts $P(k) \Rightarrow P(k+1)$ — has no truth value to propagate, rendering the entire argument vacuous. The base case is therefore not a formality; it is the logical seed from which all subsequent cases grow.

More precisely, mathematical induction rests on the well-ordering principle: every non-empty subset of $\mathbb{N}$ has a least element. If $P(n)$ failed for some $n$, the set $S = \{n \in \mathbb{N} : \lnot P(n)\}$ would have a minimum $m$. The base case rules out $m = n_0$, and the inductive step rules out any $m > n_0$, so $S$ must be empty, giving $P(n)$ for all $n \geq n_0$.

**Worked Example.** Prove that the sum of the first $n$ positive integers satisfies

$$\sum_{k=1}^{n} k = \frac{n(n+1)}{2}.$$

*Base case* ($n = 1$): The left-hand side equals $1$. The right-hand side equals $\frac{1 \cdot 2}{2} = 1$. Since $1 = 1$, $P(1)$ is verified. $\square$

The inductive step (not the focus here) would assume $P(m)$ and derive $P(m+1)$ by adding $m+1$ to both sides.

**Key Theorem (Principle of Mathematical Induction).** Let $P(n)$ be a predicate on $\mathbb{N}$. If (i) $P(n_0)$ holds, and (ii) for every $k \geq n_0$, $P(k) \Rightarrow P(k+1)$, then $P(n)$ holds for all $n \geq n_0$.

Condition (i) is precisely the base case. Altering $n_0$ shifts the domain of validity: choosing $n_0 = 3$ proves $P(n)$ only for $n \geq 3$, so selecting the correct base is part of the mathematical content of the proof.

### induction_proof (0.0s)

## Induction Proof

**Definition.** Mathematical induction is a proof technique used to establish that a proposition $P(n)$ holds for every natural number $n \geq n_0$. The method proceeds in two steps. First, the *base case*: verify that $P(n_0)$ is true. Second, the *inductive step*: assume $P(k)$ is true for some arbitrary $k \geq n_0$ (the *inductive hypothesis*), then prove that $P(k+1)$ follows necessarily. Because the base case anchors the chain and the inductive step propagates it, the principle guarantees $P(n)$ for all $n \geq n_0$ by the well-ordering property of $\mathbb{N}$.

**Worked Example.** Prove that the sum of the first $n$ positive integers satisfies

$$S(n) = \sum_{i=1}^{n} i = \frac{n(n+1)}{2}.$$

*Base case* ($n = 1$): $S(1) = 1 = \frac{1 \cdot 2}{2} = 1$. ✓

*Inductive step*: Assume $S(k) = \frac{k(k+1)}{2}$ for some $k \geq 1$. Then

$$S(k+1) = S(k) + (k+1) = \frac{k(k+1)}{2} + (k+1) = (k+1)\!\left(\frac{k}{2} + 1\right) = \frac{(k+1)(k+2)}{2}.$$

This is precisely the formula evaluated at $k+1$, so the inductive step holds. By the principle of mathematical induction, the identity is true for all $n \geq 1$.

**Key Theorem (Principle of Mathematical Induction).** Let $P(n)$ be a proposition defined for $n \in \mathbb{N}$. If (i) $P(n_0)$ is true, and (ii) $P(k) \Rightarrow P(k+1)$ for every $k \geq n_0$, then $P(n)$ is true for all $n \geq n_0$.

*Proof sketch.* Suppose the conclusion fails; let $S = \{n \geq n_0 : \lnot P(n)\}$ be nonempty. By the well-ordering principle, $S$ has a least element $m$. Since $P(n_0)$ holds, $m > n_0$, so $m - 1 \geq n_0$ and $P(m-1)$ is true. By the inductive step, $P(m)$ must also be true — a contradiction. Hence $S = \emptyset$.

### reduction (0.0s)

## Reduction

**Definition.** A *reduction* is a systematic transformation that maps a mathematical object to a canonical representative within its equivalence class, preserving the properties of interest while eliminating inessential complexity. Formally, given a set $S$ and an equivalence relation $\sim$ on $S$, a reduction is a function $r: S \to S$ satisfying three properties:

1. **Equivalence preservation:** $r(x) \sim x$ for all $x \in S$.
2. **Idempotency:** $r(r(x)) = r(x)$ for all $x \in S$.
3. **Canonicity:** $x \sim y \implies r(x) = r(y)$.

Together these guarantee that equivalent objects share a unique canonical form, and that applying the reduction a second time has no further effect.

**Worked Example.** Fix $n = 7$ and define $a \sim b$ if and only if $7 \mid (a - b)$. The modular reduction $r(x) = x \bmod 7$ maps every integer to its remainder in $\{0, 1, 2, 3, 4, 5, 6\}$.

$$r(23) = 23 - 3 \cdot 7 = 2, \qquad r(-4) = -4 + 7 = 3, \qquad r(14) = 0.$$

Verification of canonicity: $23 \sim 2$ because $7 \mid (23 - 2) = 21$. ✓ Idempotency holds trivially since $2 \in \{0,\ldots,6\}$ implies $r(2) = 2$.

**Key Theorem (Division Algorithm).** For any integers $a$ and $n > 0$ there exist *unique* integers $q$ and $r$ with $0 \le r < n$ such that

$$a = q\,n + r.$$

The remainder $r = a \bmod n$ is the canonical representative of the equivalence class $[a]$ in $\mathbb{Z}/n\mathbb{Z}$.

*Proof sketch.* Existence: the set $\{a - kn : k \in \mathbb{Z},\ a - kn \ge 0\}$ is non-empty (take $k$ sufficiently negative) and bounded below, so it has a minimum element $r$. If $r \ge n$ then $r - n \ge 0$ is a smaller element, a contradiction; hence $0 \le r < n$. Uniqueness follows from the fact that two remainders in $\{0,\ldots,n-1\}$ whose difference is divisible by $n$ must be equal. $\square$

Reduction is a pervasive paradigm: Gaussian elimination reduces a matrix to row echelon form; the Euclidean algorithm reduces a GCD computation to successively smaller remainders; polynomial long division reduces a rational function to a proper fraction. In each instance the same triad—equivalence preservation, idempotency, canonicity—holds.

```python
# Lab: modular reduction in SymPy

samples = [23, -4, 14, 100]
canonical = {a: Mod(a, n) for a in samples}
```

### partition_subroutine (0.0s)

## Partition Subroutine

**Definition.** Let $A$ be an array of $n$ comparable elements indexed $A[1], A[2], \ldots, A[n]$. A *partition subroutine* with respect to a chosen *pivot* element $p = A[k]$ is a procedure that rearranges $A$ in-place so that the resulting array satisfies the *partition invariant*:

$$A[i] \leq p \text{ for all } i < q, \quad A[q] = p, \quad A[j] \geq p \text{ for all } j > q,$$

where $q$ is the *pivot's final index*. The subroutine returns $q$ and runs in $\Theta(n)$ time using $O(1)$ auxiliary space.

The Lomuto scheme is the most pedagogically transparent implementation. It maintains two pointers: a *store pointer* $s$ and a *scan pointer* $j$. Initially $s = \ell - 1$ where $\ell$ is the left boundary. For each $j$ from $\ell$ to $r - 1$, if $A[j] \leq p$ the element is swapped with $A[s+1]$ and $s$ is incremented. After the scan, the pivot is placed at $A[s+1]$ and $q = s + 1$ is returned.

**Worked Example.** Consider $A = [3, 6, 8, 10, 1, 2, 1]$ with $p = A[7] = 1$ (the last element). Tracing Lomuto with $\ell = 1$, $r = 7$:

| $j$ | $A[j]$ | $A[j] \leq 1$? | Array after step |
|-----|--------|----------------|-----------------|
| 1 | 3 | No | unchanged |
| 2 | 6 | No | unchanged |
| 3 | 8 | No | unchanged |
| 4 | 10 | No | unchanged |
| 5 | 1 | Yes, $s\to1$ | swap $A[1]\leftrightarrow A[5]$: $[1,6,8,10,3,2,1]$ |
| 6 | 2 | No | unchanged |

Place pivot: swap $A[s+1] = A[2]$ with $A[7]$: $A = [1, 1, 8, 10, 3, 2, 6]$. Returned index $q = 2$. Every element left of index 2 satisfies $\leq 1$ and every element right satisfies $\geq 1$. ✓

**Key Theorem** *(Partition Correctness)*. Upon termination of Lomuto's scheme on $A[\ell \ldots r]$, the partition invariant holds at the returned index $q$, and no element is compared more than once. Consequently the total work is exactly $r - \ell$ comparisons.

*Proof sketch.* The loop invariant is: for all $i \in [\ell, s]$, $A[i] \leq p$, and for all $i \in [s+1, j-1]$, $A[i] > p$. Establishment is trivial before the first iteration. Maintenance follows by case analysis on whether $A[j] \leq p$. Termination at $j = r$ yields the invariant over the full range; placing the pivot at $s+1$ restores $A[q] = p$. Each element is visited by $j$ exactly once, giving $\Theta(r - \ell + 1)$ comparisons. $\blacksquare$

**Lab Cell.**

```python
from sympy import symbols, Function, Rational

def lomuto_partition(A, lo, hi):
    pivot = A[hi]
    s = lo - 1
    for j in range(lo, hi):
        if A[j] <= pivot:
            s += 1
            A[s], A[j] = A[j], A[s]
    A[s + 1], A[hi] = A[hi], A[s + 1]
    return s + 1

A = [3, 6, 8, 10, 1, 2, 1]
q = lomuto_partition(A, 0, len(A) - 1)
print(f"pivot index: {q}, array: {A}")
# Expected: pivot index: 1, array: [1, 1, 8, 10, 3, 2, 6]
```

## Recursion

**Definition.** A function $f$ is defined *recursively* if its value at an argument is expressed in terms of its value at one or more strictly simpler arguments, together with one or more *base cases* that terminate the descent. Formally, a recursive definition specifies:

1. **Base case(s):** explicit values $f(n_0), f(n_1), \ldots$ for the smallest inputs.
2. **Recursive case:** a rule $f(n) = g\bigl(n,\, f(n-1),\, f(n-2),\ldots\bigr)$ for $n$ beyond the base cases, where $g$ involves only arguments strictly less than $n$.

Well-foundedness—the guarantee that repeated application of the recursive case always reaches a base case—is what separates a valid recursive definition from a circular one.

**Worked example: the factorial function.** Define $n!$ for $n \in \mathbb{N}_0$ by

$$
0! = 1, \qquad n! = n \cdot (n-1)! \quad \text{for } n \geq 1.
$$

Computing $4!$ unwinds as follows:

$$
4! = 4 \cdot 3! = 4 \cdot 3 \cdot 2! = 4 \cdot 3 \cdot 2 \cdot 1! = 4 \cdot 3 \cdot 2 \cdot 1 \cdot 0! = 24.
$$

Each call reduces $n$ by $1$; since $n$ is a non-negative integer, the chain terminates at $0!$ in exactly $n$ steps. The *call stack* at depth $k$ holds the pending multiplication $k \cdot (\cdots)$, so the process requires $O(n)$ space as well as $O(n)$ time.

**Key theorem (Structural Induction Principle).** Let $P(n)$ be a property of natural numbers. If $P(0)$ holds, and $P(k)$ implies $P(k+1)$ for every $k \geq 0$, then $P(n)$ holds for all $n \in \mathbb{N}_0$. This principle is the mathematical counterpart of recursion: the base case mirrors the inductive base; the inductive step mirrors the recursive case. Any terminating recursion can therefore be reasoned about by induction, and correctness proofs for recursive algorithms follow this template directly.

### quickselect (24.9s)

## Quickselect

**Definition.** The *quickselect* algorithm solves the *order-statistic problem*: given an unsorted array $A$ of $n$ distinct elements and an integer $k$ with $1 \le k \le n$, return the element that would occupy position $k$ in the sorted order of $A$. Unlike a full sort, quickselect exploits the partition subroutine of quicksort to narrow the search to a single subarray at each recursive step, discarding the other half entirely.

Formally, let $\text{partition}(A, \ell, r)$ rearrange $A[\ell \dots r]$ around a pivot $p$ and return the pivot's final index $q$. Quickselect then proceeds:

$$
\text{quickselect}(A, \ell, r, k) =
\begin{cases}
A[\ell] & \text{if } \ell = r, \\
\text{quickselect}(A, \ell, q-1, k) & \text{if } k < q, \\
A[q] & \text{if } k = q, \\
\text{quickselect}(A, q+1, r, k) & \text{if } k > q.
\end{cases}
$$

**Worked Example.** Let $A = [3, 1, 4, 1, 5, 9, 2, 6]$ (treating duplicates as distinct by index) and $k = 4$ (the median of eight elements). Choose pivot $p = A[0] = 3$. After partitioning, suppose $A$ becomes $[1, 1, 2, 3, 5, 9, 4, 6]$ with pivot landing at index $q = 3$. Since $k = 4 > q = 3$, recurse on $A[4 \dots 7] = [5, 9, 4, 6]$ seeking local rank $k' = 1$. Choosing pivot $5$, after partition: $[4, 5, 9, 6]$, pivot at local index $1$. Since $k' = 1 = q'$, return $5$. The 4th-smallest element is $\mathbf{5}$.

**Key Theorem (Expected Complexity).** When the pivot is chosen uniformly at random, the expected number of comparisons made by quickselect is $\Theta(n)$.

*Proof sketch.* Let $C(n)$ denote the expected comparison count. After a random pivot, the probability that the pivot lands in position $i$ is $1/n$ for each $i$. The recursion reduces to a subproblem of expected size at most $3n/4$ with probability at least $1/2$ (a "good" split). A geometric-series argument on the expected work at each level yields $C(n) \le 8n$, giving $C(n) = O(n)$. The $\Omega(n)$ lower bound is immediate since every element must be examined at least once. $\blacksquare$

In the worst case (always choosing the minimum or maximum as pivot), the recurrence satisfies $T(n) = T(n-1) + \Theta(n)$, giving $T(n) = \Theta(n^2)$. The *median-of-medians* pivot strategy achieves $\Theta(n)$ in the worst case.

**Lab Cell.**

```python
import sympy as sp
import random

def quickselect(arr, k):
    """Return the k-th smallest element (1-indexed) using random pivot."""
    if len(arr) == 1:
        return arr[0]
    pivot = random.choice(arr)
    left  = [x for x in arr if x < pivot]
    mid   = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    if k <= len(left):
        return quickselect(left, k)
    elif k <= len(left) + len(mid):
        return pivot
    else:
        return quickselect(right, k - len(left) - len(mid))

# Demonstration
A = [3, 1, 4, 1, 5, 9, 2, 6]
for k in range(1, len(A) + 1):
    result = quickselect(A[:], k)
    sp.pprint(sp.Eq(sp.Symbol(f'a_{{{k}}}'), result))
```

## Median Of Medians

**Definition.** The *median-of-medians* algorithm is a deterministic linear-time selection procedure that identifies the $k$-th smallest element of an unsorted array $A$ of $n$ distinct elements in worst-case $\Theta(n)$ time. Unlike randomized quickselect, which achieves $O(n)$ expected time but $O(n^2)$ worst-case time, median-of-medians guarantees an asymptotically optimal pivot choice by constructing a pivot $p$ that partitions $A$ such that each resulting subarray contains at most $\frac{7n}{10} + 6$ elements.

**Algorithm Sketch.** The procedure operates in five stages:

1. Divide $A$ into $\lceil n/5 \rceil$ groups of at most five elements each.
2. Sort each group and extract its median $m_i$.
3. Recursively apply the algorithm to the set $M = \{m_1, m_2, \ldots, m_{\lceil n/5 \rceil}\}$ to find the median of medians $p$.
4. Partition $A$ around $p$ into sets $L = \{a \in A : a < p\}$ and $R = \{a \in A : a > p\}$.
5. Recurse on $L$ or $R$ depending on whether $|L| + 1$ equals, exceeds, or falls short of $k$.

**Worked Example.** Let $A = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]$ and suppose we seek the 6th smallest element.

- Form groups of five: $G_1 = [3,1,4,1,5]$, $G_2 = [9,2,6,5,3]$, $G_3 = [5]$.
- Sorted medians: $\text{med}(G_1) = 3$, $\text{med}(G_2) = 5$, $\text{med}(G_3) = 5$, so $M = [3,5,5]$.
- Median of $M$ is $p = 5$.
- Partition: $L = [3,1,4,1,2,3]$, $R = [9,6]$, and $p$ appears at positions $7,9,11$ (three copies).
- Since $|L| = 6 \geq k = 6$, the answer is the 6th smallest of $L$, which resolves to $4$.

**Key Theorem.** The median-of-medians algorithm runs in $\Theta(n)$ worst-case time. The recurrence is:

$$T(n) \leq T\!\left(\left\lceil \tfrac{n}{5} \right\rceil\right) + T\!\left(\tfrac{7n}{10} + 6\right) + O(n)$$

Since $\tfrac{1}{5} + \tfrac{7}{10} = \tfrac{9}{10} < 1$, the Master Theorem (case 3 variant) confirms $T(n) = O(n)$.

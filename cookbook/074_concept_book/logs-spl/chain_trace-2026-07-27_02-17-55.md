### partition (0.0s)

## 划分

**定义。** 设 $S$ 为非空集合。$S$ 的一个**划分**（partition）是 $S$ 的一族非空子集 $\{A_1, A_2, \ldots, A_k\}$，满足以下两个条件：

1. **互不相交**：对任意 $i \neq j$，有 $A_i \cap A_j = \emptyset$；
2. **覆盖全集**：$A_1 \cup A_2 \cup \cdots \cup A_k = S$。

每个子集 $A_i$ 称为一个**块**（block）或**等价类**。直观而言，划分将集合的元素"无重叠地分组"，使得每个元素恰好属于且仅属于一个块。

**划分与等价关系的对应。** 划分与等价关系之间存在深刻的双向联系：给定 $S$ 上的等价关系 $\sim$，则所有等价类 $[a] = \{x \in S \mid x \sim a\}$ 恰好构成 $S$ 的一个划分；反之，任意划分均诱导一个等价关系（同块则等价）。

**工作示例。** 设 $S = \{1, 2, 3, 4, 5, 6\}$，定义关系 $a \sim b \iff 3 \mid (a - b)$（即 $a$ 与 $b$ 模 $3$ 同余）。

- $[1] = \{1, 4\}$，$[2] = \{2, 5\}$，$[3] = \{3, 6\}$。

验证：三个块互不相交，且 $\{1,4\} \cup \{2,5\} \cup \{3,6\} = S$，故这是 $S$ 的一个划分，共 $3$ 个块。

**关键定理（Bell 数）。** 有限集 $S = \{1, 2, \ldots, n\}$ 的所有划分的总数称为第 $n$ 个 **Bell 数** $B_n$，满足递推关系

$$B_{n+1} = \sum_{k=0}^{n} \binom{n}{k} B_k, \quad B_0 = 1.$$

前几项为 $B_0=1,\; B_1=1,\; B_2=2,\; B_3=5,\; B_4=15$。该递推的组合意义：从 $n+1$ 个元素中选取与元素 $n+1$ 同块的 $k$ 个元素，再对其余 $n-k$ 个元素递归计数。

**实验单元（SymPy）。**

```python
from sympy.combinatorics.partitions import Partition, RGS_generalized
from sympy import bell

# 计算 Bell 数
for n in range(7):
    print(f"B_{n} = {bell(n)}")

# 枚举 {0,1,2,3} 的所有划分
from sympy.utilities.iterables import partitions
S = [0, 1, 2, 3]
# 使用受限增长序列枚举
from sympy.combinatorics.partitions import RGS_enum
print(f"{{0,1,2,3}} 的划分总数: {RGS_enum(4)}")  # 应输出 15
```

### sigma_notation (0.0s)

## Sigma 记号

**定义．** 设 $a_1, a_2, \ldots, a_n$ 为一列实数，$k$ 为求和指标，则**Sigma 记号**（求和记号）定义为

$$\sum_{k=m}^{n} a_k \;=\; a_m + a_{m+1} + \cdots + a_n,$$

其中 $m$ 称为**下界**，$n$ 称为**上界**，$k$ 为**哑指标**（dummy index），可用任意字母替换而不改变求和值。当 $n < m$ 时，约定空和等于零。

**例题．** 计算 $\displaystyle S = \sum_{k=1}^{5}(2k - 1)$。

逐项展开：

$$S = (2\cdot1-1)+(2\cdot2-1)+(2\cdot3-1)+(2\cdot4-1)+(2\cdot5-1) = 1+3+5+7+9 = 25.$$

注意到这正好是前五个奇数之和，结果等于 $5^2 = 25$。此规律将由下面的定理加以说明。

**关键定理（基本求和公式）．** 对任意正整数 $n$，成立以下三个恒等式：

$$\sum_{k=1}^{n} 1 = n, \qquad \sum_{k=1}^{n} k = \frac{n(n+1)}{2}, \qquad \sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}.$$

*证明思路（第二式）．* 令 $S = 1 + 2 + \cdots + n$，同时写出逆序 $S = n + (n-1) + \cdots + 1$，两式相加得 $2S = n(n+1)$，故 $S = \dfrac{n(n+1)}{2}$。$\blacksquare$

利用线性性质 $\displaystyle\sum_{k=1}^{n}(a_k + b_k) = \sum_{k=1}^{n}a_k + \sum_{k=1}^{n}b_k$ 及 $\displaystyle\sum_{k=1}^{n}c\,a_k = c\sum_{k=1}^{n}a_k$，可将多项式形式的求和化归为上述公式的组合。

**实验单元（SymPy）．**

```python
from sympy import symbols, summation, factor

k, n = symbols('k n', positive=True, integer=True)

# 验证前 n 项平方和公式
expr = summation(k**2, (k, 1, n))
print(factor(expr))          # 输出: n*(n + 1)*(2*n + 1)/6

# 数值验证：n = 5 时的奇数和
print(summation(2*k - 1, (k, 1, 5)))  # 输出: 25
```

运行上述代码，可直观验证定理公式并为后续积分近似（Riemann 和）的学习奠定基础。

### antiderivative (0.0s)

## Antiderivative

### 定义

设函数 $F(x)$ 在区间 $I$ 上可微，若对所有 $x \in I$ 均满足

$$F'(x) = f(x),$$

则称 $F(x)$ 为 $f(x)$ 在区间 $I$ 上的一个**原函数**（antiderivative）。由于任意常数 $C$ 的导数为零，故若 $F(x)$ 是 $f(x)$ 的一个原函数，则 $F(x) + C$（$C \in \mathbb{R}$）也是 $f(x)$ 的原函数。全体原函数的集合称为 $f(x)$ 的**不定积分**，记作

$$\int f(x)\,\mathrm{d}x = F(x) + C.$$

此处积分号 $\int$ 与微分元 $\mathrm{d}x$ 共同指定积分变量，常数 $C$ 称为**积分常数**。

### 例题

求 $f(x) = 3x^2$ 的不定积分。

**解：** 猜测原函数具有形式 $F(x) = x^n$，对其求导得 $F'(x) = nx^{n-1}$。令 $n = 3$，则 $(x^3)' = 3x^2 = f(x)$，验证成立。因此

$$\int 3x^2\,\mathrm{d}x = x^3 + C.$$

验证：对 $x^3 + C$ 求导，得 $3x^2$，与原函数定义吻合。

### 核心定理

**定理（原函数存在性与唯一性）。** 若 $f(x)$ 在区间 $I$ 上连续，则 $f(x)$ 在 $I$ 上必存在原函数。进一步，若 $F(x)$ 与 $G(x)$ 均为 $f(x)$ 在 $I$ 上的原函数，则存在常数 $C$ 使得

$$G(x) = F(x) + C, \quad \forall x \in I.$$

**证明思路：** 令 $H(x) = G(x) - F(x)$，则 $H'(x) = G'(x) - F'(x) = f(x) - f(x) = 0$。由拉格朗日中值定理，导数恒为零的函数在连通区间上必为常数，故 $H(x) = C$，即 $G(x) = F(x) + C$。$\blacksquare$

### 实验单元（SymPy）

```python
from sympy import symbols, integrate, diff

x = symbols('x')
f = 3*x**2

F = integrate(f, x)
print("不定积分：", F)          # 输出：x**3
print("验证求导：", diff(F, x)) # 输出：3*x**2
```

运行上述代码，SymPy 自动省略积分常数 $C$；在实际应用中，务必手动添加 $+\, C$ 以表示完整的原函数族。

### riemann_sum (0.0s)

## Riemann Sum

### 定义

设函数 $f$ 在闭区间 $[a, b]$ 上有界。将 $[a, b]$ 分成 $n$ 个子区间，分割点为

$$a = x_0 < x_1 < x_2 < \cdots < x_n = b,$$

每个子区间的长度记为 $\Delta x_i = x_i - x_{i-1}$。在第 $i$ 个子区间 $[x_{i-1}, x_i]$ 内任取一点 $c_i$，则 **黎曼和**（Riemann Sum）定义为

$$S_n = \sum_{i=1}^{n} f(c_i)\,\Delta x_i.$$

黎曼和的几何意义是：以 $f(c_i)$ 为高、$\Delta x_i$ 为宽的若干矩形的有向面积之和，用以近似曲线 $y = f(x)$ 与 $x$ 轴所围成的区域面积。当所有子区间的最大长度 $\|\Delta\| = \max_i \Delta x_i \to 0$ 时，若极限存在且与 $c_i$ 的选取方式无关，则称 $f$ 在 $[a, b]$ 上**黎曼可积**，该极限即为定积分：

$$\int_a^b f(x)\,dx = \lim_{\|\Delta\|\to 0} \sum_{i=1}^{n} f(c_i)\,\Delta x_i.$$

### 具体例题

计算 $f(x) = x^2$ 在 $[0, 1]$ 上以**右端点**为采样点、均匀分割 $n$ 份时的黎曼和，并对 $n \to \infty$ 取极限。

均匀分割时 $\Delta x = \tfrac{1}{n}$，右端点 $c_i = \tfrac{i}{n}$，故

$$S_n = \sum_{i=1}^{n} \left(\frac{i}{n}\right)^2 \cdot \frac{1}{n} = \frac{1}{n^3}\sum_{i=1}^{n} i^2 = \frac{1}{n^3} \cdot \frac{n(n+1)(2n+1)}{6}.$$

化简得 $S_n = \dfrac{(n+1)(2n+1)}{6n^2}$，当 $n \to \infty$ 时

$$\lim_{n\to\infty} S_n = \frac{1}{3},$$

与精确值 $\displaystyle\int_0^1 x^2\,dx = \frac{1}{3}$ 完全吻合。

### 关键定理

**定理（黎曼可积充分条件）**：若 $f$ 在 $[a, b]$ 上连续，则 $f$ 在 $[a, b]$ 上黎曼可积。更一般地，若 $f$ 有界且仅有有限个不连续点，则结论同样成立。

证明思路：连续函数在紧集上一致连续，因此当 $\|\Delta\| \to 0$ 时，上黎曼和与下黎曼和之差趋于零，从而二者共同收敛至同一极限。

### 实验单元（SymPy）

```python
from sympy import symbols, summation, limit, oo, Rational

i, n = symbols('i n', positive=True, integer=True)
# 右端点黎曼和
c_i   = i / n
delta = Rational(1) / n
S_n   = summation(c_i**2 * delta, (i, 1, n))
print("黎曼和 S_n =", S_n)
print("极限    =", limit(S_n, n, oo))
```

### area_under_curve_limit (0.0s)

## Area Under Curve Limit

**定义**

设函数 $f(x)$ 在闭区间 $[a, b]$ 上连续且非负。将 $[a, b]$ 等分为 $n$ 个子区间，每个子区间的宽度为 $\Delta x = \dfrac{b - a}{n}$，第 $i$ 个子区间的右端点为 $x_i = a + i\Delta x$。定义**黎曼和**（Riemann Sum）为

$$
S_n = \sum_{i=1}^{n} f(x_i)\,\Delta x.
$$

曲线 $y = f(x)$ 与直线 $x = a$、$x = b$ 及 $x$ 轴所围成的**曲线下面积**定义为该黎曼和在 $n \to \infty$ 时的极限：

$$
A = \lim_{n \to \infty} S_n = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i)\,\Delta x.
$$

此极限即为定积分 $\displaystyle\int_a^b f(x)\,dx$，当该极限存在时，称 $f$ 在 $[a, b]$ 上**黎曼可积**。

---

**例题**

计算 $f(x) = x^2$ 在 $[0, 1]$ 上的曲线下面积。

取 $n$ 等分，$\Delta x = \dfrac{1}{n}$，$x_i = \dfrac{i}{n}$，则

$$
S_n = \sum_{i=1}^{n} \left(\frac{i}{n}\right)^2 \cdot \frac{1}{n} = \frac{1}{n^3}\sum_{i=1}^{n} i^2 = \frac{1}{n^3} \cdot \frac{n(n+1)(2n+1)}{6}.
$$

对上式取极限：

$$
A = \lim_{n \to \infty} \frac{n(n+1)(2n+1)}{6n^3} = \lim_{n \to \infty} \frac{(1)(1 + \frac{1}{n})(2 + \frac{1}{n})}{6} = \frac{1 \cdot 1 \cdot 2}{6} = \frac{1}{3}.
$$

故 $\displaystyle\int_0^1 x^2\,dx = \dfrac{1}{3}$。

---

**关键定理（微积分基本定理，第二部分）**

设 $F$ 为 $f$ 在 $[a, b]$ 上的任意一个原函数，即 $F'(x) = f(x)$，则

$$
\int_a^b f(x)\,dx = F(b) - F(a).
$$

该定理将极限求和过程与求原函数直接联系起来，使得无需每次从黎曼和出发均可高效计算面积。

---

**实验单元（SymPy）**

```python
from sympy import symbols, integrate, Rational

x = symbols('x')
f = x**2

# 定积分（精确值）
area = integrate(f, (x, 0, 1))
print(area)          # 输出：1/3

# 验证黎曼和近似
n = 1000
dx = Rational(1, n)
riemann = sum(f.subs(x, Rational(i, n)) * dx for i in range(1, n + 1))
print(float(riemann))  # 趋近于 0.3333...
```

### definite_integral (0.0s)

## Definite Integral

### 定义

设函数 $f$ 在闭区间 $[a, b]$ 上有界。将区间 $[a, b]$ 划分为 $n$ 个子区间，令 $a = x_0 < x_1 < \cdots < x_n = b$，并在每个子区间 $[x_{i-1}, x_i]$ 上任取样本点 $\xi_i$。定义**黎曼和**为

$$S_n = \sum_{i=1}^{n} f(\xi_i)\,\Delta x_i, \quad \Delta x_i = x_i - x_{i-1}.$$

若当最大子区间长度 $\|\Delta\| = \max_i \Delta x_i \to 0$ 时，$S_n$ 趋向与划分方式及样本点选取无关的极限，则称 $f$ 在 $[a, b]$ 上**黎曼可积**，将该极限记为

$$\int_a^b f(x)\,dx = \lim_{\|\Delta\|\to 0} \sum_{i=1}^{n} f(\xi_i)\,\Delta x_i.$$

几何意义上，当 $f(x) \geq 0$ 时，定积分等于曲线 $y = f(x)$ 与 $x$ 轴在 $[a, b]$ 上所围面积。

### 例题

计算 $\displaystyle\int_0^2 x^2\,dx$。

将 $[0, 2]$ 均匀划分为 $n$ 份，取右端点为样本点，则 $x_i = \tfrac{2i}{n}$，$\Delta x = \tfrac{2}{n}$。

$$S_n = \sum_{i=1}^{n} \left(\frac{2i}{n}\right)^2 \cdot \frac{2}{n} = \frac{8}{n^3}\sum_{i=1}^{n} i^2 = \frac{8}{n^3}\cdot\frac{n(n+1)(2n+1)}{6}.$$

令 $n \to \infty$，得 $\displaystyle\int_0^2 x^2\,dx = \frac{8}{6} \cdot 2 = \frac{8}{3}$。

### 微积分基本定理

**定理**（牛顿–莱布尼茨公式）：设 $f$ 在 $[a, b]$ 上连续，$F$ 是 $f$ 的任意一个原函数，即 $F'(x) = f(x)$，则

$$\int_a^b f(x)\,dx = F(b) - F(a).$$

该定理将积分的计算从极限过程简化为求原函数，是微积分的核心结论。

### 实验单元（SymPy）

```python
from sympy import symbols, integrate

x = symbols('x')
# 计算定积分
result = integrate(x**2, (x, 0, 2))
print(result)   # 输出：8/3
```

### fundamental_theorem_calculus_part1 (0.0s)

## Fundamental Theorem Calculus Part1

### 定义

设 $f$ 在闭区间 $[a, b]$ 上连续。定义**积分上限函数**（又称面积函数）为

$$F(x) = \int_a^x f(t)\, dt, \quad x \in [a, b].$$

**微积分基本定理（第一部分）** 断言：$F$ 在 $(a, b)$ 上可微，且对每一 $x \in (a, b)$，有

$$F'(x) = f(x).$$

换言之，对连续函数而言，对其积分再求导，可以还原该函数本身。这一结论揭示了微分与积分之间的深刻对称性——两者互为逆运算。

### 证明思路

利用导数定义：

$$F'(x) = \lim_{h \to 0} \frac{F(x+h) - F(x)}{h} = \lim_{h \to 0} \frac{1}{h}\int_x^{x+h} f(t)\, dt.$$

由于 $f$ 在 $[x, x+h]$ 上连续，由积分中值定理，存在 $c_h \in [x, x+h]$ 使得

$$\frac{1}{h}\int_x^{x+h} f(t)\, dt = f(c_h).$$

当 $h \to 0$ 时，$c_h \to x$，再由 $f$ 的连续性得 $f(c_h) \to f(x)$，从而 $F'(x) = f(x)$。$\blacksquare$

### 具体例题

设 $f(t) = t^2$，$a = 0$，求

$$F(x) = \int_0^x t^2\, dt$$

并验证 $F'(x) = f(x)$。

**解：** 直接计算积分：

$$F(x) = \int_0^x t^2\, dt = \left[\frac{t^3}{3}\right]_0^x = \frac{x^3}{3}.$$

对 $F$ 求导：

$$F'(x) = \frac{d}{dx}\left(\frac{x^3}{3}\right) = x^2 = f(x). \quad \checkmark$$

### 关键定理

若 $f$ 在 $[a, b]$ 上连续，则由 $F(x) = \int_a^x f(t)\,dt$ 定义的函数满足：

1. $F$ 在 $[a, b]$ 上连续；
2. $F$ 在 $(a, b)$ 上可微；
3. $F'(x) = f(x)$，对所有 $x \in (a, b)$ 成立。

### 实验单元（SymPy）

```python
from sympy import symbols, integrate, diff, cos

t, x = symbols('t x')
f = cos(t)
F = integrate(f, (t, 0, x))   # F(x) = sin(x)
dF = diff(F, x)
print("F(x) =", F)            # sin(x)
print("F'(x) =", dF)          # cos(x)
print("等于 f(x)？", dF == f)  # True
```

运行上述代码，可验证 $F(x) = \sin x$ 的导数恰为 $\cos x$，从而以计算实验印证本定理。

### fundamental_theorem_calculus_part2 (0.0s)

## Fundamental Theorem Calculus Part2

**定义。** 设 $f$ 在闭区间 $[a, b]$ 上连续，$F$ 是 $f$ 在该区间上的任意一个原函数，即满足 $F'(x) = f(x)$，则定积分由下式给出：

$$\int_a^b f(x)\,dx = F(b) - F(a).$$

此结论通常记作 $\Big[F(x)\Big]_a^b$，即对原函数在上下限处取值之差。微积分基本定理第二部分的核心意义在于：它将求定积分的问题转化为寻找原函数的问题，使得复杂的极限求和过程得以避免。

---

**例题。** 计算 $\displaystyle\int_1^3 (2x + 1)\,dx$。

首先求被积函数 $f(x) = 2x + 1$ 的一个原函数。由幂函数积分法则：

$$F(x) = x^2 + x.$$

验证：$F'(x) = 2x + 1 = f(x)$，满足条件。代入上下限：

$$\int_1^3 (2x+1)\,dx = F(3) - F(1) = (9 + 3) - (1 + 1) = 12 - 2 = 10.$$

几何意义上，此结果等于曲线 $y = 2x+1$ 在区间 $[1,3]$ 上方、$x$ 轴上方所围梯形的面积，可直接验证：面积 $= \tfrac{1}{2}(3 + 7)\times 2 = 10$，与积分结果一致。

---

**关键定理（微积分基本定理第二部分）。** 若 $f$ 在 $[a,b]$ 上连续，$F$ 为其原函数，则：

$$\int_a^b f(x)\,dx = F(b) - F(a).$$

**证明概要。** 由微积分基本定理第一部分，定义累积函数 $G(x) = \int_a^x f(t)\,dt$，则 $G'(x) = f(x)$。因此 $G$ 与 $F$ 均为 $f$ 的原函数，故 $F(x) = G(x) + C$（$C$ 为常数）。于是

$$F(b) - F(a) = G(b) - G(a) = \int_a^b f(t)\,dt - 0 = \int_a^b f(x)\,dx. \quad \square$$

---

**实验单元（SymPy）。**

```python
from sympy import symbols, integrate, diff

x = symbols('x')
f = 2*x + 1
F = integrate(f, x)          # 求原函数
result = F.subs(x, 3) - F.subs(x, 1)  # 代入上下限
print("原函数 F(x) =", F)
print("定积分值 =", result)
# 验证：diff(F, x) == f
print("验证 F'(x) = f(x):", diff(F, x) == f)
```

运行上述代码，输出应为 $F(x) = x^2 + x$，积分值为 $10$，验证正确。学生可将被积函数替换为 $\sin x$、$e^x$ 等，观察定理对不同函数的适用性。

### integration_by_substitution (18.7s)

## Integration By Substitution

### 定义

换元积分法（又称变量替换法）是一种将复合函数的积分化为更简单形式的技巧。其理论基础是链式法则的逆运算。

**定理（换元积分法）**：设 $u = g(x)$ 在区间 $I$ 上可微，$f$ 在 $g(I)$ 上连续，则

$$\int f(g(x))\, g'(x)\, dx = \int f(u)\, du$$

其中右端对 $u$ 求不定积分后，将 $u = g(x)$ 代回即得原变量的表达式。

对于定积分，变量替换同样适用，但积分限须随之改变：

$$\int_a^b f(g(x))\, g'(x)\, dx = \int_{g(a)}^{g(b)} f(u)\, du$$

### 例题

计算 $\displaystyle\int 2x\cos(x^2)\, dx$。

**解**：令 $u = x^2$，则 $\dfrac{du}{dx} = 2x$，即 $du = 2x\, dx$。将被积式改写：

$$\int 2x\cos(x^2)\, dx = \int \cos(u)\, du = \sin(u) + C = \sin(x^2) + C$$

**验证**：对结果求导，$\dfrac{d}{dx}\sin(x^2) = \cos(x^2) \cdot 2x$，与原被积函数一致。

### 关键定理

换元积分法的正确性由链式法则保证。若 $F'(u) = f(u)$，则

$$\frac{d}{dx} F(g(x)) = F'(g(x))\, g'(x) = f(g(x))\, g'(x)$$

两端对 $x$ 积分即得换元公式。选取适当替换的原则是：被积式中应能识别出某个内层函数 $g(x)$ 及其导数 $g'(x)$（允许相差常数倍）。若 $g'(x)$ 缺失或无法补齐，则换元法通常不适用，需考虑分部积分或其他方法。

### 实验：用 SymPy 验证

```python
from sympy import symbols, cos, sin, integrate, diff, simplify

x = symbols('x')

# 原积分
expr = 2 * x * cos(x**2)
result = integrate(expr, x)
print("不定积分结果:", result)           # 期望输出 sin(x**2)

# 验证：对结果求导应还原被积函数
check = simplify(diff(result, x) - expr)
print("验证（应为 0）:", check)
```

运行上述代码后，`result` 将输出 $\sin(x^2)$，`check` 输出 $0$，从而以符号计算确认换元积分的正确性。

## Integrals Exponential Functions

### 定义

指数函数的积分是微积分中的核心内容之一。对于以自然常数 $e$ 为底的指数函数，其不定积分定义如下：

$$\int e^x \, dx = e^x + C$$

其中 $C$ 为任意常数。这一结果源于 $e^x$ 是唯一满足 $\frac{d}{dx}f(x) = f(x)$ 的函数（在相差常数因子的意义下）。对于一般底数 $a > 0$，$a \neq 1$，有：

$$\int a^x \, dx = \frac{a^x}{\ln a} + C$$

此公式可由换底公式 $a^x = e^{x \ln a}$ 与链式法则推导得出。

---

### 计算示例

**例题：** 计算 $\displaystyle\int_0^2 3e^{2x} \, dx$。

令 $u = 2x$，则 $du = 2\, dx$，即 $dx = \dfrac{du}{2}$。当 $x=0$ 时 $u=0$，当 $x=2$ 时 $u=4$。于是：

$$\int_0^2 3e^{2x}\,dx = 3 \cdot \frac{1}{2}\int_0^4 e^u\,du = \frac{3}{2}\Big[e^u\Big]_0^4 = \frac{3}{2}(e^4 - 1) \approx 81.95$$

---

### 核心定理

**定理（指数函数积分公式）：** 设 $k \neq 0$ 为实常数，则：

$$\int e^{kx}\, dx = \frac{1}{k}e^{kx} + C$$

**证明概要：** 设 $F(x) = \dfrac{1}{k}e^{kx}$，对其求导得 $F'(x) = \dfrac{1}{k} \cdot k \cdot e^{kx} = e^{kx}$，与被积函数一致，故结论成立。$\blacksquare$

该定理是处理物理、工程与概率论中指数衰减与增长模型的基础工具。例如，放射性衰变模型 $N(t) = N_0 e^{-\lambda t}$ 在时间区间 $[0,T]$ 上的积分给出该时段内的总粒子数量期望。

---

### 实验单元（SymPy）

```python
import sympy as sp

x, k = sp.symbols('x k', real=True)

# 一般形式
print(sp.integrate(sp.exp(k*x), x))          # exp(k*x)/k

# 定积分示例
print(sp.integrate(3*sp.exp(2*x), (x, 0, 2)))  # 3*exp(4)/2 - 3/2
```

运行上述代码，验证符号计算结果与手算结果是否一致。建议修改参数 $k$ 与积分上下限，观察结果的变化规律，加深对公式的直觉认识。

### net_change_theorem (0.0s)

## 净变化定理

**定义。** 设函数 $F(x)$ 在闭区间 $[a, b]$ 上连续可微，且 $F'(x) = f(x)$。则 $F$ 在该区间上的**净变化**（net change）定义为

$$\Delta F = F(b) - F(a).$$

由微积分基本定理，净变化可通过对变化率积分得到：

$$F(b) - F(a) = \int_a^b f(x)\,dx.$$

这一等式即称为**净变化定理**（Net Change Theorem）。其核心思想在于：一个量的总变化量，等于其瞬时变化率在时间（或空间）上的累积之和。

---

**例题。** 设某质点沿直线运动，其速度函数为 $v(t) = 3t^2 - 4t + 1$（单位：m/s），求该质点在 $t \in [1, 3]$ 上的净位移。

设位移函数为 $s(t)$，则 $s'(t) = v(t)$。由净变化定理：

$$\Delta s = s(3) - s(1) = \int_1^3 (3t^2 - 4t + 1)\,dt.$$

逐项积分：

$$\int_1^3 3t^2\,dt = \Big[t^3\Big]_1^3 = 27 - 1 = 26,$$

$$\int_1^3 4t\,dt = \Big[2t^2\Big]_1^3 = 18 - 2 = 16,$$

$$\int_1^3 1\,dt = 3 - 1 = 2.$$

因此 $\Delta s = 26 - 16 + 2 = 12$ 米。需注意，净位移与路程不同——前者为有向量，后者需对 $|v(t)|$ 积分。

---

**关键定理（净变化定理）。** 设 $f$ 在 $[a, b]$ 上可积，$F$ 为 $f$ 的一个原函数，则

$$\int_a^b f(x)\,dx = F(b) - F(a).$$

此定理是微积分基本定理第二部分的直接推论，将微分与积分统一为互逆运算，是分析学的核心支柱之一。

---

**实验单元（SymPy）。**

```python
from sympy import symbols, integrate, Rational

t = symbols('t')
v = 3*t**2 - 4*t + 1

net_displacement = integrate(v, (t, 1, 3))
print("净位移：", net_displacement)  # 输出：12
```

运行以上代码，可验证上述手算结果。读者可尝试修改速度函数或积分区间，观察净变化如何随参数变化。

### price_demand_application (19.4s)

## Price Demand Application

### 定义

**需求函数**描述商品价格与市场需求量之间的关系。设 $p$ 为单价（元），$q$ 为需求量（件），则需求函数记作 $q = D(p)$，通常满足 $D'(p) < 0$，即价格上升时需求下降。在经济分析中，**价格弹性**（price elasticity of demand）是衡量需求对价格变化敏感程度的核心指标，定义为

$$\varepsilon(p) = \frac{dq}{dp} \cdot \frac{p}{q} = \frac{p}{D(p)} \cdot D'(p).$$

当 $|\varepsilon| > 1$ 时称需求**富有弹性**；当 $|\varepsilon| < 1$ 时称需求**缺乏弹性**；当 $|\varepsilon| = 1$ 时称**单位弹性**。

### 例题

设某商品的需求函数为 $q = D(p) = 200 - 4p$，其中 $0 \le p \le 50$。

**（1）求价格为 $p = 30$ 时的需求弹性。**

首先，$D'(p) = -4$，且 $D(30) = 200 - 120 = 80$。代入弹性公式：

$$\varepsilon(30) = \frac{30}{80} \cdot (-4) = -\frac{3}{2}.$$

由于 $|\varepsilon(30)| = 1.5 > 1$，需求富有弹性，此时适当降价可增加总收益。

**（2）确定使总收益 $R(p) = p \cdot D(p)$ 最大的价格。**

$$R(p) = p(200 - 4p) = 200p - 4p^2.$$

令 $R'(p) = 200 - 8p = 0$，解得 $p^* = 25$，对应最大收益 $R(25) = 200 \times 25 - 4 \times 625 = 2500$ 元。

### 关键定理

**收益与弹性定理**：设 $R(p) = p \cdot D(p)$，则

$$R'(p) = D(p)\bigl[1 + \varepsilon(p)\bigr].$$

**证明概要**：由乘积法则，$R'(p) = D(p) + p D'(p) = D(p)\!\left(1 + \frac{p D'(p)}{D(p)}\right) = D(p)[1+\varepsilon(p)]$。$\square$

推论：当 $\varepsilon(p) = -1$（单位弹性）时，$R'(p) = 0$，总收益达到极值。

### 实验单元（SymPy）

```python
from sympy import *
p = symbols('p', positive=True)
D = 200 - 4*p
R = p * D
epsilon = diff(D, p) * p / D
print("弹性 ε(p) =", simplify(epsilon))
print("R'(p) =", diff(R, p))
p_star = solve(diff(R, p), p)
print("最优价格 p* =", p_star, "，最大收益 R =", R.subs(p, p_star[0]))
```

### outcome (0.0s)

## 结果

**定义。** 设 $\Omega$ 为一随机试验的**样本空间**，即该试验所有可能结局的集合。其中每一个元素 $\omega \in \Omega$ 称为一个**基本结果**（outcome），它是不可再分的最小观测单元。形式上，若试验进行一次，则恰好实现 $\Omega$ 中的唯一一个元素。

更精确地，三元组 $(\Omega, \mathcal{F}, P)$ 构成一个**概率空间**，其中 $\mathcal{F} \subseteq 2^{\Omega}$ 是 $\sigma$-代数，$P: \mathcal{F} \to [0,1]$ 是满足 Kolmogorov 公理的概率测度。单个结果 $\omega$ 本身满足

$$
P(\{\omega\}) \geq 0, \qquad \sum_{\omega \in \Omega} P(\{\omega\}) = 1 \quad (\text{当 } \Omega \text{ 为可数集时}),
$$

而对于连续样本空间，则以积分代替求和。

---

**例题。** 掷一枚均匀六面骰子。样本空间为

$$
\Omega = \{1, 2, 3, 4, 5, 6\},
$$

共 6 个基本结果。由对称性，每个结果的概率相等：

$$
P(\{\omega\}) = \frac{1}{6}, \quad \forall\, \omega \in \Omega.
$$

事件"掷出偶数"可表示为集合 $A = \{2, 4, 6\} \subset \Omega$，故

$$
P(A) = P(\{2\}) + P(\{4\}) + P(\{6\}) = \frac{1}{6} + \frac{1}{6} + \frac{1}{6} = \frac{1}{2}.
$$

此处 $A$ 是三个基本结果的并，体现了事件由结果聚合而成的层次结构。

---

**关键定理（单点集的测度性）。** 设 $(\Omega, \mathcal{F}, P)$ 为概率空间且 $\Omega$ 可数。则对任意 $\omega \in \Omega$，单点集 $\{\omega\} \in \mathcal{F}$，且

$$
P(A) = \sum_{\omega \in A} P(\{\omega\}), \quad \forall\, A \in \mathcal{F}.
$$

**证明概要：** 由 $\sigma$-代数对可数并封闭，$\{\omega\} = \bigcap_{n=1}^{\infty} A_n$（适当选取 $A_n \in \mathcal{F}$）属于 $\mathcal{F}$；再由 $P$ 的可数可加性，对互不相交的单点集求和即得。$\blacksquare$

---

**实验单元（SymPy）**

```python
from sympy.stats import Die, P, Eq
from sympy import Rational

D = Die('D', 6)                        # 定义均匀六面骰子
for face in range(1, 7):
    print(f"P(D={face}) =", P(Eq(D, face)))   # 每个基本结果的概率

even_prob = P(Eq(D % 2, 0))           # 事件"偶数"的概率
print("P(偶数) =", even_prob)
```

运行上述代码，可验证每个基本结果的概率均为 $\tfrac{1}{6}$，偶数事件概率为 $\tfrac{1}{2}$，与理论完全吻合。

### sample_space (0.0s)

## 样本空间

**定义。** 设某随机试验 $\mathcal{E}$ 为一可重复的观测过程，其所有可能结果的全体构成一个集合，称为该试验的**样本空间**（sample space），记作 $\Omega$。$\Omega$ 中的每个元素 $\omega$ 称为一个**样本点**（sample point）或**基本结果**。若 $|\Omega| < \infty$，则称 $\Omega$ 为**有限样本空间**；若 $\Omega$ 可列无穷，则为**可列无穷样本空间**；若 $\Omega$ 不可列，则为**不可列样本空间**。

**具体示例。** 考虑同时掷两枚均匀硬币的试验，每枚硬币的结果为正面（H）或反面（T）。按顺序记录两枚硬币的结果，则样本空间为

$$
\Omega = \{(H,H),\,(H,T),\,(T,H),\,(T,T)\},
$$

共 $|\Omega| = 4$ 个样本点。若改为记录正面朝上的枚数，则样本空间变为 $\Omega' = \{0, 1, 2\}$，这提示我们：**样本空间的选取依赖于所关注的信息粒度**，同一物理试验可对应不同的数学样本空间。再考虑测量某零件长度（单位：mm）的连续试验，若长度理论上可取任意正值，则 $\Omega = (0, +\infty)$，为不可列样本空间。

**关键定理（样本空间的代数结构）。** 设 $\Omega$ 为样本空间，$\mathcal{F}$ 为 $\Omega$ 上满足以下条件的集族：(i) $\Omega \in \mathcal{F}$；(ii) 若 $A \in \mathcal{F}$，则 $A^c \in \mathcal{F}$；(iii) 若 $A_1, A_2, \ldots \in \mathcal{F}$，则 $\bigcup_{i=1}^{\infty} A_i \in \mathcal{F}$。则称 $(\Omega, \mathcal{F})$ 为**可测空间**，$\mathcal{F}$ 为 $\sigma$-代数。在此结构上定义概率测度 $P: \mathcal{F} \to [0,1]$，三元组 $(\Omega, \mathcal{F}, P)$ 构成概率空间，这是现代概率论的公理化基础。

**实验单元（SymPy）。**

```python
from sympy import FiniteSet, symbols

# 两枚硬币的样本空间
outcomes = [('H','H'), ('H','T'), ('T','H'), ('T','T')]
Omega = FiniteSet(*outcomes)

print("样本空间 Ω =", Omega)
print("样本点个数 |Ω| =", len(Omega))

# 事件：至少一枚正面
event_A = FiniteSet(*[o for o in outcomes if 'H' in o])
print("事件 A（至少一枚H）=", event_A)
print("P(A) =", len(event_A) / len(Omega))
```

### event (0.0s)

## 事件

**定义．** 设 $\Omega$ 为一随机试验的**样本空间**，即所有可能结果的全体。$\Omega$ 的任意子集 $A \subseteq \Omega$ 称为一个**事件**。若试验结果 $\omega \in A$，则称事件 $A$ **发生**；若 $\omega \notin A$，则称 $A$ **不发生**。特别地，$\Omega$ 本身称为**必然事件**，空集 $\emptyset$ 称为**不可能事件**。在可测空间框架下，事件须属于某一 $\sigma$-代数 $\mathcal{F}$，以保证概率的可加性得以严格定义。

**集合运算与事件的对应．** 事件之间的逻辑关系与集合运算一一对应：

$$A \cup B \quad \text{（$A$ 或 $B$ 至少之一发生）}, \qquad A \cap B \quad \text{（$A$ 与 $B$ 同时发生）}, \qquad A^c = \Omega \setminus A \quad \text{（$A$ 不发生）}.$$

若 $A \cap B = \emptyset$，则称 $A$ 与 $B$ **互斥**（互不相容）。

**具体例子．** 掷一枚公平的六面骰子，样本空间为 $\Omega = \{1,2,3,4,5,6\}$。定义事件

$$A = \{\text{出现偶数}\} = \{2,4,6\}, \qquad B = \{\text{出现大于}4的数\} = \{5,6\}.$$

则：

$$A \cup B = \{2,4,5,6\}, \quad A \cap B = \{6\}, \quad A^c = \{1,3,5\}.$$

由于 $A \cap B = \{6\} \neq \emptyset$，故 $A$ 与 $B$ 不互斥。

**关键定理（概率的有限可加性）．** 设 $A_1, A_2, \ldots, A_n$ 两两互斥，则

$$P\!\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} P(A_i).$$

**证明思路：** 由互斥条件 $A_i \cap A_j = \emptyset$（$i \neq j$），各事件对应的样本点不重叠，故其概率（频率极限意义下）可直接相加。完整证明由 Kolmogorov 公理中的 $\sigma$-可加性推出。

**实验单元（SymPy）．**

```python
from sympy import FiniteSet

omega = FiniteSet(1, 2, 3, 4, 5, 6)
A = FiniteSet(2, 4, 6)          # 偶数
B = FiniteSet(5, 6)             # 大于4

print("A ∪ B =", A.union(B))
print("A ∩ B =", A.intersect(B))
print("Aᶜ    =", omega - A)
print("互斥？ ", A.intersect(B) == FiniteSet())
```

运行此单元，可直观验证上述集合运算结果，并将 $\Omega$ 替换为任意有限样本空间以探索更复杂的事件结构。

### probability (0.0s)

## 概率

**定义。** 设 $\Omega$ 为一个非空集合，称为**样本空间**，其元素称为**基本事件**。$\mathcal{F}$ 是 $\Omega$ 的子集所构成的 $\sigma$-代数，其元素称为**事件**。**概率测度** $P: \mathcal{F} \to [0,1]$ 是满足以下柯尔莫哥洛夫公理的函数：

1. **非负性**：对任意事件 $A \in \mathcal{F}$，有 $P(A) \geq 0$；
2. **规范性**：$P(\Omega) = 1$；
3. **可数可加性**：若 $A_1, A_2, \ldots \in \mathcal{F}$ 两两不相交，则

$$P\!\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i).$$

三元组 $(\Omega, \mathcal{F}, P)$ 称为**概率空间**。

---

**例题。** 掷一枚均匀骰子，样本空间为 $\Omega = \{1, 2, 3, 4, 5, 6\}$，每个基本事件的概率均为 $\tfrac{1}{6}$。设事件 $A = \{\text{出现偶数}\} = \{2, 4, 6\}$，则由可数可加性得

$$P(A) = P(\{2\}) + P(\{4\}) + P(\{6\}) = \frac{1}{6} + \frac{1}{6} + \frac{1}{6} = \frac{1}{2}.$$

---

**关键定理（容斥原理）。** 对任意两个事件 $A, B \in \mathcal{F}$，有

$$P(A \cup B) = P(A) + P(B) - P(A \cap B).$$

**证明概要。** 将 $A \cup B$ 分拆为三个两两不相交的部分：$A \setminus B$、$B \setminus A$ 与 $A \cap B$。由可数可加性，$P(A) = P(A \setminus B) + P(A \cap B)$，$P(B) = P(B \setminus A) + P(A \cap B)$，两式相加后减去重复计入的 $P(A \cap B)$ 即得结论。$\blacksquare$

---

**实验单元（SymPy）。**

```python
from sympy import Rational, symbols
from sympy.stats import Die, P as prob, Gt

X = Die('X', 6)                          # 均匀六面骰子
p_even = prob(X % 2 | X, True)          # 偶数事件概率
A = prob(X > 2)                          # P(X > 2)
B = prob(X > 4)                          # P(X > 4)
print("P(偶数) =", prob(X % 2 == 0))    # 期望输出：1/2
print("P(X>2) =", A, "  P(X>4) =", B)
```

运行后应输出 $P(\text{偶数}) = \tfrac{1}{2}$，$P(X > 2) = \tfrac{2}{3}$，$P(X > 4) = \tfrac{1}{3}$，与手算结果一致，从而验证概率公理的数值实现。

### and_event (18.6s)

## And Event

**定义．** 设 $(\Omega, \mathcal{F}, P)$ 为一概率空间，$A, B \in \mathcal{F}$ 为两个事件。**积事件**（又称**交事件**）定义为

$$
A \cap B \;=\; \{\omega \in \Omega : \omega \in A \text{ 且 } \omega \in B\},
$$

即样本点 $\omega$ 同时属于 $A$ 与 $B$ 时所构成的事件。若 $A \cap B = \varnothing$，则称 $A$ 与 $B$ **互斥**（不相容）。积事件可推广至有限或可数无穷族：$\bigcap_{i=1}^{n} A_i$ 表示所有 $A_i$ 同时发生的事件。

---

**典型例题．** 掷一枚标准骰子一次，样本空间为 $\Omega = \{1,2,3,4,5,6\}$。令

$$
A = \{\text{点数为偶数}\} = \{2,4,6\}, \qquad B = \{\text{点数大于 }3\} = \{4,5,6\}.
$$

则

$$
A \cap B = \{4,6\}.
$$

若骰子均匀，每个基本事件概率均为 $\tfrac{1}{6}$，故

$$
P(A \cap B) = \frac{|A \cap B|}{|\Omega|} = \frac{2}{6} = \frac{1}{3}.
$$

---

**关键定理（容斥原理）．** 对任意 $A, B \in \mathcal{F}$，

$$
P(A \cup B) = P(A) + P(B) - P(A \cap B).
$$

**证明思路：** 将 $A \cup B$ 分解为三个两两互斥的部分：$A \setminus B$、$A \cap B$、$B \setminus A$，利用概率的可列可加性分别求和，再化简即得。此公式揭示：若直接相加 $P(A)+P(B)$，则 $A \cap B$ 中的概率被计算了两次，故须减去一次 $P(A \cap B)$。

---

**实验单元（SymPy）．**

```python
from sympy import FiniteSet, Rational

Omega = FiniteSet(1, 2, 3, 4, 5, 6)
A = FiniteSet(2, 4, 6)
B = FiniteSet(4, 5, 6)

A_and_B = A.intersect(B)          # {4, 6}
prob = Rational(len(A_and_B), len(Omega))
print(f"A ∩ B = {A_and_B},  P(A ∩ B) = {prob}")  # 1/3
```

运行上述代码，可验证 $P(A \cap B) = \tfrac{1}{3}$，并可自行修改集合 $A$、$B$，观察积事件随定义变化的规律。

### complement_event (19.8s)

## 补事件

**定义** 设 $\Omega$ 为某随机试验的样本空间，$A$ 为 $\Omega$ 的一个事件（即 $A \subseteq \Omega$）。$A$ 的**补事件**（complement event），记作 $\bar{A}$ 或 $A^c$，定义为

$$\bar{A} = \Omega \setminus A = \{\omega \in \Omega \mid \omega \notin A\}.$$

直观上，$\bar{A}$ 包含所有"$A$ 不发生"时所对应的结果。补事件满足以下基本恒等式：

$$A \cup \bar{A} = \Omega, \qquad A \cap \bar{A} = \varnothing,$$

即 $A$ 与 $\bar{A}$ 构成样本空间的一个**划分**（partition）。

---

**例题** 掷一枚均匀六面骰子，样本空间为 $\Omega = \{1, 2, 3, 4, 5, 6\}$。设事件 $A = \{2, 4, 6\}$（掷出偶数）。则

$$\bar{A} = \{1, 3, 5\},$$

即"掷出奇数"。由于骰子均匀，每个基本结果的概率均为 $\tfrac{1}{6}$，因此

$$P(A) = \frac{3}{6} = \frac{1}{2}, \qquad P(\bar{A}) = \frac{3}{6} = \frac{1}{2}.$$

验证：$P(A) + P(\bar{A}) = 1$，与下述定理一致。

---

**关键定理（补概率公式）** 设 $P$ 为 $\Omega$ 上的概率测度，$A \subseteq \Omega$，则

$$P(\bar{A}) = 1 - P(A).$$

**证明概要** 由于 $A$ 与 $\bar{A}$ 互不相交且 $A \cup \bar{A} = \Omega$，由概率的可加性公理得

$$P(A) + P(\bar{A}) = P(\Omega) = 1,$$

移项即得 $P(\bar{A}) = 1 - P(A)$。$\blacksquare$

补概率公式在实践中极为有用：当直接计算 $P(A)$ 较为繁琐，而 $P(\bar{A})$ 更易求得时（例如"至少发生一次"与"一次也不发生"之间的转换），往往借助此公式间接求解。

---

**实验室代码（SymPy）**

```python
from sympy import FiniteSet, Rational

Omega = FiniteSet(1, 2, 3, 4, 5, 6)
A = FiniteSet(2, 4, 6)
A_bar = Omega - A          # 补事件

P_A     = Rational(len(A),     len(Omega))
P_A_bar = Rational(len(A_bar), len(Omega))

print(f"A      = {A}")
print(f"Ā      = {A_bar}")
print(f"P(A)   = {P_A}")
print(f"P(Ā)   = {P_A_bar}")
print(f"P(A)+P(Ā) = {P_A + P_A_bar}")   # 应输出 1
```

运行上述单元格，可验证 $P(A) + P(\bar{A}) = 1$ 恒成立，从而直观体会补概率公式的正确性。

### or_event (17.3s)

## Or Event

**定义**

设样本空间为 $\Omega$，$A$ 与 $B$ 为其上的两个事件。**并事件**（或事件）定义为

$$A \cup B = \{\omega \in \Omega \mid \omega \in A \text{ 或 } \omega \in B\}$$

即：只要结果 $\omega$ 属于 $A$、属于 $B$，或同时属于两者，事件 $A \cup B$ 就发生。在日常语言中，"$A$ 或 $B$"采用**逻辑或**的含义，允许两者同时成立。

**典型例子**

掷一枚均匀六面骰子，样本空间为 $\Omega = \{1,2,3,4,5,6\}$。令

$$A = \{\text{结果为偶数}\} = \{2,4,6\}, \quad B = \{\text{结果大于 4}\} = \{5,6\}.$$

则

$$A \cup B = \{2,4,5,6\}.$$

事件 $A \cup B$ 表示"骰子点数为偶数，或点数大于 4"。注意 $6 \in A \cap B$，它被计入 $A \cup B$ 一次，而非两次——集合的并运算天然避免重复计数。

**关键定理：加法公式**

对任意两个事件 $A$ 与 $B$，

$$\boxed{P(A \cup B) = P(A) + P(B) - P(A \cap B).}$$

**证明思路**：将 $A \cup B$ 分解为三个互不相交的部分：$A \setminus B$、$A \cap B$、$B \setminus A$。对各部分分别应用概率的可加性，再合并，即得上式。当 $A \cap B = \varnothing$（互斥事件）时，公式退化为 $P(A \cup B) = P(A) + P(B)$。

以上例为例：$P(A)=\tfrac{3}{6}$，$P(B)=\tfrac{2}{6}$，$P(A\cap B)=P(\{6\})=\tfrac{1}{6}$，故

$$P(A\cup B)=\frac{3}{6}+\frac{2}{6}-\frac{1}{6}=\frac{4}{6}=\frac{2}{3}.$$

**实验室单元（SymPy）**

```python
from sympy import FiniteSet, Rational

Omega = FiniteSet(1, 2, 3, 4, 5, 6)
A = FiniteSet(2, 4, 6)
B = FiniteSet(5, 6)

AuB = A.union(B)
print("A ∪ B =", AuB)

P = lambda E: Rational(len(E), len(Omega))
print("P(A ∪ B) =", P(AuB))
print("加法公式验证:", P(A) + P(B) - P(A.intersect(B)))
```

运行结果应输出 $A \cup B = \{2,4,5,6\}$ 且两种计算均给出 $\tfrac{2}{3}$，从而以计算实验验证加法公式。

### venn_diagram (18.3s)

## Venn 图

### 定义

设 $U$ 为全集（universal set），即讨论范围内所有元素的集合。**Venn 图**（维恩图）是一种用封闭曲线（通常为圆形）在矩形框内直观表示集合及其关系的图示工具。每个圆代表一个集合，圆内区域表示该集合的元素，矩形框代表全集 $U$。

对于两个集合 $A, B \subseteq U$，Venn 图将平面划分为四个互不相交的区域：

$$A \setminus B, \quad B \setminus A, \quad A \cap B, \quad U \setminus (A \cup B)$$

其中 $A \setminus B = A \cap B^c$ 表示属于 $A$ 但不属于 $B$ 的元素之集合，$B^c = U \setminus B$ 为 $B$ 的补集。

### 具体示例

设 $U = \{1, 2, 3, 4, 5, 6, 7, 8\}$，$A = \{1, 2, 3, 4\}$，$B = \{3, 4, 5, 6\}$。

在 Venn 图中，各区域的元素如下：

- 仅属于 $A$：$A \setminus B = \{1, 2\}$
- 仅属于 $B$：$B \setminus A = \{5, 6\}$
- 同属两者：$A \cap B = \{3, 4\}$
- 两者均不属于：$U \setminus (A \cup B) = \{7, 8\}$

由此可验证：$|A \cup B| = |A| + |B| - |A \cap B| = 4 + 4 - 2 = 6$，与直接计数 $\{1,2,3,4,5,6\}$ 一致。

### 核心定理：容斥原理

**定理**（两集合容斥原理）：设 $A, B$ 为有限集，则

$$|A \cup B| = |A| + |B| - |A \cap B|$$

**证明思路**：在计算 $|A| + |B|$ 时，$A \cap B$ 中的元素被重复计数两次，故需减去一次 $|A \cap B|$，即得等式。此原理可推广至 $n$ 个集合：

$$\left|\bigcup_{i=1}^{n} A_i\right| = \sum_{i}|A_i| - \sum_{i<j}|A_i \cap A_j| + \cdots + (-1)^{n+1}|A_1 \cap \cdots \cap A_n|$$

### 实验单元（SymPy）

```python
from sympy import FiniteSet

U = FiniteSet(1, 2, 3, 4, 5, 6, 7, 8)
A = FiniteSet(1, 2, 3, 4)
B = FiniteSet(3, 4, 5, 6)

print("A ∩ B =", A.intersect(B))          # {3, 4}
print("A ∪ B =", A.union(B))              # {1, 2, 3, 4, 5, 6}
print("A \\ B =", A - B)                  # {1, 2}
print("|A ∪ B| =", len(A.union(B)))       # 6
# 验证容斥原理
assert len(A.union(B)) == len(A) + len(B) - len(A.intersect(B))
```

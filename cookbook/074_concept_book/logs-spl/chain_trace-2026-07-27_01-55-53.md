### limit (0.0s)

## 极限

**定义**

设函数 $f$ 定义在点 $a$ 的某个去心邻域内。若对任意 $\varepsilon > 0$，存在 $\delta > 0$，使得当 $0 < |x - a| < \delta$ 时，均有

$$|f(x) - L| < \varepsilon,$$

则称 $L$ 为 $f(x)$ 在 $x \to a$ 时的**极限**，记作

$$\lim_{x \to a} f(x) = L.$$

此定义（称为 $\varepsilon$-$\delta$ 定义）的核心在于：无论我们对 $f(x)$ 与 $L$ 之间的误差要求多么严苛（即 $\varepsilon$ 多么小），总能找到一个充分小的 $\delta$，使 $x$ 足够接近 $a$ 时误差得到控制。注意，$x = a$ 处 $f$ 是否有定义与极限值无关。

**例题**

证明 $\displaystyle\lim_{x \to 2}(3x - 1) = 5$。

**证明**：需要对给定的 $\varepsilon > 0$ 找到合适的 $\delta$。计算

$$|f(x) - 5| = |(3x - 1) - 5| = |3x - 6| = 3|x - 2|.$$

要使 $3|x - 2| < \varepsilon$，只需 $|x - 2| < \dfrac{\varepsilon}{3}$。故取 $\delta = \dfrac{\varepsilon}{3}$，则当 $0 < |x - 2| < \delta$ 时，

$$|f(x) - 5| = 3|x - 2| < 3\delta = \varepsilon. \qquad \square$$

**关键定理（极限的唯一性）**

若 $\displaystyle\lim_{x \to a} f(x)$ 存在，则其值唯一。

**证明思路**：设 $\lim_{x\to a}f(x)=L$ 且 $\lim_{x\to a}f(x)=M$，$L\neq M$。取 $\varepsilon=\dfrac{|L-M|}{2}>0$，则由定义可得

$$|L - M| \leq |f(x)-L| + |f(x)-M| < \varepsilon + \varepsilon = |L-M|,$$

矛盾，故 $L = M$。$\square$

**实验单元（SymPy）**

```python
from sympy import symbols, limit, oo

x = symbols('x')

# 验证上述例题
print(limit(3*x - 1, x, 2))          # 输出: 5

# 探索经典极限
print(limit((1 + 1/x)**x, x, oo))    # 输出: E（即自然常数 e）
print(limit(sin(x)/x, x, 0))         # 输出: 1
```

运行以上代码，观察 SymPy 如何通过符号运算直接给出极限值，从而验证 $\varepsilon$-$\delta$ 推导的正确性。

### continuity_at_a_point (16.6s)

## Continuity At A Point

**定义。** 设函数 $f$ 在点 $a$ 的某邻域内有定义。若

$$\lim_{x \to a} f(x) = f(a),$$

则称 $f$ 在点 $a$ **连续**。用 $\varepsilon$-$\delta$ 语言表述：对任意 $\varepsilon > 0$，存在 $\delta > 0$，使得当 $|x - a| < \delta$ 时，有 $|f(x) - f(a)| < \varepsilon$。

该定义包含三个隐含条件：$f(a)$ 必须有定义；极限 $\lim_{x \to a} f(x)$ 必须存在；极限值必须等于函数值。任一条件不满足，$f$ 在 $a$ 处即称为**不连续**。

---

**典型例题。** 判断函数

$$f(x) = \begin{cases} \dfrac{x^2 - 1}{x - 1}, & x \neq 1, \\ 3, & x = 1 \end{cases}$$

在 $x = 1$ 处是否连续。

**解。** 当 $x \neq 1$ 时，

$$f(x) = \frac{(x-1)(x+1)}{x-1} = x + 1.$$

故 $\lim_{x \to 1} f(x) = 1 + 1 = 2$。然而 $f(1) = 3 \neq 2$，极限存在但不等于函数值，因此 $f$ 在 $x = 1$ 处**不连续**，此类不连续称为**可去间断点**，只需令 $f(1) = 2$ 即可修复。

---

**关键定理（连续函数的代数运算）。** 若 $f$ 与 $g$ 在点 $a$ 处连续，则 $f + g$、$f - g$、$fg$ 及（当 $g(a) \neq 0$ 时）$f/g$ 均在 $a$ 处连续。进一步，若 $g$ 在 $a$ 处连续且 $f$ 在 $g(a)$ 处连续，则复合函数 $f \circ g$ 在 $a$ 处连续。

这一定理保证了所有多项式函数在实数轴上处处连续，有理函数在分母不为零的点处连续。

---

**实验室练习（SymPy）。**

```python
from sympy import symbols, limit, Piecewise, Eq

x = symbols('x')
f = Piecewise(((x**2 - 1)/(x - 1), x != 1), (3, True))

lim_val = limit(f, x, 1)        # 计算极限
f_at_1  = f.subs(x, 1)          # 计算函数值
print("极限值:", lim_val)        # 输出 2
print("函数值:", f_at_1)         # 输出 3
print("连续?", Eq(lim_val, f_at_1))  # 输出 False
```

运行上述代码，观察极限值与函数值之差，理解可去间断点的本质。将 `3` 改为 `2`，重新运行，验证连续性条件得到满足。

### continuity_over_an_interval (17.2s)

## Continuity Over An Interval

**定义**

设函数 $f$ 在区间 $I$ 上有定义。若对 $I$ 内部的每一点 $c$，均有

$$\lim_{x \to c} f(x) = f(c),$$

则称 $f$ 在 $I$ 的内部连续。对于闭区间 $[a, b]$，还需补充端点处的单侧条件：

$$\lim_{x \to a^+} f(x) = f(a), \qquad \lim_{x \to b^-} f(x) = f(b).$$

满足上述所有条件时，称 $f$ 在闭区间 $[a,b]$ 上连续，记作 $f \in C[a,b]$。

**例题**

考察 $f(x) = \sqrt{x}$ 在 $[0, 4]$ 上的连续性。

- 对任意内点 $c \in (0,4)$，由极限运算法则可得 $\lim_{x\to c}\sqrt{x} = \sqrt{c} = f(c)$，故 $f$ 在内部连续。  
- 在左端点 $x=0$：$\lim_{x\to 0^+}\sqrt{x} = 0 = f(0)$，右极限存在且等于函数值。  
- 在右端点 $x=4$：$\lim_{x\to 4^-}\sqrt{x} = 2 = f(4)$，左极限存在且等于函数值。

因此 $f(x)=\sqrt{x}$ 在 $[0,4]$ 上连续，即 $f \in C[0,4]$。

**关键定理**

> **介值定理（Intermediate Value Theorem）**  
> 若 $f \in C[a,b]$，且 $f(a) \neq f(b)$，则对介于 $f(a)$ 与 $f(b)$ 之间的任意值 $k$，存在 $\xi \in (a,b)$ 使得 $f(\xi) = k$。

**证明概要**：不妨设 $f(a) < k < f(b)$。令 $g(x) = f(x) - k$，则 $g(a) < 0 < g(b)$。由连续函数的性质，$g$ 在 $[a,b]$ 上满足确界原理，利用二分逼近构造单调有界序列，其极限 $\xi$ 即满足 $g(\xi)=0$，从而 $f(\xi)=k$。

**实验单元（SymPy）**

```python
from sympy import *
x = symbols('x')
f = sqrt(x)
# 验证内点处的极限
c = Rational(9, 4)
print(limit(f, x, c))          # 输出 3/2
print(f.subs(x, c))            # 输出 3/2
# 介值定理示例：在 [1,4] 上寻找 f(x)=1.5 的根
print(solve(f - Rational(3,2), x))  # 输出 [9/4]
```

通过本节可知，区间连续性是一个整体性质，它将逐点的极限条件统一在整段区间上，并由此推导出介值定理等强大结论，为后续微积分基本定理奠定坚实基础。

### intermediate_value_theorem (17.8s)

## Intermediate Value Theorem

### 定义

设函数 $f$ 在闭区间 $[a, b]$ 上连续，且 $f(a) \neq f(b)$。若 $k$ 是介于 $f(a)$ 与 $f(b)$ 之间的任意实数，即

$$\min\{f(a),\, f(b)\} < k < \max\{f(a),\, f(b)\},$$

则至少存在一点 $c \in (a, b)$，使得 $f(c) = k$。

这一定理的本质在于：连续函数的图像不能"跳跃"——从一个值出发，到达另一个值，必然经过中间的每一个值。正如一个人从海拔 $0$ 米攀登至海拔 $3000$ 米，必然在某一时刻身处海拔 $1500$ 米处。

### 具体例子

考察函数 $f(x) = x^3 - x - 1$，试证明方程 $f(x) = 0$ 在区间 $[1, 2]$ 上有实根。

计算端点处的函数值：

$$f(1) = 1 - 1 - 1 = -1 < 0,$$
$$f(2) = 8 - 2 - 1 = 5 > 0.$$

由于 $f(1) < 0 < f(2)$，而 $f$ 在 $[1, 2]$ 上连续（多项式函数处处连续），由介值定理知，存在 $c \in (1, 2)$ 使得 $f(c) = 0$，即方程在该区间内至少有一个实根。

### 关键定理

**介值定理（正式陈述）**：若 $f \in C[a, b]$（即 $f$ 在 $[a, b]$ 上连续），则 $f$ 在 $[a, b]$ 上的值域包含区间 $[\min\{f(a), f(b)\},\, \max\{f(a), f(b)\}]$。

**证明思路**：令 $S = \{x \in [a,b] : f(x) < k\}$。由 $f(a) < k$ 知 $S$ 非空且有上界 $b$，故上确界 $c = \sup S$ 存在。利用 $f$ 的连续性及上确界的定义，可导出 $f(c) = k$，矛盾假设 $f(c) \neq k$ 将产生逻辑矛盾，故结论成立。

### 实验单元（SymPy）

```python
import sympy as sp

x = sp.Symbol('x')
f = x**3 - x - 1

# 在 [1, 2] 上寻找零点
root = sp.solve(f, x)
numerical_roots = [r.evalf() for r in root if r.is_real]

print("精确根：", root)
print("数值近似：", numerical_roots)

# 验证介值条件
print(f"f(1) = {f.subs(x, 1)},  f(2) = {f.subs(x, 2)}")
```

运行上述代码可验证：方程 $x^3 - x - 1 = 0$ 在 $(1, 2)$ 内确有唯一实根，约为 $x \approx 1.3247$，与介值定理的存在性预测完全吻合。

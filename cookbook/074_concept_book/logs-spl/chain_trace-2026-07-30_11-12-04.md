## Big Data

**Definition.** A dataset is said to exhibit *big data* characteristics when its volume, velocity, or variety (the "three Vs") exceed the processing capacity of conventional single-machine systems. More precisely, let $N$ denote the number of records, $d$ the number of features per record, and $\tau$ the arrival rate (records per second). A dataset is operationally classified as big data when any one of the following conditions holds:

$$N \cdot d > M_{\text{RAM}}, \qquad \tau > \lambda_{\text{disk}}, \qquad \text{or} \quad \dim(\mathcal{S}) \text{ is heterogeneous},$$

where $M_{\text{RAM}}$ is available memory, $\lambda_{\text{disk}}$ is sustainable write throughput, and $\mathcal{S}$ is the schema space. The hallmark challenge is that standard $O(N)$ or $O(N \log N)$ algorithms become infeasible when $N \sim 10^9$ or larger, forcing a shift to distributed or streaming paradigms.

**Worked Example.** Suppose a retailer logs $N = 10^9$ transactions, each described by $d = 50$ floating-point features stored as 64-bit doubles. The raw storage requirement is

$$S = N \cdot d \cdot 8 \text{ bytes} = 10^9 \times 50 \times 8 = 4 \times 10^{11} \text{ bytes} = 400 \text{ GB}.$$

A workstation with 32 GB of RAM cannot load this dataset into memory; a naive pandas `read_csv` call would raise a `MemoryError`. The solution is to partition the data into $k$ shards of size $\lceil N/k \rceil$ each, process each shard independently, and aggregate partial statistics. For the sample mean $\bar{x}$, the aggregation is exact:

$$\bar{x} = \frac{1}{N} \sum_{i=1}^{k} n_i \bar{x}_i, \qquad n_i = \left\lceil \frac{N}{k} \right\rceil.$$

**Key Theorem (Embarrassingly Parallel Reduction).** Let $f: \mathbb{R}^d \to \mathbb{R}$ be a *decomposable* statistic, meaning $f(\mathcal{D}) = g\!\left(f(\mathcal{D}_1), \ldots, f(\mathcal{D}_k)\right)$ for some aggregator $g$. Then the total computation time satisfies $T_k = T_1 / k + T_{\text{comm}}$, where $T_{\text{comm}}$ is network overhead. When $T_{\text{comm}} \ll T_1$, near-linear speedup is achieved. Sum, count, min, max, and histogram bin counts are all decomposable; median and exact quantiles are not.

**Lab Cell.**

```python
import sympy as sp

N, k, n_i = sp.symbols('N k n_i', positive=True)
x_bar_i   = sp.Symbol(r'\bar{x}_i')

# Symbolic mean aggregation formula
x_bar_global = sp.Rational(1, 1) * sp.Sum(n_i * x_bar_i, (sp.Symbol('i'), 1, k)) / N
sp.pprint(sp.Eq(sp.Symbol(r'\bar{x}'), x_bar_global))

# Concrete shard size example
shard_size = sp.ceiling(sp.Integer(10**9) / 32)
print(f"Records per shard (32 shards): {shard_size}")
```

## Machine Learning Model

**Definition.** A *machine learning model* is a parametric function $f_{\boldsymbol{\theta}} : \mathcal{X} \to \mathcal{Y}$, where $\mathcal{X} \subseteq \mathbb{R}^d$ is the input space, $\mathcal{Y}$ is the output space, and $\boldsymbol{\theta} \in \Theta \subseteq \mathbb{R}^p$ is a vector of learnable parameters. Given a dataset $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^{n}$, learning consists of finding parameters $\boldsymbol{\theta}^*$ that minimize an empirical loss functional

$$\boldsymbol{\theta}^* = \arg\min_{\boldsymbol{\theta} \in \Theta} \frac{1}{n} \sum_{i=1}^{n} \mathcal{L}\!\left(f_{\boldsymbol{\theta}}(\mathbf{x}_i),\, y_i\right),$$

where $\mathcal{L} : \mathcal{Y} \times \mathcal{Y} \to \mathbb{R}_{\geq 0}$ is a loss function measuring discrepancy between predictions and targets. The model family (e.g., linear, polynomial, neural network) determines the hypothesis class $\mathcal{H} = \{f_{\boldsymbol{\theta}} : \boldsymbol{\theta} \in \Theta\}$.

**Worked Example.** Consider simple linear regression, where $\mathcal{X} = \mathbb{R}$, $\mathcal{Y} = \mathbb{R}$, and $f_{\boldsymbol{\theta}}(x) = \theta_1 x + \theta_0$. With squared loss $\mathcal{L}(\hat{y}, y) = (\hat{y} - y)^2$, the empirical risk becomes

$$R(\theta_0, \theta_1) = \frac{1}{n}\sum_{i=1}^{n}(\theta_1 x_i + \theta_0 - y_i)^2.$$

Setting $\partial R / \partial \theta_0 = 0$ and $\partial R / \partial \theta_1 = 0$ yields the closed-form ordinary least-squares solution:

$$\theta_1^* = \frac{\sum_i (x_i - \bar{x})(y_i - \bar{y})}{\sum_i (x_i - \bar{x})^2}, \qquad \theta_0^* = \bar{y} - \theta_1^* \bar{x},$$

where $\bar{x}$ and $\bar{y}$ denote sample means.

**Key Theorem (Bias–Variance Decomposition).** For any model $f_{\boldsymbol{\theta}}$ trained on a random dataset, the expected squared prediction error at a point $\mathbf{x}$ decomposes as

$$\mathbb{E}\!\left[(y - f_{\boldsymbol{\theta}}(\mathbf{x}))^2\right] = \underbrace{\mathrm{Bias}^2[f_{\boldsymbol{\theta}}(\mathbf{x})]}_{\text{systematic error}} + \underbrace{\mathrm{Var}[f_{\boldsymbol{\theta}}(\mathbf{x})]}_{\text{estimation variance}} + \underbrace{\sigma^2}_{\text{irreducible noise}}.$$

This result implies a fundamental trade-off: richer hypothesis classes reduce bias but increase variance, motivating regularization techniques such as ridge regression, which augments the loss with a penalty $\lambda\|\boldsymbol{\theta}\|_2^2$.

**Lab Cell.**
```python
from sympy import symbols, diff, solve, Rational, simplify

x, y_sym, t0, t1 = symbols('x y t0 t1')
# Toy dataset: three points
data = [(1, 2), (2, 3), (3, 5)]
n = len(data)

R = sum((t1*xi + t0 - yi)**2 for xi, yi in data) / n
dR_dt0 = diff(R, t0)
dR_dt1 = diff(R, t1)
solution = solve([dR_dt0, dR_dt1], [t0, t1])
print("OLS solution:", solution)
# Verify: f(x) = solution[t1]*x + solution[t0]
f = solution[t1]*x + solution[t0]
print("Fitted line:", simplify(f))
```

## Data Mining

**Definition.** *Data mining* is the computational process of discovering structural patterns, statistical regularities, and predictive relationships in large datasets by combining methods from statistics, machine learning, and database theory. Formally, given a dataset $\mathcal{D} = \{x_1, x_2, \ldots, x_n\} \subset \mathbb{R}^d$, data mining seeks a model $f : \mathbb{R}^d \to \mathcal{Y}$ — or a set of rules $\mathcal{R}$ — that compactly describes the generating distribution $P(\mathbf{x})$ or a conditional distribution $P(y \mid \mathbf{x})$, where $y \in \mathcal{Y}$ is a target variable. The discipline is distinguished from pure statistics by its emphasis on scalability: algorithms must remain tractable as $n$ and $d$ grow to millions.

**Worked Example.** Consider a retail dataset of $n = 10{,}000$ transactions, each a binary vector $\mathbf{x} \in \{0,1\}^{500}$ indicating which of 500 products were purchased together. A foundational task is *association rule mining*: find pairs $(A, B)$ of item sets such that the *support*

$$\text{supp}(A \Rightarrow B) = \frac{|\{\mathbf{x} \in \mathcal{D} : A \cup B \subseteq \mathbf{x}\}|}{n}$$

exceeds a threshold $\sigma$, and the *confidence*

$$\text{conf}(A \Rightarrow B) = \frac{\text{supp}(A \cup B)}{\text{supp}(A)}$$

exceeds a threshold $\gamma$. Setting $\sigma = 0.02$ and $\gamma = 0.60$ might reveal, for example, that customers who purchase bread and butter also purchase jam with 63% confidence — an actionable insight for shelf placement.

**Key Theorem (Apriori Anti-Monotonicity).** If an item set $S$ has $\text{supp}(S) < \sigma$, then every superset $S' \supset S$ satisfies $\text{supp}(S') \leq \text{supp}(S) < \sigma$. This monotonicity of the support measure allows the Apriori algorithm to prune the exponential search space $2^{500}$ by discarding all extensions of low-support sets, reducing practical complexity to a manageable breadth-first traversal over frequent item sets only.

**Lab Cell.**

```python
from sympy import Rational

transactions = [
    {"bread", "butter", "jam"},
    {"bread", "butter"},
    {"bread", "jam"},
    {"butter", "jam"},
    {"bread", "butter", "jam"},
]

n = len(transactions)
supp_AB  = sum(1 for t in transactions if {"bread","butter"} <= t) / n
supp_ABC = sum(1 for t in transactions if {"bread","butter","jam"} <= t) / n
conf     = Rational(int(supp_ABC * n), int(supp_AB * n))

print(f"supp(bread ∧ butter) = {supp_AB}")
print(f"conf(bread,butter ⇒ jam) = {conf}")
```

Running this cell yields $\text{conf} = \tfrac{2}{3} \approx 0.667$, confirming the rule at a 60% threshold.

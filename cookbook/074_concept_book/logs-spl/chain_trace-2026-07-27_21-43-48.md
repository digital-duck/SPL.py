### flow_network (35.6s)

## Flow Network

**Definition.** A *flow network* is a directed graph $G = (V, E)$ equipped with a non-negative *capacity function* $c : E \to \mathbb{R}_{\geq 0}$, a designated *source* $s \in V$, and a designated *sink* $t \in V$. Given such a network, a *flow* is any assignment $f : E \to \mathbb{R}_{\geq 0}$ that obeys two rules at every edge and every interior vertex:

1. **Capacity constraint:** $0 \leq f(u,v) \leq c(u,v)$ for every edge $(u,v) \in E$.
2. **Flow conservation:** For every vertex $v \in V \setminus \{s, t\}$, total inflow equals total outflow:
$$\sum_{u:(u,v)\in E} f(u,v) \;=\; \sum_{w:(v,w)\in E} f(v,w).$$

The *value* of a flow is the net amount leaving the source: $|f| = \sum_{w:(s,w)\in E} f(s,w) - \sum_{u:(u,s)\in E} f(u,s)$.

**Worked Example.** Take $V = \{s, A, B, t\}$ with capacities $c(s,A)=3$, $c(s,B)=2$, $c(A,t)=2$, $c(B,t)=3$, $c(A,B)=1$. Set $f(s,A)=3$, $f(s,B)=2$, $f(A,t)=2$, $f(A,B)=1$, $f(B,t)=3$. At vertex $A$: inflow $= 3$, outflow $= 2 + 1 = 3$ ✓. At vertex $B$: inflow $= 2 + 1 = 3$, outflow $= 3$ ✓. Each edge respects its capacity, and $|f| = 3 + 2 = 5$.

**Key Theorem (Max-Flow Min-Cut).** The maximum achievable flow value from $s$ to $t$ equals the minimum total capacity of any set of edges whose removal disconnects $s$ from $t$. The proof identifies a maximum flow with a residual graph that admits no augmenting path; the vertices reachable from $s$ in that residual graph then define the separating edge set of minimum capacity.

**Lab Cell (NetworkX).**

```python
G = nx.DiGraph()
G.add_edge('s', 'A', capacity=3)
G.add_edge('s', 'B', capacity=2)
G.add_edge('A', 't', capacity=2)

print("Max flow:", flow_value)          # Expected: 5
print("Flow on each edge:", flow_dict)
```

### flow (21.5s)

## Flow

**Definition.** Let $f : \mathbb{R}^n \to \mathbb{R}^n$ be a smooth vector field and consider the autonomous ordinary differential equation

$$\dot{\mathbf{x}} = f(\mathbf{x}), \qquad \mathbf{x}(0) = \mathbf{x}_0.$$

Under the Picard–Lindelöf theorem, if $f$ is Lipschitz continuous on an open set $U \subseteq \mathbb{R}^n$, there exists a unique solution $\mathbf{x}(t)$ for $t$ in some interval $(-\varepsilon, \varepsilon)$. The **flow** of $f$ is the map

$$\phi : \mathbb{R} \times \mathbb{R}^n \to \mathbb{R}^n, \qquad \phi(t, \mathbf{x}_0) = \mathbf{x}(t),$$

where $\phi(t, \mathbf{x}_0)$ records the position at time $t$ of the trajectory that starts at $\mathbf{x}_0$. For each fixed $t$, the map $\phi_t(\cdot) := \phi(t, \cdot)$ is a diffeomorphism; the collection $\{\phi_t\}_{t \in \mathbb{R}}$ forms a one-parameter group satisfying $\phi_0 = \mathrm{id}$ and $\phi_{s+t} = \phi_s \circ \phi_t$.

**Worked example.** Take $n = 2$ and $f(x, y) = (-y,\; x)$. The system $\dot{x} = -y$, $\dot{y} = x$ has the explicit solution

$$\phi\!\left(t,\begin{pmatrix}x_0\\y_0\end{pmatrix}\right) = \begin{pmatrix}\cos t & -\sin t\\ \sin t & \cos t\end{pmatrix}\begin{pmatrix}x_0\\y_0\end{pmatrix}.$$

Every initial point traces a circle of radius $r = \sqrt{x_0^2 + y_0^2}$ with period $2\pi$. The group property is immediate: $\phi_{s+t} = R_{s+t} = R_s R_t = \phi_s \circ \phi_t$, where $R_\theta$ denotes rotation by $\theta$.

**Key theorem (Continuity of flow).** If $f$ is $C^k$ ($k \geq 1$), then the flow $\phi(t, \mathbf{x}_0)$ is $C^k$ jointly in $(t, \mathbf{x}_0)$. In particular, the Jacobian $\partial \phi_t / \partial \mathbf{x}_0$ satisfies the **variational equation**

$$\frac{d}{dt}\frac{\partial \phi_t}{\partial \mathbf{x}_0} = Df\!\left(\phi_t(\mathbf{x}_0)\right)\frac{\partial \phi_t}{\partial \mathbf{x}_0},$$

with initial condition $\partial \phi_0 / \partial \mathbf{x}_0 = I$. This linear ODE propagates small perturbations forward in time and is fundamental to stability analysis and Lyapunov exponents.

**Lab cell.**

```python
from sympy import symbols, cos, sin, Matrix, simplify

t, x0, y0 = symbols('t x0 y0', real=True)

# Flow of the rotation vector field f(x,y) = (-y, x)
phi = Matrix([cos(t)*x0 - sin(t)*y0,
              sin(t)*x0 + cos(t)*y0])

# Verify group property: phi(s+t) = phi_s(phi_t(x0,y0))
s = symbols('s', real=True)
phi_t = phi                                      # phi(t, (x0,y0))
phi_s_of_phi_t = phi_t.subs([(t, s), (x0, phi[0]), (y0, phi[1])])
phi_sum = phi.subs(t, s + t)

print(simplify(phi_s_of_phi_t - phi_sum))       # Expected: Matrix([0, 0])
```

### capacity_function (52.3s)

## Capacity Function

**Definition.** Let $G = (V, E)$ be a directed graph. A *capacity function* is a map $c : E \to \mathbb{R}_{\geq 0}$ that assigns to each directed edge $(u, v) \in E$ a non-negative real number $c(u, v)$, called the *capacity* of that edge. For any ordered pair $(u, v)$ where no directed edge exists, we set $c(u, v) = 0$ by convention. Intuitively, $c(u, v)$ represents the maximum rate at which some commodity — data, fluid, traffic — can be transported from $u$ to $v$ per unit time.

A *flow network* is a quadruple $(G, c, s, t)$ where $s \in V$ is the designated *source* and $t \in V$ is the designated *sink*. Every quantitative question about routing — how much can be sent, where the bottleneck lies — is ultimately answered in terms of $c$. Subsequent sections introduce feasible flows and the Max-Flow Min-Cut Theorem; the present goal is to read and construct $c$ correctly.

**Worked Example.** Consider the network with vertex set $\{s, a, b, t\}$ and the following capacity assignments:

$$c(s,a) = 3,\quad c(s,b) = 2,\quad c(a,t) = 2,\quad c(b,t) = 3,\quad c(a,b) = 1.$$

All other ordered pairs, such as $(a, s)$ or $(b, a)$, receive capacity $0$ by the default convention. Observe that the total capacity leaving $s$ is $c(s,a)+c(s,b)=5$ and the total capacity entering $t$ is $c(a,t)+c(b,t)=5$ — a balance that will prove significant when maximum flows are studied. For now, verify that every listed value is non-negative and that unlisted directed pairs default to $0$.

**Theorem (Asymmetry of $c$).** In a capacity function, it is possible that $c(u,v) \neq c(v,u)$ for the same pair of vertices. Consequently, the direction of each edge is essential: reversing it may reduce the capacity to zero. This asymmetry is precisely what allows flow networks to model one-way pipes, directed highways, and asymmetric bandwidth links.

```python
# Lab: build and inspect a capacity function
capacities = {('s','a'): 3, ('s','b'): 2,
              ('a','t'): 2, ('b','t'): 3, ('a','b'): 1}

def c(u, v):
    return capacities.get((u, v), 0)

assert all(val >= 0 for val in capacities.values())

print(f"c(a,b) = {c('a','b')}, c(b,a) = {c('b','a')}")  # c(a,b) = 1, c(b,a) = 0

out_s = c('s', 'a') + c('s', 'b')
print(f"Total capacity leaving s: {out_s}")  # 5
```

### feasible_flow (19.3s)

## Feasible Flow

**Definition.** Let $G = (V, E)$ be a directed graph in which every edge $e \in E$ carries a *capacity* $c(e) \geq 0$ and a *lower bound* $\ell(e) \geq 0$. A **feasible flow** is a function $f : E \to \mathbb{R}_{\geq 0}$ satisfying two conditions:

1. **Capacity constraints:** $\ell(e) \leq f(e) \leq c(e)$ for every $e \in E$.
2. **Flow conservation:** For every internal node $v \in V \setminus \{s, t\}$,
$$\sum_{e \text{ into } v} f(e) \;=\; \sum_{e \text{ out of } v} f(e).$$

Here $s$ denotes the **source** (net producer of flow) and $t$ the **sink** (net consumer). When all lower bounds are zero, the feasibility condition reduces to the familiar capacity and conservation constraints of standard network flow.

**Worked Example.** Consider a network with nodes $\{s, a, b, t\}$ and edges:

| Edge | $\ell$ | $c$ |
|------|--------|-----|
| $s \to a$ | 1 | 4 |
| $s \to b$ | 0 | 3 |
| $a \to t$ | 2 | 5 |
| $b \to t$ | 1 | 3 |
| $a \to b$ | 0 | 2 |

Set $f(s \to a) = 3$, $f(s \to b) = 1$, $f(a \to t) = 3$, $f(b \to t) = 1$, $f(a \to b) = 0$. Verify: all values lie within $[\ell, c]$, node $a$ has inflow $3$ and outflow $3 + 0 = 3$ ✓, node $b$ has inflow $1$ and outflow $1$ ✓. This assignment is a feasible flow of value $|f| = f(s \to a) + f(s \to b) = 4$.

**Key Theorem (Feasibility Characterization).** A feasible flow exists in a network with lower bounds if and only if, in the *circulation* obtained by adding a return arc $t \to s$ with $\ell = c = \infty$, the auxiliary network constructed by replacing each bounded arc with a demand-shifted arc admits a *saturating* flow from a supersource $S$ to a supersink $T$. Equivalently, feasibility requires that for every subset $U \subseteq V$,

$$\sum_{e \text{ entering } U} c(e) \;\geq\; \sum_{e \text{ leaving } U} \ell(e).$$

This cut condition generalizes the max-flow min-cut theorem to networks with mandatory lower bounds.

**Lab Cell.**

```python
import sympy as sp

# Edge data: (tail, head, lower, capacity)
edges = [
    ('s','a', 1, 4),
    ('s','b', 0, 3),
    ('a','t', 2, 5),
    ('b','t', 1, 3),
    ('a','b', 0, 2),
]

# Proposed flow assignment
flow = {('s','a'): 3, ('s','b'): 1,
        ('a','t'): 3, ('b','t'): 1, ('a','b'): 0}

# Check capacity constraints
cap_ok = all(l <= flow[u,v] <= c for u,v,l,c in edges)

# Check conservation at internal nodes
def net_flow(node):
    inflow  = sum(flow[u,v] for u,v,_,_ in edges if v == node)
    outflow = sum(flow[u,v] for u,v,_,_ in edges if u == node)
    return sp.Rational(inflow - outflow)

conservation_ok = all(net_flow(n) == 0 for n in ['a','b'])

print("Capacity constraints satisfied:", cap_ok)
print("Flow conservation satisfied:", conservation_ok)
print("Flow value:", flow[('s','a')] + flow[('s','b')])
```

### flow_value (19.8s)

## Flow Value

**Definition.** Let $G = (V, E, c)$ be a directed network where $c : E \to \mathbb{R}_{\geq 0}$ assigns a *capacity* to each edge, and let $s, t \in V$ denote a designated *source* and *sink*, respectively. A *feasible flow* is a function $f : E \to \mathbb{R}_{\geq 0}$ satisfying two conditions:

1. **Capacity constraint:** $0 \leq f(u,v) \leq c(u,v)$ for every edge $(u,v) \in E$.
2. **Flow conservation:** For every internal node $v \in V \setminus \{s, t\}$,
$$\sum_{u : (u,v)\in E} f(u,v) \;=\; \sum_{w : (v,w)\in E} f(v,w).$$

The *flow value* $|f|$ is defined as the net flow out of the source:
$$|f| \;=\; \sum_{w : (s,w)\in E} f(s,w) \;-\; \sum_{u : (u,s)\in E} f(u,s).$$

An equivalent characterization via the sink follows immediately from conservation: $|f|$ also equals the net flow into $t$.

**Worked Example.** Consider the network with nodes $\{s, a, b, t\}$ and edges $s \to a$ (capacity 3), $s \to b$ (capacity 2), $a \to t$ (capacity 2), $b \to t$ (capacity 3), $a \to b$ (capacity 1). Assign flows $f(s,a)=3$, $f(s,b)=1$, $f(a,t)=2$, $f(a,b)=1$, $f(b,t)=2$. Verify conservation at $a$: inflow $3$, outflow $2+1=3$. At $b$: inflow $1+1=2$, outflow $2$. The flow value is $|f| = f(s,a)+f(s,b) = 3+1 = 4$, confirmed by sink inflow $f(a,t)+f(b,t) = 2+2 = 4$.

**Key Theorem (Max-Flow Min-Cut).** For any network $G$ with source $s$ and sink $t$, the maximum achievable flow value equals the minimum capacity of any $s$-$t$ cut:
$$\max_f |f| \;=\; \min_{(S,T)} \sum_{\substack{u \in S,\, v \in T \\ (u,v)\in E}} c(u,v),$$
where the minimum is taken over all partitions $(S, T)$ of $V$ with $s \in S$ and $t \in T$. This duality theorem, due to Ford and Fulkerson (1956), is foundational to combinatorial optimization.

**Lab Cell.**

```python
import sympy as sp
from sympy.combinatorics.named_groups import SymmetricGroup

# Represent the example network as a capacity matrix
nodes = ['s', 'a', 'b', 't']
idx   = {n: i for i, n in enumerate(nodes)}
cap   = sp.zeros(4, 4)

edges = [('s','a',3),('s','b',2),('a','t',2),('b','t',3),('a','b',1)]
for u, v, c in edges:
    cap[idx[u], idx[v]] = c

flow_vals = [3, 1, 2, 2, 1]
flow_mat  = sp.zeros(4, 4)
for (u, v, _), fv in zip(edges, flow_vals):
    flow_mat[idx[u], idx[v]] = fv

source_row = flow_mat[idx['s'], :]
flow_value = sum(source_row)
sp.pprint(sp.Eq(sp.Symbol('|f|'), flow_value))
```

### maximum_flow_problem (22.3s)

## Maximum Flow Problem

**Definition.** Let $G = (V, E)$ be a directed graph with a distinguished *source* $s \in V$ and *sink* $t \in V$. Each edge $(u, v) \in E$ carries a non-negative *capacity* $c(u, v) \geq 0$. A *flow* is a function $f : E \to \mathbb{R}_{\geq 0}$ satisfying two conditions:

1. **Capacity constraint:** $0 \leq f(u,v) \leq c(u,v)$ for every $(u,v) \in E$.
2. **Flow conservation:** For every $v \in V \setminus \{s, t\}$,
$$\sum_{u:(u,v)\in E} f(u,v) \;=\; \sum_{w:(v,w)\in E} f(v,w).$$

The *value* of a flow is $|f| = \sum_{w:(s,w)\in E} f(s,w)$, the total flow leaving the source. The **maximum flow problem** asks for a flow $f^*$ that maximises $|f|$ subject to the constraints above.

**Worked Example.** Consider the network with $V = \{s, a, b, t\}$ and edges with capacities $c(s,a)=3$, $c(s,b)=2$, $c(a,t)=2$, $c(b,t)=3$, and $c(a,b)=1$. One feasible flow sets $f(s,a)=2$, $f(s,b)=2$, $f(a,t)=2$, $f(b,t)=2$, $f(a,b)=0$, yielding $|f|=4$. Can we do better? Sending one additional unit along $s \to a \to b \to t$ (each edge has residual capacity 1) raises the value to $|f^*|=5$. No further augmentation is possible, so $5$ is optimal.

**Key Theorem (Max-Flow Min-Cut).** The maximum value of any $s$–$t$ flow equals the minimum *capacity* of any $s$–$t$ cut. An $s$–$t$ cut is a partition $(S, T)$ of $V$ with $s \in S$ and $t \in T$; its capacity is $\sum_{u \in S,\, v \in T} c(u,v)$. In the example above, the cut $(\{s,a,b\}, \{t\})$ has capacity $c(a,t)+c(b,t)=5$, confirming optimality.

*Proof sketch.* Every flow value is bounded above by every cut capacity (weak duality). The Ford–Fulkerson algorithm terminates only when no augmenting path exists in the residual graph, at which point the reachable set from $s$ defines a cut whose capacity exactly equals the current flow value (strong duality). $\square$

**Lab Cell.**

```python
from sympy import symbols, Integer

# Represent capacities as a dictionary and run BFS-based augmentation
capacity = {('s','a'):3, ('s','b'):2, ('a','t'):2,
            ('b','t'):3, ('a','b'):1}

def bfs_path(cap, flow, source, sink):
    from collections import deque
    parent = {source: None}
    queue = deque([source])
    nodes = set(u for e in cap for u in e)
    while queue:
        u = queue.popleft()
        for (x,y), c in cap.items():
            if x == u and y not in parent:
                if c - flow.get((x,y),0) > 0:
                    parent[y] = (x,y); queue.append(y)
            if y == u and x not in parent:
                if flow.get((x,y),0) > 0:
                    parent[x] = (y,x); queue.append(x)
    return parent if sink in parent else None

flow = {}
while (p := bfs_path(capacity, flow, 's', 't')):
    edge = ('s','t')
    path, node = [], 't'
    while p[node]: path.append(p[node]); node = p[node][0]
    aug = min(capacity.get(e,0) - flow.get(e,0)
              if e in capacity else flow.get((e[1],e[0]),0)
              for e in path)
    for e in path: flow[e] = flow.get(e,0) + aug

print("Maximum flow:", sum(flow.get(('s',v),0) for v in ['a','b']))
```

## Hyperbolic Functions

### 定义

双曲函数是以自然指数函数为基础构造的一族基本函数，其定义如下：

$$\sinh x = \frac{e^x - e^{-x}}{2}, \qquad \cosh x = \frac{e^x + e^{-x}}{2}$$

由此派生出：

$$\tanh x = \frac{\sinh x}{\cosh x} = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$

以及倒数形式 $\operatorname{csch} x$、$\operatorname{sech} x$、$\coth x$，定义方式与三角函数的倒数类比。双曲函数的命名源于其与单位双曲线 $x^2 - y^2 = 1$ 的参数关系：点 $(\cosh t,\, \sinh t)$ 恒满足该方程，正如 $(\cos t,\, \sin t)$ 满足单位圆方程。

### 例题

**计算 $\cosh(\ln 3)$ 的值。**

将 $x = \ln 3$ 代入定义：

$$\cosh(\ln 3) = \frac{e^{\ln 3} + e^{-\ln 3}}{2} = \frac{3 + \tfrac{1}{3}}{2} = \frac{\tfrac{10}{3}}{2} = \frac{5}{3}$$

此结果亦可验证恒等式：$\cosh^2(\ln 3) - \sinh^2(\ln 3) = 1$。

### 基本恒等式与定理

**定理（基本双曲恒等式）：** 对一切实数 $x$，有

$$\cosh^2 x - \sinh^2 x = 1$$

**证明思路：** 直接展开：

$$\cosh^2 x - \sinh^2 x = \left(\frac{e^x+e^{-x}}{2}\right)^2 - \left(\frac{e^x-e^{-x}}{2}\right)^2 = \frac{(e^{2x}+2+e^{-2x})-(e^{2x}-2+e^{-2x})}{4} = \frac{4}{4} = 1 \qquad \square$$

此外，导数关系与三角函数高度类比：

$$\frac{d}{dx}\sinh x = \cosh x, \qquad \frac{d}{dx}\cosh x = \sinh x$$

注意后者符号与三角函数不同（无负号）。

### 实验单元（SymPy）

```python
from sympy import *
x = symbols('x')

# 验证基本恒等式
expr = cosh(x)**2 - sinh(x)**2
print(simplify(expr))          # 输出：1

# 计算具体值
print(cosh(log(3)))            # 输出：5/3

# 求导
print(diff(sinh(x), x))        # 输出：cosh(x)
print(diff(cosh(x), x))        # 输出：sinh(x)
```

运行上述代码，可直观验证恒等式及导数公式，加深对双曲函数代数结构的理解。

## 悬链线

**定义。** 将一条均匀、柔软、不可伸长的链条两端固定，在重力作用下，链条自然下垂所形成的曲线称为**悬链线**（catenary）。以最低点为原点、竖直向上为 $y$ 轴建立坐标系，悬链线方程为

$$
y = a\cosh\!\left(\frac{x}{a}\right) = \frac{a}{2}\!\left(e^{x/a} + e^{-x/a}\right),
$$

其中参数 $a = T_0 / (\rho g) > 0$，$T_0$ 为最低点处的水平张力，$\rho$ 为链条线密度，$g$ 为重力加速度。悬链线与抛物线外形相近，但本质不同——后者描述弹道，前者由力平衡决定。

**例题。** 设 $a = 1$，计算区间 $[-2, 2]$ 上悬链线的弧长。弧长公式为

$$
L = \int_{-2}^{2} \sqrt{1 + \left(\frac{dy}{dx}\right)^2}\, dx.
$$

由于 $\dfrac{dy}{dx} = \sinh(x/a)$，利用双曲恒等式 $1 + \sinh^2 u = \cosh^2 u$，被积函数化简为 $\cosh(x)$。故

$$
L = \int_{-2}^{2} \cosh(x)\, dx = \Big[\sinh(x)\Big]_{-2}^{2} = 2\sinh(2) \approx 7.254.
$$

**关键定理（悬链线的变分刻画）。** 在所有连接两固定端点、弧长相同的曲线中，使重心最低的曲线恰好是悬链线。其等价表述为：满足力平衡微分方程

$$
\frac{d^2 y}{dx^2} = \frac{1}{a}\sqrt{1 + \left(\frac{dy}{dx}\right)^2}
$$

且边界条件 $y'(0) = 0$ 的唯一解为 $y = a\cosh(x/a)$。此定理将几何极值问题与物理平衡统一，是变分法的经典范例。

**实验单元（SymPy）。**

```python
from sympy import *
x, a = symbols('x a', positive=True)

y = a * cosh(x / a)
arc_length_integrand = sqrt(1 + diff(y, x)**2)
print(simplify(arc_length_integrand))   # 应输出 cosh(x/a)

L = integrate(arc_length_integrand.subs(a, 1), (x, -2, 2))
print(L, float(L))                      # 2*sinh(2) ≈ 7.2537
```

运行上述代码，学生可验证双曲函数恒等式的化简过程，并将数值结果与手算答案对照，从而加深对悬链线几何性质的直觉理解。

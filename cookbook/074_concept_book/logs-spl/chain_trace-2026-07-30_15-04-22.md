## Sequence

**Definition.** A *sequence* is a function $a : \mathbb{N} \to \mathbb{R}$ (or more generally, into any set $S$). We write its values as an ordered list $(a_1, a_2, a_3, \ldots)$, or in compact notation $\{a_n\}_{n=1}^{\infty}$. The integer $n$ is called the *index* and $a_n$ the $n$-th *term*. A sequence is *finite* if the domain is $\{1, 2, \ldots, N\}$ for some $N \in \mathbb{N}$, and *infinite* otherwise. Two sequences are equal if and only if $a_n = b_n$ for every index $n$ in their shared domain.

**Worked Example.** Consider the sequence defined by $a_n = \dfrac{(-1)^{n+1}}{n}$. Listing the first five terms:

$$a_1 = 1,\quad a_2 = -\tfrac{1}{2},\quad a_3 = \tfrac{1}{3},\quad a_4 = -\tfrac{1}{4},\quad a_5 = \tfrac{1}{5}.$$

The terms alternate in sign and decrease in absolute value toward zero. This is the sequence of partial harmonic terms with alternating sign, and it plays a central role in the theory of conditionally convergent series.

**Key Theorem (Squeeze Theorem for Sequences).** Let $\{a_n\}$, $\{b_n\}$, $\{c_n\}$ be sequences satisfying $a_n \le b_n \le c_n$ for all sufficiently large $n$. If

$$\lim_{n \to \infty} a_n = L = \lim_{n \to \infty} c_n,$$

then $\lim_{n \to \infty} b_n = L$ as well.

*Proof sketch.* Given $\varepsilon > 0$, choose $N$ large enough that $|a_n - L| < \varepsilon$ and $|c_n - L| < \varepsilon$ for all $n > N$. The sandwich inequality $a_n \le b_n \le c_n$ then forces $L - \varepsilon < b_n < L + \varepsilon$, i.e., $|b_n - L| < \varepsilon$. $\square$

**Lab Cell (SymPy).**

```python
from sympy import *

n = symbols('n', positive=True, integer=True)

a = ((-1)**(n + 1)) / n

# Compute and display first ten terms
terms = [a.subs(n, k) for k in range(1, 11)]
print("Terms:", terms)

# Verify the limit
print("Limit:", limit(a, n, oo))
```

Running this cell confirms that each term matches the pattern derived above and that $\lim_{n \to \infty} a_n = 0$, consistent with the Squeeze Theorem applied with $c_n = 1/n$ and $a_n = -1/n$.

### time_series (0.0s)

## Time Series

**Definition.** A *time series* is a sequence of observations $\{x_t\}_{t=1}^{T}$ indexed by discrete time $t \in \mathbb{Z}$, where each $x_t$ is a realization of a random variable $X_t$. The collection $\{X_t\}$ is called a *stochastic process*. A time series is said to be *weakly stationary* (or *covariance-stationary*) if its mean and autocovariance structure are invariant under time shifts:

$$\mathbb{E}[X_t] = \mu \quad \text{for all } t,$$
$$\operatorname{Cov}(X_t, X_{t+k}) = \gamma(k) \quad \text{for all } t, k,$$

where $\gamma(k)$ is called the *autocovariance function* at lag $k$. The normalized version, $\rho(k) = \gamma(k)/\gamma(0)$, is the *autocorrelation function* (ACF). These two quantities — $\gamma$ and $\rho$ — are the primary tools for characterizing the internal dependence structure of a stationary series.

**Worked Example.** Consider daily closing prices of a stock over $T = 5$ days: $x_1 = 100,\ x_2 = 102,\ x_3 = 101,\ x_4 = 105,\ x_5 = 103$. Compute the sample mean $\bar{x} = \frac{1}{5}\sum_{t=1}^{5} x_t = 102.2$. The lag-1 sample autocovariance is

$$\hat{\gamma}(1) = \frac{1}{T}\sum_{t=2}^{T}(x_t - \bar{x})(x_{t-1} - \bar{x}) = \frac{1}{5}\bigl[(-1.2)(-2.2) + (-1.2)(-0.2) + (2.8)(-1.2) + (0.8)(2.8)\bigr] = 0.56.$$

A positive $\hat{\gamma}(1)$ indicates that consecutive observations tend to move together — a feature common in financial data.

**Key Theorem (Properties of the ACF).** For any weakly stationary process $\{X_t\}$, the autocorrelation function satisfies:

$$\rho(0) = 1, \qquad \rho(-k) = \rho(k) \quad \text{for all } k \in \mathbb{Z}, \qquad |\rho(k)| \leq 1.$$

Symmetry follows directly from the definition of covariance; the bound $|\rho(k)| \leq 1$ is a consequence of the Cauchy–Schwarz inequality applied to $X_t$ and $X_{t+k}$. Together, these constraints rule out spurious correlation estimates outside $[-1, 1]$ and allow the ACF to be plotted on a standardized scale — the foundation of all graphical stationarity diagnostics.

**Lab Cell (SymPy).**

```python
import sympy as sp

k = sp.Symbol('k', integer=True)
phi, sigma2 = sp.symbols('phi sigma2', positive=True)

# AR(1) autocovariance: gamma(k) = sigma^2 * phi^|k| / (1 - phi^2)
gamma = sigma2 * phi**sp.Abs(k) / (1 - phi**2)
rho   = sp.simplify(gamma / gamma.subs(k, 0))
sp.pprint(rho)  # yields phi^|k|; verify rho(0)=1 and symmetry
```

### error (0.0s)

## Error

**Definition.** Let $x^*$ denote the exact value of a quantity and $\tilde{x}$ its computed or measured approximation. The *absolute error* is

$$
e_{\text{abs}} = |x^* - \tilde{x}|,
$$

and the *relative error*, defined when $x^* \neq 0$, is

$$
e_{\text{rel}} = \frac{|x^* - \tilde{x}|}{|x^*|}.
$$

Relative error is dimensionless and therefore the preferred measure when comparing approximations across different scales. A related concept is *significant digits*: $\tilde{x}$ agrees with $x^*$ to $d$ significant digits when $e_{\text{rel}} < 5 \times 10^{-d}$.

Error arises from two principal sources. *Truncation error* results from replacing an infinite mathematical process (a series, an integral, a limit) with a finite one. *Round-off error* results from representing real numbers in finite-precision floating-point arithmetic. In practice these two sources interact: reducing truncation error by taking more steps can amplify round-off error through accumulated floating-point operations.

**Worked Example.** Approximate $e^{0.1}$ using the two-term Taylor series $1 + x$, evaluated at $x = 0.1$.

- Approximation: $\tilde{x} = 1.1$
- Exact value: $x^* = e^{0.1} \approx 1.10517091\ldots$
- Absolute error: $e_{\text{abs}} = |1.10517091 - 1.1| \approx 5.17 \times 10^{-3}$
- Relative error: $e_{\text{rel}} = \dfrac{5.17 \times 10^{-3}}{1.10517} \approx 4.68 \times 10^{-3}$

Adding the next term $\tfrac{x^2}{2} = 0.005$ gives $\tilde{x} = 1.105$, reducing the relative error to approximately $1.54 \times 10^{-4}$, roughly a 30-fold improvement. Each additional term decreases the truncation error by a factor of approximately $x/n$.

**Theorem (Taylor Remainder Bound).** If $f$ is $(n+1)$ times continuously differentiable on an interval containing $0$ and $x$, then the truncation error of the $n$-term Taylor approximation satisfies

$$
\left|f(x) - \sum_{k=0}^{n} \frac{f^{(k)}(0)}{k!} x^k\right| \leq \frac{M}{(n+1)!} |x|^{n+1},
$$

where $M = \max_{\xi \in [0,x]} |f^{(n+1)}(\xi)|$.

**Lab Cell.**

```python
from sympy import exp, series, Abs, symbols, N

x = symbols('x')
f = exp(x)
x0 = 0.1

for n in range(1, 5):
    approx = series(f, x, 0, n).removeO().subs(x, x0)
    exact  = N(f.subs(x, x0), 15)
    rel_err = Abs(exact - approx) / Abs(exact)
    print(f"n={n}  approx={float(approx):.8f}  rel_err={float(rel_err):.2e}")
```

## Time Series Model

**Definition.** A *time series* is a sequence of observations $\{x_t\}_{t=1}^{T}$ indexed by discrete time $t \in \mathbb{Z}$; this section takes that notion as given and introduces its single new object: the **autoregressive model of order $p$**, denoted $\mathrm{AR}(p)$:

$$x_t = \phi_1 x_{t-1} + \phi_2 x_{t-2} + \cdots + \phi_p x_{t-p} + \varepsilon_t, \qquad \varepsilon_t \overset{\text{i.i.d.}}{\sim} \mathcal{N}(0, \sigma^2),$$

where $\phi_1, \ldots, \phi_p \in \mathbb{R}$ are *autoregressive coefficients* and $\varepsilon_t$ is white noise. The model asserts that the present value is a linear combination of the $p$ most recent values plus an unpredictable shock. When all the statistical properties of $x_t$ depend only on the time gap between observations—not on the calendar time itself—the process is said to be *weakly stationary*, a prerequisite for the coefficient estimates to carry meaning.

**Worked Example.** Consider the $\mathrm{AR}(1)$ process $x_t = 0.8\, x_{t-1} + \varepsilon_t$ with $\sigma^2 = 1$ and $x_0 = 0$. Taking expectations of both sides, stationarity requires $\mu = 0.8\mu$, so $\mu = 0$. The variance satisfies $\mathrm{Var}(x_t) = \sigma^2/(1 - 0.8^2) \approx 2.78$, and the correlation between $x_t$ and $x_{t-k}$ equals $0.8^k$. At lag $k = 3$ this correlation is $0.512$, indicating substantial serial dependence three steps ahead—precisely the structure the $\mathrm{AR}(1)$ model encodes.

**Theorem (Stationarity of $\mathrm{AR}(p)$).** The $\mathrm{AR}(p)$ process is weakly stationary if and only if all roots of the characteristic polynomial

$$\Phi(z) = 1 - \phi_1 z - \phi_2 z^2 - \cdots - \phi_p z^p$$

lie *strictly outside* the unit circle, $|z| > 1$, in the complex plane. For the $\mathrm{AR}(1)$ case this reduces to $|\phi_1| < 1$, consistent with the example above where $|\phi_1| = 0.8$.

**Lab Cell.**

```python
import numpy as np
from sympy import symbols, Rational, Abs, solve

phi = Rational(4, 5)          # 0.8 as exact fraction
z   = symbols('z')
char_poly = 1 - phi * z
roots = solve(char_poly, z)   # [5/4]
print("Root:", roots, "  |root| > 1:", Abs(roots[0]) > 1)

# Simulate AR(1) numerically
rng  = np.random.default_rng(42)
T    = 200
x    = np.zeros(T)
eps  = rng.normal(0, 1, T)
for t in range(1, T):
    x[t] = 0.8 * x[t-1] + eps[t]
print("Sample mean:", x.mean().round(3), " Sample var:", x.var().round(3))
```

### forecasting (0.0s)

## Forecasting

**Definition.** *Forecasting* is the process of estimating the value of a quantity at a future time $t + h$ given observations up to and including time $t$. Formally, let $\{y_t\}_{t=1}^{T}$ be a discrete time series. An $h$-step-ahead point forecast is a function $\hat{y}_{T+h|T} = f(y_T, y_{T-1}, \ldots)$ that minimises a chosen loss, most commonly the mean squared error $\mathbb{E}[(y_{T+h} - \hat{y}_{T+h|T})^2]$. A *prediction interval* accompanies the point forecast to express uncertainty: $[\hat{y}_{T+h|T} \pm z_{\alpha/2}\,\hat{\sigma}_h]$, where $\hat{\sigma}_h$ is the estimated $h$-step forecast standard deviation and $z_{\alpha/2}$ is the standard normal critical value for coverage $1-\alpha$.

**Worked Example.** Consider monthly average temperatures (°C) recorded over 24 months. Suppose the series exhibits a linear trend $\mu_t = \beta_0 + \beta_1 t$ with additive white noise $\varepsilon_t \sim \mathcal{N}(0, \sigma^2)$, so $y_t = \beta_0 + \beta_1 t + \varepsilon_t$. Ordinary least squares yields $\hat{\beta}_0 = 5.2$ and $\hat{\beta}_1 = 0.3$ from the 24 observations. The 3-step-ahead forecast is:
$$\hat{y}_{27|24} = 5.2 + 0.3 \times 27 = 13.3 \text{ °C.}$$
With residual standard deviation $\hat{\sigma} = 1.1$ °C and $z_{0.025} = 1.96$, the 95 % prediction interval is $[13.3 \pm 2.16] = [11.14,\ 15.46]$ °C.

**Key Theorem (Unbiasedness of the Linear Trend Forecast).** Let $y_t = \beta_0 + \beta_1 t + \varepsilon_t$ with $\mathbb{E}[\varepsilon_t] = 0$ and $\mathrm{Var}(\varepsilon_t) = \sigma^2 < \infty$. The OLS forecast $\hat{y}_{T+h|T} = \hat{\beta}_0 + \hat{\beta}_1(T+h)$ is unbiased: $\mathbb{E}[\hat{y}_{T+h|T}] = \beta_0 + \beta_1(T+h)$. Moreover, among all linear unbiased forecasts formed from $\{y_1, \ldots, y_T\}$, it achieves the smallest mean squared forecast error. The proof follows directly from the Gauss–Markov theorem applied to the design matrix evaluated at the future time point $T + h$.

**Lab Cell (SymPy).**
```python
import sympy as sp

t, beta0, beta1 = sp.symbols('t beta0 beta1')
trend = beta0 + beta1 * t
forecast = trend.subs([(beta0, sp.Rational(26, 5)),
                       (beta1, sp.Rational(3, 10)),
                       (t, 27)])
print("Point forecast:", forecast)          # 13.3
sigma_h = sp.Rational(11, 10)
z = sp.Rational(196, 100)
lower = forecast - z * sigma_h
upper = forecast + z * sigma_h
print(f"95% PI: [{lower}, {upper}]")        # [11.144, 15.456]
```

## Naive Forecasting

**Definition.** Let $\{y_t\}_{t=1}^{T}$ be a univariate time series. The *naive forecast* for horizon $h \geq 1$ is defined as

$$\hat{y}_{T+h \mid T} = y_T,$$

that is, every future value is predicted to equal the most recently observed value. Equivalently, the naive method assumes that the best available information about the future is the present, with no trend, seasonality, or autocorrelation exploited beyond the last observation. Despite its simplicity, the naive forecast serves as the canonical *baseline*: any more sophisticated model must outperform it to justify its additional complexity.

A natural variant, the *seasonal naive* forecast, accommodates periodic data by setting

$$\hat{y}_{T+h \mid T} = y_{T+h-m},$$

where $m$ is the seasonal period (e.g., $m = 12$ for monthly data). Here the forecast for a given future month equals the value recorded in the same month of the previous cycle.

---

**Worked Example.** Suppose daily closing prices of a stock (in USD) for five consecutive days are

$$y_1 = 102,\quad y_2 = 105,\quad y_3 = 103,\quad y_4 = 107,\quad y_5 = 106.$$

The naive one-step-ahead forecast is $\hat{y}_6 = y_5 = 106$. The two-step-ahead forecast is equally $\hat{y}_7 = 106$. If the true value on day 6 turns out to be $y_6 = 109$, the forecast error is $e_6 = y_6 - \hat{y}_{6\mid 5} = 3$.

---

**Key Theorem (Random Walk Optimality).** If $\{y_t\}$ follows a random walk, i.e., $y_t = y_{t-1} + \varepsilon_t$ where $\varepsilon_t \overset{\text{iid}}{\sim}(0,\sigma^2)$, then the naive forecast minimizes the mean squared error among all linear unbiased predictors. Formally,

$$\mathbb{E}\!\left[(y_{T+h} - \hat{y}_{T+h\mid T})^2\right] = h\sigma^2,$$

which is the irreducible variance and cannot be reduced by any predictor that relies solely on the observed history $\{y_1,\ldots,y_T\}$.

---

**Lab Cell.**

```python
import sympy as sp

# Symbolic naive forecast error variance for a random walk
h, sigma2 = sp.symbols('h sigma^2', positive=True)
mse = h * sigma2
print("MSE of naive forecast (random walk):", mse)

# Numerical example
prices = [102, 105, 103, 107, 106]
naive_forecast = prices[-1]          # 106
actual_day6    = 109
error          = actual_day6 - naive_forecast
print(f"Naive forecast: {naive_forecast}, Error: {error}")
```

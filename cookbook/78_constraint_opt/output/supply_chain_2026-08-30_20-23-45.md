### Step 3 — MODI (UV) Optimality Test and Improvement

The UV method assigns dual variables u_i, v_j such that u_i + v_j = c(i,j) for every basic cell, then computes the **reduced cost** d(i,j) = c(i,j) − u_i − v_j for each non-basic cell. Any negative d(i,j) means cost can be reduced.

**UV values for the initial BFS (set u1 = 0):**

From the 12 basic cell equations:

| | Value | Derivation |
|--|-------|-----------|
| u1 | 0 | set by convention |
| v2 | 2 | W1-D2: 0 + v2 = 2 |
| u5 | 1 | W5-D2: u5 + 2 = 3 |
| v1 | 4 | W5-D1: 1 + v1 = 5 |
| u2 | 3 | W2-D1: u2 + 4 = 7 |
| v3 | 0 | W2-D3: 3 + v3 = 3 |
| u3 | 2 | W3-D3: u3 + 0 = 2 |
| v5 | 5 | W2-D5: 3 + v5 = 8 |
| u7 | 2 | W7-D5: u7 + 5 = 7 |
| v4 | 1 | W7-D4: 2 + v4 = 3 |
| u4 | 1 | W4-D4: u4 + 1 = 2 |
| u6 | −3 | W6-D5: u6 + 5 = 2 |
| u8 | −2 | W8-D1: u8 + 4 = 2 |

**Key negative reduced costs found:**

- d(W3,D1) = 3 − 2 − 4 = **−3** ← enter basis
- d(W3,D5) = 4 − 2 − 5 = **−3**
- d(W8,D5) = 3 − (−2) − 5 = **−3** (effectively 3+2−5)

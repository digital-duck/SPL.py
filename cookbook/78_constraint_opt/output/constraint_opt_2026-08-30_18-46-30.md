# Constraint Optimization Report

**Problem:** A furniture workshop produces chairs and tables. Each chair requires 2 hours of labor and 3 kg of wood, earning $20 profit. Each table requires 4 hours of labor and 5 kg of wood, earning $30 profit. The workshop has 24 hours of labor and 30 kg of wood available per day. Both quantities must be non-negative. Maximize daily profit.

## Solution

### 1. Model formulation

**Decision variables:**
- x = chairs produced per day
- y = tables produced per day

**Objective:** Maximize Z = 20x + 30y

**Constraints:**
- Labor: 2x + 4y ≤ 24
- Wood: 3x + 5y ≤ 30
- Non-negativity: x ≥ 0, y ≥ 0

---

### 2. Feasible region corners

The feasible region is a convex polygon. Its corners arise from pairs of binding constraints.

**Corner A — both non-negativity constraints bind (the origin):**
x = 0, y = 0 → point **(0, 0)**

**Corner B — labor binds, x = 0:**
2(0) + 4y = 24 → y = 6
Feasibility check (wood): 3(0) + 5(6) = 30 ≤ 30 ✓ → point **(0, 6)**

**Corner C — wood binds, y = 0:**
3x + 5(0) = 30 → x = 10
Feasibility check (labor): 2(10) + 4(0) = 20 ≤ 24 ✓ → point **(10, 0)**

**Candidate — labor binds, y = 0:**
2x + 4(0) = 24 → x = 12
Feasibility check (wood): 3(12) + 5(0) = 36 > 30 ✗ **Infeasible — rejected**

**Candidate — labor and wood both bind simultaneously:**
Solve the 2×2 system:
```
2x + 4y = 24   … (i)
3x + 5y = 30   … (ii)
```
From (i): x = 12 − 2y. Substitute into (ii):
3(12 − 2y) + 5y = 30
36 − 6y + 5y = 30
36 − y = 30
y = 6, then x = 12 − 2(6) = 0

This gives (0, 6), already found as Corner B. The two resource constraints intersect **exactly on the y-axis**, so there is no interior intersection; the feasible region is a triangle.

---

### 3. Objective evaluated at each corner

| Corner | x  | y | Z = 20x + 30y                 |
|--------|----|---|-------------------------------|
| A      | 0  | 0 | 20(0) + 30(0) = **$0**        |
| B      | 0  | 6 | 20(0) + 30(6) = 0 + 180 = **$180** |
| C      | 10 | 0 | 20(10) + 30(0) = 200 + 0 = **$200** |

---

### 4. Optimal solution

**Produce 10 chairs and 0 tables for a maximum daily profit of $200.**

*Why chairs dominate:* Chairs earn $10 per labor-hour and $6.67 per kg of wood; tables earn $7.50 per labor-hour and $6.00 per kg. Chairs are more efficient on both scarce resources, so the LP corner that maximizes profit uses chairs exclusively until wood is exhausted.

*Integrality:* The problem implies whole units of furniture. The LP optimum (10, 0) is already integer, so there is no rounding issue.

---

## Verification

Plug x = 10, y = 0 back into every constraint.

**Labor constraint:**
2(10) + 4(0) = 20 + 0 = 20 ≤ 24 ✓
Slack = 24 − 20 = **4 hours** (not binding)

**Wood constraint:**
3(10) + 5(0) = 30 + 0 = 30 ≤ 30 ✓
Slack = 30 − 30 = **0 kg** (binding — wood is the single active constraint at the optimum)

**Non-negativity:**
x = 10 ≥ 0 ✓ and y = 0 ≥ 0 ✓

**Objective value:**
Z = 20 × 10 + 30 × 0 = 200 + 0 = **$200** ✓

All constraints satisfied; optimal profit confirmed at **$200 per day**.

# Constraint Optimization Report

**Problem:** A factory makes chairs (2h labor, 4kg wood, $20 profit) and tables (4h labor, 3kg wood, $30 profit). Available: 20h labor, 24kg wood. Maximize profit.

## Solution

### 1. Define Variables, Objective, and Constraints

Let **x** = chairs produced, **y** = tables produced.

**Objective:** Maximize Z = 20x + 30y

**Constraints:**
- Labor:  2x + 4y ≤ 20
- Wood:   4x + 3y ≤ 24
- Non-negativity: x ≥ 0, y ≥ 0

### 2. Find Feasible-Region Corners

There are four candidate vertices — one from each pair of binding constraints.

**Corner A — both axes binding (origin):** x = 0, y = 0. Trivially satisfies all constraints.

**Corner B — labor boundary meets x-axis (y = 0):**
2x + 4(0) = 20 → x = 10.
Check wood: 4(10) = 40 > 24. **Infeasible.**

Try wood boundary on x-axis: 4x + 3(0) = 24 → **x = 6**.
Check labor: 2(6) = 12 ≤ 20. **Feasible.** → Corner B = **(6, 0)**.

**Corner C — labor boundary meets y-axis (x = 0):**
2(0) + 4y = 20 → **y = 5**.
Check wood: 3(5) = 15 ≤ 24. **Feasible.** → Corner C = **(0, 5)**.

(Wood boundary on y-axis gives y = 8, but labor = 4 × 8 = 32 > 20 — infeasible.)

**Corner D — both constraints binding simultaneously:**

System:
```
2x + 4y = 20   →   x + 2y = 10   … (1)
4x + 3y = 24                      … (2)
```

From (1): x = 10 − 2y. Substitute into (2):
4(10 − 2y) + 3y = 24
40 − 8y + 3y = 24
40 − 5y = 24
5y = 16
**y = 3.2**

x = 10 − 2(3.2) = 10 − 6.4 = **x = 3.6**

Check feasibility: both constraints are binding by construction — feasible. → Corner D = **(3.6, 3.2)**.

### 3. Evaluate Objective at Each Corner

| Corner | (x, y)     | Z = 20x + 30y                      |
|--------|------------|------------------------------------|
| A      | (0, 0)     | 0 + 0 = **$0**                    |
| B      | (6, 0)     | 120 + 0 = **$120**                |
| C      | (0, 5)     | 0 + 150 = **$150**                |
| D      | (3.6, 3.2) | 72 + 96 = **$168** ← maximum     |

### 4. Optimal Solution

**Continuous LP optimum:** produce 3.6 chairs and 3.2 tables for a profit of **$168**.

**Integrality note:** Physical production requires whole units. The LP vertex (3.6, 3.2) is not integer-valued, so rounding must respect all constraints. Testing the nearest feasible integer points:

| (x, y) | Labor check       | Wood check        | Z           |
|--------|-------------------|-------------------|-------------|
| (3, 3) | 6+12 = 18 ≤ 20 ✓ | 12+9 = 21 ≤ 24 ✓ | 60+90 = $150|
| (4, 2) | 8+8 = 16 ≤ 20 ✓  | 16+6 = 22 ≤ 24 ✓ | 80+60 = $140|
| (4, 3) | 8+12 = 20 ≤ 20 ✓ | 16+9 = 25 > 24 ✗  | infeasible  |
| (2, 4) | 4+16 = 20 ≤ 20 ✓ | 8+12 = 20 ≤ 24 ✓  | 40+120 = **$160**|

**Integer optimum:** x = 2 chairs, y = 4 tables, Z = **$160**.

---

## Verification

Verifying the **continuous optimum** (x = 3.6, y = 3.2):

**Labor constraint:**
2 × 3.6 + 4 × 3.2 = 7.2 + 12.8 = **20 ≤ 20** — **binding** (no slack)

**Wood constraint:**
4 × 3.6 + 3 × 3.2 = 14.4 + 9.6 = **24 ≤ 24** — **binding** (no slack)

**Objective:**
3.6 × $20 + 3.2 × $30 = $72 + $96 = **$168** ✓

Verifying the **integer optimum** (x = 2, y = 4):

**Labor constraint:**
2 × 2 + 4 × 4 = 4 + 16 = **20 ≤ 20** — **binding**

**Wood constraint:**
4 × 2 + 3 × 4 = 8 + 12 = **20 ≤ 24** — slack of 4 kg

**Objective:**
2 × $20 + 4 × $30 = $40 + $120 = **$160** ✓

Both solutions check out. The $8 gap ($168 → $160) is the integrality penalty — the LP relaxation is attainable only if fractional units are permitted.

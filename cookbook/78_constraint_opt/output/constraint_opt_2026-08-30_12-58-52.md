# Constraint Optimization Report

**Problem:** A furniture workshop produces chairs and tables. Each chair requires 2 hours of labor and 3 kg of wood, earning $20 profit. Each table requires 4 hours of labor and 5 kg of wood, earning $30 profit. The workshop has 24 hours of labor and 30 kg of wood available per day. Both quantities must be non-negative. Maximize daily profit.

## Solution

Here's the solution to the furniture workshop optimization problem using mathematical reasoning only:

**1. Define decision variables and state the objective and constraints.**

Let:

*   `x` = number of chairs produced daily
*   `y` = number of tables produced daily

The **objective function**, which we want to maximize, is the total profit:

Profit (Z) = 20x + 30y

The **constraints** are derived from the limited resources:

*   **Labor Constraint:** 2x + 4y ≤ 24  (Maximum labor hours available)
*   **Wood Constraint:** 3x + 5y ≤ 30 (Maximum wood available)
*   **Non-negativity Constraints:** x ≥ 0, y ≥ 0

**2. Find the feasible region corners:**

To find the corner points of the feasible region defined by these constraints, we need to solve for intersections between the constraint lines. We'll first simplify the labor and wood constraints:

*   Labor Constraint: 2x + 4y ≤ 24  => x + 2y ≤ 12
*   Wood Constraint: 3x + 5y ≤ 30

Now, let’s find the intersection points by solving pairs of equations.

* **Intersection of x + 2y = 12 and 3x + 5y = 30:**

To solve this system, we can use substitution or elimination. Let's use elimination. Multiply the first equation by -3:
-3x -6y = -36
Now add this to the second equation:
(3x + 5y) + (-3x -6y) = 30 + (-36)
-y = -6
Therefore, y = 6.

Substitute y = 6 into x + 2y = 12:
x + 2(6) = 12
x + 12 = 12
x = 0

So one corner point is (0, 6).

* **Intersection of x + 2y = 12 and x = 0:**
Substitute x=0 into x+2y=12
0 + 2y = 12
y = 6.  This gives us the point (0, 6) which we already have.

* **Intersection of 3x + 5y = 30 and y = 0:**
Substitute y=0 into 3x+5y=30
3x + 5(0) = 30
3x = 30
x = 10.  This gives us the point (10, 0).

* **Intersection of x + 2y = 12 and y = 0:**
Substitute y=0 into x+2y=12
x + 2(0) = 12
x = 12.  This gives us the point (12, 0). However, this point is not feasible because 3(12)+5(0)=36>30

* **Intersection of x = 0 and y = 0:** This point is (0, 0)

Multiply the first equation by -3:
-3x - 6y = -36
Add it to the second equation:
(3x + 5y) + (-3x - 6y) = 30 - 36
-y = -6
y = 6

Substitute y=6 into x+2y=12:
x + 2*6 = 12
x + 12 = 12
x = 0

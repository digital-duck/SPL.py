# Constraint Optimization Report

**Problem:** A furniture workshop produces chairs and tables. Each chair requires 2 hours of labor and 3 kg of wood, earning $20 profit. Each table requires 4 hours of labor and 5 kg of wood, earning $30 profit. The workshop has 24 hours of labor and 30 kg of wood available per day. Both quantities must be non-negative. Maximize daily profit.

## Solution

Let:

*   `x` be the number of chairs produced daily.
*   `y` be the number of tables produced daily.

**1. Define Decision Variables and State the Objective and Constraints:**

The objective is to maximize daily profit. The objective function is:

Maximize  Z = 20x + 30y

Subject to the following constraints:

*   Labor constraint: 2x + 4y ≤ 24
*   Wood constraint: 3x + 5y ≤ 30
*   Non-negativity constraints: x ≥ 0, y ≥ 0

**2. Find the Feasible Region Corners:**

We need to find the intersection points of the constraint lines formed by these inequalities.

First, let's graph the lines defined by the constraints and determine the feasible region.

*   **2x + 4y = 24  => x + 2y = 12**
    When x = 0, y = 6. When y = 0, x = 12.
*   **3x + 5y = 30**
    When x = 0, y = 6. When y = 0, x = 10.

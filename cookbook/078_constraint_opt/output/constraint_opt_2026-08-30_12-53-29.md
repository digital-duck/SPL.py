# Constraint Optimization Report

**Problem:** A furniture workshop produces chairs and tables. Each chair requires 2 hours of labor and 3 kg of wood, earning $20 profit. Each table requires 4 hours of labor and 5 kg of wood, earning $30 profit. The workshop has 24 hours of labor and 30 kg of wood available per day. Both quantities must be non-negative. Maximize daily profit.

## Solution

Let's solve this linear programming problem step-by-step.

**1. Define Decision Variables and State the Objective and Constraints:**

*   Let `x` be the number of chairs produced daily.
*   Let `y` be the number of tables produced daily.

The objective is to maximize daily profit:
*   Objective Function (Profit):  `P = 20x + 30y`

Constraints are based on available resources:
*   Labor Constraint: `2x + 4y <= 24`  (2 hours/chair * x chairs + 4 hours/table * y tables <= 24 hours)
*   Wood Constraint: `3x + 5y <= 30` (3 kg/chair * x chairs + 5kg/table * y tables <= 30 kg)
*   Non-negativity Constraints:  `x >= 0`, `y >= 0`

**2. Find the Feasible Region Corners:**

To find the feasible region corners, we need to solve systems of equations formed by the constraints.

*   **Corner 1:** `x = 0`, `y = 0`
    *   P = 20(0) + 30(0) = 0

*   **Corner 2:**  `x = 0` (from Labor constraint)
    *   `2(0) + 4y = 24  =>  4y = 24  => y = 6`
    *   P = 20(0) + 30(6) = 180

*   **Corner 3:** `y = 0` (from Wood constraint)
    *   `3x + 5(0) = 30 => 3x = 30 => x = 10`
    *   P = 20(10) + 30(0) = 200

*   **Corner 4:** Intersection of Labor and Wood constraints:
    *   We have the system:
        *   `2x + 4y = 24`  => `x = 12 - 2y`
        *   `3x + 5y = 30`
    Substitute x in second equation:
    *   `3(12-2y) + 5y = 30`
    *   `36 - 6y + 5y = 30`
    *   `-y = -6`
    *   `y = 6`
    Then,  `x = 12 - 2(6) = 12 - 12 = 0`. This is the same as corner 2.

Let's solve it another way: Multiply the first equation by 3 and the second by 2 to eliminate x:
*   `6x + 12y = 72`
*   `6x + 10y = 60`
Subtracting the second from the first gives: `2y = 12`, so `y = 6`.  Then, `2x + 4(6) = 24` => `2x + 24 = 24` => `2x = 0` => `x = 0`. This is the same as corner 2.

*   **Corner 5:** Intersection of Labor and Wood constraints:
    Let's solve them directly by multiplying first constraint by -3 and adding to second one:
     *  -6x -12y = -72
     *  3x + 5y = 30
     Adding the two equations gives:
     *   -3x - 7y = -42 =>  3x = 7y - 42. -> x = (7/3)y - 14

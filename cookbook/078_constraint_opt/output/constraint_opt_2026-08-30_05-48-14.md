# Constraint Optimization Report

**Problem:** A factory makes chairs (2h labor, 4kg wood, $20 profit) and tables (4h labor, 3kg wood, $30 profit). Available: 20h labor, 24kg wood. Maximize profit.

**Solver status:** `Optimal`
**Optimal objective value:** 168

**Decision variables:**
  - chairs = 3.6
  - tables = 3.2

## Interpretation

**Optimal Decision:** Produce **3.6 chairs** and **3.2 tables** per production cycle. (In practice, round to 4 chairs and 3 tables, then verify feasibility.)

**Optimal Profit:** **$168** — the maximum achievable given current resources.

**Binding Constraints:** Both constraints are fully consumed — all **20 labor hours** and all **24 kg of wood** are used. Neither resource has slack; every unit is spoken for.

**Recommendation:** Since both resources are simultaneously exhausted, acquiring more of *either* labor or wood will unlock additional profit — prioritize whichever is cheaper to expand, as relaxing either constraint opens room to produce more.

## Solver Code (LLM-generated, PuLP)

```python
prob = pulp.LpProblem("factory_profit", pulp.LpMaximize)

chairs = pulp.LpVariable("chairs", lowBound=0)
tables = pulp.LpVariable("tables", lowBound=0)

prob += 20 * chairs + 30 * tables

prob += 2 * chairs + 4 * tables <= 20
prob += 4 * chairs + 3 * tables <= 24

prob.solve(pulp.PULP_CBC_CMD(msg=0))

_result = {
    "status": pulp.LpStatus[prob.status],
    "objective": pulp.value(prob.objective),
    "variables": {v.name: pulp.value(v) for v in prob.variables()}
}
```

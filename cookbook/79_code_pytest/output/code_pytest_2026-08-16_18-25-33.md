**Spec:** Write a Python function merge_sorted(a, b) that merges two sorted lists into one sorted list without using sorted() or list.sort(). Both input lists contain integers and are already sorted ascending. The function must run in O(n+m) time.

## Generated Code

```python
def merge_sorted(a, b):
    result = []
    i = j = 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            result.append(a[i])
            i += 1
        else:
            result.append(b[j])
            j += 1
    result.extend(a[i:])
    result.extend(b[j:])
    return result
```

## Explanation

The function uses the classic two-pointer merge: it walks both lists simultaneously with indices i and j, always appending whichever current element is smaller, then advancing that list's pointer. Once one list is exhausted, the while loop ends and the two extend calls append whatever remains in the other list — this handles the edge cases where one list is longer than the other, or where one list is empty entirely. Because each element is visited exactly once, the algorithm runs in O(n+m) time as required.

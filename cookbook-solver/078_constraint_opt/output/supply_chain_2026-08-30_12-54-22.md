# Supply Chain Optimization Report

**Problem:** A company has two warehouses and three retail stores. Warehouse W1 has 80 units of inventory; Warehouse W2 has 60 units. Store S1 needs 50 units, Store S2 needs 40 units, Store S3 needs 50 units. Shipping costs per unit: W1 to S1 costs $2, W1 to S2 costs $3, W1 to S3 costs $1; W2 to S1 costs $5, W2 to S2 costs $4, W2 to S3 costs $8. All store demand must be met exactly. Minimize total shipping cost.

## Solution

**1. Cost Matrix and Supply/Demand Table:**

First, we represent the transportation costs in a cost matrix:

|         | S1   | S2   | S3   |
|---------|------|------|------|
| **W1**  | $2   | $3   | $1   |
| **W2**  | $5   | $4   | $8   |


Next, we create a supply/demand table to represent the inventory levels and requirements:

| Warehouse | W1    | W2    | Total |
|-----------|-------|-------|-------|
| S1        | 0     | 0     | 50    |
| S2        | 0     | 0     | 40    |
| S3        | 0     | 0     | 50    |
| **Total** | 80    | 60    | 190   |



**2. Applying the Minimum Cost Method:**

The Northwest Corner Method is used to find an initial feasible solution:

* **Iteration 1:**  Start at the northwest corner (W1 to S1). Send 50 units from W1 to S1. This satisfies the demand for S1.
   * W1 remaining: 80 - 50 = 30
   * S1 fulfilled: 50
   * Cost so far: 50 * $2 = $100

* **Iteration 2:** Move to the northeast corner (W1 to S2). Send 30 units from W1 to S2. This satisfies the demand for S2.
    * W1 remaining : 30
    * S2 fulfilled: 40 + 30 = 70
    * Cost so far: $100 + (30 * $3) = $100 + $90 = $190

* **Iteration 3:** Move to the southeast corner (W1 to S3). Send the remaining 30 units from W1 to S3.
    * W1 remaining: 0
    * S3 fulfilled: 50 + 30 = 80
    * Cost so far: $190 + (30 * $1) = $190 + $30 = $220

* **Iteration 4:** Move to the next available cell, W2 to S1. Send 60 units from W2 to S1. This satisfies the demand for S1.
    * W2 remaining: 60 - 60 = 0
    * S1 fulfilled: 50 + 60 = 110 (This exceeds demand, so we can't proceed with this step)

* **Iteration 5:** Move to the next available cell, W2 to S2. Send the remaining 0 units from W2 to S2 since it is already fulfilled.
    * W2 remaining: 0
    * S2 fulfilled: 70
    * Cost so far: $220

* **Iteration 6:** Move to the next available cell, W2 to S3. Send the remaining 0 units from W2 to S3 since it is already fulfilled.
    * W2 remaining: 0
    * S3 fulfilled: 80
    * Cost so far: $220

Since all demands are met by this point, there’s no further cost reduction possible using the Minimum Cost Method.



**3. Optimal Shipping Plan and Total Minimum Cost:**

The optimal shipping plan is as follows:

* W1 to S1: 50 units at $2/unit = $100
* W1 to S2: 30 units at $3/unit = $90
* W1 to S3: 30 units at $1/unit = $30

Total Minimum Cost = $100 + $90 + $30 = $220

# Constraint Optimization Report

**Problem:** A furniture workshop produces chairs and tables. Each chair requires 2 hours of labor and 3 kg of wood, earning $20 profit. Each table requires 4 hours of labor and 5 kg of wood, earning $30 profit. The workshop has 24 hours of labor and 30 kg of wood available per day. Both quantities must be non-negative. Maximize daily profit.

**Solver status:** `Optimal`
**Optimal objective value:** 200

**Decision variables:**
  - Chair = 10
  - Table = 0

## Interpretation

This optimization result tells us that to maximize daily profit, the workshop should produce 10 chairs and 0 tables. The optimal daily profit is $200.0. All constraints – labor hours and wood usage – are binding, meaning we're using exactly all available resources.  Essentially, the model found the most profitable way to utilize the workshop’s limited capacity. We should focus production entirely on chairs to achieve this maximum profit.

## Solution Verification

Let 'x' be the number of chairs produced and 'y' be the number of tables produced.

**Constraints:**

1.  Labor Constraint: 2x + 4y ≤ 24
    Substituting x = 10, y = 0: 2(10) + 4(0) ≤ 24  => 20 ≤ 24 (Binding)

2.  Wood Constraint: 3x + 5y ≤ 30
     Substituting x = 10, y = 0: 3(10) + 5(0) ≤ 30 => 30 ≤ 30 (Binding)

3. Non-negativity Constraints:  x ≥ 0, y ≥ 0
    Since x=10 and y=0, these constraints are automatically satisfied.

**Objective Function:** Profit = 20x + 30y
Substituting x = 10, y = 0: Profit = 20(10) + 30(0) = $200

The solver reports an optimal objective value of $200.0 which matches our calculation. The solution is therefore correct as it utilizes all available labor and wood resources to maximize profit, producing only chairs.

from pulp import *

# Create the LP problem
prob = LpProblem("Furniture Production", LpMaximize)

# Define decision variables
chair_var = LpVariable('Chair', lowBound=0, cat='Integer')
table_var = LpVariable('Table', lowBound=0, cat='Integer')

# Set the objective function
prob += 20 * chair_var + 30 * table_var, "Total Profit"

# Add constraints
prob += 2 * chair_var + 4 * table_var <= 24, "Labor Constraint"
prob += 3 * chair_var + 5 * table_var <= 30, "Wood Constraint"

# Solve the problem
prob.solve(pulp.PULP_CBC_CMD(msg=0))

# Store the results
_result = {
    "status": pulp.LpStatus[prob.status],
    "objective": pulp.value(prob.objective),
    "variables": {v.name: pulp.value(v) for v in prob.variables()}
}

### 3. Solve the System of Binding Constraints

Set all variables to zero except x₁₄ (Ottoman), x₁₉ (Bar Cart), x₈ (Coffee Table).

**Fabric constraint (binding = 20):**
```
1.2 × x₁₄ = 20
x₁₄ = 20 / 1.2 = 50/3 ≈ 16.667 units
```

**Steel constraint (binding = 18):**
```
2.5 × x₁₉ = 18
x₁₉ = 18 / 2.5 = 7.2 units
```

**Finishing constraint (binding = 30):**
```
0.3 × (50/3) + 0.5 × 7.2 + 0.4 × x₈ = 30
5.000 + 3.600 + 0.4 × x₈ = 30
0.4 × x₈ = 21.4
x₈ = 53.5 units
```

**Check labor (should be ≤ 200):**
```
2 × (50/3) + 2.5 × 7.2 + 2 × 53.5
= 100/3 + 18 + 107
= 33.333 + 18 + 107 = 158.333  ≤ 200  ✓  (slack = 41.667h)
```

**Check lumber (should be ≤ 250):**
```
1 × (50/3) + 1.5 × 7.2 + 4 × 53.5
= 16.667 + 10.8 + 214 = 241.467  ≤ 250  ✓  (slack = 8.533 kg)
```

Both non-binding — confirming π_L = π_W = 0.

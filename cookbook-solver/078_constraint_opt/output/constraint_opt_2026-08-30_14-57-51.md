# Constraint Optimization Report

**Problem:** A furniture workshop produces chairs and tables. Each chair requires 2 hours of labor and 3 kg of wood, earning $20 profit. Each table requires 4 hours of labor and 5 kg of wood, earning $30 profit. The workshop has 24 hours of labor and 30 kg of wood available per day. Both quantities must be non-negative. Maximize daily profit.

## Solution

### 1. Decision Variables, Objective, and Constraints

Let **x** = chairs produced per day, **y** = tables produced per day.

**Objective:** Maximize Z = 20x + 30y

**Subject to:**
- Labor:   2x + 4y ≤ 24
- Wood:    3x + 5y ≤ 30
- Non-neg: x ≥ 0,  y ≥ 0

### 2. Finding the Feasible-Region Corners

Label the binding-constraint lines:
- **L1:** 2x + 4y = 24
- **L2:** 3x + 5y = 30

There are four candidate corner pairs. I check each in turn.

---

**Corner A — x = 0, y = 0 (origin)**
Trivially feasible. Record (0, 0).

---

**Corner B — x = 0 meets L1**
Set x = 0 in L1: 4y = 24 → y = 6.
Check L2: 3(0) + 5(6) = 30 ≤ 30. ✓ Feasible.
Record **(0, 6)**.

---

**Corner C — x = 0 meets L2**
Set x = 0 in L2: 5y = 30 → y = 6.
Check L1: 2(0) + 4(6) = 24 ≤ 24. ✓
This yields **(0, 6)** — the same point as Corner B.
Both constraint lines pass through (0, 6), so it is a single vertex where both are simultaneously binding.

---

**Corner D — y = 0 meets L1**
Set y = 0 in L1: 2x = 24 → x = 12.
Check L2: 3(12) + 5(0) = 36 > 30. ✗ **Infeasible.** Discard.

---

**Corner E — y = 0 meets L2**
Set y = 0 in L2: 3x = 30 → x = 10.
Check L1: 2(10) + 4(0) = 20 ≤ 24. ✓ Feasible.
Record **(10, 0)**.

---

**Corner F — L1 ∩ L2 (interior intersection)**

Solve the 2×2 system:
```
2x + 4y = 24   … (1)
3x + 5y = 30   … (2)
```
Multiply (1) by 3 and (2) by 2:
```
6x + 12y = 72
6x + 10y = 60
```
Subtract: 2y = 12 → **y = 6**.
Back-substitute into (1): 2x + 24 = 24 → **x = 0**.

The interior intersection is (0, 6) — already found on the y-axis. The two constraint lines share only this one first-quadrant point; they do **not** produce an interior vertex. This confirms the feasible region is the triangle with vertices **(0, 0)**, **(0, 6)**, **(10, 0)**.

### 3. Objective Evaluated at Every Vertex

| Vertex  | Z = 20x + 30y                  |
|---------|-------------------------------|
| (0, 0)  | 20(0) + 30(0) = **$0**        |
| (0, 6)  | 20(0) + 30(6) = **$180**      |
| (10, 0) | 20(10) + 30(0) = **$200** ← maximum |

### 4. Optimal Solution

**x = 10 chairs, y = 0 tables, Z = $200/day.**

This is consistent with intuition: chairs earn $10 per labor-hour and $6.67 per kg of wood; tables earn $7.50/hour and $6.00/kg. Chairs dominate on both scarce resources, so the LP naturally pushes all production to chairs.

**Integrality note:** The problem implies integer quantities (whole chairs and tables). The LP optimum (10, 0) is already integer-valued, so no rounding is needed and no integrality gap exists.

---

## Verification

Plug x = 10, y = 0 into every constraint.

**Labor constraint**
2(10) + 4(0) = 20 + 0 = **20 ≤ 24** ✓
Slack = 24 − 20 = 4 hours. **Not binding.**

**Wood constraint**
3(10) + 5(0) = 30 + 0 = **30 ≤ 30** ✓
Slack = 30 − 30 = 0 kg. **Binding** — all wood is consumed.

**Non-negativity**
x = 10 ≥ 0 ✓
y = 0 ≥ 0 ✓

**Objective value**
Z = 20 × 10 + 30 × 0 = 200 + 0 = **$200**

All constraints satisfied; the wood constraint is the single binding resource at optimality. Maximum daily profit is **$200**, achieved by producing **10 chairs and 0 tables**.

# Constraint Optimization Report

**Problem:** A furniture workshop produces chairs and tables. Each chair requires 2 hours of labor and 3 kg of wood, earning $20 profit. Each table requires 4 hours of labor and 5 kg of wood, earning $30 profit. The workshop has 24 hours of labor and 30 kg of wood available per day. Both quantities must be non-negative. Maximize daily profit.

**Solver status:** `Optimal`
**Optimal objective value:** 200

**Decision variables:**
  - Chair = 10
  - Table = 0

## Interpretation

This optimization result tells us that to maximize daily profit, the workshop should produce 10 chairs and 0 tables. The optimal daily profit is $200. All constraints are binding – meaning the workshop is using exactly all available labor hours (24 hours) and wood (30 kg). This suggests a highly efficient production strategy focusing solely on chair manufacturing to fully utilize resources and achieve maximum profitability.

## Solution Verification

Let ‘x’ be the number of chairs produced and ‘y’ be the number of tables produced. We want to maximize the objective function: Profit = 20x + 30y, subject to the constraints:
* Labor: 2x + 4y ≤ 24
* Wood: 3x + 5y ≤ 30
* Non-negativity: x ≥ 0, y ≥ 0

Solving this linear program yields an optimal solution of x = 10 and y = 0. Let’s verify the constraints:

**Constraint 1 (Labor):** 2(10) + 4(0) = 20 ≤ 24  (Satisfied, Binding)
**Constraint 2 (Wood):** 3(10) + 5(0) = 30 ≤ 30  (Satisfied, Binding)

Now let’s calculate the optimal profit:
Profit = 20x + 30y = 20(10) + 30(0) = 200 + 0 = $200.

The solver reports an optimal objective value of $200, which matches our calculation. Therefore, the solution is correct.

from pulp import *

# Create the LP problem
prob = LpProblem("Furniture Production", LpMaximize)

# Define decision variables
chair_var = LpVariable('Chair', lowBound=0, cat='Integer')
table_var = LpVariable('Table', lowBound=0, cat='Integer')

# Set the objective function
prob += 20 * chair_var + 30 * table_var, "Total Profit"

# Add constraints
prob += 2 * chair_var + 4 * table_var <= 24, "Labor Constraint"
prob += 3 * chair_var + 5 * table_var <= 30, "Wood Constraint"

# Solve the problem
prob.solve(pulp.PULP_CBC_CMD(msg=0))

# Store the results
_result = {
    "status": pulp.LpStatus[prob.status],
    "objective": pulp.value(prob.objective),
    "variables": {v.name: pulp.value(v) for v in prob.variables()}
}

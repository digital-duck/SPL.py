# Constraint Optimization Report

**Problem:** A factory makes chairs (2h labor, 4kg wood, $20 profit) and tables (4h labor, 3kg wood, $30 profit). Available: 20h labor, 24kg wood. Maximize profit.

**Solver status:** `Optimal`
**Optimal objective value:** 168

**Decision variables:**
  - chairs = 3.6
  - tables = 3.2

## Interpretation

**Optimal Decision:** Produce 3.6 chairs and 3.2 tables per production cycle. Since fractional units aren't practical, rounding to 4 chairs and 3 tables yields $170 profit — verify feasibility before implementing.

**Optimal Profit:** $168 (continuous optimum).

**Binding Constraints:** Both constraints are fully exhausted — all 20 labor hours and all 24 kg of wood are used. There is zero slack in either resource.

**Recommendation:** Since both resources are simultaneously maxed out, any profit improvement requires acquiring more labor *and* more wood together — relaxing only one constraint will not increase output.

## Solver Code (LLM-generated, PuLP)

```python
prob = pulp.LpProblem("factory_profit", pulp.LpMaximize)

chairs = pulp.LpVariable("chairs", lowBound=0)
tables = pulp.LpVariable("tables", lowBound=0)

prob += 20 * chairs + 30 * tables

prob += 2 * chairs + 4 * tables <= 20
prob += 4 * chairs + 3 * tables <= 24

prob.solve(pulp.PULP_CBC_CMD(msg=0))

_result = {
    "status": pulp.LpStatus[prob.status],
    "objective": pulp.value(prob.objective),
    "variables": {v.name: pulp.value(v) for v in prob.variables()}
}
```
